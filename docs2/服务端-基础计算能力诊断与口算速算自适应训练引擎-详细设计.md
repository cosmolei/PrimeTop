# 服务端-基础计算能力诊断与口算速算自适应训练引擎 详细设计

## 1. 模块概述

### 1.1 功能定位

基础计算能力是小学阶段数学学习的基石。本引擎面向小学一年级至六年级学生（可向上延伸至初一），提供口算、竖式计算、混合运算等基础计算能力的 **诊断 → 训练 → 评估 → 巩固** 全闭环服务。

核心目标：
1. **精准诊断**：通过少量测试题快速标定学生在加减乘除、混合运算、简便运算等维度上的能力水平。
2. **自适应训练**：基于诊断结果和学生历史表现，动态生成难度合适的练习题集。
3. **速度与正确率双维度提升**：跟踪答题速度和正确率变化趋势，自动调节难度梯度。
4. **融入学习闭环**：与错题本、知识点掌握度、学习规划、成就系统等模块联动。

### 1.2 适用学段

| 学段 | 核心训练内容 |
| --- | --- |
| 一年级 | 20以内加减法、比大小 |
| 二年级 | 100以内加减法、乘法口诀表 |
| 三年级 | 一位数乘除法、两位数乘除法、混合运算 |
| 四年级 | 多位数乘除法、四则混合运算、简便运算 |
| 五年级 | 小数加减乘除、分数基本运算 |
| 六年级 | 分数四则运算、百分数运算、复杂混合运算 |
| 初一（扩展） | 有理数运算、整式加减 |

### 1.3 设计原则

- **短时高频**：单次训练 3~5 分钟，适合碎片化练习。
- **难度梯度平滑**：题目难度细粒度分级，避免难度跳跃打击信心。
- **正向反馈即时**：每题即时批改，训练结束即时生成报告。
- **数据驱动**：所有训练数据沉淀至学习画像，反哺推荐和规划。

### 2.2 模块职责边界

| 模块 | 职责 | 不做的事 |
| --- | --- | --- |
| 诊断模块 | 短测试序列编排、能力标定 | 不负责日常训练出题 |
| 出题引擎 | 根据参数生成/检索计算题 | 不负责应用题/几何题 |
| 批改评估 | 答案判定、用时统计、速度评分 | 不做主观题批改 |

| 分析报告 | 训练报告生成、趋势统计 | 不替代学情分析主服务 |

```typescript
enum CalcDimension {
  ADDITION = 'addition',           // 加法
  SUBTRACTION = 'subtraction',     // 减法
  MULTIPLICATION = 'multiplication', // 乘法
  DIVISION = 'division',           // 除法
  MIXED = 'mixed',                 // 四则混合运算
  SIMPLIFY = 'simplify',           // 简便运算
  DECIMAL = 'decimal',             // 小数运算
  FRACTION = 'fraction',           // 分数运算
  PERCENT = 'percent',             // 百分数运算
  NEGATIVE = 'negative',           // 有理数（负数）运算
}

/** 运算类型 */
enum OperationType {
  ORAL = 'oral',           // 口算（心算）
  VERTICAL = 'vertical',   // 竖式计算
  EQUATION = 'equation',   // 解方程（含未知数）
}

/** 题目呈现格式 */
enum ProblemFormat {
  PLAIN = 'plain',         // 纯文本算式：3 + 5 = ?
  COMPARISON = 'comparison', // 比大小：3+5 ○ 4+3
  FILL_BLANK = 'fill_blank', // 填空：3 + ? = 8
  SEQUENCE = 'sequence',   // 数列规律：2, 4, 6, ?, 10
```

```typescript
  // 数值范围

  maxValue: number;

  // 是否含括号

  // 是否允许负数结果

  // 限时（秒），0表示不限时
  timeLimitPerProblem: number;
}
```

## 4. 出题引擎（Problem Generator）

### 4.1 出题策略

出题引擎支持两种模式：

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| **规则生成** | 根据参数模板随机生成算式 | 日常训练、挑战模式（无限题目） |
| **题库检索** | 从预置题库中按标签检索 | 诊断测试、竞赛专题（质量可控） |

### 4.2 规则生成算法

#### 4.2.1 核心生成流程

```typescript
class ProblemGenerator {
  /**
   * 根据参数生成一道计算题
   */
  generate(params: CalcParams, dimension: CalcDimension, format: ProblemFormat): SessionProblem {
    switch (dimension) {
      case CalcDimension.ADDITION:
        return this.generateAddition(params, format);
      case CalcDimension.SUBTRACTION:
        return this.generateSubtraction(params, format);
      case CalcDimension.MULTIPLICATION:
        return this.generateMultiplication(params, format);
      case CalcDimension.DIVISION:
        return this.generateDivision(params, format);
      case CalcDimension.MIXED:
        return this.generateMixed(params, format);
      case CalcDimension.SIMPLIFY:
        return this.generateSimplify(params, format);
      case CalcDimension.DECIMAL:
        return this.generateDecimal(params, format);
      case CalcDimension.FRACTION:
        return this.generateFraction(params, format);
      default:
        throw new Error(`Unsupported dimension: ${dimension}`);
    }
  }

  /**
   * 加法生成
   */
  private generateAddition(params: CalcParams, format: ProblemFormat): SessionProblem {
    const operands: number[] = [];
    for (let i = 0; i < params.operandCount; i++) {
      operands.push(this.randomInt(params.minValue, params.maxValue));
    }

    // 如果要求进位，重新生成直到满足条件
    if (params.requireCarry && operands.length === 2) {
      while (!this.hasCarry(operands[0], operands[1])) {
        operands[0] = this.randomInt(params.minValue, params.maxValue);
        operands[1] = this.randomInt(params.minValue, params.maxValue);
      }
    }

    const answer = operands.reduce((a, b) => a + b, 0);
    const operators = Array(params.operandCount - 1).fill('+');
    const expression = this.buildExpression(operands, operators);

    return {
      problemId: this.hashProblem(expression),
      expression,
      format,
      dimension: CalcDimension.ADDITION,
      difficultyLevel: params.level,
      operands,
      operators,
      correctAnswer: answer,
      hint: this.generateHint(dimension='addition', operands),
    };
  }

  /**
   * 除法生成（确保整除或按要求产生余数）
   */
  private generateDivision(params: CalcParams, format: ProblemFormat): SessionProblem {
    // 先生成除数和商，再反推被除数，保证整除
    const divisor = this.randomInt(params.minValue, Math.min(params.maxValue, 99));
    const quotient = this.randomInt(1, params.maxValue);

    let dividend: number;
    if (params.allowRemainder) {
      // 允许有余数
      const remainder = this.randomInt(0, divisor - 1);
      dividend = divisor * quotient + remainder;
    } else {
      // 必须整除
      dividend = divisor * quotient;
    }

    const operands = [dividend, divisor];
    const operators = ['÷'];
    const expression = `${dividend} ÷ ${divisor} = ?`;
    const correctAnswer = params.allowRemainder
      ? `${quotient}......${dividend - divisor * quotient}`
      : quotient;

    return {
      problemId: this.hashProblem(expression),
      expression,
      format,
      dimension: CalcDimension.DIVISION,
      difficultyLevel: params.level,
      operands,
      operators,
      correctAnswer,
    };
  }

  /**
   * 混合运算生成
   */
  private generateMixed(params: CalcParams, format: ProblemFormat): SessionProblem {
    const opPool = ['+', '-', '×', '÷'];
    const operands: number[] = [];
    const operators: string[] = [];
    const hasParen = params.hasParentheses && Math.random() > 0.5;

    // 生成运算项
    for (let i = 0; i < params.operandCount; i++) {
      operands.push(this.randomInt(params.minValue, params.maxValue));
    }
    // 生成运算符
    for (let i = 0; i < params.operandCount - 1; i++) {
      operators.push(opPool[this.randomInt(0, opPool.length - 1)]);
    }

    // 确保混合运算合法（如除法需整除）
    this.adjustForValidity(operands, operators);

    // 加入括号
    const expression = hasParen
      ? this.insertParentheses(operands, operators)
      : this.buildExpression(operands, operators);

    const correctAnswer = this.evaluateExpression(operands, operators, hasParen);

    return {
      problemId: this.hashProblem(expression),
      expression,
      format,
      dimension: CalcDimension.MIXED,
      difficultyLevel: params.level,
      operands,
      operators,
      correctAnswer,
    };
  }

  /**
   * 分数运算生成
   */
  private generateFraction(params: CalcParams, format: ProblemFormat): SessionProblem {
    const maxDen = params.fractionDenominatorMax || 12;
    const opPool = ['+', '-'];
    const operator = opPool[this.randomInt(0, opPool.length - 1)];

    // 生成两个分数
    const f1 = this.generateFractionValue(maxDen);
    const f2 = this.generateFractionValue(maxDen);

    // 确保减法结果为正
    let fractions = [f1, f2];
    if (operator === '-' && f1.value < f2.value) {
      fractions = [f2, f1];
    }

    const result = operator === '+'
      ? this.addFractions(fractions[0], fractions[1])
      : this.subtractFractions(fractions[0], fractions[1]);

    const expression = `${fractions[0].repr} ${operator} ${fractions[1].repr} = ?`;
    const correctAnswer = result.repr; // "a/b" 或 "c" (整数)

    return {
      problemId: this.hashProblem(expression),
      expression,
      format,
      dimension: CalcDimension.FRACTION,
      difficultyLevel: params.level,
      operands: [fractions[0].value, fractions[1].value],
      operators: [operator],
      correctAnswer,
    };
  }

  // ===== 工具方法 =====

  private randomInt(min: number, max: number): number {
    return Math.floor(Math.random() * (max - min + 1)) + min;
  }

  /**
   * 检查加法是否有进位
   */
  private hasCarry(a: number, b: number): boolean {
    while (a > 0 || b > 0) {
      if ((a % 10) + (b % 10) >= 10) return true;
      a = Math.floor(a / 10);
      b = Math.floor(b / 10);
    }
    return false;
  }

  /**
   * 计算表达式（安全求值，不使用eval）
   */
  private evaluateExpression(operands: number[], operators: string[], hasParen: boolean): number {
    // 先乘除后加减，处理括号优先级
    // 使用调度场算法或递归下降解析
    return this.safeEval(operands, operators, hasParen);
  }

  /**
   * 题目哈希（用于去重和ID生成）
   */
  private hashProblem(expression: string): string {
    const crypto = require('crypto');
    return crypto.createHash('sha256').update(expression).digest('hex').substring(0, 16);
  }
}
```

```typescript
class DedupManager {
  private recentProblems: Set<string>;  // 当前会话已出题目哈希
  private userHistoryCache: Set<string>; // 用户近期答过的题目哈希（Redis）

  /**

  ensureUnique(generator: () => SessionProblem, maxRetries = 10): SessionProblem {

      const problem = generator();
      if (!this.recentProblems.has(problem.problemId) &&
          !this.userHistoryCache.has(problem.problemId)) {
        this.recentProblems.add(problem.problemId);
        return problem;
      }
    }
    // 重试到上限仍重复，降低参数范围再试
    return generator();
  }
```

### 4.3 出题批次编排

```typescript
class SessionPlanner {
  /**
   * 为一次训练会话编排题目列表
   * @param sessionId  会话ID
   * @param dimensions 目标维度
   * @param baseLevel  基准难度
   * @param count      题目数量
   * @param adaptive   是否启用自适应
   */
  planSession(
    dimensions: CalcDimension[],
    baseLevel: number,
    count: number,
    adaptive: boolean
  ): SessionProblem[] {
    const problems: SessionProblem[] = [];

    // 阶段1: 热身题（难度-1，占15%）
    const warmupCount = Math.max(2, Math.floor(count * 0.15));
    for (let i = 0; i < warmupCount; i++) {
      const dim = this.pickDimension(dimensions);
      const level = Math.max(1, baseLevel - 1);
      problems.push(this.generator.generate(this.getParams(dim, level), dim, ProblemFormat.PLAIN));
    }

    // 阶段2: 核心题（基准难度，占50%）
    const coreCount = Math.floor(count * 0.5);
    for (let i = 0; i < coreCount; i++) {
      const dim = this.pickDimension(dimensions);
      problems.push(this.generator.generate(this.getParams(dim, baseLevel), dim, this.pickFormat()));
    }

    // 阶段3: 拔高题（难度+1~+2，占20%）
    const challengeCount = Math.floor(count * 0.2);
    for (let i = 0; i < challengeCount; i++) {
      const dim = this.pickDimension(dimensions);
      const level = Math.min(10, baseLevel + this.generator.randomInt(1, 2));
      problems.push(this.generator.generate(this.getParams(dim, level), dim, ProblemFormat.PLAIN));
    }

    // 阶段4: 趣味题（变换格式，占15%）
    const funCount = count - warmupCount - coreCount - challengeCount;
    for (let i = 0; i < funCount; i++) {
      const dim = this.pickDimension(dimensions);
      problems.push(this.generator.generate(
        this.getParams(dim, baseLevel), dim, ProblemFormat.SEQUENCE
      ));
    }

    // 打乱顺序（但保持热身在前2题）
    return this.shuffleKeepingFirst(problems, warmupCount);
  }
}
```

## 5. 难度自适应调控（Adaptive Difficulty Controller）

### 5.1 自适应算法

采用基于 **项目反应理论（IRT）简化模型** 的自适应调控：

```
核心逻辑：
- 连续答对 N 题 → 难度 +1
- 连续答错 M 题 → 难度 -1
- 用时过快（S/A级）→ 加分奖励翻倍
- 用时过慢（D级）→ 不降难度但减少题量
```

### 5.2 参数配置

```typescript
class AdaptiveController {
  private config: AdaptiveConfig;
  private history: AnswerRecord[];   // 滑动窗口

  /**
   * 根据最近答题表现，决定下一题难度
   */
  decideNextLevel(currentLevel: number): { level: number; reason: string } {
    const recent = this.getRecentRecords(this.config.slidingWindowSize);
    const accuracy = this.calculateAccuracy(recent);
    const [low, high] = this.config.accuracyComfortZone;

    // 规则1: 连续错误 → 降难度
    const consecutiveWrong = this.countConsecutive(recent, false);
    if (consecutiveWrong >= this.config.consecutiveWrongToLevelDown) {
      const newLevel = Math.max(this.config.minLevel, currentLevel - 1);
      return { level: newLevel, reason: `连续${consecutiveWrong}题错误，降低难度` };
    }

    // 规则2: 连续正确 → 升难度
    const consecutiveCorrect = this.countConsecutive(recent, true);
    if (consecutiveCorrect >= this.config.consecutiveCorrectToLevelUp) {
      const newLevel = Math.min(this.config.maxLevel, currentLevel + 1);
      return { level: newLevel, reason: `连续${consecutiveCorrect}题正确，提升难度` };
    }

    // 规则3: 正确率过低 → 降难度
    if (recent.length >= 3 && accuracy < low) {
      const newLevel = Math.max(this.config.minLevel, currentLevel - 1);
      return { level: newLevel, reason: `正确率${(accuracy * 100).toFixed(0)}%低于阈值` };
    }

    // 规则4: 正确率很高但用时很慢 → 维持难度（巩固速度）
    if (accuracy >= high && this.avgSpeedGrade(recent) === SpeedGrade.D) {
      return { level: currentLevel, reason: '正确率达标，维持难度提升速度' };
    }

    // 默认: 维持当前难度
    return { level: currentLevel, reason: '维持当前难度' };
  }

  /**
   * 计算速度评级
   */
  calculateSpeedGrade(timeUsedMs: number, expectedMs: number): SpeedGrade {
    const ratio = timeUsedMs / expectedMs;
    if (ratio <= 0.5) return SpeedGrade.S;
    if (ratio <= 0.7) return SpeedGrade.A;
    if (ratio <= 1.0) return SpeedGrade.B;
    if (ratio <= 1.3) return SpeedGrade.C;
    return SpeedGrade.D;
  }
}
```

### 5.4 能力等级更新（IRT模型简化版）

```typescript
class ProficiencyUpdater {
  /**
   * 每次答题后更新能力等级
   * 使用简化版 Elo 评分更新公式
   *
   * @param currentLevel  当前能力等级
   * @param problemLevel  题目难度
   * @param isCorrect     是否正确
   * @param timeRatio     用时比 (实际/期望)
   * @returns 新的能力等级
   */
  updateProficiency(
    currentLevel: number,
    problemLevel: number,
    isCorrect: boolean,
    timeRatio: number
  ): number {
    // K因子：能力等级越高，变化越慢
    const K = 0.3 - currentLevel * 0.02;

    // 预期正确概率（基于难度差）
    const levelDiff = problemLevel - currentLevel;
    const expectedScore = 1 / (1 + Math.pow(10, levelDiff / 4));

    // 实际得分（正确=1, 错误=0），加入速度因子
    const speedFactor = isCorrect ? Math.max(0.5, Math.min(1.5, 1.0 / timeRatio)) : 0;
    const actualScore = isCorrect ? 1 : 0;

    // 更新公式
    const delta = K * speedFactor * (actualScore - expectedScore);
    const newLevel = currentLevel + delta;

    // 约束到 [1.0, 10.0]
    return Math.max(1.0, Math.min(10.0, Math.round(newLevel * 10) / 10));
  }
}
```

## 6. 诊断模块（Diagnostic Engine）

### 6.1 诊断设计

诊断测试通过 **少量精选题目** 快速标定学生各维度能力等级，用于：
- 新用户首次使用时的冷启动能力评估
- 学期初/学段切换时的能力基线重置
- 长期未练习后的能力衰退检测

### 6.2 诊断流程

```
开始诊断
  │
  ▼
选择目标年级 → 确定诊断维度集合
  │
  ▼
第1轮：每个维度出2道 Level 3 的题（探测基线）
  │
  ▼
根据第1轮正确率 → 二叉搜索调整难度
  ├─ 正确率 ≥ 75% → 第2轮出 Level 5 的题
  ├─ 正确率 25%~75% → 第2轮出 Level 3 的题
  └─ 正确率 ≤ 25% → 第2轮出 Level 1 的题
  │
  ▼
根据第2轮结果 → 精确定位能力等级
  │
  ▼
生成诊断报告 → 写入能力画像
```

### 6.3 诊断题目编排

```typescript
class DiagnosticPlanner {
  /**
   * 为指定年级生成诊断测试卷
   * 总题数：维度数 × 4题 = 约 16~28 题
   * 预计用时：5~8 分钟
   */
  planDiagnostic(grade: number): SessionProblem[] {
    // 根据年级确定需诊断的维度
    const dimensions = this.getDimensionsForGrade(grade);
    const problems: SessionProblem[] = [];

    for (const dim of dimensions) {
      // 每维度4题：Level 2, 3, 4, 5 各一题
      const levels = [2, 3, 4, 5];
      for (const level of levels) {
        const params = this.getDifficultyTemplate(grade, dim, level);
        const problem = this.generator.generate(params, dim, ProblemFormat.PLAIN);
        problem.seq = problems.length;
        problems.push(problem);
      }
    }

    // 打乱但确保同维度题目不相邻
    return this.interleave(problems, dimensions.length);
  }

  /**
   * 根据诊断结果计算各维度初始能力等级
   */
  evaluateDiagnostic(answers: SessionProblem[]): Map<CalcDimension, number> {
    const dimAnswers = new Map<CalcDimension, SessionProblem[]>();

    // 按维度分组
    for (const a of answers) {
      if (!dimAnswers.has(a.dimension)) {
        dimAnswers.set(a.dimension, []);
      }
      dimAnswers.get(a.dimension)!.push(a);
    }

    const results = new Map<CalcDimension, number>();
    for (const [dim, records] of dimAnswers) {
      const level = this.estimateLevel(records);
      results.set(dim, level);
    }

    return results;
  }

  /**
   * 使用最大似然估计计算能力等级
   */
  private estimateLevel(records: SessionProblem[]): number {
    // 对每个难度级别的题目，统计正确数
    const levelStats = new Map<number, { total: number; correct: number }>();
    for (const r of records) {
      if (!levelStats.has(r.difficultyLevel)) {
        levelStats.set(r.difficultyLevel, { total: 0, correct: 0 });
      }
      const s = levelStats.get(r.difficultyLevel)!;
      s.total++;
      if (r.isCorrect) s.correct++;
    }

    // 找到正确率最接近50%的难度级别作为估计值
    // 这是IRT中能力估计的简化方法
    let bestLevel = 3;
    let minDiff = Infinity;

    for (const [level, stats] of levelStats) {
      const accuracy = stats.correct / stats.total;
      const diff = Math.abs(accuracy - 0.5);
      if (diff < minDiff) {
        minDiff = diff;
        bestLevel = level;
      }
    }

    // 微调：如果该级别正确率 > 75%，上浮0.5
    const bestStats = levelStats.get(bestLevel)!;
    const bestAccuracy = bestStats.correct / bestStats.total;
    if (bestAccuracy > 0.75) bestLevel += 0.5;
    else if (bestAccuracy < 0.25) bestLevel -= 0.5;

    return Math.max(1.0, Math.min(10.0, bestLevel));
  }
}
```

### 8.2 诊断测试流程

```typescript
// 诊断测试是特殊训练，type=diagnose，不支持自适应
// 固定题数，固定难度序列（Level 2/3/4/5 各一题）

async function startDiagnostic(userId: string, grade: number) {
  // 1. 检查是否已有诊断记录
  const existing = await proficiencyService.get(userId);
  if (existing && existing.some(p => p.totalSessions > 0)) {
    return { error: 'DIAGNOSIS_ALREADY_DONE', message: '已完成诊断，无需重复' };
  }

  // 2. 编排诊断卷
  const problems = diagnosticPlanner.planDiagnostic(grade);

  // 3. 创建会话
  const session = await sessionService.create({
    userId,
    practiceType: PracticeType.DIAGNOSE,
    dimensions: problems.map(p => p.dimension),
    grade,
    startLevel: 3,  // 诊断起点
    problems,
    status: SessionStatus.CREATED,
  });

  // 4. 返回首题
  return {
    sessionId: session.uuid,
    totalProblems: problems.length,
    firstProblem: problems[0],
  };
}

async function finishDiagnostic(sessionId: string) {
  const session = await sessionService.getById(sessionId);

  // 1. 评估各维度能力
  const results = diagnosticPlanner.evaluateDiagnostic(session.problems);

  // 2. 批量写入能力画像
  for (const [dim, level] of results) {
    await proficiencyService.upsert(session.userId, dim, {
      proficiencyLevel: level,
      totalProblems: session.problems.filter(p => p.dimension === dim).length,
      totalSessions: 1,
      lastPracticeTime: new Date(),
    });
  }

  // 3. 生成诊断报告
  const report = generateDiagnosticReport(session, results);

  // 4. 通知学习规划服务（基于诊断结果调整计划）
  await eventBus.emit('mental-math.diagnosis.completed', {
    userId: session.userId,
    dimensions: Object.fromEntries(results),
    grade: session.grade,
  });

  return report;
}
```

## 9. 奖励与激励体系

### 9.1 积分/经验计算

```typescript
class RewardCalculator {
  /**
   * 计算单题奖励
   */
  calculateProblemReward(
    difficultyLevel: number,
    isCorrect: boolean,
    speedGrade: SpeedGrade,
    streakBonus: boolean
  ): { exp: number; coins: number } {
    if (!isCorrect) {
      // 错题也给少量经验（鼓励参与）
      return { exp: 1, coins: 0 };
    }

    // 基础经验 = 难度 × 5
    const baseExp = difficultyLevel * 5;
    // 速度倍率
    const speedMultiplier = ADAPTIVE_CONFIG.speedBonusMultiplier[speedGrade];
    // 连胜奖励
    const streakMultiplier = streakBonus ? 1.5 : 1.0;

    const exp = Math.round(baseExp * speedMultiplier * streakMultiplier);
    const coins = Math.max(1, Math.round(difficultyLevel * speedMultiplier / 2));

    return { exp, coins };
  }

  /**
   * 计算训练完成奖励
   */
  calculateSessionBonus(summary: SessionSummary): { exp: number; coins: number } {
    let bonusExp = 0;

    // 全对奖励
    if (summary.correctCount === summary.totalProblems) {
      bonusExp += 50;
    }
    // 高正确率奖励
    if (summary.accuracy >= 0.9) {
      bonusExp += 30;
    }
    // 速度奖励
    if (summary.speedGrade === SpeedGrade.S || summary.speedGrade === SpeedGrade.A) {
      bonusExp += 20;
    }
    // 连续打卡奖励
    bonusExp += Math.min(50, summary.streakDays * 5);

    return { exp: bonusExp, coins: Math.round(bonusExp / 5) };
  }
}
```

```typescript
class MentalMathErrorHandler {
  /**
   * 出题失败时的降级策略
   */
  async handleGenerationFailure(
    dimension: CalcDimension,
    level: number
  ): Promise<SessionProblem> {
    try {
      // 降级1: 从预置题库检索
      const problem = await problemBankService.getByDimensionAndLevel(dimension, level);
      if (problem) return problem;

      // 降级2: 使用固定种子生成简单题
      return this.generateFallbackProblem(dimension, level);
    } catch (e) {
      // 最终降级: 返回超简单加法
      return {
        problemId: 'fallback_001',
        expression: '1 + 1 = ?',
        format: ProblemFormat.PLAIN,
        dimension: CalcDimension.ADDITION,
        difficultyLevel: 1,
        operands: [1, 1],
        operators: ['+'],
        correctAnswer: 2,
      };
    }
  }

  /**
   * 超时处理
   */
  handleAnswerTimeout(sessionId: string, seq: number): AnswerResult {
    // 记录为未作答（错误）
    return {
      seq,
      isCorrect: false,
      correctAnswer: null,
      userAnswer: null,
      timedOut: true,
      expEarned: 0,
      coinsEarned: 0,
    };
  }
}
```

### 14.1 性能指标

| 指标 | 目标值 |
| --- | --- |
| 出题延迟 | < 50ms（规则生成）/ < 20ms（缓存检索） |
| 答题批改延迟 | < 30ms |
| 训练报告生成 | < 200ms |
| 能力画像查询 | < 50ms（缓存）/ < 200ms（DB） |
| 并发训练支持 | 5000 QPS（单节点） |

### 14.2 优化策略

1. **题目预生成**：后台定时任务预生成各难度题目缓存到 Redis Queue，出题时直接 pop。
2. **批量写入**：答题记录先写 Redis，异步批量刷入 MySQL。
3. **能力画像延迟更新**：高频更新先写缓存，低频刷入数据库。
4. **难度模板全量缓存**：所有年级×维度×级别组合（约6×10×10=600条）全量缓存到本地内存。

## 16. 测试要点

### 16.1 单元测试重点

| 模块 | 测试点 |
| --- | --- |
| 出题引擎 | 各维度题目生成正确性、边界值（max/min）、进退位约束、整除保证 |
| 批改引擎 | 整数/小数/分数/带余数答案判定、大小写无关、空白处理 |
| 自适应控制 | 连续正确升难度、连续错误降难度、正确率区域维持 |
| 能力等级更新 | Elo公式收敛性、边界值（1.0和10.0）、速度因子影响 |
| 去重 | 同会话不重复、不与近期重复 |
| 奖励计算 | 难度×速度×连胜、全对bonus、封顶值 |

### 16.2 集成测试场景

```
场景1: 新用户完整流程
  注册 → 首次诊断 → 查看能力画像 → 开始每日训练 → 答题10题 → 查看报告
  预期：诊断结果正确写入画像，训练难度从诊断等级开始

场景2: 自适应难度调节
  从Level 3开始 → 连续答对3题 → 难度升至Level 4 → 连续答错2题 → 难度降回Level 3
  预期：难度变化记录在summary中，能力等级同步更新

场景3: 错题联动
  答错一题 → 错题本中出现该题 → 标签为"计算错误"
  预期：事件正确发布，错题本服务消费成功

场景4: 并发防护
  同用户同时发起两个训练 → 第二个被拒绝
  预期：返回MM_004错误

场景5: 诊断多维度
  三年级学生诊断 → 测试加/减/乘/除四个维度 → 各维度能力独立评估
  预期：画像中有4条维度记录，等级各不相同
```

### 19.3 术语表

| 术语 | 说明 |
| --- | --- |
| IRT | Item Response Theory，项目反应理论，用于根据答题表现估计能力 |
| Elo | Elo评分系统，常用于国际象棋等竞技排名，此处用于能力等级动态更新 |
| 进位 | 加法中某一位相加满10向高位进1 |
| 退位 | 减法中被减数某位不够减，向高位借1 |
| 口算 | 心算，不借助纸笔的直接计算 |
| 速度评级 | S>A>B>C>D 五档，S为最快 |
