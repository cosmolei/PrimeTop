# 学生考试备考状态智能评估与备考节奏动态调控引擎 - 详细设计

## 1. 概述

### 1.1 功能定位

本引擎是 PrimeTop 平台考试备考模块的**实时监控与动态调控中枢**，面向初中（中考）和高中（高考）场景，持续追踪学生在备考周期内的学习状态、知识掌握进度、复习效率和心理负荷，输出多维度的**备考就绪度评分（Exam Readiness Score, ERS）**，并基于评分结果动态调整备考节奏、学科时间分配和干预策略。

与已有模块的职责区分：

| 已有模块 | 职责范围 | 本引擎差异点 |
|---------|---------|-------------|
| 备考策略智能规划引擎 | 备考开始时的**初始策略制定**与考点优先级排序 | 本引擎在备考**执行过程中**持续监控并动态调控 |
| 考点梳理模块 | 考点知识内容的**组织与呈现** | 本引擎关注学生对考点的**掌握进度与效率** |
| 考试答题策略分析引擎 | 考试中的**答题技巧与时间分配** | 本引擎关注考试**前的准备状态** |
| 学习计划动态调整服务 | 通用学习计划的**通用调整** | 本引擎针对**考试备考**这一特定场景深度建模 |
| 学习投入度评估引擎 | 通用学习**投入度量化** | 本引擎将投入度映射到**备考就绪度**维度 |
| 考试焦虑识别引擎 | 考试焦虑的**识别与心理干预** | 本引擎将心理状态作为**就绪度的一个维度**纳入综合评估 |

### 1.2 设计目标

1. **实时感知**：每次学习行为发生后，5分钟内更新备考就绪度评分
2. **多维度评估**：覆盖知识掌握（40%）、练习表现（25%）、学习投入（15%）、心理状态（10%）、时间规划合理性（10%）五大维度
3. **主动预警**：在学生备考偏离轨道的早期阶段（如连续3天未复习某学科）主动触发预警
4. **动态调控**：根据就绪度变化趋势，每周自动输出节奏调整建议
5. **可视化**：为学生、家长、教师分别提供适配的就绪度看板

### 1.3 适用范围

- **用户角色**：初中生（中考备考）、高中生（高考备考）
- **触发条件**：学生设定考试目标后自动激活（如"2026年6月中考"）
- **关闭条件**：考试结束后自动归档，生成备考复盘报告

### 2.2 核心模块职责

| 模块 | 职责 | 输入 | 输出 |
|------|------|------|------|
| 数据采集层 | 汇聚学生学习行为、练习、计划执行等多源数据 | 各业务模块事件 | 标准化指标输入流 |
| 指标计算层 | 计算5个维度的子指标分数 | 标准化指标输入 | 维度评分 (0-100) |
| 评估输出层 | 加权合成就绪度总分，生成趋势和报告 | 维度评分 | ERS评分 + 趋势曲线 |
| 节奏调控器 | 基于ERS变化趋势输出节奏调整方案 | ERS趋势 + 学习计划 | 节奏调整建议 |
| 预警调度器 | 识别异常模式并触发分级预警 | ERS维度分解 + 阈值 | 预警事件 |
| 复盘分析器 | 考试结束后生成备考成效归因报告 | 备考全程数据 + 考试结果 | 复盘报告 |

## 3. 数据结构定义

### 3.1 备考目标与配置

```sql
-- 备考目标表
CREATE TABLE exam_prep_goal (
    id              BIGINT PRIMARY KEY COMMENT '主键ID',
    user_id         BIGINT NOT NULL COMMENT '学生用户ID',
    exam_type       VARCHAR(32) NOT NULL COMMENT '考试类型: MIDTERM/PEKING_EXAM/ZHONGKAO/GAOKAO/MOCK_EXAM',
    exam_date       DATE NOT NULL COMMENT '考试日期',
    target_score    INT COMMENT '目标分数（可选）',
    target_rank     VARCHAR(64) COMMENT '目标排名/等级（可选，如"前10%"）',
    subjects        JSON NOT NULL COMMENT '备考学科列表 ["math","physics","chinese",...]',
    priority_subjects JSON COMMENT '重点突破学科 ["math","physics"]',
    daily_available_minutes INT NOT NULL DEFAULT 180 COMMENT '每日可用备考时间（分钟）',
    weekend_available_minutes INT NOT NULL DEFAULT 360 COMMENT '周末可用备考时间（分钟）',
    status          VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' COMMENT '状态: ACTIVE/COMPLETED/ARCHIVED',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_status (user_id, status),
    INDEX idx_exam_date (exam_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='备考目标表';
```

### 3.2 备考就绪度评分表

```sql
-- 备考就绪度评分记录表（每天一条，按学科+总分两粒度）
CREATE TABLE exam_readiness_score (
    id                  BIGINT PRIMARY KEY COMMENT '主键ID',
    goal_id             BIGINT NOT NULL COMMENT '备考目标ID',
    user_id             BIGINT NOT NULL COMMENT '学生用户ID',
    score_date          DATE NOT NULL COMMENT '评分日期',
    subject             VARCHAR(16) NOT NULL COMMENT '学科，ALL表示综合',
    
    -- 五维评分
    knowledge_score     DECIMAL(5,2) NOT NULL COMMENT '知识掌握维度分 (0-100)',
    practice_score      DECIMAL(5,2) NOT NULL COMMENT '练习表现维度分 (0-100)',
    engagement_score    DECIMAL(5,2) NOT NULL COMMENT '学习投入维度分 (0-100)',
    psychology_score    DECIMAL(5,2) NOT NULL COMMENT '心理状态维度分 (0-100)',
    planning_score      DECIMAL(5,2) NOT NULL COMMENT '时间规划维度分 (0-100)',
    
    -- 综合评分
    overall_score       DECIMAL(5,2) NOT NULL COMMENT '综合就绪度评分 (0-100)',
    confidence_level    VARCHAR(16) NOT NULL COMMENT '置信度: LOW/MEDIUM/HIGH',
    
    -- 变化趋势
    delta_from_yesterday DECIMAL(5,2) COMMENT '较昨日变化',
    trend_7d            VARCHAR(16) COMMENT '7日趋势: RISING/STABLE/DECLINING/VOLATILE',
    
    -- 元数据
    data_completeness   DECIMAL(3,2) NOT NULL DEFAULT 1.0 COMMENT '数据完整度 0-1',
    evaluation_version  VARCHAR(16) NOT NULL COMMENT '评估算法版本',
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_goal_date_subject (goal_id, score_date, subject),
    INDEX idx_user_date (user_id, score_date),
    INDEX idx_goal_subject_date (goal_id, subject, score_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='备考就绪度评分表';
```

### 3.3 备考节奏调控记录表

```sql
-- 备考节奏调控记录表
CREATE TABLE exam_pace_adjustment (
    id                  BIGINT PRIMARY KEY COMMENT '主键ID',
    goal_id             BIGINT NOT NULL COMMENT '备考目标ID',
    user_id             BIGINT NOT NULL COMMENT '学生用户ID',
    adjustment_date     DATETIME NOT NULL COMMENT '调控时间',
    
    -- 触发原因
    trigger_type        VARCHAR(32) NOT NULL COMMENT '触发类型: SCHEDULED/THRESHOLD/ANOMALY/MANUAL',
    trigger_detail      JSON COMMENT '触发详情',
    
    -- 调控内容
    adjustments         JSON NOT NULL COMMENT '调控项列表',
    -- adjustments 结构示例:
    -- [
    --   {"type":"SUBJECT_TIME", "subject":"math", "from":60, "to":90, "reason":"..."},
    --   {"type":"DIFFICULTY", "subject":"math", "from":"MEDIUM", "to":"HARD", "reason":"..."},
    --   {"type":"ADD_REVIEW", "subject":"physics", "items":["力学综合","电磁感应"], "reason":"..."},
    --   {"type":"REDUCE_LOAD", "subject":"chinese", "from":60, "to":30, "reason":"已达到目标掌握度"}
    -- ]
    
    -- 执行状态
    status              VARCHAR(16) NOT NULL DEFAULT 'PENDING' COMMENT '状态: PENDING/APPLIED/REJECTED/EXPIRED',
    applied_at          DATETIME COMMENT '应用时间',
    user_feedback        VARCHAR(16) COMMENT '用户反馈: ACCEPTED/MODIFIED/REJECTED',
    
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_goal_status (goal_id, status),
    INDEX idx_user_date (user_id, adjustment_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='备考节奏调控记录表';
```

### 3.4 备考预警事件表

```sql
-- 备考预警事件表
CREATE TABLE exam_prep_alert (
    id                  BIGINT PRIMARY KEY COMMENT '主键ID',
    goal_id             BIGINT NOT NULL COMMENT '备考目标ID',
    user_id             BIGINT NOT NULL COMMENT '学生用户ID',
    
    alert_type          VARCHAR(32) NOT NULL COMMENT '预警类型',
    -- 类型枚举:
    -- SUBJECT_NEGLECT: 学科被忽视
    -- PROGRESS_BEHIND: 进度落后
    -- ENGAGEMENT_DROP: 投入度下降
    -- OVERLOAD_RISK: 过载风险
    -- ANXIETY_RISING: 焦虑上升
    -- MASTERY_STAGNANT: 掌握度停滞
    -- PLAN_DEVIATION: 计划偏离
    -- MOCK_SCORE_DECLINE: 模考成绩下滑
    
    severity            VARCHAR(16) NOT NULL COMMENT '严重程度: INFO/WARN/CRITICAL',
    subject             VARCHAR(16) COMMENT '关联学科（可空表示综合）',
    
    title               VARCHAR(128) NOT NULL COMMENT '预警标题',
    description         TEXT NOT NULL COMMENT '预警描述',
    metrics_snapshot    JSON NOT NULL COMMENT '触发时的指标快照',
    recommended_actions JSON NOT NULL COMMENT '建议操作列表',
    
    -- 处置状态
    status              VARCHAR(16) NOT NULL DEFAULT 'PENDING' COMMENT 'PENDING/ACKNOWLEDGED/RESOLVED/IGNORED',
    resolved_at         DATETIME COMMENT '解决时间',
    resolution          TEXT COMMENT '解决方式记录',
    
    -- 通知状态
    notified            BOOLEAN NOT NULL DEFAULT FALSE COMMENT '是否已通知用户',
    notify_channels     JSON COMMENT '已发送的通知渠道',
    
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_goal_severity (goal_id, severity, status),
    INDEX idx_user_status (user_id, status),
    INDEX idx_type_created (alert_type, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='备考预警事件表';
```

```sql

CREATE TABLE exam_prep_review (

    -- 备考周期

    final_ers           DECIMAL(5,2) COMMENT '最终就绪度评分',

    ers_trajectory      JSON COMMENT '就绪度变化轨迹 [{date, score}]',

    -- }
    
    -- 策略评估
    strategy_effectiveness JSON COMMENT '策略效果评估',
    -- 示例:
    -- {
    --   "most_effective": "错题集中复习",
    --   "least_effective": "盲目刷题",
    --   "time_allocation_score": 72.5,
    --   "pace_adherence_score": 68.0
    -- }

    improvement_suggestions JSON COMMENT '下次备考改进建议',

    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY uk_goal (goal_id),
    INDEX idx_user (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='备考复盘报告表';
```

## 5. 核心流程与算法

### 5.1 就绪度评分计算流程

```text
1. 事件摄入（练习/学习/计划/心理）
2. 特征聚合（近 1/3/7/14/30 天窗口）
3. 子指标计算（各维度 0-100 分）
4. 权重加权 → overall ERS
5. 置信度判定（数据完整度 ≥0.7 HIGH，≥0.4 MEDIUM，否则 LOW）
6. 趋势计算（7 天线性回归斜率 + 方差）
7. 持久化并发布 readiness.changed 事件
```

### 5.2 五维度评分公式

**知识掌握 (knowledge_score)**

```
knowledge_score = 40% * mastery_avg + 30% * coverage_rate*100 + 20% * weak_topic_progress + 10% * retention_index

mastery_avg      = Σ(topic_mastery_i) / topic_count
coverage_rate    = covered_topics / total_exam_topics
weak_topic_progress = 1 - (weak_topics_remaining / max(weak_topics_initial, 1))
retention_index  = 最近7天复习过的弱题掌握度提升均值
```

**练习表现 (practice_score)**

```
practice_score = 35% * correct_rate*100 + 25% * difficulty_progression + 20% * recent_improvement + 20% * mock_exam_trend

difficulty_progression = 当前平均难度 / 目标难度上限 * 100
recent_improvement     = (近7天正确率 - 前7天正确率) * 100，范围 [-20, 20]
mock_exam_trend        = 近3次模考平均分趋势，范围 [0, 100]
```

**学习投入 (engagement_score)**

```
engagement_score = 30% * active_day_ratio*100 + 25% * planned_time_completion + 25% * consistency_index + 20% * deep_focus_ratio*100

active_day_ratio      = 近7天活跃天数 / 7
planned_time_completion = min(实际学习分钟 / 计划分钟, 1.2) * 100
consistency_index     = 1 - σ(近14天每日学习分钟) / mean(...)
deep_focus_ratio       = 专注时段分钟 / 总学习分钟
```

**心理状态 (psychology_score)**

```
psychology_score = 30% * (100 - study_anxiety_score) + 25% * (100 - late_night_ratio*100) + 25% * confidence_index + 20% * fatigue_index

study_anxiety_score 来自考试焦虑引擎（0-100，越低越好）
late_night_ratio      = 23:00 后学习分钟 / 总学习分钟
confidence_index      = 近7天自我评估信心度均值
fatigue_index         = 基于学习强度与休息日的恢复指数
```

**时间规划 (planning_score)**

```
planning_score = 40% * plan_completion_rate*100 + 30% * schedule_balance_score*100 + 20% * buffer_time_score + 10% * milestone_adherence*100

plan_completion_rate  = 已完成计划项 / 总计划项
schedule_balance_score = 1 - 单科时间标准差 / 平均值
buffer_time_score     = min(剩余天数 / 完成剩余任务所需天数, 1.2) * 100
milestone_adherence   = 达成里程碑数 / 总里程碑数
```

**综合就绪度**

```
overall_score = 0.40*knowledge_score + 0.25*practice_score + 0.15*engagement_score + 0.10*psychology_score + 0.10*planning_score
```

### 5.3 节奏调控建议生成

**触发条件**

| 触发类型 | 条件 | 频控 |
| --- | --- | --- |
| SCHEDULED | 每周一 08:00 | 每周最多 1 次 |

### 6.1 就绪度评分计算器

```java
@Component
public class ReadinessScoreCalculator {

    public ExamReadinessScore calculate(Long goalId, LocalDate scoreDate) {
        ExamPrepGoal goal = goalRepository.findById(goalId)
            .orElseThrow(() -> new ExamPrepException(ExamPrepErrorCode.GOAL_NOT_FOUND));

        // 聚合近 30 天特征
        FeatureVector features = featureAggregator.aggregate(goal.getUserId(), goalId, scoreDate);

        // 计算五维分数
        double knowledge = calculateKnowledgeScore(features, goal);
        double practice = calculatePracticeScore(features, goal);
        double engagement = calculateEngagementScore(features, goal);
        double psychology = calculatePsychologyScore(features, goal);
        double planning = calculatePlanningScore(features, goal);

        // 综合评分
        double overall = 0.40 * knowledge + 0.25 * practice + 0.15 * engagement
                       + 0.10 * psychology + 0.10 * planning;

        // 置信度
        ConfidenceLevel confidence = determineConfidence(features.getCompletenessRatio());

        // 趋势
        Trend7d trend = calculateTrend(goalId, scoreDate);
        Double delta = calculateDeltaFromYesterday(goalId, scoreDate, overall);

        return ExamReadinessScore.builder()
            .goalId(goalId)
            .userId(goal.getUserId())
            .scoreDate(scoreDate)
            .subject("ALL")
            .knowledgeScore(round(knowledge))
            .practiceScore(round(practice))
            .engagementScore(round(engagement))
            .psychologyScore(round(psychology))
            .planningScore(round(planning))
            .overallScore(round(overall))
            .confidenceLevel(confidence)
            .trend7d(trend)
            .deltaFromYesterday(delta)
            .dataCompleteness(features.getCompletenessRatio())
            .evaluationVersion("v1.2")
            .build();
    }

    private ConfidenceLevel determineConfidence(double completeness) {
        if (completeness >= 0.70) return ConfidenceLevel.HIGH;
        if (completeness >= 0.40) return ConfidenceLevel.MEDIUM;
        return ConfidenceLevel.LOW;
    }
}
```

```java
@Service
public class PaceAdjustmentGenerator {

    public PaceRecommendation generate(Long goalId, TriggerType triggerType) {
        ExamPrepGoal goal = goalRepository.findById(goalId).orElseThrow();
        ReadinessSnapshot snapshot = snapshotService.getLatest(goalId);

        List<AdjustmentItem> adjustments = new ArrayList<>();

        // 学科时间再分配
        adjustments.addAll(rebalanceSubjectTime(goal, snapshot));

        // 难度提升/降低
        adjustments.addAll(adjustDifficulty(goal, snapshot));

        // 专题突破
        adjustments.addAll(suggestFocusTopics(goal, snapshot));

        // 强度调节
        adjustments.addAll(adjustIntensity(goal, snapshot));

        // 按优先级排序
        adjustments.sort(Comparator.comparing(AdjustmentItem::getPriority).reversed());

        return PaceRecommendation.builder()
            .goalId(goalId)
            .triggerType(triggerType)
            .summary(generateSummary(snapshot, adjustments))
            .currentStatus(mapCurrentStatus(snapshot, goal))
            .adjustments(adjustments)
            .projectedImpact(calculateProjectedImpact(snapshot, adjustments))
            .build();
    }

    private List<AdjustmentItem> rebalanceSubjectTime(ExamPrepGoal goal, ReadinessSnapshot snapshot) {
        List<AdjustmentItem> items = new ArrayList<>();
        double avgScore = snapshot.getSubjectScores().values().stream()
            .mapToDouble(Double::doubleValue).average().orElse(0);

        for (String subject : goal.getSubjects()) {
            double score = snapshot.getSubjectScores().getOrDefault(subject, avgScore);
            int currentMinutes = getCurrentDailyMinutes(goal, subject);
            if (score < avgScore - 10 && currentMinutes < 120) {
                int recommended = Math.min(currentMinutes + 30, 150);
                items.add(AdjustmentItem.builder()
                    .type(AdjustmentType.SUBJECT_TIME)
                    .subject(subject)
                    .currentMinutes(currentMinutes)
                    .recommendedMinutes(recommended)
                    .reason(String.format("%s就绪度(%.1f)低于均值，建议增加时间", subject, score))
                    .priority(Priority.HIGH)
                    .build());
            } else if (score > avgScore + 10 && currentMinutes > 30) {
                int recommended = Math.max(currentMinutes - 20, 20);
                items.add(AdjustmentItem.builder()
                    .type(AdjustmentType.SUBJECT_TIME)
                    .subject(subject)
                    .currentMinutes(currentMinutes)
                    .recommendedMinutes(recommended)
                    .reason(String.format("%s已达到较高就绪度(%.1f)，可适当减少", subject, score))
                    .priority(Priority.MEDIUM)
                    .build());
            }
        }
        return items;
    }
}
```

### 6.3 预警生成器

```java
@Component
public class AlertGenerator {

    public List<ExamPrepAlert> evaluateAlerts(Long goalId, LocalDate today) {
        List<ExamPrepAlert> newAlerts = new ArrayList<>();
        ExamPrepGoal goal = goalRepository.findById(goalId).orElseThrow();

        // 学科忽视检测
        for (String subject : goal.getSubjects()) {
            int daysSinceLastStudy = activityTracker.daysSinceLastStudy(goal.getUserId(), subject, today);
            if (daysSinceLastStudy >= 3) {
                newAlerts.add(buildSubjectNeglectAlert(goal, subject, daysSinceLastStudy));
            }
        }

        // 过载风险
        OverloadMetrics metrics = overloadDetector.detect(goal.getUserId(), goal, today);
        if (metrics.isAtRisk()) {
            newAlerts.add(buildOverloadAlert(goal, metrics));
        }

        // 焦虑上升
        AnxietySnapshot anxiety = anxietyClient.getLatest(goal.getUserId());
        if (anxiety != null && anxiety.getScore() >= 70 && anxiety.isRising()) {
            newAlerts.add(buildAnxietyAlert(goal, anxiety));
        }

        // 模考下滑
        MockExamTrend mockTrend = mockExamClient.getTrend(goal.getUserId(), goal.getSubjects());
        if (mockTrend.isDeclining(10)) {
            newAlerts.add(buildMockDeclineAlert(goal, mockTrend));
        }

        return deduplicateAndFilter(goalId, newAlerts, today);
    }

    private List<ExamPrepAlert> deduplicateAndFilter(Long goalId, List<ExamPrepAlert> alerts, LocalDate today) {
        return alerts.stream()
            .filter(a -> !alertRepository.existsActiveByTypeAndSubject(goalId, a.getAlertType(), a.getSubject(), today))
            .collect(Collectors.toList());
    }
}
```

```sql
    goal_id         BIGINT COMMENT '备考目标ID',
    user_id         BIGINT NOT NULL,
    status          VARCHAR(16) NOT NULL DEFAULT 'PENDING' COMMENT 'PENDING/SENT/FAILED',
    retry_count     INT NOT NULL DEFAULT 0,
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    sent_at         DATETIME,

    UNIQUE KEY uk_event_id (event_id),
    INDEX idx_status_created (status, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='备考域 Outbox';
```

## 10. 降级策略

| 场景 | 降级行为 | 红线 |
| --- | --- | --- |
| 焦虑引擎不可用 | psychology_score 使用历史均值或默认值 60，标记降级 | 不向用户隐藏备考功能 |
| 学习规划服务不可用 | planning_score 使用最近 14 天实际数据估算 | 不伪造高完成率 |
| 练习数据延迟 | 使用最近一次有效练习评分，置信度降为 LOW | 不过期硬顶 |
| 实时评分 QPS 过高 | 读缓存或返回昨日评分 | 5 分钟内必须刷新 |
| 数据库不可用 | 返回 503 并触发异步恢复 | 不返回错误分数 |
| 事件消费堆积 | 跳过非核心事件（如浏览时长），优先处理练习/考试 | 不丢练习/考试事件 |

## 12. 安全与合规

### 12.1 数据隐私

1. 备考目标、评分、调控建议属学生学习数据，不得用于营销画像。
2. 家长端仅可见汇总级就绪度与预警，不暴露学科细粒度薄弱点给非监护人。
3. 教师端仅可见班级聚合趋势，禁止查看单个学生心理维度原始分。

### 12.2 未成年人保护

1. 初中/高中学生备考目标创建需家长门 V3 确认（若用户未成年）。
2. 每日可用时间上限受防沉迷与双减规则约束，不可通过目标配置绕过。
3. 深夜学习（22:00/23:00 后）不触发正向激励，且计入疲劳指标。

### 12.3 反焦虑设计

1. 就绪度评分不展示班级/年级排名。
2. 预警文案使用成长型话术，禁止制造恐慌。
3. 心理维度异常仅向家长端披露，学生端显示为"注意休息"。

## 13. 与关联文档的契约对齐

| 文档 | 关键契约 |
| --- | --- |
| 备考策略智能规划引擎 | 初始备考目标由该引擎创建，本引擎负责执行期监控 |
| 考试焦虑识别与心理干预引擎 | psychology_score 消费该引擎输出，异常时触发心理干预 |
| 学习计划动态调整服务 | 调控建议中的应用/拒绝经该服务同步到学习计划 |
| 练习测评会话服务 | 练习结果事件为本引擎 practice_score 的主要来源 |
| 学情分析服务 | 备考复盘报告由该服务聚合展示 |
| 通知中心 | 预警与调控建议通知由该服务投递 |
| 多端数据同步 | 备考目标状态变化触发 sync.invalidated |
| 统一家长门 | 未成年用户创建目标需家长确认 |
