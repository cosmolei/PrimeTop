# 服务端-学生错题复习行为智能分析与个性化复习体验优化引擎-详细设计

## 1. 概述

### 1.1 功能定位

本引擎负责**实时采集、分析和响应学生在错题复习过程中的行为信号**，聚焦于"学生如何复习错题"而非"错题内容本身"。通过对复习过程中的翻阅模式、停留时长、重答行为、提示依赖、专注度波动等多维度数据的智能分析，构建学生错题复习行为画像，检测复习卡点与低效模式，动态优化复习内容编排与交互策略。

### 1.2 与现有模块的区别与协同

| 现有模块 | 关注点 | 与本引擎关系 |
| --- | --- | --- |
| 错题服务 | 错题**收录、存储、管理** | 本引擎消费错题复习过程中的行为数据，错题服务提供题目元数据 |
| 错题订正效果评估与复习成效追踪 | 复习**结果**评估 | 本引擎提供过程数据，效果评估提供结果数据，联合形成"过程+结果"双维评价 |
| 间隔重复算法与遗忘曲线调度引擎 | 复习**时机**决策 | 本引擎分析复习行为质量，调度引擎决定复习时机，两者协同优化复习体验 |
| 错题相似题型聚类与薄弱知识点诊断 | 错题**归因** | 本引擎识别复习困难后，可触发相似题型推荐与知识诊断 |
| 客户端-错题本页面架构与复习交互流程 | 客户端**UI交互** | 本引擎是客户端复习行为数据的消费方，客户端是数据采集源 |
| 学生认知负荷监测引擎 | 通用**认知负荷** | 本引擎专注错题复习场景的认知状态，提供更精准的领域信号 |
| 学生学习投入度多维量化 | 整体**投入度** | 本引擎提供复习场景的投入度细分数据 |
| 学习闪卡记忆系统与间隔复习卡片 | 闪卡**交互** | 本引擎为闪卡复习模式提供行为分析能力 |

### 1.3 设计目标

1. **过程透明化**：将不可见的复习思维过程转化为可量化、可分析的行为指标
2. **实时感知**：在复习过程中实时检测困难、注意力涣散、机械刷题等低效模式
3. **个性化适配**：基于学生个体复习习惯和知识薄弱程度，动态调整复习内容编排
4. **数据驱动评估**：为学情报告提供复习过程质量数据，支持形成性评价
5. **防依赖预警**：识别学生对答案/提示的过度依赖，引导独立思考能力培养

### 1.4 适用范围

| 维度 | 说明 |
| --- | --- |
| 学段 | 小学三年级及以上（需具备自主复习能力） |
| 学科 | 全学科（数学、物理、化学、生物、语文、英语、历史、地理、政治） |
| 复习类型 | 错题重做、错题浏览、错题订正、闪卡复习、错题打印复习 |
| 客户端 | 移动端 APP、Web 端、平板端 |
| 复习场景 | 日常错题复习、考前集中复习、周末周期复习、假期复习 |

### 2.2 核心处理流

```
复习行为事件 → 事件接收 → 流式特征提取 → 模式识别 → 复习状态评估 → 干预决策 → 实时反馈/离线报告
                    ↓           ↓           ↓          ↓
                持久化存储   特征仓库    模式库     干预策略库
```

### 2.3 核心服务组件

| 组件 | 职责 | 技术选型 |
| --- | --- | --- |
| ReviewBehaviorIngestionService | 接收客户端批量上报的复习行为事件 | Spring Boot + Kafka Producer |
| ReviewBehaviorStreamPipeline | 流式处理管线，实时计算特征 | Flink / Kafka Streams |
| ReviewFeatureEngine | 特征计算引擎，提取复习行为特征向量 | Flink CEP + Redis State |
| ReviewPatternDetector | 复习模式识别器，检测低效/异常模式 | 规则引擎 + ML 模型 |
| ReviewDifficultyDetector | 复习困难检测器，识别知识卡点 | 规则引擎 + 阈值模型 |
| AnswerDependencyMonitor | 答案依赖监测器，评估学生对答案/提示的依赖程度 | 累计统计 + 趋势分析 |
| ReviewInterventionAdvisor | 干预决策引擎，生成个性化干预策略 | 策略树 + Bandit 优化 |
| ReviewReportGenerator | 复习报告生成器，产出离线分析报告 | 定时任务 + ClickHouse 聚合 |

### 3.2 事件类型枚举（ReviewEventType）


## 4. 复习模式识别

### 4.1 低效复习模式定义

| 模式编码 | 模式名称 | 描述 | 检测条件 | 干预策略 |
| --- | --- | --- | --- | --- |
| `RUSH_REVIEW` | 走马观花式复习 | 快速翻阅错题，每题停留极短 | avg_view_duration < 15s 且 fast_submit_ratio > 0.6 | 提示放慢速度，建议先看解析 |
| `ANSWER_PEEKER` | 偷看答案式复习 | 频繁在作答前直接查看答案 | answer_reveal_before_submit_rate > 0.4 | 关闭快捷答案入口，引导先思考 |
| `HINT_SPAMMER` | 提示依赖式复习 | 几乎每题都请求提示 | hint_usage_rate > 0.7 且 avg_hint_level ≤ 1 | 限制提示频次，先鼓励独立尝试 |
| `EXPLANATION_SKIPPER` | 跳过解析式复习 | 答对/答错后都不看解析 | explanation_read_rate < 0.2 | 强制解析摘要展示，积分激励阅读 |
| `SERIAL_WRONG` | 连续出错模式 | 连续多题答错仍在硬刷 | 连续 ≥5 题错误 且 无暂停 | 建议休息或切换知识点 |
| `SESSION_HOPPER` | 频繁切换会话 | 短时间内多次开始/结束复习 | 30分钟内 ≥3 次会话 且 每次时长 < 3min | 提示专注一个复习批次 |
| `ZOMBIE_REVIEW` | 僵尸式复习 | 长时间空闲、无实际操作 | idle_ratio > 0.5 且 duration > 10min | 建议暂停或缩短会话 |
| `EMOTIONAL_FRUSTRATION` | 情绪挫败模式 | 愤怒点击+连续错误+长时停留 | rage_tap_count ≥ 3 且 连续错误 ≥ 3 | 触发鼓励机制，建议休息 |
| `SELECTIVE_REVIEW` | 挑题复习 | 只选择简单题目，跳过困难题 | skip_rate > 0.5 且 skipped题目难度 > 3 | 隐藏难度标记，按优先级推荐 |
| `MECHANICAL_REPEAT` | 机械重复 | 多次重做相同错题但不思考 | 同一题目attempt_count > 3 且 final_correct = 0 | 建议查看解析或请求AI辅导 |

### 4.2 高效复习模式定义

| 模式编码 | 模式名称 | 描述 | 检测条件 | 强化策略 |
| --- | --- | --- | --- | --- |
| `DEEP_LEARNER` | 深度学习者 | 充分阅读解析+添加笔记+请求同类题 | explanation_read_rate > 0.8 且 note_added_rate > 0.3 | 积分奖励，推荐进阶内容 |
| `SELF_CORRECTOR` | 自我纠偏者 | 首次错误后能独立纠正 | multi_attempt_ratio > 0.3 且 final_correct_rate > 0.7 | 正向反馈，降低后续提示门槛 |
| `CONSISTENT_REVIEWER` | 规律复习者 | 按间隔重复算法定时复习 | review_consistency > 0.8 | 连续打卡奖励，推荐给其他用户学习 |
| `STRATEGIC_LEARNER` | 策略学习者 | 根据难度调整复习策略 | 高难题目think_duration长，低难题目快速通过 | 推荐更有挑战性的内容 |

### 4.3 模式检测引擎实现

```python
from enum import Enum
from dataclasses import dataclass
from typing import List, Optional
from datetime import datetime, timedelta
import numpy as np

class PatternCategory(Enum):
    EFFICIENT = "EFFICIENT"
    INEFFICIENT = "INEFFICIENT"
    RISKY = "RISKY"
    DEPENDENT = "DEPENDENT"

@dataclass
class PatternDetectionResult:
    pattern_code: str
    pattern_name: str
    category: PatternCategory
    confidence: float  # 0-1
    evidence: dict
    detected_at: datetime
    severity: str = "LOW"  # LOW/MEDIUM/HIGH

class ReviewPatternDetector:
    """复习模式识别器 - 基于规则与统计模型的双重检测"""

    # 规则定义：模式编码 -> 检测函数 + 阈值
    PATTERN_RULES = {
        "RUSH_REVIEW": {
            "detector": "_detect_rush_review",
            "category": PatternCategory.INEFFICIENT,
            "min_sessions": 1,
        },
        "ANSWER_PEEKER": {
            "detector": "_detect_answer_peeker",
            "category": PatternCategory.DEPENDENT,
            "min_sessions": 2,
        },
        "HINT_SPAMMER": {
            "detector": "_detect_hint_spammer",
            "category": PatternCategory.DEPENDENT,
            "min_sessions": 2,
        },
        "EXPLANATION_SKIPPER": {
            "detector": "_detect_explanation_skipper",
            "category": PatternCategory.INEFFICIENT,
            "min_sessions": 1,
        },
        "SERIAL_WRONG": {
            "detector": "_detect_serial_wrong",
            "category": PatternCategory.RISKY,
            "min_sessions": 1,
        },
        "ZOMBIE_REVIEW": {
            "detector": "_detect_zombie_review",
            "category": PatternCategory.INEFFICIENT,
            "min_sessions": 1,
        },
        "EMOTIONAL_FRUSTRATION": {
            "detector": "_detect_emotional_frustration",
            "category": PatternCategory.RISKY,
            "min_sessions": 1,
        },
        "DEEP_LEARNER": {
            "detector": "_detect_deep_learner",
            "category": PatternCategory.EFFICIENT,
            "min_sessions": 2,
        },
        "SELF_CORRECTOR": {
            "detector": "_detect_self_corrector",
            "category": PatternCategory.EFFICIENT,
            "min_sessions": 3,
        },
        "MECHANICAL_REPEAT": {
            "detector": "_detect_mechanical_repeat",
            "category": PatternCategory.INEFFICIENT,
            "min_sessions": 1,
        },
    }

    def detect_patterns(
        self,
        user_id: int,
        subject: str,
        session_behaviors: List[dict],
        historical_features: Optional[dict] = None,
    ) -> List[PatternDetectionResult]:
        """检测用户在指定学科上的复习模式"""
        results = []

        for pattern_code, rule in self.PATTERN_RULES.items():
            detector_fn = getattr(self, rule["detector"])
            result = detector_fn(
                session_behaviors,
                historical_features or {},
                rule,
            )
            if result and result.confidence >= 0.5:
                results.append(result)

        # 按置信度排序
        results.sort(key=lambda r: r.confidence, reverse=True)
        return results

    def _detect_rush_review(
        self, behaviors: List[dict], history: dict, rule: dict
    ) -> Optional[PatternDetectionResult]:
        """检测走马观花式复习"""
        if len(behaviors) < 3:
            return None

        durations = [b.get("total_view_duration_ms", 0) for b in behaviors]
        fast_submits = sum(
            1 for b in behaviors
            if b.get("total_think_duration_ms", 0) < 5000
        )

        avg_duration = np.mean(durations)
        fast_ratio = fast_submits / len(behaviors)

        if avg_duration < 15000 and fast_ratio > 0.6:
            confidence = min(1.0, (0.6 - avg_duration / 25000) + (fast_ratio - 0.6) * 2)
            return PatternDetectionResult(
                pattern_code="RUSH_REVIEW",
                pattern_name="走马观花式复习",
                category=rule["category"],
                confidence=round(confidence, 2),
                evidence={
                    "avg_view_duration_ms": int(avg_duration),
                    "fast_submit_ratio": round(fast_ratio, 2),
                    "question_count": len(behaviors),
                },
                detected_at=datetime.utcnow(),
                severity="MEDIUM" if fast_ratio > 0.8 else "LOW",
            )
        return None

    def _detect_answer_peeker(
        self, behaviors: List[dict], history: dict, rule: dict
    ) -> Optional[PatternDetectionResult]:
        """检测偷看答案式复习"""
        if len(behaviors) < 4:
            return None

        peek_count = sum(
            1 for b in behaviors
            if b.get("answer_revealed_before_submit", 0) == 1
        )
        peek_rate = peek_count / len(behaviors)

        if peek_rate > 0.4:
            confidence = min(1.0, peek_rate)
            return PatternDetectionResult(
                pattern_code="ANSWER_PEEKER",
                pattern_name="偷看答案式复习",
                category=rule["category"],
                confidence=round(confidence, 2),
                evidence={
                    "peek_count": peek_count,
                    "total_questions": len(behaviors),
                    "peek_rate": round(peek_rate, 2),
                },
                detected_at=datetime.utcnow(),
                severity="HIGH" if peek_rate > 0.7 else "MEDIUM",
            )
        return None

    def _detect_hint_spammer(
        self, behaviors: List[dict], history: dict, rule: dict
    ) -> Optional[PatternDetectionResult]:
        """检测提示依赖式复习"""
        if len(behaviors) < 4:
            return None

        hint_count = sum(1 for b in behaviors if b.get("hint_used", 0) == 1)
        hint_rate = hint_count / len(behaviors)

        # 检查是否在未尝试的情况下直接请求提示
        no_attempt_hint = sum(
            1 for b in behaviors
            if b.get("hint_used", 0) == 1
            and b.get("attempt_count", 0) == 0
        )
        no_attempt_rate = no_attempt_hint / max(hint_count, 1)

        if hint_rate > 0.7:
            confidence = min(1.0, hint_rate * (0.5 + no_attempt_rate * 0.5))
            return PatternDetectionResult(
                pattern_code="HINT_SPAMMER",
                pattern_name="提示依赖式复习",
                category=rule["category"],
                confidence=round(confidence, 2),
                evidence={
                    "hint_usage_rate": round(hint_rate, 2),
                    "no_attempt_hint_rate": round(no_attempt_rate, 2),
                    "total_questions": len(behaviors),
                },
                detected_at=datetime.utcnow(),
                severity="HIGH" if no_attempt_rate > 0.5 else "MEDIUM",
            )
        return None

    def _detect_serial_wrong(
        self, behaviors: List[dict], history: dict, rule: dict
    ) -> Optional[PatternDetectionResult]:
        """检测连续出错模式"""
        if len(behaviors) < 5:
            return None

        max_consecutive_wrong = 0
        current_streak = 0
        for b in behaviors:
            if b.get("final_correct") == 0 or b.get("final_correct") is None:
                current_streak += 1
                max_consecutive_wrong = max(max_consecutive_wrong, current_streak)
            else:
                current_streak = 0

        if max_consecutive_wrong >= 5:
            avg_difficulty = np.mean([
                b.get("difficulty_level", 3) for b in behaviors
            ])
            confidence = min(1.0, max_consecutive_wrong / 8)
            return PatternDetectionResult(
                pattern_code="SERIAL_WRONG",
                pattern_name="连续出错模式",
                category=rule["category"],
                confidence=round(confidence, 2),
                evidence={
                    "max_consecutive_wrong": max_consecutive_wrong,
                    "avg_difficulty": round(float(avg_difficulty), 1),
                },
                detected_at=datetime.utcnow(),
                severity="HIGH",
            )
        return None

    def _detect_emotional_frustration(
        self, behaviors: List[dict], history: dict, rule: dict
    ) -> Optional[PatternDetectionResult]:
        """检测情绪挫败模式"""
        total_rage_taps = sum(b.get("rage_tap_count", 0) for b in behaviors)
        wrong_questions = sum(
            1 for b in behaviors
            if b.get("final_correct") == 0
        )
        long_think_wrong = sum(
            1 for b in behaviors
            if b.get("final_correct") == 0
            and b.get("total_think_duration_ms", 0) > 60000
        )

        if total_rage_taps >= 3 and wrong_questions >= 3:
            confidence = min(1.0, (total_rage_taps / 5 + wrong_questions / 8) / 2)
            return PatternDetectionResult(
                pattern_code="EMOTIONAL_FRUSTRATION",
                pattern_name="情绪挫败模式",
                category=rule["category"],
                confidence=round(confidence, 2),
                evidence={
                    "rage_tap_count": total_rage_taps,
                    "wrong_count": wrong_questions,
                    "long_think_wrong_count": long_think_wrong,
                },
                detected_at=datetime.utcnow(),
                severity="HIGH",
            )
        return None

    def _detect_deep_learner(
        self, behaviors: List[dict], history: dict, rule: dict
    ) -> Optional[PatternDetectionResult]:
        """检测深度学习者（正向模式）"""
        if len(behaviors) < 4:
            return None

        explanation_read = sum(
            1 for b in behaviors
            if b.get("total_explanation_time_ms", 0) > 10000
        )
        note_added = sum(1 for b in behaviors if b.get("note_added", 0) == 1)
        similar_requested = sum(
            1 for b in behaviors if b.get("similar_question_requested", 0) == 1
        )

        explanation_rate = explanation_read / len(behaviors)
        note_rate = note_added / len(behaviors)
        similar_rate = similar_requested / len(behaviors)

        if explanation_rate > 0.8 and (note_rate > 0.2 or similar_rate > 0.2):
            confidence = min(
                1.0,
                explanation_rate * 0.5 + max(note_rate, similar_rate) * 0.5
            )
            return PatternDetectionResult(
                pattern_code="DEEP_LEARNER",
                pattern_name="深度学习者",
                category=rule["category"],
                confidence=round(confidence, 2),
                evidence={
                    "explanation_read_rate": round(explanation_rate, 2),
                    "note_added_rate": round(note_rate, 2),
                    "similar_request_rate": round(similar_rate, 2),
                },
                detected_at=datetime.utcnow(),
                severity="LOW",
            )
        return None

    def _detect_zombie_review(
        self, behaviors: List[dict], history: dict, rule: dict
    ) -> Optional[PatternDetectionResult]:
        """检测僵尸式复习（长时间空闲无操作）"""
        if not behaviors:
            return None

        total_idle = sum(b.get("idle_total_ms", 0) for b in behaviors)
        total_duration = sum(
            b.get("total_view_duration_ms", 0) for b in behaviors
        )

        if total_duration == 0:
            return None

        idle_ratio = total_idle / total_duration

        if idle_ratio > 0.5 and total_duration > 600000:  # 10分钟
            confidence = min(1.0, idle_ratio)
            return PatternDetectionResult(
                pattern_code="ZOMBIE_REVIEW",
                pattern_name="僵尸式复习",
                category=rule["category"],
                confidence=round(confidence, 2),
                evidence={
                    "idle_ratio": round(idle_ratio, 2),
                    "total_idle_ms": total_idle,
                    "total_duration_ms": total_duration,
                },
                detected_at=datetime.utcnow(),
                severity="MEDIUM",
            )
        return None

    def _detect_mechanical_repeat(
        self, behaviors: List[dict], history: dict, rule: dict
    ) -> Optional[PatternDetectionResult]:
        """检测机械重复模式"""
        # 按question_id分组，统计每个题目的尝试次数
        question_attempts = {}
        for b in behaviors:
            qid = b.get("question_id")
            if qid:
                question_attempts[qid] = question_attempts.get(qid, 0) + 1

        for qid, count in question_attempts.items():
            if count > 3:
                # 检查是否最终答对
                q_behaviors = [b for b in behaviors if b.get("question_id") == qid]
                final_correct = any(
                    b.get("final_correct") == 1 for b in q_behaviors
                )
                if not final_correct:
                    return PatternDetectionResult(
                        pattern_code="MECHANICAL_REPEAT",
                        pattern_name="机械重复",
                        category=rule["category"],
                        confidence=0.85,
                        evidence={
                            "question_id": qid,
                            "attempt_count": count,
                            "final_correct": False,
                        },
                        detected_at=datetime.utcnow(),
                        severity="HIGH",
                    )
        return None
```

### 5.1 滑动窗口特征计算

使用 Flink CEP 实现滑动窗口内的实时特征计算：

```java
/**
 * 复习行为实时特征计算作业
 * 使用滑动窗口（30秒步长，5分钟窗口）计算实时特征
 */
public class ReviewFeatureJob {

    public static void main(String[] args) throws Exception {
        StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();
        env.enableCheckpointing(60000); // 1分钟checkpoint

        // 1. 从Kafka读取复习行为事件流
        DataStream<ReviewBehaviorEvent> eventStream = env
            .addSource(
                FlinkKafkaConsumer.<ReviewBehaviorEvent>builder()
                    .setBootstrapServers("kafka-cluster:9092")
                    .setTopics("review-behavior-events")
                    .setDeserializer(new ReviewBehaviorEventDeserializer())
                    .setGroupId("review-feature-job")
                    .build()
            )
            .name("Review Behavior Events Source")
            .filter(event -> event.getUserId() != null)
            .assignTimestampsAndWatermarks(
                WatermarkStrategy.<ReviewBehaviorEvent>forBoundedOutOfOrderness(
                    Duration.ofSeconds(10)
                )
                .withTimestampAssigner((event, ts) -> event.getTimestamp())
            );

        // 2. 按(userId, sessionId)分组，5分钟滑动窗口计算特征
        DataStream<SessionFeature> sessionFeatures = eventStream
            .keyBy(event -> new SessionKey(event.getUserId(), event.getSessionId()))
            .window(SlidingEventTimeWindows.of(Time.minutes(5), Time.seconds(30)))
            .aggregate(new SessionFeatureAggregator())
            .name("Session Feature Window");

        // 3. 实时模式检测
        DataStream<PatternAlert> patternAlerts = eventStream
            .keyBy(event -> new SessionKey(event.getUserId(), event.getSessionId()))
            .process(new RealTimePatternDetector())
            .name("Real-time Pattern Detector");

        // 4. 干预决策
        DataStream<InterventionAction> interventions = patternAlerts
            .keyBy(PatternAlert::getUserId)
            .connect(sessionFeatures.broadcast()) // 广播会话特征
            .process(new InterventionDecisionFunction())
            .name("Intervention Decision");

        // 5. 输出到下游
        sessionFeatures.addSink(
            new ClickHouseSink<>("review_session_features")
        ).name("Session Features to ClickHouse");

        patternAlerts.addSink(
            new KafkaSink<>("review-pattern-alerts")
        ).name("Pattern Alerts to Kafka");

        interventions.addSink(
            new KafkaSink<>("review-interventions")
        ).name("Interventions to Kafka");

        env.execute("Review Behavior Feature Job");
    }

    /**
     * 会话级特征聚合器
     */
    public static class SessionFeatureAggregator
            implements AggregateFunction<
                ReviewBehaviorEvent,
                SessionFeatureAccumulator,
                SessionFeature> {

        @Override
        public SessionFeatureAccumulator createAccumulator() {
            return new SessionFeatureAccumulator();
        }

        @Override
        public SessionFeatureAccumulator add(
                ReviewBehaviorEvent event,
                SessionFeatureAccumulator acc) {

            acc.userId = event.getUserId();
            acc.sessionId = event.getSessionId();
            acc.subject = event.getReviewContext().getSubject();
            acc.windowEnd = System.currentTimeMillis();

            switch (event.getEventType()) {
                case QUESTION_ANSWER_SUBMIT:
                    acc.totalSubmit++;
                    if (event.getBehaviorPayload().getAnswerCorrect()) {
                        acc.correctCount++;
                    } else {
                        acc.wrongCount++;
                    }
                    acc.totalThinkMs += event.getBehaviorPayload().getThinkDurationMs();
                    if (event.getBehaviorPayload().getHintUsed()) {
                        acc.hintUsedCount++;
                    }
                    if (event.getBehaviorPayload().getAnswerRevealedBeforeSubmit()) {
                        acc.peekCount++;
                    }
                    acc.totalExplanationMs +=
                        event.getBehaviorPayload().getTimeSpentOnExplanation();
                    break;

                case TAB_SWITCH:
                    acc.tabSwitchCount++;
                    break;

                case RAGE_TAP:
                    acc.rageTapCount++;
                    break;

                case IDLE_DETECTED:
                    acc.idleCount++;
                    break;

                case QUESTION_SKIP:
                    acc.skipCount++;
                    break;
            }
            return acc;
        }

        @Override
        public SessionFeature getResult(SessionFeatureAccumulator acc) {
            SessionFeature feature = new SessionFeature();
            feature.userId = acc.userId;
            feature.sessionId = acc.sessionId;
            feature.subject = acc.subject;
            feature.timestamp = acc.windowEnd;

            int total = Math.max(acc.totalSubmit, 1);
            feature.correctRate = (double) acc.correctCount / total;
            feature.wrongRate = (double) acc.wrongCount / total;
            feature.avgThinkMs = acc.totalThinkMs / total;
            feature.hintUsageRate = (double) acc.hintUsedCount / total;
            feature.peekRate = (double) acc.peekCount / total;
            feature.tabSwitchRate = acc.tabSwitchCount;
            feature.rageTapTotal = acc.rageTapCount;
            feature.skipRate = (double) acc.skipCount / total;
            feature.idleEpisode = acc.idleCount;

            // 实时专注度评分
            feature.focusScore = calculateFocusScore(feature);
            // 实时效率评分
            feature.efficiencyScore = calculateEfficiencyScore(feature);

            return feature;
        }

        @Override
        public SessionFeatureAccumulator merge(
                SessionFeatureAccumulator a,
                SessionFeatureAccumulator b) {
            a.totalSubmit += b.totalSubmit;
            a.correctCount += b.correctCount;
            a.wrongCount += b.wrongCount;
            a.totalThinkMs += b.totalThinkMs;
            a.hintUsedCount += b.hintUsedCount;
            a.peekCount += b.peekCount;
            a.totalExplanationMs += b.totalExplanationMs;
            a.tabSwitchCount += b.tabSwitchCount;
            a.rageTapCount += b.rageTapCount;
            a.idleCount += b.idleCount;
            a.skipCount += b.skipCount;
            return a;
        }

        /**
         * 实时专注度评分算法
         * 综合考虑Tab切换频率、空闲次数、愤怒点击等因素
         */
        private double calculateFocusScore(SessionFeature f) {
            // 基础分100，各项扣分
            double score = 100.0;

            // Tab切换扣分（每次扣5分，上限30）
            score -= Math.min(30, f.tabSwitchRate * 5);

            // 空闲次数扣分（每次扣8分，上限25）
            score -= Math.min(25, f.idleEpisode * 8);

            // 愤怒点击扣分（每次扣10分，上限20）
            score -= Math.min(20, f.rageTapTotal * 10);

            // 跳过率扣分
            score -= f.skipRate * 15;

            return Math.max(0, Math.min(100, score));
        }

        /**
         * 实时效率评分算法
         */
        private double calculateEfficiencyScore(SessionFeature f) {
            // 正确率权重 40%
            double accuracyScore = f.correctRate * 40;

            // 思考深度权重 25%（思考时间适中为佳）
            double thinkScore;
            if (f.avgThinkMs < 5000) {
                thinkScore = f.avgThinkMs / 5000.0 * 15; // 太快，低分
            } else if (f.avgThinkMs <= 120000) {
                thinkScore = 15 + (f.avgThinkMs - 5000) / 115000.0 * 10; // 适中
            } else {
                thinkScore = 25 - Math.min(10, (f.avgThinkMs - 120000) / 60000.0 * 5); // 太慢
            }

            // 提示依赖扣分 20%
            double independenceScore = (1 - f.hintUsageRate) * 20;

            // 解析阅读权重 15%
            double explanationFactor = f.totalExplanationMs > 0 ? 15 : 0;

            return Math.max(0, Math.min(
                100, accuracyScore + thinkScore + independenceScore + explanationFactor
            ));
        }
    }
}
```

```java
/**
 * 基于Flink CEP的实时复习模式检测

public class RealTimePatternDetector
        extends KeyedProcessFunction<SessionKey, ReviewBehaviorEvent, PatternAlert> {

    // 状态：连续错误计数
    private ValueState<Integer> consecutiveWrongState;
    // 状态：快速提交计数
    private ValueState<Integer> fastSubmitCountState;
    // 状态：提示使用计数
    private ValueState<Integer> hintUsedCountState;
    // 状态：总提交计数
    private ValueState<Integer> totalSubmitState;
    // 状态：会话开始时间
    private ValueState<Long> sessionStartTimeState;
    // 状态：上次空闲时间
    private ValueState<Long> lastActivityTimeState;

    @Override
    public void open(Configuration parameters) {
        consecutiveWrongState = getRuntimeContext().getState(
            new ValueStateDescriptor<>("consecutiveWrong", Integer.class)
        );
        fastSubmitCountState = getRuntimeContext().getState(
            new ValueStateDescriptor<>("fastSubmitCount", Integer.class)
        );
        hintUsedCountState = getRuntimeContext().getState(
            new ValueStateDescriptor<>("hintUsedCount", Integer.class)
        );
        totalSubmitState = getRuntimeContext().getState(
            new ValueStateDescriptor<>("totalSubmit", Integer.class)
        );
        sessionStartTimeState = getRuntimeContext().getState(
            new ValueStateDescriptor<>("sessionStart", Long.class)
        );
        lastActivityTimeState = getRuntimeContext().getState(
            new ValueStateDescriptor<>("lastActivity", Long.class)
        );
    }

    @Override
    public void processElement(
            ReviewBehaviorEvent event,
            Context ctx,
            Collector<PatternAlert> out) throws Exception {

        // 初始化会话
        if (sessionStartTimeState.value() == null) {
            sessionStartTimeState.update(event.getTimestamp());
        }
        lastActivityTimeState.update(event.getTimestamp());

        if (event.getEventType() == ReviewEventType.QUESTION_ANSWER_SUBMIT) {
            int total = (totalSubmitState.value() != null ? totalSubmitState.value() : 0) + 1;
            totalSubmitState.update(total);

            // 检测快速提交
            long thinkMs = event.getBehaviorPayload().getThinkDurationMs();
            if (thinkMs < 5000) {
                int fastCount = (fastSubmitCountState.value() != null
                    ? fastSubmitCountState.value() : 0) + 1;
                fastSubmitCountState.update(fastCount);

                // 连续3次快速提交触发预警
                if (fastCount >= 3 && (double) fastCount / total > 0.6) {
                    out.collect(new PatternAlert(
                        event.getUserId(),
                        event.getSessionId(),
                        "RUSH_REVIEW",
                        "MEDIUM",
                        Map.of(
                            "fastSubmitCount", fastCount,
                            "totalSubmit", total,
                            "avgThinkMs", thinkMs
                        ),
                        System.currentTimeMillis()
                    ));
                }
            }

            // 检测连续错误
            boolean correct = event.getBehaviorPayload().getAnswerCorrect();
            int consecutive = consecutiveWrongState.value() != null
                ? consecutiveWrongState.value() : 0;

            if (!correct) {
                consecutive++;
                consecutiveWrongState.update(consecutive);

                if (consecutive >= 5) {
                    out.collect(new PatternAlert(
                        event.getUserId(),
                        event.getSessionId(),
                        "SERIAL_WRONG",
                        "HIGH",
                        Map.of(
                            "consecutiveWrong", consecutive,
                            "suggestion", "建议休息或切换到较简单的知识点"
                        ),
                        System.currentTimeMillis()
                    ));
                }
            } else {
                consecutiveWrongState.update(0);
            }

            // 检测提示依赖
            if (event.getBehaviorPayload().getHintUsed()) {
                int hintCount = (hintUsedCountState.value() != null
                    ? hintUsedCountState.value() : 0) + 1;
                hintUsedCountState.update(hintCount);

                double hintRate = (double) hintCount / total;
                if (hintRate > 0.7 && total >= 4) {
                    out.collect(new PatternAlert(
                        event.getUserId(),
                        event.getSessionId(),
                        "HINT_SPAMMER",
                        "HIGH",
                        Map.of(
                            "hintUsedCount", hintCount,
                            "totalSubmit", total,
                            "hintRate", hintRate
                        ),
                        System.currentTimeMillis()
                    ));
                }
            }

            // 检测偷看答案
            if (event.getBehaviorPayload().getAnswerRevealedBeforeSubmit()) {
                out.collect(new PatternAlert(
                    event.getUserId(),
                    event.getSessionId(),
                    "ANSWER_PEEKER_INCIDENT",
                    "LOW",
                    Map.of(
                        "questionId", event.getReviewContext().getQuestionId()
                    ),
                    System.currentTimeMillis()
                ));
            }
        }

        // 检测情绪挫败
        if (event.getEventType() == ReviewEventType.RAGE_TAP) {
            out.collect(new PatternAlert(
                event.getUserId(),
                event.getSessionId(),
                "RAGE_TAP_INCIDENT",
                "LOW",
                Map.of("timestamp", event.getTimestamp()),
                System.currentTimeMillis()
            ));
        }
    }
}
```

```python
class InterventionDecisionEngine:
    """干预决策引擎 - 根据模式检测结果选择最优干预策略"""

    STRATEGY_MAP = {
        "RUSH_REVIEW": RushReviewIntervention(),
        "SERIAL_WRONG": SerialWrongIntervention(),
        "ANSWER_PEEKER": AnswerPeekerIntervention(),
        "ANSWER_PEEKER_INCIDENT": AnswerPeekerIntervention(),
        "HINT_SPAMMER": HintSpammerIntervention(),
        "EMOTIONAL_FRUSTRATION": EmotionalFrustrationIntervention(),
        "DEEP_LEARNER": DeepLearnerReward(),
        "MECHANICAL_REPEAT": MechanicalRepeatIntervention(),
    }

    # 干预疲劳度控制：单日最大干预次数
    DAILY_MAX_INTERVENTIONS = 8
    # 单会话最大干预次数
    SESSION_MAX_INTERVENTIONS = 4

    def decide(
        self,
        pattern_alerts: list,
        session_feature: dict,
        user_context: dict,
    ) -> Optional[InterventionAction]:
        """根据模式告警决策干预动作"""
        if not pattern_alerts:
            return None

        # 按严重程度排序
        priority_order = {"HIGH": 0, "MEDIUM": 1, "LOW": 2}
        pattern_alerts.sort(
            key=lambda a: priority_order.get(a.get("severity", "LOW"), 3)
        )

        # 取最高优先级的模式
        top_alert = pattern_alerts[0]
        pattern_code = top_alert["pattern_code"]

        strategy = self.STRATEGY_MAP.get(pattern_code)
        if not strategy:
            return None

        # 构建决策上下文
        ctx = InterventionContext(
            user_id=top_alert["userId"],
            session_id=top_alert["sessionId"],
            subject=session_feature.get("subject", ""),
            grade_level=user_context.get("gradeLevel", ""),
            current_pattern=pattern_code,
            pattern_severity=top_alert.get("severity", "LOW"),
            session_feature=session_feature,
            user_history=user_context,
            intervention_count_today=user_context.get(
                "todayInterventionCount", 0
            ),
            last_intervention_time=user_context.get(
                "lastInterventionTime"
            ),
        )

        # 干预疲劳度检查
        if ctx.intervention_count_today >= self.DAILY_MAX_INTERVENTIONS:
            return None

        if not strategy.should_trigger(ctx):
            return None

        return strategy.build_action(ctx)
```

## 8. 答案依赖度评估模型

### 8.1 依赖度综合评分算法

```python
class AnswerDependencyEvaluator:
    """
    答案/提示依赖度评估器
    综合多维度信号计算学生的答案依赖程度
    """

    # 依赖度各维度权重
    WEIGHTS = {
        "answer_reveal_rate": 0.35,       # 直接看答案率
        "answer_reveal_before_submit": 0.25,  # 提交前看答案率
        "hint_usage_rate": 0.20,          # 提示使用率
        "no_attempt_hint_rate": 0.10,     # 未尝试就请求提示率
        "explanation_skip_rate": 0.05,    # 跳过解析率
        "answer_copy_rate": 0.05,         # 复制答案率
    }

    def evaluate(
        self,
        session_behaviors: list,
        historical_features: dict = None,
    ) -> dict:
        """
        计算答案依赖度综合评分
        返回: {
            "score": 0-100 (越高越依赖),
            "level": NONE/MILD/MODERATE/SEVERE,
            "primary_factor": 主要依赖因素,
            "trend": INCREASING/STABLE/DECREASING,
            "recommendation": 建议措施
        }
        """
        if not session_behaviors:
            return self._default_result()

        total = len(session_behaviors)

        # 计算各维度
        metrics = {
            "answer_reveal_rate": sum(
                1 for b in session_behaviors
                if b.get("answer_revealed", 0) == 1
            ) / total,
            "answer_reveal_before_submit": sum(
                1 for b in session_behaviors
                if b.get("answer_revealed_before_submit", 0) == 1
            ) / total,
            "hint_usage_rate": sum(
                1 for b in session_behaviors
                if b.get("hint_used", 0) == 1
            ) / total,
            "no_attempt_hint_rate": sum(
                1 for b in session_behaviors
                if b.get("hint_used", 0) == 1
                and b.get("attempt_count", 0) == 0
            ) / max(total, 1),
            "explanation_skip_rate": 1 - sum(
                1 for b in session_behaviors
                if b.get("total_explanation_time_ms", 0) > 5000
            ) / total,
            "answer_copy_rate": sum(
                1 for b in session_behaviors
                if b.get("answer_copied", 0) == 1
            ) / total,
        }

        # 加权综合评分
        score = sum(
            metrics[factor] * weight
            for factor, weight in self.WEIGHTS.items()
        ) * 100

        # 确定依赖等级
        if score < 15:
            level = "NONE"
        elif score < 35:
            level = "MILD"
        elif score < 60:
            level = "MODERATE"
        else:
            level = "SEVERE"

        # 主要依赖因素
        primary_factor = max(
            self.WEIGHTS.keys(),
            key=lambda f: metrics[f]
        )

        # 趋势分析（需要历史数据）
        trend = "STABLE"
        if historical_features:
            prev_score = historical_features.get(
                "dependency_score", score
            )
            if score > prev_score + 10:
                trend = "INCREASING"
            elif score < prev_score - 10:
                trend = "DECREASING"

        # 生成建议
        recommendation = self._generate_recommendation(
            level, primary_factor, trend, metrics
        )

        return {
            "score": round(score, 1),
            "level": level,
            "primary_factor": primary_factor,
            "trend": trend,
            "metrics": {k: round(v, 3) for k, v in metrics.items()},
            "recommendation": recommendation,
        }

    def _generate_recommendation(
        self, level, primary_factor, trend, metrics
    ):
        recommendations = {
            ("NONE",): "独立复习能力良好，继续保持！",
            ("MILD",): "有轻微依赖倾向，注意先独立思考再查看提示。",
            ("MODERATE", "answer_reveal_before_submit"): (
                "提交前看答案的比例较高，"
                "建议启用「答案延迟查看」功能，强制先尝试作答。"
            ),
            ("MODERATE", "hint_usage_rate"): (
                "提示使用率较高，建议每道题先独立思考30秒以上，"
                "确认实在不会再请求提示。"
            ),
            ("SEVERE",): (
                "答案依赖程度较高，已启用「独立思考模式」："
                "答案查看需要延迟30秒，每题提示次数限制为1次。"
                "建议配合知识点讲解先巩固基础。"
            ),
        }

        for keys, rec in recommendations.items():
            if level in keys or primary_factor in keys:
                if trend == "INCREASING":
                    return rec + " 注意：依赖度有上升趋势，请重点关注。"
                return rec

        return "保持良好的复习习惯。"
```

```dart
/// 错题复习行为采集SDK
class ReviewBehaviorSDK {
  static const MethodChannel _channel = MethodChannel('review_behavior_sdk');

  String? _sessionId;
  final List<Map<String, dynamic>> _eventBuffer = [];
  Timer? _flushTimer;
  int _sequence = 0;

  /// 初始化SDK
  Future<void> init({
    required String userId,
    required String appVersion,
    required String platform,
  }) async {
    await _channel.invokeMethod('init', {
      'userId': userId,
      'appVersion': appVersion,
      'platform': platform,
    });

    // 每30秒批量上报一次
    _flushTimer = Timer.periodic(
      const Duration(seconds: 30),
      (_) => _flush(),
    );
  }

  /// 开始复习会话
  Future<String> startSession({
    required String reviewType,
    required String source,
    required String subject,
    int totalQuestions = 0,
  }) async {
    final response = await _channel.invokeMethod('startSession', {
      'reviewType': reviewType,
      'source': source,
      'subject': subject,
      'totalQuestions': totalQuestions,
    });

    _sessionId = response['sessionId'];

    _emitEvent(ReviewEventType.reviewSessionStart, {
      'reviewType': reviewType,
      'source': source,
      'subject': subject,
      'totalQuestions': totalQuestions,
    });

    return _sessionId!;
  }

  /// 结束复习会话
  Future<void> endSession({
    required int completedQuestions,
    String? userFeedback,
  }) async {
    if (_sessionId == null) return;

    _emitEvent(ReviewEventType.reviewSessionEnd, {
      'completedQuestions': completedQuestions,
      'userFeedback': userFeedback,
    });

    // 立即flush剩余事件
    await _flush();

    _sessionId = null;
  }

  /// 记录题目查看
  void trackQuestionView({
    required String questionId,
    required String mistakeRecordId,
    int difficultyLevel = 3,
    List<String>? knowledgePointIds,
    int sessionQuestionIndex = 0,
    int? daysSinceLastReview,
  }) {
    _emitEvent(ReviewEventType.questionView, {
      'questionId': questionId,
      'mistakeRecordId': mistakeRecordId,
      'difficultyLevel': difficultyLevel,
      'knowledgePointIds': knowledgePointIds ?? [],
      'sessionQuestionIndex': sessionQuestionIndex,
      'daysSinceLastReview': daysSinceLastReview,
    });
  }

  /// 记录答案提交
  void trackAnswerSubmit({
    required String questionId,
    required int thinkDurationMs,
    required int inputDurationMs,
    required bool answerCorrect,
    int attemptCount = 1,
    bool hintUsed = false,
    int? hintLevel,
    int? hintViewDurationMs,
    bool answerRevealedBeforeSubmit = false,
    int timeSpentOnExplanation = 0,
    bool explanationExpanded = false,
    int tabSwitchCount = 0,
    bool markResolved = false,
  }) {
    _emitEvent(ReviewEventType.questionAnswerSubmit, {
      'questionId': questionId,
      'thinkDurationMs': thinkDurationMs,
      'inputDurationMs': inputDurationMs,
      'answerCorrect': answerCorrect,
      'attemptCount': attemptCount,
      'hintUsed': hintUsed,
      'hintLevel': hintLevel,
      'hintViewDurationMs': hintViewDurationMs,
      'answerRevealedBeforeSubmit': answerRevealedBeforeSubmit,
      'timeSpentOnExplanation': timeSpentOnExplanation,
      'explanationExpanded': explanationExpanded,
      'tabSwitchCount': tabSwitchCount,
      'markResolved': markResolved,
    });
  }

  /// 记录跳过题目
  void trackSkip({required String questionId}) {
    _emitEvent(ReviewEventType.questionSkip, {
      'questionId': questionId,
    });
  }

  /// 记录Tab切换（由App生命周期监听自动调用）
  void trackTabSwitch() {
    _emitEvent(ReviewEventType.tabSwitch, {});
  }

  /// 记录空闲超时
  void trackIdle({required int idleMs}) {
    _emitEvent(ReviewEventType.idleDetected, {
      'idleMs': idleMs,
    });
  }

  /// 记录愤怒点击（由手势检测器调用）
  void trackRageTap({required int tapCount}) {
    _emitEvent(ReviewEventType.rageTap, {
      'tapCount': tapCount,
    });
  }

  /// 记录标记已掌握
  void trackMarkMastered({required String questionId}) {
    _emitEvent(ReviewEventType.markMastered, {
      'questionId': questionId,
    });
  }

  /// 批量上报
  Future<void> _flush() async {
    if (_eventBuffer.isEmpty) return;

    final events = List.from(_eventBuffer);
    _eventBuffer.clear();

    try {
      final response = await _channel.invokeMethod('batchReport', {
        'events': events,
        'sessionId': _sessionId,
      });

      // 处理服务端实时反馈
      if (response?['realtimeFeedback']?['hasFeedback'] == true) {
        _handleRealtimeFeedback(
          response!['realtimeFeedback'],
        );
      }
    } catch (e) {
      // 上报失败，放回缓冲区，下次重试
      _eventBuffer.insertAll(0, events);
      // 限制缓冲区大小
      if (_eventBuffer.length > 500) {
        _eventBuffer.removeRange(0, _eventBuffer.length - 500);
      }
    }
  }

  void _emitEvent(ReviewEventType type, Map<String, dynamic> payload) {
    if (_sessionId == null && type != ReviewEventType.reviewSessionStart) {
      return; // 未开始会话不采集
    }

    _eventBuffer.add({
      'eventId': 'evt_rev_${DateTime.now().millisecondsSinceEpoch}_$_sequence',
      'eventType': type.value,
      'sessionId': _sessionId,
      'timestamp': DateTime.now().millisecondsSinceEpoch,
      'clientTimestamp': DateTime.now().millisecondsSinceEpoch,
      'sequence': _sequence++,
      'payload': payload,
    });

    // 缓冲区满100条立即上报
    if (_eventBuffer.length >= 100) {
      _flush();
    }
  }

  void _handleRealtimeFeedback(Map<String, dynamic> feedback) {
    // 通过EventBus或Stream通知UI层展示反馈
    RealtimeFeedbackBus.instance.add(feedback);
  }

  /// 销毁SDK
  void dispose() {
    _flushTimer?.cancel();
    _flush();
  }
}
```

```python
from datetime import datetime, timedelta
import schedule

class ReviewReportScheduler:
    """复习行为分析报告定时生成器"""

    def __init__(self, feature_repo, report_repo):
        self.feature_repo = feature_repo
        self.report_repo = report_repo

    def setup_schedule(self):
        # 每日凌晨2点生成日报
        schedule.every().day.at("02:00").do(self._generate_daily_reports)
        # 每周一凌晨3点生成周报
        schedule.every().monday.at("03:00").do(self._generate_weekly_reports)
        # 每月1日凌晨4点生成月报
        schedule.every().day.do(
            self._generate_monthly_reports_if_first_day
        )

    def _generate_daily_reports(self):
        """生成每日复习行为分析报告"""
        yesterday = (datetime.now() - timedelta(days=1)).date()

        # 查询所有有复习活动的用户
        active_users = self.feature_repo.get_active_reviewers(
            date=yesterday
        )

        for user_id in active_users:
            for subject in self._get_user_subjects(user_id, yesterday):
                report = self._build_daily_report(
                    user_id, subject, yesterday
                )
                self.report_repo.save_daily_report(report)

                # 检查是否需要触发告警
                self._check_and_alert(user_id, subject, report)

    def _build_daily_report(
        self, user_id: int, subject: str, date
    ) -> dict:
        """构建单用户单学科日报"""
        sessions = self.feature_repo.get_sessions(
            user_id, subject, date
        )
        behaviors = self.feature_repo.get_behaviors(
            user_id, subject, date
        )

        if not sessions:
            return None

        report = {
            "userId": user_id,
            "subject": subject,
            "date": date.isoformat(),
            "generatedAt": datetime.utcnow().isoformat(),

            # 概览统计
            "overview": {
                "totalSessions": len(sessions),
                "totalDurationMin": sum(
                    s.get("duration_ms", 0) for s in sessions
                ) // 60000,
                "totalQuestions": sum(
                    s.get("answered_count", 0) for s in sessions
                ),
                "totalCorrect": sum(
                    s.get("correct_count", 0) for s in sessions
                ),
                "avgFocusScore": self._avg(
                    [s.get("focus_score") for s in sessions]
                ),
                "avgEfficiencyScore": self._avg(
                    [s.get("efficiency_score") for s in sessions]
                ),
            },

            # 行为画像
            "behaviorProfile": self._build_behavior_profile(behaviors),

            # 模式标签
            "patterns": self._detect_patterns_for_report(
                sessions, behaviors
            ),

            # 改进建议
            "recommendations": self._generate_recommendations(
                sessions, behaviors
            ),

            # 异常标记
            "anomalies": self._detect_anomalies(sessions, behaviors),
        }

        return report

    def _build_behavior_profile(self, behaviors: list) -> dict:
        """构建复习行为画像"""
        if not behaviors:
            return {}

        total = len(behaviors)

        # 复习风格分类
        avg_think = sum(
            b.get("total_think_duration_ms", 0) for b in behaviors
        ) / total

        explanation_read_rate = sum(
            1 for b in behaviors
            if b.get("total_explanation_time_ms", 0) > 10000
        ) / total

        hint_rate = sum(
            1 for b in behaviors if b.get("hint_used", 0) == 1
        ) / total

        # 风格判定
        if avg_think > 60000 and explanation_read_rate > 0.7:
            style = "DEEP_DELIBERATE"  # 深度思考型
        elif avg_think < 15000 and explanation_read_rate < 0.3:
            style = "FAST_SURFACE"  # 快速表层型
        elif hint_rate > 0.6:

            "avgThinkDurationMs": int(avg_think),
            "explanationEngagement": (
                "ACTIVE" if explanation_read_rate > 0.6
                else "PASSIVE" if explanation_read_rate > 0.3
                else "SKIPPER"
            ),
            "hintDependency": (
                "HIGH" if hint_rate > 0.6
                else "MODERATE" if hint_rate > 0.3
                else "LOW"
            ),
            "paceStyle": (
                "SLOW" if avg_think > 90000
                else "MODERATE" if avg_think > 30000
                else "FAST"
            ),
        }

    def _generate_recommendations(

    ) -> list:
        """生成个性化改进建议"""
        recommendations = []

        profile = self._build_behavior_profile(behaviors)
```

## 11. 错误处理与降级策略

### 11.1 错误码定义

| 错误码 | HTTP状态 | 描述 | 处理策略 |
| --- | --- | --- | --- |
| `REVIEW_BEHAVIOR_001` | 400 | 事件格式校验失败 | 丢弃非法事件，记录日志 |
| `REVIEW_BEHAVIOR_002` | 400 | sessionId不存在 | 创建匿名会话，标记异常 |
| `REVIEW_BEHAVIOR_003` | 429 | 上报频率超限 | 返回429，客户端退避重试 |
| `REVIEW_BEHAVIOR_004` | 500 | Kafka写入失败 | 降级写入本地队列，异步重试 |
| `REVIEW_BEHAVIOR_005` | 500 | Flink处理延迟 | 降级为批量离线计算 |
| `REVIEW_BEHAVIOR_006` | 503 | 分析服务不可用 | 客户端继续本地采集，服务恢复后补传 |

### 11.2 客户端降级策略

```dart
class ReviewBehaviorSDK {
  // ...

  /// 带降级策略的批量上报
  Future<void> _flushWithFallback() async {
    try {
      await _flush();
    } catch (e) {
      // 降级1：写入本地SQLite
      await _fallbackToLocalStorage();

      // 降级2：如果本地存储也失败，丢弃最旧的事件
      if (_eventBuffer.length > 1000) {
        _eventBuffer.removeRange(0, 500);
      }
    }
  }

  /// 本地降级存储
  Future<void> _fallbackToLocalStorage() async {
    final db = await _getLocalDb();
    for (final event in _eventBuffer) {
      await db.insert('review_behavior_backup', {
        'event_json': jsonEncode(event),
        'created_at': DateTime.now().toIso8601String(),
        'retry_count': 0,
      });
    }
    _eventBuffer.clear();
  }

  /// 服务恢复后补传
  Future<void> replayBackedUpEvents() async {
    final db = await _getLocalDb();
    final records = await db.query(
      'review_behavior_backup',
      where: 'retry_count < 3',
      limit: 200,
    );

    if (records.isEmpty) return;

    final events = records.map(
      (r) => jsonDecode(r['event_json'] as String)
    ).toList();

    try {
      await _channel.invokeMethod('batchReport', {
        'events': events,
        'isReplay': true,
      });

      // 删除已成功补传的记录
      for (final record in records) {
        await db.delete(
          'review_behavior_backup',
          where: 'id = ?',
          whereArgs: [record['id']],
        );
      }
    } catch (e) {
      // 标记重试次数
      for (final record in records) {
        await db.rawUpdate(
          'UPDATE review_behavior_backup SET retry_count = retry_count + 1 '
          'WHERE id = ?',
          [record['id']],
        );
      }
    }
  }
}
```

```python
class ReviewDataQualityMonitor:
    """复习行为数据质量监控"""

    def check_daily(self, date):

        checks = []

        })

        # 3. 事件顺序：QUESTION_ANSWER_SUBMIT应在QUESTION_VIEW之后
        out_of_order = self._check_event_ordering(date)

            "check": "EVENT_ORDERING",
            "passed": out_of_order < 20,
            "detail": f"{out_of_order} out-of-order events",
        })

        # 4. 用户覆盖率：当日活跃用户中有复习行为的比例
        coverage = self._check_user_coverage(date)
        checks.append({
            "check": "USER_COVERAGE",
            "passed": coverage > 0.3,
            "detail": f"{coverage:.1%} of active users have review events",
        })

        return checks
```

```
EfficiencyScore = (correctRate × 40)
    + thinkDepthScore(max 25)
    + independenceScore(max 20)
    + explanationEngagementScore(max 15)

其中:
  thinkDepthScore:
    if avgThinkMs < 5s:   thinkDepthScore = avgThinkMs/5s × 15
    if 5s ≤ avgThinkMs ≤ 120s: thinkDepthScore = 15 + (avgThinkMs-5s)/115s × 10
    if avgThinkMs > 120s: thinkDepthScore = 25 - min(10, (avgThinkMs-120s)/60s × 5)

  independenceScore = (1 - hintUsageRate × 0.6 - peekRate × 0.4) × 20

  explanationEngagementScore = min(15, explanationReadRate × 15)
```
