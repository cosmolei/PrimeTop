# 服务端 - 用户转化漏斗分析与增长归因引擎 详细设计

> 版本：v1.0 | 日期：2026-06-18 | 状态：初稿

## 1. 模块概述

### 1.1 功能定位

用户转化漏斗分析与增长归因引擎（User Conversion Funnel & Growth Attribution Engine）是 PrimeTop 平台增长分析体系的核心组件，负责对用户从注册到付费的关键旅程进行漏斗建模、转化率分析、流失节点诊断和跨触点归因，为产品迭代、增长实验和商业化决策提供量化支撑。

**与现有分析模块的边界划分：**

| 现有模块 | 关注点 | 本模块差异 |
|---------|--------|-----------|
| 用户活跃度统计与留存分析引擎 | DAU/WAU/MAU、留存率、Cohort 分析 | 本模块关注**转化路径**而非活跃度快照，回答"用户为何转化/流失"而非"多少用户活跃" |
| 用户流失预警与智能挽留策略引擎 | 识别流失风险用户并触发挽留干预 | 本模块关注**全局转化漏斗**和**归因**，不负责个体级别的实时干预 |
| 运营活动创建配置与效果归因分析 | 单次运营活动的效果追踪与 ROI | 本模块关注**产品级跨周期归因**，而非单次活动效果 |
| 用户生命周期价值预测与会员升级意向 | 个体 LTV 预测与升级倾向打分 | 本模块关注**群体级转化漏斗**和**多触点归因模型** |

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 漏斗定义与管理 | 可配置多步骤转化漏斗，支持条件过滤、事件组合、时间窗口约束 |
| 实时转化率计算 | 按天/周/月粒度计算各步骤转化率、整体转化率、步骤间流失率 |
| 多维下钻分析 | 按学段、年级、渠道、设备、会员状态等维度拆解漏斗 |
| 同群对比（Cohort Funnel） | 不同注册批次/特征群体的漏斗表现对比 |
| 多触点归因分析 | 首次触点、末次触点、线性、时间衰减、马尔可夫链等归因模型 |
| 转化时间分析 | 各步骤间转化耗时分布（P50/P90/P99）、最佳转化窗口识别 |
| 漏斗异常告警 | 转化率异常下跌、步骤流失率突增时自动告警 |
| 增长实验看板 | A/B 实验中各实验组的漏斗表现对比 |

### 1.3 核心业务漏斗定义

| 漏斗 | 步骤流 | 关键转化目标 |
|------|--------|-------------|
| 新用户激活漏斗 | 注册 → 完善档案 → 首次AI问答 → 收到回复 → 首次拍题 → 加入错题本 | 7日内完成首次学习行为 |
| 免费转付费漏斗 | 注册 → 首次AI使用 → 触达会员引导 → 试用 → 购买 | 完成付费订单 |
| 拍题转化漏斗 | 拍照 → OCR识别成功 → 查看解析 → 查看完整步骤 → 加入错题本 | 完成错题收录 |
| 学习习惯养成漏斗 | Day1活跃 → Day2活跃 → Day3活跃 → Day7活跃 → Day14活跃 | 14日持续活跃 |
| 功能发现漏斗 | 首页展示 → 功能入口点击 → 功能使用 → 功能复用 | 功能留存 |

## 3. 数据模型设计

### 3.1 漏斗定义模型（PostgreSQL）

```sql
CREATE TABLE growth_funnel_definition (
    id              BIGSERIAL PRIMARY KEY,
    funnel_key      VARCHAR(64) NOT NULL UNIQUE,
    name            VARCHAR(128) NOT NULL,
    description     TEXT,
    category        VARCHAR(32) NOT NULL,  -- registration/onboarding/engagement/monetization/retention
    owner           VARCHAR(64),
    status          VARCHAR(16) NOT NULL DEFAULT 'active',
    conversion_window_days  INT NOT NULL DEFAULT 30,
    step_max_gap_hours      INT NOT NULL DEFAULT 168,
    visibility      VARCHAR(16) NOT NULL DEFAULT 'internal',
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    created_by      VARCHAR(64) NOT NULL
);

CREATE TABLE growth_funnel_step (
    id              BIGSERIAL PRIMARY KEY,
    funnel_id       BIGINT NOT NULL REFERENCES growth_funnel_definition(id),
    step_order      INT NOT NULL,
    step_name       VARCHAR(128) NOT NULL,
    match_conditions JSONB NOT NULL,
    is_optional         BOOLEAN NOT NULL DEFAULT false,
    is_conversion_goal  BOOLEAN NOT NULL DEFAULT false,
    UNIQUE(funnel_id, step_order)
);
CREATE INDEX idx_funnel_step_funnel ON growth_funnel_step(funnel_id, step_order);
```

**match_conditions JSON 结构说明：**

```json
{
  "events": [
    {
      "event_name": "ai_conversation_send",
      "conditions": [
        {"field": "is_first_time", "op": "eq", "value": true}
      ]
    }
  ],
  "session_filter": {
    "min_duration_sec": 10
  }
}
```

- `events`：匹配事件列表，多个事件之间为 **OR** 关系
- `events[].conditions`：同一事件的附加条件，之间为 **AND** 关系
- `session_filter`：可选的会话级过滤条件

**条件操作符（`op`）支持：**

| 操作符 | 含义 | 示例值 |
|--------|------|--------|
| `eq` | 等于 | `true`、`"text"`、`123` |
| `neq` | 不等于 | `false` |
| `in` | 包含 | `["text", "voice"]` |
| `not_in` | 不包含 | `["image"]` |
| `gt` / `gte` | 大于 / 大于等于 | `10` |
| `lt` / `lte` | 小于 / 小于等于 | `100` |
| `between` | 区间 | `[10, 50]` |
| `regex` | 正则匹配 | `"^\\d{4}$"` |

### 3.2 漏斗日级聚合表（ClickHouse）

```sql
CREATE TABLE growth_funnel_daily
(
    date            Date CODEC(Delta, ZSTD),
    funnel_key      LowCardinality(String),

    -- 维度
    platform        LowCardinality(String),    -- ios / android / web / mini_program
    app_version     LowCardinality(String),
    channel         LowCardinality(String),    -- organic / referral / paid / social
    stage           LowCardinality(String),    -- preschool / primary / junior / senior
    grade           LowCardinality(String),
    is_new_user     UInt8,

    -- 步骤数据（数组，索引 = 步骤序号 - 1）
    step_entered     Array(UInt64),
    step_converted   Array(UInt64),
    step_dropped     Array(UInt64),
    step_median_hours Array(Float32),
    step_p90_hours   Array(Float32),

    -- 整体指标
    total_entered    UInt64,
    total_converted  UInt64,
    overall_rate     Float32,

    computed_at      DateTime CODEC(Delta, ZSTD)
)
ENGINE = MergeTree()
PARTITION BY (toYYYYMM(date))
ORDER BY (date, funnel_key, platform, channel, stage, grade, is_new_user)
TTL date + INTERVAL 730 DAY;
```

### 3.3 用户触点记录表（ClickHouse）

```sql
CREATE TABLE user_touchpoint
(
    event_id         String,
    user_id          UInt64,
    session_id       String,
    event_name       LowCardinality(String),
    event_category   LowCardinality(String),  -- learning/social/commercial/system
    event_timestamp  DateTime64(3),
    feature_module   LowCardinality(String),  -- ai_tutor/photo_search/sync_class/mistake_book/...
    feature_action   LowCardinality(String),  -- view/click/complete/share/purchase
    user_stage       LowCardinality(String),

    is_pre_conversion   UInt8,
    conversion_event_id String DEFAULT '',
```

```sql
    touchpoint_module   VARCHAR(64) NOT NULL,
    touchpoint_action   VARCHAR(64),
    period_start        DATE NOT NULL,
    period_end          DATE NOT NULL,
    total_conversions   INT NOT NULL,
    attributed_conversions FLOAT NOT NULL,
    attribution_weight  FLOAT NOT NULL,
```
