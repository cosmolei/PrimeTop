# 增值服务与商品系统 - 详细设计

## 1. 模块概述

### 1.1 定位

增值服务与商品系统（Value-Added Services & Product System，简称 VAS）是订阅制会员的补充商业化模块，面向所有用户（含免费用户和会员）提供按次/按量/按包的增值商品购买与消费能力。

### 1.2 与会员体系的关系

| 维度 | 会员订阅 | 增值商品 |
|------|----------|----------|
| 计费模式 | 周期性（月/季/年） | 一次性购买或按量扣减 |
| 权益范围 | 综合权益包 | 单项能力扩展 |
| 目标用户 | 长期高频用户 | 有特定需求的用户 |
| 交互方式 | 订阅/续费/升降级 | 浏览/购买/消费/用尽提醒 |

### 1.3 核心商品类型

| 商品类型 | 示例 | 计量方式 |
|----------|------|----------|
| 次数包 | AI 问答次数包、拍题次数包、作文批改次数包 | 按次扣减 |
| 时长包 | 口语陪练时长包、1v1 答疑时长包 | 按分钟扣减 |
| 内容包 | 专项题库训练包、精品课程包、考前冲刺资料包 | 解锁后永久/限期访问 |
| 功能包 | 深度作文批改包、高级学情分析报告包 | 按次扣减 |
| 组合包 | 开学礼包、期末冲刺包、暑假特训包 | 包含多种权益的一次性包 |

```sql
CREATE TABLE product (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,

    name            VARCHAR(128) NOT NULL COMMENT '商品名称',
    subtitle        VARCHAR(256) COMMENT '副标题/描述',
    category        VARCHAR(32)  NOT NULL COMMENT '商品分类: COUNT_PACK / TIME_PACK / CONTENT_PACK / FEATURE_PACK / COMBO_PACK',
    sub_category    VARCHAR(64)  COMMENT '子分类，如 ai_qa / photo_question / essay / oral_practice',
    cover_image     VARCHAR(512) COMMENT '封面图 URL',
    detail_images   JSON         COMMENT '详情图 URL 列表',
    description     TEXT         COMMENT '商品详情描述（富文本/Markdown）',
    
    -- 定价
    original_price  DECIMAL(10,2) NOT NULL COMMENT '原价（元）',
    current_price   DECIMAL(10,2) NOT NULL COMMENT '现价（元）',
    currency        VARCHAR(8)   DEFAULT 'CNY' COMMENT '货币',
    
    -- 有效期
    validity_type   VARCHAR(16)  NOT NULL DEFAULT 'PERMANENT' COMMENT 'PERMANENT:永久 / DAYS:购买后N天 / FIXED:固定时间段',
    validity_days   INT          COMMENT 'validity_type=DAYS 时的天数',
    fixed_start     DATETIME     COMMENT 'fixed 开始时间',
    fixed_end       DATETIME     COMMENT 'fixed 结束时间',
    
    -- 商品内容（计数型）
    total_quota     INT          COMMENT '总量（次数/分钟数），NULL 表示不限或按内容解锁',
    quota_unit      VARCHAR(16)  COMMENT '计量单位: TIMES / MINUTES / UNITS',
    
    -- 适用范围
    target_grades   JSON         COMMENT '适用年级列表，NULL 表示全年级',
    target_subjects JSON         COMMENT '适用学科列表，NULL 表示全学科',
    
    -- 关联内容（内容型商品）
    linked_content  JSON         COMMENT '关联内容ID列表，如题库ID、课程ID',
    
    -- 组合包子项
    combo_items     JSON         COMMENT '组合包子项: [{"product_code":"...","quota":10},...]',

    sort_order      INT          DEFAULT 0 COMMENT '排序权重',
    on_sale_at      DATETIME     COMMENT '上架时间',
    off_sale_at     DATETIME     COMMENT '下架时间',
    
    -- 限购
    purchase_limit  INT          COMMENT '每人限购数量，NULL 不限',
    
    -- 标签

    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    INDEX idx_status_sort (status, sort_order),
```

### 3.1 商品浏览与购买流程

```
用户浏览商品列表
    │
    ├── GET /api/v1/products?category=COUNT_PACK&sub_category=ai_qa
    │
    ▼
选择商品/SKU
    │
    ├── GET /api/v1/products/{product_code}/detail
    │
    ▼
确认购买（创建订单）
    │
    ├── POST /api/v1/orders
    │   body: { sku_code, quantity, payment_channel }
    │
    ▼
支付（复用支付服务）
    │
    ├── POST /api/v1/payments/create
    │   body: { order_id, channel }
    │
    ▼
支付回调 → 订单确认
    │
    ├── 支付网关回调 → OrderService.confirm()
    │   1. 校验支付结果
    │   2. 更新订单状态
    │   3. 发放资产（AssetService.grant()）
    │   4. 发送购买成功通知
    │
    ▼
用户看到资产到账
```

### 3.2 资产发放流程

```python
class AssetService:
    """
    资产发放核心逻辑
    """
    
    async def grant(self, user_id: int, order_id: str, 
                    sku: ProductSku, product: Product) -> list[UserAsset]:
        """
        订单支付成功后发放资产
        - 次数包/时长包 → user_asset
        - 内容包 → user_unlocked_content
        - 组合包 → 递归发放子项
        """
        assets = []
        
        if product.category == 'COMBO_PACK':
            # 组合包：递归发放每个子项
            for item in product.combo_items:
                sub_product = await self.get_by_code(item['product_code'])
                sub_assets = await self.grant(
                    user_id, order_id, 
                    # 使用子项的 quota，不是 SKU 的
                    MockSku(quota=item['quota']),
                    sub_product
                )
                assets.extend(sub_assets)
                
        elif product.category in ('COUNT_PACK', 'TIME_PACK', 'FEATURE_PACK'):
            # 计量型资产
            expires_at = self._calc_expires(product)
            asset = UserAsset(
                user_id=user_id,
                asset_type=self._map_asset_type(product.sub_category),
                source_type='PURCHASE',
                source_id=order_id,
                total_quota=sku.quota,
                used_quota=0,
                remaining_quota=sku.quota,
                quota_unit=product.quota_unit,
                expires_at=expires_at,
                status=1,
            )
            await self.asset_repo.create(asset)
            assets.append(asset)
            
        elif product.category == 'CONTENT_PACK':
            # 内容解锁型
            for content_ref in product.linked_content:
                unlock = UserUnlockedContent(
                    user_id=user_id,
                    content_type=content_ref['type'],
                    content_id=content_ref['id'],
                    source_order_id=order_id,
                    expires_at=self._calc_expires(product),
                )
                await self.unlock_repo.create(unlock)
            
        # 刷新缓存
        await self._refresh_cache(user_id)
        
        # 发送资产到账事件
        await self.event_bus.emit(AssetGrantedEvent(
            user_id=user_id, order_id=order_id, assets=assets
        ))
        
        return assets
```

### 3.3 资产消费（扣减）流程

```
业务请求（如 AI 问答）
    │
    ▼
API 网关 / 业务服务 → QuotaCheckMiddleware
    │
    ├── 1. 从 Redis 读取用户该类型资产余额
    ├── 2. 余额 > 0 → 放行，预扣减 Redis 计数
    ├── 3. 余额 = 0 → 拒绝，返回错误码 + 引导购买
    │
    ▼
业务处理（AI 模型调用）
    │
    ▼
结果返回后 → 异步确认扣减
    │
    ├── AssetService.consume()
    │   1. SELECT ... FOR UPDATE （锁定资产行）
    │   2. UPDATE user_asset SET used_quota += 1, remaining_quota -= 1
    │   3. INSERT asset_consume_log
    │   4. remaining_quota = 0 → 更新 status = 2，发事件
    │   5. 释放锁
    │
    ▼
失败回滚
    │
    ├── 业务调用失败 → AssetService.rollback()
    │   1. Redis 计数 +1
    │   2. DB 事务回滚或补偿扣减
```

### 3.4 资产查询与合并逻辑

用户可能同时拥有多个同类型资产（如会员权益 + 购买的次数包），查询余额时需要合并计算：

```python
class AssetQueryService:
    
    async def get_remaining(self, user_id: int, asset_type: str) -> QuotaSummary:
        """
        查询用户某类型资产的合并余额
        优先级：即将过期的 > 刚购买的 > 会员权益
        消费顺序：先进先出（按过期时间升序消费）
        """
        # 先查缓存
        cached = await self.cache.get(f"user:asset:{user_id}:{asset_type}")
        if cached:
            return QuotaSummary(**cached)
        
        # 查 DB
        assets = await self.asset_repo.find_valid_by_type(user_id, asset_type)
        
        total_remaining = sum(a.remaining_quota for a in assets)
        earliest_expire = min(
            (a.expires_at for a in assets if a.expires_at), 
            default=None
        )
        
        result = QuotaSummary(
            asset_type=asset_type,
            total_remaining=total_remaining,
            asset_count=len(assets),
            earliest_expires_at=earliest_expire,
            items=[
                QuotaItem(
                    asset_id=a.id,
                    source_type=a.source_type,
                    remaining=a.remaining_quota,
                    total=a.total_quota,
                    expires_at=a.expires_at,
                ) for a in assets
            ]
        )
        
        # 写缓存（短 TTL，5 分钟）
        await self.cache.set(
            f"user:asset:{user_id}:{asset_type}", 
            result.dict(), ttl=300
        )
        
        return result
```

### 3.5 过期处理（定时任务）

```python
# Celery 定时任务：每小时检查即将过期的资产
@celery.task(name='asset.expire_check')
def expire_check():
    """
    1. 扫描 expires_at < now() 且 status = 1 的资产
    2. 批量更新 status = 3（已过期）
    3. 清除相关缓存
    4. 发送过期通知（过期前1天/3天/7天提醒）
    """
    # 即将过期提醒（7天/3天/1天）
    for days in [7, 3, 1]:
        threshold = now() + timedelta(days=days)
        assets = Asset.query.filter(
            Asset.status == 1,
            Asset.expires_at <= threshold,
            Asset.expires_at > now(),
            Asset.remaining_quota > 0,
        ).all()
        
        for asset in assets:
            notify_user(asset.user_id, 
                f"您的{asset.asset_type}还有{asset.remaining_quota}次，将在{days}天后过期")

    # 已过期处理
    expired = Asset.query.filter(
        Asset.status == 1,
        Asset.expires_at < now(),
    ).all()
    
    for asset in expired:
        asset.status = 3
        clear_asset_cache(asset.user_id, asset.asset_type)
```

### 6.1 业务模块接入配额检查（中间件模式）

```python
# 在 API 网关或业务服务中作为中间件/装饰器使用
class QuotaGuard:
    """
    通用配额守卫
    业务服务通过装饰器声明本接口需要哪种配额
    """
    
    def __init__(self, asset_type: str, amount: int = 1):
        self.asset_type = asset_type
        self.amount = amount
    
    def __call__(self, func):
        async def wrapper(request, *args, **kwargs):
            user_id = request.user_id
            
            # 预扣减（Redis + DB）
            result = await quota_service.pre_deduct(
                user_id=user_id,
                asset_type=self.asset_type,
                amount=self.amount,
                business_type=self.asset_type,
                business_id=request.trace_id,
                trace_id=request.trace_id,
            )
            
            if not result.success:
                raise QuotaInsufficientError(
                    asset_type=self.asset_type,
                    remaining=result.remaining,
                    suggested_product=result.suggested_product,
                )
            
            try:
                response = await func(request, *args, **kwargs)
                # 成功：确认扣减（已由 pre_deduct 完成）
                return response
            except Exception as e:
                # 失败：回滚扣减
                await quota_service.rollback(
                    trace_id=request.trace_id,
                    reason=str(e),
                )
                raise
        
        return wrapper


# 业务模块使用示例
```

```python
class AssetExceptionHandler:
    
    async def handle_deduct_conflict(self, exc: ConcurrentDeductError):
        """
        并发扣减冲突（乐观锁失败）
        策略：自动重试 3 次，间隔 50ms
        """
        for attempt in range(3):
            await asyncio.sleep(0.05 * (attempt + 1))
            result = await self.retry_deduct(exc.trace_id)
            if result.success:
                return result
        raise QuotaServiceUnavailable()
    
    async def handle_grant_failure(self, exc: GrantFailedError):
        """
        资产发放失败（支付成功但发放失败）
        策略：记录补偿表，定时重试 + 告警
        """
        await self.compensation_repo.create(
            order_id=exc.order_id,
            user_id=exc.user_id,
            sku_code=exc.sku_code,
            status='PENDING',
            retry_count=0,
        )
        await self.alert_service.send(
            level='CRITICAL',
            title=f'资产发放失败: order={exc.order_id}',
        )
```

```dart
class PurchaseService {
  final ApiClient _api;
  final PaymentService _payment;
  
  /// 发起购买
  Future<PurchaseResult> purchase({
    required String skuCode,
    required String paymentChannel,
    String? couponCode,
  }) async {
    // 1. 创建订单
    final order = await _api.post('/vas/orders', body: {
      'sku_code': skuCode,
      'quantity': 1,
      'payment_channel': paymentChannel,
      'coupon_code': couponCode,
    });

      orderId: order['order_id'],
      channel: paymentChannel,
      params: order['payment_params'],
    );

      final asset = await _pollAssetGranted(
        orderId: order['order_id'],
        timeout: Duration(seconds: 5),
      );
      
      return PurchaseResult(
        success: true,
        orderId: order['order_id'],
        grantedAsset: asset,
      );
    }
    
    return PurchaseResult(success: false, orderId: order['order_id']);
  }
}
```

### 9.3 服务端 - 配额检查装饰器（Flask）

```python
from functools import wraps
from flask import request, g

def require_quota(asset_type: str, amount: int = 1):
    """
    API 配额检查装饰器
    用法：
        @require_quota('AI_QA')
        def ai_question():
            ...
    """
    def decorator(f):
        @wraps(f)
        async def wrapper(*args, **kwargs):
            user_id = g.user_id
            trace_id = request.headers.get('X-Trace-Id', uuid4().hex)
            
            # 预扣减
            result = await quota_client.pre_deduct(
                user_id=user_id,
                asset_type=asset_type,
                amount=amount,
                business_type=asset_type,
                trace_id=trace_id,
            )
            
            if not result['success']:
                # 余额不足 → 返回引导信息
                return jsonify({
                    'code': 400201,
                    'message': f'{ASSET_NAMES[asset_type]}次数不足',
                    'data': {
                        'remaining': result.get('remaining', 0),
                        'suggested_product': result.get('suggested_product'),
                    }
                }), 402
            
            # 注入 trace_id 供回滚使用
            g.quota_trace_id = trace_id
            
            try:
                response = await f(*args, **kwargs)
                return response
            except Exception:
                # 业务异常 → 回滚扣减
                await quota_client.rollback(trace_id=trace_id)
                raise
        
        return wrapper
    return decorator
```

## 12. 安全与合规

### 12.1 未成年人消费限制

```python
class MinorPurchaseGuard:
    """未成年人购买保护"""
    
    MAX_SINGLE_AMOUNT = Decimal('50.00')  # 单笔最高 50 元
    MAX_MONTHLY_AMOUNT = Decimal('200.00')  # 月累计最高 200 元
    
    async def check(self, user_id: int, amount: Decimal) -> bool:
        profile = await self.get_student_profile(user_id)
        if not profile.is_minor:
            return True  # 成年人不限
        
        if amount > self.MAX_SINGLE_AMOUNT:
            raise MinorPurchaseLimitError(
                f'单笔消费不能超过 {self.MAX_SINGLE_AMOUNT} 元'
            )
        
        monthly_total = await self.get_monthly_total(user_id)
        if monthly_total + amount > self.MAX_MONTHLY_AMOUNT:
            raise MinorPurchaseLimitError(
                f'本月累计消费不能超过 {self.MAX_MONTHLY_AMOUNT} 元'
            )
        
        # 通知家长
        await self.notify_parent(user_id, f'您的孩子正在购买学习增值包（{amount}元）')
        
        return True
```
