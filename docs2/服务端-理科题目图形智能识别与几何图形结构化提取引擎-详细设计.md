## 1. 概述

### 1.1 功能目标

在数学、物理、化学、生物等理科题目中，图形往往是题目的核心信息载体——几何证明题中的三角形、物理题中的受力分析图、化学题中的分子结构、函数题中的曲线图像等。仅靠文本 OCR 无法完整理解题意。

本引擎负责从拍照图片或上传图片中：

1. **检测并切割**题目中的图形区域
2. **分类**图形类型（几何图形、函数图像、电路图、力学图、化学结构式、生物图等）
3. **结构化提取**图形中的关键要素（点坐标、线段、角度、元器件、化学键等）
4. **输出**可供 AI 推理引擎消费的结构化描述

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **流水线设计** | 检测 → 分类 → 解析 → 结构化输出，每步可独立迭代 |
| **降级容错** | 单步失败不阻塞整体流程，降级为区域截图 + 类型标签 |
| **精度优先** | 几何题角度/长度需高精度提取，容忍误差 < 1° / 1px |
| **可扩展** | 新增图形类型只需注册新的解析器，不改核心流程 |
| **缓存复用** | 相似图形可命中缓存，避免重复推理 |

```python
def detect_diagram_regions(preprocessed: PreprocessedImage) -> List[DiagramRegion]:
```

#### 步骤 3：图形类型分类

```python
def classify_diagram(region: DiagramRegion, image: np.ndarray) -> ClassificationResult:
    # 多模型投票 + 规则辅助
    scores = {}
    
    # 1. CNN 分类器（ResNet/EfficientNet 微调）
    cnn_result = diagram_classifier.predict(image)
    for label, prob in cnn_result:
        scores[label] = scores.get(label, 0) + prob * 0.6
    
    # 2. 规则辅助判断
    rule_hints = rule_based_hints(region, image)
    # 例：检测到大量直线段和角度标记 → 倾向几何图形
    #     检测到坐标轴 → 倾向函数图像 / 坐标系
    #     检测到特定符号（Ω、A、V） → 倾向电路图
    for label, weight in rule_hints:
        scores[label] = scores.get(label, 0) + weight * 0.3
    
    # 3. 文本上下文辅助（利用 OCR 结果中的关键词）
    text_hints = text_context_hints(region.nearby_text)
    for label, weight in text_hints:
        scores[label] = scores.get(label, 0) + weight * 0.1
    
    # 选择得分最高的类型
    best_type = max(scores, key=scores.get)
    confidence = scores[best_type]
    
    return ClassificationResult(
        diagram_type=best_type,
        confidence=confidence,
        all_scores=scores,
        is_reliable=confidence > 0.7
    )
```

#### 步骤 4：深度解析（按类型分发）

```python
def parse_diagram(region: DiagramRegion, 
                  classification: ClassificationResult,
                  image: np.ndarray) -> DiagramParseResult:
    
    parser = parser_registry.get(classification.diagram_type)
    
    if parser is None or not classification.is_reliable:
        # 降级：返回区域裁剪图 + 类型标签
        return DiagramParseResult.fallback(
            region=region,
            type_label=classification.diagram_type,
            cropped_image=crop(image, region.bbox),
            reason='NO_PARSER_OR_LOW_CONFIDENCE'
        )
    
    try:
        result = parser.parse(region, ImageContext(image=image, classification=classification))
        result.validate()  # 结构化结果校验
        return result
    except ParseTimeoutError:
        return DiagramParseResult.fallback(region, classification.diagram_type, 
                                           crop(image, region.bbox), 'PARSE_TIMEOUT')
    except ParseError as e:
        return DiagramParseResult.fallback(region, classification.diagram_type,
                                           crop(image, region.bbox), f'PARSE_ERROR: {e}')
```

## 4. 核心图形解析器详细设计

### 4.1 平面几何图形解析器（`GEOMETRY_2D`）

#### 4.1.1 提取要素

| 要素 | 说明 | 提取方法 |
|------|------|----------|
| 顶点 | 点A、B、C 等 | 线段交点检测 + 标注文字OCR |
| 线段 | AB、BC、AC 等 | 霍夫变换 + 端点关联 |
| 角度 | ∠ABC = 60° | 线段夹角计算 + 角度标记识别 |
| 平行/垂直标记 | ∥、⊥ | 符号模板匹配 |
| 相等标记 | 等长记号（单杠/双杠） | 标记检测 |
| 圆 | 圆心、半径、弧 | 圆检测（Hough Circle / 椭圆拟合） |
| 辅助线 | 虚线、延长线 | 线型分类（实线/虚线） |
| 标注文字 | A、B、C、数字 | OCR + 位置关联 |

#### 4.1.2 解析流程

```python
class Geometry2DParser(DiagramParser):
    
    def parse(self, region: DiagramRegion, context: ImageContext) -> DiagramParseResult:
        img = context.image_cropped(region.bbox)
        
        # Step 1: 线段检测
        lines = self._detect_lines(img)
        # lines: [{start: (x,y), end: (x,y), type: 'solid'|'dashed', length_px: float}]
        
        # Step 2: 顶点提取（线段交点 + 端点聚类）
        vertices = self._extract_vertices(lines)
        # vertices: [{point: (x,y), connected_lines: [line_idx, ...]}]
        
        # Step 3: 文字标注识别与关联
        labels = self._ocr_labels(img)
        # labels: [{text: 'A', bbox: (x,y,w,h)}]
        vertex_labels = self._associate_labels_to_vertices(vertices, labels)
        
        # Step 4: 边长与角度计算
        edges = self._compute_edges(vertices, lines)
        angles = self._compute_angles(vertices, edges)
        
        # Step 5: 特殊标记识别
        parallel_marks = self._detect_parallel_marks(lines)
        perpendicular_marks = self._detect_perpendicular_marks(lines)
        equal_length_marks = self._detect_equal_marks(edges)
        right_angle_marks = self._detect_right_angle_marks(vertices)
        
        # Step 6: 圆与弧检测
        circles = self._detect_circles(img)
        arcs = self._detect_arcs(img, circles)
        
        # Step 7: 形状识别（三角形、四边形、多边形）
        shapes = self._identify_shapes(vertices, edges, angles)
        
        return GeometryParseResult(
            vertices=vertex_labels,
            edges=edges,
            angles=angles,
            shapes=shapes,
            circles=circles,
            arcs=arcs,
            marks={
                'parallel': parallel_marks,
                'perpendicular': perpendicular_marks,
                'equal_length': equal_length_marks,
                'right_angle': right_angle_marks,
            },
            # 生成自然语言描述，供 AI 消费
            description=self._generate_description(
                vertex_labels, edges, angles, shapes, circles, arcs
            )
        )
```

### 4.2 函数图像解析器（`FUNCTION_GRAPH`）

#### 4.2.1 提取要素

| 要素 | 说明 |
|------|------|
| 坐标轴 | x轴、y轴，原点位置，正方向 |
| 刻度 | 刻度线位置与对应数值 |
| 曲线 | 函数曲线的像素轨迹 |
| 关键点 | 与坐标轴交点、极值点、拐点 |
| 渐近线 | 水平、垂直、斜渐近线 |
| 区域填充 | 阴影区域（积分、不等式） |
| 标注 | 函数表达式、点坐标文字 |

#### 4.2.2 解析流程

```python
class FunctionGraphParser(DiagramParser):
    
    def parse(self, region: DiagramRegion, context: ImageContext) -> DiagramParseResult:
        img = context.image_cropped(region.bbox)
        
        # Step 1: 坐标轴检测
        axes = self._detect_axes(img)
        # axes: {x_axis: {start, end, direction}, y_axis: {start, end, direction}, origin: (x,y)}
        
        # Step 2: 刻度提取
        ticks = self._extract_ticks(img, axes)
        # 计算像素到实际坐标的比例尺
        scale = self._compute_scale(ticks)
        # scale: {x: pixels_per_unit, y: pixels_per_unit}
        
        # Step 3: 曲线提取（排除坐标轴后的连通区域）
        curves = self._extract_curves(img, axes)
        
        # Step 4: 曲线类型识别（基于形状特征）
        for curve in curves:
            curve.points_real = self._pixel_to_real(curve.points_pixel, axes.origin, scale)
            curve.feature_type = self._classify_curve_shape(curve.points_real)
            # feature_type: 'linear'|'quadratic'|'cubic'|'exponential'|'logarithmic'|
            #               'sinusoidal'|'absolute_value'|'inverse'|'unknown'
        
        # Step 5: 关键点检测
        key_points = self._detect_key_points(curves, axes)
        # 与x轴交点（零点）、与y轴交点、极值点、拐点
        
        # Step 6: 函数参数拟合
        for curve in curves:
            if curve.feature_type != 'unknown':
                curve.fitted_params = self._fit_function(curve.feature_type, curve.points_real)
                curve.equation_str = self._params_to_equation(curve.feature_type, curve.fitted_params)
        
        # Step 7: 标注文字识别
        annotations = self._ocr_annotations(img)
        
        return FunctionGraphParseResult(
            axes=axes,
            scale=scale,
            curves=curves,
            key_points=key_points,
            annotations=annotations,
            description=self._generate_description(axes, curves, key_points)
        )
```

### 4.3 电路图解析器（`CIRCUIT_DIAGRAM`）

#### 4.3.1 支持的元器件

| 符号 | 元器件 | 识别方法 |
|------|--------|----------|
| ─[ ]─ | 电阻 R | 矩形框 + 字母R |
| ─(Ω)─ | 电阻（国际符号） | 锯齿形 + 字母R |
| ─| |─ | 电容 C | 两条平行短线 |
| ─⊘─ | 电压表 V | 圆圈中带V |
| ─⊙─ | 电流表 A | 圆圈中带A |
| ─ бат─ | 电池/电源 | 长短线交替 |
| ─/ ─ | 开关 S | 带缺口的线段 |
| (E) | 电动势 E | 圆圈中带E |

#### 4.3.2 解析流程

```python
class CircuitDiagramParser(DiagramParser):
    
    def parse(self, region: DiagramRegion, context: ImageContext) -> DiagramParseResult:
        img = context.image_cropped(region.bbox)
        
        # Step 1: 元器件检测（基于模板匹配 / 轻量级目标检测）
        components = self._detect_components(img)
        # components: [{type: 'RESISTOR', bbox, label: 'R1', value: '10Ω'}, ...]
        
        # Step 2: 导线提取（连通性分析）
        wires = self._trace_wires(img, components)
        # 建立节点-元器件拓扑图
        
        # Step 3: 节点识别
        nodes = self._identify_nodes(components, wires)
        
        # Step 4: 回路识别
        loops = self._identify_loops(components, wires, nodes)
        
        # Step 5: 构建电路拓扑图
        circuit_graph = self._build_circuit_graph(components, wires, nodes, loops)
        
        # Step 6: 参数提取（电阻值、电压值等）
        for comp in components:
            if comp.label:
                comp.value = self._extract_component_value(comp.label, context.nearby_text)
        
        return CircuitParseResult(
            components=components,
            nodes=nodes,
            wires=wires,
            loops=loops,
            circuitGraph=circuitGraph,
            description=self._generate_description(components, nodes, loops)
        )
```

## 7. 错误处理

### 7.1 错误码体系

| 错误码 | HTTP | 含义 | 处理建议 |
|--------|------|------|----------|
| `DIAGRAM_001` | 400 | 图片格式不支持 | 提示用户上传 JPG/PNG |
| `DIAGRAM_002` | 400 | 图片尺寸过小 (< 100x100) | 提示用户重新拍照 |
| `DIAGRAM_003` | 400 | 图片尺寸过大 (> 20MB) | 自动压缩后重试 |
| `DIAGRAM_004` | 422 | 未检测到任何图形区域 | 返回空结果，提示"未识别到图形" |
| `DIAGRAM_005` | 422 | 所有图形分类置信度均 < 0.3 | 返回检测区域截图 + "未知图形类型" |
| `DIAGRAM_101` | 500 | 检测模型推理失败 | 降级为布局分析区域提取 |
| `DIAGRAM_102` | 500 | 分类模型推理失败 | 降级为 "MIXED" 类型 |
| `DIAGRAM_103` | 500 | 深度解析器异常 | 降级返回区域截图 + 类型标签 |
| `DIAGRAM_104` | 504 | 处理超时 | 返回部分结果 + 超时提示 |
| `DIAGRAM_201` | 429 | 调用频率超限 | 提示用户稍后重试 |
| `DIAGRAM_202` | 403 | 非会员超出每日限额 | 引导购买会员 |

### 7.2 降级策略

```
正常流程：检测 + 分类 + 深度解析 → 结构化数据
                                    │
                              失败 ↓
检测 + 分类（无解析） → 类型标签 + 区域截图
                           │
                     失败 ↓
仅检测（无分类） → 区域截图 + "图形区域" 标签
                      │
                失败 ↓
返回原图 + "未识别到图形"（不影响文本 OCR 和 AI 解题流程）
```

**关键原则**：图形识别失败绝不能阻塞拍题答疑主流程。AI 解题引擎始终可以获取原图作为兜底。

### 7.3 重试策略

| 场景 | 策略 |
|------|------|
| 模型推理瞬时失败 | 自动重试 1 次，间隔 500ms |
| GPU 资源不足 | 进入队列，最多等待 15s |
| 图片解码失败 | 不重试，直接返回错误 |
| 超时 | 不重试，返回部分结果 |

```yaml
      failure_rate_threshold: 0.5
      wait_duration_in_open_state: 30s
    deep_parse:
      failure_rate_threshold: 0.3      # 深度解析失败率高时熔断
      wait_duration_in_open_state: 60s
```

### 8.3 缓存策略

```python
def get_cached_or_recognize(image_id: str, bbox: BBox) -> Optional[DiagramParseResult]:
    # 1. 计算感知哈希
    phash = compute_phash(image_id, bbox)
    
    # 2. 查询缓存
    cached = diagram_cache_repo.find(phash, bbox_hash(bbox))
    if cached and cached.confidence > 0.7:
        # 更新命中统计
        diagram_cache_repo.increment_hit_count(phash, bbox_hash(bbox))
        return cached
    
    return None  # 未命中，执行识别

def cache_result(image_id: str, bbox: BBox, result: DiagramParseResult):
    if result.confidence < 0.5:
        return  # 低置信度结果不缓存
    
    phash = compute_phash(image_id, bbox)
    diagram_cache_repo.save(
        image_hash=phash,
        bbox_hash=bbox_hash(bbox),
        diagram_type=result.diagram_type,
        structured_data=result.structured_data,
        description=result.description,
        confidence=result.confidence
    )
```

### 9.2 构建 AI 解题上下文

```python
def build_prompt_with_diagrams(question_text: str, 
                                diagrams: List[DiagramData],
                                subject: str,
                                grade: str) -> str:
    prompt_parts = [
        f"## 题目文本\n{question_text}",
    ]
    
    for i, diag in enumerate(diagrams):
        prompt_parts.append(f"\n## 图形信息 {i+1}")
        prompt_parts.append(f"图形类型: {diag.type_name}")
        prompt_parts.append(f"图形描述: {diag.description}")
        
        if diag.structured_data:
            prompt_parts.append(f"结构化数据:\n```json\n{json.dumps(diag.structured_data, ensure_ascii=False, indent=2)}\n```")
        
        if diag.cropped_image_url:
            prompt_parts.append(f"\n[附图: {diag.cropped_image_url}]")
    
    prompt_parts.append(f"\n## 解题要求")
    prompt_parts.append(f"请基于以上题目文本和图形信息进行解答。学科: {subject}，年级: {grade}。")
    prompt_parts.append("注意分析图形中的关键要素和关系。")
    
    return "\n".join(prompt_parts)
```

```python
# 反馈数据回流管线
def feedback_loop():
    """
    收集用户纠正反馈 → 人工审核 → 扩充训练集 → 重训模型
    """
    # 1. 收集低置信度或被纠正的样本
    feedback_samples = collect_feedback_samples(days=30)
    
    # 2. 人工审核（标注平台）
    reviewed = review_platform.batch_review(feedback_samples)
    
    # 3. 加入训练集
    for sample in reviewed:
        training_set.add(sample)
    
    # 4. 触发模型重训（达到阈值时）
    if training_set.new_samples_count > 500:
        trigger_retrain(model_type='detection')
```
