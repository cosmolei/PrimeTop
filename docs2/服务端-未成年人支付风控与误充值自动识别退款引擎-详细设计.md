# 未成年人支付风控与误充值自动识别退款引擎 - 详细设计

> **文档版本**：v1.0  
> **创建日期**：2026-06-20  
> **关联模块**：支付服务、会员订阅、用户服务、家长中心、风控系统  
> **优先级**：P1（V1.0 阶段必须具备）

---

## 1. 模块概述

### 1.1 设计背景

启硕 PrimeTop 面向 K12 全学段用户，核心用户群包含大量未成年人。根据中国《未成年人保护法》《未成年人网络保护条例》《关于防止未成年人沉迷网络游戏的通知》等法规要求，以及 Apple App Store / Google Play 的相关合规政策，教育类 APP 必须建立完善的未成年人支付保护机制：

1. **法规要求**：未成年人未经监护人同意进行的网络消费，监护人有权要求退款。
2. **平台合规**：App Store 和 Google Play 对未成年人应用内购有严格审核要求。
3. **用户体验**：误充值引发的客诉若处理不当，将导致差评、投诉升级和品牌损失。
4. **风控需求**：恶意退款请求也需要被有效识别和拦截，保障平台营收安全。

### 1.2 功能目标

构建一套覆盖**事前拦截、事中监控、事后处理**的全链路支付风控引擎：

| 阶段 | 核心能力 |
| --- | --- |
| 事前拦截 | 支付前风险评估、未成年人操作识别、支付密码验证、家长授权校验 |
| 事中监控 | 异常支付行为实时检测、高频消费拦截、大额消费预警 |
| 事后处理 | 误充值自动识别、退款申请智能分拣、自动化退款执行、人工审核工作台 |

### 1.3 设计原则

1. **未成年人优先**：在风险与体验冲突时，优先保护未成年人权益。
2. **自动为主、人工为辅**：标准化场景自动处理，复杂场景人工介入。
3. **可审计可追溯**：所有风控决策保留完整推理链路和审计日志。
4. **合规驱动**：严格遵循教育类产品支付合规要求。

### 2.2 核心服务职责

| 服务 | 职责 | 部署方式 |
| --- | --- | --- |
| RiskPreCheck | 支付前风险评估与拦截决策 | 同步调用，<100ms 响应 |
| RiskMonitor | 实时支付行为监控与异常告警 | 异步事件驱动 |
| RefundProcess | 退款申请接收、分拣、执行 | 混合（自动+人工） |
| RuleEngine | 风控规则管理与执行 | 同步+异步 |

| RefundDecisionEngine | 退款决策（自动批准/拒绝/转人工） | 同步调用 |

## 4. 事前风控：支付前风险评估

### 4.1 风控检查流程

```
用户发起支付请求
        │
        ▼
┌───────────────────┐
│ 1. 基础身份校验    │ ── 用户是否存在、是否登录态有效
└───────┬───────────┘
        │ pass
        ▼
┌───────────────────┐
│ 2. 支付权限校验    │ ── 支付管控状态检查（冻结/禁止？）
└───────┬───────────┘
        │ pass
        ▼
┌───────────────────┐
│ 3. 未成年人专项检查 │ ── 是否未成年？家长是否授权？家长支付密码？
└───────┬───────────┘
        │ pass / challenge
        ▼
┌───────────────────┐
│ 4. 规则引擎评估    │ ── 频次/金额/设备/行为模式等规则匹配
└───────┬───────────┘
        │
        ▼
┌───────────────────────────────────────┐
│ 5. 综合决策                           │
│   risk_score < 30 → PASS              │
│   30 ≤ risk_score < 60 → CHALLENGE    │
│   60 ≤ risk_score < 80 → REVIEW       │
│   risk_score ≥ 80 → BLOCK             │
└───────────────────────────────────────┘
```

### 4.2 未成年人支付专项检查

```java
/**
 * 未成年人支付前置检查服务
 */
@Service
public class MinorPaymentPreCheckService {

    @Autowired
    private UserRiskProfileService profileService;
    @Autowired
    private ParentBindingService parentBindingService;
    @Autowired
    private PaymentPasswordService passwordService;
    @Autowired
    private FeatureService featureService;

    /**
     * 未成年人支付前专项检查
     * 
     * @param request 支付请求上下文
     * @return 检查结果
     */
    public PreCheckResult check(MinorPaymentContext context) {
        Long userId = context.getUserId();
        RiskProfile profile = profileService.getOrInit(userId);

        // Step 1: 判断是否未成年人
        if (!profile.isMinor()) {
            return PreCheckResult.pass();
        }

        // Step 2: 检查支付管控状态
        if (profile.getPaymentStatus() == PaymentControlStatus.PERMANENT_BAN.getCode()) {
            return PreCheckResult.block("ACCOUNT_PAYMENT_BANNED", 
                "该账号已被禁止支付：" + profile.getFrozenReason());
        }
        if (profile.getPaymentStatus() == PaymentControlStatus.FROZEN_TEMP.getCode()) {
            if (profile.getFrozenUntil() != null 
                && profile.getFrozenUntil().isAfter(LocalDateTime.now())) {
                return PreCheckResult.block("ACCOUNT_PAYMENT_FROZEN",
                    "该账号支付功能暂时冻结，解冻时间：" + profile.getFrozenUntil());
            }
        }

        // Step 3: 金额限制检查
        BigDecimal amount = context.getAmount();
        if (profile.getPaymentLimitSingle() != null 
            && amount.compareTo(profile.getPaymentLimitSingle()) > 0) {
            return PreCheckResult.block("EXCEED_SINGLE_LIMIT",
                String.format("单笔支付限额 ¥%.2f，当前金额 ¥%.2f", 
                    profile.getPaymentLimitSingle(), amount));
        }

        // Step 4: 家长授权校验
        ParentAuthorizationResult authResult = checkParentAuthorization(context, profile);
        if (!authResult.isPassed()) {
            return authResult.toPreCheckResult();
        }

        // Step 5: 24小时/7天 累计限额检查
        if (exceedsCumulativeLimit(profile, amount)) {
            return PreCheckResult.block("EXCEED_CUMULATIVE_LIMIT",
                "超出周期内累计支付限额");
        }

        // Step 6: 高风险行为模式检测
        RiskPatternResult patternResult = detectRiskPattern(context, profile);
        if (patternResult.getRiskLevel() >= RiskLevel.HIGH) {
            return PreCheckResult.review("HIGH_RISK_PATTERN_DETECTED", 
                patternResult.getDetail());
        }

        return PreCheckResult.pass();
    }

    /**
     * 家长授权校验
     */
    private ParentAuthorizationResult checkParentAuthorization(
            MinorPaymentContext context, RiskProfile profile) {
        // 未绑定家长：根据金额和频次决定是否需要绑定
        if (!profile.isParentBound()) {
            BigDecimal amount = context.getAmount();
            // 超过阈值必须绑定家长才能支付
            if (amount.compareTo( minorPaymentConfig.getRequireParentBindThreshold()) >= 0) {
                return ParentAuthorizationResult.requireParentBinding(
                    "根据未成年人保护要求，支付 ¥" 
                    + minorPaymentConfig.getRequireParentBindThreshold() 
                    + " 以上需要绑定家长账号");
            }
            // 首次支付需要引导绑定（但不强制阻断）
            if (profile.getTotalPaymentCount() == 0) {
                return ParentAuthorizationResult.guideBindParent(null);
            }
            return ParentAuthorizationResult.pass();
        }

        Long parentId = parentBindingService.getParentId(context.getUserId());
        if (!passwordService.hasPaymentPassword(parentId)) {
            // 低额支付允许，高额需要设置密码
            if (context
