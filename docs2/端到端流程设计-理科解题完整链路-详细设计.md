### 2.3 阶段划分

| 阶段 | 名称 | 耗时目标 | 负责方 |
|------|------|----------|--------|
| P1 | 入口适配与上下文构建 | ≤100ms | 客户端 / 服务端入口层 |
| P2 | 额度预检 | ≤50ms | 解题编排 → 额度服务 |
| P3 | 学科识别 + 条件结构化 + 模型匹配 | ≤1s | 解题编排 → 模型匹配服务 |
| P4 | AI 推理解题 (SSE 流式) | 首 token ≤2s, 完整 ≤20s | 解题编排 → AI → RAG |
| P5 | 结果校验与后处理 | ≤500ms | 解题编排 → 校验服务 |
| P6 | 渐进式答案展示 (含答案管控) | 即时 (流式) | 解题编排 → 答案管控 → 客户端 |
| P7 | 后置异步处理 | 异步, ≤5s | 事件消费者集群 |

## 3. 入口场景详细设计

### 3.1 入口①：AI 辅导对话

**场景**：学生在 AI 对话中输入理科问题（文字/语音/图片），系统识别为理科题目后自动激活解题引擎。

```dart
// 客户端：AI对话页监听理科意图
class AIChatScienceDetector {
  /// 检测对话中是否出现理科解题意图
  ScienceDetectResult? detect(UserMessage message) {
    // 已有学科上下文 + 问题包含理科关键词 → 直接激活
    if (message.subjectContext?.isScience == true) {
      return ScienceDetectResult(
        subject: message.subjectContext!.subject,
        confidence: 1.0,
        source: 'context',
      );
    }

    // 无学科上下文 → 客户端轻量关键词预判
    final keywords = _scienceKeywords[message.currentSubject];
    if (keywords != null) {
      for (final kw in keywords) {
        if (message.text.contains(kw)) {
          return ScienceDetectResult(
            subject: message.currentSubject!,
            confidence: 0.7,
            source: 'keyword',
          );
        }
      }
    }
    return null; // 交由服务端判定
  }
}
```

```json

  "messageId": "msg_xyz789",
  "question": {

    "imageUrl": null,
    "ocrResultId": null
  },

    "subject": "math",
```

- 解题结果回注到对话流中

### 3.2 入口②：拍照搜题

**场景**：用户拍照后识别为理科题目，搜题编排服务调用理科解题引擎。

```python
# 服务端：拍照搜题编排 → 理科解题引擎的桥接
class PhotoSearchScienceBridge:
    """拍照搜题识别为理科后的桥接逻辑"""

    async def bridge_to_science_solve(
        self,
        parsed_question: ParsedQuestion,
        search_context: PhotoSearchContext,
    ) -> ScienceSolveRequest:
        """将拍照搜题上下文转换为理科解题请求"""

        return ScienceSolveRequest(
            entry_point=EntryPoint.PHOTO_SEARCH,
            request_id=search_context.request_id,
            question=QuestionInput(
                text=parsed_question.structured_text,
                image_url=search_context.oss_url,
                ocr_result_id=parsed_question.ocr_id,
                ocr_confidence=parsed_question.confidence,
            ),
            context=UserContext(
                user_id=search_context.user_id,
                subject=parsed_question.subject,
                grade_level=search_context.grade_level,
                textbook_version=search_context.textbook_version,
                chapter_id=parsed_question.chapter_id,
                conversation_history=[],  # 拍题无对话历史

                show_method_summary=True,
                show_similar_problems=True,

```

**特点**：
- 携带 OCR 置信度，影响后续掌握度证据强度
- 无对话历史，依赖题面文本和 OCR 结构化数据
- 拍题入口的图片 URL 传递给多模态模型

### 3.4 入口④：练习测评

**场景**：学生在练习中提交理科题目答案后，触发解题引擎生成标准解题步骤供对照。

```python
class PracticeScienceBridge:
    """练习批改后触发理科解题"""

    async def on_answer_submitted(
        self,
        event: PracticeAnswerSubmittedEvent,
    ) -> None:
        """练习答案提交后，如果答错或部分正确，触发明细解题"""

        question = await self._question_repo.get(event.question_id)

        if not question.subject.is_science:
            return

        # 仅在答错/部分正确时生成详细解析
        if event.correctness == Correctness.FULL_CORRECT:
            return

        solve_request = ScienceSolveRequest(
            entry_point=EntryPoint.PRACTICE,
            practice_session_id=event.session_id,
            question=QuestionInput(
                text=question.text,
                question_bank_id=question.id,
            ),
            context=UserContext(
                user_id=event.user_id,
                subject=question.subject,
                grade_level=event.grade_level,
                textbook_version=event.textbook_version,
                chapter_id=question.chapter_id,
            ),
            options=SolveOptions(
                detail_level="detailed",
                show_method_summary=True,
                show_similar_problems=True,
                # 练习场景不流式，批改结果页一次性展示
                streaming=False,
            ),
        )

        # 异步生成，不阻塞批改流程
        asyncio.create_task(self._science_service.solve(solve_request))
```

## 4. 阶段详细设计

### 4.1 P1：入口适配与上下文构建

#### 4.1.1 统一请求模型

不同入口通过 `ScienceSolveRequest` 统一入参，入口适配层负责将各入口参数转换。

```python
@dataclass
class ScienceSolveRequest:
    """理科解题统一请求"""
    # 入口标识
    entry_point: EntryPoint          # ai_chat | photo_search | sync_classroom | practice | mistake_review
    request_id: str = field(default_factory=generate_request_id)

    # 多态入口字段（按入口类型填充）
    conversation_id: Optional[str] = None   # ai_chat
    practice_session_id: Optional[str] = None  # practice
    lesson_id: Optional[str] = None         # sync_classroom
    mistake_id: Optional[str] = None        # mistake_review

    # 题目输入
    question: QuestionInput

    # 用户上下文
    context: UserContext

    # 解题选项
    options: SolveOptions

    # 客户端信息
    client_request_id: Optional[str] = None  # 幂等键
    device_info: Optional[DeviceInfo] = None


@dataclass
class QuestionInput:
    """题目输入（多模态）"""
    text: str                                    # 题目文本（必填）
    image_url: Optional[str] = None              # 题目图片 URL
    ocr_result_id: Optional[str] = None          # OCR 结果 ID
    ocr_confidence: Optional[float] = None       # OCR 置信度
    question_bank_id: Optional[str] = None       # 题库中的题目 ID（如有）


@dataclass
class UserContext:
    """用户上下文"""
    user_id: int
    subject: Optional[Subject] = None           # 学科（可为空，服务端自动检测）
    grade_level: Optional[GradeLevel] = None
    textbook_version: Optional[str] = None
    chapter_id: Optional[str] = None
    conversation_history: List[Dict] = field(default_factory=list)
    previous_errors: List[ErrorTag] = field(default_factory=list)  # 错题场景


@dataclass
class SolveOptions:
    """解题选项"""
    detail_level: str = "detailed"              # brief | standard | detailed
    show_method_summary: bool = True
    show_similar_problems: bool = True
    emphasize_error_points: bool = False        # 错题重练场景强化易错点
    max_steps: int = 20
    streaming: bool = True
```

```python
class ScienceClassifierService:
    """理科题目分类器"""

    async def classify(
        self,
        question: QuestionInput,
        context: UserContext,
    ) -> ClassificationResult:
        """学科+题型分类"""

        # 优先使用上下文学科
        if context.subject and context.subject.is_science:
            subject = context.subject
        else:
            # 自动检测学科
            subject = await self._detect_subject(question.text)

        # 题型分类（基于规则+轻量模型）
        problem_type = await self._classify_type(
            text=question.text,
            subject=subject,
            grade_level=context.grade_level,
        )

        return ClassificationResult(
            subject=subject,
            problem_type=problem_type,
            confidence=0.95,
        )

    async def _detect_subject(self, text: str) -> Subject:
        """学科检测"""
        # 规则优先：关键词命中
        subject_keywords = {
            Subject.MATH: ["方程", "函数", "几何", "数列", "概率", "积分", "导数"],
            Subject.PHYSICS: ["受力", "速度", "加速度", "电路", "电场", "磁场", "光"],
            Subject.CHEMISTRY: ["化学", "反应", "元素", "分子", "离子", "有机", "酸碱"],
            Subject.BIOLOGY: ["细胞", "基因", "DNA", "遗传", "生态", "光合", "呼吸"],
        }

        scores = {}
        for subj, kws in subject_keywords.items():
            scores[subj] = sum(1 for kw in kws if kw in text)

        best = max(scores, key=scores.get)
        if scores[best] >= 2:
            return best

        # 降级：轻量分类模型
        return await self._classifier_model.predict(text)

    async def _classify_type(
        self, text: str, subject: Subject, grade_level: GradeLevel,
    ) -> str:
        """题型分类"""
        # 从模型目录中匹配（见理科解题-详细设计.md §3.3）
        models = await self._model_catalog.get_models(
            subject=subject,
            grade_level=grade_level,
        )
        for model in models:
            if any(kw in text for kw in model.keywords):
                return model.id

        # 默认返回学科通用解题
        return f"{subject.value}_general"
```

```python
class ConditionExtractor:
    """从题目文本中结构化提取已知条件、隐含条件、求解目标"""

    async def extract(
        self,
        text: str,
        subject: Subject,
        problem_type: str,
    ) -> StructuredConditions:
        """条件结构化"""

        # 数学类：提取变量、方程、约束
        if subject == Subject.MATH:
            return await self._extract_math_conditions(text, problem_type)

        # 物理/化学类：提取物理量、单位、已知/求
        if subject in (Subject.PHYSICS, Subject.CHEMISTRY):
            return await self._extract_physics_conditions(text, problem_type)

        # 生物类：较轻的结构化，主要做关键词标注
        return await self._extract_bio_conditions(text)

    async def _extract_physics_conditions(
        self, text: str, problem_type: str,
    ) -> StructuredConditions:
        """物理条件提取"""
        # 使用 NER + 规则提取 "量值+单位" 模式
        # 例: "初速度 20m/s" → {"symbol": "v₀", "value": 20, "unit": "m/s"}
        conditions = []

        # 正则匹配: 数字+单位模式
        import re
        patterns = [
            (r'(\d+\.?\d*)\s*(m/s|kg|N|J|W|V|A|Ω|Pa|Hz|℃|°)', 'physical_quantity'),
            (r'质量[为是约]\s*(\d+\.?\d*)\s*(kg|g)', 'mass'),
            (r'速度[为是约]\s*(\d+\.?\d*)\s*(m/s|km/h)', 'velocity'),
        ]

        for pattern, qtype in patterns:
            for match in re.finditer(pattern, text):
                conditions.append(Condition(
                    type="explicit",
                    raw=match.group(0),
                    value=match.group(1),
                    unit=match.group(2),
                ))

        # 隐含条件推断（基于题型）
        implicit = self._infer_implicit_conditions(problem_type, conditions)

        # 求解目标提取
        target = self._extract_target(text)

        return StructuredConditions(
            explicit=conditions,
            implicit=implicit,
            target=target,
        )

    def _infer_implicit_conditions(
        self, problem_type: str, explicit: List[Condition],
    ) -> List[Condition]:
        """基于题型推断隐含条件"""
        implicit_rules = {
            "projectile_motion": [
                Condition(type="implicit", symbol="g", value="9.8", unit="m/s²",
                          description="重力加速度"),
            ],
            "circuit": [
                Condition(type="implicit", description="串联电流相等"),
                Condition(type="implicit", description="并联电压相等"),
            ],
        }
        return implicit_rules.get(problem_type, [])
```

```python
class ScienceSolveStreamGenerator:
    """理科解题 SSE 流式生成器"""

    async def stream_solve(
        self,
        request: ScienceSolveRequest,
        prompt_ctx: PromptContext,
        quota_reservation: QuotaReservation,
    ) -> AsyncIterator[SSEEvent]:
        """SSE 流式解题"""

        solve_id = generate_solve_id()
        full_response = StringBuilder()

        # ① 发送元信息
        yield SSEEvent(event="meta", data={
            "solve_id": solve_id,
            "entry_point": request.entry_point.value,
            "source": "ai",
        })

        try:
            # ② 调用 AI 模型 (流式)
            async for token in self._ai_service.stream_chat(
                messages=prompt_ctx.messages,
                model=prompt_ctx.model.model_name,
                temperature=prompt_ctx.model.temperature,
                max_tokens=prompt_ctx.model.max_tokens,
            ):
                full_response.append(token)
                yield SSEEvent(event="delta", data={
                    "content": token,
                    "type": "text",
                })

            # ③ 后处理：解析 AI 结构化输出
            raw_text = full_response.to_string()
            processed = await self._post_process(raw_text, request)

            # ④ 答案管控分级
            tiers = self._answer_tier_service.split_into_tiers(
                full_text=processed.clean_text,
                subject=request.context.subject,
                question_type=classification.problem_type,
                user_grade=request.context.grade_level,
            )
            for tier in tiers:
                yield SSEEvent(event=f"tier_{tier.level}", data=tier.to_dict())

            # ⑤ 知识点标注
            kps = await self._knowledge_service.extract_points(
                text=processed.clean_text,
                subject=request.context.subject,
                grade=request.context.grade_level,
            )
            yield SSEEvent(event="knowledge_points", data={
                "points": [kp.to_dict() for kp in kps],
            })

            # ⑥ 易错点标注
            traps = self._extract_traps(processed.steps)
            if traps:
                yield SSEEvent(event="error_prone_points", data={
                    "traps": traps,
                })

            # ⑦ 方法总结
            if request.options.show_method_summary and processed.method_summary:
                yield SSEEvent(event="method_summary", data={
                    "title": processed.method_summary.title,
                    "strategy": processed.method_summary.strategy,
                    "key_formulas": [f.to_dict() for f in processed.method_summary.key_formulas],
                })

            # ⑧ 同类题推荐
            if request.options.show_similar_problems:
                related = await self._question_service.find_similar(
                    text=request.question.text,
                    subject=request.context.subject,
                    grade=request.context.grade_level,
                    problem_type=classification.problem_type,
                    top_k=3,
                )
                yield SSEEvent(event="related_questions", data={
                    "questions": [{"id": r.id, "title": r.title, "difficulty": r.difficulty} for r in related],
                })

            # ⑨ 确认额度扣减
            await self._quota_service.confirm(quota_reservation.reservation_id)

            # ⑩ 异步保存（不阻塞 SSE 流）
            asyncio.create_task(self._async_save(
                solve_id=solve_id,
                request=request,
                processed=processed,
                kps=kps,
                tokens_used=processed.token_count,
                ai_model=prompt_ctx.model.model_name,
            ))

            yield SSEEvent(event="done", data={
                "solve_id": solve_id,
                "total_tokens": processed.token_count,
                "duration_ms": processed.duration_ms,
            })

        except AIModelError as e:
            # AI 模型错误 → 切换备选模型重试
            yield SSEEvent(event="fallback", data={"reason": str(e)})
            async for event in self._retry_with_fallback(
                request, prompt_ctx, quota_reservation, e,
            ):
                yield event
```

```python
class ScienceResultValidator:
    """理科解题结果校验器"""

    async def validate(
        self,
        raw_response: str,
        request: ScienceSolveRequest,
        classification: ClassificationResult,
    ) -> ValidationResult:
        """多维校验"""

        errors = []

        # ① 格式校验：JSON 结构完整性
        parsed = self._parse_response(raw_response)
        if not parsed:
            errors.append(ValidationError(
                type="format", severity="high",
                message="AI输出格式异常，无法解析为结构化数据",
            ))
            return ValidationResult(valid=False, errors=errors, parsed=None)

        # ② 数值验算（数学/物理/化学）
        if classification.subject in (Subject.MATH, Subject.PHYSICS, Subject.CHEMISTRY):
            calc_errors = self._verify_calculations(parsed.steps)
            errors.extend(calc_errors)

        # ③ 单位一致性检查（物理/化学）
        if classification.subject in (Subject.PHYSICS, Subject.CHEMISTRY):
            unit_errors = self._check_units(parsed.steps, classification.subject)
            errors.extend(unit_errors)

        # ④ 公式合理性检查
        formula_errors = self._check_formulas(parsed.steps, classification.problem_type)
        errors.extend(formula_errors)

        # ⑤ 逻辑一致性检查（答案是否回答了题目所问）
        logic_errors = self._check_logic_consistency(
            parsed, request.question.text,
        )
        errors.extend(logic_errors)

        # 判定严重程度
        critical = [e for e in errors if e.severity == "high"]
        if critical:
            return ValidationResult(valid=False, errors=errors, parsed=parsed)

        return ValidationResult(
            valid=True,
            errors=errors,  # 可包含 low 级别的提示
            parsed=parsed,
        )

    def _verify_calculations(self, steps: List[Step]) -> List[ValidationError]:
        """数值验算：提取步骤中的算式，用 Python 计算/符号计算验证"""
        errors = []
        for step in steps:
            for formula in step.formulas:
                try:
                    # 提取等号两侧，计算右侧，对比左侧
                    result = self._eval_math_expression(formula)
                    expected = self._extract_result(formula)
                    if result is not None and expected is not None:
                        if not self._approx_equal(result, expected, tolerance=0.02):
                            errors.append(ValidationError(
                                type="calculation",
                                severity="high",
                                step_index=step.step_index,
                                message=f"步骤{step.step_index}计算有误: 期望{expected}, 实际{result}",
                            ))
                except Exception:
                    pass  # 无法验算的表达式跳过
        return errors

    def _check_units(self, steps: List[Step], subject: Subject) -> List[ValidationError]:
        """单位一致性检查"""
        errors = []
        for step in steps:
            for formula in step.formulas:
                if not self._units_consistent(formula, subject):
                    errors.append(ValidationError(
                        type="unit",
                        severity="medium",
                        step_index=step.step_index,
                        message=f"步骤{step.step_index}可能存在单位不一致",
                    ))
        return errors
```

```python
class ScienceSolveEventConsumer:
    """理科解题完成后置处理"""

    @subscribe("science_solve.completed")
    async def on_solve_completed(self, event: ScienceSolveCompletedEvent):
        """解题完成事件处理"""

        # 并行执行不互相依赖的任务
        await asyncio.gather(
            self._update_mastery(event),
            self._record_solve(event),
            self._update_ability_dimensions(event),
            self._track_cost(event),
            self._emit_analytics(event),
            return_exceptions=True,
        )

        # 依赖前序完成的任务
        if event.entry_point == EntryPoint.MISTAKE_REVIEW:
            await self._update_mistake_record(event)

        if event.is_new_question:
            await self._ingest_new_question(event)

    async def _update_mastery(self, event: ScienceSolveCompletedEvent):
        """更新知识点掌握度"""
        knowledge_points = await self._kp_extractor.extract(
            event.question_text,
            event.answer_text,
            event.subject,
        )

        # 入口因子：不同入口的学习证据强度不同
        entry_factors = {
            EntryPoint.AI_CHAT: 0.6,
            EntryPoint.PHOTO_SEARCH: 0.8,
            EntryPoint.SYNC_CLASSROOM: 0.7,
            EntryPoint.PRACTICE: 1.0,       # 练习场景证据最强
            EntryPoint.MISTAKE_REVIEW: 0.9,  # 错题重练也较强
        }
        entry_factor = entry_factors.get(event.entry_point, 0.5)

        # 难度权重
        difficulty_weights = {"easy": 0.6, "medium": 0.8, "hard": 1.0}
        difficulty_weight = difficulty_weights.get(event.difficulty, 0.7)

        # 用户行为因子：是否完整查看
        behavior_factor = 1.0 if event.fully_viewed else 0.4

        evidence_strength = entry_factor * difficulty_weight * behavior_factor

        for kp in knowledge_points:
            await self._mastery_service.update(
                user_id=event.user_id,
                knowledge_point_id=kp.id,
                evidence_type=f"science_solve_{event.entry_point.value}",
                evidence_strength=evidence_strength,
                metadata={
                    "subject": event.subject.value,
                    "problem_type": event.problem_type,
                    "solve_id": event.solve_id,
                },
            )

    async def _update_ability_dimensions(self, event: ScienceSolveCompletedEvent):
        """更新学科能力维度"""
        # 理科解题主要影响的能力维度
        dimension_map = {
            Subject.MATH: ["logical_reasoning", "calculation", "spatial_reasoning"],
            Subject.PHYSICS: ["logical_reasoning", "calculation", "experiment_analysis"],
            Subject.CHEMISTRY: ["logical_reasoning", "calculation", "experiment_analysis"],
            Subject.BIOLOGY: ["logical_reasoning", "reading_comprehension", "experiment_analysis"],
        }

        dimensions = dimension_map.get(event.subject, ["logical_reasoning"])
        for dim in dimensions:
            await self._dimension_service.incremental_update(
                user_id=event.user_id,
                subject=event.subject,
                dimension=dim,
                score_delta=0.05 * (1.0 if event.fully_viewed else 0.3),
            )

    async def _update_mistake_record(self, event: ScienceSolveCompletedEvent):
        """更新错题订正记录（仅错题重练入口）"""
        await self._mistake_service.update_review_record(
            mistake_id=event.mistake_id,
            review_type="solve_view",
            understanding_score=event.understanding_feedback,  # 用户自评（如有）
            knowledge_points=event.knowledge_point_ids,
        )
```

## 7. 错误处理与降级策略

### 7.1 错误分类与处理

| 阶段 | 错误类型 | 错误码 | 处理策略 | 用户提示 |
|------|----------|--------|----------|----------|
| P1 | 入口参数异常 | INVALID_ENTRY | 返回400错误 | "请求参数异常" |
| P2 | 额度不足 | QUOTA_EXCEEDED | 拦截，引导升级 | "今日解题次数已用完" |
| P3 | 学科识别失败 | CLASSIFY_FAIL | 使用用户上下文学科 | 无感降级 |
| P3 | 条件结构化失败 | STRUCTURE_FAIL | 原始文本直接送 AI | 无感降级 |
| P3 | 模型匹配失败 | MODEL_MATCH_FAIL | 使用学科通用模型 | 无感降级 |
| P4 | AI首token超时(>5s) | AI_FIRST_TOKEN_TIMEOUT | 切换备选模型重试 | "正在换一种方式思考..." |
| P4 | AI全部不可用 | AI_ALL_DOWN | 返回缓存或提示稍后 | "AI服务繁忙，请稍后再试" |
| P4 | AI输出格式错误 | AI_FORMAT_ERROR | 后处理修复或重试 | "正在优化解析..." |
| P5 | 数值验算不通过 | VALIDATION_CALC_ERROR | 多模型复核 | "让我重新计算一下..." |
| P5 | 单位不一致 | VALIDATION_UNIT_ERROR | 尝试自动修正 | 无感降级 + 警告标注 |
| P6 | SSE连接断开 | SSE_DISCONNECT | 客户端自动重连 | 无感重连 |
| P7 | 异步处理失败 | ASYNC_FAIL | 重试队列 | 无感 |

### 7.2 降级矩阵

```
Level 0: 完整理科解题管线（学科识别+结构化+模型匹配+推理增强模型+校验+答案管控）
Level 1: 跳过条件结构化（原始文本直送AI，跳过数值验算）
Level 2: 跳过模型匹配（使用通用Prompt，不区分题型）
Level 3: 降级模型（推理增强 → 通用模型，降低成本）
Level 4: 缓存优先（仅返回题库已有答案，不触发AI）
Level 5: 服务降级（提示稍后重试，返回基础提示）
```

```python
class ScienceSolveDegradationChain:
    """理科解题降级链"""

    async def execute_with_fallback(
        self,
        request: ScienceSolveRequest,
    ) -> AsyncIterator[SSEEvent]:
        """带降级的执行"""
        try:
            async for e in self._full_pipeline(request):      # Level 0
                yield e
        except (StructureError, ModelMatchError):
            async for e in self._skip_structure_pipeline(request):  # Level 1/2
                yield e
        except AIModelError:
            try:
                async for e in self._fallback_model_pipeline(request):  # Level 3
                    yield e
            except AIAllDownError:
                cached = await self._try_cache_only(request)    # Level 4
                if cached:
                    async for e in self._stream_cached(cached):
                        yield e
                else:
                    yield SSEEvent(event="error", data={       # Level 5
                        "code": "SERVICE_BUSY",
                        "message": "AI服务繁忙，请稍后再试",
                    })
```
