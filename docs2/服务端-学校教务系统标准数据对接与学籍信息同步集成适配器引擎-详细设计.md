# 服务端-学校教务系统标准数据对接与学籍信息同步集成适配器引擎-详细设计

## 1. 概述

### 1.1 模块定位

本模块是 PrimeTop 平台 V2.0 阶段 B 端教育合作场景的核心基础设施，负责与各类学校教务管理系统（SIS, Student Information System）建立标准化数据对接通道，实现学校侧学生学籍信息、班级组织架构、课程安排、考试成绩等关键数据的自动化同步与持续更新。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 标准化接入 | 提供统一的数据交换协议和标准 API 层，屏蔽不同 SIS 厂商差异 |
| 多厂商兼容 | 内置适配器支持国内主流教务系统（正方、强智、青果、金智等），支持自定义扩展 |
| 实时+批量双模 | 关键数据变更实时推送，历史数据批量同步，兼顾时效性与吞吐量 |
| 隐私合规 | 严格遵循《个人信息保护法》《未成年人保护法》，数据最小化采集，明示授权 |
| 故障隔离 | 单一学校同步异常不影响其他学校，支持断点续传和自动重试 |
| 可观测 | 全链路同步状态可视，异常告警，对账审计 |

### 1.3 适用范围

- PrimeTop 与中小学/教培机构的系统对接
- 区域教育平台统一数据归集
- 教师端班级数据自动初始化
- 学情报告数据源补充
- B 端合作客户的数据导入导出

### 1.4 名词约定

| 术语 | 含义 |
| --- | --- |
| SIS | 学校信息管理系统（Student Information System），如正方教务、强智教务等 |
| 租户（Tenant） | 接入 PrimeTop 的一所学校或一个教育机构，对应一个 organization |
| 数据源（DataSource） | 一个租户下可能存在多个 SIS 数据源（如初中部用正方、高中部用强智） |
| 同步任务（SyncJob） | 一次数据同步操作的逻辑单元 |
| 适配器（Adapter） | 针对特定 SIS 厂商的数据格式转换与协议适配组件 |
| 实体映射（EntityMapping） | 外部 SIS 实体与 PrimeTop 内部实体的字段映射关系 |

## 2. 国内主流教务系统调研与对接策略

### 2.1 主流 SIS 厂商概览

| 厂商 | 市场覆盖 | 对接方式 | 数据格式 | 认证方式 |
| --- | --- | --- | --- | --- |
| 正方软件 | 高校/部分高中 | REST API / 数据库视图 | JSON / 表格视图 | AppKey + Secret |
| 强智科技 | 高校/中学 | WebService / REST API | XML / JSON | Token |
| 青果教育 | 中小学 | 数据库直连 / 文件导出 | SQL Server / Excel | DB 账号 |
| 金智教育 | 高校/区域平台 | REST API / OAuth2 | JSON | OAuth2 Client Credentials |
| 杭州正方（中小学版） | 中小学 | REST API | JSON | API Key |
| 天臣电子 | 中小学 | 数据库直连 / API | MySQL / JSON | DB 账号 / Token |
| 自研/其他 | 各类学校 | 文件导出(Excel/CSV) 或定制 API | 多种 | 多种 |

### 2.2 对接策略矩阵

| SIS 类型 | 推荐对接方式 | 同步模式 | 安全要求 |
| --- | --- | --- | --- |
| 有标准 REST API | API 拉取 + Webhook 推送 | 实时增量 + 定时全量 | HTTPS + Token |
| 仅数据库视图 | 只读数据库账号定时拉取 | 定时增量 | VPN / 专线 + 只读账号 |
| 仅文件导出 | SFTP / 对象存储定时上传 | 批量全量 | SFTP 加密传输 |
| 无系统/纸质 | 运营人员手动录入 / Excel 导入 | 人工触发 | 后台权限控制 |
| 区域教育平台 | 统一数据交换标准协议 | 实时推送 | 政务网 / HTTPS + 证书 |

### 3.2 核心组件职责

| 组件 | 职责 |
| --- | --- |
| AdapterManager | 管理所有适配器实例，按租户配置选择适配器 |
| XxxAdapter | 特定 SIS 的数据获取与格式转换实现 |
| DataSyncEngine | 同步流程编排，调度具体同步任务 |
| EntityMapper | 将外部数据映射为内部标准实体 |
| ConflictResolver | 处理外部数据与内部数据的冲突 |
| SyncCheckpointManager | 记录同步进度，支持断点续传 |
| DataValidator | 校验数据完整性与合法性 |
| SyncAuditLogger | 记录同步操作审计日志 |
| RateLimiter | 控制对 SIS 的请求频率，防止过载 |

```java
            if (resp.getStatusCode().is2xxSuccessful()) {
                return HealthCheckResult.healthy("正方教务连接正常");

            SisDataSourceConfig config,

        rateLimiter.acquire(); // 限流
        
        // 构建请求
        String url = config.getApiBaseUrl() + "/api/students";
        MultiValueMap<String, String> params = new LinkedMultiValueMap<>();
        params.add("page", String.valueOf(cursor.getPageNo()));
        params.add("size", String.valueOf(DEFAULT_PAGE_SIZE));
        params.add("schoolYear", filter.getAcademicYear());
        
        if (filter.getGradeLevel() != null) {
            params.add("grade", String.valueOf(filter.getGradeLevel()));
        }
        if (filter.getClassCode() != null) {
            params.add("classCode", filter.getClassCode());
        }
        if (filter.getUpdatedAfter() != null) {
            params.add("updatedAfter", 
                filter.getUpdatedAfter().format(DateTimeFormatter.ISO_DATE_TIME));
        }
        
        HttpHeaders headers = buildAuthHeaders(config);
        HttpEntity<Void> entity = new HttpEntity<>(headers);
        
        ResponseEntity<ZhengfangPageResp> resp = restTemplate.exchange(

            HttpMethod.GET, entity,

            ? cursor.nextPage()
            : null;

            .total(body.getData().getTotal())
```

```java
            throw new SisSyncException("FILE_PARSE_ERROR", "文件解析失败: " + e.getMessage(), e);
        }

    private String detectTemplateType(Sheet sheet) {
        Row headerRow = sheet.getRow(0);
        if (headerRow == null) return "standard";
        
        String firstCell = headerRow.getCell(0).getStringCellValue();
        if ("学号".equals(firstCell)) return "standard";
        if ("xh".equals(firstCell)) return "zhengfang_export";
        if ("student_no".equals(firstCell)) return "custom_v1";
        return "standard";

        int pageSize = cursor != null ? cursor.getPageSize() : 5000;

                // 记录错误但继续处理其他行
            }
        }
        
        return students;
    }
```

```java
    RUNNING(1, "运行中"),
    SUCCESS(2, "成功"),
    PARTIAL_FAILED(3, "部分失败"),
    FAILED(4, "失败"),

    private final int code;
    private final String desc;
    // ...

/**
 * 同步任务状态机 - 定义合法状态流转
 */
public class SyncJobStateMachine {
    
    private static final Map<SyncJobStatus, Set<SyncJobStatus>> TRANSITIONS = Map.of(
        SyncJobStatus.PENDING, Set.of(SyncJobStatus.RUNNING, SyncJobStatus.CANCELLED),
        SyncJobStatus.RUNNING, Set.of(SyncJobStatus.SUCCESS, SyncJobStatus.PARTIAL_FAILED, 
                                       SyncJobStatus.FAILED, SyncJobStatus.CANCELLED),
        SyncJobStatus.FAILED, Set.of(SyncJobStatus.PENDING), // 允许失败后重试
        SyncJobStatus.PARTIAL_FAILED, Set.of(SyncJobStatus.PENDING),
        SyncJobStatus.SUCCESS, Set.of(), // 终态
        SyncJobStatus.CANCELLED, Set.of() // 终态
    );
    
    public static void validateTransition(SyncJobStatus from, SyncJobStatus to) {
        Set<SyncJobStatus> allowed = TRANSITIONS.getOrDefault(from, Set.of());
        if (!allowed.contains(to)) {
            throw new IllegalStateTransitionException(
                String.format("非法状态流转: %s → %s", from, to)
            );
        }
    }
}
```

### 6.2 增量同步核心算法

```java
/**
 * 数据同步引擎核心实现
 */
@Slf4j
@Service
public class DataSyncEngine {
    
    @Autowired private SisAdapterFactory adapterFactory;
    @Autowired private EntityMapper entityMapper;
    @Autowired private ConflictResolver conflictResolver;
    @Autowired private SyncCheckpointManager checkpointManager;
    @Autowired private DataValidator dataValidator;
    @Autowired private SisSyncJobMapper jobMapper;
    @Autowired private SisSyncLogMapper logMapper;
    @Autowired private SisExternalEntityMapper entityMappingMapper;
    @Autowired private DomainEventPublisher eventPublisher;
    
    /**
     * 执行同步任务
     */
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public SyncJobResult execute(SisSyncJob job, SisDataSource dataSource) {
        long startTime = System.currentTimeMillis();
        
        try {
            // 1. 状态流转
            updateJobStatus(job, SyncJobStatus.RUNNING);
            
            // 2. 获取适配器
            SisAdapter adapter = adapterFactory.getAdapter(dataSource.getAdapterType());
            
            // 3. 构建过滤条件
            SyncFilter filter = buildSyncFilter(job, dataSource);
            
            // 4. 获取断点（如果有）
            SyncCursor cursor = checkpointManager.getCheckpoint(job);
            
            // 5. 按实体类型逐个同步
            SyncJobResult result = SyncJobResult.init();
            
            for (String entityType : job.getEntityTypesList()) {
                EntitySyncResult entityResult = syncEntity(
                    adapter, dataSource, filter, cursor, entityType
                );
                result.merge(entityResult);
            }
            
            // 6. 更新任务状态
            result.setDurationMs(System.currentTimeMillis() - startTime);
            SyncJobStatus finalStatus = determineFinalStatus(result);
            updateJobResult(job, result, finalStatus);
            
            // 7. 发布领域事件
            publishSyncCompletedEvent(job, result);
            
            return result;
            
        } catch (Exception e) {
            log.error("同步任务执行失败, jobId={}", job.getId(), e);
            updateJobStatus(job, SyncJobStatus.FAILED, e.getMessage());
            throw new SisSyncException("SYNC_EXECUTION_ERROR", "同步执行失败", e);
        }
    }
    
    /**
     * 同步单个实体类型
     */
    private EntitySyncResult syncEntity(
            SisAdapter adapter, 
            SisDataSource dataSource,
            SyncFilter filter, 
            SyncCursor cursor, 
            String entityType) {
        
        EntitySyncResult result = EntitySyncResult.init(entityType);
        int pageNum = cursor != null ? cursor.getPageNo() : 1;
        boolean hasMore = true;
        
        while (hasMore) {
            // 1. 拉取数据
            PageResult<? extends ExternalEntity> page;
            switch (entityType) {
                case "STUDENT":
                    page = adapter.fetchStudents(dataSource.getConfig(), filter, 
                              SyncCursor.of(pageNum));
                    break;
                case "TEACHER":
                    page = adapter.fetchTeachers(dataSource.getConfig(), filter, 
                              SyncCursor.of(pageNum));
                    break;
                case "CLASS":
                    page = adapter.fetchClasses(dataSource.getConfig(), filter, 
                              SyncCursor.of(pageNum));
                    break;
                case "COURSE":
                    page = adapter.fetchCourses(dataSource.getConfig(), filter, 
                              SyncCursor.of(pageNum));
                    break;
                case "EXAM_SCORE":
                    page = adapter.fetchExamScores(dataSource.getConfig(), filter, 
                              SyncCursor.of(pageNum));
                    break;
                default:
                    throw new IllegalArgumentException("不支持的实体类型: " + entityType);
            }
            
            // 2. 逐条处理
            for (ExternalEntity externalEntity : page.getData()) {
                try {
                    EntitySyncOutcome outcome = processEntity(
                        dataSource.getId(), entityType, externalEntity
                    );
                    result.record(outcome);
                    
                    // 记录明细日志
                    logSyncDetail(outcome);
                    
                } catch (Exception e) {
                    log.error("实体处理失败: type={}, externalId={}", 
                        entityType, externalEntity.getExternalId(), e);
                    result.recordError(externalEntity.getExternalId(), e);
                }
            }
            
            // 3. 保存断点
            checkpointManager.saveCheckpoint(
                dataSource.getId(), entityType, pageNum, page.getNextCursor()
            );
            
            // 4. 分页控制
            hasMore = page.isHasMore();
            pageNum++;
            
            // 5. 批量提交（每页一次）
            // 已通过 @Transactional 在外层控制
        }
        
        return result;
    }
    
    /**
     * 处理单个实体的完整流程：匹配 → 变更检测 → 转换 → 冲突解决 → 写入
     */
    private EntitySyncOutcome processEntity(
            Long dataSourceId, 
            String entityType, 
            ExternalEntity externalEntity) {
        
        String dataHash = DigestUtils.md5Hex(
            JSON.toJSONString(externalEntity)
        );
        
        // 1. 查找已有映射
        SisExternalEntity existingMapping = entityMappingMapper.findByExternalId(
            dataSourceId, entityType, externalEntity.getExternalId()
        );
        
        // 2. 判断操作类型
        if (existingMapping == null) {
            // 新实体 → CREATE
            return handleCreate(dataSourceId, entityType, externalEntity, dataHash);
        }
        
        // 3. 变更检测
        if (dataHash.equals(existingMapping.getDataHash())) {
            // 数据未变更 → SKIP
            return EntitySyncOutcome.skipped(
                entityType, externalEntity.getExternalId(), 
                existingMapping.getInternalId()
            );
        }
        
        // 4. 数据变更 → UPDATE
        return handleUpdate(existingMapping, externalEntity, dataHash);
    }
    
    /**
     * 处理新实体创建
     */
    private EntitySyncOutcome handleCreate(
            Long dataSourceId,
            String entityType, 
            ExternalEntity externalEntity,
            String dataHash) {
        
        // 1. 数据校验
        ValidationResult validation = dataValidator.validate(externalEntity);
        if (!validation.isValid()) {
            return EntitySyncOutcome.error(
                entityType, externalEntity.getExternalId(),
                "VALIDATION_ERROR", validation.getErrors()
            );
        }
        
        // 2. 尝试匹配已有内部实体（通过学号/工号/姓名+生日等）
        Long internalId = entityMapper.tryMatchExisting(
            dataSourceId, entityType, externalEntity
        );
        
        if (internalId != null) {
            // 匹配到已有实体 → 更新映射关系
            entityMappingMapper.insertMapping(
                dataSourceId, entityType, 
                externalEntity.getExternalId(), 
                internalId, dataHash, 
                externalEntity, true
            );
            return EntitySyncOutcome.linked(entityType, 
                externalEntity.getExternalId(), internalId);
        }
        
        // 3. 创建新的内部实体
        Long newInternalId = entityMapper.createInternalEntity(
            dataSourceId, entityType, externalEntity
        );
        
        // 4. 记录映射
        entityMappingMapper.insertMapping(
            dataSourceId, entityType,
            externalEntity.getExternalId(),
            newInternalId, dataHash,
            externalEntity, false
        );
        
        // 5. 发布实体创建事件
        eventPublisher.publish(new SisEntityCreatedEvent(
            dataSourceId, entityType, 
            externalEntity.getExternalId(), newInternalId
        ));
        
        return EntitySyncOutcome.created(entityType, 
            externalEntity.getExternalId(), newInternalId);
    }
    
    /**
     * 处理实体更新
     */
    private EntitySyncOutcome handleUpdate(
            SisExternalEntity mapping,
            ExternalEntity externalEntity,
            String newDataHash) {
        
        // 1. 数据校验
        ValidationResult validation = dataValidator.validate(externalEntity);
        if (!validation.isValid()) {
            return EntitySyncOutcome.error(
                mapping.getEntityType(), 
                externalEntity.getExternalId(),
                "VALIDATION_ERROR", validation.getErrors()
            );
        }
        
        // 2. 获取内部当前数据
        Object internalCurrent = entityMapper.getInternalEntity(
            mapping.getInternalId(), mapping.getEntityType()
        );
        
        // 3. 冲突检测
        ConflictResult conflict = conflictResolver.detect(
            internalCurrent, externalEntity, mapping
        );
        
        // 4. 冲突处理
        if (conflict.hasConflict()) {
            ConflictResolution resolution = conflictResolver.resolve(
                conflict, ConflictPolicy.valueOf(mapping.getConflictPolicy())
            );
            
            if (resolution == ConflictResolution.SKIP) {
                return EntitySyncOutcome.conflictSkipped(
                    mapping.getEntityType(),
                    externalEntity.getExternalId(),
                    conflict.getDescription()
                );
            }
            // 否则继续执行更新
        }
        
        // 5. 执行更新
        entityMapper.updateInternalEntity(
            mapping.getInternalId(), 
            mapping.getEntityType(), 
            externalEntity
        );
        
        // 6. 更新映射哈希
        entityMappingMapper.updateHash(
            mapping.getId(), newDataHash, externalEntity
        );
        
        // 7. 发布更新事件
        eventPublisher.publish(new SisEntityUpdatedEvent(
            mapping.getDataSourceId(), 
            mapping.getEntityType(),
            externalEntity.getExternalId(),
            mapping.getInternalId()
        ));
        
        return EntitySyncOutcome.updated(
            mapping.getEntityType(),
            externalEntity.getExternalId(),
            mapping.getInternalId()
        );
    }
    
    /**
     * 构建同步过滤条件
     */
    private SyncFilter buildSyncFilter(SisSyncJob job, SisDataSource dataSource) {
        SyncFilter filter = new SyncFilter();
        
        // 增量同步：使用上次同步时间
        if (job.getJobType().equals("INCREMENTAL")) {
            filter.setUpdatedAfter(dataSource.getLastSyncTime());
        }
        
        filter.setAcademicYear(getCurrentAcademicYear());
        filter.setSemester(getCurrentSemester());
        
        return filter;
    }
    
    /**
     * 根据结果决定最终状态
     */
    private SyncJobStatus determineFinalStatus(SyncJobResult result) {
        if (result.getFailedCount() == 0) {
            return SyncJobStatus.SUCCESS;
        }
        if (result.getSuccessCount() > 0) {
            return SyncJobStatus.PARTIAL_FAILED;
        }
        return SyncJobStatus.FAILED;
    }
}
```

### 6.3 变更检测策略

```java
/**
 * 变更检测器 - 判断外部数据是否发生变化
 */
@Component
public class ChangeDetector {
    
    /**
     * 策略1：哈希比对（默认）
     * 对完整数据JSON计算MD5，快速判断是否变更
     */
    public boolean hasChangedByHash(String oldHash, Object newData) {
        String newHash = DigestUtils.md5Hex(JSON.toJSONString(newData));
        return !oldHash.equals(newHash);
    }
    
    /**
     * 策略2：时间戳比对
     * 适用于 SIS 提供 updatedAt 字段的场景
     */
    public boolean hasChangedByTimestamp(
            LocalDateTime lastSynced, 
            LocalDateTime entityUpdated) {
        return entityUpdated != null && entityUpdated.isAfter(lastSynced);
    }
    
    /**
     * 策略3：版本号比对
     * 适用于 SIS 提供数据版本号的场景
     */
    public boolean hasChangedByVersion(Long oldVersion, Long newVersion) {
        return !Objects.equals(oldVersion, newVersion);
    }
    
    /**
     * 策略4：字段级 Diff
     * 精确到字段级别的变更检测，支持增量字段更新
     */
    public FieldDiffResult fieldLevelDiff(Object oldData, Object newData) {
        Map<String, Object> oldMap = convertToMap(oldData);
        Map<String, Object> newMap = convertToMap(newData);
        
        Map<String, Object> changed = new LinkedHashMap<>();
        Map<String, Object> added = new LinkedHashMap<>();
        Map<String, Object> removed = new LinkedHashMap<>();
        
        Set<String> allKeys = new HashSet<>();
        allKeys.addAll(oldMap.keySet());
        allKeys.addAll(newMap.keySet());
        
        for (String key : allKeys) {
            Object oldVal = oldMap.get(key);
            Object newVal = newMap.get(key);
            
            if (oldVal == null && newVal != null) {
                added.put(key, newVal);
            } else if (oldVal != null && newVal == null) {
                removed.put(key, oldVal);
            } else if (oldVal != null && !oldVal.equals(newVal)) {
                changed.put(key, newVal);
            }
        }
        
        return new FieldDiffResult(changed, added, removed);
    }
}
```

### 6.4 冲突解决策略

```java
/**
 * 冲突解决器
 * 当外部 SIS 数据与平台内部数据不一致时，按策略决定如何处理
 */
@Component
public class ConflictResolver {
    
    /**
     * 检测冲突
     */
    public ConflictResult detect(
            Object internalCurrent, 
            ExternalEntity externalNew,
            SisExternalEntity mapping) {
        
        List<FieldConflict> conflicts = new ArrayList<>();
        
        if (internalCurrent instanceof Student) {
            Student internal = (Student) internalCurrent;
            ExternalStudent external = (ExternalStudent) externalNew;
            
            // 检测关键字段冲突
            if (internal.getGradeLevel() != null && 
                !internal.getGradeLevel().equals(external.getGradeLevel())) {
                conflicts.add(new FieldConflict("gradeLevel", 
                    internal.getGradeLevel(), external.getGradeLevel(),
                    ConflictSource.MANUAL_EDIT));
            }
            
            if (internal.getClassId() != null) {
                // 检查内部班级是否被手动调整过
                boolean manuallyAdjusted = isManuallyAdjusted(
                    internal.getId(), "class_id"
                );
                if (manuallyAdjusted) {
                    conflicts.add(new FieldConflict("classId",
                        internal.getClassId(), external.getClassCode(),
                        ConflictSource.MANUAL_EDIT));
                }
            }
        }
        
        return new ConflictResult(conflicts);
    }
    
    /**
     * 解决冲突
     */
    public ConflictResolution resolve(ConflictResult conflict, ConflictPolicy policy) {
        switch (policy) {
            case EXTERNAL_WINS:
                // 外部数据优先，直接覆盖
                return ConflictResolution.PROCEED;
                
            case INTERNAL_WINS:
                // 内部数据优先，跳过更新
                return ConflictResolution.SKIP;
                
            case LATEST_WINS:
                // 时间戳新的优先
                return resolveByTimestamp(conflict);
                
            case MANUAL_REVIEW:
                // 需要人工审核
                createManualReviewTask(conflict);
                return ConflictResolution.DEFERRED;
                
            case FIELD_LEVEL_MERGE:
                // 字段级合并（非冲突字段正常更新）
                return ConflictResolution.PROCEED_WITH_PARTIAL;
                
            default:
                return ConflictResolution.SKIP;
        }
    }
}

/**
 * 冲突处理策略枚举
 */
public enum ConflictPolicy {
    EXTERNAL_WINS,      // 外部优先（默认）
    INTERNAL_WINS,      // 内部优先
    LATEST_WINS,        // 最新时间戳优先
    MANUAL_REVIEW,      // 人工审核
    FIELD_LEVEL_MERGE   // 字段级合并
}
```

## 8. 断点续传机制

### 8.1 设计思路

大规模数据同步过程中可能因网络中断、SIS 限流、系统重启等原因中断。断点续传确保同步任务能从中断点恢复，避免从头重来。

### 8.2 实现代码

```java
/**
 * 断点续传管理器
 */
@Component
public class SyncCheckpointManager {
    
    @Autowired private RedisTemplate<String, Object> redisTemplate;
    @Autowired private SisSyncJobMapper jobMapper;
    
    private static final String CHECKPOINT_KEY = "sis:sync:checkpoint:%d:%s";
    private static final Duration CHECKPOINT_TTL = Duration.ofHours(24);
    
    /**
     * 保存断点
     */
    public void saveCheckpoint(
            Long dataSourceId, 
            String entityType,
            int pageNo, 
            SyncCursor cursor) {
        
        String key = String.format(CHECKPOINT_KEY, dataSourceId, entityType);
        
        CheckpointInfo info = CheckpointInfo.builder()
            .dataSourceId(dataSourceId)
            .entityType(entityType)
            .pageNo(pageNo)
            .cursor(cursor)
            .savedAt(LocalDateTime.now())
            .build();
        
        redisTemplate.opsForValue().set(key, info, CHECKPOINT_TTL);
    }
    
    /**
     * 获取断点
     */
    public SyncCursor getCheckpoint(SisSyncJob job) {
        // 优先从任务记录中恢复
        if (job.getCheckpointData() != null) {
            return SyncCursor.fromJson(job.getCheckpointData());
        }
        return null; // 全新任务
    }
    
    /**
     * 清除断点
     */
    public void clearCheckpoint(Long dataSourceId, String entityType) {
        String key = String.format(CHECKPOINT_KEY, dataSourceId, entityType);
        redisTemplate.delete(key);
    }
    
    /**
     * 恢复中断的任务
     */
    public void resumeInterruptedJob(Long dataSourceId) {
        // 查找状态为 RUNNING 但心跳超时的任务
        SisSyncJob interrupted = jobMapper.findInterruptedJob(
            dataSourceId, 
            LocalDateTime.now().minusMinutes(10)
        );
        
        if (interrupted != null) {
            // 创建恢复任务，从断点继续
            SisSyncJob resumeJob = SisSyncJob.builder()
                .dataSourceId(dataSourceId)
                .jobType("RESUME")
                .entityTypes(interrupted.getEntityTypes())
                .resumeFrom(interrupted.getResumeFrom())
                .checkpointData(interrupted.getCheckpointData())
                .triggeredBy("AUTO_RESUME")
                .build();
            
            jobMapper.insert(resumeJob);
            
            log.info("自动恢复中断任务: 原任务={}, 新任务={}", 
                interrupted.getId(), resumeJob.getId());
        }
    }
}
```

## 9. 对账引擎

### 9.1 设计目标

定期核对外部 SIS 数据与平台内部数据的一致性，发现差异并生成对账报告。

### 9.2 实现

```java
/**
 * 数据对账引擎
 */
@Slf4j
@Service
public class SisReconciliationEngine {
    
    @Autowired private SisAdapterFactory adapterFactory;
    @Autowired private SisExternalEntityMapper mappingMapper;
    @Autowired private EntityMapper entityMapper;
    
    /**
     * 执行对账
     */
    public ReconciliationReport reconcile(
            Long dataSourceId, 
            List<String> entityTypes) {
        
        ReconciliationReport report = new ReconciliationReport(dataSourceId);
        
        for (String entityType : entityTypes) {
            EntityReconciliation entityReport = reconcileEntity(
                dataSourceId, entityType
            );
            report.addEntityReport(entityType, entityReport);
        }
        
        // 生成差异报告
        if (report.hasDiscrepancies()) {
            report.generateDiscrepancyFile();
            alertService.sendReconciliationAlert(report);
        }
        
        return report;
    }
    
    private EntityReconciliation reconcileEntity(
            Long dataSourceId, 
            String entityType) {
        
        // 1. 获取外部实体总数
        int externalCount = adapterFactory
            .getAdapter(getAdapterType(dataSourceId))
            .countEntities(dataSourceId, entityType);
        
        // 2. 获取内部映射总数
        int internalCount = mappingMapper.countByDataSourceAndType(
            dataSourceId, entityType
        );
        
        // 3. 差异检测
        int countDiff = externalCount - internalCount;
        
        // 4. 数据一致性抽样校验（随机抽取5%）
        List<SisExternalEntity> samples = mappingMapper.randomSample(
            dataSourceId, entityType, 
            Math.max(10, internalCount / 20)
        );
        
        int consistencyPassed = 0;
        int consistencyFailed = 0;
        List<DataDiscrepancy> discrepancies = new ArrayList<>();
        
        for (SisExternalEntity mapping : samples) {
            try {
                ExternalEntity external = fetchSingleEntity(
                    dataSourceId, entityType, mapping.getExternalId()
                );
                Object internal = entityMapper.getInternalEntity(
                    mapping.getInternalId(), entityType
                );
                
                if (isConsistent(external, internal)) {
                    consistencyPassed++;
                } else {
                    consistencyFailed++;
                    discrepancies.add(buildDiscrepancy(mapping, external, internal));
                }
            } catch (Exception e) {
                consistencyFailed++;
                log.warn("对账抽样失败: externalId={}", mapping.getExternalId(), e);
            }
        }
        
        return EntityReconciliation.builder()
            .externalCount(externalCount)
            .internalCount(internalCount)
            .countDifference(countDiff)
            .sampleSize(consistencyPassed + consistencyFailed)
            .consistencyPassed(consistencyPassed)
            .consistencyFailed(consistencyFailed)
            .discrepancies(discrepancies)
            .build();
    }
    
    /**
     * 数据一致性校验（字段级别）
     */
    private boolean isConsistent(ExternalEntity external, Object internal) {
        if (internal instanceof Student && external instanceof ExternalStudent) {
            return isStudentConsistent((ExternalStudent) external, (Student) internal);
        }
        // ... 其他实体类型
        return true;
    }
    
    private boolean isStudentConsistent(ExternalStudent ext, Student stu) {
        if (!Objects.equals(ext.getName(), stu.getName())) return false;
        if (!Objects.equals(ext.getGradeLevel(), stu.getGradeLevel())) return false;
        if (!Objects.equals(ext.getClassCode(), 
                stu.getClassCode())) return false;
        if (!Objects.equals(ext.getStudentStatus(), 
                mapToInternalStatus(stu.getStatus()))) return false;
        return true;
    }
}
```

## 10. 定时调度设计

### 10.1 调度策略

| 同步类型 | 频率 | 触发方式 | 说明 |
| --- | --- | --- | --- |
| 全量同步 | 每月1次 | Cron: `0 0 3 1 * ?` | 每月1日凌晨3点执行 |
| 增量同步 | 每小时 | FixedRate: 3600s | 拉取变更数据 |
| 实时推送 | 实时 | Webhook | SIS 主动推送（如支持） |
| 对账校验 | 每天1次 | Cron: `0 0 5 * * ?` | 每日凌晨5点核对 |

### 10.2 调度实现

```java
/**
 * 同步任务调度器
 */
@Slf4j
@Component
public class SisSyncScheduler {
    
    @Autowired private SisDataSourceMapper dataSourceMapper;
    @Autowired private DataSyncEngine syncEngine;
    @Autowired private SyncCheckpointManager checkpointManager;
    @Autowired private SisReconciliationEngine reconciliationEngine;
    
    /**
     * 定时增量同步（每小时）
     */
    @Scheduled(fixedDelay = 3600000, initialDelay = 60000)
    public void scheduledIncrementalSync() {
        List<SisDataSource> activeSources = dataSourceMapper.findActiveSources("INCREMENTAL");
        
        for (SisDataSource source : activeSources) {
            try {
                // 每个数据源串行执行，避免并发问题
                SisSyncJob job = createJob(source, "INCREMENTAL", 
                    List.of("STUDENT", "TEACHER", "CLASS"));
                syncEngine.execute(job, source);
                
                // 更新最后同步时间
                dataSourceMapper.updateLastSyncTime(source.getId(), LocalDateTime.now());
                
            } catch (Exception e) {
                log.error("增量同步失败: dataSourceId={}", source.getId(), e);
            }
            
            // 数据源间间隔，避免同时请求
            sleep(5000);
        }
    }
    
    /**
     * 定时全量同步（每月1日）
     */
    @Scheduled(cron = "0 0 3 1 * ?")
    public void scheduledFullSync() {
        List<SisDataSource> activeSources = dataSourceMapper.findActiveSources("FULL");
        
        for (SisDataSource source : activeSources) {
            try {
                SisSyncJob job = createJob(source, "FULL",
                    List.of("STUDENT", "TEACHER", "CLASS", "COURSE", "EXAM_SCORE"));
                syncEngine.execute(job, source);
            } catch (Exception e) {
                log.error("全量同步失败: dataSourceId={}", source.getId(), e);
            }
        }
    }
    
    /**
     * 中断任务恢复检查（每5分钟）
     */
    @Scheduled(fixedDelay = 300000)
    public void checkInterruptedJobs() {
        List<SisDataSource> sources = dataSourceMapper.findAll();
        
        for (SisDataSource source : sources) {
            checkpointManager.resumeInterruptedJob(source.getId());
        }
    }
    
    /**
```

```java
     */
    public String maskPhone(String phone) {
        if (StringUtils.isBlank(phone) || phone.length() < 7) return "***";
        return phone.substring(0, 3) + "****" + phone.substring(phone.length() - 4);
    }
    
    /**
```

### 12.2 错误处理策略

```java
/**
 * 同步错误处理器
 */
@Component
@Slf4j
public class SisErrorHandler {
    
    /**
     * 处理单条记录错误
     */
    public void handleRecordError(
            SisSyncJob job, 
            ExternalEntity entity, 
            Exception error) {
        
        SisErrorCode errorCode = classifyError(error);
        
        // 记录错误日志
        SisSyncLog errorLog = SisSyncLog.builder()
            .jobId(job.getId())
            .dataSourceId(job.getDataSourceId())
            .entityType(entity.getEntityType())
            .externalId(entity.getExternalId())
            .action("SYNC")
            .result(0) // 失败
            .errorCode(errorCode.name())
            .errorMessage(error.getMessage())
            .dataAfter(JSON.toJSONString(entity))
            .build();
        logMapper.insert(errorLog);
        
        // 可恢复错误 → 加入重试队列
        if (errorCode.isRetryable()) {
            retryQueueManager.enqueue(job.getId(), entity, errorCode, error);
        }
        
        // 严重错误 → 告警
        if (errorCode.getSeverity() == Severity.CRITICAL) {
            alertService.sendCriticalAlert(
                "SIS同步严重错误",
                String.format("jobId=%d, entity=%s, externalId=%s, error=%s",
                    job.getId(), entity.getEntityType(), 
                    entity.getExternalId(), error.getMessage())
            );
        }
    }
    
    /**
     * 错误分类
     */
    private SisErrorCode classifyError(Exception e) {
        if (e instanceof SocketTimeoutException) {
            return SisErrorCode.SIS_CONNECTION_TIMEOUT;
        }
        if (e instanceof HttpServerErrorException) {
            int status = ((HttpServerErrorException) e).getStatusCode().value();
            if (status == 429) return SisErrorCode.SIS_RATE_LIMITED;
            if (status >= 500) return SisErrorCode.SIS_CONNECTION_TIMEOUT;
        }
        if (e instanceof JsonParseException) {
            return SisErrorCode.SIS_DATA_FORMAT_ERROR;
        }
        if (e instanceof ConstraintViolationException) {
            return SisErrorCode.SIS_VALIDATION_ERROR;
        }
        return SisErrorCode.UNKNOWN;
    }
}
```

```java
/**
 * 分布式锁 - 确保同一数据源同时只有一个同步实例
 */
@Component
public class SisSyncLock {
    
    @Autowired private RedisTemplate<String, String> redisTemplate;
    
    private static final String LOCK_KEY = "sis:sync:lock:%d";
    private static final Duration LOCK_TTL = Duration.ofMinutes(30);
    
    public boolean tryLock(Long dataSourceId, String instanceId) {
        String key = String.format(LOCK_KEY, dataSourceId);
        Boolean acquired = redisTemplate.opsForValue()
            .setIfAbsent(key, instanceId, LOCK_TTL);
        return Boolean.TRUE.equals(acquired);
    }
    
    public void unlock(Long dataSourceId, String instanceId) {
        String key = String.format(LOCK_KEY, dataSourceId);
        String current = redisTemplate.opsForValue().get(key);
        if (instanceId.equals(current)) {
            redisTemplate.delete(key);
        }
    }
}
```

```java
        assertThatThrownBy(() -> syncEngine.execute(job1, ds))
            .isInstanceOf(SisSyncException.class);
        
        // 断点已保存
        SyncCursor checkpoint = checkpointManager.getCheckpoint(job1);
        assertThat(checkpoint).isNotNull();
        assertThat(checkpoint.getPageNo()).isEqualTo(3);
        
        // Mock API 恢复正常
        mockZhengfangApi(ds).clearFailure();
        
        // 恢复执行 - 从第3页继续
        SisSyncJob job2 = createResumeJob(ds, job1);
        SyncJobResult result = syncEngine.execute(job2, ds);
        
        // 验证：总共同步500条（前2页在job1中已完成）
        assertThat(result.getNewCount()).isEqualTo(300); // 500 - 200(已完成)
    }
}
```

### 19.1 自定义适配器扩展

第三方开发人员可以按以下步骤添加新的 SIS 适配器：

```java
/**
 * 自定义适配器示例 - 接入 "智慧校园" 系统
 */
@Component
public class SmartCampusSisAdapter implements SisAdapter {
    
    @Override
    public String getAdapterType() {
        return "smart_campus";
    }
    
    @Override
    public HealthCheckResult healthCheck(SisDataSourceConfig config) {
        // 实现健康检查逻辑
        // ...
    }
    
    @Override
    public PageResult<ExternalStudent> fetchStudents(
            SisDataSourceConfig config, 
            SyncFilter filter, 
            SyncCursor cursor) {
        // 实现学生数据拉取逻辑
        // 将智慧校园系统的数据格式转换为 ExternalStudent
        // ...
    }
    
    // 实现其他必须方法...
}

/**
 * 注册自定义适配器
 */
@Configuration
public class CustomAdapterConfig {
    @Bean
    public SisAdapterRegistrar sisAdapterRegistrar(
            SisAdapterFactory factory,
            SmartCampusSisAdapter smartCampusAdapter) {
        return new SisAdapterRegistrar(() -> {
            factory.register(smartCampusAdapter);
        });
    }
}
```

## 附录 A：教育部教育数据标准参考

### 学籍编号规则参考

```
学籍号（G字头）：G + 身份证号（18位）= 19位
学籍号（L字头）：L + 临时身份标识 = 19位（无身份证学生）
学籍辅号：学校自定编号，用于校内管理
```
