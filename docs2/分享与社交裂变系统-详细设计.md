# 分享与社交裂变系统 - 详细设计

## 1. 模块概述

### 1.1 功能定位

为 PrimeTop 提供统一的内容分享与社交裂变能力，支持用户将学习成就、学情报告、错题笔记、学习计划等以海报/小程序卡片/链接等形式分享至微信、QQ、微博等社交平台，同时提供邀请裂变、组队学习、排行榜等社交激励机制，驱动用户增长与活跃。

### 1.2 设计目标

| 指标 | 目标 |
|------|------|
| 分享成功率 | ≥95%（端内分享到外部平台） |
| 海报生成耗时 | ≤2s（含CDN上传） |
| 裂变转化率 | 邀请链接点击→注册 ≥15% |
| 链路可用性 | 99.9%（海报渲染为非关键路径，降级至纯文本分享） |

### 1.3 覆盖场景

1. **学习成就分享**：连续打卡天数、里程碑徽章、学科突破、考试模拟成绩
2. **内容分享**：AI讲解截图、错题笔记、作文批改结果、知识点卡片
3. **学情报告分享**：周报/月报摘要、家长端报告卡片
4. **邀请裂变**：邀请新用户注册、组队学习、班级邀请
5. **社交互动**：好友排行榜、学习PK、小组挑战

### 2.2 服务边界

Share Service 作为独立业务服务，职责范围：

- 分享内容生成与管理
- 海报模板管理与渲染
- 邀请码/裂变链接生成与归因
- 社交互动数据（排行榜、PK）
- 分享行为统计与归因

**不在范围内**：微信/QQ SDK 调用（客户端负责）、支付（支付服务负责）、内容审核（安全服务负责）。

```sql
CREATE TABLE share_record (
    id              BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id         BIGINT UNSIGNED NOT NULL COMMENT '分享发起用户',
    share_type      VARCHAR(32) NOT NULL COMMENT '分享类型: achievement/content/report/referral/pk',
    target_type     VARCHAR(32) NOT NULL COMMENT '目标对象类型: badge/streak/report/note/question/exam',
    target_id       VARCHAR(64) NOT NULL COMMENT '目标对象ID',
    
    -- 分享渠道
    channel         VARCHAR(32) NOT NULL COMMENT '分享渠道: wechat_session/wechat_timeline/qq/weibo/link_copy/download_poster',
    
    -- 海报信息
    poster_url      VARCHAR(512) DEFAULT NULL COMMENT '生成的海报CDN地址',
    poster_template_id INT UNSIGNED DEFAULT NULL COMMENT '使用的海报模板ID',
    
    -- 裂变追踪
    share_code      VARCHAR(32) NOT NULL COMMENT '唯一分享短码',
    share_link      VARCHAR(512) DEFAULT NULL COMMENT '短链接',

    view_count      INT UNSIGNED DEFAULT 0 COMMENT '浏览次数',
    click_count     INT UNSIGNED DEFAULT 0 COMMENT '点击次数',
    convert_count   INT UNSIGNED DEFAULT 0 COMMENT '转化(注册)次数',

    status          TINYINT UNSIGNED DEFAULT 1 COMMENT '1-有效 2-已删除 3-已过期',
    
    created_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at      DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
    expired_at      DATETIME DEFAULT NULL COMMENT '过期时间(NULL永不过期)',
    
    INDEX idx_user_id (user_id),
    INDEX idx_share_code (share_code),
    INDEX idx_target (target_type, target_id),
    INDEX idx_created (created_at),
    INDEX idx_channel_created (channel, created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
  COMMENT='分享记录表';
```

```sql

CREATE TABLE share_event (
    event_date      Date,
    event_time      DateTime64(3),
    event_type      String,          -- share_created/poster_viewed/link_clicked/app_installed/reward_granted
    share_id        UInt64,
    user_id         UInt64,
    share_type      String,
    channel         String,
    share_code      String,

    invitee_id      UInt64 DEFAULT 0,
    device_id       String DEFAULT '',
    os              String DEFAULT '',
    app_version     String DEFAULT '',
    campaign_id     String DEFAULT ''
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(event_date)
ORDER BY (event_date, event_type, user_id)
TTL event_date + INTERVAL 180 DAY
```

## 4. API 接口设计

### 4.1 创建分享

```
POST /api/v1/shares
```

**Request:**
```json
{
  "share_type": "achievement",
  "target_type": "badge",
  "target_id": "streak_30",
  "channel": "wechat_session"
}
```

**Response:**
```json
{
  "code": 0,
  "data": {
    "share_id": 1029384756,
    "share_code": "S8K2M1",
    "share_link": "https://primetop.app/s/S8K2M1",
    "poster_url": "https://cdn.primetop.app/poster/2026/05/22/abc123.png",
    "poster_template": "achievement_badge",
    "expires_in": 604800,
    "mini_program": {
      "path": "pages/share/landing?code=S8K2M1",
      "hd_image_url": "https://cdn.primetop.app/poster/2026/05/22/abc123.png"
    }
  }
}
```

**业务逻辑：**
1. 校验用户对 target 的访问权限
2. 查找匹配的海报模板（按 target_type + 学段）
3. 渲染海报并上传至 CDN
4. 生成唯一 share_code 和短链接
5. 写入 share_record
6. 发布 `share.created` 事件

## 5. 海报渲染引擎

### 5.1 服务端渲染架构

采用服务端 Canvas 渲染（Puppeteer / sharp / Skia），确保海报质量和一致性：


### 5.2 渲染流程

```python
# share/services/poster_renderer.py

from dataclasses import dataclass
from typing import Any, Dict, List, Optional
import json
import hashlib
import skia  # skia-python bindings

@dataclass
class RenderElement:
    id: str
    type: str  # text / image / image_circle / qrcode / rect / line
    x: int
    y: int
    z_index: int = 0
    # text props
    content: Optional[str] = None
    font_size: int = 24
    font_color: str = "#000000"
    font_weight: str = "normal"
    text_align: str = "left"
    max_width: Optional[int] = None
    # image props
    source: Optional[str] = None
    width: Optional[int] = None
    height: Optional[int] = None
    radius: Optional[int] = None  # for image_circle
    # qrcode props
    size: Optional[int] = None


class PosterRenderer:
    """服务端海报渲染器，基于 Skia"""
    
    FONT_REGISTRY = {
        "normal": "NotoSansSC-Regular.otf",
        "bold": "NotoSansSC-Bold.otf",
    }
    
    def __init__(self, oss_client, cdn_domain: str):
        self.oss = oss_client
        self.cdn_domain = cdn_domain
        self._font_cache = {}
    
    async def render(
        self,
        template: dict,
        variables: Dict[str, Any],
    ) -> str:
        """
        渲染海报并上传至CDN，返回CDN地址。
        
        Args:
            template: poster_template 记录
            variables: 模板变量字典，如 {"user.nickname": "小明", "streak.days": 30}
        
        Returns:
            海报CDN地址
        """
        # 1. 绑定变量到 elements
        elements = self._bind_variables(template["elements"], variables)
        
        # 2. 计算 cache key（模板+变量哈希）
        cache_key = self._compute_cache_key(template["id"], variables)
        cached_url = await self._check_cache(cache_key)
        if cached_url:
            return cached_url
        
        # 3. 初始化 Skia Surface
        width = template["canvas_width"]
        height = template["canvas_height"]
        surface = skia.Surface(width, height)
        canvas = surface.getCanvas()
        
        # 4. 绘制背景
        background = self._load_image(template["background_url"])
        canvas.drawImage(background, 0, 0)
        
        # 5. 按 z_index 排序绘制元素
        sorted_elements = sorted(elements, key=lambda e: e.z_index)
        for elem in sorted_elements:
            self._draw_element(canvas, elem)
        
        # 6. 编码为 PNG
        image = surface.makeImageSnapshot()
        png_data = image.encodeToData(skia.kPNG)
        png_bytes = bytes(png_data)
        
        # 7. 上传至 OSS
        oss_key = f"poster/2026/05/22/{cache_key}.png"  # 动态日期
        await self.oss.upload(oss_key, png_bytes, content_type="image/png")
        
        # 8. 缓存结果
        await self._set_cache(cache_key, oss_key)
        
        return f"https://{self.cdn_domain}/{oss_key}"
    
    def _bind_variables(
        self,
        elements_config: List[dict],
        variables: Dict[str, Any],
    ) -> List[RenderElement]:
        """将模板变量绑定到元素配置"""
        result = []
        for cfg in elements_config:
            elem = RenderElement(**{k: v for k, v in cfg.items() if v is not None})
            # 替换文本中的 {{variable}} 占位符
            if elem.content:
                elem.content = self._replace_vars(elem.content, variables)
            if elem.source and elem.source.startswith("{{"):
                elem.source = self._replace_vars(elem.source, variables)
            result.append(elem)
        return result
    
    def _replace_vars(self, text: str, variables: Dict[str, Any]) -> str:
        """替换 {{key}} 格式的变量"""
        import re
        def replacer(match):
            key = match.group(1)
            return str(variables.get(key, match.group(0)))
        return re.sub(r'\{\{(\w+(?:\.\w+)*)\}\}', replacer, text)
    
    def _draw_element(self, canvas, elem: RenderElement):
        """根据类型绘制元素"""
        dispatch = {
            "text": self._draw_text,
            "image": self._draw_image,
            "image_circle": self._draw_circle_image,
            "qrcode": self._draw_qrcode,
            "rect": self._draw_rect,
        }
        handler = dispatch.get(elem.type)
        if handler:
            handler(canvas, elem)
    
    def _draw_text(self, canvas, elem: RenderElement):
        font = self._get_font(elem.font_size, elem.font_weight)
        paint = skia.Paint()
        paint.setColor(skia.Color(*self._parse_color(elem.font_color)))
        
        if elem.text_align == "center" and elem.max_width:
            # 居中文本
            blob = skia.TextBlob(elem.content, font)
            text_width = blob.bounds().width()
            x = elem.x - text_width / 2
        else:
            x = elem.x
        
        canvas.drawString(elem.content, x, elem.y, font, paint)
    
    def _draw_circle_image(self, canvas, elem: RenderElement):
        """绘制圆形头像"""
        image = self._load_image(elem.source)
        if not image:
            return
        radius = elem.radius or 50
        # 创建圆形裁剪路径
        canvas.save()
        path = skia.Path()
        path.addCircle(elem.x, elem.y, radius)
        canvas.clipPath(path)
        # 绘制图片（居中）
        img_width = radius * 2
        img_height = radius * 2
        canvas.drawImageRect(
            image,
            skia.Rect.MakeXYWH(elem.x - radius, elem.y - radius, img_width, img_height),
        )
        canvas.restore()
    
    def _draw_qrcode(self, canvas, elem: RenderElement):
        """绘制二维码"""
        import qrcode
        from io import BytesIO
        
        qr = qrcode.QRCode(version=1, box_size=10, border=0)
        qr.add_data(elem.content or "")
        qr.make(fit=True)
        img = qr.make_image(fill_color="black", back_color="white")
        
        buf = BytesIO()
        img.save(buf, format="PNG")
        qr_image = skia.Image.MakeFromEncoded(bytes(buf.getvalue()))
        
        size = elem.size or 174
        canvas.drawImageRect(
            qr_image,
            skia.Rect.MakeXYWH(elem.x, elem.y, size, size),
        )
    
    def _compute_cache_key(self, template_id: int, variables: dict) -> str:
        """计算缓存键"""
        var_hash = hashlib.md5(
            json.dumps(variables, sort_keys=True).encode()
        ).hexdigest()[:12]
        return f"t{template_id}_{var_hash}"
```

```dart
class _PosterPainter extends CustomPainter {
  final PosterTemplate template;
  final Map<String, dynamic> variables;
  
  _PosterPainter({required this.template, required this.variables});
  
  @override
  void paint(Canvas canvas, Size size) {
    // 1. 绘制背景
    // background_image 通过 precache 后获取
    
    // 2. 按 z_index 排序
    final sorted = [...template.elements]
      ..sort((a, b) => a.zIndex.compareTo(b.zIndex));
    
    for (final elem in sorted) {
      switch (elem.type) {
        case 'text':
          _drawText(canvas, elem);
          break;
        case 'image_circle':
          _drawCircleImage(canvas, elem);
          break;
        case 'qrcode':
          _drawQrCode(canvas, elem);
          break;
        case 'image':
          _drawImage(canvas, elem);
          break;
      }
    }
  }
  
  void _drawText(Canvas canvas, RenderElement elem) {
    final text = _resolveVariables(elem.content ?? '');
    final fontSize = elem.fontSize.toDouble();
    final fontWeight = elem.fontWeight == 'bold' 
        ? FontWeight.bold 
        : FontWeight.normal;
    
    final textStyle = TextStyle(
      color: _parseColor(elem.fontColor),
      fontSize: fontSize,
      fontWeight: fontWeight,
    );
    
    final textSpan = TextSpan(text: text, style: textStyle);
    final textPainter = TextPainter(
      text: textSpan,
      textDirection: TextDirection.ltr,
      textAlign: elem.textAlign == 'center' 
          ? TextAlign.center 
          : TextAlign.left,
    );
    
    textPainter.layout(maxWidth: elem.maxWidth?.toDouble() ?? size.width);
    
    double dx = elem.x.toDouble();
    if (elem.textAlign == 'center') {
      dx = dx - textPainter.width / 2;
    }
    
    textPainter.paint(canvas, Offset(dx, elem.y.toDouble()));
  }
  
  void _drawCircleImage(Canvas canvas, RenderElement elem) {
    final imageUrl = _resolveVariables(elem.source ?? '');
    final radius = (elem.radius ?? 50).toDouble();
    
    // 从缓存获取图片（预先 precacheImage）
    final image = _imageCache[imageUrl];
    if (image == null) return;
    
    canvas.save();
    final path = Path()..addOval(
      Rect.fromCircle(center: Offset(elem.x.toDouble(), elem.y.toDouble()), radius: radius),
    );
    canvas.clipPath(path);
    
    paintImage(
      canvas: canvas,
      rect: Rect.fromCircle(
        center: Offset(elem.x.toDouble(), elem.y.toDouble()),
        radius: radius,
      ),
      image: image,
      fit: BoxFit.cover,
    );
    canvas.restore();
  }
  
  void _drawQrCode(Canvas canvas, RenderElement elem) {
    final content = _resolveVariables(elem.content ?? '');
    final qrSize = (elem.size ?? 174).toDouble();
    
    final qrPainter = QrPainter(
      data: content,
      version: QrVersions.auto,
      eyeStyle: const QrEyeStyle(eyeShape: QrEyeShape.square),
      dataModuleStyle: const QrDataModuleStyle(
        dataModuleShape: QrDataModuleShape.square,
      ),
    );
    
    qrPainter.paint(canvas, Size(qrSize, qrSize));
  }
  
  String _resolveVariables(String text) {
    return text.replaceAllMapped(
      RegExp(r'\{\{(\w+(?:\.\w+)*)\}\}'),
      (m) => variables[m.group(1)]?.toString() ?? m.group(0)!,
    );
  }
  
  @override
  bool shouldRepaint(covariant _PosterPainter oldDelegate) {
    return template != oldDelegate.template || variables != oldDelegate.variables;
  }
}
```

```python
class ReferralEngine:

            return code.code
```

### 6.2 归因策略

```python
class AttributionStrategy:
    """
    归因策略（优先级从高到低）：
    1. 邀请码归因：注册时直接输入/链接携带的邀请码
    2. 渠道归因：share_code 短链接携带的分享码
    3. 设备指纹归因：匹配安装时的设备指纹与之前的点击事件
    4. 自然量：无法归因的视为自然流量
    
    归因窗口：
    - 邀请码：30天
    - 分享链接点击：7天
    - 设备指纹：3天
    """
    
    CODE_WINDOW_DAYS = 30
    LINK_WINDOW_DAYS = 7
    FINGERPRINT_WINDOW_DAYS = 3
    
    @classmethod
    async def attribute(
        cls,
        new_user_id: int,
        referral_code: str | None,
        share_code: str | None,
        device_fingerprint: str | None,
        channel: str | None,
        db_session,
        clickhouse_client,
    ) -> dict | None:
        """执行归因，返回归因结果或None"""
        
        # 1. 邀请码归因（最高优先级）
        if referral_code:
            code_record = await db_session.execute(
                select(ReferralCode)
                .where(ReferralCode.code == referral_code, ReferralCode.status == 1)
            )
            code = code_record.scalar_one_or_none()
            if code and code.user_id != new_user_id:
                return {
                    "referrer_id": code.user_id,
                    "source": "referral_code",
                    "code": referral_code,
                    "channel": channel,
                }
        
        # 2. 分享码归因
        if share_code:
            share_record = await db_session.execute(
                select(ShareRecord)
                .where(
                    ShareRecord.share_code == share_code,
                    ShareRecord.status == 1,
                    ShareRecord.created_at >= datetime.utcnow() - timedelta(days=cls.LINK_WINDOW_DAYS),
                )
            )
            share = share_record.scalar_one_or_none()
            if share and share.user_id != new_user_id:
                return {
                    "referrer_id": share.user_id,
                    "source": "share_link",
                    "share_record_id": share.id,
                    "code": share_code,
                    "channel": channel,
                }
        
        # 3. 设备指纹归因（查 ClickHouse 近3天的点击事件）
        if device_fingerprint:
            events = await clickhouse_client.query(
                """
                SELECT share_id, user_id, share_code, event_time
                FROM share_event
                WHERE event_type = 'link_clicked'
                  AND device_id = %(fp)s
                  AND event_date >= today() - 3
                ORDER BY event_time DESC
                LIMIT 1
                """,
                params={"fp": device_fingerprint},
            )
            if events:
                event = events[0]
                if event["user_id"] != new_user_id:
                    return {
                        "referrer_id": event["user_id"],
                        "source": "fingerprint",
                        "share_record_id": event["share_id"],
                        "code": event["share_code"],
                        "channel": "fingerprint",
                    }
        
        return None  # 自然流量
```

```python
class LeaderboardService:
    """排行榜服务"""
    
    # 使用 Redis Sorted Set 做实时排名，定时落库
    REDIS_KEY_PREFIX = "lb:"
    
    @classmethod
    async def update_score(
        cls,
        lb_type: str,
        period_key: str,
        user_id: int,
        score_delta: float,
        user_snapshot: dict,
        redis_client,
    ):
        """实时更新排行榜分数（Redis ZINCRBY）"""
        key = f"{cls.REDIS_KEY_PREFIX}{lb_type}:{period_key}"
        redis_client.zincrby(key, score_delta, str(user_id))
        
        # 更新用户快照（用于排行榜展示）
        hash_key = f"{key}:info"
        redis_client.hset(hash_key, str(user_id), json.dumps({
            "nickname": user_snapshot["nickname"],
            "avatar_url": user_snapshot["avatar_url"],
            "grade_label": user_snapshot["grade_label"],
        }))
    
    @classmethod
    async def get_ranking(
        cls,
        lb_type: str,
        period_key: str,
        user_id: int,
        limit: int,
        redis_client,
        db_session,
    ) -> dict:
        """获取排行榜"""
        key = f"{cls.REDIS_KEY_PREFIX}{lb_type}:{period_key}"
        hash_key = f"{key}:info"
        
        # 获取 Top N
        top_raw = redis_client.zrevrange(key, 0, limit - 1, withscores=True)
        
        # 获取我的排名
        my_rank = redis_client.zrevrank(key, str(user_id))
        my_score = redis_client.zscore(key, str(user_id))
        
        entries = []
        for idx, (uid, score) in enumerate(top_raw):
            info_raw = redis_client.hget(hash_key, uid)
            info = json.loads(info_raw) if info_raw else {}
            entries.append({
                "rank": idx + 1,
                "user_id": int(uid),
                "nickname": info.get("nickname", ""),
                "avatar_url": info.get("avatar_url", ""),
                "grade_label": info.get("grade_label", ""),
                "score": score,
            })
        
        return {
            "type": lb_type,
            "period_key": period_key,
            "my_rank": (my_rank + 1) if my_rank is not None else None,
            "my_score": my_score,
            "entries": entries,
            "total": redis_client.zcard(key),
        }
    
    @classmethod
    async def settle_to_db(cls, lb_type: str, period_key: str, db_session, redis_client):
        """将 Redis 排行榜数据落库（定时任务）"""
        key = f"{cls.REDIS_KEY_PREFIX}{lb_type}:{period_key}"
        hash_key = f"{key}:info"
        
        all_data = redis_client.zrevrange(key, 0, -1, withscores=True)
        
        for rank, (uid, score) in enumerate(all_data, 1):
            info_raw = redis_client.hget(hash_key, uid)
            info = json.loads(info_raw) if info_raw else {}
            
            await db_session.execute(
                insert(LeaderboardEntry)
                .values(
                    leaderboard_type=lb_type,
                    period_key=period_key,
                    user_id=int(uid),
                    score=score,
                    rank_position=rank,
                    nickname=info.get("nickname"),
                    avatar_url=info.get("avatar_url"),
                    grade_label=info.get("grade_label"),
                )
                .on_duplicate_key_update(
                    score=score,
                    rank_position=rank,
                    nickname=info.get("nickname"),
                    avatar_url=info.get("avatar_url"),
                    grade_label=info.get("grade_label"),
                )
            )
        
        await db_session.commit()
```

### 8.3 PK流程

```python
class PKService:
    
    @classmethod
    async def create_pk(
        cls,
        challenger_id: int,
        pk_type: str,
        target_user_id: int | None,
        config: dict,
        db_session,
    ) -> dict:
        """创建PK挑战"""
        
        # 生成题目池
        questions = await QuestionService.pick_questions(
            subject=config["subject"],
            difficulty=config["difficulty"],
            count=config["question_count"],
            exclude_recent=True,
        )
        
        pk_id = f"pk_{datetime.utcnow().strftime('%Y%m%d%H%M%S')}_{secrets.token_hex(4)}"
        share_code = generate_share_code()
        
        pk = PKSession(
            id=pk_id,
            pk_type=pk_type,
            challenger_id=challenger_id,
            opponent_id=target_user_id,
            config=config,
            questions=[q.id for q in questions],
            share_code=share_code,
            status="pending",
            expires_at=datetime.utcnow() + timedelta(hours=24),
        )
        db_session.add(pk)
        await db_session.commit()
        
        # 如果有指定对手，发送推送通知
        if target_user_id:
            await PushService.send(target_user_id, {
                "type": "pk_challenge",
                "pk_id": pk_id,
                "challenger_nickname": await cls._get_nickname(challenger_id),
            })
        
        return {
            "pk_id": pk_id,
            "share_code": share_code,
            "status": "pending",
            "expires_at": pk.expires_at.isoformat(),
        }
    
    @classmethod
    async def submit_answer(
        cls,
        pk_id: str,
        user_id: int,
        question_id: int,
        answer: str,
        time_spent_ms: int,
        db_session,
        event_bus,
    ) -> dict:
        """提交PK答题"""
        pk = await db_session.get(PKSession, pk_id)
        if not pk or pk.status != "active":
            raise BusinessException(ErrorCode.PK_NOT_ACTIVE)
        
        # 记录答案
        is_correct = await cls._check_answer(question_id, answer)
        pk_answer = PKAnswer(
            pk_id=pk_id,
            user_id=user_id,
            question_id=question_id,
            answer=answer,
            is_correct=is_correct,
            time_spent_ms=time_spent_ms,
            answered_at=datetime.utcnow(),
        )
        db_session.add(pk_answer)
        
        # 更新得分
        if is_correct:
            if user_id == pk.challenger_id:
                pk.challenger_score += 1
            else:
                pk.opponent_score += 1
        
        # 检查是否双方都答完
        await cls._check_completion(pk, db_session, event_bus)
        
        await db_session.commit()
        
        return {"is_correct": is_correct, "current_score": pk.challenger_score if user_id == pk.challenger_id else pk.opponent_score}
```

```dart
class ShareAdapter {
  static const _channel = MethodChannel('com.primetop/share');
  
  /// 执行分享
  static Future<ShareResult> share({
    required ShareChannel channel,
    String? title,
    String? description,
    String? webPageUrl,
    String? imagePath,
    String? miniProgramPath,
  }) async {
    try {
      final result = await _channel.invokeMethod<int>('share', {
        'channel': channel.name,
        'title': title,
        'description': description,
        'webPageUrl': webPageUrl,
        'imagePath': imagePath,
        'miniProgramPath': miniProgramPath,
      });
      
      return ShareResult.values[result ?? 2];
    } on PlatformException catch (e) {
      if (e.code == 'NOT_INSTALLED') {
        return ShareResult.notInstalled;
      }
      return ShareResult.failed;
    }
  }
  
  /// 分享学习成就（快捷方法）
  static Future<ShareResult> shareAchievement({
    required String shareCode,
    required String posterUrl,
    required String title,
    required String description,
  }) async {
    // 优先分享小程序卡片（如果在微信环境）
    // 降级到海报图片分享
    // 再降级到复制链接
    
    final channel = ShareChannel.wechatSession;
    final result = await share(
      channel: channel,
      title: title,
      description: description,
      imagePath: await _downloadPoster(posterUrl),
      miniProgramPath: 'pages/share/landing?code=$shareCode',
    );
    
    if (result == ShareResult.notInstalled) {
      // 降级到系统分享
      return share(
        channel: ShareChannel.systemShare,
        title: title,
        description: '$description\n\n${_getShareLink(shareCode)}',
      );
    }
    
    return result;
  }
  
  static Future<String> _downloadPoster(String url) async {
    final dir = await getTemporaryDirectory();
    final file = File('${dir.path}/share_poster_${DateTime.now().millisecondsSinceEpoch}.png');
    await Dio().download(url, file.path);
    return file.path;
  }

    return 'https://primetop.app/s/$code';
  }
```

## 11. 反作弊与安全

### 11.1 反作弊规则

| 行为 | 检测方式 | 处置 |
|------|----------|------|
| 刷邀请 | 同一设备/IP多次注册 | 标记无效，不发放奖励 |
| 自我邀请 | 同设备不同账号互邀 | 拒绝归因 |
| 虚假PK | 固定对手刷分 | PK结果无效 |
| 海报滥用 | 生成频率过高 | 限流(每用户10次/天) |
| 分享链接篡改 | 校验 share_code 签名 | 拒绝服务 |

## 12. 降级策略

| 故障场景 | 降级方案 |
|----------|----------|
| 海报渲染服务不可用 | 跳过海报生成，仅返回文字链接；客户端降级到纯文本分享 |
| CDN 上传失败 | 重试3次后返回文字链接 |
| Redis 排行榜不可用 | 直接查 MySQL 的 leaderboard_entry（结算数据），延迟更高 |
| ClickHouse 归因不可用 | 跳过设备指纹归因，仅用邀请码/分享码归因 |
| 推送服务不可用 | PK邀请走端内消息，推送延迟补发 |
| 微信SDK未安装 | 引导下载微信或降级到系统分享/复制链接 |
