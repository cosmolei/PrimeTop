# 服务端请求上下文传递与服务间调用规范 - 详细设计

> **模块版本**: v1.0 | **日期**: 2026-05-25 | **状态**: 初稿
> **原始需求来源**: `docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` §8.2, §8.4, §8.7
> **依赖文档**: API网关与通用接口规范、服务端代码分层规范与通用开发模板、服务端分布式链路追踪与全链路可观测体系、服务端审计日志与操作追溯系统、异步任务与事件驱动架构

## 1. 模块概述

### 1.1 问题背景

PrimeTop 采用模块化单体架构，服务端内部各业务模块（用户、AI、题目、错题、学习、支付等）之间存在大量同步和异步调用。每个请求从 API 网关进入后，需要携带一组"请求上下文"信息（如用户 ID、设备信息、链路追踪 ID、租户 ID 等），这些信息需要在以下场景中可靠传递：

1. **Router → Service → Repository** 层间传递
2. **模块 A → 模块 B** 的跨模块同步调用
3. **主线程 → Celery Worker** 的异步任务上下文传递
4. **进程内事件总线**的事件发布/订阅
5. **SSE 流式响应**的长生命周期上下文保持
6. **后台定时任务**的无请求上下文场景

如果缺少统一的上下文传递规范，会导致：
- 各模块自行从 request 获取用户信息，Service 层耦合 HTTP 层
- 异步任务丢失追踪 ID，日志无法串联
- 审计日志缺少操作人和操作来源
- 跨模块调用难以追踪和排错

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| 透明传递 | 开发者在 Service/Repository 层无需关心上下文来源，通过统一接口获取 |
| 异步安全 | Celery 任务、线程池、asyncio task 均能正确获取上下文 |
| 可观测 | 上下文中的 trace_id 贯穿所有日志和跨服务调用 |
| 可扩展 | 新增上下文字段无需修改所有调用链 |
| 可测试 | 测试时可以方便地构造和注入上下文 |

### 1.3 适用范围

- 技术栈：Python 3.11+ / FastAPI 0.100+ / Celery 5.x
- 架构：模块化单体 → 未来微服务
- 所有新增业务模块必须遵循本规范

## 2. 请求上下文模型

### 2.1 RequestContext 数据结构

```python
from dataclasses import dataclass, field
from enum import Enum
from typing import Optional
import time
import uuid


class Platform(str, Enum):
    """客户端平台"""
    ANDROID = "android"
    IOS = "ios"
    WEB = "web"
    MINI_PROGRAM = "mini_program"
    ADMIN = "admin"      # 管理后台
    INTERNAL = "internal"  # 内部服务间调用


class CallSource(str, Enum):
    """调用来源"""
    API_GATEWAY = "api_gateway"    # 外部 API 请求
    CRON_JOB = "cron_job"          # 定时任务
    CELERY_TASK = "celery_task"    # Celery 异步任务
    EVENT_HANDLER = "event_handler"  # 事件处理器
    INTERNAL_CALL = "internal_call"  # 内部模块间调用
    CLI = "cli"                    # 命令行


@dataclass
class DeviceInfo:
    """设备信息"""
    device_id: Optional[str] = None       # 设备唯一标识
    device_model: Optional[str] = None    # 设备型号，如 "iPhone 15 Pro"
    os_version: Optional[str] = None      # 操作系统版本，如 "iOS 17.2"
    app_version: Optional[str] = None     # APP 版本号，如 "1.2.0"
    network_type: Optional[str] = None    # 网络类型：wifi/4g/5g/unknown


@dataclass
class RequestContext:
    """
    请求上下文 —— 贯穿整个请求生命周期的元数据。
    
    通过 contextvars 在同步/异步调用链中自动传递，
    开发者通过 get_request_context() 获取，不需要显式传参。
    """
    # === 身份信息 ===
    user_id: Optional[int] = None          # 当前登录用户 ID
    student_id: Optional[int] = None       # 当前学生档案 ID（家长切换时可能不同）
    parent_id: Optional[int] = None        # 家长 ID（家长端请求时）
    admin_id: Optional[int] = None         # 管理员 ID（后台请求时）
    
    # === 租户信息 ===
    tenant_id: Optional[int] = None        # 租户 ID（B端合作场景，默认 None）
    tenant_type: Optional[str] = None      # 租户类型：school/institution/individual
    
    # === 链路追踪 ===
    trace_id: str = field(default_factory=lambda: uuid.uuid4().hex[:16])
    span_id: str = field(default_factory=lambda: uuid.uuid4().hex[:8])
    parent_span_id: Optional[str] = None
    
    # === 请求元数据 ===
    request_id: str = field(default_factory=lambda: uuid.uuid4().hex)
    platform: Platform = Platform.WEB
    call_source: CallSource = CallSource.API_GATEWAY
    client_ip: Optional[str] = None
    
    # === 设备信息 ===
    device: DeviceInfo = field(default_factory=DeviceInfo)
    
    # === 请求级标记 ===
    is_member: bool = False                # 用户是否为会员（减少重复查询）
    member_level: Optional[str] = None     # 会员等级
    stage: Optional[str] = None            # 当前学段（缓存，避免每次查库）
    grade: Optional[str] = None            # 当前年级
    
    # === 权限缓存 ===
    permissions: set = field(default_factory=set)   # 用户权限集合
    roles: set = field(default_factory=set)          # 用户角色集合
    
    # === 时间戳 ===
    request_time: float = field(default_factory=time.time)
    
    # === 实验分流 ===
    experiment_variants: dict = field(default_factory=dict)  # {"exp_id": "variant_name"}
    
    @property
    def is_authenticated(self) -> bool:
        return self.user_id is not None
    
    @property
    def is_admin_request(self) -> bool:
        return self.call_source == CallSource.API_GATEWAY and self.admin_id is not None
    
    @property
    def is_internal_call(self) -> bool:
        return self.call_source in (
            CallSource.CRON_JOB, CallSource.CELERY_TASK,
            CallSource.EVENT_HANDLER, CallSource.INTERNAL_CALL
        )
    
    def to_dict(self) -> dict:
        """序列化为 dict，用于日志记录和异步任务传递"""
        return {
            "user_id": self.user_id,
            "student_id": self.student_id,
            "parent_id": self.parent_id,
            "admin_id": self.admin_id,
            "tenant_id": self.tenant_id,
            "trace_id": self.trace_id,
            "span_id": self.span_id,
            "request_id": self.request_id,
            "platform": self.platform.value,
            "call_source": self.call_source.value,
            "client_ip": self.client_ip,
            "device": {
                "device_id": self.device.device_id,
                "app_version": self.device.app_version,
            },
            "is_member": self.is_member,
            "stage": self.stage,
            "grade": self.grade,
            "request_time": self.request_time,
        }
    
    def to_headers(self) -> dict:
        """序列化为 HTTP Headers，用于跨服务调用传递"""
        headers = {
            "X-Trace-Id": self.trace_id,
            "X-Span-Id": self.span_id,
            "X-Request-Id": self.request_id,
            "X-Platform": self.platform.value,
            "X-Call-Source": self.call_source.value,
        }
        if self.user_id:
            headers["X-User-Id"] = str(self.user_id)
        if self.tenant_id:
            headers["X-Tenant-Id"] = str(self.tenant_id)
        return headers
    
    @classmethod
    def from_headers(cls, headers: dict) -> "RequestContext":
        """从 HTTP Headers 反序列化（用于内部服务间调用接收端）"""
        return cls(
            user_id=int(h) if (h := headers.get("X-User-Id")) else None,
            tenant_id=int(h) if (h := headers.get("X-Tenant-Id")) else None,
            trace_id=headers.get("X-Trace-Id", uuid.uuid4().hex[:16]),
            span_id=uuid.uuid4().hex[:8],
            parent_span_id=headers.get("X-Span-Id"),
            request_id=headers.get("X-Request-Id", uuid.uuid4().hex),
            platform=Platform(headers.get("X-Platform", "web")),
            call_source=CallSource(headers.get("X-Call-Source", "internal_call")),
        )
```

### 2.2 上下文字段优先级

某些字段存在覆盖场景：

| 场景 | 覆盖规则 |
|------|----------|
| 家长代操作 | `parent_id` 设为家长 ID，`student_id` 设为被管理的孩子 ID，`user_id` 设为家长 ID |
| 教师查看班级 | `admin_id` 设为教师 ID，`user_id` 为空 |
| 管理后台操作 | `admin_id` 设为管理员 ID |
| 内部服务调用 | 保持原始上下文，`call_source` 标记为 `internal_call` |
| 定时任务 | `user_id` 为空，`call_source` 标记为 `cron_job` |

## 3. 上下文传递机制

### 3.1 核心：contextvars

使用 Python 3.7+ 的 `contextvars` 模块实现自动传递，它是 asyncio 原生支持的上下文变量机制。

```python
# app/core/context.py

from contextvars import ContextVar, copy_context
from typing import Optional

# 全局 ContextVar，每个请求/任务独立副本
_request_context: ContextVar[Optional["RequestContext"]] = ContextVar(
    "request_context", default=None
)


def set_request_context(ctx: "RequestContext") -> None:
    """设置当前请求上下文（中间件调用）"""
    _request_context.set(ctx)


def get_request_context() -> "RequestContext":
    """
    获取当前请求上下文。
    
    如果在没有请求上下文的环境中调用（如定时任务未初始化），
    返回一个默认的内部调用上下文。
    """
    ctx = _request_context.get()
    if ctx is None:
        # 创建一个默认的内部上下文，防止 NPE
        from app.core.context_model import RequestContext, CallSource
        ctx = RequestContext(call_source=CallSource.INTERNAL_CALL)
        _request_context.set(ctx)
    return ctx


def get_optional_context() -> Optional["RequestContext"]:
    """获取当前请求上下文，不存在返回 None（用于需要区分场景的地方）"""
    return _request_context.get()


def clear_request_context() -> None:
    """清除当前请求上下文（请求结束时调用）"""
    _request_context.set(None)
```

### 3.2 FastAPI 中间件：自动注入

```python
# app/core/middleware.py

import time
import uuid
from starlette.middleware.base import BaseHTTPMiddleware, RequestResponseEndpoint
from starlette.requests import Request
from starlette.responses import Response
from app.core.context import set_request_context, clear_request_context
from app.core.context_model import (
    RequestContext, DeviceInfo, Platform, CallSource
)
from app.core.security import decode_jwt_token


class RequestContextMiddleware(BaseHTTPMiddleware):
    """
    请求上下文中间件 —— 每个请求进入时自动构建 RequestContext。
    
    处理顺序：
    1. 解析 JWT Token → 填充用户信息
    2. 解析请求头 → 填充设备/平台/追踪信息
    3. 缓存会员状态/学段信息 → 减少后续查询
    4. 设置 contextvar → 后续层自动获取
    5. 请求结束时清除 → 防止内存泄漏
    """
    
    async def dispatch(
        self, request: Request, call_next: RequestResponseEndpoint
    ) -> Response:
        # 1. 构建基础上下文
        ctx = RequestContext(
            trace_id=request.headers.get("X-Trace-Id", uuid.uuid4().hex[:16]),
            request_id=request.headers.get(
                "X-Request-Id", uuid.uuid4().hex
            ),
            platform=self._parse_platform(request),
            call_source=CallSource.API_GATEWAY,
            client_ip=self._get_client_ip(request),
            request_time=time.time(),
        )
        
        # 2. 解析认证信息
        auth_header = request.headers.get("Authorization", "")
        if auth_header.startswith("Bearer "):
            token = auth_header[7:]
            payload = decode_jwt_token(token)
            if payload:
                ctx.user_id = payload.get("user_id")
                ctx.student_id = payload.get("student_id")
                ctx.parent_id = payload.get("parent_id")
                ctx.admin_id = payload.get("admin_id")
                ctx.is_member = payload.get("is_member", False)
                ctx.member_level = payload.get("member_level")
                ctx.stage = payload.get("stage")
                ctx.grade = payload.get("grade")
                ctx.tenant_id = payload.get("tenant_id")
        
        # 3. 解析设备信息
        ctx.device = DeviceInfo(
            device_id=request.headers.get("X-Device-Id"),
            device_model=request.headers.get("X-Device-Model"),
            os_version=request.headers.get("X-OS-Version"),
            app_version=request.headers.get("X-App-Version"),
            network_type=request.headers.get("X-Network-Type"),
        )
        
        # 4. 解析实验分流
        exp_header = request.headers.get("X-Experiment-Variants")
        if exp_header:
            # 格式: "exp_123=variant_a,exp_456=variant_b"
            for pair in exp_header.split(","):
                if "=" in pair:
                    k, v = pair.split("=", 1)
                    ctx.experiment_variants[k.strip()] = v.strip()
        
        # 5. 设置到 contextvar
        set_request_context(ctx)
        
        try:
            response = await call_next(request)
            # 将 trace_id 和 request_id 写回响应头，方便客户端排障
            response.headers["X-Trace-Id"] = ctx.trace_id
            response.headers["X-Request-Id"] = ctx.request_id
            return response
        finally:
            clear_request_context()
    
    def _parse_platform(self, request: Request) -> Platform:
        ua = request.headers.get("User-Agent", "").lower()
        platform_header = request.headers.get("X-Platform", "").lower()
        
        if platform_header in ("android", "ios", "web", "mini_program", "admin"):
            return Platform(platform_header)
        if "android" in ua:
            return Platform.ANDROID
        if "iphone" in ua or "ipad" in ua:
            return Platform.IOS
        return Platform.WEB
    
    def _get_client_ip(self, request: Request) -> str:
        forwarded = request.headers.get("X-Forwarded-For")
        if forwarded:
            return forwarded.split(",")[0].strip()
        return request.client.host if request.client else "unknown"
```

### 3.3 FastAPI 依赖注入：快捷获取

```python
# app/core/dependencies.py

from typing import Optional
from fastapi import Depends, Query, Header
from app.core.context import get_request_context
from app.core.context_model import RequestContext


def get_context() -> RequestContext:
    """获取当前请求上下文（FastAPI 依赖注入用）"""
    return get_request_context()


def get_current_user_id(ctx: RequestContext = Depends(get_context)) -> int:
    """获取当前用户 ID，未登录抛 401"""
    if not ctx.is_authenticated:
        from app.core.exceptions import AuthenticationError
        raise AuthenticationError("未登录或 Token 已过期")
    return ctx.user_id


def get_optional_user_id(ctx: RequestContext = Depends(get_context)) -> Optional[int]:
    """获取当前用户 ID，未登录返回 None"""
    return ctx.user_id


def get_current_student_id(ctx: RequestContext = Depends(get_context)) -> int:
    """获取当前学生档案 ID"""
    sid = ctx.student_id or ctx.user_id
    if not sid:
        from app.core.exceptions import AuthenticationError
        raise AuthenticationError("未登录或 Token 已过期")
    return sid


def get_admin_id(ctx: RequestContext = Depends(get_context)) -> int:
    """获取当前管理员 ID，非管理员抛 403"""
    if not ctx.is_admin_request:
        from app.core.exceptions import PermissionDeniedError
        raise PermissionDeniedError("需要管理员权限")
    return ctx.admin_id


def get_tenant_id(ctx: RequestContext = Depends(get_context)) -> Optional[int]:
    """获取当前租户 ID"""
    return ctx.tenant_id
```

```python
# app/modules/question/service.py

from app.core.context import get_request_context
from app.core.context_model import RequestContext
from app.core.exceptions import PermissionDeniedError


class QuestionService:
    
    def get_question(self, question_id: int) -> Question:

        ctx = get_request_context()
        
        # 日志自动包含 trace_id（见 §4 日志集成）
        logger.info(f"获取题目详情: question_id={question_id}")

        self.event_bus.publish("question.viewed", {
            "question_id": question_id,
            "user_id": ctx.user_id,
            "student_id": ctx.student_id,
            "trace_id": ctx.trace_id,
        })
        
        return question
    
    def create_question(self, data: QuestionCreate) -> Question:
        ctx = get_request_context()
        
        # 审计日志自动记录操作人
        question = self.repo.create(data)
        
        logger.info(
            f"创建题目: id={question.id}, "
            f"operator={ctx.admin_id or ctx.user_id}, "
            f"source={ctx.call_source.value}"
        )
        return question
```

## 4. 日志集成

### 4.1 结构化日志自动注入

所有日志自动包含 trace_id、request_id、user_id，无需手动传递：

```python
# app/core/logging.py

import logging
import json
from app.core.context import get_optional_context


class ContextualFormatter(logging.Formatter):
    """自动注入请求上下文的日志格式化器"""
    
    def format(self, record: logging.LogRecord) -> str:
        ctx = get_optional_context()
        
        log_entry = {
            "timestamp": self.formatTime(record, self.datefmt),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
            "trace_id": ctx.trace_id if ctx else "-",
            "request_id": ctx.request_id if ctx else "-",
            "user_id": ctx.user_id if ctx else None,
            "tenant_id": ctx.tenant_id if ctx else None,
            "platform": ctx.platform.value if ctx else None,
        }
        
        # 去掉 None 值
        log_entry = {k: v for k, v in log_entry.items() if v is not None}
        
        if record.exc_info and record.exc_info[0]:
            log_entry["exception"] = self.formatException(record.exc_info)
        
        return json.dumps(log_entry, ensure_ascii=False)


def setup_logging():
    """初始化日志系统"""
    root_logger = logging.getLogger()
    root_logger.setLevel(logging.INFO)
    
    handler = logging.StreamHandler()
    handler.setFormatter(ContextualFormatter(datefmt="%Y-%m-%d %H:%M:%S"))
    root_logger.addHandler(handler)
```

## 5. 跨模块同步调用规范

### 5.1 模块间调用方式

模块化单体中，跨模块调用直接通过 Python 方法调用。上下文通过 contextvars 自动传递，无需额外操作：

```python
# app/modules/ai/service.py 中调用错题模块

class AIService:
    def __init__(self, mistake_service: MistakeService):
        self.mistake_service = mistake_service
    
    async def handle_wrong_answer(self, question_id: int, user_answer: str):
        ctx = get_request_context()  # 自动获取当前请求上下文
        
        # 直接调用，contextvar 自动传递（同一 asyncio task）
        await self.mistake_service.add_mistake(
            student_id=ctx.student_id,
            question_id=question_id,
            user_answer=user_answer,
            source="ai_chat",
        )
```

### 5.2 跨模块调用约束

| 规则 | 说明 |
|------|------|
| 禁止 import 对方 Router | 模块间只能通过 Service 接口交互 |
| 禁止直接操作对方数据库表 | 通过 Service 或 Repository 接口 |
| 禁止传递 request 对象 | 使用 get_request_context() 获取上下文 |
| 优先使用事件总线解耦 | 非强一致场景使用异步事件 |
| 调用超时必须有 | 通过 asyncio.wait_for 设置超时 |

### 5.3 跨模块调用封装模式

对于可能演进为微服务的热点调用，预留 HTTP 调用适配层：

```python
# app/common/module_client.py

from typing import Any, Optional
import httpx
from app.core.context import get_request_context
from app.core.config import settings


class ModuleClient:
    """
    模块间调用客户端 —— 当前为进程内调用，未来可切换为 HTTP/RPC。
    所有跨模块调用统一通过此客户端，方便后续拆分微服务。
    """
    
    def __init__(self):
        self._http_client: Optional[httpx.AsyncClient] = None
    
    async def call(
        self,
        module: str,      # 目标模块名：user/ai/question/mistake/learning/payment
        method: str,       # 方法名/路径
        params: dict = None,
        timeout: float = 10.0,
    ) -> Any:
        ctx = get_request_context()
        
        if settings.USE_IN_PROCESS_CALLS:
            # 模块化单体：进程内直接调用
            return await self._in_process_call(module, method, params)
        else:
            # 微服务模式：HTTP 调用
            return await self._http_call(module, method, params, ctx, timeout)
    
    async def _http_call(
        self, module: str, method: str, 
        params: dict, ctx, timeout: float
    ) -> Any:
        """HTTP 模式：自动注入上下文 Headers"""
        if not self._http_client:
            self._http_client = httpx.AsyncClient(timeout=timeout)
        
        url = f"{settings.get_module_url(module)}/internal/{method}"
        headers = ctx.to_headers()
        headers["Authorization"] = f"Bearer {settings.INTERNAL_SERVICE_TOKEN}"
        
        response = await self._http_client.post(url, json=params, headers=headers)
        response.raise_for_status()
        return response.json()["data"]
    
    async def _in_process_call(
        self, module: str, method: str, params: dict
    ) -> Any:
        """进程内模式：通过服务注册表调用"""
        from app.core.service_registry import get_service
        service = get_service(module)
        handler = getattr(service, method)
        return await handler(**params)


# 全局单例
module_client = ModuleClient()
```

### 6.1 Celery 任务上下文传递

Celery Worker 运行在独立进程中，contextvars 不会自动传递。需要通过任务参数显式传递，Worker 端重建上下文：

```python
# app/common/celery_context.py

from functools import wraps
from app.core.context import set_request_context, clear_request_context
from app.core.context_model import RequestContext, CallSource


def with_context(task_func):
    """
    Celery 任务装饰器 —— 自动从 kwargs 中提取上下文并设置。
    
    用法:
        @app.task(bind=True)
        @with_context
        def generate_report(self, report_id, **kwargs):
            ctx = get_request_context()  # ✅ 可以获取到上下文
            ...
    """
    @wraps(task_func)
    def wrapper(*args, **kwargs):
        ctx_data = kwargs.pop("_context", None)
        
        if ctx_data:
            ctx = RequestContext(
                user_id=ctx_data.get("user_id"),
                student_id=ctx_data.get("student_id"),
                trace_id=ctx_data.get("trace_id"),
                request_id=ctx_data.get("request_id"),
                call_source=CallSource.CELERY_TASK,
                platform=ctx_data.get("platform", "web"),
            )
        else:
            ctx = RequestContext(call_source=CallSource.CELERY_TASK)
        
        set_request_context(ctx)
        try:
            return task_func(*args, **kwargs)
        finally:
            clear_request_context()
    
    return wrapper
```

## 7. 进程内事件总线上下文传递

### 7.1 事件携带上下文

```python
# app/common/event_bus.py

import asyncio
import logging
from dataclasses import dataclass, field
from typing import Any, Callable, Dict, List
from app.core.context import get_request_context

logger = logging.getLogger(__name__)


@dataclass
class DomainEvent:
    """领域事件基类 —— 自动携带上下文"""
    event_type: str
    payload: dict = field(default_factory=dict)
    trace_id: str = ""
    user_id: int | None = None
    student_id: int | None = None
    timestamp: float = field(default_factory=time.time)
    
    def __post_init__(self):
        # 自动从当前上下文填充
        ctx = get_request_context()
        if not self.trace_id:
            self.trace_id = ctx.trace_id
        if not self.user_id:
            self.user_id = ctx.user_id
        if not self.student_id:
            self.student_id = ctx.student_id


class EventBus:
    """进程内异步事件总线"""
    
    def __init__(self):
        self._handlers: Dict[str, List[Callable]] = {}
    
    def subscribe(self, event_type: str, handler: Callable):
        self._handlers.setdefault(event_type, []).append(handler)
    
    async def publish(self, event_type: str, payload: dict = None):
        """发布事件 —— 自动携带当前请求上下文"""
        event = DomainEvent(event_type=event_type, payload=payload or {})
        
        handlers = self._handlers.get(event_type, [])
        for handler in handlers:
            try:
                result = handler(event)
                if asyncio.iscoroutine(result):
                    await result
            except Exception as e:
                logger.error(
                    f"事件处理失败: type={event_type}, handler={handler.__name__}, "
                    f"trace_id={event.trace_id}, error={e}",
                    exc_info=True
                )


# 全局单例
```

## 12. 上下文生命周期

### 12.1 完整生命周期图

```
请求进入 API 网关
    │
    ▼
RequestContextMiddleware 创建 RequestContext
    │ set_request_context(ctx)
    │
    ├─► Router 层处理（通过 Depends(get_context) 获取）
    │      │
    │      ├─► Service 层（通过 get_request_context() 获取）
    │      │      │
    │      │      ├─► Repository 层（一般不需要上下文）
    │      │      │
    │      │      ├─► 跨模块调用（contextvar 自动传递）
    │      │      │
    │      │      ├─► 发起 Celery 任务（apply_async_with_context 注入）
    │      │      │
    │      │      └─► 发布事件（DomainEvent 自动携带）
    │      │
    │      └─► 返回 Response
    │
    ▼
RequestContextMiddleware 清理
    clear_request_context()
```

### 12.2 异步任务生命周期

```
Celery Worker 进程
    │
    ▼
@with_context 装饰器从 kwargs._context 恢复
    │ set_request_context(ctx)
    │
    ├─► 任务函数执行
    │      ├─► get_request_context() ✅ 可用
    │      ├─► 日志 ✅ 包含 trace_id
    │      ├─► 发起子任务（apply_async_with_context ✅ 传递）
    │      └─► 发布事件（自动携带 ✅）
    │
    ▼
@with_context 装饰器清理
    clear_request_context()
```

### 12.3 线程安全说明

| 场景 | contextvars 行为 | 是否安全 |
|------|------------------|----------|
| 同一 asyncio task 内 | 自动传递 | ✅ 安全 |
| asyncio.create_task() | 复制父上下文 | ✅ 安全 |
| asyncio.gather() | 各子任务独立副本 | ✅ 安全 |
| threading.Thread | 不传递 | ⚠️ 需手动传递 |
| ProcessPoolExecutor | 不传递 | ⚠️ 需通过参数传递 |
| Celery Worker（独立进程） | 不传递 | ⚠️ 需通过 _context 参数传递 |

### 12.4 线程池场景处理

```python
# app/common/thread_context.py

import asyncio
from concurrent.futures import ThreadPoolExecutor
from app.core.context import get_request_context, set_request_context


class ContextAwareExecutor(ThreadPoolExecutor):
    """支持上下文传递的线程池"""
    
    def submit(self, fn, *args, **kwargs):
        # 捕获当前上下文
        ctx = get_request_context()
        
        def wrapper(*a, **kw):
            set_request_context(ctx)
            try:
                return fn(*a, **kw)
            finally:
                set_request_context(None)
        
        return super().submit(wrapper, *args, **kwargs)


# 使用示例
executor = ContextAwareExecutor(max_workers=4)

def heavy_computation(data):
    ctx = get_request_context()  # ✅ 可以获取到
    ...

future = executor.submit(heavy_computation, data)
```

## 13. 错误处理

### 13.1 上下文相关错误码

| 错误码 | 含义 | 场景 |
|--------|------|------|
| CTX_001 | 上下文未初始化 | Service 层在非请求环境中被直接调用 |

| CTX_003 | 管理员身份缺失 | 管理后台接口但无 admin_id |
| CTX_004 | 租户信息缺失 | B 端接口但无 tenant_id |

## 15. 微服务演进预留

### 15.1 当前 → 微服务切换点

| 当前（模块化单体） | 微服务 | 切换成本 |
|---------------------|--------|----------|
| contextvars 自动传递 | HTTP Headers + gRPC metadata | 中 |
| `get_request_context()` 不变 | 底层改为从 headers 解析 | 低（接口不变） |
| `ModuleClient._in_process_call` | `ModuleClient._http_call` | 零（已预留） |
| Celery `_context` 参数 | HTTP Headers | 低 |
| 进程内事件总线 | Kafka + 消息头 | 中 |

### 15.2 微服务模式下的上下文传递

```python
# 未来微服务架构下的上下文中间件
class MicroserviceContextMiddleware:
    """微服务模式：从 HTTP/gRPC 元数据中提取上下文"""
    
    async def dispatch(self, request, call_next):
        # 从上游传递的 Headers 中恢复上下文
        ctx = RequestContext.from_headers(dict(request.headers))
        set_request_context(ctx)
        try:
            return await call_next(request)
        finally:
            clear_request_context()
```
