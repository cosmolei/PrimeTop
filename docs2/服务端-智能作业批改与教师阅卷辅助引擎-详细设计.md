# 服务端-智能作业批改与教师阅卷辅助引擎-详细设计

## 1. 模块概述

### 1.1 功能定位

智能作业批改与教师阅卷辅助引擎是 PrimeTop 教师端核心服务之一，为教师提供从学生作业提交后的 **AI 预批改 → 教师复核确认 → 批改结果回传学生 → 修订重提** 的全链路批改工作流。

该引擎不替代教师评判，而是通过 AI 能力完成「客观题自动判分 + 主观题初筛建议 + 通用批注生成 + 班级共性问题统计」，将教师从重复性批改劳动中解放出来，使其精力聚焦于个性化指导。

### 1.2 与已有模块的边界

| 模块 | 职责边界 | 与本引擎关系 |
|------|----------|-------------|
| 服务端-教师班级管理与作业发布服务 | 作业创建、发布、催交、学生提交管理 | 上游：提供待批改的提交记录 |
| 服务端-练习答题实时批改服务 | 学生在 APP 内练习时的实时自动判分 | 并行：处理 APP 内即时练习，不处理教师布置的作业 |
| 服务端-作文批改评分引擎 | 专门处理作文类题目的深度批改 | 协作：作文类作业调用作文批改引擎，本引擎负责编排与复核 |
| 服务端-理科解题步骤推导服务 | 理科题目的分步解析 | 协作：主观题批改时调用该服务获取标准解题路径 |
| 客户端-学生班级与作业提交页面 | 学生端作业提交 UI | 下游：展示批改结果 |
| 客户端-教师端页面架构 | 教师端批改工作台 UI | 下游：展示预批改建议供教师复核 |

### 1.3 适用场景

| 场景类型 | 示例 | AI 预批改策略 |
|----------|------|-------------|
| 客观题作业 | 选择题、填空题、判断题 | 全自动判分，教师仅复核异常 |
| 计算题作业 | 数学计算、物理求解 | 自动对比答案 + 步骤分析，教师复核关键步骤 |
| 简答题作业 | 名词解释、简述题、翻译题 | AI 生成评分建议与参考批注，教师确认或修改 |
| 作文类作业 | 语文作文、英语作文 | 调用作文批改引擎，教师复核评语 |
| 实验报告作业 | 物理/化学/生物实验报告 | AI 检查格式与关键要素，教师评阅内容深度 |
| 手写拍照作业 | 学生手写拍照提交 | OCR 识别 → 自动判分 / 初筛建议 |

### 2.2 核心服务组件

| 组件 | 职责 | 技术方案 |
|------|------|---------|
| 预批改调度器 (Pre-Grading Dispatcher) | 接收作业提交事件，根据题型路由到对应批改策略 | 策略模式 + 事件驱动 |
| 判分引擎 (Scoring Engine) | 执行自动判分逻辑，输出得分、对错标记 | 规则引擎 + AI 辅助 |
| 批注生成器 (Annotation Generator) | 生成分步骤批注、错误提示、改进建议 | Prompt 模板 + RAG |
| 复核编排器 (Review Orchestrator) | 管理 AI 预批改 → 教师复核 → 确认/修改 → 发布 的状态流转 | 状态机 + 工作流 |
| 评分策略管理器 (Scoring Strategy Manager) | 管理不同题型、学科的评分规则与容错策略 | 规则配置 + 动态加载 |
| 班级统计分析器 (Class Analytics) | 汇总班级批改数据，生成共性错误、分布统计 | 聚合计算 + 缓存 |

## 3. 核心数据模型

### 3.1 PostgreSQL 表结构

#### 3.1.1 homework_submission（作业提交记录）

```sql
CREATE TABLE homework_submission (
    id              BIGSERIAL PRIMARY KEY,
    submission_no   VARCHAR(32) NOT NULL UNIQUE,          -- 提交编号: SUB-YYYYMMDD-XXXXX
    homework_id     BIGINT NOT NULL,                       -- 关联作业ID
    student_id      BIGINT NOT NULL,                       -- 学生ID
    class_id        BIGINT NOT NULL,                       -- 班级ID
    teacher_id      BIGINT NOT NULL,                       -- 布置教师ID
    subject_code    VARCHAR(16) NOT NULL,                  -- 学科代码: MATH/PHYS/CHEM...
    grade_level     SMALLINT NOT NULL,                     -- 年级: 1-12
    submission_type VARCHAR(16) NOT NULL,                  -- 提交方式: ONLINE/PHOTO/MIXED
    status          VARCHAR(24) NOT NULL DEFAULT 'SUBMITTED', -- 见状态机
    submit_time     TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    late_flag       BOOLEAN NOT NULL DEFAULT FALSE,        -- 迟交标记
    grace_period_end TIMESTAMPTZ,                          -- 宽限期截止(迟交允许)
    total_score     DECIMAL(6,2),                          -- 最终总分
    max_score       DECIMAL(6,2) NOT NULL,                 -- 作业满分
    auto_score      DECIMAL(6,2),                          -- AI预批改得分
    final_score     DECIMAL(6,2),                          -- 教师确认后得分
    ai_confidence   DECIMAL(4,3),                          -- AI预批改置信度 0.000-1.000
    teacher_review  VARCHAR(16),                           -- 教师复核结果: CONFIRMED/MODIFIED/OVERRULED
    review_time     TIMESTAMPTZ,                           -- 教师复核时间
    publish_time    TIMESTAMPTZ,                           -- 成绩发布时间
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    CONSTRAINT fk_submission_homework FOREIGN KEY (homework_id) REFERENCES homework(id),
    CONSTRAINT fk_submission_student FOREIGN KEY (student_id) REFERENCES users(id),

    INDEX idx_submission_homework (homework_id, status),
    INDEX idx_submission_teacher_status (teacher_id, status, submit_time),
    INDEX idx_submission_class (class_id, homework_id, status)
);

COMMENT ON TABLE homework_submission IS '学生作业提交主记录';
```

#### 3.1.2 grading_task（批改任务）

```sql
CREATE TABLE grading_task (
    id              BIGSERIAL PRIMARY KEY,
    submission_id   BIGINT NOT NULL,                       -- 关联提交记录
    task_type       VARCHAR(16) NOT NULL,                  -- AUTO/FULL_AUTO/SEMI_AUTO/MANUAL
    question_id     BIGINT NOT NULL,                       -- 关联题目ID
    question_type   VARCHAR(16) NOT NULL,                  -- CHOICE/FILL/JUDGE/SHORT_ANS/ESSAY/CALC/PROOF
    student_answer  JSONB NOT NULL,                        -- 学生作答内容(含文本/图片URL)
    correct_answer  JSONB NOT NULL,                        -- 标准答案
    max_score       DECIMAL(5,2) NOT NULL,                 -- 该题满分
    auto_score      DECIMAL(5,2),                          -- AI判分
    auto_result     VARCHAR(16),                           -- CORRECT/INCORRECT/PARTIAL/REVIEW_NEEDED
    auto_comment    TEXT,                                  -- AI生成批注
    auto_rubric_hit JSONB,                                 -- AI评分点命中情况 [{rubric_id, hit, reason}]
    ai_model_used   VARCHAR(64),                           -- 使用的AI模型标识
    ai_tokens_used  INTEGER,                               -- Token消耗
    ai_latency_ms   INTEGER,                               -- AI处理耗时(毫秒)
    teacher_score   DECIMAL(5,2),                          -- 教师修正分数
    teacher_comment TEXT,                                  -- 教师批注
    teacher_result  VARCHAR(16),                           -- 教师判定的结果
    status          VARCHAR(24) NOT NULL DEFAULT 'PENDING', -- PENDING/AI_GRADING/AI_DONE/TEACHER_REVIEW/GRADED
    sequence_no     SMALLINT NOT NULL,                     -- 题号顺序
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    CONSTRAINT fk_task_submission FOREIGN KEY (submission_id) REFERENCES homework_submission(id),

    INDEX idx_task_submission (submission_id, sequence_no),
    INDEX idx_task_status (status, created_at)
);

COMMENT ON TABLE grading_task IS '单题维度批改任务';
```

#### 3.1.3 grading_rubric（评分规则/评分点）

```sql
CREATE TABLE grading_rubric (
    id              BIGSERIAL PRIMARY KEY,
    question_id     BIGINT NOT NULL,                       -- 关联题目(通用规则时关联到作业题)
    homework_id     BIGINT,                                -- 关联作业(自定义规则)
    rubric_name     VARCHAR(128) NOT NULL,                 -- 规则名称
    rubric_type     VARCHAR(16) NOT NULL,                  -- EXACT_MATCH/KEYWORD/SEMANTIC/STEP_BASED/SCORE_RANGE
    max_score       DECIMAL(5,2) NOT NULL,                 -- 该评分点满分
    rubric_config   JSONB NOT NULL,                        -- 规则配置(见3.2节)
    tolerance       JSONB,                                 -- 容错配置: {case_insensitive, typo_tolerance, ...}
    applies_grade   VARCHAR(32),                           -- 适用学段(可空表示通用)
    created_by      BIGINT NOT NULL,                       -- 创建者(教师/系统)
    created_by_type VARCHAR(16) NOT NULL DEFAULT 'TEACHER', -- TEACHER/SYSTEM
    is_active       BOOLEAN NOT NULL DEFAULT TRUE,
    version         INTEGER NOT NULL DEFAULT 1,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    INDEX idx_rubric_question (question_id, is_active),
    INDEX idx_rubric_homework (homework_id)
);

COMMENT ON TABLE grading_rubric IS '题目/作业级评分规则定义';
```

**rubric_config JSONB 结构示例：**

```jsonc
// EXACT_MATCH 类型
{
  "expected": ["A"],
  "caseSensitive": false,
  "trimWhitespace": true
}

// KEYWORD 类型
{
  "must_include": ["光合作用", "叶绿体"],
  "should_include": ["光反应", "暗反应", "ATP"],
  "keyword_scores": { "光合作用": 2.0, "叶绿体": 1.5, "光反应": 1.0, "暗反应": 1.0 },
  "deduct_per_missing": 0.5
}

// SEMANTIC 类型
{
  "reference_answer": "光合作用是绿色植物利用光能...",
  "semantic_threshold": 0.75,
  "partial_score_ranges": [
    { "min_sim": 0.90, "score_ratio": 1.0 },
    { "min_sim": 0.75, "score_ratio": 0.7 },
    { "min_sim": 0.50, "score_ratio": 0.4 }
  ]
}

// STEP_BASED 类型
{
  "steps": [
    { "step_no": 1, "description": "设未知数x", "score": 1.0, "keywords": ["设", "x"] },
    { "step_no": 2, "description": "列出方程", "score": 2.0, "keywords": ["方程", "="] },
    { "step_no": 3, "description": "求解x", "score": 1.0, "keywords": ["x=", "解得"] },
    { "step_no": 4, "description": "写出答案", "score": 1.0, "keywords": ["答"] }
  ]
}
```

### 4.2 接口详细定义

#### 4.2.1 触发批量预批改

```
POST /api/v1/grading/batch-pre-grade
```

**请求体：**
```json
{
  "homework_id": 123456,
  "class_id": 789,
  "submission_ids": [1001, 1002, 1003],   // 可选，不传则批改该作业所有已提交
  "grading_mode": "FULL_AUTO_FIRST",        // FULL_AUTO_FIRST | SEMI_AUTO_ALL | MANUAL_ONLY
  "priority": "NORMAL",                     // URGENT | NORMAL | LOW
  "callback_url": "/internal/grading/callback"  // 批改完成回调
}
```

**响应体（202 Accepted）：**
```json
{
  "code": 0,
  "data": {
    "batch_id": "BATCH-20260614-001",
    "total": 45,
    "accepted": 45,
    "rejected": 0,
    "estimated_completion_minutes": 8,
    "task_status_url": "/api/v1/grading/batch/BATCH-20260614-001/status"
  }
}
```

**处理逻辑：**

1. 校验 homework_id 和 class_id 的有效性及调用者权限
2. 查询符合条件的 submission 列表（status = SUBMITTED）
3. 检查是否已有正在进行的批改任务（Redis 锁）
4. 按题型分类，创建 grading_task 记录
5. 将任务推入消息队列，按优先级调度
6. 返回 batch_id 供轮询/回调使用

#### 4.2.2 教师复核批改

```
PUT /api/v1/grading/tasks/{grading_task_id}/review
```

**请求体：**

```java
/**
 * 选择题/判断题自动判分
 */
public GradingResult gradeChoice(StudentAnswer answer, CorrectAnswer correct, GradingRubric rubric) {
    // 1. 标准化答案 (去空格、统一大小写)
    String normalizedStudent = normalize(answer.getText(), rubric.getTolerance());
    String normalizedCorrect = normalize(correct.getText(), rubric.getTolerance());

    // 2. 多答案场景 (如多选题)
    Set<String> studentSet = parseAnswerSet(normalizedStudent);
    Set<String> correctSet = parseAnswerSet(normalizedCorrect);

    // 3. 判分
    if (studentSet.equals(correctSet)) {
        return GradingResult.fullScore(rubric.getMaxScore(), "完全正确");
    }

    // 多选题部分给分策略
    if (rubric.getConfig().partialCreditEnabled()) {
        int correctCount = intersection(studentSet, correctSet).size();
        int wrongCount = difference(studentSet, correctSet).size();
        int totalCorrect = correctSet.size();

        double score = (correctCount - wrongCount * rubric.getConfig().wrongPenalty())
                       / totalCorrect * rubric.getMaxScore();
        score = Math.max(0, score);  // 不低于0分

        String comment = formatPartialComment(correctCount, wrongCount, totalCorrect);
        return GradingResult.partial(score, comment);
    }

    return GradingResult.zero("答案不正确");
}
```

```java
 * 简答题/计算题 AI 辅助批改

public Mono<GradingResult> gradeSubjectiveWithAI(
        GradingTask task, GradingRubric rubric, StudentProfile profile) {

    // 1. 构建 AI 批改 Prompt
    GradingPrompt prompt = GradingPromptBuilder.builder()
        .question(task.getQuestion())
        .standardAnswer(task.getCorrectAnswer())
        .studentAnswer(task.getStudentAnswer())
        .rubric(rubric)
        .studentGrade(profile.getGradeLevel())      // 适龄化
        .maxScore(task.getMaxScore())
        .subject(task.getSubjectCode())
        .build();

    // 2. 调用大模型 (流式)
    return aiModelClient.streamChat(prompt.toMessages())
        .timeout(Duration.ofSeconds(15))
        .flatMap(response -> {
            // 3. 解析 AI 返回的评分结构
            AIGradingResult aiResult = parseGradingResponse(response);

            // 4. 校验分数范围
            if (aiResult.getScore().compareTo(task.getMaxScore()) > 0) {
                aiResult.setScore(task.getMaxScore());
                aiResult.addWarning("AI评分超出满分，已截断");
            }

            // 5. 计算置信度
            double confidence = calculateConfidence(aiResult, rubric);

            // 6. 生成批注
            List<Annotation> annotations = generateAnnotations(aiResult, task);

            return Mono.just(GradingResult.builder()
                .score(aiResult.getScore())
                .result(determineResult(aiResult.getScore(), task.getMaxScore()))
                .comment(aiResult.getComment())
                .confidence(confidence)
                .annotations(annotations)
                .rubricHits(aiResult.getRubricHits())
                .modelUsed(response.getModel())
                .tokensUsed(response.getUsage().getTotalTokens())
                .latencyMs(response.getLatencyMs())
                .build());
        })
        .onErrorResume(e -> {
            // 降级：标记为需要手动批改
            log.warn("AI grading failed for task {}", task.getId(), e);
            return Mono.just(GradingResult.manualNeeded("AI批改失败，请手动批改"));
        });
}
```

```java
/**
 * 教师复核批改结果

@Transactional
public ReviewResult reviewGrading(
        Long taskId, Long teacherId, ReviewAction action, ReviewRequest req) {

    GradingTask task = gradingTaskMapper.selectByIdForUpdate(taskId);

    // 1. 状态校验
    if (task.getStatus() != Status.AI_DONE && task.getStatus() != Status.GRADED) {
        throw new BizException(ErrorCode.INVALID_STATUS);
    }

    // 2. 权限校验
    verifyTeacherPermission(task, teacherId);

    ReviewResult result = new ReviewResult();

    switch (action) {
        case CONFIRM:
            // 教师确认AI批改结果
            task.setTeacherScore(task.getAutoScore());
            task.setTeacherResult(task.getAutoResult());
            task.setTeacherComment(req.getComment());  // 可选追加评语
            task.setStatus(Status.GRADED);
            result.setAdjusted(false);
            break;

        case MODIFY:
            // 教师修改分数和批注
            validateScore(req.getScore(), task.getMaxScore());
            task.setTeacherScore(req.getScore());
            task.setTeacherResult(req.getResult());
            task.setTeacherComment(req.getComment());
            task.setStatus(Status.GRADED);

            // 记录AI与教师评分差异(用于AI质量优化)
            recordScoreDelta(task, req.getScore());
            result.setAdjusted(true);
            result.setPreviousScore(task.getAutoScore());
            result.setCurrentScore(req.getScore());
            break;

        case OVERRULE:
            // 完全推翻AI结果，教师重新批改
            task.setTeacherScore(req.getScore());
            task.setTeacherResult(req.getResult());
            task.setTeacherComment(req.getComment());
            task.setStatus(Status.GRADED);
            task.setOverruled(true);
            recordOverrule(task, req.getReason());
            break;

        case MARK_FOR_DISCUSSION:
            // 标记为课堂讨论题
            task.setFlaggedForDiscussion(true);
            task.setDiscussionNote(req.getComment());
            // 状态保持不变
            break;
    }

    // 3. 保存批注
    if (req.getAnnotations() != null && !req.getAnnotations().isEmpty()) {
        saveAnnotations(taskId, teacherId, req.getAnnotations());
    }

    // 4. 更新评分点命中
    if (req.getRubricAdjustments() != null) {
        updateRubricHits(taskId, req.getRubricAdjustments());
    }

    task.setReviewedBy(teacherId);
    task.setReviewedAt(Instant.now());
    gradingTaskMapper.updateById(task);

    // 5. 检查是否所有题目批改完成
    checkSubmissionCompletion(task.getSubmissionId());

    return result;
}
```

```java
/**
```

```java
public Mono<PhotoGradingResult> gradePhotoSubmission(
        Long submissionId, List<String> imageUrls, Long homeworkId) {

    Homework homework = homeworkService.getById(homeworkId);
    List<Question> questions = homework.getQuestions();

    return Flux.fromIterable(imageUrls)
        .flatMap(imageUrl -> {

            return imagePreprocessor.enhance(imageUrl)

                });

        .collectList()
        .flatMap(ocrResults -> {

                ocrResults, questions, homework.getLayoutTemplate());

            // 4. 创建 grading_task 并执行批改

                .map(detected -> buildGradingTask(submissionId, detected, questions))
                .toList();

            return gradingOrchestrator.batchGrade(tasks)
                .doOnNext(result -> {
                    // 6. 标记 OCR 识别不确定的区域
                    markLowConfidenceRegions(ocrResults);
                });
```

```java
@RabbitListener(queues = "grading.auto.subjective", concurrency = "5")
public void handleSubjectiveGrading(GradingMessage message, Channel channel) {
    long deliveryTag = message.getDeliveryTag();

    try {
        GradingTask task = gradingTaskMapper.selectById(message.getPayload().getGradingTaskId());

        // 幂等校验
        if (task.getStatus() != Status.PENDING) {
            channel.basicAck(deliveryTag, false);
            return;
        }

        // 更新状态为AI批改中
        task.setStatus(Status.AI_GRADING);
        gradingTaskMapper.updateById(task);

        // 执行AI批改
        GradingResult result = gradingStrategyManager
            .getStrategy(task.getQuestionType())
            .grade(task);

        // 保存结果
        applyGradingResult(task, result);

        // 检查提交是否全部完成
        gradingOrchestrator.checkSubmissionCompletion(task.getSubmissionId());

        channel.basicAck(deliveryTag, false);

    } catch (AIModelException e) {
        // AI模型异常，重试
        handleRetry(message, e, channel);
    } catch (Exception e) {
        log.error("Grading failed for task {}", message.getPayload().getGradingTaskId(), e);
        // 降级为手动批改
        markManualNeeded(message.getPayload().getGradingTaskId(), e.getMessage());
        channel.basicAck(deliveryTag, false);  // 不重入队列
    }
}
```

```java
/**
 * 定时任务：作业截止后自动触发预批改
 */
@Scheduled(cron = "0 */5 * * * *")  // 每5分钟扫描
public void autoTriggerPreGrading() {
    // 1. 查找已截止但未触发批改的作业
    List<Homework> dueHomework = homeworkService.findDueUngraded();

    for (Homework hw : dueHomework) {
        try {
            // 2. 检查宽限期
            if (hw.getGracePeriodMinutes() > 0) {
                Instant graceEnd = hw.getDueTime()
                    .plus(hw.getGracePeriodMinutes(), ChronoUnit.MINUTES);
                if (Instant.now().isBefore(graceEnd)) {
                    continue;  // 还在宽限期内，等下一轮
                }
            }

            // 3. 获取所有已提交记录
            List<Long> submissionIds = submissionService
                .findSubmittedIds(hw.getId());

            if (submissionIds.isEmpty()) {
                homeworkService.markNoSubmission(hw.getId());
                continue;
            }

            // 4. 触发批量批改
            batchGradingService.triggerBatchPreGrading(
                hw.getId(), hw.getClassId(), submissionIds, GradingMode.FULL_AUTO_FIRST
            );

            // 5. 标记为已触发
            homeworkService.markGradingTriggered(hw.getId());

            // 6. 通知教师
            notificationService.sendTeacherNotification(
                hw.getTeacherId(),
                NotificationType.HOMEWORK_AUTO_GRADING_STARTED,
                Map.of("homework_title", hw.getTitle(),
                       "submission_count", submissionIds.size())
            );

        } catch (Exception e) {
            log.error("Auto trigger grading failed for homework {}", hw.getId(), e);
        }
    }
}
```

## 8. AI 批改质量保障

### 8.1 置信度计算模型

```java
/**
 * AI批改结果置信度计算
 * 综合考虑多个维度评估批改可靠性
 */
public double calculateConfidence(GradingResult result, GradingRubric rubric) {
    // 1. 分数与评分点的匹配度
    double rubricConsistency = calculateRubricConsistency(result.getRubricHits(), rubric);

    // 2. AI回答完整性 (是否所有评分点都有判定)
    double completeness = (double) result.getRubricHits().size() / rubric.getStepCount();

    // 3. 评分极端情况惩罚 (满分和0分置信度降低)
    double scoreExtremity = 1.0;
    double scoreRatio = result.getScore().doubleValue() / rubric.getMaxScore().doubleValue();
    if (scoreRatio == 1.0 || scoreRatio == 0.0) {
        scoreExtremity = 0.85;
    }

    // 4. 模型自报告置信度 (部分模型支持)
    double modelConfidence = result.getModelConfidence() != null
        ? result.getModelConfidence() : 0.8;

    // 5. 综合置信度
    return rubricConsistency * 0.4 + completeness * 0.25 + scoreExtremity * 0.15 + modelConfidence * 0.2;
}
```

### 8.2 置信度路由策略

| 置信度范围 | 路由策略 | 教师视图标记 |
|-----------|---------|-------------|
| ≥ 0.95 | 自动确认 (客观题) 或 优先展示 (主观题) | ✅ 绿色标记 |
| 0.85 ~ 0.95 | 正常进入教师复核队列 | 🔵 蓝色标记 |
| 0.70 ~ 0.85 | 教师复核队列中靠前展示 | 🟡 黄色标记 "建议重点查看" |

```java
private Mono<GradingResult> fallbackToManual(GradingTask task, Throwable e) {
    log.warn("AI grading circuit breaker open for task {}", task.getId(), e);

    GradingTask update = new GradingTask();
    update.setId(task.getId());

        task.getTeacherId(), task.getSubmissionId(), task.getId()
    );

    return Mono.just(GradingResult.manualNeeded("AI服务暂时不可用，已转为手动批改"));
}
```

```java
@Component
public class GradingPermissionAspect {

    @Around("@annotation(RequireGradingPermission)")
    public Object checkPermission(ProceedingJoinPoint pjp) throws Throwable {
        Long teacherId = SecurityContext.getCurrentUserId();
        Long submissionId = extractSubmissionId(pjp);

        // 1. 校验提交记录归属
        HomeworkSubmission sub = submissionMapper.selectById(submissionId);

        // 2. 校验教师与班级关系
        if (!classService.isClassTeacher(teacherId, sub.getClassId())) {
            // 检查是否为年级组长/学科组长(只读权限)
            if (pjp.hasAnnotation(ReadOnly.class)) {
                if (!classService.isGradeLeader(teacherId, sub.getClassId())) {
                    throw new BizException(ErrorCode.FORBIDDEN);
                }
            } else {

        if (sub.getStatus() == Status.PUBLISHED
                && !hasSpecialPermission(teacherId, "grading.modify_published")) {

        }

        return pjp.proceed();
    }
```
