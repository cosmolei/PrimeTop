# 教育内容适龄性评估与分级引擎 - 详细设计

> 版本: 1.0 | 创建: 2026-05-24 | 状态: 初稿

## 1. 概述

### 1.1 问题背景

PrimeTop 覆盖幼儿至高中全学段，同一知识点在不同年级的讲解深度、表达方式、示例难度和术语密度差异巨大。例如"分数"这个概念：
- 小学三年级：把一个披萨切成 4 块，每块是 1/4
- 初中：分数是有理数的一种表示，分子/分母互质时为最简分数
- 高中：分数是实数域中的元素，可以映射到数轴上的点

原始设计文档多处要求"分学段讲解"、"分龄适配"，但当前各模块各自实现适龄逻辑，缺乏统一的内容复杂度评估和适龄分级能力。具体痛点：

1. **AI 输出不可控**：大模型可能用高中生语言回答小学生问题，反之亦然
2. **题目推荐错配**：向低年级学生推荐超纲题目
3. **知识讲解跳跃**：跳过前置概念直接讲解高阶内容
4. **素材推荐不当**：推荐与学段认知水平不符的阅读材料
5. **无量化指标**：无法度量内容的"适龄程度"，只能靠人工审核

### 1.2 模块定位

**教育内容适龄性评估与分级引擎**（AgeFit Engine）是一个跨模块的内容评估服务，负责：
- 对任意文本内容（AI 回复、题目、知识点讲解、素材等）进行复杂度评分
- 将评分映射到目标学段的适龄等级
- 为内容生产/推荐/AI 生成提供适龄约束
- 监控全系统内容的适龄合规率

**本模块不负责：**
- UI 层面的分龄适配 → 见 `分龄UI适配与交互设计规范-详细设计.md`
- Prompt 模板的分龄策略 → 见 `AI-Prompt编排与场景模板系统-详细设计.md`
- 题目 IRT 难度标定 → 见 `题目难度标定与能力评估模型-详细设计.md`
- 学生能力评估 → 见 `用户学习画像与能力维度模型-详细设计.md`

### 1.3 设计目标

| 目标 | 指标 |
|------|------|
| 评估准确率 | 适龄等级与人工标注一致率 ≥ 90% |
| 评估延迟 | 单次文本评估 ≤ 50ms（规则引擎）, ≤ 500ms（模型引擎） |
| 覆盖率 | 全系统 AI 输出、题目、知识讲解 100% 经过评估 |
| 可解释性 | 每次评估输出具体不达标维度和修改建议 |
| 成本 | 规则引擎零模型调用成本，模型引擎仅对规则不确定样本调用 |

## 2. 核心概念与数据模型

### 2.1 适龄等级定义

系统定义 5 个适龄等级，覆盖从幼儿到高中的完整学段：

```python
class AgeFitLevel(str, Enum):
    """内容适龄等级"""
    LEVEL_1 = "L1"  # 幼儿启蒙 (3-6岁)：无专业术语，图像化描述，短句
    LEVEL_2 = "L2"  # 小学低段 (6-9岁)：简单词汇，生活化类比，短段落
    LEVEL_3 = "L3"  # 小学高段 (9-12岁)：基础学科术语，简单推理，中等段落
    LEVEL_4 = "L4"  # 初中 (12-15岁)：学科标准术语，多步推理，长段落
    LEVEL_5 = "L5"  # 高中 (15-18岁)：专业术语，复杂推理，抽象建模

    @classmethod
    def from_grade(cls, grade: "GradeEnum") -> "AgeFitLevel":
        """根据年级映射适龄等级"""
        mapping = {
            "K1": cls.LEVEL_1, "K2": cls.LEVEL_1, "K3": cls.LEVEL_1,
            "G1": cls.LEVEL_2, "G2": cls.LEVEL_2, "G3": cls.LEVEL_2,
            "G4": cls.LEVEL_3, "G5": cls.LEVEL_3, "G6": cls.LEVEL_3,
            "G7": cls.LEVEL_4, "G8": cls.LEVEL_4, "G9": cls.LEVEL_4,
            "G10": cls.LEVEL_5, "G11": cls.LEVEL_5, "G12": cls.LEVEL_5,
        }
        return mapping.get(grade, cls.LEVEL_3)  # 默认小学高段
```

### 2.2 内容复杂度维度

评估内容时从 6 个独立维度打分，每个维度 1-5 分：

```python
class ComplexityDimension(str, Enum):
    """内容复杂度评估维度"""
    VOCABULARY = "vocabulary"        # 词汇复杂度：专业术语密度、生僻字比例
    SENTENCE = "sentence"            # 句式复杂度：句子长度、从句嵌套、修辞手法
    CONCEPT = "concept"              # 概念深度：前置知识要求、抽象程度
    REASONING = "reasoning"          # 推理复杂度：逻辑步骤数、思维转换次数
    EXPRESSION = "expression"        # 表达密度：信息密度、单位文本信息量
    DOMAIN_TERM = "domain_term"      # 学科术语：学科专属概念和符号的使用频率


class ComplexityScore:
    """内容复杂度评分"""
    vocabulary: float     # 1.0-5.0
    sentence: float       # 1.0-5.0
    concept: float        # 1.0-5.0
    reasoning: float      # 1.0-5.0
    expression: float     # 1.0-5.0
    domain_term: float    # 1.0-5.0

    @property
    def overall(self) -> float:
        """加权综合评分"""
        weights = {
            "vocabulary": 0.20,
            "sentence": 0.15,
            "concept": 0.25,
            "reasoning": 0.20,
            "expression": 0.10,
            "domain_term": 0.10,
        }
        return sum(getattr(self, k) * w for k, w in weights.items())

    def to_age_fit_level(self) -> AgeFitLevel:
        """综合评分映射到适龄等级"""
        score = self.overall
        if score <= 1.5: return AgeFitLevel.LEVEL_1
        elif score <= 2.3: return AgeFitLevel.LEVEL_2
        elif score <= 3.1: return AgeFitLevel.LEVEL_3
        elif score <= 3.9: return AgeFitLevel.LEVEL_4
        else: return AgeFitLevel.LEVEL_5
```

## 3. 评估引擎架构

### 3.1 两级评估架构

系统采用"规则引擎优先 + 模型引擎兜底"的两级评估架构：

```
               ┌─────────────────┐
               │   输入内容       │
               │  + 目标适龄等级   │
               └────────┬────────┘
                        │
               ┌────────▼────────┐
               │  L1: 规则引擎    │
               │  (正则 + 词典    │
               │   + 统计特征)    │
               └────────┬────────┘
                        │
                ┌───────┴───────┐
                │ confidence ≥  │
                │    0.85?      │
                ├───Yes────┐──No┤
                │          │    │
           ┌────▼───┐      │ ┌──▼─────────┐
           │ 直接输出 │      │ │ L2: 模型引擎│
           │ 结果     │      │ │ (轻量分类器)│
           └─────────┘      │ └──────┬─────┘
                            │        │
                            │   ┌────▼─────┐
                            │   │ 输出结果   │
                            │   └──────────┘
                            │
                       ┌────▼────────────┐
                       │ 异步写入评估记录  │
                       │ + 更新缓存       │
                       └─────────────────┘
```

### 3.2 规则引擎

规则引擎基于可量化的文本统计特征，无模型调用成本：

```python
class RuleBasedEvaluator:
    """规则引擎：基于统计特征和词典匹配"""

    def __init__(self, db: AsyncSession, redis: Redis):
        self.db = db
        self.redis = redis
        self._vocab_cache: Dict[int, Set[str]] = {}  # level -> word set
        self._term_cache: Dict[str, Dict[str, int]] = {}  # subject -> {term -> min_level}

    async def evaluate(
        self, text: str, target_level: AgeFitLevel, subject: str = None
    ) -> "EvaluationResult":
        """评估内容的适龄性"""

        # 1. 预处理：分句、分词
        sentences = self._split_sentences(text)
        words = self._tokenize(text)

        # 2. 逐维度打分
        scores = ComplexityScore()
        scores.vocabulary = await self._score_vocabulary(words, target_level)
        scores.sentence = self._score_sentence_complexity(sentences, target_level)
        scores.concept = await self._score_concept_depth(text, target_level, subject)
        scores.reasoning = self._score_reasoning_complexity(text, target_level)
        scores.expression = self._score_expression_density(text, sentences)
        scores.domain_term = await self._score_domain_terms(text, target_level, subject)

        # 3. 综合评级
        scored_level = scores.to_age_fit_level()
        is_fit = self._is_level_compatible(scored_level, target_level)

        # 4. 收集超标细节
        detail = self._collect_violations(text, scores, target_level)

        # 5. 计算置信度
        confidence = self._calculate_confidence(scores)

        return EvaluationResult(
            scores=scores,
            scored_level=scored_level,
            is_fit=is_fit,
            confidence=confidence,
            detail=detail,
            method="rule",
        )

    async def _score_vocabulary(
        self, words: List[str], target_level: AgeFitLevel
    ) -> float:
        """词汇复杂度评分"""
        if not words:
            return 1.0

        level_value = {"L1": 1, "L2": 2, "L3": 3, "L4": 4, "L5": 5}[target_level.value]

        # 统计超纲词汇比例
        vocab_set = await self._get_vocab_for_level(level_value)
        over_level_count = 0
        over_level_words = []

        for word in words:
            word_level = await self._get_word_level(word)
            if word_level and word_level > level_value:
                over_level_count += 1
                over_level_words.append((word, word_level))

        ratio = over_level_count / len(words) if words else 0

        # 超纲率映射到分数
        # 0% -> 1.0, 5% -> 2.0, 10% -> 3.0, 20% -> 4.0, 30%+ -> 5.0
        if ratio <= 0.01: return 1.0
        elif ratio <= 0.05: return 2.0
        elif ratio <= 0.10: return 3.0
        elif ratio <= 0.20: return 4.0
        else: return 5.0

    def _score_sentence_complexity(
        self, sentences: List[str], target_level: AgeFitLevel
    ) -> float:
        """句式复杂度评分"""
        if not sentences:
            return 1.0

        # 平均句长（中文字符数）
        avg_len = sum(len(self._remove_punct(s)) for s in sentences) / len(sentences)

        # 从句/修饰语密度（通过逗号、顿号、关联词近似估算）
        clause_markers = ["，", "、", "因为", "所以", "虽然", "但是", "如果", "那么", "既然", "因此"]
        clause_count = sum(
            sum(1 for m in clause_markers if m in s) for s in sentences
        )
        clause_density = clause_count / len(sentences)

        # 长句比例（超过 target 等级标准句长的句子占比）
        max_lengths = {"L1": 15, "L2": 20, "L3": 30, "L4": 40, "L5": 50}
        threshold = max_lengths[target_level.value]
        long_ratio = sum(1 for s in sentences if len(s) > threshold) / len(sentences)

        # 综合评分
        score = 1.0
        if avg_len > threshold * 1.5: score += 1.0
        if clause_density > 1.5: score += 0.5
        if long_ratio > 0.3: score += 0.5
        if avg_len > threshold * 2.0: score += 1.0
        if clause_density > 3.0: score += 1.0

        return min(score, 5.0)

    async def _score_concept_depth(
        self, text: str, target_level: AgeFitLevel, subject: str = None
    ) -> float:
        """概念深度评分：检测是否使用了超出目标等级的抽象概念"""
        level_value = {"L1": 1, "L2": 2, "L3": 3, "L4": 4, "L5": 5}[target_level.value]

        # 抽象概念标记词
        abstract_markers = {
            3: ["概念", "原理", "规律", "性质", "定理", "定义"],
            4: ["模型", "假设", "推导", "证明", "归纳", "演绎", "公理"],
            5: ["范式", "映射", "同构", "变换", "张量", "矩阵变换", "傅里叶"],
        }

        # 计算使用的抽象概念中超出目标等级的数量
        over_level_concepts = 0
        for concept_level, markers in abstract_markers.items():
            if concept_level > level_value:
                for marker in markers:
                    if marker in text:
                        over_level_concepts += 1

        # 抽象概念数量映射
        if over_level_concepts == 0: return min(level_value, 3.0)
        elif over_level_concepts <= 1: return level_value + 0.5
        elif over_level_concepts <= 3: return level_value + 1.0
        else: return min(level_value + 2.0, 5.0)

    def _score_reasoning_complexity(
        self, text: str, target_level: AgeFitLevel
    ) -> float:
        """推理复杂度评分"""
        # 推理步骤标记词
        step_markers = [
            "首先", "其次", "然后", "接着", "最后", "因此", "所以",
            "第一步", "第二步", "第三步", "第四步", "第五步",
            "已知", "求证", "证明", "因为", "可得",
        ]
        step_count = sum(1 for m in step_markers if m in text)

        # 条件嵌套深度（"如果...那么如果...那么"模式）
        conditional_count = text.count("如果") + text.count("若") + text.count("假设")

        # 映射到分数
        if step_count <= 1 and conditional_count == 0: return 1.0
        elif step_count <= 2 and conditional_count <= 1: return 2.0
        elif step_count <= 4 and conditional_count <= 2: return 3.0
        elif step_count <= 6 and conditional_count <= 3: return 4.0
        else: return 5.0

    def _score_expression_density(
        self, text: str, sentences: List[str]
    ) -> float:
        """表达密度评分：单位文本中的信息量"""
        if not text:
            return 1.0

        # 公式/符号密度
        formula_markers = ["=", "+", "-", "×", "÷", "²", "³", "√", "∫", "∑", "π"]
        formula_count = sum(text.count(m) for m in formula_markers)

        # 列表/枚举密度
        list_markers = ["①", "②", "③", "1.", "2.", "3.", "•", "-"]
        list_count = sum(text.count(m) for m in list_markers)

        chars = len(text)
        density = (formula_count + list_count * 2) / max(chars / 100, 1)

        if density <= 0.5: return 1.0
        elif density <= 1.0: return 2.0
        elif density <= 2.0: return 3.0
        elif density <= 4.0: return 4.0
        else: return 5.0

    async def _score_domain_terms(
        self, text: str, target_level: AgeFitLevel, subject: str = None
    ) -> float:
        """学科术语复杂度评分"""
        level_value = {"L1": 1, "L2": 2, "L3": 3, "L4": 4, "L5": 5}[target_level.value]

        term_registry = await self._get_term_registry(subject)
        over_level_terms = 0
        over_level_list = []

        for term, min_level in term_registry.items():
            if term in text and min_level > level_value:
                over_level_terms += 1
                over_level_list.append((term, min_level))

        if over_level_terms == 0: return 1.0
        elif over_level_terms <= 1: return 3.0
        elif over_level_terms <= 3: return 4.0
        else: return 5.0

    def _is_level_compatible(
        self, scored: AgeFitLevel, target: AgeFitLevel
    ) -> bool:
        """判断评估等级是否兼容目标等级（允许低1级，不允许高）"""
        level_order = {"L1": 1, "L2": 2, "L3": 3, "L4": 4, "L5": 5}
        return level_order[scored.value] <= level_order[target.value]

    def _calculate_confidence(self, scores: ComplexityScore) -> float:
        """计算规则引擎置信度"""
        score_values = [
            scores.vocabulary, scores.sentence, scores.concept,
            scores.reasoning, scores.expression, scores.domain_term,
        ]
        # 各维度方差越小，置信度越高（评分一致 = 规则引擎足够判断）
        import statistics
        variance = statistics.variance(score_values)
        # 方差 < 0.5 → 高置信度，方差 > 2.0 → 低置信度
        if variance <= 0.3: return 0.95
        elif variance <= 0.8: return 0.85
        elif variance <= 1.5: return 0.70
        else: return 0.50

    def _collect_violations(
        self, text: str, scores: ComplexityScore, target_level: AgeFitLevel
    ) -> dict:
        """收集具体的超标项"""
        violations = []

        # 词汇超标
        if scores.vocabulary > {"L1": 1.5, "L2": 2.5, "L3": 3.5, "L4": 4.5, "L5": 5.0}[target_level.value]:
            violations.append({
                "dimension": "vocabulary",
                "severity": "high",
                "message": f"词汇复杂度 {scores.vocabulary:.1f} 超出目标等级阈值",
                "suggestion": "替换为更简单的同义词或添加解释",
            })

        # 句式超标
        if scores.sentence > {"L1": 2.0, "L2": 2.5, "L3": 3.5, "L4": 4.5, "L5": 5.0}[target_level.value]:
            violations.append({
                "dimension": "sentence",
                "severity": "medium",
                "message": f"句式复杂度 {scores.sentence:.1f} 超出目标等级",
                "suggestion": "拆分长句，减少从句嵌套",
            })

        # 概念深度超标
        if scores.concept > {"L1": 1.5, "L2": 2.5, "L3": 3.5, "L4": 4.5, "L5": 5.0}[target_level.value]:
            violations.append({
                "dimension": "concept",
                "severity": "high",
                "message": f"概念深度 {scores.concept:.1f} 超出目标等级",
                "suggestion": "添加前置概念说明或使用类比解释",
            })

        return {
            "violations": violations,
            "total_score": scores.overall,
            "scored_level": scores.to_age_fit_level().value,
        }
