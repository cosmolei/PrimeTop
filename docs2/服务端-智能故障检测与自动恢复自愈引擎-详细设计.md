# 服务端 - 智能故障检测与自动恢复自愈引擎 详细设计

## 1. 概述

### 1.1 功能定位

智能故障检测与自动恢复自愈引擎（Intelligent Fault Detection & Auto-Remediation Engine，简称 iFARE）是 PrimeTop 平台的生产级可靠性基础设施，负责实时感知服务异常、自动执行恢复策略、降低人工干预频率，保障学生在学习过程中获得连续稳定的服务体验。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 快速感知 | 服务异常发生后 30 秒内完成检测与确认 |
| 自动恢复 | 80% 以上的常见故障无需人工介入即可自动恢复 |
| 安全可控 | 所有自愈操作可回滚、可审计、可人工覆盖 |
| 噪音抑制 | 告警聚合与关联分析，避免告警风暴 |
| 持续学习 | 基于历史故障数据优化检测规则与恢复策略 |

### 1.3 适用范围

- 覆盖所有微服务（用户服务、学习服务、AI 服务、题目服务、错题服务、内容服务、支付服务、消息服务等）
- 覆盖基础设施组件（MySQL、Redis、Elasticsearch、Milvus、对象存储、消息队列）
- 覆盖 AI 模型调用链路（大模型 API、OCR、ASR/TTS）
- 覆盖 K8s 集群节点与网络

### 1.4 与现有系统的关系

| 现有系统 | 关系 |
| --- | --- |
| SLO 服务等级目标管理 | iFARE 消费 SLO 指标作为故障检测信号源 |
| 健康检查与服务就绪探针 | iFARE 复用探针数据，并在此基础上做趋势分析与预测 |
| 日志与监控告警体系 | iFARE 接收告警事件作为输入，进行关联分析与降噪 |
| 错误处理与服务降级策略 | iFARE 在自动恢复失败后触发降级策略 |
| 优雅停机与流量排空 | iFARE 可触发优雅停机作为恢复手段之一 |
| 混沌工程验证平台 | 混沌工程注入故障验证 iFARE 的检测与恢复能力 |
| 分布式链路追踪 | iFARE 利用 trace 数据定位故障根因 |

### 4.1 信号采集与预处理层

#### 4.1.1 MetricStream - 指标流处理器

负责从 Prometheus / VictoriaMetrics 拉取时序指标，进行实时滑动窗口计算。

```python
from dataclasses import dataclass, field
from typing import Callable
from collections import deque
import time

@dataclass
class MetricSample:
    """单个指标采样"""
    service: str
    instance: str
    metric_name: str
    value: float
    timestamp: float
    labels: dict = field(default_factory=dict)


class MetricStreamProcessor:
    """指标流处理器：滑动窗口聚合与基线对比"""

    def __init__(self, window_size: int = 60, slide_interval: int = 10):
        self.window_size = window_size  # 窗口大小（秒）
        self.slide_interval = slide_interval  # 滑动间隔（秒）
        self._windows: dict[str, deque] = {}  # key -> deque[MetricSample]
        self._baselines: dict[str, tuple[float, float]] = {}  # key -> (mean, std)

    def ingest(self, sample: MetricSample):
        """摄入一个指标采样"""
        key = f"{sample.service}:{sample.instance}:{sample.metric_name}"
        if key not in self._windows:
            self._windows[key] = deque(maxlen=self.window_size // self.slide_interval + 1)
        self._windows[key].append(sample)

    def compute_stats(self, key: str) -> dict | None:
        """计算窗口内的统计值"""
        samples = self._windows.get(key)
        if not samples or len(samples) < 3:
            return None
        values = [s.value for s in samples]
        mean = sum(values) / len(values)
        variance = sum((v - mean) ** 2 for v in values) / len(values)
        std = variance ** 0.5
        return {
            "mean": mean,
            "std": std,
            "min": min(values),
            "max": max(values),
            "latest": values[-1],
            "count": len(values),
        }

    def detect_anomalies(self) -> list[dict]:
        """检测窗口内的异常"""
        anomalies = []
        for key, samples in self._windows.items():
            stats = self.compute_stats(key)
            if not stats or stats["count"] < 5:
                continue

            latest = stats["latest"]
            mean = stats["mean"]
            std = stats["std"]

            # 1. 阈值检测：超出硬编码阈值
            threshold = self._get_threshold(key)
            if threshold and latest > threshold:
                anomalies.append({
                    "key": key,
                    "type": "THRESHOLD",
                    "value": latest,
                    "threshold": threshold,
                    "severity": self._calc_severity(latest, threshold),
                })

            # 2. Z-Score 异常检测：偏离均值超过3个标准差
            if std > 0:
                z_score = abs(latest - mean) / std
                if z_score > 3.0:
                    anomalies.append({
                        "key": key,
                        "type": "Z_SCORE",
                        "value": latest,
                        "mean": mean,
                        "std": std,
                        "z_score": z_score,
                        "severity": 2 if z_score > 5 else 1,
                    })

            # 3. 突变检测：环比变化率超过阈值
            if len(samples) >= 2:
                prev = samples[-2].value
                if prev > 0:
                    change_rate = abs(latest - prev) / prev
                    if change_rate > 0.5:  # 50%变化
                        anomalies.append({
                            "key": key,
                            "type": "SPIKE",
                            "value": latest,
                            "previous": prev,
                            "change_rate": change_rate,
                            "severity": 2 if change_rate > 1.0 else 1,
                        })

        return anomalies

    def _get_threshold(self, key: str) -> float | None:
        """获取指标阈值配置"""
        # 实际从配置中心读取
        thresholds = {
            "error_rate": 0.05,        # 错误率 > 5%
            "p99_latency_ms": 3000,     # P99延迟 > 3s
            "cpu_usage": 0.90,          # CPU使用率 > 90%
            "memory_usage": 0.90,       # 内存使用率 > 90%
            "disk_usage": 0.85,         # 磁盘使用率 > 85%
            "connection_pool_usage": 0.90,
            "queue_depth": 10000,
        }
        metric_name = key.split(":")[-1]
        return thresholds.get(metric_name)

    def _calc_severity(self, value: float, threshold: float) -> int:
        if value > threshold * 2:
            return 3  # FATAL
        elif value > threshold * 1.5:
            return 2  # CRITICAL
        else:
            return 1  # WARNING
```

#### 4.1.2 LogPatternExtractor - 日志模式提取器

```python
import re
from collections import Counter, defaultdict

class LogPatternExtractor:
    """从日志流中提取异常模式"""

    # 预定义的错误模式
    ERROR_PATTERNS = [
        re.compile(r'(?i)exception|error|fatal|panic|oom|stack\s*trace'),
        re.compile(r'connection\s*(refused|timeout|reset|closed)'),
        re.compile(r'(?i)out\s*of\s*memory'),
        re.compile(r'(?i)deadlock\s*detected'),
        re.compile(r'(?i)circuit\s*breaker\s*(open|tripped)'),
        re.compile(r'(?i)rate\s*limit\s*exceeded|429'),
        re.compile(r'(?i)upstream\s*(timeout|error|unavailable)|502|503|504'),
        re.compile(r'(?i)database\s*(timeout|connection\s*lost|too\s*many\s*connections)'),
    ]

    def __init__(self, window_seconds: int = 60):
        self.window_seconds = window_seconds
        self._error_counts: dict[str, Counter] = defaultdict(Counter)
        self._normal_baseline: dict[str, int] = {}

    def process_log(self, service: str, log_line: str, timestamp: float):
        """处理单条日志"""
        for pattern in self.ERROR_PATTERNS:
            match = pattern.search(log_line)
            if match:
                # 提取错误类型（归一化）
                error_type = self._normalize_error(match.group())
                self._error_counts[service][error_type] += 1
                return {
                    "service": service,
                    "error_type": error_type,
                    "matched_text": match.group(),
                    "raw_log": log_line[:500],  # 截取前500字符
                    "timestamp": timestamp,
                }
        return None

    def _normalize_error(self, text: str) -> str:
        text = text.lower().strip()
        if 'timeout' in text:
            return 'TIMEOUT'
        elif 'connection' in text and any(w in text for w in ['refused', 'reset', 'closed', 'lost']):
            return 'CONNECTION_FAILURE'
        elif 'oom' in text or 'out of memory' in text:
            return 'OOM'
        elif 'deadlock' in text:
            return 'DEADLOCK'
        elif 'circuit' in text:
            return 'CIRCUIT_BREAKER_OPEN'
        elif 'rate' in text and 'limit' in text:
            return 'RATE_LIMITED'
        elif any(code in text for code in ['502', '503', '504', 'upstream']):
            return 'UPSTREAM_ERROR'
        elif '429' in text:
            return 'RATE_LIMITED'
        elif 'database' in text:
            return 'DB_ERROR'
        else:
            return 'GENERIC_ERROR'

    def check_error_burst(self, service: str) -> dict | None:
        """检查错误是否突发增长"""
        counter = self._error_counts.get(service)
        if not counter:
            return None
        total = sum(counter.values())
        baseline = self._normal_baseline.get(service, 10)
        if total > baseline * 5:  # 错误量是基线的5倍以上
            return {
                "service": service,
                "total_errors": total,
                "baseline": baseline,
                "top_errors": counter.most_common(3),
            }
        return None

    def reset_window(self):
        """重置时间窗口"""
        self._error_counts.clear()
```

### 4.2 告警关联与根因分析

#### 4.2.1 AlertCorrelator - 告警关联器

将时间窗口内相关的异常信号聚合为一个故障事件。

```python
from datetime import datetime, timedelta

class AlertCorrelator:
    """告警关联器：时间窗口 + 拓扑关系双维度聚合"""

    def __init__(self, dependency_resolver, time_window_seconds: int = 120):
        self.dependency_resolver = dependency_resolver
        self.time_window = timedelta(seconds=time_window_seconds)
        self._pending_signals: list[dict] = []

    def add_signal(self, signal: dict) -> dict | None:
        """
        添加异常信号，如果关联形成事件则返回事件
        """
        now = datetime.utcnow()
        signal["received_at"] = now

        # 清理过期信号
        self._pending_signals = [
            s for s in self._pending_signals
            if now - s["received_at"] <= self.time_window
        ]

        # 寻找关联的已有信号
        related = self._find_related(signal)

        self._pending_signals.append(signal)

        # 如果关联信号数量达到阈值，形成事件
        if len(related) >= 2:
            event = self._create_incident(related + [signal])
            # 从pending中移除已关联的信号
            related_ids = {id(s) for s in related}
            self._pending_signals = [
                s for s in self._pending_signals if id(s) not in related_ids
            ]
            return event
        return None

    def _find_related(self, signal: dict) -> list[dict]:
        """找到与当前信号关联的其他信号"""
        related = []
        signal_service = signal.get("source_service", "")

        for existing in self._pending_signals:
            existing_service = existing.get("source_service", "")

            # 1. 同服务
            if signal_service == existing_service:
                related.append(existing)
                continue

            # 2. 上下游依赖关系
            if self.dependency_resolver.has_dependency(signal_service, existing_service):
                related.append(existing)
                continue

            # 3. 同信号类型（跨服务同一故障的表现）
            if signal.get("signal_key") == existing.get("signal_key"):
                related.append(existing)

        return related

    def _create_incident(self, signals: list[dict]) -> dict:
        """从关联信号创建故障事件"""
        services = list({s["source_service"] for s in signals})
        max_severity = max(s.get("severity", 1) for s in signals)
        root_cause = self._guess_root_cause(signals)

        return {
            "title": f"{'/'.join(services[:3])} 服务异常",
            "severity": max_severity,
            "affected_services": services,
            "signals": [s.get("signal_id") for s in signals],
            "root_cause_guess": root_cause,
            "detection_time": datetime.utcnow().isoformat(),
        }

    def _guess_root_cause(self, signals: list[dict]) -> str:
        """
        基于拓扑图推断根因：
        在依赖链中最下游（被依赖最多）的异常服务通常是根因
        """
        service_scores: dict[str, int] = {}
        for signal in signals:
            svc = signal["source_service"]
            # 被其他异常服务依赖的次数越多，越可能是根因
            dependents = self.dependency_resolver.get_dependents(svc)
            service_scores[svc] = sum(
                1 for d in dependents
                if any(s["source_service"] == d for s in signals)
            )

        if not service_scores:
            return "UNKNOWN"

        root = max(service_scores, key=service_scores.get)
        return f"{root} (依赖得分: {service_scores[root]})"
```

```python
class ServiceDependencyResolver:
    """服务依赖关系解析器"""

    def __init__(self):
        # 邻接表表示的依赖图
        # dependencies[A] = {B, C} 表示 A 依赖 B 和 C
        self._dependencies: dict[str, set[str]] = {}
        # 反向依赖：dependents[B] = {A, C} 表示 B 被 A 和 C 依赖
        self._dependents: dict[str, set[str]] = {}

    def register_dependency(self, upstream: str, downstream: str):
        """注册依赖关系"""
        self._dependencies.setdefault(upstream, set()).add(downstream)
        self._dependents.setdefault(downstream, set()).add(upstream)

    def has_dependency(self, a: str, b: str) -> bool:
        """a 和 b 之间是否有直接依赖关系"""
        return (b in self._dependencies.get(a, set()) or
                a in self._dependencies.get(b, set()))

    def get_dependents(self, service: str) -> set[str]:
        """获取直接依赖该服务的上游服务"""
        return self._dependents.get(service, set())

    def get_dependencies(self, service: str) -> set[str]:
        """获取该服务直接依赖的下游服务"""
        return self._dependencies.get(service, set())

    def get_blast_radius(self, service: str, depth: int = 2) -> set[str]:
        """获取故障爆炸半径（向上传播depth层）"""
        affected = {service}
        frontier = {service}
        for _ in range(depth):
            next_frontier = set()
            for svc in frontier:
                next_frontier.update(self.get_dependents(svc))
            next_frontier -= affected
            affected.update(next_frontier)
            frontier = next_frontier
            if not frontier:
                break
        return affected
```

```python
from dataclasses import dataclass
from typing import Any
import json

@dataclass
class RemediationAction:
    """单个恢复动作"""
    action_type: str          # RESTART_POD / SCALE_UP / FLUSH_CACHE / 
                              # CIRCUIT_BREAKER_OPEN / FAILOVER / 
                              # DRAIN_AND_REPLACE / NOTIFY_ONCALL
    target: dict              # 动作目标
    params: dict              # 动作参数
    timeout_seconds: int = 60 # 超时时间
    retry_count: int = 1      # 重试次数


class PlaybookMatchEngine:
    """自愈策略匹配引擎"""

    def __init__(self, playbook_store, dependency_resolver):
        self.playbook_store = playbook_store
        self.dependency_resolver = dependency_resolver
        self._recent_executions: dict[str, float] = {}  # service -> last_execution_time

    def match(self, incident: dict) -> dict | None:
        """
        根据故障事件匹配最佳恢复策略
        返回: {playbook, actions, estimated_time} 或 None
        """
        affected_services = incident.get("affected_services", [])
        root_cause = incident.get("root_cause_guess", "")
        severity = incident.get("severity", 1)

        # 获取所有启用的策略，按优先级排序
        playbooks = self.playbook_store.get_enabled_playbooks()

        candidates = []
        for playbook in playbooks:
            score = self._calculate_match_score(playbook, incident)
            if score > 0:
                # 检查冷却时间
                if self._in_cooldown(playbook, affected_services):
                    continue
                candidates.append((score, playbook))

        if not candidates:
            return None

        # 选择得分最高的策略
        candidates.sort(key=lambda x: -x[0])
        best_score, best_playbook = candidates[0]

        # 构建执行计划
        actions = self._build_execution_plan(best_playbook, incident)
        estimated_time = sum(a.timeout_seconds for a in actions)

        return {
            "playbook_id": best_playbook["playbook_id"],
            "playbook_name": best_playbook["name"],
            "match_score": best_score,
            "actions": [self._action_to_dict(a) for a in actions],
            "estimated_recovery_seconds": estimated_time,
            "rollback_available": bool(best_playbook.get("rollback_actions")),
        }

    def _calculate_match_score(self, playbook: dict, incident: dict) -> float:
        """计算策略与事件的匹配度"""
        score = 0.0
        condition = playbook["trigger_condition"]

        # 匹配服务
        target_services = condition.get("services", [])
        affected = set(incident.get("affected_services", []))
        if target_services:
            matched = affected & set(target_services)
            if matched:
                score += 40 * (len(matched) / len(target_services))
            else:
                return 0  # 服务不匹配，直接排除

        # 匹配信号类型
        signal_types = condition.get("signal_types", [])
        incident_signals = set()
        for sig in incident.get("signals", []):
            incident_signals.add(sig.get("signal_key", ""))
        if signal_types:
            matched_signals = incident_signals & set(signal_types)
            if matched_signals:
                score += 30

        # 匹配严重度
        min_severity = condition.get("min_severity", 1)
        if incident.get("severity", 0) >= min_severity:
            score += 15

        # 历史成功率加权
        success_rate = playbook.get("success_rate", 0)
        score *= (0.5 + success_rate)  # 成功率越高，得分越高

        # 执行次数惩罚（执行次数过多的策略可能需要重新评估）
        total_exec = playbook.get("total_executions", 0)
        if total_exec > 50:
            score *= 0.8

        return score

    def _in_cooldown(self, playbook: dict, services: list[str]) -> bool:
        """检查策略是否在冷却期内"""
        cooldown = playbook.get("cooldown_seconds", 300)
        key = f"{playbook['playbook_id']}"
        last_exec = self._recent_executions.get(key, 0)
        import time
        return (time.time() - last_exec) < cooldown

    def _build_execution_plan(self, playbook: dict, incident: dict) -> list[RemediationAction]:
        """构建执行动作序列"""
        actions_data = playbook["actions"]
        actions = []

        for action_data in actions_data:
            action = RemediationAction(
                action_type=action_data["type"],
                target=self._resolve_target(action_data.get("target", {}), incident),
                params=action_data.get("params", {}),
                timeout_seconds=action_data.get("timeout_seconds", 60),
                retry_count=action_data.get("retry_count", 1),
            )
            actions.append(action)

        return actions

    def _resolve_target(self, target_template: dict, incident: dict) -> dict:
        """解析目标模板中的变量"""
        resolved = {}
        for k, v in target_template.items():
            if isinstance(v, str) and v.startswith("${"):
                # 变量替换：${incident.affected_services[0]}
                var_name = v[2:-1]
                resolved[k] = self._extract_variable(var_name, incident)
            else:
                resolved[k] = v
        return resolved

    def _extract_variable(self, path: str, data: dict) -> Any:
        """从事件数据中提取变量值"""
        parts = path.split(".")
        current = data
        for part in parts:
            if "[" in part:
                key = part.split("[")[0]
                idx = int(part[part.index("[") + 1:part.index("]")])
                current = current.get(key, [])[idx]
            else:
                current = current.get(part)
        return current

    def _action_to_dict(self, action: RemediationAction) -> dict:
        return {
            "type": action.action_type,
            "target": action.target,
            "params": action.params,
            "timeout_seconds": action.timeout_seconds,
        }
```

```python
class SafetyGuard:
    """安全检查守卫：在执行前验证操作的安全性"""

    # 危险动作白名单（需要人工确认）
    DANGEROUS_ACTIONS = {
        "SCALE_DOWN",          # 缩容
        "DELETE_POD",          # 删除Pod
        "FLUSH_ALL_CACHE",     # 清空全部缓存
        "DATABASE_FAILOVER",   # 数据库主从切换
        "SHUTDOWN_SERVICE",    # 关闭服务
    }

    # 受保护的服务（不可自动重启）
    PROTECTED_SERVICES = {
        "mysql-primary",
        "payment-gateway",
    }

    def __init__(self, dependency_resolver, config_center):
        self.dependency_resolver = dependency_resolver
        self.config = config_center

    def validate(self, action: dict, incident: dict) -> dict:
        """
        验证动作安全性
        返回: {approved: bool, reason: str, requires_human: bool}
        """
        action_type = action["action_type"]
        target_service = action.get("target", {}).get("service", "")

        # 检查1：受保护服务
        if target_service in self.PROTECTED_SERVICES:
            return {
                "approved": False,
                "reason": f"受保护服务 {target_service} 禁止自动操作",
                "requires_human": True,
            }

        # 检查2：危险动作
        if action_type in self.DANGEROUS_ACTIONS:
            # 检查是否在允许的时间窗口内（低峰期允许更多自动操作）
            if not self._is_within_safe_window():
                return {
                    "approved": False,
                    "reason": f"危险动作 {action_type} 仅在低峰期可自动执行",
                    "requires_human": True,
                }

        # 检查3：爆炸半径评估
        blast_radius = self.dependency_resolver.get_blast_radius(target_service, depth=2)
        if len(blast_radius) > 5:
            return {
                "approved": False,
                "reason": f"操作 {target_service} 将影响 {len(blast_radius)} 个服务，爆炸半径过大",
                "requires_human": True,
            }

        # 检查4：当前是否已有正在执行的恢复操作
        active_executions = self._get_active_executions(target_service)
        if active_executions:
            return {
                "approved": False,
                "reason": f"服务 {target_service} 已有 {len(active_executions)} 个正在执行的恢复操作",
                "requires_human": False,
            }

        # 检查5：限流检查 - 同一服务在短时间内不超过最大恢复次数
        recent_count = self._count_recent_executions(target_service, minutes=30)
        max_allowed = self.config.get("max_remediations_per_30min", 3)
        if recent_count >= max_allowed:
            return {
                "approved": False,
                "reason": f"服务 {target_service} 在30分钟内已执行 {recent_count} 次恢复操作，达到上限",
                "requires_human": True,
            }

        return {
            "approved": True,
            "reason": "安全检查通过",
            "requires_human": False,
        }

    def _is_within_safe_window(self) -> bool:
        """是否在安全操作窗口内（凌晨1点-5点允许更多操作）"""
        from datetime import datetime
        hour = datetime.now().hour
        return 1 <= hour <= 5

    def _get_active_executions(self, service: str) -> list:
        """获取服务的活跃执行"""
        # 实际从数据库查询 status=RUNNING 的执行记录
        return []

    def _count_recent_executions(self, service: str, minutes: int) -> int:
        """统计近N分钟内的执行次数"""
        # 实际从数据库查询
        return 0
```

```python
import subprocess
import json
import time
from abc import ABC, abstractmethod

class ActionHandler(ABC):
    """动作处理器接口"""

    @abstractmethod
    def execute(self, target: dict, params: dict, timeout: int) -> dict:
        """执行动作"""
        pass

    @abstractmethod
    def rollback(self, target: dict, params: dict) -> dict:
        """回滚动作"""
        pass


class RestartPodHandler(ActionHandler):
    """K8s Pod 重启处理器"""

    def execute(self, target: dict, params: dict, timeout: int) -> dict:
        namespace = target.get("namespace", "default")
        deployment = target.get("deployment")
        pod = target.get("pod")

        if deployment:
            # 通过 rollout restart 重启整个 Deployment
            cmd = [
                "kubectl", "rollout", "restart",
                f"deployment/{deployment}",
                "-n", namespace
            ]
        elif pod:
            # 删除单个 Pod（K8s 会自动重建）
            cmd = [
                "kubectl", "delete", "pod", pod,
                "-n", namespace,
                "--grace-period=30"
            ]
        else:
            return {"success": False, "error": "未指定 deployment 或 pod"}

        try:
            result = subprocess.run(
                cmd, capture_output=True, text=True, timeout=timeout,
                env={"KUBECONFIG": "/etc/kubernetes/admin.conf"}
            )
            if result.returncode == 0:
                # 等待 Pod 就绪
                if deployment:
                    self._wait_deployment_ready(deployment, namespace, timeout)
                return {
                    "success": True,
                    "output": result.stdout.strip(),
                    "action": "RESTART_POD",
                    "target": target,
                }
            else:
                return {
                    "success": False,
                    "error": result.stderr.strip(),
                    "action": "RESTART_POD",
                }
        except subprocess.TimeoutExpired:
            return {
                "success": False,
                "error": f"Pod重启超时（{timeout}秒）",
                "action": "RESTART_POD",
            }

    def rollback(self, target: dict, params: dict) -> dict:
        # Pod 重启不可回滚，但可以记录上一次的 rollout 状态
        deployment = target.get("deployment")
        namespace = target.get("namespace", "default")
        if deployment:
            cmd = [
                "kubectl", "rollout", "undo",
                f"deployment/{deployment}", "-n", namespace
            ]
            result = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
            return {"success": result.returncode == 0}
        return {"success": False, "error": "无法回滚"}

    def _wait_deployment_ready(self, deployment: str, namespace: str, timeout: int):
        """等待 Deployment 所有 Pod 就绪"""
        cmd = [
            "kubectl", "rollout", "status",
            f"deployment/{deployment}", "-n", namespace,
            f"--timeout={timeout}s"
        ]
        subprocess.run(cmd, capture_output=True, text=True, timeout=timeout + 10)


class ScaleUpHandler(ActionHandler):
    """扩容处理器"""

    def execute(self, target: dict, params: dict, timeout: int) -> dict:
        deployment = target["deployment"]
        namespace = target.get("namespace", "default")
        current_replicas = params.get("current_replicas", 2)
        scale_to = params.get("scale_to", current_replicas * 2)
        max_replicas = params.get("max_replicas", 10)

        scale_to = min(scale_to, max_replicas)

        cmd = [
            "kubectl", "scale",
            f"deployment/{deployment}",
            f"--replicas={scale_to}",
            "-n", namespace
        ]
        result = subprocess.run(cmd, capture_output=True, text=True, timeout=timeout)
        return {
            "success": result.returncode == 0,
            "scaled_from": current_replicas,
            "scaled_to": scale_to,
            "output": result.stdout.strip() if result.returncode == 0 else result.stderr.strip(),
        }

    def rollback(self, target: dict, params: dict) -> dict:
        deployment = target["deployment"]
        namespace = target.get("namespace", "default")
        original = params.get("current_replicas", 2)
        cmd = [
            "kubectl", "scale",
            f"deployment/{deployment}",
            f"--replicas={original}",
            "-n", namespace
        ]
        result = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
        return {"success": result.returncode == 0}


class FlushCacheHandler(ActionHandler):
    """缓存清理处理器"""

    def __init__(self, redis_client):
        self.redis = redis_client

    def execute(self, target: dict, params: dict, timeout: int) -> dict:
        cache_pattern = params.get("pattern", "*")
        cache_type = params.get("cache_type", "pattern")  # pattern / prefix / all

        if cache_type == "all":
            # 仅清理非关键缓存，保护 session 数据
            protected_prefixes = ["session:", "lock:", "ratelimit:"]
            deleted = 0
            for key_batch in self.redis.scan_iter(match="*", count=500):
                key = key_batch.decode() if isinstance(key_batch, bytes) else key_batch
                if not any(key.startswith(p) for p in protected_prefixes):
                    self.redis.delete(key)
                    deleted += 1
            return {"success": True, "deleted_keys": deleted, "protected": True}
        else:
            deleted = 0
            for key in self.redis.scan_iter(match=cache_pattern, count=500):
                self.redis.delete(key)
                deleted += 1
            return {"success": True, "deleted_keys": deleted, "pattern": cache_pattern}

    def rollback(self, target: dict, params: dict) -> dict:
        # 缓存清理不可回滚，缓存会自然重建
        return {"success": True, "note": "缓存不可回滚，将自然重建"}


class RemediationExecutor:
    """自愈执行器：编排动作序列的执行"""

    HANDLER_MAP = {
        "RESTART_POD": RestartPodHandler,
        "SCALE_UP": ScaleUpHandler,
        "FLUSH_CACHE": FlushCacheHandler,
        # 可扩展更多处理器...
    }

    def __init__(self, safety_guard: SafetyGuard, incident_store, execution_store):
        self.safety_guard = safety_guard
        self.incident_store = incident_store
        self.execution_store = execution_store
        self._handlers: dict[str, ActionHandler] = {}

    def register_handler(self, action_type: str, handler: ActionHandler):
        self._handlers[action_type] = handler

    async def execute_remediation(
        self,
        incident: dict,
        playbook: dict,
        actions: list[dict],
    ) -> dict:
        """
        执行完整的恢复流程
        """
        execution_id = self._generate_execution_id()
        incident_id = incident["incident_id"]

        # 记录执行开始
        execution_record = {
            "execution_id": execution_id,
            "incident_id": incident_id,
            "playbook_id": playbook["playbook_id"],
            "status": "RUNNING",
            "started_at": time.time(),
            "action_log": [],
        }
        await self.execution_store.save(execution_record)

        # 更新事件状态
        await self.incident_store.update_status(incident_id, "REMEDIATING")

        completed_actions = []
        overall_success = True

        for i, action in enumerate(actions):
            action_type = action["type"]
            target = action["target"]
            params = action.get("params", {})
            timeout = action.get("timeout_seconds", 60)

            # 安全检查
            validation = self.safety_guard.validate(action, incident)
            if not validation["approved"]:
                execution_record["action_log"].append({
                    "step": i + 1,
                    "action": action_type,
                    "target": target,
                    "status": "SKIPPED",
                    "reason": validation["reason"],
                    "requires_human": validation["requires_human"],
                })
                if validation["requires_human"]:
                    # 需要人工介入，暂停自动执行
                    overall_success = False
                    await self._notify_oncall(incident, action, validation["reason"])
                    break
                continue

            # 执行动作
            handler = self._handlers.get(action_type)
            if not handler:
                execution_record["action_log"].append({
                    "step": i + 1,
                    "action": action_type,
                    "status": "NO_HANDLER",
                    "reason": f"未找到 {action_type} 的处理器",
                })
                overall_success = False
                continue

            start_time = time.time()
            try:
                result = handler.execute(target, params, timeout)
                elapsed = time.time() - start_time

                log_entry = {
                    "step": i + 1,
                    "action": action_type,
                    "target": target,
                    "status": "SUCCESS" if result.get("success") else "FAILED",
                    "result": result,
                    "elapsed_ms": int(elapsed * 1000),
                }
                execution_record["action_log"].append(log_entry)
                await self.execution_store.update(execution_record)

                if result.get("success"):
                    completed_actions.append((action, result))
                    # 执行后等待服务稳定
                    await self._wait_stabilize(target, wait_seconds=15)
                else:
                    overall_success = False
                    # 尝试回滚已完成的部分
                    await self._rollback_completed(completed_actions)
                    break

            except Exception as e:
                elapsed = time.time() - start_time
                execution_record["action_log"].append({
                    "step": i + 1,
                    "action": action_type,
                    "target": target,
                    "status": "ERROR",
                    "error": str(e),
                    "elapsed_ms": int(elapsed * 1000),
                })
                overall_success = False
                break

        # 完成
        execution_record["status"] = "SUCCESS" if overall_success else "FAILED"
        execution_record["completed_at"] = time.time()
        await self.execution_store.update(execution_record)

        # 更新事件状态
        if overall_success:
            await self.incident_store.update_status(incident_id, "RESOLVED", resolved_by="AUTO")
        else:
            await self.incident_store.update_status(incident_id, "ESCALATED")

        return execution_record

    async def _wait_stabilize(self, target: dict, wait_seconds: int):
        """执行后等待服务稳定"""
        import asyncio
        await asyncio.sleep(wait_seconds)

    async def _rollback_completed(self, completed: list[tuple[dict, dict]]):
        """回滚已完成的动作"""
        for action, _ in reversed(completed):
            handler = self._handlers.get(action["type"])
            if handler:
                try:
                    handler.rollback(action["target"], action.get("params", {}))
                except Exception:
                    pass  # 回滚失败不阻断流程

    async def _notify_oncall(self, incident: dict, action: dict, reason: str):
        """通知值班人员"""
        # 通过消息服务发送通知
        notification = {
            "type": "REMEDIATION_ESCALATION",
            "incident_id": incident.get("incident_id"),
            "title": incident.get("title"),
            "severity": incident.get("severity"),
            "blocked_action": action["type"],
            "reason": reason,
            "services": incident.get("affected_services"),
            "timestamp": time.time(),
        }
        # 实际调用通知服务发送企业微信/钉钉/电话告警
        print(f"[ESCALATION] {json.dumps(notification, ensure_ascii=False)}")

    def _generate_execution_id(self) -> str:
        import uuid
        return f"exec-{uuid.uuid4().hex[:12]}"
```

### 6.2 状态机定义

```python
from enum import Enum

class IncidentStatus(str, Enum):
    DETECTED = "DETECTED"           # 异常已检测
    CONFIRMED = "CONFIRMED"         # 确认为故障
    REMEDIATING = "REMEDIATING"     # 自愈进行中
    RESOLVED = "RESOLVED"           # 自愈成功
    FAILED = "FAILED"               # 自愈失败
    ESCALATED = "ESCALATED"         # 升级人工处理
    MANUAL_RESOLVED = "MANUAL_RESOLVED"  # 人工恢复
    CLOSED = "CLOSED"               # 已关闭


# 合法状态转换
VALID_TRANSITIONS = {
    IncidentStatus.DETECTED: [IncidentStatus.CONFIRMED, IncidentStatus.CLOSED],
    IncidentStatus.CONFIRMED: [IncidentStatus.REMEDIATING, IncidentStatus.ESCALATED],
    IncidentStatus.REMEDIATING: [
        IncidentStatus.RESOLVED,
        IncidentStatus.FAILED,
        IncidentStatus.ESCALATED,
    ],
    IncidentStatus.RESOLVED: [IncidentStatus.CLOSED],
    IncidentStatus.FAILED: [IncidentStatus.ESCALATED, IncidentStatus.REMEDIATING],
    IncidentStatus.ESCALATED: [
        IncidentStatus.MANUAL_RESOLVED,
        IncidentStatus.REMEDIATING,  # 允许人工确认后重试
    ],
    IncidentStatus.MANUAL_RESOLVED: [IncidentStatus.CLOSED],
    IncidentStatus.CLOSED: [],  # 终态
}


class IncidentStateMachine:
    """事件状态机"""

    def __init__(self, incident_store):
        self.store = incident_store

    async def transition(
        self,
        incident_id: str,
        target_status: IncidentStatus,
        operator: str = "AUTO",
        note: str = "",
    ):
        """执行状态转换"""
        incident = await self.store.get(incident_id)
        if not incident:
            raise ValueError(f"事件不存在: {incident_id}")

        current = IncidentStatus(incident["status"])
        if target_status not in VALID_TRANSITIONS.get(current, []):
            raise ValueError(
                f"非法状态转换: {current.value} -> {target_status.value}"
            )

        update_fields = {
            "status": target_status.value,
            "updated_at": datetime.utcnow(),
        }

        if target_status == IncidentStatus.RESOLVED:
            update_fields["resolved_at"] = datetime.utcnow()
            update_fields["resolved_by"] = operator
        elif target_status == IncidentStatus.CLOSED:
            update_fields["resolved_at"] = update_fields.get(
                "resolved_at", datetime.utcnow()
            )

        if note:
            update_fields["resolution_note"] = note

        await self.store.update(incident_id, update_fields)
        # 记录状态转换审计日志
        await self._audit_log(incident_id, current, target_status, operator, note)

    async def _audit_log(self, incident_id, from_status, to_status, operator, note):
        """记录审计日志"""
        audit = {
            "incident_id": incident_id,
            "from_status": from_status.value,
            "to_status": to_status.value,
            "operator": operator,
            "note": note,
            "timestamp": datetime.utcnow().isoformat(),
        }
        # 写入审计日志表
        print(f"[AUDIT] {audit}")
```

## 9. 错误处理与降级策略

### 9.1 iFARE 自身的容错设计

iFARE 作为可靠性基础设施，自身必须具备极高的容错能力。

| 场景 | 处理策略 |
| --- | --- |
| iFARE 主实例宕机 | 备用实例 30 秒内接管（基于 K8s Leader Election） |
| Prometheus 查询超时 | 使用上次缓存指标，降级为仅日志模式检测 |
| K8s API Server 不可达 | 暂停所有 K8s 相关恢复动作，仅执行通知和记录 |
| 策略数据库不可达 | 加载内存中的策略快照继续运行 |
| 通知服务不可达 | 本地缓存通知，定时重试，不阻断恢复流程 |
| 自愈执行器超时 | 标记执行失败，升级人工处理 |

### 9.2 错误码定义

| 错误码 | 含义 | 处理建议 |
| --- | --- | --- |
| IFARE_001 | 信号采集失败 | 检查数据源连接 |
| IFARE_002 | 策略匹配无结果 | 检查策略是否启用，是否都在冷却期 |
| IFARE_003 | 安全检查未通过 | 查看 SafetyGuard 返回的 reason |
| IFARE_004 | 执行动作超时 | 检查目标服务状态，考虑手动干预 |
| IFARE_005 | K8s 操作失败 | 检查 RBAC 权限和集群状态 |
| IFARE_006 | 回滚失败 | 紧急人工介入，检查服务状态 |
| IFARE_007 | 自愈引擎内部异常 | 查看 iFARE Pod 日志 |

### 9.3 防止自愈雪崩

```python
class RemediationCircuitBreaker:
    """自愈熔断器：防止自愈操作本身导致雪崩"""

    def __init__(self, threshold: int = 5, cooldown: int = 1800):
        self.failure_threshold = threshold  # 连续失败次数阈值
        self.cooldown_seconds = cooldown    # 熔断后冷却时间
        self._consecutive_failures = 0
        self._circuit_open = False
        self._open_until = 0

    def can_execute(self) -> tuple[bool, str]:
        """检查是否允许执行"""
        import time
        if self._circuit_open:
            if time.time() >= self._open_until:
                self._circuit_open = False
                self._consecutive_failures = 0
                return True, "熔断器恢复（半开状态）"
            else:
                remaining = int(self._open_until - time.time())
                return False, f"自愈熔断器已打开，{remaining}秒后恢复"

        return True, "正常"

    def record_success(self):
        self._consecutive_failures = 0

    def record_failure(self):
        import time
        self._consecutive_failures += 1
        if self._consecutive_failures >= self.failure_threshold:
            self._circuit_open = True
            self._open_until = time.time() + self.cooldown_seconds
            # 触发紧急通知
            print(f"[CRITICAL] 自愈熔断器已打开！连续失败 {self._consecutive_failures} 次")
```

```python
class PostIncidentAnalyzer:
    """事后分析自动化"""

    async def generate_post_mortem(self, incident_id: str) -> dict:
        """自动生成事件复盘报告"""
        incident = await self.incident_store.get(incident_id)
        executions = await self.execution_store.get_by_incident(incident_id)
        signals = await self.signal_store.get_by_incident(incident_id)
        timeline = await self._build_timeline(incident, signals, executions)

        return {
            "incident_id": incident_id,
            "title": incident["title"],
            "severity": incident["severity"],
            "summary": await self._generate_summary(incident, executions),
            "timeline": timeline,
            "impact_analysis": {
                "affected_services": incident["affected_services"],
                "affected_users": incident["affected_users"],
                "duration_seconds": self._calc_duration(incident),
                "peak_error_rate": await self._get_peak_metric(
                    incident, "error_rate"
                ),
                "peak_latency_ms": await self._get_peak_metric(
                    incident, "p99_latency_ms"
                ),
            },
            "root_cause": incident.get("root_cause", "待人工补充"),
            "remediation_evaluation": self._evaluate_remediation(executions),
            "recommendations": await self._generate_recommendations(
                incident, executions
            ),
            "action_items": [],  # 需人工填写
        }

    def _evaluate_remediation(self, executions: list) -> dict:
        """评估恢复效果"""
        if not executions:
            return {"overall": "NO_AUTO_REMEDIATION"}

        total = len(executions)
        success = sum(1 for e in executions if e["status"] == "SUCCESS")
        total_time = sum(e.get("duration_ms", 0) for e in executions)

        return {
            "overall": "EFFECTIVE" if success > 0 else "INEFFECTIVE",
            "auto_attempted": total,
            "auto_succeeded": success,
            "total_remediation_time_ms": total_time,
            "strategies_used": [
                {
                    "playbook": e["playbook_name"],
                    "result": e["status"],
                    "duration_ms": e.get("duration_ms"),
                }
                for e in executions
            ],
        }

    async def _generate_recommendations(
        self, incident: dict, executions: list
    ) -> list[str]:
        """生成改进建议"""
        recommendations = []

        # 如果自愈失败，建议优化策略
        failed = [e for e in executions if e["status"] == "FAILED"]
        if failed and not any(e["status"] == "SUCCESS" for e in executions):
            recommendations.append(
                f"自愈策略未成功，建议审查 playbook 并增加新的恢复策略"
            )

        # 如果频繁发生同类故障，建议根因修复
        similar = await self.incident_store.count_similar(
            root_cause=incident.get("root_cause"),
            days=30,
        )
        if similar >= 3:
            recommendations.append(
                f"近30天发生 {similar} 次类似故障，建议进行根因修复而非依赖自愈"
            )

        # 如果恢复时间过长
        duration = self._calc_duration(incident)
        if duration > 300:
            recommendations.append(
                f"恢复耗时 {duration}秒，建议优化检测速度或增加预防性策略"
            )

        return recommendations
```

```python
class PlaybookOptimizer:
    """策略自动调优器"""

    async def optimize(self):
        """每周执行一次策略优化分析"""
        playbooks = await self.playbook_store.get_all_enabled()

        for pb in playbooks:
            recent = await self.execution_store.get_recent_30d(pb["playbook_id"])

            if len(recent) < 3:
                continue  # 数据不足

            success_rate = sum(
                1 for e in recent if e["status"] == "SUCCESS"
            ) / len(recent)

            # 低成功率策略建议禁用或调整
            if success_rate < 0.3:
                await self._flag_for_review(
                    pb, reason=f"成功率仅 {success_rate:.0%}，建议审查"
                )

            # 调整冷却时间
            if success_rate > 0.9:
                # 高成功率可以缩短冷却
                current_cooldown = pb["cooldown_seconds"]
                suggested = max(current_cooldown - 60, 120)
                if suggested < current_cooldown:
                    await self._suggest_param_change(
                        pb, "cooldown_seconds", current_cooldown, suggested,
                        reason="高成功率策略，建议缩短冷却时间"
                    )

            # 分析最佳执行时间
            durations = [
                e.get("duration_ms", 0) for e in recent
                if e["status"] == "SUCCESS"
            ]
            if durations:
                avg_duration = sum(durations) / len(durations)
                p95_duration = sorted(durations)[int(len(durations) * 0.95)]
                # 建议调整超时时间
                current_timeout = pb["actions"][0].get("timeout_seconds", 60)
                if p95_duration / 1000 > current_timeout * 0.8:
                    suggested_timeout = int(p95_duration / 1000 * 1.5)
                    await self._suggest_param_change(
                        pb, "timeout_seconds", current_timeout, suggested_timeout,
                        reason=f"P95耗时接近超时阈值，建议调大超时"
                    )
```
