# 服务端数据归档与生命周期管理策略 - 详细设计

## 1. 概述

### 1.1 背景

PrimeTop 作为全学段 AI 辅助学习产品，随着用户增长和学习数据持续积累，数据库和存储中的数据量将快速增长。学习行为日志、AI 对话记录、答题记录、错题数据等具有明显的"时间衰减"特性——近期数据高频访问，历史数据访问频率骤降。如果将所有数据长期保留在热存储中，将面临：

1. **存储成本失控**：学习行为日志按月增长 50%+，3 年后可达 TB 级
2. **查询性能退化**：大表扫描、索引膨胀导致在线查询变慢
3. **合规风险**：未按法规要求保留/销毁数据
4. **运维困难**：大表 DDL、备份恢复时间不可控

### 1.2 目标

1. 建立完整的数据生命周期管理体系，覆盖热→温→冷→归档→销毁全流程
2. 在线查询性能不受历史数据影响，核心表单表数据量可控
3. 满足《个人信息保护法》《儿童个人信息网络保护规定》等法规的数据保留与销毁要求
4. 存储成本年增长率控制在 30% 以内

### 1.3 适用范围

| 数据类别 | 典型表/存储 | 数据特征 |
|---------|-----------|---------|
| 学习行为日志 | `learning_activity_log` | 高频写入，近期查询，历史低频 |
| AI 对话记录 | `ai_conversation`, `ai_message` | 写入密集，近期回看，长期统计 |
| 答题记录 | `answer_record` | 高频写入，近期查询，长期分析 |
| 错题记录 | `mistake_record` | 活跃查询，长期保留 |
| 操作审计日志 | `audit_log` | 合规要求保留 180 天+ |
| 支付订单 | `order`, `payment_record` | 合规要求保留 5 年+ |
| 用户设备日志 | `device_log`, `crash_report` | 近期排查，30 天后极少访问 |
| 会话缓存 | Redis session/缓存数据 | 实时访问，短 TTL |
| 搜索日志 | `search_query_log` | 分析用，30 天后归档 |
| 文件资源元数据 | `resource_meta` | 长期保留，引用频繁 |

## 2. 数据生命周期分级

### 2.1 分级定义

| 级别 | 标识 | 存储介质 | 访问频率 | 保留策略 | 典型延迟 |
|------|------|---------|---------|---------|---------|
| **热数据 (Hot)** | HOT | MySQL 主库 + Redis 缓存 | 每秒~每小时 | 0~90 天 | < 10ms |
| **温数据 (Warm)** | WARM | MySQL 归档库 / ClickHouse | 每天~每周 | 90~365 天 | < 100ms |
| **冷数据 (Cold)** | COLD | ClickHouse 冷存储 / 对象存储 Parquet | 每月~每季度 | 1~3 年 | < 1s |
| **冰数据 (Archive)** | ARCHIVE | 对象存储归档层 / 磁带 | 极少，按需 | 3~7 年（合规） | 秒~分钟级 |
| **销毁 (Destroy)** | DESTROY | 物理删除 / 脱敏后匿名化 | 无 | 到期执行 | - |

## 4. 归档引擎设计

### 4.1 归档流程状态机

```text
  ┌─────────┐     扫描超期数据     ┌───────────┐
  │ PENDING │ ──────────────────▶ │ EXPORTING │
  └─────────┘                     └─────┬─────┘
                                        │ 导出完成
                                        ▼
                                  ┌───────────┐
                                  │ IMPORTING │  写入目标存储
                                  └─────┬─────┘
                                        │ 导入完成
                                        ▼
                                  ┌───────────┐
                                  │ VERIFYING │  校验数据一致性
                                  └─────┬─────┘
                                        │ 校验通过
                                        ▼
                                  ┌───────────┐
                                  │ COMPLETED │  删除源数据 + 更新追踪表
                                  └───────────┘

  任何阶段出错 → FAILED (记录错误，可重试)
  严重错误 → ROLLED_BACK (回滚已导入数据)
```

### 4.2 归档引擎核心代码

```python
# services/archive/engine.py

import logging
import hashlib
from datetime import datetime, timedelta
from dataclasses import dataclass
from enum import Enum
from typing import Optional

from django.db import transaction, connections
from django.conf import settings

logger = logging.getLogger(__name__)


class ArchiveTarget(str, Enum):
    CLICKHOUSE = "clickhouse"
    OSS_STANDARD = "oss_standard"
    OSS_ARCHIVE = "oss_archive"
    DESTROY = "destroyed"


class ArchiveStatus(str, Enum):
    PENDING = "pending"
    EXPORTING = "exporting"
    IMPORTING = "importing"
    VERIFYING = "verifying"
    COMPLETED = "completed"
    FAILED = "failed"
    ROLLED_BACK = "rolled_back"


@dataclass
class LifecycleRule:
    table_name: str
    hot_days: int
    warm_days: int
    cold_days: int
    archive_years: int
    partition_key: str = "created_at"
    anonymize_before_destroy: bool = True
    destroy_with_user: bool = False
    cascade_parent: Optional[str] = None


class ArchiveEngine:
    """
    数据归档引擎
    负责扫描、导出、导入、校验、清理的完整生命周期管理
    """

    def __init__(self, rule: LifecycleRule):
        self.rule = rule
        self.batch_id = self._generate_batch_id()

    def _generate_batch_id(self) -> str:
        """生成归档批次号: ARC_{table}_{timestamp}"""
        now = datetime.now()
        short_table = self.rule.table_name[:20]
        return f"ARC_{short_table}_{now.strftime('%Y%m%d%H%M%S')}"

    def run_hot_to_warm(self, dry_run: bool = False) -> dict:
        """
        热数据 → 温数据 (MySQL → ClickHouse)
        将超过 hot_days 的数据归档到 ClickHouse
        """
        cutoff_date = datetime.now() - timedelta(days=self.rule.hot_days)

        logger.info(
            f"[ArchiveEngine] 开始热→温归档: table={self.rule.table_name}, "
            f"cutoff={cutoff_date}, batch={self.batch_id}"
        )

        # 1. 创建归档元数据记录
        metadata = self._create_metadata(
            source_type="mysql_hot",
            target_type="clickhouse",
            date_range_start=cutoff_date - timedelta(days=1),
            date_range_end=cutoff_date,
        )

        try:
            # 2. 导出数据
            self._update_status(metadata, ArchiveStatus.EXPORTING)

            export_result = self._export_from_mysql(
                cutoff_date=cutoff_date,
                batch_size=10000,
                dry_run=dry_run,
            )

            if export_result["row_count"] == 0:
                logger.info(f"[ArchiveEngine] 无需归档的数据, 跳过")
                self._update_status(metadata, ArchiveStatus.COMPLETED)
                return {"status": "skipped", "row_count": 0}

            # 3. 导入 ClickHouse
            self._update_status(metadata, ArchiveStatus.IMPORTING)
            self._import_to_clickhouse(export_result["temp_file"], dry_run=dry_run)

            # 4. 校验数据一致性
            self._update_status(metadata, ArchiveStatus.VERIFYING)
            verify_ok = self._verify_consistency(
                export_result["row_count"],
                export_result["checksum"],
                cutoff_date,
                dry_run=dry_run,
            )

            if not verify_ok and not dry_run:
                raise ArchiveVerificationError(
                    f"归档校验失败: table={self.rule.table_name}"
                )

            # 5. 删除热库中的已归档数据
            if not dry_run:
                self._delete_archived_from_mysql(cutoff_date, export_result["row_count"])

            # 6. 更新生命周期追踪
            self._update_status(metadata, ArchiveStatus.COMPLETED)
            if not dry_run:
                self._update_lifecycle_tracking(
                    stage="warm",
                    cutoff_date=cutoff_date,
                    row_count=export_result["row_count"],
                    size=export_result["data_size"],
                )

            logger.info(
                f"[ArchiveEngine] 热→温归档完成: rows={export_result['row_count']}"
            )
            return {
                "status": "completed",
                "row_count": export_result["row_count"],
                "batch_id": self.batch_id,
            }

        except Exception as e:
            logger.error(f"[ArchiveEngine] 归档失败: {e}", exc_info=True)
            self._update_status(metadata, ArchiveStatus.FAILED, str(e))
            raise

    def run_warm_to_cold(self, dry_run: bool = False) -> dict:
        """
        温数据 → 冷数据 (ClickHouse → 对象存储 Parquet)
        将超过 hot_days + warm_days 的数据导出为 Parquet
        """
        total_warm_days = self.rule.hot_days + self.rule.warm_days
        cutoff_date = datetime.now() - timedelta(days=total_warm_days)

        metadata = self._create_metadata(
            source_type="clickhouse",
            target_type="oss_standard",
            date_range_start=cutoff_date - timedelta(days=1),
            date_range_end=cutoff_date,
        )

        try:
            self._update_status(metadata, ArchiveStatus.EXPORTING)

            # 从 ClickHouse 导出到 Parquet
            parquet_path = (
                f"archive/cold/{self.rule.table_name}/"
                f"dt={cutoff_date.strftime('%Y-%m-%d')}/{self.batch_id}.parquet"
            )

            result = self._export_clickhouse_to_parquet(
                cutoff_date=cutoff_date,
                target_path=parquet_path,
                dry_run=dry_run,
            )

            self._update_status(metadata, ArchiveStatus.COMPLETED)
            return {
                "status": "completed",
                "row_count": result["row_count"],
                "path": parquet_path,
            }

        except Exception as e:
            self._update_status(metadata, ArchiveStatus.FAILED, str(e))
            raise

    def run_destroy(self, dry_run: bool = False) -> dict:
        """
        销毁到期数据
        根据 archive_years 判断是否已到期
        """
        destroy_cutoff = datetime.now() - timedelta(
            days=365 * self.rule.archive_years
        )

        if self.rule.archive_years == 0:
            # 不保留，直接从上一个阶段销毁
            total_days = self.rule.hot_days + self.rule.warm_days + self.rule.cold_days
            destroy_cutoff = datetime.now() - timedelta(days=total_days)

        metadata = self._create_metadata(
            source_type="oss_archive",
            target_type="destroyed",
            date_range_start=destroy_cutoff - timedelta(days=365),
            date_range_end=destroy_cutoff,
        )

        try:
            if self.rule.anonymize_before_destroy and not dry_run:
                # 先脱敏
                self._anonymize_expired_data(destroy_cutoff)

            # 删除对象存储中的文件
            self._destroy_archived_files(destroy_cutoff, dry_run=dry_run)

            self._update_status(metadata, ArchiveStatus.COMPLETED)
            logger.info(f"[ArchiveEngine] 销毁完成: cutoff={destroy_cutoff}")
            return {"status": "completed", "cutoff": destroy_cutoff}

        except Exception as e:
            self._update_status(metadata, ArchiveStatus.FAILED, str(e))
            raise

    # ──────── 私有方法 ────────

    def _create_metadata(self, source_type, target_type, date_range_start, date_range_end):
        """创建归档元数据记录"""
        from .models import ArchiveMetadata

        return ArchiveMetadata.objects.create(
            archive_batch=self.batch_id,
            source_table=self.rule.table_name,
            source_type=source_type,
            target_type=target_type,
            date_range_start=date_range_start,
            date_range_end=date_range_end,
            status=ArchiveStatus.PENDING,
            operator="system",
        )

    def _update_status(self, metadata, status, error_message=None):
        """更新归档状态"""
        metadata.status = status
        if status == ArchiveStatus.COMPLETED:
            metadata.completed_at = datetime.now()
        elif error_message:
            metadata.error_message = error_message
        metadata.save(update_fields=["status", "completed_at", "error_message"])

    def _export_from_mysql(self, cutoff_date, batch_size=10000, dry_run=False):
        """
        分批从 MySQL 导出数据到临时文件
        使用流式查询避免内存溢出
        """
        import pyarrow as pa
        import pyarrow.parquet as pq
        import tempfile

        row_count = 0
        checksum = hashlib.md5()

        with tempfile.NamedTemporaryFile(suffix=".parquet", delete=False) as tmp:
            writer = None

            try:
                # 分批流式读取
                last_id = 0
                while True:
                    with connections["default"].cursor() as cursor:
                        cursor.execute(
                            f"""
                            SELECT * FROM {self.rule.table_name}
                            WHERE {self.rule.partition_key} < %s AND id > %s
                            ORDER BY id
                            LIMIT %s
                            """,
                            [cutoff_date, last_id, batch_size],
                        )
                        columns = [col[0] for col in cursor.description]
                        rows = cursor.fetchall()

                    if not rows:
                        break

                    # 更新校验和
                    for row in rows:
                        checksum.update(str(row).encode())

                    # 写入 Parquet
                    table = pa.table(
                        {col: [row[i] for row in rows] for i, col in enumerate(columns)}
                    )

                    if writer is None:
                        writer = pq.ParquetWriter(tmp.name, table.schema)

                    writer.write_table(table)
                    row_count += len(rows)
                    last_id = rows[-1][0]  # 假设第一列是 id

                    logger.debug(
                        f"[ArchiveEngine] 已导出 {row_count} 行, last_id={last_id}"
                    )

                    if len(rows) < batch_size:
                        break

            finally:
                if writer:
                    writer.close()

            if dry_run:
                return {
                    "row_count": row_count,
                    "checksum": checksum.hexdigest(),
                    "temp_file": tmp.name,
                    "data_size": 0,
                }

        import os

        data_size = os.path.getsize(tmp.name)
        return {
            "row_count": row_count,
            "checksum": checksum.hexdigest(),
            "temp_file": tmp.name,
            "data_size": data_size,
        }

    def _import_to_clickhouse(self, parquet_file: str, dry_run=False):
        """将 Parquet 文件导入 ClickHouse"""
        if dry_run:
            logger.info(f"[ArchiveEngine] DRY RUN: 跳过 ClickHouse 导入")
            return

        from clickhouse_driver import Client

        client = Client(
            host=settings.CLICKHOUSE_HOST,
            port=settings.CLICKHOUSE_PORT,
            database=settings.CLICKHOUSE_DATABASE,
        )

        # ClickHouse 支持 INSERT FROM Parquet
        query = f"""
        INSERT INTO {self.rule.table_name}
        SELECT * FROM file('{parquet_file}', Parquet)
        """
        client.execute(query)

    def _verify_consistency(self, expected_count, expected_checksum, cutoff_date, dry_run=False):
        """
        校验归档数据一致性
        比对源表行数与目标表行数
        """
        if dry_run:
            return True

        from clickhouse_driver import Client

        client = Client(
            host=settings.CLICKHOUSE_HOST,
            port=settings.CLICKHOUSE_PORT,
            database=settings.CLICKHOUSE_DATABASE,
        )

        # 检查目标表行数
        result = client.execute(
            f"""
            SELECT count() FROM {self.rule.table_name}
            WHERE {self.rule.partition_key} < %(cutoff)s
            """,
            {"cutoff": cutoff_date},
        )
        target_count = result[0][0]

        if target_count != expected_count:
            logger.error(
                f"行数不一致: expected={expected_count}, actual={target_count}"
            )
            return False

        return True

    def _delete_archived_from_mysql(self, cutoff_date, expected_count):
        """
        从热库删除已归档数据
        分批删除，避免长事务锁表
        """
        batch_size = 5000
        total_deleted = 0

        while True:
            with transaction.atomic():
                deleted = connections["default"].cursor().execute(
                    f"""
                    DELETE FROM {self.rule.table_name}
                    WHERE {self.rule.partition_key} < %s
                    LIMIT %d
                    """ % batch_size,
                    [cutoff_date],
                )
                total_deleted += deleted

            if deleted < batch_size:
                break

            logger.debug(f"[ArchiveEngine] 已删除 {total_deleted}/{expected_count}")

            # 删除间隔，降低主库压力
            import time
            time.sleep(0.1)

        logger.info(
            f"[ArchiveEngine] 热库清理完成: deleted={total_deleted}"
        )

    def _export_clickhouse_to_parquet(self, cutoff_date, target_path, dry_run=False):
        """从 ClickHouse 导出到对象存储 Parquet"""
        if dry_run:
            return {"row_count": 0}

        # 使用 ClickHouse 的 S3 函数直接导出
        from clickhouse_driver import Client

        client = Client(
            host=settings.CLICKHOUSE_HOST,
            port=settings.CLICKHOUSE_PORT,
        )

        s3_path = f"{settings.OSS_ENDPOINT}/{settings.OSS_BUCKET}/{target_path}"

        client.execute(f"""
        INSERT INTO FUNCTION s3(
            '{s3_path}',
            '{settings.OSS_ACCESS_KEY}',
            '{settings.OSS_SECRET_KEY}',
            'Parquet'
        )
        SELECT * FROM {settings.CLICKHOUSE_DATABASE}.{self.rule.table_name}
        WHERE {self.rule.partition_key} < %(cutoff)s
        """, {"cutoff": cutoff_date})

        # 从 ClickHouse 删除
        client.execute(f"""
        ALTER TABLE {settings.CLICKHOUSE_DATABASE}.{self.rule.table_name}
        DELETE WHERE {self.rule.partition_key} < %(cutoff)s
        """, {"cutoff": cutoff_date})

        return {"row_count": 1}  # 实际应从 ClickHouse 获取

    def _anonymize_expired_data(self, cutoff_date):

    def _destroy_archived_files(self, cutoff_date, dry_run=False):
        """删除对象存储中的到期归档文件"""
        if dry_run:
            return

        s3 = boto3.client(

                    logger.info(f"[ArchiveEngine] 已删除归档文件: {obj['Key']}")

    def _is_file_expired(self, key: str, cutoff_date) -> bool:
        """判断归档文件是否已到期"""
        import re

        match = re.search(r"dt=(\d{4}-\d{2}-\d{2})", key)
        if match:
            file_date = datetime.strptime(match.group(1), "%Y-%m-%d")
            return file_date < cutoff_date
        return False

    def _update_lifecycle_tracking(self, stage, cutoff_date, row_count, size):
```

```python
    """数据销毁任务"""

    engine = ArchiveEngine(rule)

    try:
        result = engine.run_destroy(dry_run=dry_run)
        return result
    except Exception as exc:
        logger.error(f"数据销毁失败: table={table_name}, error={exc}")
        raise self.retry(exc=exc)


@shared_task
def daily_archive_job():
    """
    每日归档调度主任务
    每日凌晨 3:00 执行
    """
    rules = get_all_rules()
    tasks = []

    for rule in rules:
        # 热→温

        # 温→冷 (如果配置了 warm_days)
        if rule.warm_days > 0:
            tasks.append(archive_warm_to_cold_task.s(rule.table_name))

        # 销毁 (如果配置了 archive_years)
        if rule.archive_years >= 0:
            tasks.append(archive_destroy_task.s(rule.table_name))

    # 串行执行，避免资源竞争
    chain(tasks).apply_async()

    """
    每周数据销毁任务
    每周日凌晨 4:00 执行
    """
    rules = get_all_rules()

    for rule in rules:
        if rule.archive_years >= 0:
            archive_destroy_task.delay(rule.table_name)
```

## 5. 跨层透明查询路由

### 5.1 查询路由器

当应用需要查询可能已归档的历史数据时，通过查询路由器自动决定从哪个存储层读取。

```python
# services/archive/query_router.py

import logging
from datetime import datetime, timedelta
from enum import Enum
from typing import Optional, List, Dict, Any

logger = logging.getLogger(__name__)


class StorageLayer(str, Enum):
    HOT = "mysql_hot"
    WARM = "clickhouse"
    COLD = "oss_parquet"
    ARCHIVE = "oss_archive"
    DESTROYED = "destroyed"


class ArchiveQueryRouter:
    """
    归档查询路由器
    根据查询条件的时间范围和生命周期追踪表，决定从哪个存储层查询
    """

    def __init__(self, table_name: str):
        self.table_name = table_name

    def query(
        self,
        start_date: Optional[datetime] = None,
        end_date: Optional[datetime] = None,
        filters: Optional[Dict[str, Any]] = None,
        limit: int = 100,
    ) -> List[Dict[str, Any]]:
        """
        跨层透明查询
        如果时间范围跨越多个存储层，自动合并结果
        """
        if not start_date and not end_date:
            # 无时间范围，默认查热库
            return self._query_hot(filters or {}, limit)

        # 确定时间范围内的存储层分布
        layers = self._resolve_layers(start_date, end_date)

        results = []
        remaining = limit

        for layer in layers:
            if remaining <= 0:
                break

            if layer == StorageLayer.HOT:
                layer_results = self._query_hot(
                    {**(filters or {}),
                     f"{self._partition_key()}__gte": start_date,
                     f"{self._partition_key()}__lte": end_date},
                    remaining,
                )
            elif layer == StorageLayer.WARM:
                layer_results = self._query_warm(start_date, end_date, filters, remaining)
            elif layer == StorageLayer.COLD:
                layer_results = self._query_cold(start_date, end_date, filters, remaining)
            elif layer == StorageLayer.DESTROYED:
                logger.warning(f"查询范围包含已销毁数据: {start_date} ~ {end_date}")
                continue
            else:
                continue

            results.extend(layer_results)
            remaining -= len(layer_results)

        return results[:limit]

    def _resolve_layers(self, start_date: datetime, end_date: datetime) -> List[StorageLayer]:
        """
        解析时间范围对应的存储层
        按时间从新到旧排列
        """
        from .models import DataLifecycleTracking

        # 查询追踪表获取各日期的存储层
        trackings = DataLifecycleTracking.objects.filter(
            table_name=self.table_name,
            data_date__gte=start_date.date(),
            data_date__lte=end_date.date(),
        ).values_list("data_date", "lifecycle_stage")

        if not trackings:
            # 追踪表无记录，保守查热库
            return [StorageLayer.HOT]

        # 按阶段去重，保持时间顺序（新→旧）
        seen = set()
        layers = []
        for date, stage in sorted(trackings, key=lambda x: x[0], reverse=True):
            mapping = {
                "hot": StorageLayer.HOT,
                "warm": StorageLayer.WARM,
                "cold": StorageLayer.COLD,
                "archive": StorageLayer.ARCHIVE,
                "destroyed": StorageLayer.DESTROYED,
            }
            layer = mapping.get(stage)
            if layer and layer not in seen:
                layers.append(layer)
                seen.add(layer)

        return layers

    def _partition_key(self) -> str:
        """获取分区键字段名"""
        from .rules import get_all_rules
        for rule in get_all_rules():
            if rule.table_name == self.table_name:
                return rule.partition_key
        return "created_at"

    def _query_hot(self, filters: Dict, limit: int) -> List[Dict]:
        """查询热库 (MySQL ORM)"""
        from django.apps import apps

        model = apps.get_model("core", self._model_name())
        qs = model.objects.filter(**filters)[:limit]
        return list(qs.values())

    def _query_warm(self, start_date, end_date, filters, limit) -> List[Dict]:
        """查询温库 (ClickHouse)"""
        from clickhouse_driver import Client
        from django.conf import settings

        client = Client(
            host=settings.CLICKHOUSE_HOST,
            port=settings.CLICKHOUSE_PORT,
            database=settings.CLICKHOUSE_DATABASE,
        )

        where_clauses = [f"{self._partition_key()} >= %(start)s", f"{self._partition_key()} <= %(end)s"]
        params = {"start": start_date, "end": end_date}

        if filters:
            for key, value in filters.items():
                where_clauses.append(f"{key} = %(filter_{key})s")
                params[f"filter_{key}"] = value

        query = f"""
            SELECT * FROM {self.table_name}
            WHERE {' AND '.join(where_clauses)}
            ORDER BY {self._partition_key()} DESC
            LIMIT {limit}
        """

        result = client.execute(query, params, with_column_types=True)
        columns = [col[0] for col in result[1]]
        return [dict(zip(columns, row)) for row in result[0]]

    def _query_cold(self, start_date, end_date, filters, limit) -> List[Dict]:
        """查询冷存储 (通过 ClickHouse S3 引擎读取 Parquet)"""
        from clickhouse_driver import Client
        from django.conf import settings

        client = Client(
            host=settings.CLICKHOUSE_HOST,
            port=settings.CLICKHOUSE_PORT,
        )

        s3_pattern = (
            f"{settings.OSS_ENDPOINT}/{settings.OSS_BUCKET}/"
            f"archive/cold/{self.table_name}/*.parquet"
        )

        query = f"""
        SELECT * FROM s3(
            '{s3_pattern}',
            '{settings.OSS_ACCESS_KEY}',
            '{settings.OSS_SECRET_KEY}',
            'Parquet'
        )
        WHERE {self._partition_key()} >= %(start)s
          AND {self._partition_key()} <= %(end)s
        ORDER BY {self._partition_key()} DESC
        LIMIT {limit}
        """

        result = client.execute(
            query, {"start": start_date, "end": end_date}, with_column_types=True
        )
        columns = [col[0] for col in result[1]]
        return [dict(zip(columns, row)) for row in result[0]]

    def _model_name(self) -> str:
        """表名转模型名: answer_record → AnswerRecord"""
        return "".join(part.capitalize() for part in self.table_name.split("_"))
```

## 6. 用户注销数据清理

### 6.1 用户注销流程中的数据处理

当用户发起账号注销时，需要按照数据生命周期规则处理其所有数据：

```python
# services/archive/user_data_cleanup.py

import logging
from datetime import datetime
from typing import List

from django.db import transaction
from services.archive.rules import get_all_rules

logger = logging.getLogger(__name__)


class UserDataCleanupService:
    """
    用户数据清理服务
    处理用户注销时的数据删除/脱敏
    """

    # 用户相关的所有数据表及其清理策略
    USER_DATA_TABLES = {
        "user": {"action": "delete", "cascade": False},          # 主表最后删
        "student_profile": {"action": "delete", "cascade": True},
        "parent_binding": {"action": "delete", "cascade": True},
        "membership": {"action": "anonymize", "cascade": True},
        "order": {"action": "retain", "cascade": True},           # 支付订单合规保留
        "payment_record": {"action": "retain", "cascade": True},
        "learning_activity_log": {"action": "delete", "cascade": True},
        "ai_conversation": {"action": "anonymize", "cascade": True},
        "ai_message": {"action": "anonymize", "cascade": True},
        "answer_record": {"action": "anonymize", "cascade": True},
        "mistake_record": {"action": "delete", "cascade": True},
        "study_plan": {"action": "delete", "cascade": True},
        "learning_session": {"action": "delete", "cascade": True},
        "user_feedback": {"action": "anonymize", "cascade": True},
        "collection": {"action": "delete", "cascade": True},
        "note": {"action": "delete", "cascade": True},
        "device_log": {"action": "delete", "cascade": True},
        "search_query_log": {"action": "delete", "cascade": True},
        "audit_log": {"action": "anonymize", "cascade": True},   # 审计日志脱敏
    }

    # 脱敏字段映射：将个人标识信息替换为匿名值
    ANONYMIZE_FIELDS = {
        "ai_conversation": {"user_id": None, "device_info": None, "ip_address": None},
        "ai_message": {"user_id": None},
        "answer_record": {"student_id": None, "answer_content": "[已脱敏]"},
        "order": {"user_id": None, "phone": None, "email": None},
        "payment_record": {"user_id": None},
        "membership": {"user_id": None},
        "audit_log": {"user_id": None, "ip_address": None, "user_agent": None},
        "user_feedback": {"user_id": None, "content": "[已脱敏]"},
    }

    def cleanup_user_data(self, user_id: int, requested_at: datetime = None):
        """
        执行用户数据清理
        在注销冷却期（15天）结束后调用
        """
        requested_at = requested_at or datetime.now()
        logger.info(f"[UserDataCleanup] 开始清理用户数据: user_id={user_id}")

        cleanup_log = {
            "user_id": user_id,
            "started_at": datetime.now(),
            "actions": [],
        }

        for table, config in self.USER_DATA_TABLES.items():
            action = config["action"]

            try:
                if action == "delete":
                    self._delete_user_data(table, user_id)
                    cleanup_log["actions"].append(
                        {"table": table, "action": "deleted"}
                    )
                elif action == "anonymize":
                    self._anonymize_user_data(table, user_id)
                    cleanup_log["actions"].append(
                        {"table": table, "action": "anonymized"}
                    )
                elif action == "retain":
                    self._anonymize_user_data(table, user_id)
                    cleanup_log["actions"].append(
                        {"table": table, "action": "retained_and_anonymized"}
                    )

            except Exception as e:
                logger.error(
                    f"[UserDataCleanup] 清理失败: table={table}, user_id={user_id}, error={e}"
                )
                cleanup_log["actions"].append(
                    {"table": table, "action": "failed", "error": str(e)}
                )
                # 继续清理其他表
                continue

        # 清理归档数据（对象存储中的 Parquet 文件）
        self._cleanup_archived_user_data(user_id)

        # 记录清理日志
        cleanup_log["completed_at"] = datetime.now()
        self._record_cleanup_log(cleanup_log)

        logger.info(f"[UserDataCleanup] 用户数据清理完成: user_id={user_id}")

    def _delete_user_data(self, table: str, user_id: int):
        """删除用户在指定表中的所有数据"""
        user_columns = self._get_user_column(table)
        if not user_columns:
            return

        with transaction.atomic():
            deleted = (
                connections["default"]
                .cursor()
                .execute(
                    f"DELETE FROM {table} WHERE {user_columns} = %s",
                    [user_id],
                )
            )

        logger.info(f"[UserDataCleanup] 删除 {table}: {deleted} 行")

    def _anonymize_user_data(self, table: str, user_id: int):
        """脱敏用户在指定表中的个人标识信息"""
        if table not in self.ANONYMIZE_FIELDS:
            return

        fields = self.ANONYMIZE_FIELDS[table]
        user_column = self._get_user_column(table)

        set_clauses = []
        params = []
        for field, replacement in fields.items():
            if replacement is None:
                set_clauses.append(f"{field} = 0")  # 替换为0/空
            else:
                set_clauses.append(f"{field} = %s")
                params.append(replacement)

        params.append(user_id)

        with transaction.atomic():
            connections["default"].cursor().execute(
                f"UPDATE {table} SET {', '.join(set_clauses)} WHERE {user_column} = %s",
                params,
            )

    def _cleanup_archived_user_data(self, user_id: int):
        """清理归档存储中的用户数据"""
        # 查询归档元数据，找到包含该用户数据的 Parquet 文件
        # 重新生成不含该用户数据的文件
        # 这一步通常异步执行，不在注销流程的关键路径上
        from .tasks import cleanup_archived_user_task

        cleanup_archived_user_task.delay(user_id)
```

```python
# services/archive/compliance.py

from datetime import datetime, timedelta
from dataclasses import dataclass
from typing import Dict


@dataclass
class ComplianceRule:
    """合规保留规则"""
    regulation: str
    data_category: str
    min_retention_days: int
    action_on_expire: str  # "delete" | "anonymize" | "retain"
    requires_consent: bool = False
    notes: str = ""


# 合规保留规则表
COMPLIANCE_RULES: Dict[str, ComplianceRule] = {
    "order": ComplianceRule(
        regulation="电子商务法",
        data_category="交易信息",
        min_retention_days=365 * 3,
        action_on_expire="anonymize",
        notes="订单信息至少保留3年",
    ),
    "payment_record": ComplianceRule(
        regulation="支付清算协会",
        data_category="支付记录",
        min_retention_days=365 * 5,
        action_on_expire="retain",
        notes="支付记录保留5年",
    ),
    "audit_log": ComplianceRule(
        regulation="网络安全法",
        data_category="网络日志",
        min_retention_days=180,
        action_on_expire="anonymize",
        notes="网络日志至少保留180天",
    ),
    "user": ComplianceRule(
        regulation="个人信息保护法",
        data_category="个人信息",
        min_retention_days=0,  # 处理目的达成即可删除
        action_on_expire="delete",
        requires_consent=True,
        notes="用户注销后应删除个人信息",
    ),
    "student_profile": ComplianceRule(
        regulation="儿童个人信息网络保护规定",
        data_category="儿童个人信息",
        min_retention_days=0,
        action_on_expire="delete",
        notes="监护人要求时应立即删除",
    ),
}


def validate_retention_compliance(table_name: str, proposed_retention_days: int) -> bool:
    """
    校验提议的保留天数是否满足合规要求
    在加载 lifecycle rules 时调用
    """
    if table_name not in COMPLIANCE_RULES:
        return True  # 无特殊合规要求

    rule = COMPLIANCE_RULES[table_name]
    return proposed_retention_days >= rule.min_retention_days


def get_max_retention_days(table_name: str) -> int:
    """获取某表的最大合规保留天数"""
    if table_name not in COMPLIANCE_RULES:
        return 365 * 3  # 默认3年

    return COMPLIANCE_RULES[table_name].min_retention_days
```

```python
class ArchiveManagementViewSet(viewsets.ViewSet):
    """
    归档管理 API
    管理后台使用，需要管理员权限
    """
    permission_classes = [IsAdminUser]

    @action(detail=False, methods=["get"])
    def rules(self, request):
        """获取所有数据生命周期规则"""
        rules = get_all_rules()
        serializer = ArchiveRuleSerializer(rules, many=True)
        return Response(serializer.data)

    @action(detail=False, methods=["get"])
    def dashboard(self, request):
        """归档概览面板数据"""
        # 各表当前数据量与分布
        tables = ["learning_activity_log", "ai_conversation", "ai_message",
                   "answer_record", "mistake_record", "audit_log", "order"]

        dashboard_data = []
        for table in tables:
            tracking = DataLifecycleTracking.objects.filter(table_name=table)
            hot_count = tracking.filter(lifecycle_stage="hot").aggregate(
                total=models.Sum("record_count")
            )["total"] or 0
            warm_count = tracking.filter(lifecycle_stage="warm").aggregate(
                total=models.Sum("record_count")
            )["total"] or 0
            cold_count = tracking.filter(lifecycle_stage="cold").aggregate(
                total=models.Sum("record_count")
            )["total"] or 0

            dashboard_data.append({
                "table": table,
                "hot_records": hot_count,
                "warm_records": warm_count,
                "cold_records": cold_count,
                "total_records": hot_count + warm_count + cold_count,
            })

        return Response(dashboard_data)

    @action(detail=False, methods=["post"])
    def trigger_archive(self, request):
        """
        手动触发归档任务
        body: {
            "table_name": "learning_activity_log",
            "action": "hot_to_warm" | "warm_to_cold" | "destroy",
            "dry_run": true
        }
        """
        table_name = request.data.get("table_name")
        action = request.data.get("action", "hot_to_warm")
        dry_run = request.data.get("dry_run", True)

        if not table_name:
            return Response(
                {"error": "table_name 必填"},
                status=status.HTTP_400_BAD_REQUEST,
            )

        rule = get_rule(table_name)
        engine = ArchiveEngine(rule)

        if action == "hot_to_warm":
            result = engine.run_hot_to_warm(dry_run=dry_run)
        elif action == "warm_to_cold":
            result = engine.run_warm_to_cold(dry_run=dry_run)
        elif action == "destroy":
            result = engine.run_destroy(dry_run=dry_run)
        else:
            return Response(
                {"error": f"不支持的 action: {action}"},
                status=status.HTTP_400_BAD_REQUEST,
            )

        return Response(result)

    @action(detail=False, methods=["get"])
    def history(self, request):
        """查询归档历史"""
        queryset = ArchiveMetadata.objects.all().order_by("-created_at")

        # 过滤条件
        table = request.query_params.get("table")
        if table:
            queryset = queryset.filter(source_table=table)

        status_filter = request.query_params.get("status")
        if status_filter:
            queryset = queryset.filter(status=status_filter)

        page = self.paginate_queryset(queryset)
        serializer = ArchiveMetadataSerializer(page, many=True)
        return self.get_paginated_response(serializer.data)

    @action(detail=False, methods=["get"])
    def storage_stats(self, request):
        """存储用量统计"""
        from django.db.models import Sum

        stats = (
            DataLifecycleTracking.objects
            .values("table_name", "lifecycle_stage")
            .annotate(
                total_records=Sum("record_count"),
                total_bytes=Sum("storage_bytes"),
            )
            .order_by("table_name", "lifecycle_stage")
        )

        return Response(list(stats))
```

## 10. 错误处理与回滚

### 10.1 归档失败处理策略

| 错误场景 | 处理策略 | 自动恢复 |
|---------|---------|---------|
| MySQL 导出超时 | 降低 batch_size，增加 sleep 间隔 | ✅ 自动重试 3 次 |
| ClickHouse 导入失败 | 保留临时文件，标记 FAILED | ✅ 自动重试 |
| 数据校验不一致 | 保留源数据不动，标记 FAILED | ⚠️ 人工介入 |
| 对象存储写入失败 | 保留临时文件，标记 FAILED | ✅ 自动重试 |
| 删除源数据失败 | 不影响已导入数据，重试删除 | ✅ 自动重试 |
| 磁盘空间不足 | 中止归档，告警 | ❌ 人工介入 |

### 10.2 回滚机制

```python
# services/archive/rollback.py

import logging
from services.archive.models import ArchiveMetadata
from services.archive.engine import ArchiveStatus

logger = logging.getLogger(__name__)


class ArchiveRollbackService:
    """
    归档回滚服务
    当归档出现严重问题时，回滚已导入的数据
    """

    def rollback_batch(self, batch_id: str):
        """
        回滚指定批次的归档操作
        1. 如果数据已导入 ClickHouse，删除已导入数据
        2. 如果数据已导出到对象存储，删除文件
        3. 将批次状态标记为 ROLLED_BACK
        """
        metadata = ArchiveMetadata.objects.filter(archive_batch=batch_id).first()
        if not metadata:
            raise ValueError(f"未找到批次: {batch_id}")

        logger.info(f"[Rollback] 开始回滚批次: {batch_id}")

        try:
            if metadata.target_type == "clickhouse":
                self._rollback_clickhouse_import(metadata)
            elif metadata.target_type in ("oss_standard", "oss_archive"):
                self._rollback_oss_upload(metadata)

            metadata.status = ArchiveStatus.ROLLED_BACK
            metadata.error_message = f"手动回滚: {metadata.error_message or ''}"
            metadata.save()

            logger.info(f"[Rollback] 回滚完成: {batch_id}")

        except Exception as e:
            logger.error(f"[Rollback] 回滚失败: {e}", exc_info=True)
            raise

    def _rollback_clickhouse_import(self, metadata: ArchiveMetadata):
        """回滚 ClickHouse 导入"""
        from clickhouse_driver import Client
        from django.conf import settings

        client = Client(
            host=settings.CLICKHOUSE_HOST,
            port=settings.CLICKHOUSE_PORT,
            database=settings.CLICKHOUSE_DATABASE,
        )

        # 根据归档元数据中的时间范围删除
        client.execute(
            f"""
            ALTER TABLE {metadata.source_table}
            DELETE WHERE created_at >= %(start)s AND created_at < %(end)s
            """,
            {
                "start": metadata.date_range_start,
                "end": metadata.date_range_end,
            },
        )

    def _rollback_oss_upload(self, metadata: ArchiveMetadata):
        """回滚对象存储上传"""
        import boto3
        from django.conf import settings

        s3 = boto3.client(
            "s3",
            endpoint_url=settings.OSS_ENDPOINT,
            aws_access_key_id=settings.OSS_ACCESS_KEY,
            aws_secret_access_key=settings.OSS_SECRET_KEY,
        )

        if metadata.target_path:
            s3.delete_object(
                Bucket=settings.OSS_BUCKET, Key=metadata.target_path
            )
```

本文档定义了 PrimeTop 数据归档与生命周期管理的完整策略，覆盖：

1. **五级生命周期**：热→温→冷→冰→销毁，每级有明确的时间阈值和存储介质
2. **自动化归档引擎**：基于 Celery 定时任务，分批导出/导入/校验/清理，支持失败重试和回滚
3. **跨层透明查询**：查询路由器自动判断数据所在层级，对业务代码透明
4. **合规保留策略**：对接《个人信息保护法》《电子商务法》等法规，确保数据保留和销毁合规
5. **用户注销清理**：完整的用户数据清理流程，覆盖在线和归档数据
6. **监控告警体系**：Prometheus 指标 + Grafana 面板，实时监控归档健康度

关键设计原则：
- **渐进式归档**：不一次移动大量数据，分批分步降低风险
- **数据安全优先**：先导入校验通过，再删除源数据
- **成本可控**：冷数据使用低成本存储介质，热点数据量可控
- **合规先行**：所有保留规则需先通过合规校验
