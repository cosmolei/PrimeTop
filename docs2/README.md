# docs2 - 详细设计文档目录

本目录存放 PrimeTop 项目各功能模块的详细设计文档，供开发人员直接参考编码。

## 文档来源

原始设计文档位于 `docs/design/` 目录，本文档在其基础上进行细化，补充数据结构、API 接口、状态流转、错误处理和关键代码示例。
