# docs2 目录说明

本目录用于存放 PrimeTop 项目的详细设计文档，在原始设计文档（位于 `docs/design` 目录）基础上进行细化和扩展。这些文档旨在为开发人员提供可直接开始编码的技术方案与实现细节。

## 目录用途
- 基于项目总体设计文档，对各类功能点/模块进行详细设计
- 包含数据结构定义、API接口设计、关键代码示例、状态流转、错误处理等
- 提供开发者可直接参考的编码实现规范与流程设计

## 文件命名规范
- 文件名格式：`模块名-详细设计.md` 或 `功能点-详细设计.md`
- 建议以功能/模块名称开头，便于检索和维护

## 更新规范
- 每次仅针对一个具体功能点/模块进行细化，避免在同一功能上反复钻牛角尖
- 细化时需确保内容完整、具备可执行性，且需与原始设计保持一致
- 文件编码采用 UTF-8
- 新增或修改完成后执行 git 操作：
  ```bash
  $env:HTTP_PROXY='http://127.0.0.1:7897'; $env:HTTPS_PROXY='http://127.0.0.1:7897'
  git add .
  git commit -m "细化设计：模块名"
  git push
  ```

## 注意事项
- 严格禁止修改 `docs/design` 目录下的原始文件
- 如需追溯设计依据，请参考对应 `docs/design` 中的原始设计章节
