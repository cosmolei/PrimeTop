## 文档使用指南

### 对于开发人员
1. **首次接入权限系统**：先阅读 `权限管理与角色访问控制-详细设计.md`，了解整体架构
2. **客户端系统权限**：参考 `客户端系统权限管理与运行时授权框架-详细设计.md`
3. **快速集成**：使用 `用户权限管理-详细设计.md` 中的代码示例和 API 文档

### 对于架构设计人员
1. 从 `权限管理与角色访问控制-详细设计.md` 了解权限体系设计思路
2. 参考 `用户权限管理-详细设计.md` 查看数据结构和接口设计细节
3. 根据项目需求调整权限模型和策略

### 对于测试人员
1. 根据 `用户权限管理-详细设计.md` 中的测试要点编写测试用例
2. 参考各文档中的状态流转图设计测试场景
3. 使用错误码定义进行异常测试

### 客户端推送通知
- **[客户端-推送通知通道集成与本地提醒调度引擎-详细设计.md](./客户端-推送通知通道集成与本地提醒调度引擎-详细设计.md)**

  - 通知渠道体系、权限管理、免打扰时段、内容脱敏与未成年人保护
  - 适用对象：客户端开发、移动端开发
