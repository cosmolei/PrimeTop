# docs2 - 详细设计文档目录

## 目录用途

本目录存放 PrimeTop 项目的详细设计文档，用于将主设计文档（`docs/design` 目录）中的功能模块细化到可编码实现的程度。

## 文档标准

每个详细设计文档应包含以下内容：

1. **概述**：模块功能定位、目标、适用范围
2. **数据结构定义**：数据库表设计、数据模型、字段说明
3. **API 接口设计**：RESTful 接口定义、请求/响应格式
4. **关键代码示例**：核心算法、业务逻辑、数据处理流程
5. **状态流转**：业务状态机、状态转换条件
6. **错误处理**：异常场景、错误码、降级策略
7. **性能优化**：缓存策略、查询优化、并发控制
8. **安全与合规**：权限控制、数据脱敏、内容审核

## 文档规范

- **文件编码**：UTF-8
- **文件命名**：`模块名-详细设计.md`
- **Markdown 格式**：使用标准 Markdown 语法
- **代码块**：使用语言标识符（如 `python`、`java`、`sql`）

## 维护原则

1. **不修改原始设计**：绝对不能修改 `docs/design` 目录下的原始文件
2. **渐进式细化**：每次针对一个功能点进行细化，避免钻牛角尖
3. **可编码导向**：细化程度应让开发人员能直接开始编码
4. **版本同步**：每次更新后进行 git commit 和 push
