# docs2 - 详细设计文档

本目录存放基于 `docs/design` 目录下原始设计文档的**细化设计文档**。

## 目的

将高层设计转化为开发人员可直接编码的详细设计，包括：
- 数据结构定义（数据库表结构、字段说明）
- API 接口设计（路径、方法、请求/响应体）
- 状态流转图
- 关键代码示例
- 错误处理策略
- 边界条件与注意事项

## 约定

- 文件命名：`模块名-详细设计.md`
- 每个文件聚焦一个功能模块
- 所有接口设计遵循 RESTful 风格
- 数据库使用 PostgreSQL，缓存使用 Redis
- 时间字段统一使用 ISO 8601 格式（`yyyy-MM-dd'T'HH:mm:ss.SSS'Z'`），存储为 UTC
