# 服务端-大模型推理流式输出全链路保障与异常恢复引擎-详细设计

## 1. 概述

### 1.1 功能定位

本模块负责 PrimeTop 平台 AI 大模型推理流式输出（SSE/Streaming）场景下的全链路可靠性保障，包括流式会话状态管理、中断检测与恢复、不完整回答处理、多模型容灾切换以及流式质量监控。

### 1.2 问题背景

PrimeTop 的 AI 辅导对话、解题推导、作文批改等核心场景均依赖大模型流式输出（Server-Sent Events）。在实际生产环境中，流式输出面临以下挑战：

| 问题场景 | 发生频率 | 影响 |
| --- | --- | --- |
| 客户端网络抖动导致 SSE 连接断开 | 高 | 学生看到回答断在中间，体验割裂 |
| 服务端网关/代理超时切断长连接 | 中 | 流式中断，已生成内容丢失 |
| 大模型推理过程中服务端异常 | 低 | 整个回答不可用 |
| 客户端 App 崩溃或被系统杀死 | 中 | 学生重进后找不到之前的回答 |
| 弱网环境下心跳丢失误判断连 | 高 | 不必要的重连和重复生成 |
| 模型生成内容过长导致超时 | 中 | 后半段内容无法送达 |

**核心矛盾**：教育场景对回答完整性和准确性要求极高——半句解题步骤可能误导学生，因此必须保障流式输出"要么完整送达，要么优雅降级"，绝不能呈现断裂、不完整的教育内容。

### 1.3 设计目标

1. **中断可恢复**：流式输出中断后，客户端可在 3 秒内通过恢复协议获取剩余内容。
2. **内容不丢失**：已生成但未送达客户端的内容不会因连接断开而丢失。
3. **幂等安全**：恢复请求不会导致重复生成或重复计费。
4. **透明降级**：无法恢复时，提供明确的降级策略（非流式补全、换模型重试、提示用户）。
5. **教育完整性校验**：恢复后对回答完整性进行校验，拒绝呈现断裂的教育内容。
6. **可观测**：全链路流式输出质量可监控、可告警、可追溯。

### 1.4 适用范围

- AI 辅导对话（多轮问答、解题推导）
- 拍照搜题解析（分步解析流式输出）
- 作文批改（结构化反馈流式输出）
- 背诵检测反馈
- AI 语音对话（TTS 流式输出场景适配）

### 1.5 与现有模块的关系

| 现有模块 | 关系 |
| --- | --- |
| SSE 流式响应与 AI 增量渲染引擎 | 本模块增强其异常处理能力，提供中断恢复协议 |
| AI 模型调用多供应商容灾切换与自动降级引擎 | 本模块在流式场景下调用其容灾能力 |
| 错误处理与服务降级策略 | 本模块遵循统一错误码体系，补充流式场景特有错误 |
| 客户端网络请求治理与弱网适配方案 | 本模块提供服务端恢复接口，客户端模块负责重连逻辑 |
| 多模态输入统一处理与智能路由引擎 | 本模块保障路由后流式推理的可靠性 |

### 2.2 核心组件职责

| 组件 | 职责 | 部署位置 |
| --- | --- | --- |
| **流式会话状态管理器** (StreamSessionStateManager) | 管理流式会话生命周期状态，跟踪每个流式请求的当前状态 | 服务端 |
| **响应片段存储管理器** (ResponseFragmentBuffer) | 将模型生成的增量内容实时写入 Redis，按序列号索引 | 服务端 + Redis |
| **恢复决策器** (RecoveryDecisioner) | 根据中断原因、已生成内容比例、模型状态等决定恢复策略 | 服务端 |
| **完整性校验器** (CompletenessValidator) | 校验恢复后或完成后的回答是否结构完整（Markdown闭合、LaTeX闭合、步骤完整） | 服务端 |
| **心跳管理器** (HeartbeatManager) | 维持 SSE 连接活性，检测静默断连 | 服务端 + 客户端 |
| **超时管理器** (TimeoutManager) | 管理流式输出的各类超时（首token、总时长、单chunk间隔） | 服务端 |
| **质量监控器** (QualityMonitor) | 采集流式输出质量指标，对接监控告警系统 | 服务端 |

```

**状态枚举 (StreamSessionStatus)**：

| 状态 | 说明 | 后续可转移状态 |
| --- | --- | --- |
| `CREATED` | 会话创建，尚未开始推理 | `STREAMING`, `FAILED`, `TIMEOUT` |
| `STREAMING` | 推理进行中，正在生成并推送 | `COMPLETED`, `INTERRUPTED`, `FAILED`, `TIMEOUT` |
| `COMPLETED` | 推理完成且全部内容已确认送达客户端 | （终态） |
| `INTERRUPTED` | 连接断开，推理可能仍在进行或已停止 | `RESUMING`, `COMPLETED`, `FAILED` |
| `RESUMING` | 客户端发起恢复请求 | `COMPLETED`, `FAILED` |
| `FAILED` | 推理失败或恢复失败 | （终态） |
| `TIMEOUT` | 超时（首token超时/总时长超时/单chunk间隔超时） | `FAILED` |
| `CANCELLED` | 用户主动取消 | （终态） |

### 3.2 响应片段 (StreamChunk)

存储在 Redis 中，使用 Redis List 存储，Key 格式：`stream:chunks:{sessionId}`

每个 chunk 的结构：

```json
{
  "seq": 0,
  "type": "TOKEN",
  "content": "解这道题",
  "delta": "解这道题",
  "timestamp": "2026-07-31T10:30:01.500Z",
  "tokenCount": 4,
  "cumulativeTokens": 4
}
```

**Chunk 类型枚举**：

| 类型 | 说明 |
| --- | --- |
| `TOKEN` | 模型生成的文本增量 |
| `THINKING` | 推理过程标记（如 CoT 链） |
| `FORMAT` | 格式标记（如 Markdown 标题、代码块开始/结束） |
| `CITATION` | 知识来源引用 |
| `IMAGE_PLACEHOLDER` | 图片占位符（如公式渲染、图表） |
| `SAFETY_FILTERED` | 安全过滤替换标记 |
| `DONE` | 模型生成结束标记 |
| `ERROR` | 推理错误标记 |

### 3.3 客户端确认记录 (ClientAckRecord)

### 5.2 中断检测机制

#### 5.2.1 服务端检测

```python
class InterruptionDetector:
    """中断检测器：多维度检测流式输出是否中断"""

    # 检测策略配置
    DETECTION_CONFIG = {
        # 心跳超时：超过 N 秒未收到客户端 ACK
        "client_ack_timeout_sec": 15,
        # 心跳发送间隔
        "heartbeat_interval_sec": 5,
        # 心跳响应超时：发送 ping 后 N 秒未收到 pong
        "heartbeat_response_timeout_sec": 10,
        # 写入失败重试次数
        "write_failure_retry": 3,
        # 写入失败重试间隔
        "write_failure_retry_interval_ms": 500,
    }

    async def detect_interruption(self, session: StreamSession) -> Optional[str]:
        """
        检测是否发生中断，返回中断原因或 None
        """
        # 1. 检查客户端 ACK 超时
        ack_age = time.time() - session.last_ack_timestamp
        if ack_age > self.DETECTION_CONFIG["client_ack_timeout_sec"]:
            return "CLIENT_ACK_TIMEOUT"

        # 2. 检查心跳响应
        if session.pending_heartbeat:
            ping_age = time.time() - session.last_heartbeat_sent
            timeout = self.DETECTION_CONFIG["heartbeat_response_timeout_sec"]
            if ping_age > timeout:
                return "HEARTBEAT_TIMEOUT"

        # 3. 检查写入异常
        if session.consecutive_write_failures >= self.DETECTION_CONFIG["write_failure_retry"]:
            return "WRITE_FAILURE"

        return None
```

#### 5.2.2 客户端检测

客户端通过以下信号判断 SSE 连接是否中断：

| 信号 | 判定逻辑 | 延迟 |
| --- | --- | --- |
| `EventSource` onerror 回调 | 浏览器/原生网络层报告连接错误 | 即时 ~ 30s |
| 心跳超时 | 超过 N 秒未收到服务端心跳 | 10 ~ 15s |
| Chunk 间隔超时 | 超过 N 秒未收到新 chunk（排除模型思考时间） | 30 ~ 60s |
| App 生命周期事件 | App 进入后台/被系统杀死后恢复 | 即时 |

### 5.5 恢复策略详解

#### 5.5.1 CACHE_REPLAY（缓存重放）

**适用场景**：推理仍在进行或已完成，客户端只需追赶已有内容。

**流程**：
1. 从 Redis 读取 `lastReceivedSeq + 1` 开始的所有 chunks
2. 以批量化方式快速推送给客户端（适当合并小 chunk，减少 SSE 事件数）
3. 如果推理仍在进行，追赶完毕后无缝切换到实时推送
4. 如果推理已完成，推送完毕后发送 `DONE` 事件

**性能要求**：
- 追赶延迟 < 500ms（首 chunk 到达客户端）
- 追赶吞吐 > 100 chunks/s

#### 5.5.2 MODEL_RESUME（模型续写）

**适用场景**：推理已停止，已生成内容不完整（如 Markdown 代码块未闭合、解题步骤未完成）。

**流程**：
1. 从 Redis 读取全部已生成 chunks，拼接为 `partial_content`
2. 检查 `partial_content` 的结构完整性（见 5.6 节）
3. 构造续写 Prompt：
   ```
   请继续以下未完成的教育内容输出，保持风格和格式一致：

   ---已生成内容---
   {partial_content}
   ---结束---

   请从中断处自然续写，不要重复已生成的内容。
   ```
4. 使用同一模型重新发起流式推理
5. 将新生成的 chunks 续接在已有 chunks 之后
6. 新 chunk 的 seq 从 `lastChunkSeq + 1` 继续

**注意事项**：
- 模型续写可能产生少量重复内容（重叠区域），需在客户端做去重处理
- 续写最多重试 `maxRetries`（默认 2）次
- 续写场景记录到质量监控，标记为 `model_resume`

#### 5.5.3 FALLBACK（模型降级）

**适用场景**：原模型不可用或续写失败，需要切换到备选模型重新生成。

**流程**：
1. 从备选模型列表中选择一个（按优先级排序）
2. 使用原始 Prompt + 已生成部分作为参考，发起全新推理
3. 新推理结果完全替换原有 chunks（从 seq=0 开始）
4. 客户端收到 `event=restart` 通知，清空本地缓存重新渲染

**备选模型优先级**：
```python
FALLBACK_MODEL_CHAIN = [
    {"provider": "openai", "model": "gpt-4-turbo", "priority": 1},
    {"provider": "anthropic", "model": "claude-3-sonnet", "priority": 2},
    {"provider": "zhipu", "model": "glm-4", "priority": 3},
    {"provider": "qwen", "model": "qwen-max", "priority": 4},
]
```

#### 5.5.4 GRACEFUL_FAIL（优雅降级）

**适用场景**：所有恢复策略均失败，无法提供完整 AI 回答。

**降级方案**：
1. 如果已有部分内容且通过了结构完整性校验 → 返回部分内容 + 免责提示
2. 如果内容不完整 → 返回友好提示 + 建议重试
3. 退还本次调用的 AI 额度（不计费）
4. 记录失败日志用于后续分析

**用户提示模板**：
```
😅 抱歉，回答过程中遇到了网络波动。

已为您恢复部分内容（约 60%），但剩余部分未能成功加载。
建议您：
1. 重新提问获取完整回答
2. 换一种方式描述问题
3. 稍后重试

本次提问不消耗使用次数。
```

### 5.6 回答完整性校验

```python
class CompletenessValidator:
    """
    校验 AI 流式输出的结构完整性
    教育内容必须结构完整，避免断裂的公式、步骤或代码块误导学生
    """

    # 需要配对的结构标记
    PAIRED_MARKERS = [
        ("```", "```"),          # 代码块
        ("$$", "$$"),            # 块级 LaTeX 公式
        ("\\[", "\\]"),         # LaTeX 块公式
        ("|", "|"),             # 表格行（需在表格上下文中）
    ]

    # 需要闭合的 Markdown 结构
    MD_CLOSURES = {
        "**": "**",
        "*": "*",
        "__": "__",
        "~~": "~~",
        "`": "`",
        "(": ")",
        "[": "]",
    }

    def validate(self, content: str, scene: str) -> ValidationResult:
        """
        校验内容完整性
        返回：(is_complete, issues, completion_suggestion)
        """
        issues = []

        # 1. 代码块完整性
        code_block_count = content.count("```")
        if code_block_count % 2 != 0:
            issues.append({
                "type": "UNCLOSED_CODE_BLOCK",
                "severity": "HIGH",
                "message": "代码块未闭合",
                "position": content.rfind("```")
            })

        # 2. LaTeX 公式完整性
        dollar_count = content.count("$$")
        if dollar_count % 2 != 0:
            issues.append({
                "type": "UNCLOSED_LATEX",
                "severity": "HIGH",
                "message": "LaTeX 块级公式未闭合",
                "position": content.rfind("$$")
            })

        # 3. 行内 LaTeX 检查
        inline_latex_pattern = r'(?<!\$)\$(?!\$)(.+?)(?<!\$)\$(?!\$)'
        inline_matches = re.findall(inline_latex_pattern, content)
        # 检查是否有未配对的 $（排除 $$ 后的剩余 $）

        # 4. 步骤完整性（教育场景特有）
        if scene in ("ai_tutoring", "photo_search"):
            step_pattern = re.findall(
                r'(?:步骤|Step)\s*\d+[：:）)]', content, re.IGNORECASE
            )
            if step_pattern:
                # 检查最后的步骤是否完整
                last_step = step_pattern[-1]
                last_step_pos = content.rfind(last_step)
                after_step = content[last_step_pos + len(last_step):]
                if len(after_step.strip()) < 10:
                    issues.append({
                        "type": "INCOMPLETE_STEP",
                        "severity": "MEDIUM",
                        "message": f"最后一步 '{last_step}' 内容可能不完整",
                        "position": last_step_pos
                    })

        # 5. 列表完整性
        # 检查列表是否被截断（最后一个列表项后没有总结/结论）
        list_pattern = re.findall(r'^[\-\*\d+\.]\s+.+', content, re.MULTILINE)
        if list_pattern and not re.search(
            r'(因此|综上|所以|总之|结论|最终|Answer|Result|答案)',
            content[-200:],
            re.IGNORECASE
        ):
            issues.append({
                "type": "POSSIBLE_MISSING_CONCLUSION",
                "severity": "LOW",
                "message": "列表/步骤结束但未检测到结论性内容"
            })

        # 6. 段落完整性
        if content and not content.endswith(('.', '。', '!', '！', '?', '？', '\n\n', '```')):
            issues.append({
                "type": "POSSIBLE_TRUNCATION",
                "severity": "MEDIUM",
                "message": "内容末尾缺少自然结束标点，可能被截断"
            })

        is_complete = len([i for i in issues if i["severity"] in ("HIGH", "MEDIUM")]) == 0

        suggestion = self._get_completion_suggestion(issues, content)

        return ValidationResult(
            is_complete=is_complete,
            issues=issues,
            completion_suggestion=suggestion
        )

    def _get_completion_suggestion(self, issues: list, content: str) -> str:
        """生成续写建议 Prompt"""
        suggestions = []
        for issue in issues:
            if issue["type"] == "UNCLOSED_CODE_BLOCK":
                suggestions.append("请补全未闭合的代码块内容")
            elif issue["type"] == "UNCLOSED_LATEX":
                suggestions.append("请补全未闭合的数学公式")
            elif issue["type"] == "INCOMPLETE_STEP":
                suggestions.append("请完成最后的解题步骤")
            elif issue["type"] == "POSSIBLE_MISSING_CONCLUSION":
                suggestions.append("请补充总结或结论")
        return "；".join(suggestions) if suggestions else ""
```

## 7. 心跳与超时设计

### 7.1 心跳机制

```
服务端                                    客户端
  │                                        │
  │  正常流式 chunk 推送中                  │
  │  (chunk 本身就是活跃信号)              │
  │───────────────────────────────────────►│
  │                                        │
  │  [5秒无新 chunk]                       │
  │  发送心跳                              │
  │  event: heartbeat                     │
  │  data: {"ts":1722409815}              │
  │───────────────────────────────────────►│
  │                                        │
  │  客户端回复 ack（可选）                 │
  │  POST /stream/heartbeat/{sessionId}   │
  │◄───────────────────────────────────────│
  │                                        │
  │  [心跳发出后10秒无 ack]                │
  │  判定连接可能断开                      │
  │  会话状态 → INTERRUPTED                │
  │                                        │
```

**心跳参数配置**：

```python
HEARTBEAT_CONFIG = {
    # 空闲多久后发送心跳（无 chunk 推送的间隙）
    "idle_threshold_sec": 5,
    # 心跳间隔（固定间隔发送，防止 NAT 超时）
    "heartbeat_interval_sec": 8,
    # 心跳响应超时
    "response_timeout_sec": 10,
    # 连续心跳失败后判定中断
    "max_heartbeat_failures": 2,
    # NAT 保活间隔（比常见 60s NAT 超时短）
    "nat_keepalive_sec": 30,
}
```

### 7.2 超时体系

| 超时类型 | 默认值 | 说明 | 超时后行为 |
| --- | --- | --- | --- |
| 连接建立超时 | 5s | 从请求到 SSE 连接建立的等待时间 | 返回 503 + 建议重试 |
| 首 Token 超时 | 15s | 等待模型输出第一个 token 的时间 | 触发模型降级或返回超时提示 |
| 单 Chunk 间隔超时 | 30s | 两个 chunk 之间的最大间隔（排除模型思考阶段） | 发送心跳探测 → 判定中断 |
| 总推理超时 | 120s | 整个流式推理的最大允许时长 | 中止推理 + 降级处理 |
| 恢复请求超时 | 10s | 恢复请求的处理时间 | 返回恢复失败 + 建议重新提问 |
| 会话 TTL | 30min | 流式会话在 Redis 中的存活时间 | 过期清理，不可恢复 |

class TimeoutManager:
    """流式输出超时管理器"""

    TIMEOUTS = {
        "connection_establish": 5_000,       # 5s
        "first_token": 15_000,              # 15s
        "chunk_interval": 30_000,           # 30s
        "total_inference": 120_000,         # 120s
        "recovery_process": 10_000,         # 10s
        "session_ttl": 30 * 60 * 1000,     # 30min
    }

    def __init__(self, redis_client):
        self.redis = redis_client
        self._timers = {}  # sessionId -> {timer_type: timer}

    async def start_first_token_timer(self, session_id: str):
        """启动首 Token 超时计时器"""
        timer = asyncio.create_task(
            self._first_token_timeout(session_id)
        )
        self._timers.setdefault(session_id, {})["first_token"] = timer

    async def cancel_first_token_timer(self, session_id: str):
        """取消首 Token 超时计时器（收到首 token 后调用）"""
        timer = self._timers.get(session_id, {}).pop("first_token", None)
        if timer:
            timer.cancel()

    async def _first_token_timeout(self, session_id: str):
        """首 Token 超时处理"""
        try:
            await asyncio.sleep(self.TIMEOUTS["first_token"] / 1000)
            # 超时未收到首 token
            await self._handle_first_token_timeout(session_id)
        except asyncio.CancelledError:
            pass

    async def _handle_first_token_timeout(self, session_id: str):
        """处理首 Token 超时"""
        session = await self._get_session(session_id)
        if session.status != "STREAMING":
            return  # 可能刚好在超时前收到了

        logger.warning(
            f"First token timeout for session {session_id}, "
            f"provider={session.model_provider}, model={session.model_name}"
        )

        # 尝试模型降级
        if session.retry_count < session.max_retries:
            await self._trigger_model_fallback(session, reason="FIRST_TOKEN_TIMEOUT")
        else:
            # 超过重试次数，直接失败
            await self._fail_session(
                session_id,
                reason="FIRST_TOKEN_TIMEOUT",
                error_code="MODEL_UNRESPONSIVE",
                message="AI 正在思考中，请稍后重试"
            )

```python
"""
StreamingGuardEngine - 流式输出全链路保障引擎核心控制器
"""

import asyncio
import hashlib
import json
import time
import uuid
from dataclasses import dataclass, field
from enum import Enum
from typing import AsyncGenerator, Optional

import redis.asyncio as aioredis
from fastapi import Request
from fastapi.responses import StreamingResponse


class StreamStatus(str, Enum):
    CREATED = "CREATED"
    STREAMING = "STREAMING"
    COMPLETED = "COMPLETED"
    INTERRUPTED = "INTERRUPTED"
    RESUMING = "RESUMING"
    FAILED = "FAILED"
    TIMEOUT = "TIMEOUT"
    CANCELLED = "CANCELLED"


@dataclass
class StreamSession:
    session_id: str
    user_id: str
    conversation_id: str
    model_provider: str
    model_name: str
    prompt_hash: str
    status: StreamStatus = StreamStatus.CREATED
    total_chunks: int = 0
    total_tokens: int = 0
    last_chunk_seq: int = -1
    last_client_ack_seq: int = -1
    retry_count: int = 0
    max_retries: int = 2
    created_at: float = field(default_factory=time.time)
    updated_at: float = field(default_factory=time.time)
    metadata: dict = field(default_factory=dict)

    def to_dict(self) -> dict:
        return {
            "sessionId": self.session_id,
            "userId": self.user_id,
            "conversationId": self.conversation_id,
            "modelProvider": self.model_provider,
            "modelName": self.model_name,
            "promptHash": self.prompt_hash,
            "status": self.status.value,
            "totalChunks": self.total_chunks,
            "totalTokens": self.total_tokens,
            "lastChunkSeq": self.last_chunk_seq,
            "lastClientAckSeq": self.last_client_ack_seq,
            "retryCount": self.retry_count,
            "maxRetries": self.max_retries,
            "createdAt": self.created_at,
            "updatedAt": self.updated_at,
            "metadata": self.metadata,
        }


class StreamingGuardEngine:
    """
    流式保障引擎：管理流式会话生命周期、中断恢复、完整性校验
    """

    # Redis Key 前缀
    SESSION_KEY = "stream:session:{session_id}"
    CHUNKS_KEY = "stream:chunks:{session_id}"
    ACK_KEY = "stream:ack:{session_id}"

    # 会话 TTL（30分钟）
    SESSION_TTL = 30 * 60

    # Chunk 批量推送大小
    CHUNK_BATCH_SIZE = 5

    def __init__(
        self,
        redis: aioredis.Redis,
        model_dispatcher,        # AI模型调度器
        completeness_validator,   # 完整性校验器
        quality_monitor,          # 质量监控器
    ):
        self.redis = redis
        self.model_dispatcher = model_dispatcher
        self.validator = completeness_validator
        self.monitor = quality_monitor
        self._active_sessions: dict[str, StreamSession] = {}

    async def create_stream_session(
        self,
        user_id: str,
        conversation_id: str,
        prompt: str,
        context: dict,
        options: dict,
    ) -> StreamSession:
        """创建流式会话"""
        session_id = self._gen_session_id()
        prompt_hash = hashlib.sha256(prompt.encode()).hexdigest()

        # 选择模型
        model_info = await self.model_dispatcher.select_model(
            scene=context.get("scene", "ai_tutoring"),
            subject=context.get("subject"),
            model_preference=options.get("model", "auto"),
        )

        session = StreamSession(
            session_id=session_id,
            user_id=user_id,
            conversation_id=conversation_id,
            model_provider=model_info["provider"],
            model_name=model_info["model"],
            prompt_hash=prompt_hash,
            metadata={
                **context,
                "prompt": prompt[:500],  # 截断存储
                "options": options,
            },
        )

        # 持久化到 Redis
        await self.redis.setex(
            self.SESSION_KEY.format(session_id=session_id),
            self.SESSION_TTL,
            json.dumps(session.to_dict()),
        )

        self._active_sessions[session_id] = session
        return session

    async def stream_generate(
        self,
        session: StreamSession,
        request: Request,
    ) -> StreamingResponse:
        """
        执行流式推理并返回 SSE 响应
        核心方法：协调模型推理、chunk存储、推送和异常处理
        """
        async def event_generator():
            try:
                # 发送元数据事件
                yield self._format_sse(
                    event="meta",
                    data=json.dumps({
                        "sessionId": session.session_id,
                        "model": session.model_name,
                        "provider": session.model_provider,
                    }),
                )

                # 更新会话状态
                session.status = StreamStatus.STREAMING
                await self._save_session(session)

                # 记录开始时间
                start_time = time.time()
                first_token_time = None
                chunk_buffer = []

                # 调用模型推理
                async for token_data in self.model_dispatcher.stream_inference(
                    provider=session.model_provider,
                    model=session.model_name,
                    prompt=session.metadata["prompt"],
                    options=session.metadata.get("options", {}),
                ):
                    # 检查客户端是否仍连接
                    if await request.is_disconnected():
                        logger.info(
                            f"Client disconnected for session {session.session_id}"
                        )
                        session.status = StreamStatus.INTERRUPTED
                        await self._save_session(session)
                        break

                    # 处理 token
                    session.last_chunk_seq += 1
                    session.total_chunks += 1
                    session.total_tokens += token_data.get("token_count", 1)
                    session.updated_at = time.time()

                    # 构造 chunk
                    chunk = {
                        "seq": session.last_chunk_seq,
                        "type": token_data.get("type", "TOKEN"),
                        "content": token_data["content"],
                        "timestamp": time.time(),
                        "tokenCount": token_data.get("token_count", 1),
                    }

                    # 写入 Redis（持久化 chunk）
                    await self.redis.rpush(
                        self.CHUNKS_KEY.format(session_id=session.session_id),
                        json.dumps(chunk),
                    )
                    # 延长 chunk 列表的 TTL
                    await self.redis.expire(
                        self.CHUNKS_KEY.format(session_id=session.session_id),
                        self.SESSION_TTL,
                    )

                    # 记录首 token 时间
                    if first_token_time is None:
                        first_token_time = time.time()
                        await self.monitor.record_ttft(
                            session.session_id,
                            int((first_token_time - start_time) * 1000),
                        )

                    # 推送给客户端
                    yield self._format_sse(
                        event="token",
                        id=str(chunk["seq"]),
                        data=json.dumps(chunk),
                    )

                    # 每 N 个 chunk 更新一次会话状态
                    if session.total_chunks % self.CHUNK_BATCH_SIZE == 0:
                        await self._save_session(session)

                # 推理完成
                if session.status != StreamStatus.INTERRUPTED:
                    session.status = StreamStatus.COMPLETED

                    # 发送完成事件
                    yield self._format_sse(
                        event="done",
                        id=str(session.last_chunk_seq + 1),
                        data=json.dumps({
                            "totalTokens": session.total_tokens,
                            "durationMs": int((time.time() - start_time) * 1000),
                            "sessionId": session.session_id,
                        }),
                    )

                # 异步落库和质量上报
                asyncio.create_task(
                    self._post_completion(session, start_time, first_token_time)
                )

            except ModelInferenceError as e:
                session.status = StreamStatus.FAILED
                await self._save_session(session)
                yield self._format_sse(
                    event="error",
                    data=json.dumps({
                        "code": "MODEL_INFERENCE_ERROR",
                        "message": str(e),
                        "retryable": True,
                    }),
                )
                await self.monitor.record_failure(
                    session.session_id, "MODEL_INFERENCE_ERROR"
                )

            except Exception as e:
                logger.exception(
                    f"Stream error for session {session.session_id}: {e}"
                )
                session.status = StreamStatus.FAILED
                await self._save_session(session)
                yield self._format_sse(
                    event="error",
                    data=json.dumps({
                        "code": "INTERNAL_ERROR",
                        "message": "服务异常，请稍后重试",
                        "retryable": True,
                    }),
                )

        return StreamingResponse(
            event_generator(),
            media_type="text/event-stream",
            headers={
                "Cache-Control": "no-cache",
                "Connection": "keep-alive",
                "X-Accel-Buffering": "no",  # Nginx 禁用缓冲
                "X-Stream-Session-Id": session.session_id,
            },
        )

    async def resume_stream(
        self,
        session_id: str,
        last_received_seq: int,
        reason: str,
        request: Request,
    ) -> StreamingResponse:
        """
        恢复中断的流式会话
        """
        session = await self._get_session(session_id)
        if not session:
            raise StreamException(
                code="SESSION_NOT_FOUND",
                message=f"会话 {session_id} 不存在或已过期",
                http_status=404,
            )

        if session.status in (StreamStatus.COMPLETED, StreamStatus.CANCELLED):
            raise StreamException(
                code="SESSION_NOT_RESUMABLE",
                message=f"会话状态为 {session.status}，不可恢复",
                http_status=409,
            )

        recovery_id = f"rc_{uuid.uuid4().hex[:20]}"

        # 决策恢复策略
        strategy = await self._decide_recovery_strategy(
            session, last_received_seq
        )

        logger.info(
            f"Resume session {session_id}: strategy={strategy}, "
            f"from_seq={last_received_seq + 1}, reason={reason}"
        )

        session.status = StreamStatus.RESUMING
        await self._save_session(session)

        async def resume_generator():
            try:
                yield self._format_sse(
                    event="resume",
                    data=json.dumps({
                        "sessionId": session_id,
                        "recoveryId": recovery_id,
                        "fromSeq": last_received_seq + 1,
                        "strategy": strategy,
                    }),
                )

                if strategy == "CACHE_REPLAY":
                    async for event in self._cache_replay(
                        session, last_received_seq, request
                    ):
                        yield event

                elif strategy == "MODEL_RESUME":
                    async for event in self._model_resume(
                        session, last_received_seq, recovery_id, request
                    ):
                        yield event

                elif strategy == "FALLBACK":
                    async for event in self._fallback_regenerate(
                        session, recovery_id, request
                    ):
                        yield event

                elif strategy == "GRACEFUL_FAIL":
                    yield self._format_sse(
                        event="error",
                        data=json.dumps({
                            "code": "RECOVERY_FAILED",
                            "message": "抱歉，回答恢复失败，请重新提问",
                            "refundTokens": True,
                        }),
                    )

            except Exception as e:
                logger.exception(f"Resume failed for {session_id}: {e}")
                yield self._format_sse(
                    event="error",
                    data=json.dumps({
                        "code": "RESUME_INTERNAL_ERROR",
                        "message": "恢复过程中出错",
                        "retryable": False,
                    }),
                )

            finally:
                await self._log_recovery(
                    session_id, recovery_id, last_received_seq,
                    strategy, reason
                )

        return StreamingResponse(
            resume_generator(),
            media_type="text/event-stream",
            headers={
                "Cache-Control": "no-cache",
                "Connection": "keep-alive",
                "X-Accel-Buffering": "no",
                "X-Stream-Recovery-Id": recovery_id,
            },
        )

    async def _cache_replay(
        self,
        session: StreamSession,
        last_received_seq: int,
        request: Request,
    ) -> AsyncGenerator:
        """缓存重放：从 Redis 读取未送达的 chunks 并推送"""
        chunks_key = self.CHUNKS_KEY.format(session_id=session.session_id)

        # 读取从 last_received_seq + 1 开始的所有 chunks
        all_chunks = await self.redis.lrange(chunks_key, 0, -1)

        # 过滤出需要重放的 chunks
        replay_chunks = []
        for chunk_str in all_chunks:
            chunk = json.loads(chunk_str)
            if chunk["seq"] > last_received_seq:
                replay_chunks.append(chunk)

        # 按序列号排序
        replay_chunks.sort(key=lambda c: c["seq"])

        logger.info(
            f"Cache replay for {session.session_id}: "
            f"{len(replay_chunks)} chunks to replay"
        )

        # 批量推送（合并小 chunk 加快追赶速度）
        batch = []
        for chunk in replay_chunks:
            if await request.is_disconnected():
                session.status = StreamStatus.INTERRUPTED
                await self._save_session(session)
                return

            batch.append(chunk)
            if len(batch) >= 3:  # 每3个chunk合并推送一次
                yield self._format_sse(
                    event="token_batch",
                    data=json.dumps({"chunks": batch}),
                )
                batch = []

        # 推送剩余
        if batch:
            yield self._format_sse(
                event="token_batch",
                data=json.dumps({"chunks": batch}),
            )

        # 检查推理是否已完成
        if session.status == StreamStatus.COMPLETED or session.total_chunks > 0:
            # 检查是否所有 chunk 都已重放
            if replay_chunks and replay_chunks[-1]["seq"] >= session.last_chunk_seq:
                session.status = StreamStatus.COMPLETED
                await self._save_session(session)

                yield self._format_sse(
                    event="done",
                    data=json.dumps({
                        "totalTokens": session.total_tokens,
                        "recovered": True,
                        "totalChunks": session.total_chunks,
                    }),
                )
                return

        # 推理仍在进行，切换到实时推送模式
        yield self._format_sse(
            event="resume_live",
            data=json.dumps({
                "message": "已追平历史内容，继续实时输出...",
            }),
        )

        # 等待新 chunk 并推送
        last_seq = replay_chunks[-1]["seq"] if replay_chunks else last_received_seq
        async for token_data in self._poll_new_chunks(session, last_seq, request):
            yield token_data

    async def _model_resume(
        self,
        session: StreamSession,
        last_received_seq: int,
        recovery_id: str,
        request: Request,
    ) -> AsyncGenerator:
        """模型续写：读取已生成内容，请求模型继续生成"""
        # 获取已生成的完整内容
        chunks_key = self.CHUNKS_KEY.format(session_id=session.session_id)
        all_chunks = await self.redis.lrange(chunks_key, 0, -1)

        partial_content = ""
        for chunk_str in all_chunks:
            chunk = json.loads(chunk_str)
            partial_content += chunk.get("content", "")

        # 完整性校验
        validation = self.validator.validate(
            partial_content, session.metadata.get("scene", "ai_tutoring")
        )

        # 构造续写 Prompt
        resume_prompt = self._build_resume_prompt(
            session.metadata["prompt"],
            partial_content,
            validation.completion_suggestion,
        )

        logger.info(
            f"Model resume for {session.session_id}: "
            f"partial_len={len(partial_content)}, "
            f"issues={len(validation.issues)}"
        )

        # 推送已缓存部分（快速重放）
        async for event in self._cache_replay(session, last_received_seq, request):
            yield event

        # 续写新内容
        try:
            async for token_data in self.model_dispatcher.stream_inference(
                provider=session.model_provider,
                model=session.model_name,
                prompt=resume_prompt,
                options={
                    **session.metadata.get("options", {}),
                    "is_resume": True,
                },
            ):
                if await request.is_disconnected():
                    session.status = StreamStatus.INTERRUPTED
                    await self._save_session(session)
                    return

                session.last_chunk_seq += 1
                session.total_chunks += 1
                session.total_tokens += token_data.get("token_count", 1)

                chunk = {
                    "seq": session.last_chunk_seq,
                    "type": token_data.get("type", "TOKEN"),
                    "content": token_data["content"],
                    "timestamp": time.time(),
                    "tokenCount": token_data.get("token_count", 1),
                }

                await self.redis.rpush(
                    self.CHUNKS_KEY.format(session_id=session.session_id),
                    json.dumps(chunk),
                )

                yield self._format_sse(
                    event="token",
                    id=str(chunk["seq"]),
                    data=json.dumps(chunk),
                )

        except Exception as e:
            logger.error(f"Model resume failed: {e}")
            yield self._format_sse(
                event="error",
                data=json.dumps({
                    "code": "MODEL_RESUME_FAILED",
                    "message": "续写失败，已返回已生成部分",
                    "partial": True,
                }),
            )

        session.status = StreamStatus.COMPLETED
        await self._save_session(session)

        yield self._format_sse(
            event="done",
            data=json.dumps({
                "totalTokens": session.total_tokens,
                "recovered": True,
                "resumeMode": "MODEL_RESUME",
            }),
        )

    async def _decide_recovery_strategy(
        self,
        session: StreamSession,
        last_received_seq: int,
    ) -> str:
        """决策恢复策略"""
        # 刷新会话状态
        fresh_session = await self._get_session(session.session_id)
        if fresh_session:
            session = fresh_session

        # 如果推理仍在进行
        if session.status == StreamStatus.STREAMING:
            return "CACHE_REPLAY"

        # 推理已结束，检查内容完整性
        chunks_key = self.CHUNKS_KEY.format(session_id=session.session_id)
        chunk_count = await self.redis.llen(chunks_key)

        if chunk_count == 0:
            # 没有缓存数据
            if session.retry_count < session.max_retries:
                return "FALLBACK"
            return "GRACEFUL_FAIL"

        # 读取所有 chunks 进行完整性校验
        all_chunks = await self.redis.lrange(chunks_key, 0, -1)
        full_content = "".join(
            json.loads(c).get("content", "") for c in all_chunks
        )

        validation = self.validator.validate(
            full_content, session.metadata.get("scene", "ai_tutoring")
        )

        if validation.is_complete:
            return "CACHE_REPLAY"
        elif session.retry_count < session.max_retries:
            return "MODEL_RESUME"
        else:
            return "GRACEFUL_FAIL"

    def _build_resume_prompt(
        self,
        original_prompt: str,
        partial_content: str,
        completion_suggestion: str,
    ) -> str:
        """构造续写 Prompt"""
        return f"""你是一个教育辅导AI。你之前的回答因网络原因中断了，请从中断处继续输出。

原始问题：
{original_prompt}

已生成的部分内容（请勿重复这部分）：
---
{partial_content[-2000:]}
---

中断原因分析：{completion_suggestion or '内容被截断'}

请从已生成内容的断点处自然续写，保持相同的风格、格式和语气。不要重复已生成的内容，直接从中断处继续。"""

    def _format_sse(
        self,
        event: str = None,
        id: str = None,
        data: str = "",
    ) -> str:
        """格式化 SSE 事件"""
        lines = []
        if id:
            lines.append(f"id: {id}")
        if event:
            lines.append(f"event: {event}")
        lines.append(f"data: {data}")
        lines.append("")  # 空行表示事件结束
        return "\n".join(lines) + "\n"

    def _gen_session_id(self) -> str:
        """生成会话ID"""
        date_str = time.strftime("%Y%m%d", time.gmtime())
        random_str = uuid.uuid4().hex[:12]
        return f"ss_{date_str}_{random_str}"

    async def _save_session(self, session: StreamSession):
        """保存会话状态到 Redis"""
        session.updated_at = time.time()
        await self.redis.setex(
            self.SESSION_KEY.format(session_id=session.session_id),
            self.SESSION_TTL,
            json.dumps(session.to_dict()),
        )

    async def _get_session(self, session_id: str) -> Optional[StreamSession]:
        """从 Redis 获取会话"""
        data = await self.redis.get(
            self.SESSION_KEY.format(session_id=session_id)
        )
        if not data:
            return None
        d = json.loads(data)
        return StreamSession(
            session_id=d["sessionId"],
            user_id=d["userId"],
            conversation_id=d.get("conversationId", ""),
            model_provider=d["modelProvider"],
            model_name=d["modelName"],
            prompt_hash=d["promptHash"],
            status=StreamStatus(d["status"]),
            total_chunks=d.get("totalChunks", 0),
            total_tokens=d.get("totalTokens", 0),
            last_chunk_seq=d.get("lastChunkSeq", -1),
            last_client_ack_seq=d.get("lastClientAckSeq", -1),
            retry_count=d.get("retryCount", 0),
            max_retries=d.get("maxRetries", 2),
            metadata=d.get("metadata", {}),
        )

    async def _log_recovery(
        self,
        session_id: str,
        recovery_id: str,
        from_seq: int,
        strategy: str,
        reason: str,

        """记录恢复日志"""

### 8.2 客户端恢复管理器（TypeScript/Flutter）

```typescript
/**
 * StreamRecoveryManager - 客户端流式恢复管理器
 * 负责 SSE 断线检测和自动恢复
 */

interface StreamChunk {
  seq: number;
  type: string;
  content: string;
  timestamp: number;
}

interface StreamMeta {
  sessionId: string;
  model: string;
  provider: string;
}

class StreamRecoveryManager {
  private sessionId: string | null = null;
  private chunks: Map<number, StreamChunk> = new Map();
  private lastReceivedSeq: number = -1;
  private reconnectAttempts: number = 0;
  private maxReconnectAttempts: number = 3;
  private reconnectDelayMs: number = 1000;
  private isRecovering: boolean = false;
  private heartbeatTimer: number | null = null;
  private lastChunkTime: number = Date.now();

  constructor(
    private apiBase: string,
    private onChunk: (chunk: StreamChunk) => void,
    private onMeta: (meta: StreamMeta) => void,
    private onDone: (data: any) => void,
    private onError: (error: any) => void,
  ) {}

  /**
   * 发起流式请求
   */
  async startStream(
    message: string,
    context: any,
    options: any,
  ): Promise<void> {
    const response = await fetch(
      `${this.apiBase}/api/v1/ai/chat/stream`,
      {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${getAuthToken()}`,
          'Accept': 'text/event-stream',
        },
        body: JSON.stringify({ message, context, options }),
      },
    );

    if (!response.ok || !response.body) {
      throw new Error(`Stream request failed: ${response.status}`);
    }

    await this.processSSEStream(response.body);
  }

  /**
   * 处理 SSE 流
   */
  private async processSSEStream(
    stream: ReadableStream<Uint8Array>,
  ): Promise<void> {
    const reader = stream.getReader();
    const decoder = new TextDecoder();
    let buffer = '';

    try {
      while (true) {
        const { done, value } = await reader.read();
        if (done) break;

        buffer += decoder.decode(value, { stream: true });
        const lines = buffer.split('\n');
        buffer = lines.pop() || '';

        let currentEvent = '';
        let currentId = '';
        let currentData = '';

        for (const line of lines) {
          if (line.startsWith('event: ')) {
            currentEvent = line.slice(7);
          } else if (line.startsWith('id: ')) {
            currentId = line.slice(4);
          } else if (line.startsWith('data: ')) {
            currentData = line.slice(6);
          } else if (line === '' && currentData) {
            // 空行 = 事件结束
            this.handleSSEEvent(currentEvent, currentId, currentData);
            currentEvent = '';
            currentId = '';
            currentData = '';
          }
        }
      }
    } catch (error) {
      // 网络错误，触发恢复
      console.warn('SSE stream error:', error);
      await this.attemptRecovery('NETWORK_ERROR');
    }
  }

  /**
   * 处理 SSE 事件
   */
  private handleSSEEvent(
    event: string,
    id: string,
    data: string,
  ): void {
    try {
      const parsed = JSON.parse(data);

      switch (event) {
        case 'meta':
          this.sessionId = parsed.sessionId;
          this.onMeta(parsed);
          break;

        case 'token':
        case 'token_batch':
          if (event === 'token_batch') {
            // 批量 chunk
            for (const chunk of parsed.chunks) {
              this.processChunk(chunk);
            }
          } else {
            this.processChunk(parsed);
          }
          this.lastChunkTime = Date.now();
          break;

        case 'heartbeat':
          // 心跳，重置超时计时
          this.lastChunkTime = Date.now();
          break;

        case 'resume':
          console.log(
            `Recovery started: strategy=${parsed.strategy}, fromSeq=${parsed.fromSeq}`,
          );
          break;

        case 'resume_live':
          console.log('Catch-up complete, switching to live mode');
          break;

        case 'done':
          this.onDone(parsed);
          this.cleanup();
          break;

        case 'error':
          if (parsed.retryable) {
            this.attemptRecovery(parsed.code || 'STREAM_ERROR');
          } else {
            this.onError(parsed);
            this.cleanup();
          }
          break;
      }
    } catch (e) {
      console.error('Failed to parse SSE data:', data, e);
    }
  }

  /**
   * 处理单个 chunk
   */
  private processChunk(chunk: StreamChunk): void {
    this.chunks.set(chunk.seq, chunk);
    if (chunk.seq > this.lastReceivedSeq) {
      this.lastReceivedSeq = chunk.seq;
    }
    this.onChunk(chunk);
  }

  /**
   * 尝试恢复
   */
  private async attemptRecovery(reason: string): Promise<void> {
    if (this.isRecovering) return;
    if (!this.sessionId) return;
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      this.onError({
        code: 'RECOVERY_EXHAUSTED',
        message: '多次恢复失败，请重新提问',
      });
      this.cleanup();
      return;
    }

    this.isRecovering = true;
    this.reconnectAttempts++;

    // 指数退避
    const delay = this.reconnectDelayMs * Math.pow(2, this.reconnectAttempts - 1);
    await this.sleep(delay);

    console.log(
      `Attempting recovery #${this.reconnectAttempts} ` +
      `for session ${this.sessionId}, lastSeq=${this.lastReceivedSeq}`,
    );

    try {
      const response = await fetch(
        `${this.apiBase}/api/v1/ai/stream/resume`,
        {
          method: 'POST',
          headers: {
            'Content-Type': 'application/json',
            'Authorization': `Bearer ${getAuthToken()}`,
            'Accept': 'text/event-stream',
          },
          body: JSON.stringify({
            sessionId: this.sessionId,
            lastReceivedSeq: this.lastReceivedSeq,
            reason,
          }),
        },
      );

      if (response.ok && response.body) {
        await this.processSSEStream(response.body);
      } else if (response.status === 404) {
        // 会话不存在
        this.onError({
          code: 'SESSION_EXPIRED',
          message: '会话已过期，请重新提问',
        });
        this.cleanup();
      } else {
        throw new Error(`Resume failed: ${response.status}`);
      }
    } catch (error) {
      console.error('Recovery failed:', error);
      // 继续重试
      await this.attemptRecovery('RETRY');
    } finally {
      this.isRecovering = false;
    }
  }

  /**
   * 启动心跳监控
   */
  private startHeartbeatMonitor(): void {
    const HEARTBEAT_TIMEOUT = 30_000; // 30秒无数据视为断连

    this.heartbeatTimer = window.setInterval(() => {
      const elapsed = Date.now() - this.lastChunkTime;
      if (elapsed > HEARTBEAT_TIMEOUT) {
        console.warn('Heartbeat timeout, attempting recovery');
        this.attemptRecovery('HEARTBEAT_TIMEOUT');
      }
    }, 10_000); // 每10秒检查一次
  }

  /**
   * 获取已缓存的所有内容
   */
  getCachedContent(): string {
    const sortedChunks = Array.from(this.chunks.values())
      .sort((a, b) => a.seq - b.seq);
    return sortedChunks.map(c => c.content).join('');
  }

  /**
   * 清理资源
   */
  private cleanup(): void {
    if (this.heartbeatTimer) {
      clearInterval(this.heartbeatTimer);
      this.heartbeatTimer = null;
    }
    this.sessionId = null;
    this.chunks.clear();
    this.lastReceivedSeq = -1;
    this.reconnectAttempts = 0;
    this.isRecovering = false;
  }

  private sleep(ms: number): Promise<void> {
    return new Promise(resolve => setTimeout(resolve, ms));
  }
}

- 恢复接口单独限流：每用户每分钟最多 5 次恢复请求
- 续写场景额外消耗 token 额度，但向用户只计费一次（原始请求）

interface StreamSessionCache {

  conversationId: string;
  lastReceivedSeq: number;

  `stream_cache_${sessionId}`,
  JSON.stringify(streamCache)

// App 启动时检查
function checkPendingStreams(): StreamSessionCache[] {
  const pending = [];
  for (const key of Object.keys(localStorage)) {
    if (key.startsWith('stream_cache_')) {
      const cache: StreamSessionCache = JSON.parse(localStorage[key]);
      // 24小时内的会话才提示恢复
      if (Date.now() - cache.createdAt < 24 * 60 * 60 * 1000) {
        pending.push(cache);
      } else {
        // 过期清理
        localStorage.removeItem(key);
      }
    }
  }
  return pending;
}

| 完整性校验-步骤 | 最后一步内容过短 | 返回 INCOMPLETE_STEP |
| 恢复策略决策-缓存重放 | 推理完成且内容完整 | 策略为 CACHE_REPLAY |
| 恢复策略决策-模型续写 | 推理停止且内容不完整 | 策略为 MODEL_RESUME |
| 恢复策略决策-降级 | 重试次数耗尽 | 策略为 GRACEFUL_FAIL |
| 恢复策略决策-备用模型 | 原模型不可用 | 策略为 FALLBACK |

## 17. 版本演进与扩展点

### 17.1 短期优化（V1.0）

- WebSocket 双向通信替代 SSE，支持更灵活的交互
- chunk 差异压缩（Delta Encoding），减少传输量
- 模型推理结果预检，提前发现可能不完整的回答

### 17.2 中期演进（V1.5）

- 边缘节点缓存：在 CDN 边缘缓存高频问题的流式回答
- 多模态恢复：图片、语音等非文本 chunk 的恢复支持
- 智能恢复策略：基于历史数据学习最优恢复策略

### 17.3 长期扩展（V2.0）

- P2P 辅助传输：利用 WebRTC 在设备间共享公共回答的 chunk
- 跨区域恢复：多区域部署时的会话迁移和恢复
- AI 辅助完整性修复：模型自动检测并修复断裂内容
