# 服务端-家庭账户管理与多孩子切换服务 - 详细设计

> **版本**: v1.0 | **最后更新**: 2026-06-01 | **优先级**: P1 (V1.5)
> **依赖**: 用户账号体系、统一认证授权与令牌管理体系、支付与会员订阅、服务端-用户额度管控与功能门控引擎

---

## 1. 模块概述

### 1.1 背景与目标

PrimeTop 面向 K12 家庭场景，一个家庭中通常有多个孩子处于不同学段。家长需要一个统一入口管理所有孩子的学习状态、切换查看不同孩子的学情数据、并为家庭整体购买套餐。

本服务负责家庭维度的账户管理，核心职责：

1. **家庭组创建与管理**：家长创建家庭组，邀请/绑定孩子账号
2. **多孩子切换**：家长在不同孩子身份之间快速切换，查看对应学情
3. **家庭套餐权益共享**：家庭会员权益在多个孩子之间合理分配
4. **数据隔离与聚合**：每个孩子的学习数据严格隔离，同时支持家庭维度聚合
5. **家长管控统一配置**：时长限制、内容范围等策略按孩子维度独立管理

### 1.2 核心概念

| 概念 | 说明 |
| --- | --- |
| 家庭组 (Family) | 由一个家长创建的共享单元，包含 1 个家长 + N 个孩子 |
| 家长角色 (Parent) | 家庭组的管理者，拥有最高管控权限 |
| 孩子角色 (Child) | 被绑定到家庭组的学生账号，拥有独立学习空间 |
| 家庭套餐 (Family Plan) | 支持多孩子的会员套餐，权益在家庭成员间分配 |
| 活跃孩子 (Active Child) | 当前家长正在查看/操作的孩子，用于数据切换上下文 |

### 1.3 约束与限制

| 约束 | 值 | 说明 |
| --- | --- | --- |
| 最大孩子数 | 5 | 单个家庭组最多绑定 5 个孩子 |
| 单孩子绑定家庭数 | 1 | 一个孩子只能绑定一个家庭组 |
| 家长创建家庭数 | 1 | 一个家长账号只能创建/拥有一个家庭组 |
| 绑定邀请有效期 | 7 天 | 邀请链接/验证码过期时间 |
| 切换频率限制 | 60 次/小时 | 防止频繁切换导致缓存击穿 |

## 2. 数据模型

### 2.1 家庭组表 `family`

```sql
CREATE TABLE `family` (
    `id`                BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '家庭组ID',
    `family_code`       VARCHAR(16) NOT NULL COMMENT '家庭唯一编码(用于邀请)',
    `parent_user_id`    BIGINT UNSIGNED NOT NULL COMMENT '家长用户ID',
    `family_name`       VARCHAR(64) NOT NULL DEFAULT '' COMMENT '家庭名称(如"张小明家")',
    `avatar`            VARCHAR(512) NOT NULL DEFAULT '' COMMENT '家庭头像URL',
    `plan_type`         TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '套餐类型: 0=无/1=个人/2=家庭',
    `plan_expires_at`   DATETIME DEFAULT NULL COMMENT '家庭套餐到期时间',
    `max_children`      TINYINT UNSIGNED NOT NULL DEFAULT 5 COMMENT '最大孩子数',
    `status`            TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '状态: 0=已解散/1=正常/2=冻结',
    `created_at`        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at`        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_family_code` (`family_code`),
    UNIQUE KEY `uk_parent_user_id` (`parent_user_id`),
    KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='家庭组表';
```

### 2.2 家庭成员表 `family_member`

```sql
CREATE TABLE `family_member` (
    `id`                BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '成员记录ID',
    `family_id`         BIGINT UNSIGNED NOT NULL COMMENT '家庭组ID',
    `user_id`           BIGINT UNSIGNED NOT NULL COMMENT '孩子用户ID',
    `nickname`          VARCHAR(32) NOT NULL DEFAULT '' COMMENT '家长给孩子设的昵称',
    `relation`          TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '关系: 1=子女/2=其他',
    `sort_order`        TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '排列顺序(0最前)',
    `joined_at`         DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '加入时间',
    `bind_method`       TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '绑定方式: 1=邀请码/2=手机验证/3=扫码',

    `unbound_at`        DATETIME DEFAULT NULL COMMENT '解绑时间',
    `unbound_reason`    VARCHAR(128) DEFAULT '' COMMENT '解绑原因',

    `updated_at`        DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
```

## 4. 核心业务逻辑

### 4.1 家庭组状态机

```
                    ┌──────────┐
         创建       │  CREATED  │
        ────────>   │  (正常)   │
                    └────┬─────┘
                         │
            ┌────────────┼────────────┐
            │ 绑定孩子    │            │ 套餐到期
            ▼            │            ▼
     ┌─────────────┐     │     ┌──────────────┐
     │ HAS_CHILDREN│     │     │ PLAN_EXPIRED │
     │ (有孩子)     │     │     │ (套餐过期)    │
     └──────┬──────┘     │     └──────┬───────┘
            │            │            │
            │ 全部解绑    │            │ 续费
            ▼            │            ▼
     ┌──────────┐        │     ┌─────────────┐
     │ NO_CHILD │────────┘     │  CREATED    │
     │ (无孩子)  │              │  (恢复)      │
     └──────────┘              └─────────────┘
            │
            │ 家长主动解散
            ▼
     ┌───────────┐
     │ DISSOLVED │
     │ (已解散)   │
     └───────────┘
```

### 4.2 孩子绑定状态机

```
     ┌────────────┐   接受邀请/验证通过   ┌──────────┐
     │ PENDING    │ ──────────────────> │  ACTIVE  │
     │ (待确认)    │                     │  (正常)   │
     └────────────┘                     └────┬─────┘
                                            │
                          解绑/家长操作       │
                                            ▼
                                     ┌────────────┐
                                     │ UNBOUND    │
                                     │ (已解绑)    │
                                     └────────────┘
```

### 4.3 核心服务类设计

```python

# ============================================================

import secrets

    DISSOLVED = 0
    ACTIVE = 1
    FROZEN = 2

    UNBOUND = 0
    ACTIVE = 1
    PENDING = 2


class FamilyService:
    """家庭组核心业务服务"""

    def __init__(self, db, cache, event_bus):
        self.db = db
        self.cache = cache
        self.event_bus = event_bus

    # ---- 家庭组管理 ----

    async def create_family(
        self,
        parent_user_id: int,
        family_name: Optional[str] = None
    ) -> dict:
        """
        创建家庭组
        
        业务规则:
        1. 一个家长只能创建一个家庭组
        2. 自动生成6位唯一家庭编码
        3. 默认最大孩子数=5
        """
        # 检查是否已有家庭组
        existing = await self.db.fetch_one(
            "SELECT id FROM family WHERE parent_user_id = %s AND status != %s",
            [parent_user_id, FamilyStatus.DISSOLVED]
        )
        if existing:
            raise BizError(409001, "已创建过家庭组")

        # 生成唯一编码
        family_code = await self._generate_family_code()

        # 使用家长昵称作为默认家庭名
        if not family_name:
            parent = await self.db.fetch_one(
                "SELECT nickname FROM users WHERE id = %s",
                [parent_user_id]
            )
            family_name = f"{parent['nickname']}家"

        family_id = await self.db.insert("family", {
            "family_code": family_code,
            "parent_user_id": parent_user_id,
            "family_name": family_name,
            "status": FamilyStatus.ACTIVE,
        })

        # 写缓存
        await self.cache.set(
            f"user:family:{parent_user_id}",
            str(family_id),
            ex=86400
        )

        # 发布事件
        await self.event_bus.publish("family.created", {
            "family_id": family_id,
            "parent_user_id": parent_user_id,
        })

        return {
            "family_id": family_id,
            "family_code": family_code,
            "family_name": family_name,
            "max_children": 5,
        }

    async def _generate_family_code(self) -> str:
        """生成6位唯一家庭编码(排除易混淆字符)"""
        chars = string.ascii_uppercase + string.digits
        exclude = set('O0I1L')  # 排除易混淆
        safe_chars = [c for c in chars if c not in exclude]
        
        for _ in range(10):  # 最多重试10次
            code = ''.join(secrets.choice(safe_chars) for _ in range(6))
            exists = await self.db.fetch_one(
                "SELECT id FROM family WHERE family_code = %s",
                [code]
            )
            if not exists:
                return code
        raise SystemError("无法生成唯一家庭编码")

    # ---- 孩子绑定 ----

    async def generate_invite(
        self,
        family_id: int,
        parent_user_id: int,
        child_nickname: str,
        child_phone: str = "",
        target_grade: int | None = None
    ) -> dict:
        """
        生成绑定邀请
        
        业务规则:
        1. 校验家庭孩子数未满
        2. 校验昵称合规(2-16字符,无敏感词)
        3. 邀请码8位,有效期7天
        """
        # 校验孩子数量
        count = await self._count_active_children(family_id)
        family = await self._get_family(family_id)
        if count >= family["max_children"]:
            raise BizError(409002, "家庭孩子数已满")

        # 昵称校验
        self._validate_nickname(child_nickname)

        # 生成邀请码
        invite_code = secrets.token_urlsafe(6).upper()[:8]
        expires_at = datetime.now() + timedelta(days=7)

        invite_id = await self.db.insert("family_invitation", {
            "family_id": family_id,
            "invite_code": invite_code,
            "inviter_user_id": parent_user_id,
            "invitee_phone": child_phone,
            "child_nickname": child_nickname,
            "target_grade": target_grade,
            "status": 0,
            "expires_at": expires_at,
        })

        # 缓存邀请码
        await self.cache.set(
            f"invite:{invite_code}",
            json.dumps({
                "family_id": family_id,
                "inviter_user_id": parent_user_id,
                "expires_at": expires_at.isoformat(),
                "child_nickname": child_nickname,
                "target_grade": target_grade,
            }),
            ex=int(timedelta(days=7).total_seconds())
        )

        return {
            "invite_code": invite_code,
            "expires_at": expires_at.isoformat(),
            "invite_url": f"primetop://family/join?code={invite_code}",
        }

    async def accept_invite(
        self,
        child_user_id: int,
        invite_code: str
    ) -> dict:
        """
        接受邀请绑定
        
        业务规则:
        1. 邀请码有效
        2. 孩子未绑定其他家庭
        3. 孩子不是家长账号
        4. 家庭孩子数未满
        5. 绑定成功后发布事件,触发额度初始化等
        """
        # 获取邀请信息(先从缓存)
        invite_data = await self.cache.get(f"invite:{invite_code}")
        if not invite_data:
            invite_data = await self.db.fetch_one(
                "SELECT * FROM family_invitation WHERE invite_code = %s AND status = 0",
                [invite_code]
            )
        if not invite_data:
            raise BizError(404002, "邀请码不存在或已过期")

        invite = json.loads(invite_data) if isinstance(invite_data, str) else invite_data

        # 校验过期
        if datetime.fromisoformat(invite["expires_at"]) < datetime.now():
            raise BizError(404002, "邀请码已过期")

        # 校验孩子未绑定其他家庭
        existing = await self.db.fetch_one(
            "SELECT id FROM family_member WHERE user_id = %s AND status = %s",
            [child_user_id, MemberStatus.ACTIVE]
        )
        if existing:
            raise BizError(409003, "该账号已绑定其他家庭")

        # 校验不是家长自己
        family = await self._get_family(invite["family_id"])
        if family["parent_user_id"] == child_user_id:
            raise BizError(403001, "家长账号不能作为孩子绑定")

        # 校验孩子数
        count = await self._count_active_children(invite["family_id"])
        if count >= family["max_children"]:
            raise BizError(409004, "家庭孩子数已满")

        # 获取排序号
        max_sort = await self.db.fetch_val(
            "SELECT COALESCE(MAX(sort_order), -1) FROM family_member WHERE family_id = %s AND status = %s",
            [invite["family_id"], MemberStatus.ACTIVE]
        )

        # 创建绑定
        member_id = await self.db.insert("family_member", {
            "family_id": invite["family_id"],
            "user_id": child_user_id,
            "nickname": invite["child_nickname"],
            "sort_order": max_sort + 1,
            "bind_method": 1,
            "status": MemberStatus.ACTIVE,
        })

        # 更新邀请状态
        await self.db.update(
            "UPDATE family_invitation SET status = 1, child_user_id = %s, used_at = NOW() WHERE invite_code = %s",
            [child_user_id, invite_code]
        )

        # 清除缓存
        await self.cache.delete(f"invite:{invite_code}")
        await self._invalidate_members_cache(invite["family_id"])
        await self.cache.set(
            f"user:family:{child_user_id}",
            str(invite["family_id"]),
            ex=86400
        )

        # 创建默认管控策略
        await self.db.insert("parent_control_policy", {
            "family_id": invite["family_id"],
            "child_user_id": child_user_id,
            "daily_time_limit": 120,  # 默认120分钟
            "content_level": 0,
        })

        # 发布事件
        await self.event_bus.publish("family.child.bound", {
            "family_id": invite["family_id"],
            "child_user_id": child_user_id,
            "child_nickname": invite["child_nickname"],
        })

        return {
            "family_id": invite["family_id"],
            "family_name": family["family_name"],
            "child_nickname": invite["child_nickname"],
            "role": "child",
        }

    # ---- 孩子切换 ----

    async def switch_active_child(
        self,
        parent_user_id: int,
        child_user_id: int
    ) -> dict:
        """
        切换活跃孩子
        
        业务规则:
        1. 目标孩子必须在该家庭中且状态正常
        2. 切换频率限制(60次/小时)
        3. 切换后缓存活跃孩子ID
        4. 返回目标孩子的简要学习数据
        """
        # 频率限制
        rate_key = f"rate:child_switch:{parent_user_id}"
        count = await self.cache.incr(rate_key)
        if count == 1:
            await self.cache.expire(rate_key, 3600)
        if count > 60:
            raise BizError(429001, "切换过于频繁，请稍后再试")

        # 获取家庭组
        family = await self._get_family_by_parent(parent_user_id)
        if not family:
            raise BizError(404001, "家庭组不存在")

        # 校验孩子在家庭中
        member = await self.db.fetch_one(
            "SELECT * FROM family_member WHERE family_id = %s AND user_id = %s AND status = %s",
            [family["id"], child_user_id, MemberStatus.ACTIVE]
        )
        if not member:
            raise BizError(404003, "孩子不在该家庭中")

        # 更新活跃孩子
        await self.cache.set(
            f"parent:active_child:{parent_user_id}",
            str(child_user_id),
            ex=86400 * 30  # 30天
        )

        # 获取孩子简要学习数据
        summary = await self._get_child_learning_summary(child_user_id)

        return {
            "active_child": {
                "user_id": child_user_id,
                "nickname": member["nickname"],
                "learning_summary": summary,
            }
        }

    # ---- 解绑 ----

    async def unbind_child(
        self,
        family_id: int,
        child_user_id: int,
        reason: str
    ) -> dict:
        """
        解绑孩子
        
        业务规则:
        1. 至少保留一个孩子(除非是最后一个且要解散家庭)
        2. 软删除,标记解绑时间和原因
        3. 清除相关缓存
        4. 发布事件,触发额度回收等
        """
        member = await self.db.fetch_one(
            "SELECT * FROM family_member WHERE family_id = %s AND user_id = %s AND status = %s",
            [family_id, child_user_id, MemberStatus.ACTIVE]
        )
        if not member:
            raise BizError(404003, "孩子不在该家庭中")

        # 执行解绑
        await self.db.update(
            """UPDATE family_member 
               SET status = %s, unbound_at = NOW(), unbound_reason = %s 
               WHERE family_id = %s AND user_id = %s""",
            [MemberStatus.UNBOUND, reason, family_id, child_user_id]
        )

        # 清缓存
        await self._invalidate_members_cache(family_id)
        await self.cache.delete(f"user:family:{child_user_id}")

        # 如果该孩子是当前活跃孩子,清除活跃状态
        family = await self._get_family(family_id)
        active_key = f"parent:active_child:{family['parent_user_id']}"
        active_child = await self.cache.get(active_key)
        if active_child == str(child_user_id):
            await self.cache.delete(active_key)

        # 发布事件
        await self.event_bus.publish("family.child.unbound", {
            "family_id": family_id,
            "child_user_id": child_user_id,
            "child_nickname": member["nickname"],
            "reason": reason,
        })

        return {"unbound": True, "child_user_id": child_user_id}

    # ---- 私有方法 ----

    async def _count_active_children(self, family_id: int) -> int:
        return await self.db.fetch_val(
            "SELECT COUNT(*) FROM family_member WHERE family_id = %s AND status = %s",
            [family_id, MemberStatus.ACTIVE]
        )

    async def _get_family(self, family_id: int) -> dict:
        family = await self.db.fetch_one(
            "SELECT * FROM family WHERE id = %s", [family_id]
        )
        if not family:
            raise BizError(404001, "家庭组不存在")
        return family

    async def _get_family_by_parent(self, parent_user_id: int) -> Optional[dict]:
        return await self.db.fetch_one(
            "SELECT * FROM family WHERE parent_user_id = %s AND status != %s",
            [parent_user_id, FamilyStatus.DISSOLVED]
        )

    async def _invalidate_members_cache(self, family_id: int):
        await self.cache.delete(f"family:members:{family_id}")

    async def _get_child_learning_summary(self, child_user_id: int) -> dict:
        """获取孩子简要学习汇总(聚合查询)"""
        today = datetime.now().strftime("%Y-%m-%d")
        row = await self.db.fetch_one(
            """SELECT 
                 COALESCE(SUM(duration_seconds), 0) / 60 AS today_minutes,
                 COUNT(CASE WHEN st.status = 'done' THEN 1 END) AS today_tasks_done,
                 COUNT(*) AS today_tasks_total
               FROM study_task st
               WHERE st.user_id = %s AND st.task_date = %s""",
            [child_user_id, today]
        )
        weak_points = await self.db.fetch_all(
            """SELECT kp.name 
               FROM weak_point wp 
               JOIN knowledge_point kp ON wp.kp_id = kp.id
               WHERE wp.user_id = %s AND wp.level <= 2
               ORDER BY wp.level ASC LIMIT 5""",
            [child_user_id]
        )
        streak = await self.db.fetch_val(
            "SELECT streak_days FROM user_learning_stats WHERE user_id = %s",
            [child_user_id]
        )
        return {
            "today_minutes": int(row["today_minutes"] or 0),
            "today_tasks_total": row["today_tasks_total"] or 0,
            "today_tasks_done": row["today_tasks_done"] or 0,
            "weak_points_count": len(weak_points),
            "streak_days": streak or 0,
        }
```

```python
class FamilyQuotaAllocator:
    """
    家庭套餐权益分配器
    
    核心策略:
    1. 家庭套餐的总额度在所有孩子之间公平分配
    2. 支持"均分"和"优先分配"两种模式
    3. 单个孩子不会超过个人套餐的额度上限
    4. 额度变更时实时生效
    """

    # 家庭套餐权益分配模式
    ALLOC_MODE_EVEN = "even"        # 均分模式: 总额度 / 孩子数
    ALLOC_MODE_PRIORITY = "priority" # 优先模式: 家长指定各孩子额度

    def __init__(self, db, cache, quota_service):
        self.db = db
        self.cache = cache
        self.quota_service = quota_service  # 引用: 用户额度管控与功能门控引擎

    async def get_family_quota_status(self, family_id: int) -> dict:
        """获取家庭套餐额度使用情况"""
        cache_key = f"family:quota:{family_id}"
        cached = await self.cache.hgetall(cache_key)
        if cached:
            return cached

        # 从DB查询
        family = await self.db.fetch_one(
            "SELECT * FROM family WHERE id = %s", [family_id]
        )
        if not family or family["plan_type"] != 2:
            return {"plan_type": family["plan_type"] if family else 0}

        # 查询每个孩子的额度使用
        members = await self.db.fetch_all(
            "SELECT user_id FROM family_member WHERE family_id = %s AND status = 1",
            [family_id]
        )
        child_quotas = []
        for m in members:
            q = await self.quota_service.get_user_quota_summary(m["user_id"])
            child_quotas.append({
                "user_id": m["user_id"],
                "quotas": q,
            })

        result = {
            "plan_type": 2,
            "plan_expires_at": family["plan_expires_at"].isoformat() if family["plan_expires_at"] else None,
            "children_count": len(members),
            "children": child_quotas,
        }

        await self.cache.hset(cache_key, mapping=result)
        await self.cache.expire(cache_key, 3600)
        return result

    async def allocate_child_quota(
        self,
        family_id: int,
        child_user_id: int,
        quota_type: str,
        amount: int
    ) -> bool:
        """
        为指定孩子分配额度
        
        调用额度管控引擎的接口:
        - quota_type: 'ai_daily', 'photo_daily', 'essay_monthly' 等
        - amount: 分配数量
        """
        # 校验孩子属于该家庭
        member = await self.db.fetch_one(
            "SELECT id FROM family_member WHERE family_id = %s AND user_id = %s AND status = 1",
            [family_id, child_user_id]
        )
        if not member:
            raise BizError(404003, "孩子不在该家庭中")

        # 获取家庭总额度
        total = await self._get_family_total_quota(family_id, quota_type)
        
        # 获取其他孩子已分配额度
        others_used = await self._get_other_children_used(family_id, child_user_id, quota_type)
        
        if amount > (total - others_used):
            raise BizError(409005, "可分配额度不足")

        await self.quota_service.set_user_quota(
            user_id=child_user_id,
            quota_type=quota_type,
            amount=amount,
            source=f"family:{family_id}"
        )
        
        # 清除缓存
        await self.cache.delete(f"family:quota:{family_id}")
        return True

    async def _get_family_total_quota(self, family_id: int, quota_type: str) -> int:
        """获取家庭套餐对某额度类型的总额度"""
        # 从配置或订阅计划中获取
        FAMILY_PLAN_QUOTAS = {
            "ai_daily": 200,          # 家庭版: 200次/天 (个人版50)
            "photo_daily": 100,       # 100次/天
            "essay_monthly": 30,      # 30次/月
            "tutor_session_daily": 5, # 5次/天
        }
        return FAMILY_PLAN_QUOTAS.get(quota_type, 0)

    async def _get_other_children_used(self, family_id: int, exclude_user_id: int, quota_type: str) -> int:
        """获取其他孩子已分配的额度总和"""
        members = await self.db.fetch_all(
            "SELECT user_id FROM family_member WHERE family_id = %s AND user_id != %s AND status = 1",
            [family_id, exclude_user_id]
        )
        total = 0
        for m in members:
            q = await self.quota_service.get_user_quota(m["user_id"], quota_type)
            total += q.get("allocated", 0)
        return total
```

```python
class FamilyAuthMiddleware:
    """家庭模块权限校验"""

    async def verify_parent(self, request) -> dict:
        """校验当前用户是家长且拥有家庭组"""
        user = request.state.user
        if user["role"] != "parent":
            raise BizError(403002, "仅家长可执行此操作")
        
        family = await self.family_service._get_family_by_parent(user["id"])
        if not family:
            raise BizError(404001, "家庭组不存在")
        
        request.state.family = family
        return family

    async def verify_child_in_family(self, family_id: int, child_user_id: int):
        """校验孩子属于指定家庭"""
        member = await self.db.fetch_one(
            "SELECT id FROM family_member WHERE family_id = %s AND user_id = %s AND status = 1",
            [family_id, child_user_id]
        )
        if not member:
            raise BizError(403003, "无权操作该孩子的数据")

    async def verify_invite_rate_limit(self, parent_user_id: int):
        """邀请码生成频率限制"""
        key = f"rate:invite_gen:{parent_user_id}"
        count = await self.cache.incr(key)
        if count == 1:
            await self.cache.expire(key, 3600)
        if count > 20:  # 每小时最多20次
            raise BizError(429002, "邀请生成过于频繁")
```

### 6.3 数据隔离保障

```python
# 孩子数据查询强制带 family_id + child_user_id 条件
class ChildDataQueryGuard:
    """
    确保家长查询孩子数据时,始终校验归属关系
    所有查询孩子数据的接口必须经过此Guard
    """

    async def guard(self, parent_user_id: int, child_user_id: int):
        family = await self.family_service._get_family_by_parent(parent_user_id)
        if not family:
            raise BizError(404001, "家庭组不存在")
        
        member = await self.db.fetch_one(
            "SELECT id FROM family_member WHERE family_id = %s AND user_id = %s AND status = 1",
            [family["id"], child_user_id]
        )
        if not member:
            raise BizError(403003, "无权查看该孩子的数据")
        
        return family["id"]
```

## 7. 错误码定义

| 错误码 | HTTP Status | 说明 | 处理建议 |
| --- | --- | --- | --- |
| 404001 | 404 | 家庭组不存在 | 引导创建家庭组 |
| 404002 | 404 | 邀请码不存在或已过期 | 重新生成邀请码 |
| 404003 | 404 | 孩子不在该家庭中 | 刷新家庭信息 |
| 409001 | 409 | 已创建过家庭组 | 跳转已有家庭 |
| 409002 | 409 | 家庭孩子数已满 | 升级套餐或解绑 |
| 409003 | 409 | 该账号已绑定其他家庭 | 先解绑再绑定 |
| 409004 | 409 | 家庭孩子数已满(邀请时) | 提示家长 |
| 409005 | 409 | 可分配额度不足 | 调整分配或升级 |
| 403001 | 403 | 账号类型不匹配 | 提示用学生账号 |
| 403002 | 403 | 非家长角色 | 切换家长角色 |
| 403003 | 403 | 无权操作该孩子数据 | 确认绑定关系 |
| 400001 | 400 | 昵称不合规 | 修改昵称 |
| 400002 | 400 | 至少保留一个孩子 | - |
| 429001 | 429 | 切换过于频繁 | 稍后重试 |
| 429002 | 429 | 邀请生成过于频繁 | 稍后重试 |
