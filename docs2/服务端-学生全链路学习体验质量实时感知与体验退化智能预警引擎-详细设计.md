# 服务端-学生全链路学习体验质量实时感知与体验退化智能预警引擎

> **文档版本**：v1.0  
> **创建日期**：2026-07-30  
> **模块定位**：基础设施 / 可观测性 / 体验质量保障  
> **优先级**：P1  
> **依赖模块**：分布式链路追踪、SLO管理平台、客户端性能监控、AI辅导请求编排、统一用户行为埋点平台

---

## 1. 概述

### 1.1 功能定位

本引擎负责**全链路、实时、多维度**地感知学生在使用 PrimeTop App 过程中的体验质量（Learning Experience Quality, LEQ），在体验发生退化时第一时间发出智能预警，并自动触发缓解策略。

与已有模块的区别：

| 已有模块 | 关注范围 | 与本引擎关系 |
| --- | --- | --- |
| SLO 服务等级目标管理 | 后端服务可用性/延迟 SLO | 本引擎消费 SLO 数据，但关注点是**用户感知体验**而非纯技术指标 |
| 分布式链路追踪 | 服务间调用链路可视化 | 链路追踪是本引擎的**数据源之一** |
| 客户端性能监控 | App 崩溃率、启动速度、FPS | 客户端数据是本引擎的**前端信号源** |
| AI辅导对话体验质量评估 | AI 对话单一场景的交互质量 | 本引擎覆盖**全学习旅程**，AI 对话只是其中一条链路 |
| 智能故障检测与自愈引擎 | 系统级故障检测和自动恢复 | 本引擎关注**用户体验影响**，故障引擎关注**系统健康** |

### 1.2 设计目标

1. **全旅程覆盖**：覆盖从 App 启动 → 首页加载 → AI 问答 → 拍题识别 → 练习答题 → 错题复习 → 学情查看等全部核心学习路径。
2. **实时感知**：体验指标延迟不超过 30 秒（从事件发生到仪表盘可见）。
3. **智能归因**：当体验退化时，自动关联后端服务指标、AI 模型质量、网络状态等多维数据，输出根因分析。
4. **分级预警**：按影响范围 × 严重程度进行分级，避免告警风暴。
5. **自动缓解**：对已知模式的体验退化，自动触发降级策略（如模型切换、缓存兜底）。

### 1.3 适用场景

| 场景 | 体验质量关注点 |
| --- | --- |
| AI 智能辅导对话 | 首 Token 延迟、回答完整度、回答质量评分、对话中断率 |
| 拍照搜题 | OCR 识别耗时、识别准确率、解析生成成功率 |
| 同步课堂学习 | 内容加载时间、视频缓冲频率、页面交互流畅度 |
| 练习测评 | 答题提交延迟、批改结果返回时间、页面切换卡顿 |
| 错题本操作 | 列表加载时间、错题图片加载成功率 |
| 首页工作台 | 首屏渲染时间、个性化推荐响应时间、弹窗加载 |

## 3. 数据结构定义

### 3.1 学习体验事件 (LearningExperienceEvent)

客户端和服务端统一上报的体验事件基础结构。

```typescript
interface LearningExperienceEvent {
  // ── 事件标识 ──
  eventId: string;              // 事件唯一 ID (UUID)
  timestamp: number;            // 事件发生时间 (毫秒)
  
  // ── 用户信息 ──
  userId: string;               // 用户 ID
  studentProfile: {
    grade: string;              // 年级 (如 "G6", "J1", "S1")
    stage: string;              // 学段 ( kindergarten | primary | junior | senior )
    isVip: boolean;             // 是否会员
  };
  
  // ── 会话与链路 ──
  sessionId: string;            // 学习会话 ID
  traceId: string;              // 分布式链路追踪 ID
  spanId: string;               // 当前 Span ID
  
  // ── 体验场景 ──
  scenario: ExperienceScenario; // 体验场景枚举
  scenarioDetail: string;       // 场景细节 (如 "数学/AI辅导/多轮追问")
  
  // ── 体验信号 ──
  metrics: ExperienceMetric[];  // 体验指标列表
  signals: BehavioralSignal[];  // 行为信号列表
  
  // ── 设备与环境 ──
  deviceInfo: {
    platform: string;           // android | ios | web
    appVersion: string;
    networkType: string;        // wifi | 4g | 5g | weak
    deviceTier: string;         // high | medium | low
  };
  
  // ── 体验评分 ──
  leqScore?: number;            // 实时体验质量评分 (0-100, 服务端计算)
}

type ExperienceScenario = 
  | 'APP_STARTUP'           // App 启动
  | 'HOME_WORKBENCH'        // 首页工作台
  | 'AI_TUTORING_DIALOG'   // AI 辅导对话
  | 'PHOTO_SEARCH'          // 拍照搜题
  | 'SYNC_CLASSROOM'        // 同步课堂学习
  | 'PRACTICE_ASSESSMENT'   // 练习测评
  | 'ERROR_BOOK'            // 错题本操作
  | 'STUDY_PLAN'            // 学习规划
  | 'KNOWLEDGE_GRAPH'       // 知识图谱浏览
  | 'COMPOSITION_COACHING'  // 作文辅导
  | 'EXAM_SIMULATION'       // 考试模拟
  | 'PARENT_CENTER'         // 家长中心
  | 'SEARCH'                // 全局搜索
  | 'NOTIFICATION';         // 消息通知
```

### 3.2 体验指标 (ExperienceMetric)

```typescript
interface ExperienceMetric {
  metricKey: string;          // 指标键 (如 "first_token_latency_ms")
  metricValue: number;        // 指标值
  unit: MetricUnit;           // 单位
  threshold?: {               // 该指标的阈值
    good: number;             // 体验良好阈值
    tolerable: number;        // 可容忍阈值
    frustrating: number;     // 体验糟糕阈值
  };
  quality: QualityLevel;      // 本次指标的质量等级
}

type MetricUnit = 'ms' | 'count' | 'ratio' | 'score' | 'boolean';

interface BehavioralSignal {
  signalType: SignalType;
  signalValue: number | string;
  confidence: number;         // 0-1, 信号置信度
}

type SignalType =
  | 'TAP_FREQUENCY'           // 点击频率
  | 'SCROLL_SPEED'            // 滚动速度
  | 'DWELL_TIME'              // 停留时间
  | 'RETRY_COUNT'             // 重试次数
  | 'ABANDON_RATE'            // 放弃率
  | 'ERROR_DISMISS_TIME'      // 错误提示关闭时间
  | 'BACK_GESTURE_COUNT'      // 返回手势次数
  | 'SCREEN_OFF_DURING_TASK'  // 任务执行中息屏
  | 'REPEATED_TAP';           // 重复点击（暗示卡顿）

enum QualityLevel {
  GOOD = 'good',           // 体验良好
  TOLERABLE = 'tolerable', // 可接受
  DEGRADED = 'degraded',   // 已退化
  FRUSTRATING = 'frustrating' // 体验糟糕
}
```

### 3.3 体验质量评分模型 (LEQ Score)

综合评分模型，将多维体验指标归一化为 0-100 的单一分数。

```typescript
interface LeqScoreModel {
  scenario: ExperienceScenario;       // 场景
  totalScore: number;                 // 综合评分 (0-100)
  
  // ── 四维评分 ──
  dimensions: {
    responsiveness: DimensionScore;   // 响应性 (速度/延迟)
    reliability: DimensionScore;      // 可靠性 (成功率/错误率)
    quality: DimensionScore;          // 内容质量 (AI回答/识别准确率)
    fluency: DimensionScore;          // 流畅性 (交互连贯/无卡顿)
  };
  
  // ── 计算元数据 ──
  calculatedAt: number;
  sampleSize: number;                 // 样本量
  timeWindow: string;                 // 统计窗口 (如 "PT5M")
}

interface DimensionScore {
  score: number;              // 维度评分 (0-100)
  weight: number;             // 权重 (场景相关)
  contributors: Array<{       // 评分贡献因子
    metric: string;
    value: number;
    impact: number;           // 对评分的影响值 (-100 ~ +100)
  }>;
}
```

### 3.4 体验退化事件 (ExperienceDegradationEvent)

```typescript
interface ExperienceDegradationEvent {
  eventId: string;
  detectedAt: number;
  
  // ── 退化描述 ──
  scenario: ExperienceScenario;
  degradationType: DegradationType;
  severity: Severity;
  
  // ── 影响范围 ──
  impact: {
    affectedUsers: number;        // 影响用户数
    affectedPercentage: number;   // 影响用户占比
    affectedScenarios: string[];  // 波及其他场景
    affectedGrades: string[];     // 影响年级范围
  };
  
  // ── 指标快照 ──
  currentMetrics: Record<string, number>;  // 当前值
  baselineMetrics: Record<string, number>; // 基线值
  deviationRatio: Record<string, number>;  // 偏离比例
  
  // ── 根因分析 ──
  rootCause: RootCauseAnalysis;
  
  // ── 缓解策略 ──
  mitigationActions: MitigationAction[];
  
  // ── 状态 ──
  status: DegradationStatus;
  resolvedAt?: number;
  resolutionNote?: string;
}

type DegradationType =
  | 'LATENCY_SPIKE'           // 延迟突增
  | 'ERROR_RATE_INCREASE'     // 错误率上升
  | 'QUALITY_DROP'            // 内容质量下降
  | 'AVAILABILITY_LOSS'       // 可用性丢失
  | 'INTERACTION_JANK'        // 交互卡顿
  | 'COMPOSITE_DEGRADATION';  // 复合型退化

enum Severity {
  CRITICAL = 'critical',   // 全量用户受影响，核心功能不可用
  HIGH = 'high',           // 大量用户受影响，体验严重退化
  MEDIUM = 'medium',       // 部分用户受影响，体验明显退化
  LOW = 'low';             // 少量用户受影响，轻微退化
}

interface RootCauseAnalysis {
  primaryCause: string;          // 主要原因
  causeCategory: CauseCategory;
  evidence: Evidence[];          // 支撑证据
  confidenceScore: number;       // 置信度 0-1
  causalChain: CausalNode[];     // 因果链
}

type CauseCategory =
  | 'AI_MODEL_ISSUE'         // AI 模型异常
  | 'UPSTREAM_SERVICE_DOWN'  // 上游服务宕机
  | 'NETWORK_DEGRADATION'    // 网络退化
  | 'RESOURCE_EXHAUSTION'    // 资源耗尽
  | 'CONFIG_ERROR'           // 配置错误
  | 'CONTENT_DATA_ERROR'     // 内容数据错误
  | 'CLIENT_BUG'             // 客户端 Bug
  | 'EXTERNAL_DEPENDENCY'    // 外部依赖异常
  | 'UNKNOWN';

interface Evidence {
  source: string;       // 数据源 (如 "prometheus", "trace", "rum")
  metric: string;
  value: string;
  description: string;
}

interface CausalNode {
  layer: string;         // 根因层级
  component: string;     // 组件
  issue: string;         // 问题
  impactOnUser: string;  // 对用户的影响
}

interface MitigationAction {
  actionType: MitigationType;
  triggeredBy: 'auto' | 'manual';
  executedAt?: number;
  result?: 'success' | 'partial' | 'failed';
  detail: string;
}

type MitigationType =
  | 'MODEL_FAILOVER'           // 模型故障切换
  | 'CACHE_FALLBACK'           // 缓存兜底
  | 'RATE_LIMIT_ADJUST'        // 限流调整
  | 'CIRCUIT_BREAKER_OPEN'     // 熔断开启
  | 'CONTENT_FALLBACK'         // 内容降级
  | 'USER_NOTIFICATION'        // 用户提示
  | 'SCALE_OUT';               // 扩容

type DegradationStatus =
  | 'DETECTED'
  | 'ANALYZING'
  | 'MITIGATING'
  | 'MONITORING'
  | 'RESOLVED'
  | 'IGNORED';
```

### 4.3 LEQ 综合评分计算

```python
import math
from typing import Dict, List

class LeqScoreCalculator:
    """学习体验质量 (LEQ) 综合评分计算器"""
    
    # 默认维度权重配置 (可按场景覆盖)
    DEFAULT_WEIGHTS = {
        "responsiveness": 0.35,
        "reliability": 0.30,
        "fluency": 0.20,
        "quality": 0.15,
    }
    
    # 场景级权重覆盖
    SCENARIO_WEIGHTS = {
        "AI_TUTORING_DIALOG": {
            "responsiveness": 0.30,
            "reliability": 0.25,
            "fluency": 0.15,
            "quality": 0.30,  # AI回答场景，质量权重提高
        },
        "PHOTO_SEARCH": {
            "responsiveness": 0.35,
            "reliability": 0.30,
            "fluency": 0.10,
            "quality": 0.25,  # 识别准确率权重提高
        },
        "PRACTICE_ASSESSMENT": {
            "responsiveness": 0.30,
            "reliability": 0.35,  # 练习提交可靠性最重要
            "fluency": 0.25,
            "quality": 0.10,
        },
    }
    
    def calculate(
        self,
        scenario: str,
        metrics: Dict[str, float],
        sample_size: int
    ) -> "LeqResult":
        """
        计算场景级 LEQ 评分
        
        Args:
            scenario: 体验场景
            metrics: 原子指标字典 {metric_key: value}
            sample_size: 样本量
            
        Returns:
            LeqResult: 评分结果
        """
        weights = self.SCENARIO_WEIGHTS.get(
            scenario, self.DEFAULT_WEIGHTS
        )
        
        dimension_scores = {}
        
        # 1. 计算各维度得分
        dimension_scores["responsiveness"] = self._score_responsiveness(
            scenario, metrics
        )
        dimension_scores["reliability"] = self._score_reliability(
            scenario, metrics
        )
        dimension_scores["fluency"] = self._score_fluency(
            scenario, metrics
        )
        dimension_scores["quality"] = self._score_quality(
            scenario, metrics
        )
        
        # 2. 样本量置信度衰减
        confidence = self._sample_confidence(sample_size)
        
        # 3. 加权综合评分
        total_score = sum(
            dimension_scores[dim].score * weights[dim]
            for dim in weights
        )
        
        # 4. 应用置信度调整
        adjusted_score = total_score * confidence + (1 - confidence) * 50  # 小样本向中庸分靠拢
        
        return LeqResult(
            total_score=round(adjusted_score, 1),
            dimensions=dimension_scores,
            weights=weights,
            sample_size=sample_size,
            confidence=confidence
        )
    
    def _score_responsiveness(
        self, scenario: str, metrics: Dict[str, float]
    ) -> "DimensionScore":
        """计算响应性得分 (延迟类指标)"""
        latency_metrics = self._get_latency_metrics(scenario)
        contributors = []
        
        for metric_key, spec in latency_metrics.items():
            value = metrics.get(metric_key)
            if value is None:
                continue
            
            # 使用对数曲线归一化: good_threshold=100分, frustrating=0分
            score = self._latency_to_score(
                value, spec["good"], spec["frustrating"]
            )
            contributors.append(MetricContributor(
                metric=metric_key,
                value=value,
                impact=score - 50  # 相对于中位数的影响
            ))
        
        avg_score = (
            sum(c.impact for c in contributors) / len(contributors) + 50
            if contributors else 75  # 默认中上
        )
        
        return DimensionScore(
            score=max(0, min(100, avg_score)),
            weight=self.DEFAULT_WEIGHTS["responsiveness"],
            contributors=contributors
        )
    
    def _latency_to_score(
        self, value: float, good: float, frustrating: float
    ) -> float:
        """
        将延迟值映射为 0-100 分
        
        使用对数曲线而非线性映射，因为用户对延迟的感知是对数的：
        - 1s → 3s 的差异感知远大于 8s → 10s
        """
        import math
        if value <= good:
            return 100.0
        if value >= frustrating:
            return 0.0
        
        log_good = math.log(good)
        log_frustrating = math.log(frustrating)
        log_value = math.log(value)
        
        # 对数空间中的线性插值
        ratio = (log_value - log_good) / (log_frustrating - log_good)
        score = 100.0 * (1 - ratio)
        
        return max(0, min(100, score))
    
    def _sample_confidence(self, sample_size: int) -> float:
        """样本量置信度 (小样本时降低评分可信度)"""
        if sample_size >= 100:
            return 1.0
        if sample_size >= 30:
            return 0.85 + 0.15 * (sample_size - 30) / 70
        if sample_size >= 10:
            return 0.6 + 0.25 * (sample_size - 10) / 20
        return max(0.3, 0.6 * sample_size / 10)
```

### 5.1 双层检测策略

```text
Layer 1: 规则检测层 (Rule-based Detection)
  ├── 绝对阈值检测 (固定阈值，如 P95 > 5s → 告警)

Layer 2: 智能检测层 (ML-based Detection)

  ├── 突变检测 (CUSUM 算法)
  └── 复合模式检测 (多维指标联合异常)
```

### 5.2 动态基线自适应

```python
from collections import deque
from datetime import datetime, timedelta
import statistics

class AdaptiveBaseline:
    """
    动态体验质量基线
    
    特性：
    - 基于历史数据自动建立基线
    - 支持时段感知 (工作日/周末/高峰期/低峰期)
    - 指数平滑跟踪长期趋势
    - 季节性模式识别 (如晚间高峰延迟)
    """
    
    def __init__(
        self,
        scenario: str,
        metric_key: str,
        window_size: int = 10080,  # 默认7天分钟级数据
        min_samples: int = 100,
        smoothing_alpha: float = 0.05,
    ):
        self.scenario = scenario
        self.metric_key = metric_key
        self.window_size = window_size
        self.min_samples = min_samples
        self.alpha = smoothing_alpha
        
        self.history: deque = deque(maxlen=window_size)
        self.ewma_p50: float | None = None
        self.ewma_p90: float | None = None
        self.ewma_p95: float | None = None
        
        # 时段基线: {time_segment: {p50, p90, p95}}
        self.segment_baselines: dict[str, dict] = {}
        
    def update(self, value: float, timestamp: datetime) -> None:
        """更新基线"""
        self.history.append((timestamp, value))
        
        # 指数平滑更新
        if self.ewma_p50 is None:
            self.ewma_p50 = value
            self.ewma_p90 = value
            self.ewma_p95 = value
        else:
            self.ewma_p50 = (1 - self.alpha) * self.ewma_p50 + self.alpha * value
            # P90/P95 使用稍大的平滑系数以更快跟踪尾部
            self.ewma_p90 = (1 - self.alpha * 1.5) * self.ewma_p90 + self.alpha * 1.5 * value
            self.ewma_p95 = (1 - self.alpha * 2) * self.ewma_p95 + self.alpha * 2 * value
        
        # 更新时段基线
        segment = self._get_time_segment(timestamp)
        if segment not in self.segment_baselines:
            self.segment_baselines[segment] = {
                "values": deque(maxlen=1000),
            }
        self.segment_baselines[segment]["values"].append(value)
        
        # 每100个样本重新校准时段百分位
        segment_values = list(self.segment_baselines[segment]["values"])
        if len(segment_values) >= 50 and len(segment_values) % 100 == 0:
            self.segment_baselines[segment].update({
                "p50": statistics.median(segment_values),
                "p90": self._percentile(segment_values, 90),
                "p95": self._percentile(segment_values, 95),
            })
    
    def get_baseline(self, timestamp: datetime) -> "Baseline":
        """获取指定时间的基线值"""
        segment = self._get_time_segment(timestamp)
        seg_data = self.segment_baselines.get(segment, {})
        
        # 优先使用时段基线，否则使用全局基线
        if "p50" in seg_data:
            return Baseline(
                p50=seg_data["p50"],
                p90=seg_data["p90"],
                p95=seg_data["p95"],
                source=f"segment:{segment}"
            )
        
        return Baseline(
            p50=self.ewma_p50 or 0,
            p90=self.ewma_p90 or 0,
            p95=self.ewma_p95 or 0,
            source="global_ewma"
        )
    
    def _get_time_segment(self, ts: datetime) -> str:
        """根据时间划分时段"""
        hour = ts.hour
        if 6 <= hour < 12:
            return "MORNING"
        elif 12 <= hour < 18:
            return "AFTERNOON"
        elif 18 <= hour < 23:
            return "EVENING"  # 晚高峰
        else:
            return "NIGHT"
    
    def _percentile(self, data: list[float], p: float) -> float:
        """计算百分位数"""
        sorted_data = sorted(data)
        idx = int(len(sorted_data) * p / 100)
        return sorted_data[min(idx, len(sorted_data) - 1)]
```

```python
from dataclasses import dataclass
from enum import Enum
from typing import Callable

class DetectionRule:
    """退化检测规则"""
    
    def __init__(
        self,
        rule_id: str,
        scenario: str,
        metric_key: str,
        rule_type: str,  # absolute | relative_baseline | relative_trend
        condition: dict,
        severity_map: dict,
        cooldown_seconds: int = 300,
    ):
        self.rule_id = rule_id
        self.scenario = scenario
        self.metric_key = metric_key
        self.rule_type = rule_type
        self.condition = condition
        self.severity_map = severity_map
        self.cooldown_seconds = cooldown_seconds
        self.last_triggered: dict[str, datetime] = {}  # key → last trigger time
    
    def evaluate(
        self,
        current_value: float,
        baseline: Baseline,
        context: dict
    ) -> "DetectionResult | None":
        """评估规则是否触发"""
        
        if self.rule_type == "absolute":
            return self._eval_absolute(current_value)
        elif self.rule_type == "relative_baseline":
            return self._eval_relative_baseline(current_value, baseline)
        elif self.rule_type == "relative_trend":
            return self._eval_relative_trend(current_value, context)
        
        return None
    
    def _eval_absolute(self, value: float) -> "DetectionResult | None":
        """绝对阈值检测"""
        thresholds = self.condition.get("thresholds", {})
        
        for severity_str, threshold in thresholds.items():
            operator = self.condition.get("operator", ">")
            
            triggered = (
                (operator == ">" and value > threshold) or
                (operator == "<" and value < threshold)
            )
            
            if triggered:
                severity = Severity(severity_str.lower())
                return DetectionResult(
                    triggered=True,
                    rule_id=self.rule_id,
                    severity=severity,
                    current_value=value,
                    threshold_value=threshold,
                    description=f"{self.metric_key}={value:.2f} {operator} {threshold} ({severity_str})"
                )
        
        return DetectionResult(triggered=False, rule_id=self.rule_id)
    
    def _eval_relative_baseline(
        self, value: float, baseline: Baseline
    ) -> "DetectionResult | None":
        """相对基线偏移检测"""
        baseline_value = getattr(baseline, self.condition.get("baseline_field", "p95"))
        if baseline_value == 0:
            return None
        
        deviation_ratio = (value - baseline_value) / baseline_value
        trigger_ratio = self.condition.get("trigger_ratio", 2.0)
        
        if deviation_ratio >= trigger_ratio:
            severity = self._map_severity_by_ratio(deviation_ratio)
            return DetectionResult(
                triggered=True,
                rule_id=self.rule_id,
                severity=severity,
                current_value=value,
                threshold_value=baseline_value,
                deviation_ratio=deviation_ratio,
                description=(
                    f"{self.metric_key}={value:.2f} exceeds baseline "
                    f"{baseline_value:.2f} by {deviation_ratio:.1%}"
                )
            )
        
        return DetectionResult(triggered=False, rule_id=self.rule_id)
    
    def _map_severity_by_ratio(self, ratio: float) -> Severity:
        """根据偏离比例映射严重程度"""
        if ratio >= 5.0:
            return Severity.CRITICAL
        elif ratio >= 3.0:
            return Severity.HIGH
        elif ratio >= 2.0:
            return Severity.MEDIUM
        else:
            return Severity.LOW
```

### 6.1 因果推理图模型

```python
from typing import Dict, List, Set, Tuple
from dataclasses import dataclass, field

class CausalGraph:
    """
    体验退化根因分析因果图
    
    构建从基础设施层到用户体验层的因果关系网络，
    通过反向推理定位根因。
    
    因果层级 (自底向上):
    L0: 基础设施 (CPU/Memory/Disk/Network)
    L1: 中间件 (Database/Cache/MessageQueue)
    L2: 服务层 (微服务健康/响应时间/错误率)
    L3: AI 能力层 (模型可用性/Token延迟/输出质量)
    L4: 业务编排层 (请求编排/Prompt组装/RAG检索)
    L5: 客户端层 (渲染/交互/网络)
    L6: 用户体验层 (延迟/错误/流畅度/质量)
    """
    
    def __init__(self):
        # 节点: {node_id: CausalNode}
        self.nodes: Dict[str, CausalNode] = {}
        # 边: parent_id → [(child_id, relation)]
        self.edges: Dict[str, List[Tuple[str, str]]] = {}
        self._build_default_graph()
    
    def _build_default_graph(self):
        """构建默认因果网络"""
        
        # L3: AI 能力层
        ai_nodes = [
            ("ai_model_api_health", "AI模型API健康", "L3"),
            ("ai_model_rate_limit", "AI模型限流", "L3"),
            ("ai_model_token_queue", "Token生成排队", "L3"),
            ("rag_retrieval_latency", "RAG检索延迟", "L3"),
            ("content_filter_latency", "内容安全过滤延迟", "L3"),
        ]

            ("api_gateway_latency", "API网关延迟", "L2"),
            ("bff_aggregation_latency", "BFF聚合延迟", "L2"),
            ("question_service_health", "题目服务健康", "L2"),
            ("content_service_health", "内容服务健康", "L2"),
            ("error_book_service_health", "错题服务健康", "L2"),
        ]
        
        # L1: 中间件
        mw_nodes = [
            ("db_query_latency", "数据库查询延迟", "L1"),
            ("redis_hit_rate", "Redis缓存命中率", "L1"),

        ]
        
        # L0: 基础设施
        infra_nodes = [
            ("cpu_usage", "CPU使用率", "L0"),
            ("memory_usage", "内存使用率", "L0"),
            ("network_latency", "网络延迟", "L0"),
            ("disk_io", "磁盘IO", "L0"),
        ]
        
        for node_id, name, layer in (ai_nodes + svc_nodes + mw_nodes + infra_nodes):
            self.add_node(node_id, name, layer)
        
        # 构建因果边 (parent → child 表示 parent 的异常可能导致 child 异常)
        causal_links = [
            # L0 → L1
            ("cpu_usage", "db_query_latency"),
            ("memory_usage", "db_query_latency"),
            ("cpu_usage", "redis_hit_rate"),
            ("memory_usage", "redis_hit_rate"),
            ("network_latency", "vector_db_latency"),
            ("disk_io", "db_query_latency"),
            
            # L1 → L2
            ("db_query_latency", "question_service_health"),
            ("db_query_latency", "content_service_health"),
            ("db_query_latency", "error_book_service_health"),
            ("redis_hit_rate", "api_gateway_latency"),
            ("redis_hit_rate", "bff_aggregation_latency"),
            ("mq_consumer_lag", "content_service_health"),
            
            # L1 → L3
            ("vector_db_latency", "rag_retrieval_latency"),

        for parent, child in causal_links:
            self.add_edge(parent, child, "causes")
    
    def add_node(self, node_id: str, name: str, layer: str):
        self.nodes[node_id] = CausalNode(
            node_id=node_id, name=name, layer=layer
        )
    
    def add_edge(self, parent: str, child: str, relation: str):
        if parent not in self.edges:
            self.edges[parent] = []
        self.edges[parent].append((child, relation))
    
    def diagnose(
        self,
        degraded_user_metrics: List[str],
        system_signals: Dict[str, float],
        time_window: tuple[datetime, datetime]
    ) -> "RootCauseResult":
        """
        根因诊断
        
        Args:
            degraded_user_metrics: 退化的用户体验指标列表
            system_signals: 系统信号 {signal_key: value}
            time_window: 时间窗口
            
        Returns:
            根因分析结果
        """
        # 1. 从退化的用户指标反向追溯
        candidate_causes = set()
        for metric in degraded_user_metrics:
            ancestors = self._find_ancestors(metric)
            candidate_causes.update(ancestors)
        
        # 2. 用系统信号验证候选根因
        scored_causes = []
        for cause_id in candidate_causes:
            signal_value = system_signals.get(cause_id)
            if signal_value is None:
                continue
            
            # 检查该信号是否异常
            anomaly_score = self._anomaly_score(cause_id, signal_value)
            
            if anomaly_score > 0.5:  # 确认为异常
                # 计算因果路径强度
                path_strength = self._path_strength(cause_id, degraded_user_metrics)
                confidence = anomaly_score * path_strength
                
                scored_causes.append(ScoredCause(
                    cause_id=cause_id,
                    cause_name=self.nodes[cause_id].name,
                    layer=self.nodes[cause_id].layer,
                    signal_value=signal_value,
                    anomaly_score=anomaly_score,
                    path_strength=path_strength,
                    confidence=confidence,
                ))
        
        # 3. 排序并构建因果链
        scored_causes.sort(key=lambda x: x.confidence, reverse=True)
        
        primary = scored_causes[0] if scored_causes else None
        causal_chain = self._build_causal_chain(
            primary.cause_id, degraded_user_metrics
        ) if primary else []
        
        return RootCauseResult(
            primary_cause=primary,
            all_causes=scored_causes[:5],
            causal_chain=causal_chain,
            evidence=self._collect_evidence(scored_causes, system_signals),
        )
    
    def _find_ancestors(self, node_id: str, depth: int = 5) -> Set[str]:
        """反向追溯所有祖先节点"""
        ancestors = set()
        queue = [node_id]
        visited = set()
        
        for _ in range(depth):
            if not queue:
                break
            next_queue = []
            for node in queue:
                if node in visited:
                    continue
                visited.add(node)
                for parent_id, edges in self.edges.items():
                    for child_id, _ in edges:
                        if child_id == node and parent_id not in visited:
                            ancestors.add(parent_id)
                            next_queue.append(parent_id)
            queue = next_queue
        
        return ancestors
    
    def _anomaly_score(self, node_id: str, value: float) -> float:
        """计算信号的异常分数"""
        # 简化版: 这里应接入实际的异常检测模型
        thresholds = {
            "cpu_usage": (70, 85, 95),
            "memory_usage": (75, 85, 95),
            "db_query_latency": (100, 500, 1000),
            "redis_hit_rate": (95, 85, 70),  # 反向: 低于阈值是异常
            "mq_consumer_lag": (1000, 5000, 10000),
        }
        
        if node_id not in thresholds:
            return 0.0
        
        warn, high, crit = thresholds[node_id]
        
        # 对反向指标(低值=异常)特殊处理
        if node_id == "redis_hit_rate":
            if value < crit: return 1.0
            if value < high: return 0.7
            if value < warn: return 0.3
            return 0.0
        
        # 正向指标(高值=异常)
        if value >= crit: return 1.0
        if value >= high: return 0.7
        if value >= warn: return 0.3
        return 0.0
    
    def _path_strength(
        self, cause_id: str, target_metrics: List[str]
    ) -> float:
        """计算从根因到用户指标的因果路径强度"""
        # 简化: 路径越短, 强度越高; 有直接边 = 1.0
        max_strength = 0.0
        for target in target_metrics:
            path_len = self._shortest_path_length(cause_id, target)
            if path_len is not None:
                strength = 1.0 / (1.0 + path_len * 0.2)  # 衰减
                max_strength = max(max_strength, strength)
        return max_strength
    
    def _shortest_path_length(self, start: str, end: str) -> int | None:
        """BFS 最短路径"""
        if start == end:
            return 0
        queue = [(start, 0)]
        visited = {start}
        while queue:
            node, dist = queue.pop(0)
            for child_id, _ in self.edges.get(node, []):
                if child_id == end:
                    return dist + 1
                if child_id not in visited:
                    visited.add(child_id)
                    queue.append((child_id, dist + 1))
        return None
    
    def _build_causal_chain(
        self, root_id: str, target_metrics: List[str]
    ) -> List[CausalChainNode]:
        """构建从根因到用户指标的因果链"""
        chain = []
        # 找到最短路径作为展示
        best_path = None
        best_len = float('inf')
        
        for target in target_metrics:
            path = self._find_path(root_id, target)
            if path and len(path) < best_len:
                best_path = path
                best_len = len(path)
        
        if best_path:
            for i, node_id in enumerate(best_path):
                chain.append(CausalChainNode(
                    layer=self.nodes[node_id].layer,
                    component=node_id,
                    name=self.nodes[node_id].name,
                    description=f"层级{i}: {self.nodes[node_id].name}",
                    impact_on_user="→".join(
                        self.nodes[n].name for n in best_path[i:]
                    )
                ))
        
        return chain
    
    def _find_path(self, start: str, end: str) -> List[str] | None:
        """DFS 找一条路径"""
        if start == end:
            return [start]
        for child_id, _ in self.edges.get(start, []):
            sub_path = self._find_path(child_id, end)
            if sub_path:
                return [start] + sub_path
        return None
    
    def _collect_evidence(
        self, causes: List["ScoredCause"], signals: Dict[str, float]
    ) -> List[Evidence]:
        """收集支撑证据"""
        evidence = []
        for cause in causes[:3]:
            evidence.append(Evidence(
                source="system_signal",
                metric=cause.cause_id,
                value=f"{cause.signal_value}",
                description=(
                    f"{cause.cause_name} 异常 "
                    f"(值={cause.signal_value}, "
                    f"异常分={cause.anomaly_score:.2f})"
                )
            ))
        return evidence
```

### 8.2 策略执行引擎

```python
class MitigationStrategyEngine:
    """自动缓解策略执行引擎"""
    
    def __init__(
        self,
        strategy_repo: MitigationStrategyRepository,
        action_executors: dict[str, MitigationActionExecutor],
        event_bus: EventBus,
    ):
        self.strategy_repo = strategy_repo
        self.action_executors = action_executors
        self.event_bus = event_bus
        self.execution_history: dict[str, list[Execution]] = {}
    
    async def handle_degradation(
        self, degradation: ExperienceDegradationEvent
    ) -> list[MitigationResult]:
        """处理体验退化事件"""
        
        # 1. 匹配适用的策略
        strategies = await self.strategy_repo.find_matching(
            scenario=degradation.scenario,
            degradation_type=degradation.degradationType,
            severity=degradation.severity,
        )
        
        results = []
        for strategy in strategies:
            # 2. 检查触发条件
            if not self._check_conditions(strategy, degradation):
                continue
            
            # 3. 检查冷却和次数限制
            if not self._check_cooldown(strategy):
                continue
            
            # 4. 执行动作
            if strategy.auto_execute:
                result = await self._execute_action(strategy, degradation)
                results.append(result)
                
                # 5. 发布事件
                await self.event_bus.publish(MitigationExecuted(
                    strategy_id=strategy.strategy_id,
                    degradation_id=degradation.eventId,
                    result=result,
                ))
            else:
                # 通知人工
                await self._notify_manual_execution(strategy, degradation)
        
        return results
    
    def _check_conditions(
        self, strategy: MitigationStrategyConfig,
        degradation: ExperienceDegradationEvent
    ) -> bool:
        """验证所有触发条件"""
        for condition in strategy.trigger.conditions:
            metric_value = degradation.currentMetrics.get(condition.metric)
            if metric_value is None:
                # 检查特殊指标
                if condition.metric == "affected_percentage":
                    metric_value = degradation.impact.affectedPercentage
                else:
                    return False
            
            if condition.operator == ">" and not metric_value > condition.value:
                return False
            if condition.operator == "<" and not metric_value < condition.value:
                return False
        
        return True
    
    def _check_cooldown(self, strategy: MitigationStrategyConfig) -> bool:
        """检查冷却时间"""
        history = self.execution_history.get(strategy.strategy_id, [])
        
        # 检查执行次数
        recent = [e for e in history if e.is_recent(strategy.cooldown_seconds)]
        if len(recent) >= strategy.max_executions:
            return False
        
        # 检查冷却
        if recent:
            latest = max(recent, key=lambda e: e.executed_at)
            elapsed = (datetime.now() - latest.executed_at).total_seconds()
            if elapsed < strategy.cooldown:
                return False
        
        return True
    
    async def _execute_action(
        self, strategy: MitigationStrategyConfig,
        degradation: ExperienceDegradationEvent
    ) -> MitigationResult:
        """执行缓解动作"""
        executor = self.action_executors.get(strategy.action.type)
        if not executor:
            return MitigationResult(
                strategy_id=strategy.strategy_id,
                success=False,
                error=f"No executor for action type: {strategy.action.type}"
            )
        
        try:
            result = await executor.execute(
                degradation=degradation,
                params=strategy.action.params
            )
            
            # 记录执行历史
            self.execution_history.setdefault(
                strategy.strategy_id, []
            ).append(Execution(
                executed_at=datetime.now(),
                degradation_id=degradation.eventId,
                result=result
            ))
            
            return result
            
        except Exception as e:
            return MitigationResult(
                strategy_id=strategy.strategy_id,
                success=False,
                error=str(e)
            )
```

```java
/**
 * 学习体验质量实时处理作业
 * 
 * 数据流:
 * Kafka(体验事件) → 指标计算 → 退化检测 → 根因分析 → 告警/缓解
 */
public class LearningExperienceQualityJob {

    public static void main(String[] args) throws Exception {
        StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();
        env.enableCheckpointing(60000); // 1分钟checkpoint
        env.setParallelism(8);

        // ── 1. 体验事件 Source ──
        DataStream<LearningExperienceEvent> eventStream = env
            .fromSource(
                KafkaSource.<LearningExperienceEvent>builder()
                    .setBootstrapServers("kafka:9092")
                    .setTopics("leq-events")
                    .setGroupId("leq-processor")
                    .setStartingOffsets(OffsetsInitializer.committedOffsets(OffsetResetStrategy.LATEST))
                    .setValueOnlyDeserializer(new JsonDeserializationSchema<>(LearningExperienceEvent.class))
                    .build(),
                WatermarkStrategy.<LearningExperienceEvent>forBoundedOutOfOrderness(Duration.ofSeconds(10))
                    .withTimestampAssigner((event, ts) -> event.getTimestamp()),
                "leq-events-source"
            );

        // ── 2. 指标实时聚合 (5分钟滚动窗口 + 1分钟滑动) ──
        DataStream<MetricAggregation> aggregationStream = eventStream
            .keyBy(LearningExperienceEvent::getScenario)
            .window(SlidingEventTimeWindows.of(Time.minutes(5), Time.minutes(1)))
            .aggregate(new MetricAggregationFunction());

        // 写入数据库 + 发布到 Kafka
        aggregationStream
            .filter(a -> a.getSampleCount() > 0)
            .map(new RichMapFunction<MetricAggregation, MetricAggregation>() {
                private transient LeqScoreCalculator calculator;
                
                @Override
                public void open(Configuration params) {
                    calculator = new LeqScoreCalculator();
                }
                
                @Override
                public MetricAggregation map(MetricAggregation agg) throws Exception {
                    // 实时计算 LEQ 评分
                    LeqResult result = calculator.calculate(
                        agg.getScenario(),
                        agg.getMetrics(),
                        agg.getSampleCount()
                    );
                    agg.setLeqScore(result.getTotalScore());
                    return agg;
                }
            })
            .sinkTo(JdbcSink.simplify(
                JdbcConnectionOptions.builder()
                    .withUrl("jdbc:mysql://db:3306/primetop")
                    .withDriverName("com.mysql.cj.jdbc.Driver")
                    .build(),
                new MetricAggregationJdbcStatement(),
                JdbcExecutionOptions.builder()
                    .withBatchSize(100)
                    .withBatchIntervalMs(5000)
                    .build()
            ));

        // ── 3. 体验退化检测 (CEP 模式匹配) ──
        Pattern<MetricAggregation, ?> latencySpikePattern = Pattern
            .<MetricAggregation>begin("first_high")
            .where(new SimpleCondition<MetricAggregation>() {
                @Override
                public boolean filter(MetricAggregation agg) {
                    Double p95 = agg.getMetrics().get("ai.first_token_latency_p95");
                    return p95 != null && p95 > 5000;
                }
            })
            .timesOrMore(2)  // 连续2个窗口
            .consecutive()
            .within(Time.minutes(3));

        CEP.pattern(aggregationStream.keyBy(MetricAggregation::getScenario), latencySpikePattern)
            .select(new DegradationPatternSelector())
            .sinkTo(new DegradationEventSink());

        // ── 4. 行为信号异常检测 ──
        DataStream<BehaviorAnomaly> anomalyStream = eventStream
            .keyBy(e -> Tuple2.of(e.getUserId(), e.getScenario()))
            .process(new BehaviorAnomalyDetector());

        // ── 5. 合并信号 → 根因分析 ──
        anomalyStream
            .connect(aggregationStream.broadcast(BASLINE_STATE_DESCRIPTOR))
            .process(new RootCauseAnalysisFunction())
            .filter(event -> event != null)
            .addSink(new AlertTriggerSink());

        env.execute("LearningExperienceQualityJob");
    }
}
```

```java
/**
 * 窗口内指标聚合函数
 * 
 * 对每个场景的体验事件按窗口聚合，计算各指标的百分位值和质量分布
 */
public class MetricAggregationFunction 
        extends AggregateFunction<
            LearningExperienceEvent, 
            MetricAggregationAccumulator, 
            MetricAggregation> {

    @Override
    public MetricAggregationAccumulator createAccumulator() {
        return new MetricAggregationAccumulator();
    }

    @Override
    public MetricAggregationAccumulator add(
            LearningExperienceEvent event, 
            MetricAggregationAccumulator acc) {
        
        acc.scenario = event.getScenario();
        acc.sampleCount++;
        
        for (ExperienceMetric metric : event.getMetrics()) {
            String key = metric.getMetricKey();
            acc.metricValues
                .computeIfAbsent(key, k -> new MetricAccumulator(key))
                .addValue(metric.getMetricValue(), metric.getQuality());
        }
        
        // 设备档次分布
        acc.deviceTierCounts.merge(event.getDeviceInfo().getDeviceTier(), 1, Integer::sum);
        
        // 网络类型分布
        acc.networkTypeCounts.merge(event.getDeviceInfo().getNetworkType(), 1, Integer::sum);
        
        return acc;
    }

    @Override
    public MetricAggregation getResult(MetricAggregationAccumulator acc) {
        MetricAggregation result = new MetricAggregation();
        result.setScenario(acc.scenario);
        result.setSampleCount(acc.sampleCount);
        
        Map<String, Double> metrics = new HashMap<>();
        for (Map.Entry<String, MetricAccumulator> entry : acc.metricValues.entrySet()) {
            MetricAccumulator mac = entry.getValue();
            metrics.put(entry.getKey() + "_p50", mac.getPercentile(50));
            metrics.put(entry.getKey() + "_p90", mac.getPercentile(90));
            metrics.put(entry.getKey() + "_p95", mac.getPercentile(95));
            metrics.put(entry.getKey() + "_p99", mac.getPercentile(99));
            metrics.put(entry.getKey() + "_avg", mac.getAverage());
            
            // 质量分布
            metrics.put(entry.getKey() + "_good_ratio", 
                (double) mac.goodCount / mac.totalCount);
            metrics.put(entry.getKey() + "_frustrating_ratio", 
                (double) mac.frustratingCount / mac.totalCount);
        }
        result.setMetrics(metrics);
        result.setDeviceTierDistribution(acc.deviceTierCounts);
        result.setNetworkDistribution(acc.networkTypeCounts);
        
        return result;
    }

    @Override
    public MetricAggregationAccumulator merge(
            MetricAggregationAccumulator a, 
            MetricAggregationAccumulator b) {
        a.sampleCount += b.sampleCount;
        b.metricValues.forEach((k, v) -> 
            a.metricValues.merge(k, v, MetricAccumulator::merge));
        b.deviceTierCounts.forEach((k, v) -> 
            a.deviceTierCounts.merge(k, v, Integer::sum));
        b.networkTypeCounts.forEach((k, v) -> 
            a.networkTypeCounts.merge(k, v, Integer::sum));
        return a;
    }
}

/**
 * 百分位计算累加器 (使用 T-Digest 近似算法)
 */
class MetricAccumulator {
    private final String key;
    private final TDigest digest = TDigest.createAvlDigest(100); // 压缩参数100
    public int totalCount = 0;
    public int goodCount = 0;
    public int tolerableCount = 0;
    public int degradedCount = 0;
    public int frustratingCount = 0;
    
    public void addValue(double value, QualityLevel quality) {
        digest.add(value);
        totalCount++;
        switch (quality) {
            case GOOD -> goodCount++;
            case TOLERABLE -> tolerableCount++;
            case DEGRADED -> degradedCount++;
            case FRUSTRATING -> frustratingCount++;
        }
    }
    
    public double getPercentile(int p) {
        return digest.quantile(p / 100.0);
    }
    
    public double getAverage() {
        // T-Digest不直接提供均值，可以用 (P25+P50+P75)/3 近似
        // 或额外维护一个sum和count
        return (getPercentile(25) + getPercentile(50) + getPercentile(75)) / 3.0;
    }
    
    public MetricAccumulator merge(MetricAccumulator other) {
        // T-Digest 支持合并
        this.digest.add(other.digest);
        this.totalCount += other.totalCount;
        this.goodCount += other.goodCount;
        this.tolerableCount += other.tolerableCount;
        this.degradedCount += other.degradedCount;
        this.frustratingCount += other.frustratingCount;
        return this;
    }
}
```

```dart
    }
  }

  }
```

## 13. 错误处理与降级

### 13.1 引擎自身容错

| 故障场景 | 处理策略 |
| --- | --- |
| Kafka 消费者断连 | 自动重连（指数退避），断连期间使用客户端本地缓存兜底 |
| Flink 作业失败 | Checkpoint 恢复；失败期间降级为简单阈值检测 |
| 基线数据丢失 | 回退到预置默认基线 (`DEFAULT_THRESHOLDS`) |
| 根因分析服务不可用 | 跳过根因分析，仅输出退化检测+基础告警 |
| 数据库写入失败 | 写入 Kafka 死信队列，后台重试 |
| 告警通道不可用 | 告警降级为仅 Dashboard 展示，记录日志 |

```python
class DataQualityGuard:
    """体验数据质量守卫"""
    
    def validate_event(
        self, event: LearningExperienceEvent
    ) -> ValidationResult:
        """验证事件数据质量"""
        errors = []
        
        # 必填字段检查
        if not event.eventId:
            errors.append("Missing eventId")
        if not event.userId:
            errors.append("Missing userId")
        if not event.scenario:
            errors.append("Missing scenario")
        
        # 时间戳合理性
        now = time.time() * 1000
        if abs(now - event.timestamp) > 5 * 60 * 1000:  # 5分钟偏差
            errors.append(f"Timestamp skew too large: {event.timestamp}")
        
        # 指标值合理性
        for metric in event.metrics:
            if metric.metricValue < 0:
                errors.append(f"Negative metric value: {metric.metricKey}")
            if metric.metricValue > 10_000_000:  # 1000万
                errors.append(f"Unreasonable metric value: {metric.metricKey}")
        
        # 设备信息完整性
        if not event.deviceInfo.platform:
            errors.append("Missing platform")
        
        if errors:
            return ValidationResult(valid=False, errors=errors)
        return ValidationResult(valid=True)
```

## 18. 术语表

| 术语 | 定义 |
| --- | --- |
| LEQ (Learning Experience Quality) | 学习体验质量评分，0-100分 |
| 退化 (Degradation) | 体验指标偏离正常基线的现象 |
| 基线 (Baseline) | 基于历史数据建立的正常体验指标范围 |
| 根因 (Root Cause) | 导致体验退化的最底层原因 |
| 缓解 (Mitigation) | 为减轻体验退化影响而采取的自动化或手动动作 |
| LEQ Score | 综合体验质量评分，由四个维度加权计算 |
| CEP (Complex Event Processing) | 复杂事件处理，用于检测事件序列中的模式 |
| RUM (Real User Monitoring) | 真实用户监控 |
| T-Digest | 一种高效的百分位近似统计算法 |
