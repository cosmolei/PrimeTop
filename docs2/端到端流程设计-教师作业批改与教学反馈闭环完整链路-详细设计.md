> **文档版本**：v1.0

> **关联文档**：服务端-智能作业批改与教师阅卷辅助引擎、服务端-教师班级管理与作业发布服务、端到端流程设计-学生作业接收完成提交与反馈闭环完整链路、端到端流程设计-教师端班级管理与作业发布完整链路

## 1. 概述

### 1.1 文档目的

本文档详细描述教师从 **接收学生作业提交** → **AI自动批改预处理** → **教师阅卷批改** → **生成分反馈** → **反馈下发学生** → **学生查看与申诉** → **班级学情聚合分析** → **教学计划动态调整** 的完整端到端闭环流程。

该流程是教师端核心工作流之一，涉及教师端Web/APP交互、AI批改引擎、消息推送、学情分析、错题归档等多个子系统的联动。本文档为开发团队提供跨模块集成的详细技术设计，确保各子系统的数据流、状态流转、异常处理协调一致。

### 1.2 适用范围

| 维度 | 说明 |
|------|------|
| 适用学段 | 小学、初中、高中 |
| 作业类型 | 客观题（选择/填空/判断）、主观题（简答/论述/作文）、图片题（手写拍照） |
| 批改模式 | AI全自动批改、AI辅助+教师复核、教师纯人工批改 |
| 反馈粒度 | 逐题评分、整份作业评语、班级共性分析报告 |

### 1.3 核心设计目标

1. **效率优先**：客观题由AI秒级批改，教师只需关注主观题，节省70%以上阅卷时间
2. **质量兜底**：AI初评 + 教师复核双重保障，教师可一键修改AI评分和评语
3. **闭环联动**：批改结果自动流入学情分析、错题本、复习计划，无需人工干预
4. **反馈及时**：客观题提交即可反馈，主观题批改完成后24h内推送反馈通知
5. **数据驱动**：批改数据自动生成班级学情报告，辅助教师调整教学重点

### 1.4 与现有文档的关系

```
端到端流程设计-教师端班级管理与作业发布完整链路  ← 教师布置作业
    ↓ 学生完成作业
端到端流程设计-学生作业接收完成提交与反馈闭环     ← 学生提交作业
    ↓ 触发批改流程
▼ 本文档：教师作业批改与教学反馈闭环              ← 教师批改+反馈
    ↓ 反馈下发
学生端：查看成绩 → 错题自动收录 → 复习计划调整
```

## 2. 角色与场景定义

### 2.1 参与角色

| 角色 | 职责 | 系统标识 |
|------|------|----------|
| 教师 | 阅卷批改、评分确认、撰写评语、调整教学计划 | `TEACHER` |
| AI系统 | 客观题自动批改、主观题初步评分、评语草稿生成 | `SYSTEM_AI` |
| 学生 | 查看批改结果、阅读评语、发起成绩申诉 | `STUDENT` |
| 家长 | 查看孩子作业成绩（可选，受隐私设置控制） | `PARENT` |

### 2.2 核心用户场景

**场景A — 日常小作业快速批改（高频）**
> 教师布置数学随堂练习（20道选择题），学生在线作答提交。系统秒级自动批改，教师收到成绩汇总后确认发布，全班30名学生即时收到成绩和解析。

**场景B — 主观题AI辅助批改（中频）**
> 教师布置语文阅读理解（3道主观题），学生提交文字作答。AI对每道题进行初评打分并生成评语草稿，教师逐题审核、修改评分和评语后确认发布。

**场景C — 手写作业拍照批改（中频）**
> 教师布置数学解答题，学生纸上作答拍照上传。AI通过OCR识别手写内容，进行步骤分步评分并标注扣分点，教师在批改界面查看原图+AI叠加标注进行复核。

**场景D — 作文深度批改（低频高耗时）**
> 教师布置英语作文，AI生成多维度评分（立意/结构/语言/语法）和修改建议，教师整体审核后选择性采纳或全部重写评语，学生收到带批注的作文反馈。

**场景E — 学生成绩申诉（低频）**
> 学生对某道主观题的评分有异议，一键发起申诉并附加说明。教师收到申诉通知后重新审阅，决定维持或修改评分。

## 4. 数据结构定义

### 4.1 核心表设计

#### 4.1.1 作业批改任务表 `hw_grading_task`

```sql
CREATE TABLE hw_grading_task (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    task_id         VARCHAR(64) NOT NULL UNIQUE COMMENT '批改任务唯一ID',
    homework_id     BIGINT NOT NULL COMMENT '关联作业ID',
    class_id        BIGINT NOT NULL COMMENT '班级ID',
    subject_code    VARCHAR(20) NOT NULL COMMENT '学科编码',
    teacher_id      BIGINT NOT NULL COMMENT '教师ID',
    
    -- 任务状态
    status          VARCHAR(20) NOT NULL DEFAULT 'PENDING' 
                    COMMENT 'PENDING/AI_GRADING/TEACHER_REVIEW/PUBLISHED/APPEALED/CLOSED',
    
    -- 提交统计
    total_students      INT NOT NULL DEFAULT 0 COMMENT '应提交人数',
    submitted_count     INT NOT NULL DEFAULT 0 COMMENT '已提交人数',
    auto_graded_count   INT NOT NULL DEFAULT 0 COMMENT 'AI已批改人数',
    teacher_reviewed_count INT NOT NULL DEFAULT 0 COMMENT '教师已复核人数',
    
    -- 时间节点
    submit_deadline     DATETIME NOT NULL COMMENT '提交截止时间',
    ai_grading_started_at   DATETIME COMMENT 'AI批改开始时间',
    ai_grading_completed_at DATETIME COMMENT 'AI批改完成时间',
    teacher_review_started_at  DATETIME COMMENT '教师开始阅卷时间',
    published_at        DATETIME COMMENT '成绩发布时间',
    
    -- 配置
    grading_mode        VARCHAR(20) NOT NULL DEFAULT 'AI_ASSIST' 
                        COMMENT 'AUTO_ONLY/AI_ASSIST/MANUAL_ONLY',
    
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_homework (homework_id),
    INDEX idx_teacher_status (teacher_id, status),
    INDEX idx_class (class_id, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='作业批改任务';
```

### 5.1 阶段一：提交接收与预处理

#### 5.1.1 触发条件

当学生提交作业时（参见 `端到端流程设计-学生作业接收完成提交与反馈闭环`），系统自动触发批改预处理。

#### 5.1.2 处理流程

```

    ├─→ [1] 提交校验
    │      - 检查是否在截止时间内（标记 is_late）

    │
    ├─→ [2] 内容标准化
    │      - 文本作答：统一编码、过滤非法字符

    │
    ├─→ [3] 创建批改记录
    │      - 在 hw_student_grading 创建 PENDING 记录
    │      - 关联 hw_grading_task
    │
    ├─→ [4] 路由判改策略
```

#### 5.2.2 客观题批改引擎关键代码

```python
class ObjectiveGradingEngine:
    """客观题自动批改引擎"""
    
    GRADING_RULES = {
        'MULTIPLE_CHOICE': self._grade_choice,
        'FILL_BLANK': self._grade_fill_blank,
        'TRUE_FALSE': self._grade_choice,
        'MULTIPLE_RESPONSE': self._grade_multi_response,
    }
    
    def grade(self, question: dict, student_answer: str) -> dict:
        """
        批改单道客观题
        返回: {isCorrect, score, comment, errorType}
        """
        q_type = question['questionType']
        correct_answer = question['correctAnswer']
        max_score = question['maxScore']
        
        grading_fn = self.GRADING_RULES.get(q_type)
        if not grading_fn:
            raise ValueError(f"Unsupported question type: {q_type}")
        
        return grading_fn(student_answer, correct_answer, max_score, question)
    
    def _grade_choice(self, student_answer, correct_answer, max_score, question):
        """选择题判分"""
        if student_answer.strip().upper() == correct_answer.strip().upper():
            return {
                'isCorrect': True,
                'score': max_score,
                'comment': '回答正确',
                'errorType': None
            }
        else:
            kp = question.get('knowledgePoints', [])
            return {
                'isCorrect': False,
                'score': 0,
                'comment': f'选择了{student_answer}，正确答案是{correct_answer}。',
                'errorType': 'CONCEPT_ERROR',
                'knowledgePoints': kp
            }
    
    def _grade_fill_blank(self, student_answer, correct_answer, max_score, question):
        """填空题判分（支持容错匹配）"""
        # 标准化：去首尾空格、全角转半角、统一标点
        normalized_student = self._normalize_answer(student_answer)
        
        # 可接受答案列表
        acceptable = question.get('acceptableAnswers', [correct_answer])
        acceptable = [self._normalize_answer(a) for a in acceptable]
        
        if normalized_student in acceptable:
            return {'isCorrect': True, 'score': max_score, 'comment': '回答正确', 'errorType': None}
        
        # 部分正确（关键词包含）
        keywords = question.get('keywords', [])
        matched = [kw for kw in keywords if kw in normalized_student]
        if matched and len(matched) >= len(keywords) * 0.5:
            partial_score = max_score * 0.5
            return {
                'isCorrect': False,
                'score': partial_score,
                'comment': f'部分正确，包含关键词：{matched}。但完整答案应为：{correct_answer}',
                'errorType': 'INCOMPLETE'
            }
        
        return {
            'isCorrect': False,
            'score': 0,
            'comment': f'答案不正确，正确答案：{correct_answer}',
            'errorType': 'CONCEPT_ERROR'
        }
    
    def _normalize_answer(self, text: str) -> str:
        """答案标准化"""
        import unicodedata
        text = unicodedata.normalize('NFKC', text.strip().lower())
        # 去除多余空格
        return ' '.join(text.split())
```

```python
class SubjectiveGradingEngine:
    """主观题AI批改引擎"""
    
    async def grade(self, question: dict, student_answer: str, 
                    context: GradingContext) -> dict:
        """
        使用大模型对主观题进行评分
        """
        rubric = question.get('gradingRubric', {})
        prompt = self._build_grading_prompt(
            question=question,
            student_answer=student_answer,
            rubric=rubric,
            grade_level=context.grade_level,
            subject=context.subject
        )
        
        # 调用大模型
        response = await self.llm_client.chat(
            model=context.grading_model_id,
            messages=[
                {"role": "system", "content": GRADING_SYSTEM_PROMPT},
                {"role": "user", "content": prompt}
            ],
            temperature=0.1,  # 低温度保证评分一致性
            response_format={"type": "json_object"},
            timeout=30
        )
        
        result = json.loads(response.content)
        
        return {
            'aiScore': result['score'],
            'aiConfidence': result['confidence'],
            'aiComment': result['comment'],
            'gradingSteps': result.get('steps', []),
            'knowledgePoints': result.get('knowledgePoints', []),
            'errorType': result.get('errorType')
        }
    
    def _build_grading_prompt(self, question, student_answer, rubric, 
                               grade_level, subject):
        return f"""你是一位专业的{subject}教师，请对以下学生答案进行评分。

## 题目信息
- 题干：{question['stem']}
- 满分：{question['maxScore']}分
- 学段年级：{grade_level}

## 评分标准（Rubric）
{json.dumps(rubric, ensure_ascii=False, indent=2)}

## 学生答案
{student_answer}

## 参考答案
{question.get('referenceAnswer', '无')}

## 输出要求
请以JSON格式输出评分结果：
{{
    "score": 数字（0到满分之间，精确到0.5）,
    "confidence": 0到1之间的数字（对评分结果的信心度）,
    "comment": "评语（先肯定优点，再指出不足，给出改进建议，100字以内）",
    "errorType": "CONCEPT_ERROR|CALCULATION_ERROR|INCOMPLETE|LOGIC_ERROR|EXPRESSION_ERROR|null",
    "steps": [{{"stepIndex": 1, "stepContent": "...", "stepScore": 2, "stepMaxScore": 3, "stepResult": "CORRECT|PARTIALLY_CORRECT|INCORRECT", "aiNote": "..."}}],
    "knowledgePoints": ["知识点ID列表"]
}}

## 注意事项
1. 评分必须严格参照评分标准，不因书写质量增减分数
2. 分步给分：即使最终答案错误，中间步骤正确也应给部分分
3. 评语用词要鼓励为主，避免打击学生积极性
4. confidence低于0.6时，建议在comment中标注"建议教师复核"
"""
```

#### 5.7.2 知识点掌握度更新算法

```python
def update_mastery_after_grading(student_id: int, 
                                  grading_detail: dict,
                                  homework_config: dict):
    """
    作业批改后更新学生知识点掌握度
    使用改进的BKT (Bayesian Knowledge Tracing) 模型
    """
    questions = grading_detail['questionGradingDetail']['questions']
    
    # 按知识点分组统计
    kp_results = defaultdict(lambda: {'correct': 0, 'total': 0, 'partial': 0})
    
    for q in questions:
        for kp_id in q.get('knowledgePoints', []):
            if q['isCorrect']:
                kp_results[kp_id]['correct'] += 1
            elif q.get('score', 0) > 0:
                kp_results[kp_id]['partial'] += 0.5
            kp_results[kp_id]['total'] += 1
    
    # 更新每个知识点的掌握度
    for kp_id, result in kp_results.items():
        current_mastery = get_current_mastery(student_id, kp_id)
        
        # BKT参数
        P_T = 0.1   # 知识迁移概率
        P_S = 0.2   # 猜对概率
        P_G = 0.05  # 失误概率
        
        # 观测到的正确率
        observed_rate = (result['correct'] + result['partial']) / result['total']
        
        # 贝叶斯更新
        if observed_rate >= 1.0:
            # 全对：掌握度提升
            new_mastery = current_mastery + (1 - current_mastery) * P_T
            new_mastery = min(0.99, new_mastery)
        elif observed_rate <= 0.0:
            # 全错：掌握度下降
            new_mastery = current_mastery * (1 - P_T)
            new_mastery = max(0.01, new_mastery)
        else:
            # 部分正确：温和调整
            adjustment = (observed_rate - 0.5) * 0.1
            new_mastery = max(0.01, min(0.99, current_mastery + adjustment))
        
        # 持久化
        save_mastery_update(
            student_id=student_id,
            knowledge_point_id=kp_id,
            old_mastery=current_mastery,
            new_mastery=new_mastery,
            source='HOMEWORK_GRADING',
            source_id=grading_detail['gradingId'],
            evidence_count=result['total']
        )
```
