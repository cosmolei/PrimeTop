## 1. 模块概述

### 1.1 功能定位

本文档是口算拍照整页批改域(Oral Calculation Photo Batch-Grading,内部代号 OCB-UI)的**客户端呈现层权威**,兑现 README 批次(四十六)登记的"口算拍照客户端页面(服务端已就绪,客户端页面层零覆盖)"缺口。

经全目录关键词扫描确认(2026-11-23,`口算拍照/整页批改/竖式批改`):服务端《口算拍照整页批改引擎》与思维训练系统(蹭词命中)存在,口算拍照批改**客户端页面层零覆盖**——《客户端-拍照搜题答疑页面架构与交互设计》为单题检索场景,《客户端-拍照图像采集与预处理引擎》为采集基础设施不含批改编排语义,《客户端-口算拍照批改》相关的整页标注渲染/逐格交互/家长改判链路无任何文档承接。本文补齐该缺口(模式同批次(四十)棋类/(四十五)配音/(四十六)词语辨析:服务端已就绪→客户端页面层补全)。

口算批改页面的核心交互是**整页影像的呈现与人工兜底**:家长(或学生)连拍 1-4 页口算作业→端侧预处理与直传→服务端异步批改→客户端轮询进度→整页标注图叠加逐格热区渲染→家长对低置信度格子确认/改判→报告与针对性训练建议呈现。客户端只做呈现、采集与人工确认:零判分、零识别、零错因计算。

## 3. 页面架构

### 3.1 `/oral-calc` 批改首页

**布局**:顶部孩子切换条(家长身份渲染,委托家庭账户组件;学生身份隐藏)+ 今日配额卡 + 拍照主按钮 + 历史任务列表(倒序,分页加载)。

**配额卡**:渲染服务端 `dailyQuota {used, limit}`(创建任务响应回传并缓存 5min):"今日已批改 X/Y 页";used≥limit 时主按钮置灰并渲染"今日批改次数已用完,明天再来吧"(47411 预呈现,服务端为权威);配额不可本地预扣(G2)。

**历史任务卡要素**:任务号(taskNo)、日期、页数、状态角标(进行中/已完成/部分完成/已失败/已过期)、正确率(仅完成态渲染,服务端值原样展示)、缩略标注图(PrimeImageLoader 委托,无则渲染页数占位)。

**交互规约**:
- 进行中任务卡点击直达进度页;失败任务卡渲染"重新拍照"引导(禁"重试批改"——服务端 G6 终态不可变,重跑即新建任务);
- 47416 幂等命中(重复创建回放旧任务):若回放任务已在历史列表且为终态,首页弹出"这页最近批改过"提示卡,一键直达旧结果(G12 客户端提示义务);
- 骨架屏/空态/错误态遵循《客户端-页面状态模式与骨架屏加载空态错误态设计规范》。

### 3.2 `/oral-calc/capture` 拍照与上传页

**结构**:顶部页卡横条(1-4 页,每页缩略图+删除+重拍)+ 取景区(委托拍照预处理引擎)+ 底部操作条(拍照/从相册选择/完成上传)。

**拍照规约**:
- 页数上限 4 页(服务端 pageCount 1-4),超出吐司"一次最多拍 4 页";
- 每张照片经端侧预处理(透视矫正/去阴影/增强/智能压缩至目标体积,R2 委托),预处理参数固定为"整页文档模式",禁用户手动滤镜(与拍题单题裁剪模式区分);
- 本地预检:格式 jpg/png/webp(47402 预检)/单图 ≤20MB(47403 预检,超限引导压缩重拍);
- 相册导入允许(与听写 G12 相机强制不同:本场景家长整理作业常用相册),导入图同样过预处理管线。

**上传编排**:
1. 点击"开始批改"→ 按钮置 LOADING 防双击 → POST /tasks(childId/pageCount/imageMeta/clientRequestId),clientRequestId 为 UUID v7 任务级幂等键,全链路复用;
2. 响应 uploadUrls 按 pageNo 严格对齐(G12);逐页直传 OSS(R3 委托,并行度 2,单图失败重试≤2 次仍败则整体失败引导重拍,47401);
3. 全部直传成功 → POST /tasks/{id}/images:complete(幂等,重复回调安全);随后本地临时文件进入 CLEANUP 通道 finally 删除(G1),跳进度页;
4. 直传中退出页面:上传继续后台执行,本地文件保留至上传回调完成再清;回到页面经任务状态恢复上传进度(禁重新创建任务)。

**家长场景前置**:scene=PARENT_GRADE 需已选 childId,创建前渲染确认条"将为 <孩子昵称> 批改作业"(昵称脱敏,家庭账户委托);scene=SELF_CHECK(学生自查)无 childId,禁渲染家长专属文案(G9)。

### 3.3 `/oral-calc/task/:taskId` 批改进度页

**阶段呈现**:服务端状态→阶段条映射(禁本地推断进度):

| 服务端状态 | 阶段条呈现 |
| --- | --- |
| CREATED/UPLOADED | "照片已收到,准备开始…" |
| ANALYZING | "正在分析版面…"(附提示"识别整页题目布局") |
| RECOGNIZING | "正在辨认题目和手写答案…"(渲染 progress.doneItems/totalItems 进度环) |
| GRADING | "正在逐题批改…" |
| REPORTING | "正在生成批改报告…" |
| COMPLETED/PARTIAL_COMPLETED | 自动跳结果页 |
| FAILED/EXPIRED/CANCELED | 终态视图(失败话术/过期话术/已取消) |

**轮询规约**:1s 起 1.5 倍退避封顶 5s(服务端 §5.3 建议);推送召回为加速通道(服务端完成事件经消息中心推送,客户端收到 push 立即拉取一次);轮询期间页面不可取消态为 SUBMITTED 之后仅允许"取消任务"(服务端无取消 API 时置灰,呈现"批改进行中,马上好")——取消语义以服务端为准(竞态裁决 §6.3)。

**异常呈现**:47421/47422(识别/判题服务繁忙):终态失败视图+"稍后再试"引导,禁自动连点重试(冷却 3s);47404(照片模糊降级帧):进度页顶部黄色提示条"照片有点模糊,部分题目可能需要您确认",不阻断流程(200 语义帧)。

### 3.4 `/oral-calc/task/:taskId/result` 整页结果页(核心页)

**主渲染**:服务端 `result_annotated.webp`(红 ✓/蓝 ✗ 服务端已绘制)铺满宽度,Pinch 缩放 + 平移(交互手势归手势系统);下方汇总条:总题数/正确数/正确率(服务端 summary 原样渲染,禁本地重算 R7)。

**逐格热区**:按 items[].bbox(千分比坐标)在图上叠加透明热区(PrimeImageLoader 图片加载完成后按容器实际尺寸换算,R4 委托);热区仅交互用途,禁在热区上再绘制对错符号(G5)。

**格子视觉语义**:

| 格子状态 | 热区呈现 |
| --- | --- |
| GRADED + isCorrect=true | 绿色 30% 描边(可点) |
| GRADED + isCorrect=false | 红色 30% 描边 + 角标错因图标(可点) |
| PENDING_REVIEW(reviewStatus) | 黄色脉冲描边 + "待确认"角标(必点,家长确认义务) |
| UNSUPPORTED | 灰色描边 + "暂不支持"角标(点击呈现分流弹层) |
| RECOG_FAILED | 虚线灰框 + "未识别"角标 |

**单格详情抽屉**(点击热区弹出):
- 题目文本(problemText 原样,如"36+47=")、识别出的手写答案(studentAnswer)、标准答案(expectedValue,仅判题后存在);
- 正误结论(isCorrect 服务端原样)+ 错因友好话术(R11 映射表:进位/退位/口诀/符号/抄错/未作答/其他,话术带"可能"前缀,禁确定性诊断);
- lowConfidence=true 或 reviewStatus=PENDING_REVIEW:顶部黄色条"这题没太看清,请确认孩子写的是:<studentAnswer>?",家长按钮组:[判对了][判错了](=改判入口)+ [识别错了](=误识别上报);
- reviewStatus=CONFIRMED:渲染"已确认"态,改判按钮隐藏(一次性 G6);
- UNSUPPORTED:呈现"这类题(竖式/应用题)暂不支持整页批改"+ [去拍照搜题]分流按钮(深链接 R12)+ 禁对错渲染。

**家长改判流程**(抽屉内):
- 点击[判对了]/[判错了]→ PUT /items/{id}/review {isCorrect, note?}→ 乐观呈现 LOADING → 成功后 resync 拉取 result+summary 全量刷新(禁本地局部改统计,G6 改判不回写识别字段但展示统计以服务端为准);
- 47413(改判冲突):吐司"该题已被确认过"并 resync;
- 误识别上报:[识别错了]→ 弹层选择"孩子实际写的是____"(数字输入,选填)→ POST /items/{id}/misjudgment {kind:RECOGNITION, correctValue}→ 吐司"已记录,会帮助我们改得更准"(24h 幂等,重复点击静默成功)。

**手动框选模式**(服务端 D3/47406 引导):结果/失败视图检测到 failCode=OCB_006(47406)或响应 degrade 标记 manualFrameSelect=true 时,呈现[手动框选题目]入口→全屏态展示原图,家长拖拽框选题目区域(每框一题,≥1 框,≤60 框)→提交框选坐标(千分比)→服务端按框重跑;客户端禁对框内内容做任何识别(G11)。框选提交期间呈现"按你框选的范围重新批改…"并重走轮询。

### 3.5 `/oral-calc/report/:reportId` 报告页

**报告头**:标题(服务端 title 原样)/正确率环形图(委托可视化引擎)/总题数/正确数/书写用时(duration_seconds 家长可选填写,缺省不渲染)。

**错因分布**:error_stats_json 原样渲染横向条形图(枚举→R11 话术),NONE 不渲染;PENDING_REVIEW 格子服务端已剔除,禁本地补算(G4)。

**薄弱运算维度**:weak_ops_json 渲染四运算卡(加/减/乘/除,accuracy<0.8 标"建议多练"),呈现"已为孩子推荐针对性口算训练"提示条(训练编排权威归口算速算引擎 R 边界,客户端只透传提示,禁渲染训练计划本体)。

**AI 点评(ai_comment)**:
- ai_comment_status=PENDING/GENERATING:骨架条"正在生成鼓励点评…";
- 轮询:进入报告页后轮询 GET /reports/{id} 每 3s 一次直至 READY/FAILED,上限 10 次(推送召回双通道);
- READY:原样渲染,禁二次加工;AIGC 徽标常驻不可关闭;
- FAILED(47420 语义):点评模块整体隐藏,禁错误占位(降级诚实);
- 点评禁含成绩对比/负向标签(服务端 C5),客户端禁追加对比文案。

```dart
class OcbCaptureController extends Notifier<OcbCaptureState> {
  static const maxPages = 4;
  String? _clientRequestId;            // UUID v7 任务级幂等键,全链路复用(G2)

  /// 开始批改:创建任务(幂等)→ 按 pageNo 对齐直传 → complete
  Future<void> startGrading({required int? childId, required String scene,
      required List<CapturedPage> pages}) async {
    if (state is OcbCapturingBusy) return;      // 双击门控
    _clientRequestId ??= const Uuid().v7();
    state = OcbCapturingBusy();

    try {
      final created = await _api.createTask(
        childId: childId,
        pageCount: pages.length,
        scene: scene,
        imageMeta: pages.map((p) => p.meta).toList(),
        clientRequestId: _clientRequestId!,
      );                                       // 47416 幂等命中:回放同任务直接续传

      final slots = Map.fromEntries(created.uploadUrls.map((s) => MapEntry(s.pageNo, s)));
      for (final page in pages) {
        final slot = slots[page.pageNo];       // 严格按 pageNo 对齐(G12),禁按下标
        if (slot == null) throw const OcbException('upload slot missing');
        await _uploader.putDirect(slot.url, File(page.path),
            contentType: page.meta.contentType, parallel: 2);  // R3 委托,重试内聚
        await _wipe(page.path);                // G1:上传成功即删本地临时文件
      }

      await _api.completeImages(created.taskId);   // 幂等回调
      state = OcbCaptureDone(created.taskId);
      router.push('/oral-calc/task/${created.taskId}');
    } on OcbApiException catch (e) {
      for (final p in pages) { await _wipe(p.path); } // 异常路同样清理
      state = OcbCaptureFailed(e.code);
    }
  }

  Future<void> _wipe(String path) async {
    final f = File(path);
    if (await f.exists()) await f.delete();    // CLEANUP:CI 断言零残留(G1)
  }
}
```

### 5.2 OcbProgressController(轮询退避 + 推送召回)

```dart
class OcbProgressController extends Notifier<OcbProgressState> {
  static const _maxInterval = Duration(seconds: 5);

  Timer? _timer;
  Duration _interval = const Duration(seconds: 1);

  void start(int taskId) {
    _poll(taskId);
    _timer = Timer.periodic(_interval, (_) => _poll(taskId));
  }

  Future<void> _poll(int taskId) async {
    final vo = await _api.getTaskStatus(taskId);
    switch (vo.status) {
      case 'COMPLETED':
      case 'PARTIAL_COMPLETED':
        _timer?.cancel();
        router.replace('/oral-calc/task/$taskId/result');  // 禁本地推断结果
      case 'FAILED':
      case 'EXPIRED':
      case 'CANCELED':
        _timer?.cancel();
        state = OcbTerminalView(vo);                        // 终态话术渲染
      default:
        _interval = Duration(milliseconds: (_interval.inMilliseconds * 1.5).round())
            .clamp(const Duration(seconds: 1), _maxInterval);
        _timer?.cancel();
        _timer = Timer.periodic(_interval, (_) => _poll(taskId));
        state = OcbPhaseView(vo);                           // 阶段条映射(§3.3)
    }
  }

  /// 推送召回:消息中心完成推送 → 立即拉取一次(R9 委托,禁自建通知)
  void onPushRecall(int taskId) => _poll(taskId);
}
```

## 6. 状态机与守卫

### 6.1 客户端镜像状态机

```text
CAPTURING --(开始批改)--> CREATING --(uploadUrls 就绪)--> UPLOADING
UPLOADING --(全部直传完成)--> SUBMITTING(complete,不可取消)
SUBMITTING --(进入轮询)--> POLLING --(终态帧)--> RESULT_READY | PARTIAL_VIEW
POLLING --(失败帧)--> FAILED_VIEW | EXPIRED_VIEW
任意非终态 --(退后台)--> PAUSED_LOCAL(轮询暂停,回前台立即补拉)
RESULT_READY --(47406/D3)--> MANUAL_FRAME_SELECT(框选重跑后回 POLLING)
RESULT_READY --(改判/上报成功)--> SYNC_REFRESH(resync 全量刷新)
POLLING/SUBMITTING 为不可取消态:网络失败重试复用同一请求语义,禁另起新任务
```
