## 1. 模块定位与职责

### 1.1 业务背景

阅读理解在中考英语中占比约 30%-40%，高考英语中占比约 35%-45%，是分值最高、区分度最大的题型。通用设计文档 `docs2/英语阅读理解专项训练系统-详细设计.md` 已定义了数据模型、API 接口和核心业务逻辑，但服务端内部的推荐算法实现、答题分析引擎、AI 精讲编排管线、缓存策略、事件驱动流程等尚未展开到可编码级别。本服务文档聚焦于服务端实现层的详细设计。

### 1.2 服务职责

| 职责 | 说明 |
| --- | --- |
| 分级阅读材料管理 | 材料入库、难度自动标定、标签维护、内容索引 |
| 个性化文章推荐 | 基于能力档案的多策略混合推荐 |
| 答题智能分析 | 逐题批改、错因归类、能力维度增量计算 |
| AI 精读讲解编排 | 多题型 Prompt 模板拼装与流式输出 |
| 阅读能力画像维护 | 六维能力分数更新、CEFR 等级估算、蓝思值追踪 |
| 训练计划生成 | 基于薄弱维度的周期训练编排 |
| 生词收集联动 | 阅读中生词自动提取，同步至单词本系统 |
| 事件广播 | 训练完成事件发布，驱动下游错题/学情/画像模块 |

### 1.3 服务边界

- **本服务负责**：阅读理解材料推荐、答题批改分析、AI 精讲编排、能力维度更新、训练计划生成
- **不负责**：题库 CRUD（题目服务）、知识图谱查询（知识点服务）、通用 AI 对话（AI 对话引擎）、口语评估（口语服务）、听力训练（听力服务）、完形填空（完形填空服务）
- **依赖服务**：

| 依赖服务 | 用途 | 调用方式 |
| --- | --- | --- |
| 题目服务 | 获取/存储阅读题目 | Feign 同步调用 |

| AI 对话引擎 | 大模型批改/出题/精讲 | SSE 流式调用 |

| 单词本服务 | 生词同步 | 事件驱动 |

### 4.1 个性化文章推荐引擎

#### 4.1.1 推荐策略体系

**策略一：薄弱维度强化推荐（WeaknessBoostStrategy）**

```java
@Service
public class WeaknessBoostStrategy implements ReadingRecommendStrategy {

    @Override
    public String getStrategyName() { return "weakness_boost"; }

    @Override
    public double score(ReadingMaterial candidate, RecommendContext context) {
        UserReadingProfile profile = context.getProfile();
        String weakestDim = profile.getWeakestDimension();
        
        // 获取材料包含的题型 → 能力维度映射
        List<String> materialQuestionTypes = candidate.getQuestionTypes();
        Map<String, Double> dimCoverage = computeDimensionCoverage(materialQuestionTypes);
        
        // 薄弱维度的覆盖度
        double weakDimCoverage = dimCoverage.getOrDefault(weakestDim, 0.0);
        
        // 薄弱程度越严重，推荐权重越高
        double weakSeverity = (50.0 - profile.getDimensionScore(weakestDim)) / 50.0;
        weakSeverity = Math.max(0, weakSeverity);
        
        return weakDimCoverage * weakSeverity;
    }

    @Override
    public double getWeight(RecommendContext context) {
        // 用户能力越不均衡，此策略权重越高
        double gap = context.getProfile().getMaxDimensionScore() 
                   - context.getProfile().getMinDimensionScore();
        return Math.min(1.5, 0.5 + gap / 40.0);
    }
    
    /**
     * 计算材料对各能力维度的覆盖度
     */
    private Map<String, Double> computeDimensionCoverage(List<String> questionTypes) {
        // 题型 → 能力维度影响权重（与通用设计文档 5.1 保持一致）
        Map<String, Map<String, Double>> typeDimensionMap = Map.of(
            "main_idea",    Map.of("main_idea_grasp", 0.8, "structure_analysis", 0.2),
            "detail",       Map.of("detail_retrieval", 0.9, "speed_efficiency", 0.1),
            "inference",    Map.of("inference_reasoning", 0.7, "vocabulary_in_context", 0.3),
            "word_guessing", Map.of("vocabulary_in_context", 0.8, "inference_reasoning", 0.2),
            "attitude",     Map.of("inference_reasoning", 0.5, "main_idea_grasp", 0.5),
            "purpose",      Map.of("main_idea_grasp", 0.6, "structure_analysis", 0.4),
            "title",        Map.of("main_idea_grasp", 0.7, "inference_reasoning", 0.3),
            "structure",    Map.of("structure_analysis", 0.9, "main_idea_grasp", 0.1),
            "seven_choose_five", Map.of("structure_analysis", 0.5, "inference_reasoning", 0.3, "detail_retrieval", 0.2)
        );
        
        Map<String, Double> coverage = new HashMap<>();
        for (String qt : questionTypes) {
            Map<String, Double> dims = typeDimensionMap.getOrDefault(qt, Map.of("detail_retrieval", 1.0));
            dims.forEach((dim, weight) -> coverage.merge(dim, weight, Double::sum));
        }
        
        // 归一化
        double maxVal = coverage.values().stream().mapToDouble(Double::doubleValue).max().orElse(1.0);
        coverage.replaceAll((k, v) -> v / maxVal);
        return coverage;
    }
}
```

**策略二：难度适宜度推荐（DifficultyFitStrategy）**

```java
@Service
public class DifficultyFitStrategy implements ReadingRecommendStrategy {

    @Override
    public String getStrategyName() { return "difficulty_fit"; }

    @Override
    public double score(ReadingMaterial candidate, RecommendContext context) {
        int userDifficulty = context.getProfile().getRecommendedDifficulty();
        int materialDifficulty = candidate.getDifficulty();
        
        // 正态分布拟合：难度差越小得分越高
        double diff = Math.abs(materialDifficulty - userDifficulty);
        double sigma = 1.5; // 容忍范围
        return Math.exp(-0.5 * Math.pow(diff / sigma, 2));
    }
}
```

**策略三：题材偏好推荐（GenrePreferenceStrategy）**

```java
@Service
public class GenrePreferenceStrategy implements ReadingRecommendStrategy {

    @Override
    public String getStrategyName() { return "genre_preference"; }

    @Override
    public double score(ReadingMaterial candidate, RecommendContext context) {
        UserReadingGenrePreference pref = context.getGenrePreference(
            candidate.getGenre(), candidate.getTopic());
        
        if (pref == null) return 0.5; // 新题材默认中等
        
        // 高正确率题材 → 拓展推荐（提高兴趣）
        // 低正确率题材 → 降低推荐频率（避免挫败感）
        double accuracyFactor = pref.getAvgAccuracy() > 0.6 ? 1.0 : 0.6;
        
        return pref.getPreferenceScore() * accuracyFactor;
    }
}
```

**策略四：协同过滤推荐（CollaborativeFilteringStrategy）**

```java
@Service
public class CollaborativeFilteringStrategy implements ReadingRecommendStrategy {

    @Override
    public String getStrategyName() { return "collaborative_filtering"; }

    @Override
    public double score(ReadingMaterial candidate, RecommendContext context) {
        // 基于相似用户群体的偏好
        // 使用 Redis 存储的用户-材料交互矩阵进行实时计算
        
        Long userId = context.getUserId();
        Long materialId = candidate.getId();
        
        // 获取相似用户对该材料的评价
        List<Double> similarUserScores = getSimilarUserScores(userId, materialId);
        if (similarUserScores.isEmpty()) return 0.5;
        
        return similarUserScores.stream()
            .mapToDouble(Double::doubleValue)
            .average()
            .orElse(0.5);
    }
    
    private List<Double> getSimilarUserScores(Long userId, Long materialId) {
        // 1. 从 Redis 获取用户能力向量
        // 2. 找出余弦相似度 Top-K 的相似用户
        // 3. 获取相似用户对该材料的训练正确率
        // 实现委托给 recommend-data-service 微服务
        
        String cacheKey = String.format("reading:cf:similar_users:%d", userId);
        List<Long> similarUserIds = redisTemplate.opsForList().range(cacheKey, 0, 49);
        if (similarUserIds == null || similarUserIds.isEmpty()) {
            return Collections.emptyList();
        }
        
        return practiceRecordRepository.findAccuracyByUsersAndMaterial(
            similarUserIds, materialId);
    }
}
```

**策略五：探索-利用平衡（ExplorationStrategy）**

```java
@Service
public class ExplorationStrategy implements ReadingRecommendStrategy {

    @Override
    public String getStrategyName() { return "exploration"; }

    @Override
    public double score(ReadingMaterial candidate, RecommendContext context) {
        // ε-greedy 思想：对从未推荐过的材料给予探索奖励
        Set<Long> exposedIds = context.getRecentlyExposedMaterialIds();
        
        if (!exposedIds.contains(candidate.getId())) {
            return 0.6 + Math.random() * 0.4; // 未曝光材料获得随机探索分
        }
        
        // 曝光次数越少，探索分越高
        long exposureCount = context.getExposureCount(candidate.getId());
        return Math.max(0.1, 0.5 - exposureCount * 0.05);
    }
    
    @Override
    public double getWeight(RecommendContext context) {
        // 新用户探索权重更高
        int practiceCount = context.getProfile().getTotalPractices();
        return practiceCount < 10 ? 0.8 : 0.3;
    }
}
```

#### 4.1.2 推荐编排器

```java
     * 执行多策略混合推荐
     */
    public RecommendResult recommend(Long userId, RecommendRequest request) {
        // 1. 构建推荐上下文
        RecommendContext context = buildContext(userId, request);
        
        // 2. 获取候选材料池
        List<ReadingMaterial> candidates = getCandidates(context);
        
        if (candidates.isEmpty()) {
            log.warn("No reading material candidates for user {}", userId);
            return RecommendResult.empty();
        }
        
        // 3. 多策略打分
        List<ScoredMaterial> scoredList = candidates.parallelStream()
            .map(material -> {
                Map<String, Double> strategyScores = new LinkedHashMap<>();
                double totalScore = 0;
                double totalWeight = 0;
                
                for (ReadingRecommendStrategy strategy : strategies) {
                    double score = strategy.score(material, context);
                    double weight = strategy.getWeight(context);
                    // 覆盖配置中心权重
                    weight = strategyWeights.getOrDefault(strategy.getStrategyName(), weight);
                    
                    strategyScores.put(strategy.getStrategyName(), score);
                    totalScore += score * weight;
                    totalWeight += weight;
                }
                
                return new ScoredMaterial(material, totalScore / totalWeight, strategyScores);
            })
            .sorted(Comparator.comparingDouble(ScoredMaterial::getFinalScore).reversed())
            .collect(Collectors.toList());
        
        // 4. 多样性重排（避免连续推荐相同题材）
        List<ScoredMaterial> reranked = diversityRerank(scoredList, context);
        
        // 5. 截取 Top-N
        int count = request.getCount() != null ? request.getCount() : 5;
        List<ScoredMaterial> topN = reranked.subList(0, Math.min(count, reranked.size()));
        
        // 6. 保存推荐快照
        saveSnapshot(userId, request, topN, context);
        
        return RecommendResult.of(topN);
    }
    
    /**
     * 多样性重排：MMR (Maximal Marginal Relevance) 算法
     */
    private List<ScoredMaterial> diversityRerank(
            List<ScoredMaterial> scoredList, RecommendContext context) {
        
        List<ScoredMaterial> result = new ArrayList<>();
        Set<String> usedGenres = new HashSet<>();
        Set<String> usedTopics = new HashSet<>();
        
        double lambda = 0.7; // 相关性与多样性的平衡系数
        
        while (!scoredList.isEmpty() && result.size() < 20) {
            ScoredMaterial best = null;
            double bestMmr = Double.NEGATIVE_INFINITY;
            
            for (ScoredMaterial sm : scoredList) {
                double relevance = sm.getFinalScore();
                
                // 计算与已选集的相似度惩罚
                double diversityPenalty = 0;
                if (usedGenres.contains(sm.getMaterial().getGenre())) {
                    diversityPenalty += 0.3;
                }
                if (usedTopics.contains(sm.getMaterial().getTopic())) {
                    diversityPenalty += 0.3;
                }
                
                double mmr = lambda * relevance - (1 - lambda) * diversityPenalty;
                if (mmr > bestMmr) {
                    bestMmr = mmr;
                    best = sm;
                }
            }
            
            if (best != null) {
                result.add(best);
                usedGenres.add(best.getMaterial().getGenre());
                usedTopics.add(best.getMaterial().getTopic());
                scoredList.remove(best);
            }
        }
        
        return result;
    }
    
    /**
     * 构建推荐上下文
     */
    private RecommendContext buildContext(Long userId, RecommendRequest request) {
        UserReadingProfile profile = profileRepository.findByUserId(userId);
        
        // 最近30天已练习材料
        Set<Long> practicedIds = practiceRecordRepository
            .findRecentMaterialIds(userId, LocalDate.now().minusDays(30));
        
        // 最近推荐过的材料
        Set<Long> recentlyExposed = snapshotRepo
            .findRecentlyExposedMaterialIds(userId, 7);
        recentlyExposed.addAll(practicedIds);
        
        // 题材偏好
        List<UserReadingGenrePreference> genrePrefs = genrePreferenceRepo
            .findByUserId(userId);
        
        return RecommendContext.builder()
            .userId(userId)
            .profile(profile)
            .recentlyExposedMaterialIds(recentlyExposed)
            .request(request)
            .genrePreferences(genrePrefs)
            .build();
    }
    
    /**
     * 获取候选材料池
     */
    private List<ReadingMaterial> getCandidates(RecommendContext context) {
        int targetDifficulty = context.getProfile().getRecommendedDifficulty();
        
        // 难度范围 ±2，排除已练习和已下线材料
        return materialRepository.findCandidates(
            Math.max(1, targetDifficulty - 2),
            Math.min(10, targetDifficulty + 2),
            context.getProfile().getGradeLevel(),
            context.getRecentlyExposedMaterialIds()
        );
    }
}
```

```java
@Service
@Slf4j
public class ReadingAnswerAnalyzer {

    private final ReadingAbilityScorer abilityScorer;
    private final ReadingErrorDiagnostician errorDiagnostician;
    private final ApplicationEventPublisher eventPublisher;
    
    /**
     * 批量分析答题结果
     * @param practiceRequest 提交的答题请求
     * @param material 阅读材料（含题目）
     * @param profile 用户阅读能力档案
     * @return 完整的分析结果
     */
    @Transactional
    public PracticeAnalysisResult analyze(
            PracticeSubmitRequest practiceRequest,
            ReadingMaterial material,
            UserReadingProfile profile) {
        
        List<ReadingQuestion> questions = material.getQuestions();
        List<AnswerDetail> answers = practiceRequest.getAnswers();
        
        // 预构建 题目ID → 题目 映射
        Map<Long, ReadingQuestion> questionMap = questions.stream()
            .collect(Collectors.toMap(ReadingQuestion::getId, Function.identity()));
        
        // 逐题分析
        List<QuestionAnalysisResult> questionResults = new ArrayList<>();
        Map<String, Double> dimensionDeltas = new HashMap<>();
        List<ReadingErrorAnalysis> errors = new ArrayList<>();
        
        for (AnswerDetail answer : answers) {
            ReadingQuestion question = questionMap.get(answer.getQuestionId());
            if (question == null) {
                log.warn("Question {} not found for material {}", 
                    answer.getQuestionId(), material.getId());
                continue;
            }
            
            // 1. 批改判定
            CorrectnessResult correctness = judgeAnswer(answer, question);
            
            // 2. 能力维度增量计算
            Map<String, Double> deltas = abilityScorer.calculateDimensionDeltas(
                question.getQuestionType(),
                question.getDifficulty(),
                correctness.isCorrect(),
                answer.getTimeMs(),
                answer.isHintUsed(),
                profile.getDimensionScores()
            );
            
            // 合并维度增量
            deltas.forEach((dim, delta) -> dimensionDeltas.merge(dim, delta, Double::sum));
            
            // 3. 错误时进行错因诊断
            if (!correctness.isCorrect()) {
                ReadingErrorAnalysis errorAnalysis = errorDiagnostician.diagnose(
                    answer, question, material, correctness, profile);
                errors.add(errorAnalysis);
            }
            
            // 4. 构建单题分析结果
            questionResults.add(QuestionAnalysisResult.builder()
                .questionId(question.getId())
                .questionType(question.getQuestionType())
                .userAnswer(answer.getUserAnswer())
                .correctAnswer(question.getCorrectAnswer())
                .isCorrect(correctness.isCorrect())
                .explanation(question.getExplanation())
                .evidenceParagraph(question.getEvidenceParagraph())
                .evidenceText(question.getEvidenceText())
                .dimensionDeltas(deltas)
                .timeMs(answer.getTimeMs())
                .hintUsed(answer.isHintUsed())
                .confidence(correctness.getConfidence())
                .build());
        }
        
        // 汇总统计
        int totalQuestions = questionResults.size();
        int correctCount = (int) questionResults.stream().filter(QuestionAnalysisResult::isCorrect).count();
        double accuracy = totalQuestions > 0 ? (double) correctCount / totalQuestions : 0;
        
        // 计算阅读速度
        int wpm = calculateWPM(material.getWordCount(), practiceRequest.getReadingTimeMs());
        
        // 构建最终结果
        PracticeAnalysisResult result = PracticeAnalysisResult.builder()
            .totalQuestions(totalQuestions)
            .correctCount(correctCount)
            .accuracyRate(accuracy)
            .wordsPerMinute(wpm)
            .totalTimeMs(practiceRequest.getTotalTimeMs())
            .readingTimeMs(practiceRequest.getReadingTimeMs())
            .questionResults(questionResults)
            .dimensionDeltas(dimensionDeltas)
            .errors(errors)
            .build();
        
        // 发布训练完成事件
        eventPublisher.publishEvent(new ReadingPracticeCompletedEvent(
            practiceRequest.getUserId(), material.getId(), result));
        
        return result;
    }
    
    /**
     * 判定答案正确性（支持多种题型）
     */
    private CorrectnessResult judgeAnswer(AnswerDetail answer, ReadingQuestion question) {
        String questionType = question.getQuestionType();
        String userAnswer = answer.getUserAnswer().trim();
        String correctAnswer = question.getCorrectAnswer().trim();
        
        return switch (questionType) {
            case "main_idea", "detail", "inference", "word_guessing", 
                 "attitude", "purpose", "title", "structure" -> 
                judgeChoiceQuestion(userAnswer, correctAnswer);
                
            case "seven_choose_five" -> 
                judgeSevenChooseFive(userAnswer, correctAnswer);
                
            case "fill_blank" -> 
                judgeFillBlank(userAnswer, correctAnswer);
                
            case "short_answer" -> 
                judgeShortAnswer(userAnswer, correctAnswer, question);
                
            default -> 
                judgeChoiceQuestion(userAnswer, correctAnswer);
        };
    }
    
    /**
     * 选择题判定（支持大小写不敏感、空格容错）
     */
    private CorrectnessResult judgeChoiceQuestion(String userAnswer, String correctAnswer) {
        String normalizedUser = userAnswer.toUpperCase().replaceAll("\\s+", "");
        String normalizedCorrect = correctAnswer.toUpperCase().replaceAll("\\s+", "");
        
        boolean correct = normalizedUser.equals(normalizedCorrect);
        return CorrectnessResult.builder()
            .correct(correct)
            .confidence(correct ? 1.0 : 0.95)
            .matchType(correct ? "exact" : "mismatch")
            .build();
    }
    
    /**
     * 七选五判定：逐位比对，返回部分正确信息
     */
    private CorrectnessResult judgeSevenChooseFive(String userAnswer, String correctAnswer) {
        // userAnswer 格式: "A,D,F,G,B" 或 "ADFG"
        String[] userParts = userAnswer.toUpperCase().replaceAll("\\s+", "").split(",");
        String[] correctParts = correctAnswer.toUpperCase().replaceAll("\\s+", "").split(",");
        
        int correctSlots = 0;
        int totalSlots = Math.max(userParts.length, correctParts.length);
        
        for (int i = 0; i < Math.min(userParts.length, correctParts.length); i++) {
            if (userParts[i].equals(correctParts[i])) {
                correctSlots++;
            }
        }
        
        boolean allCorrect = correctSlots == totalSlots && totalSlots == 5;
        double partialScore = totalSlots > 0 ? (double) correctSlots / totalSlots : 0;
        
        return CorrectnessResult.builder()
            .correct(allCorrect)
            .confidence(1.0)
            .matchType(allCorrect ? "exact" : "partial")
            .partialScore(partialScore)
            .correctSlots(correctSlots)
            .totalSlots(totalSlots)
            .build();
    }
    
    /**
     * 填空题判定（支持大小写不敏感、标点容错）
     */
    private CorrectnessResult judgeFillBlank(String userAnswer, String correctAnswer) {
        String normalizedUser = normalizeForFillBlank(userAnswer);
        String normalizedCorrect = normalizeForFillBlank(correctAnswer);
        
        if (normalizedUser.equals(normalizedCorrect)) {
            return CorrectnessResult.builder().correct(true).confidence(1.0).matchType("exact").build();
        }
        
        // 编辑距离容错（允许1个字符差异）
        int editDistance = levenshteinDistance(normalizedUser, normalizedCorrect);
        if (editDistance == 1) {
            return CorrectnessResult.builder()
                .correct(true).confidence(0.85).matchType("fuzzy").build();
        }
        
        return CorrectnessResult.builder().correct(false).confidence(0.9).matchType("mismatch").build();
    }
    
    /**
     * 简答题判定（调用 AI 进行语义匹配）
     */
    private CorrectnessResult judgeShortAnswer(String userAnswer, String correctAnswer, 
                                                ReadingQuestion question) {
        // 先尝试关键词匹配
        Set<String> keywords = extractKeywords(correctAnswer);
        Set<String> userKeywords = extractKeywords(userAnswer);
        
        long matchedKeywords = keywords.stream()
            .filter(userKeywords::contains)
            .count();
        
        double keywordMatchRate = keywords.isEmpty() ? 0 : (double) matchedKeywords / keywords.size();
        
        if (keywordMatchRate >= 0.8) {
            return CorrectnessResult.builder()
                .correct(true).confidence(keywordMatchRate).matchType("keyword").build();
        }
        
        if (keywordMatchRate >= 0.5) {
            // 关键词部分匹配，调用 AI 判定
            return aiJudgeShortAnswer(userAnswer, correctAnswer, question);
        }
        
        return CorrectnessResult.builder()
            .correct(false).confidence(0.7).matchType("keyword_mismatch").build();
    }
    
    private String normalizeForFillBlank(String text) {
        return text.toLowerCase()
            .replaceAll("[^a-z0-9\\s]", "")
            .replaceAll("\\s+", " ")
            .trim();
    }
    
    private int levenshteinDistance(String a, String b) {
        int m = a.length(), n = b.length();
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 0; i <= m; i++) dp[i][0] = i;
        for (int j = 0; j <= n; j++) dp[0][j] = j;
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                dp[i][j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? dp[i - 1][j - 1]
                    : 1 + Math.min(dp[i - 1][j - 1], Math.min(dp[i - 1][j], dp[i][j - 1]));
            }
        }
        return dp[m][n];
    }
}
```

```java
@Service

    /**
     * 对单题错误进行诊断

    public ReadingErrorAnalysis diagnose(
            AnswerDetail answer,
            ReadingQuestion question,
            ReadingMaterial material,
            CorrectnessResult correctness,
            UserReadingProfile profile) {
        
        // 1. 基于规则的初步分类
        ErrorCategoryRuleResult ruleResult = classifyByRules(answer, question, profile);
        
        // 2. 如果置信度不足，调用 AI 辅助诊断
        ErrorCategory finalCategory;
        String diagnosisText;
        double confidence;
        
        if (ruleResult.getConfidence() >= 0.8) {
            finalCategory = ruleResult.getCategory();
            diagnosisText = ruleResult.getReasoning();
            confidence = ruleResult.getConfidence();
        } else {
            // AI 辅助诊断
            AiDiagnosisResult aiResult = aiDiagnose(answer, question, material, profile);
            finalCategory = aiResult.getCategory();
            diagnosisText = aiResult.getDiagnosis();
            confidence = aiResult.getConfidence();
        }
        
        // 3. 知识点归因
        List<Long> relatedKpIds = findRelatedKnowledgePoints(question, finalCategory);
        List<Long> relatedVocabIds = findRelatedVocabulary(question, finalCategory);
        
        // 4. 生成改进建议
        String suggestedFix = generateFixSuggestion(finalCategory, question, profile);
        
        return ReadingErrorAnalysis.builder()
            .practiceId(answer.getPracticeId())
            .questionId(question.getId())
            .userId(profile.getUserId())
            .errorCategory(finalCategory.name())
            .errorSubcategory(ruleResult.getSubcategory())
            .confidence(confidence)
            .relatedKnowledgePointIds(relatedKpIds)
            .relatedVocabularyIds(relatedVocabIds)
            .diagnosisText(diagnosisText)
            .suggestedFix(suggestedFix)
            .build();
    }
    
    /**
     * 基于规则的初步分类
     */
    private ErrorCategoryRuleResult classifyByRules(
            AnswerDetail answer, ReadingQuestion question, UserReadingProfile profile) {
        
        String questionType = question.getQuestionType();
        long responseTimeMs = answer.getTimeMs();
        boolean hintUsed = answer.isHintUsed();
        
        // 规则1：时间极短 + 错误 → 粗心
        double expectedTimeSeconds = 15.0 + question.getDifficulty() * 3.0;
        if (responseTimeMs < expectedTimeSeconds * 500) { // 不到期望时间的一半
            return new ErrorCategoryRuleResult(
                ErrorCategory.CARELESSNESS, "careless_rush", 
                0.85, "答题时间过短，可能未认真审题");
        }
        
        // 规则2：推理判断题 + 推理维度低 → 逻辑推理错误
        if (("inference".equals(questionType) || "attitude".equals(questionType))
            && profile.getInferenceReasoning() < 50) {
            return new ErrorCategoryRuleResult(
                ErrorCategory.LOGIC_ERROR, "inference_weakness",
                0.75, "推理判断能力较弱，推理题易出错");
        }
        
        // 规则3：词义猜测题 + 词汇维度低 → 词汇缺失
        if ("word_guessing".equals(questionType) 
            && profile.getVocabularyInContext() < 50) {
            return new ErrorCategoryRuleResult(
                ErrorCategory.VOCABULARY_DEFICIT, "contextual_vocabulary_weak",
                0.75, "语境猜词能力不足，需加强词汇积累");
        }
        
        // 规则4：使用了提示但仍答错 → 知识盲区
        if (hintUsed) {
            return new ErrorCategoryRuleResult(
                ErrorCategory.KNOWLEDGE_GAP, "hint_failed",
                0.7, "使用了提示仍未能正确作答，可能存在知识盲区");
        }
        
        // 规则5：默认 → 文本误读
        return new ErrorCategoryRuleResult(
            ErrorCategory.TEXT_MISREADING, "general",
            0.5, "需进一步分析错误原因");
    }
    
    /**
     * AI 辅助诊断（低置信度时调用）
     */
    private AiDiagnosisResult aiDiagnose(

    /**
```

```java
@Service
public class ReadingExplanationPipeline {

    private final AiDialogueEngineClient aiClient;
    private final ReadingExplanationPromptBuilder promptBuilder;
    
    /**
     * 执行精读讲解（SSE 流式返回）
     */
    public Flux<SseEvent> executeExplanation(
            Long practiceId,
            ExplanationRequest request,
            UserStudentProfile studentProfile) {
        
        // 1. 加载训练数据
        PracticeLoadResult loadData = loadPracticeData(practiceId);
        
        // 2. 根据请求模式筛选要讲解的内容
        ExplanationScope scope = determineScope(request, loadData);
        
        // 3. 构建 Prompt
        String systemPrompt = promptBuilder.buildSystemPrompt(studentProfile);
        
        // 4. 分段流式输出
        return Flux.create(sink -> {
            try {
                // 阶段1：文章结构概览
                if (scope.includeOverview()) {
                    String overviewPrompt = promptBuilder.buildOverviewPrompt(loadData.getMaterial());
                    aiClient.streamChat(systemPrompt, overviewPrompt, chunk -> {
                        sink.next(SseEvent.of("article_overview", chunk));
                    });
                }
                
                // 阶段2：逐段分析
                if (scope.includeParagraphAnalysis()) {
                    for (ParagraphAnalysisTask task : scope.getParagraphTasks()) {
                        String paraPrompt = promptBuilder.buildParagraphPrompt(
                            loadData.getMaterial(), task.getParagraphIndex());
                        aiClient.streamChat(systemPrompt, paraPrompt, chunk -> {
                            sink.next(SseEvent.of("paragraph_analysis", Map.of(
                                "paragraph_index", task.getParagraphIndex(),
                                "content", chunk
                            )));
                        });
                    }
                }
                
                // 阶段3：题目精讲（按题型策略模板）
                if (scope.includeQuestionExplanation()) {
                    for (QuestionExplanationTask task : scope.getQuestionTasks()) {
                        String questionPrompt = promptBuilder.buildQuestionExplanationPrompt(
                            loadData.getMaterial(), 
                            task.getQuestion(), 
                            task.getAnswerResult(),
                            studentProfile);
                        
                        // 按步骤流式输出
                        aiClient.streamChat(systemPrompt, questionPrompt, chunk -> {
                            sink.next(SseEvent.of("question_explanation", Map.of(
                                "question_id", task.getQuestion().getId(),
                                "content", chunk
                            )));
                        });
                    }
                }
                
                // 阶段4：解题策略总结
                if (scope.includeStrategySummary()) {
                    String strategyPrompt = promptBuilder.buildStrategySummaryPrompt(
                        scope.getQuestionTasks());
                    aiClient.streamChat(systemPrompt, strategyPrompt, chunk -> {
                        sink.next(SseEvent.of("strategy_summary", chunk));
                    });
                }
                
                sink.next(SseEvent.of("done", Map.of()));
                sink.complete();
                
            } catch (Exception e) {
                sink.error(new ReadingExplanationException("精讲生成失败", e));
            }
        });
    }
    
    /**
     * 确定讲解范围
     */
    private ExplanationScope determineScope(ExplanationRequest request, PracticeLoadResult loadData) {
        ExplanationScope scope = new ExplanationScope();
        
        switch (request.getMode()) {
            case "full_article":
                scope.setIncludeOverview(true);
                scope.setIncludeParagraphAnalysis(true);
                scope.setIncludeQuestionExplanation(true);
                scope.setQuestionTasks(loadData.getQuestionResults().stream()
                    .map(qr -> new QuestionExplanationTask(qr.getQuestion(), qr.getResult()))
                    .collect(Collectors.toList()));
                scope.setIncludeStrategySummary(true);
                break;
                
            case "wrong_only":
                scope.setIncludeQuestionExplanation(true);
                scope.setQuestionTasks(loadData.getQuestionResults().stream()
                    .filter(qr -> !qr.getResult().isCorrect())
                    .map(qr -> new QuestionExplanationTask(qr.getQuestion(), qr.getResult()))
                    .collect(Collectors.toList()));
                scope.setIncludeStrategySummary(true);
                break;
                
            case "focus_questions":
                Set<Long> focusIds = request.getFocusQuestionIds();
                scope.setIncludeQuestionExplanation(true);
                scope.setQuestionTasks(loadData.getQuestionResults().stream()
                    .filter(qr -> focusIds.contains(qr.getQuestion().getId()))
                    .map(qr -> new QuestionExplanationTask(qr.getQuestion(), qr.getResult()))
                    .collect(Collectors.toList()));
                scope.setIncludeStrategySummary(false);
                break;
        }
        
        return scope;
    }
}
```

```java
@Service
public class ReadingProfileUpdater {

    private final UserReadingProfileRepository profileRepo;
    private final ApplicationEventPublisher eventPublisher;
    
    /**
     * 增量更新阅读能力维度
     * 
     * 算法核心思想：
     * - 基于 ELO 变体，但引入维度特异性和时间衰减
     * - 每个维度独立追踪，互不影响
     * - 引入均值回归机制防止分数极端化
     * - 近期数据权重更高（指数衰减窗口）
     */
    @Transactional
    public UserReadingProfile updateProfile(
            Long userId,
            Map<String, Double> dimensionDeltas,
            PracticeAnalysisResult practiceResult) {
        
        UserReadingProfile profile = profileRepo.findByUserId(userId);
        if (profile == null) {
            profile = createInitialProfile(userId);
        }
        
        // 1. 更新各维度分数
        Map<String, Double> currentScores = profile.getDimensionScores();
        Map<String, Double> newScores = new HashMap<>(currentScores);
        
        for (Map.Entry<String, Double> entry : dimensionDeltas.entrySet()) {
            String dimension = entry.getKey();
            double delta = entry.getValue();
            double current = currentScores.getOrDefault(dimension, 50.0);
            
            // 应用均值回归因子
            double regressionFactor = 1.0 - Math.pow(Math.abs(current - 50.0) / 50.0, 1.5);
            regressionFactor = Math.max(0.3, regressionFactor);
            
            double newScore = current + delta * regressionFactor;
            // 分数范围限制 [0, 100]
            newScore = Math.max(0, Math.min(100, newScore));
            // 保留两位小数
            newScore = Math.round(newScore * 100.0) / 100.0;
            
            newScores.put(dimension, newScore);
        }
        
        profile.updateDimensionScores(newScores);
        
        // 2. 重算综合分数（加权平均）
        double overallScore = calculateOverallScore(newScores);
        profile.setOverallScore(overallScore);
        
        // 3. 估算 CEFR 等级
        String cefrLevel = estimateCefrLevel(overallScore, profile.getGradeLevel());
        profile.setCurrentCefr(cefrLevel);
        
        // 4. 估算蓝思值
        int lexile = estimateLexile(overallScore, profile.getGradeLevel());
        profile.setCurrentLexile(lexile);
        
        // 5. 更新训练统计
        profile.setTotalPractices(profile.getTotalPractices() + 1);
        profile.setTotalArticlesRead(profile.getTotalArticlesRead() + 1);
        
        // 更新平均正确率（指数移动平均）
        double prevAvg = profile.getAvgAccuracy();
        double newAvg = prevAvg * 0.8 + practiceResult.getAccuracyRate() * 0.2;
        profile.setAvgAccuracy(Math.round(newAvg * 10000) / 10000.0);
        
        // 更新平均阅读速度
        if (practiceResult.getWordsPerMinute() > 0) {
            int prevWpm = profile.getAvgWpm() != null ? profile.getAvgWpm() : 0;
            int newWpm = (int)(prevWpm * 0.7 + practiceResult.getWordsPerMinute() * 0.3);
            profile.setAvgWpm(newWpm);
        }
        
        // 6. 更新最强/最弱维度
        updateStrongestAndWeakest(profile, newScores);
        
        // 7. 更新推荐难度
        profile.setRecommendedDifficulty(calculateRecommendedDifficulty(overallScore));
        
        profileRepo.save(profile);
        
        // 8. 发布能力变更事件
        eventPublisher.publishEvent(new ReadingAbilityChangedEvent(
            userId, profile, dimensionDeltas));
        
        return profile;
    }
    
    /**
     * 综合分数计算（加权）
     */
    private double calculateOverallScore(Map<String, Double> scores) {
        // 中考/高考中各能力维度的实际权重
        Map<String, Double> weights = Map.of(
            "main_idea_grasp", 0.20,
            "detail_retrieval", 0.15,
            "inference_reasoning", 0.25,   // 推理判断权重最高（区分度最大）
            "vocabulary_in_context", 0.15,
            "structure_analysis", 0.10,
            "speed_efficiency", 0.15
        );
        
        double totalWeight = 0;
        double weightedSum = 0;
        for (Map.Entry<String, Double> entry : weights.entrySet()) {
            double score = scores.getOrDefault(entry.getKey(), 50.0);
            weightedSum += score * entry.getValue();
            totalWeight += entry.getValue();
        }
        
        return Math.round((weightedSum / totalWeight) * 100.0) / 100.0;
    }
    
    /**
     * CEFR 等级估算
     */
    private String estimateCefrLevel(double overallScore, String gradeLevel) {
        // 基于综合分数学段组合估算
        if (overallScore >= 85) return "B2";
        if (overallScore >= 70) return "B1";
        if (overallScore >= 55) return "A2";
        if (overallScore >= 35) return "A1";
        return "A0";
    }
    
    /**
     * 蓝思值估算
     */
    private int estimateLexile(double overallScore, String gradeLevel) {
        // 蓝思值范围 200L - 1400L
        int baseLexile = (int)(200 + overallScore * 12);
        return Math.max(200, Math.min(1400, baseLexile));
    }
    
    /**
     * 计算推荐训练难度
     */
    private int calculateRecommendedDifficulty(double overallScore) {
        // 能力分数映射到难度等级（1-10）
        int difficulty = (int)(overallScore / 10);
        return Math.max(1, Math.min(10, difficulty));
    }
    
    private void updateStrongestAndWeakest(UserReadingProfile profile, 
                                            Map<String, Double> scores) {
        String weakest = scores.entrySet().stream()
            .min(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElse("detail_retrieval");
        
        String strongest = scores.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElse("detail_retrieval");
        
        profile.setWeakestDimension(weakest);
        profile.setStrongestDimension(strongest);
        profile.setRecommendedFocus(weakest);
    }
}
```

```java
@Service
public class ReadingTrainingPlanGenerator {

    private final UserReadingProfileRepository profileRepo;
    private final ReadingMaterialRepository materialRepo;
    
    /**
     * 生成周期训练计划
     */
    @Transactional
    public ReadingTrainingPlan generatePlan(Long userId, String planType) {
        UserReadingProfile profile = profileRepo.findByUserId(userId);
        if (profile == null) {
            throw new BusinessException(ErrorCode.PROFILE_NOT_FOUND);
        }

            case "weekly" -> 7;
            case "intensive" -> 14;
            default -> 7;
        };

        targetScore = Math.min(100, targetScore);
        
        // 按天生成任务
        List<DailyTask> tasks = new ArrayList<>();
        for (int day = 1; day <= totalDays; day++) {
            DailyTask task = generateDailyTask(profile, targetDimension, day, totalDays);
            tasks.add(task);
        }
        
        ReadingTrainingPlan plan = ReadingTrainingPlan.builder()
            .userId(userId)
            .planType(planType)
            .targetDimension(targetDimension)
            .targetScore(targetScore)
            .tasksJson(JsonUtils.toJson(tasks))
            .totalDays(totalDays)
            .completedDays(0)
            .status(0) // 进行中
            .startedAt(LocalDateTime.now())
            .expiresAt(LocalDateTime.now().plusDays(totalDays + 1))
            .startScore(profile.getOverallScore())
            .build();
        
        return plan;
    }
    
    /**
     * 生成单日任务
     */
    private DailyTask generateDailyTask(UserReadingProfile profile, 
                                         String targetDimension, int day, int totalDays) {
        // 前期侧重薄弱维度，后期加入综合训练
        double focusRatio = day <= totalDays * 0.6 ? 0.8 : 0.5;
        
        List<String> focusTypes = dimensionToQuestionTypes(targetDimension);
        
        // 动态难度：随天数逐步提升
        int baseDifficulty = profile.getRecommendedDifficulty();
        int dayDifficulty = Math.min(10, baseDifficulty + (day - 1) / 3);
        
        // 每日2-3篇文章
        int articlesPerDay = totalDays <= 1 ? 3 : (day % 2 == 0 ? 2 : 3);
        
        // 查找匹配材料
        List<Long> materialIds = materialRepo.findIdsForPlan(
            profile.getGradeLevel(),
            dayDifficulty,
            focusTypes,
            focusRatio,
            articlesPerDay
        );
        
        // 目标正确率：逐步提高
        double minAccuracy = 0.5 + day * 0.03;
        minAccuracy = Math.min(0.85, minAccuracy);
        
        return DailyTask.builder()
            .day(day)
            .materialIds(materialIds)
            .focusTypes(focusTypes)
            .minAccuracy(minAccuracy)
            .articlesCount(articlesPerDay)
            .difficulty(dayDifficulty)
            .build();
    }
    
    /**
     * 能力维度 → 题型映射
     */
    private List<String> dimensionToQuestionTypes(String dimension) {
        return switch (dimension) {
            case "main_idea_grasp" -> List.of("main_idea", "title", "purpose");
            case "detail_retrieval" -> List.of("detail", "fill_blank");
            case "inference_reasoning" -> List.of("inference", "attitude");
            case "vocabulary_in_context" -> List.of("word_guessing", "detail");
            case "structure_analysis" -> List.of("structure", "seven_choose_five");
            case "speed_efficiency" -> List.of("detail", "main_idea");
            default -> List.of("detail");
        };
    }

        }
```

| 热门材料列表 | Redis | `reading:hot_materials:{grade}` | 15min | 定时刷新 |

### 6.2 缓存实现

```java
@Service
@Slf4j
public class ReadingCacheManager {

    private final RedisTemplate<String, Object> redisTemplate;
    private final Cache<String, Object> localCache; // Caffeine
    
    private static final String PROFILE_KEY_PREFIX = "reading:profile:";
    private static final String MATERIAL_KEY_PREFIX = "reading:material:";
    private static final long PROFILE_TTL_HOURS = 1;
    private static final long MATERIAL_TTL_HOURS = 24;
    
    /**
     * 获取用户阅读档案（先查缓存，miss 时查 DB 并回填）
     */
    public UserReadingProfile getProfile(Long userId) {
        String key = PROFILE_KEY_PREFIX + userId;
        
        // L1: 本地缓存
        UserReadingProfile cached = (UserReadingProfile) localCache.getIfPresent(key);
        if (cached != null) return cached;
        
        // L2: Redis
        cached = (UserReadingProfile) redisTemplate.opsForValue().get(key);
        if (cached != null) {
            localCache.put(key, cached);
            return cached;
        }
        
        // L3: DB
        cached = profileRepository.findByUserId(userId);
        if (cached != null) {
            putProfile(cached);
        }
        return cached;
    }
    
    public void putProfile(UserReadingProfile profile) {
        String key = PROFILE_KEY_PREFIX + profile.getUserId();
        localCache.put(key, profile);
        redisTemplate.opsForValue().set(key, profile, PROFILE_TTL_HOURS, TimeUnit.HOURS);
    }
    
    /**
     * 失效用户档案缓存（数据更新后调用）
     */
    public void evictProfile(Long userId) {
        String key = PROFILE_KEY_PREFIX + userId;
        localCache.invalidate(key);
        redisTemplate.delete(key);
    }
    
    /**
     * 获取材料详情（带缓存）
     */
    public ReadingMaterial getMaterial(Long materialId) {
        String key = MATERIAL_KEY_PREFIX + materialId;
        
        ReadingMaterial cached = (ReadingMaterial) localCache.getIfPresent(key);
        if (cached != null) return cached;
        
        cached = (ReadingMaterial) redisTemplate.opsForValue().get(key);
        if (cached != null) {
            localCache.put(key, cached);
            return cached;
        }
        
        cached = materialRepository.findById(materialId).orElse(null);
        if (cached != null) {
            localCache.put(key, cached);
            redisTemplate.opsForValue().set(key, cached, MATERIAL_TTL_HOURS, TimeUnit.HOURS);
        }
        return cached;
    }
    
    /**
     * 批量预热热门材料缓存
     */
    @Scheduled(fixedRate = 900000) // 每15分钟
    public void warmUpHotMaterials() {
        List<String> gradeLevels = List.of("5", "6", "7", "8", "9", "10", "11", "12");
        
        for (String grade : gradeLevels) {
            String key = "reading:hot_materials:" + grade;
            List<ReadingMaterial> hotMaterials = materialRepository
                .findTop20ByGradeLevelAndStatusOrderByPracticeCountDesc(
                    Integer.parseInt(grade), 1);
            
            if (!hotMaterials.isEmpty()) {
                redisTemplate.opsForValue().set(key, hotMaterials, 15, TimeUnit.MINUTES);
            }
        }
        
        log.debug("Warmed up hot reading materials cache for all grades");
    }
}
```

```java
@Service
public class BatchReadingService {

    /**
     * 批量预加载材料详情
     */
    public Map<Long, ReadingMaterial> batchGetMaterials(List<Long> materialIds) {
        // 先查缓存
        Map<Long, ReadingMaterial> result = new HashMap<>();
        List<Long> missedIds = new ArrayList<>();
        
        for (Long id : materialIds) {
            ReadingMaterial cached = cacheManager.getMaterial(id);
            if (cached != null) {
                result.put(id, cached);
            } else {
                missedIds.add(id);
            }
        }
        
        // 批量查 DB
        if (!missedIds.isEmpty()) {
            List<ReadingMaterial> fromDb = materialRepository.findAllById(missedIds);
            for (ReadingMaterial m : fromDb) {
                result.put(m.getId(), m);
                cacheManager.putMaterial(m);
            }
        }
        
        return result;
    }
}
```
