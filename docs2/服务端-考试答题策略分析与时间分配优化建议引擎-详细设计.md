# 服务端-考试答题策略分析与时间分配优化建议引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

本引擎专为学生**考试场景下的答题时间分配**与**答题节奏策略**提供数据驱动的分析、诊断与优化建议。通过对学生在模拟考试、限时练习中的逐题作答时间序列进行建模分析，识别时间管理问题（如难题耗时过长、简单题草率失分、时间不够导致空白等），输出个性化答题策略优化方案。

### 1.2 核心价值

- 帮助学生发现"不是不会，而是时间没分配好"这一隐形失分因素
- 为中考/高考等高风险考试提供考前策略建议
- 追踪学生历次模拟考的时间管理改善趋势
- 为教师提供班级层面的共性时间管理问题诊断

### 1.3 与已有模块的边界

| 已有模块 | 关系 |
|---------|------|
| 练习答题行为数据采集与学习过程分析引擎 | **数据来源**：提供原始逐题时间戳和行为日志 |
| 练习测评会话服务与答题流程状态机 | **上游**：提供答题会话状态流转 |
| 考试模拟与真题练习系统 | **场景**：提供限时考试场景上下文 |
| 学习成绩预测与考试分数预估引擎 | **互补**：成绩预测关注"能考多少分"，本引擎关注"如何在考场上最大化发挥" |
| 学生认知负荷监测与学习内容难度动态调节引擎 | **互补**：认知负荷关注实时调节，本引擎关注复盘分析与策略建议 |

### 1.4 目标用户

- **直接受益**：初中/高中学生（考试压力大的阶段）
- **间接受益**：家长（了解孩子考试策略问题）、教师（班级共性时间管理诊断）

## 2. 数据模型设计

### 2.1 核心数据表

#### 2.1.1 `exam_answer_timeline` - 考试答题时间线

记录学生在一次考试中每道题的详细时间节点。

```sql
CREATE TABLE exam_answer_timeline (
    id              BIGSERIAL PRIMARY KEY,
    timeline_id     VARCHAR(36) NOT NULL DEFAULT gen_random_uuid()::text,
    exam_session_id VARCHAR(36) NOT NULL,     -- 关联考试会话ID
    user_id         BIGINT NOT NULL,
    exam_id         BIGINT NOT NULL,           -- 关联试卷ID
    question_id     BIGINT NOT NULL,
    question_order  INT NOT NULL,              -- 题目在试卷中的序号(从1开始)
    section         VARCHAR(32),               -- 试卷板块(选择题/填空题/解答题等)

    -- 时间数据
    first_view_ts   TIMESTAMPTZ,               -- 首次查看题目时间
    first_input_ts  TIMESTAMPTZ,               -- 首次输入/作答时间
    submit_ts       TIMESTAMPTZ,               -- 提交答案时间
    time_spent_ms   INT,                       -- 实际作答耗时(毫秒)
    revisit_count   INT DEFAULT 0,             -- 回看/修改次数
    revisit_total_ms INT DEFAULT 0,            -- 回看累计耗时(毫秒)

    -- 行为标记
    is_skipped      BOOLEAN DEFAULT FALSE,     -- 是否跳过
    is_revision     BOOLEAN DEFAULT FALSE,     -- 是否为后续修改后提交
    hint_used       BOOLEAN DEFAULT FALSE,     -- 是否使用了提示
    flag_marked     BOOLEAN DEFAULT FALSE,     -- 是否标记了"待复查"

    -- 结果
    is_correct      BOOLEAN,                   -- 是否正确(考试批改后回填)
    score_earned    DECIMAL(6,2),              -- 实际得分
    score_max       DECIMAL(6,2),              -- 满分

    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    UNIQUE(exam_session_id, question_id),
    INDEX idx_user_exam (user_id, exam_id),
    INDEX idx_exam_session (exam_session_id)
);

COMMENT ON TABLE exam_answer_timeline IS '考试答题逐题时间线记录';
```

#### 2.1.2 `exam_time_strategy_profile` - 学生考试时间策略画像

```sql
CREATE TABLE exam_time_strategy_profile (
    id                  BIGSERIAL PRIMARY KEY,
    profile_id          VARCHAR(36) NOT NULL DEFAULT gen_random_uuid()::text,
    user_id             BIGINT NOT NULL,
    subject             VARCHAR(16) NOT NULL,         -- 学科
    grade_level         INT NOT NULL,                  -- 年级

    -- 整体节奏特征
    avg_pace_score      DECIMAL(4,2),                 -- 平均节奏评分(0-100, 越高越合理)
    pace_consistency    DECIMAL(4,2),                 -- 节奏稳定性(标准差的归一化)
    typical_time_dist   JSONB,                        -- 典型时间分配分布(JSON)

    -- 问题标签(布尔数组)
    problem_tags        JSONB DEFAULT '[]',           -- 如["slow_on_hard","rush_easy","poor_sequencing"]

    -- 分板块时间分配
    section_allocation  JSONB,                        -- 各板块时间占比

    -- 策略模式分类
    strategy_type       VARCHAR(32),                  -- 策略类型见枚举
    strategy_score      DECIMAL(4,2),                 -- 策略综合评分

    -- 趋势
    improvement_trend   VARCHAR(16),                  -- improving/declining/stable
    last_5_avg_score   DECIMAL(6,2),                  -- 最近5次模拟考平均得分率
    prev_5_avg_score   DECIMAL(6,2),                  -- 前5次平均得分率

    sample_exam_count   INT DEFAULT 0,                -- 样本考试数
    last_analyzed_at    TIMESTAMPTZ,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    UNIQUE(user_id, subject, grade_level),
    INDEX idx_user_subject (user_id, subject)
);

COMMENT ON TABLE exam_time_strategy_profile IS '学生考试时间策略画像';
```

#### 2.1.3 `exam_strategy_report` - 策略分析报告

```sql
CREATE TABLE exam_strategy_report (
    id              BIGSERIAL PRIMARY KEY,
    report_id       VARCHAR(36) NOT NULL DEFAULT gen_random_uuid()::text,
    user_id         BIGINT NOT NULL,
    exam_session_id VARCHAR(36) NOT NULL,
    subject         VARCHAR(16) NOT NULL,
    exam_type       VARCHAR(32),                -- mock/real_practice/predicted

    -- 核心分析结果
    total_duration_sec     INT,                 -- 考试总时长(秒)
    actual_used_sec        INT,                 -- 实际使用时长(秒)
    time_utilization       DECIMAL(4,2),        -- 时间利用率%

    -- 逐板块分析
    section_analysis       JSONB,               -- 各板块时间分配 vs 推荐分配
    -- 逐题分析
    per_question_analysis  JSONB,               -- 每题时间 vs 预期时间偏差

    -- 问题诊断
    diagnosed_issues       JSONB,               -- 诊断出的问题列表
    estimated_lost_score   DECIMAL(6,2),        -- 因时间管理问题预估失分
    lost_score_breakdown   JSONB,               -- 失分归因拆解

    -- 优化建议
    recommendations        JSONB,               -- 个性化策略建议
    recommended_time_plan  JSONB,               -- 推荐时间分配方案

    -- 预测
    predicted_gain         DECIMAL(6,2),        -- 优化后预估提分

    created_at     TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    INDEX idx_user_exam (user_id, exam_session_id),
    INDEX idx_user_subject_time (user_id, subject, created_at)
);

COMMENT ON TABLE exam_strategy_report IS '考试策略分析报告';
```

#### 2.1.4 `exam_time_benchmark` - 标准时间基准库

```sql
CREATE TABLE exam_time_benchmark (
    id                  BIGSERIAL PRIMARY KEY,
    benchmark_id        VARCHAR(36) NOT NULL DEFAULT gen_random_uuid()::text,
    exam_type           VARCHAR(32) NOT NULL,       -- 中考/高考/期中/期末/单元测
    subject             VARCHAR(16) NOT NULL,
    grade_level         INT NOT NULL,
    region              VARCHAR(32) DEFAULT 'national', -- 地区(各省考试时间不同)

    total_duration_sec  INT NOT NULL,                -- 考试总时长
    total_score         DECIMAL(6,2) NOT NULL,        -- 总分
    question_count      INT NOT NULL,                 -- 题目总数

    -- 分板块推荐
    section_plans       JSONB NOT NULL,               -- 各板块推荐时间和分值
    -- 格式: [{"section":"选择题","question_count":12,"recommended_sec":900,"score":24,"tactic":"快速准确,控制每题75秒以内"},
    --         {"section":"填空题","question_count":6,"recommended_sec":720,"score":18,...}]

    -- 难度梯度推荐
    difficulty_plans    JSONB,                        -- 不同难度题目的推荐用时
    -- 格式: {"easy":{"per_question_sec":60,"max_sec":90},"medium":{"per_question_sec":120,"max_sec":180},"hard":{"per_question_sec":240,"max_sec":300}}

    -- 策略建议
    general_tactics     JSONB NOT NULL,               -- 通用策略建议列表

    is_active           BOOLEAN DEFAULT TRUE,
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    UNIQUE(exam_type, subject, grade_level, region)
);

COMMENT ON TABLE exam_time_benchmark IS '考试时间基准库';
```

```java
public enum ExamStrategyType {
    BALANCED("均衡型", "各板块时间分配合理，节奏稳定"),
    FRONT_HEAVY("前重后轻型", "前面花时间过多，后面匆忙"),

    SEQUENTIAL_STRICT("严格顺序型", "完全按顺序做，不会灵活跳题"),
    STRATEGIC_SKIP("策略跳题型", "能主动跳过难题先做后面的"),
    TIME_ANXIOUS("时间焦虑型", "整体节奏过快，担心做不完"),
    IMPROVING("改善中", "策略正在向好的方向变化");
}
```

```java
public enum TimeManagementProblem {
    // 节奏问题
    SLOW_START("起步过慢", "考试前期花费过多时间热身进入状态"),

    INCONSISTENT_PACE("节奏不稳", "各题用时波动极大，没有稳定节奏"),

    // 分配问题
    OVERSPEND_HARD("难题超时", "在单道难题上花费超过推荐时间2倍以上"),
    UNDERSPEND_EASY("简单题草率", "简单题用时低于推荐时间50%，错误率偏高"),
```

### 4.2 时间偏差计算算法

核心算法：计算每道题的实际用时与推荐用时的偏差，并量化为分数影响。

```java
/**
 * 逐题时间偏差分析
 */
public QuestionTimeAnalysis analyzeQuestionTime(
        ExamAnswerTimeline answer,
        ExamTimeBenchmark benchmark,
        DifficultyLevel difficulty) {

    int recommendedSec = getRecommendedTime(benchmark, answer.getSection(), difficulty);
    int actualSec = answer.getTimeSpentMs() / 1000;
    double deviationRatio = (double) (actualSec - recommendedSec) / recommendedSec;

    QuestionTimeAnalysis analysis = new QuestionTimeAnalysis();
    analysis.setQuestionId(answer.getQuestionId());
    analysis.setRecommendedSec(recommendedSec);
    analysis.setActualSec(actualSec);
    analysis.setDeviationRatio(deviationRatio);

    // 时间评级
    if (deviationRatio > 1.0) {
        // 超时超过推荐2倍
        analysis.setRating("severely_over");
        analysis.setImpactScore(calculateOverTimeImpact(actualSec, recommendedSec, answer.getIsCorrect()));
    } else if (deviationRatio > 0.3) {
        analysis.setRating("slightly_over");
        analysis.setImpactScore(calculateOverTimeImpact(actualSec, recommendedSec, answer.getIsCorrect()));
    } else if (deviationRatio < -0.5) {
        // 用时不到推荐一半
        analysis.setRating("under_time");
        analysis.setImpactScore(calculateUnderTimeImpact(actualSec, recommendedSec, answer.getIsCorrect()));
    } else {
        analysis.setRating("good");
        analysis.setImpactScore(0);
    }

    // 策略性失分判定：用时异常 + 答错 = 可能是时间管理问题
    if (!answer.getIsCorrect() &&
        ("severely_over".equals(analysis.getRating()) ||
         "under_time".equals(analysis.getRating()))) {
        analysis.setStrategicLoss(true);
        analysis.setEstimatedLostScore(answer.getScoreMax());
    }

    return analysis;
}

/**
 * 计算超时影响分：超出的时间本可用于其他题目
 */
private double calculateOverTimeImpact(int actualSec, int recommendedSec, boolean isCorrect) {
    int wastedSec = actualSec - recommendedSec;
    // 每超时60秒，假设影响0.5分(可通过历史数据校准)
    double impact = wastedSec / 60.0 * 0.5;
    // 如果这道题最终也没做对，影响更大
    if (!isCorrect) {
        impact *= 1.5;
    }
    return Math.round(impact * 100) / 100.0;
}

/**
 * 计算欠时影响分：草率作答导致出错
 */
private double calculateUnderTimeImpact(int actualSec, int recommendedSec, boolean isCorrect) {
    if (isCorrect) {
        return 0; // 虽然做得快但做对了
    }
    // 草率做错：每少用30秒，0.3分影响
    int savedSec = recommendedSec - actualSec;
    double impact = savedSec / 30.0 * 0.3;
    return Math.round(impact * 100) / 100.0;
}
```

### 4.3 策略类型分类模型

基于学生在一次考试中的多维特征，使用规则+加权评分进行策略类型分类。

```java
/**
 * 策略类型分类器
 */
public class StrategyClassifier {

    public StrategyClassification classify(ExamMetrics metrics) {
        Map<ExamStrategyType, Double> scores = new EnumMap<>(ExamStrategyType.class);

        // 计算各策略类型的匹配分数
        scores.put(ExamStrategyType.STUCK_ON_HARD, calcStuckOnHardScore(metrics));
        scores.put(ExamStrategyType.RUSH_EASY, calcRushEasyScore(metrics));
        scores.put(ExamStrategyType.FRONT_HEAVY, calcFrontHeavyScore(metrics));
        scores.put(ExamStrategyType.SEQUENTIAL_STRICT, calcSequentialScore(metrics));
        scores.put(ExamStrategyType.STRATEGIC_SKIP, calcStrategicSkipScore(metrics));
        scores.put(ExamStrategyType.TIME_ANXIOUS, calcTimeAnxiousScore(metrics));
        scores.put(ExamStrategyType.BALANCED, calcBalancedScore(metrics));

        // 取最高分类型
        Map.Entry<ExamStrategyType, Double> best = scores.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .orElse(Map.entry(ExamStrategyType.BALANCED, 50.0));

        // 如果最高分不够显著(<40)，标记为 IMPROVING
        StrategyClassification result = new StrategyClassification();
        result.setType(best.getValue() >= 40 ? best.getKey() : ExamStrategyType.IMPROVING);
        result.setConfidence(best.getValue() / 100.0);
        result.setAllScores(scores);
        return result;
    }

    /**
     * 死磕难题型评分
     * 特征：难题用时 >> 推荐时间，且后续题目受影响
     */
    private double calcStuckOnHardScore(ExamMetrics m) {
        double score = 0;
        // 难题平均超时比例
        if (m.getHardOvertimeRatio() > 1.5) score += 30;
        if (m.getHardOvertimeRatio() > 2.0) score += 20;
        // 存在单题超时>3x推荐
        if (m.getMaxSingleOvertimeRatio() > 3.0) score += 20;
        // 难题后简单题正确率下降
        if (m.getPostHardAccuracyDrop() > 0.15) score += 15;
        // 未做标记跳过
        if (m.getSkipCount() == 0 && m.getHardQuestionCount() > 0) score += 15;
        return Math.min(score, 100);
    }

    /**
     * 草率简单题型评分
     * 特征：简单题用时过少且错误率偏高
     */
    private double calcRushEasyScore(ExamMetrics m) {
        double score = 0;
        // 简单题平均用时 < 推荐的50%
        if (m.getEasyUndertimeRatio() > 0.5) score += 30;
        // 简单题错误率 > 20%
        if (m.getEasyErrorRate() > 0.20) score += 30;
        // 简单题错误率 > 35%
        if (m.getEasyErrorRate() > 0.35) score += 20;
        // 整体完成时间远小于考试时间
        if (m.getTimeUtilization() < 0.80) score += 20;
        return Math.min(score, 100);
    }

    /**
     * 均衡型评分
     * 特征：各板块时间接近推荐，正确率合理
     */
    private double calcBalancedScore(ExamMetrics m) {
        double score = 50; // 基础分
        // 板块偏差小于15%
        if (m.getMaxSectionDeviation() < 0.15) score += 25;
        else if (m.getMaxSectionDeviation() < 0.30) score += 10;
        // 节奏稳定性好
        if (m.getPaceConsistency() > 70) score += 15;
        // 有复查行为
        if (m.getReviewTimeSec() > 120) score += 10;
        return Math.min(score, 100);
    }
}
```

### 4.4 预估失分归因模型

将总失分拆解为「知识性失分」和「策略性失分」。

```java
/**
 * 失分归因分析
 */
public class ScoreAttributionAnalyzer {

    /**
     * @param timeline 答题时间线
     * @param benchmark 时间基准
     * @param knowledgeMastery 知识点掌握度(来自知识追踪引擎)
     * @return 归因结果
     */
    public ScoreAttribution analyze(
            List<ExamAnswerTimeline> timeline,
            ExamTimeBenchmark benchmark,
            Map<Long, Double> knowledgeMastery) {

        double knowledgeLoss = 0;    // 知识性失分（确实不会）
        double strategyLoss = 0;     // 策略性失分（时间管理问题）
        double carelessLoss = 0;     // 粗心失分（会但做错了）

        for (ExamAnswerTimeline ans : timeline) {
            if (Boolean.TRUE.equals(ans.getIsCorrect())) continue;

            double maxScore = ans.getScoreMax() != null ? ans.getScoreMax().doubleValue() : 0;
            double mastery = knowledgeMastery.getOrDefault(ans.getQuestionId(), 0.5);
            int actualSec = ans.getTimeSpentMs() / 1000;
            int recommendedSec = getTimeRecommendation(benchmark, ans.getSection());
            double timeRatio = (double) actualSec / recommendedSec;

            if (mastery < 0.3) {
                // 知识掌握度很低 → 知识性失分
                knowledgeLoss += maxScore;
            } else if (timeRatio < 0.4 && mastery > 0.6) {
                // 知识掌握度还行但用时极少 → 粗心失分
                carelessLoss += maxScore;
            } else if (timeRatio > 2.0 && mastery > 0.4) {
                // 有一定掌握度但超时严重 → 可能是策略问题导致没做完
                strategyLoss += maxScore * 0.6;
                knowledgeLoss += maxScore * 0.4;
            } else if (mastery >= 0.3 && mastery <= 0.6) {
                // 掌握度中等：介于知识和策略之间
                knowledgeLoss += maxScore * 0.6;
                strategyLoss += maxScore * 0.4;
            } else {
                knowledgeLoss += maxScore;
            }
        }

        return new ScoreAttribution(knowledgeLoss, strategyLoss, carelessLoss);
    }
}
```

```java
            "review_habit",
            3
        )
    );

    public List<Recommendation> generate(
            List<DiagnosedIssue> issues,
            ExamTimeBenchmark benchmark,
            ExamMetrics metrics) {

        List<Recommendation> recommendations = new ArrayList<>();

        for (DiagnosedIssue issue : issues) {
            RecommendationTemplate tpl = TEMPLATES.get(issue.getProblem());
            if (tpl == null) continue;

            Recommendation rec = new Recommendation();

            rec.setPriority(tpl.getPriority());

        int perQuestionBudget = remainingSec / remainingQuestions;
        // 止损线设为单题预算的1.5倍
        return Math.max(3, Math.min(15, perQuestionBudget * 3 / 2 / 60));
    }
```

## 8. 关键业务规则

### 8.1 数据采集规则

1. **有效答题时间计算**：系统排除以下时间段，只计入实际答题时间：
   - APP切后台时间超过10秒
     - 屏幕熄屏时间
   - 系统弹窗/电话中断时间
   - 用户主动暂停考试的时间

2. **最小样本要求**：单次考试至少需要5道有效答题记录才执行策略分析

3. **时间戳精度**：客户端以秒级精度采集，网络传输使用ISO 8601格式

### 8.2 策略评分规则

策略综合评分(paceScore)计算公式：

```
paceScore = w1 × sectionAllocationScore      // 板块时间分配得分(0-100)
          + w2 × perQuestionConsistencyScore  // 逐题用时稳定性(0-100)
          + w3 × reviewBehaviorScore          // 复查行为得分(0-100)
          + w4 × skipStrategyScore            // 跳题策略得分(0-100)
          + w5 × accuracyAlignmentScore       // 时间投入与正确率对齐度(0-100)
```

权重默认值: w1=0.30, w2=0.20, w3=0.15, w4=0.15, w5=0.20，可通过运营后台调整。

### 8.3 触发预警规则

当满足以下条件之一时，向家长/教师推送策略预警：

- 连续3次考试 `paceScore < 40`
- 单次考试 `estimatedLostScore > 15`
- 策略类型连续3次为 `STUCK_ON_HARD` 且趋势为 `declining`
- 考试完成率 < 80%（时间不够导致大量空白）

## 11. 后续演进方向

1. **AI驱动的策略优化建议**：使用大模型结合策略画像和历史数据，生成更自然、更具针对性的策略建议文本
2. **同校/同班策略对比**：引入同伴基准参照，让学生了解自己在同群体中的时间管理水平
3. **策略A/B测试**：对不同策略类型的学生推送不同的策略改进方案，验证哪种建议最有效
4. **考试当天智能提醒**：考试前1天/1小时通过推送提醒关键策略要点
5. **与学习计划联动**：将时间管理训练计划自动插入学习规划模块（如每周1次限时训练）
