# 管理后台 - 客户服务与工单管理工作台 详细设计

## 1. 概述

### 1.1 模块定位

客户服务与工单管理工作台是 PrimeTop 管理后台的核心运营支撑模块，为客服团队、运营主管和技术支持团队提供统一的工单处理、用户服务、FAQ管理和质量监控界面。

本工作台是对后端客服工单系统（`support-ticket-service`）、AI智能客服引擎、用户反馈系统和意见反馈与客服工单处理链路的前端编排层，将分散的服务端能力聚合为客服人员可直接操作的「服务生产线」。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 统一工作台 | 工单处理、用户查询、FAQ管理、SLA监控归入一个界面 |
| 高效处理 | 快捷回复模板、一键查询用户信息、智能推荐解决方案 |
| 全流程可控 | 工单从接入→分配→处理→回复→关闭全链路可视可控 |
| 质量可量化 | SLA达标率、满意度、处理效率实时统计 |
| 权限分离 | 客服专员→客服主管→运营经理 分级权限管控 |

### 1.3 适用范围

| 角色 | 使用场景 |
| --- | --- |
| 客服专员 | 接单、回复用户、查看用户信息、使用FAQ回复 |
| 客服主管 | 工单分配、SLA监控、质量抽检、团队管理 |
| 运营人员 | FAQ维护、分类管理、常见问题分析 |
| 技术支持 | 处理技术类工单、查看错误日志、排查问题 |
| 运营经理 | 整体服务数据分析、服务质量评估、人员绩效考核 |

### 1.4 依赖关系

```
本工作台（Web 前端）
    │
    ├── 客服与工单系统（工单 CRUD + 状态流转 + 分配）
    ├── AI智能客服对话与工单自动分流解决引擎（智能分发 + 自动回复）
    ├── 用户基础服务与身份认证系统（用户信息查询）
    ├── 意见反馈与客服工单处理链路（反馈升级为工单）
    ├── 支付服务与订单管理（关联订单查询）
    ├── 学习服务（学习数据查询）
    ├── 消息与推送服务（通知用户工单进度）
    ├── 统一通知消息模板引擎（通知模板配置）
    ├── 服务端审计日志与操作追溯系统（操作审计）
    └── 统一文件生成与异步报表导出中心服务（报表导出）
```

## 2. 页面架构与导航设计

### 2.1 一级导航

```
管理后台
  └── 客户服务
        ├── 工作台首页      (workspace)     ← 今日概览、待办、实时统计
        ├── 工单管理        (tickets)       ← 工单列表 + 详情 + 处理
        ├── 用户服务        (users)         ← 用户查询 + 服务记录
        ├── FAQ管理         (faq)           ← 知识库 + 快捷回复
        ├── 客服管理        (agents)        ← 客服人员 + 组 + 排班
        ├── SLA与质量       (quality)       ← SLA监控 + 质检 + 满意度
        └── 数据报表        (reports)       ← 工单统计 + 服务分析
```

### 2.2 页面路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/cs/workspace` | 工作台首页 | 实时数据看板、待处理工单、紧急提醒 |
| `/cs/tickets/list` | 工单列表 | 所有工单，支持多维筛选 |
| `/cs/tickets/:id/detail` | 工单详情 | 工单完整信息 + 处理操作 |
| `/cs/tickets/create` | 创建工单 | 后台手动创建工单 |
| `/cs/users/search` | 用户查询 | 按手机号/昵称/ID查询用户 |
| `/cs/users/:id/profile` | 用户服务档案 | 用户信息 + 工单历史 + 学习数据 |
| `/cs/faq/list` | FAQ列表 | 知识库文章管理 |
| `/cs/faq/categories` | FAQ分类 | 分类树管理 |
| `/cs/faq/quick-reply` | 快捷回复模板 | 模板管理 |
| `/cs/agents/list` | 客服列表 | 客服人员管理 |
| `/cs/agents/groups` | 客服组管理 | 组别 + 技能组 |
| `/cs/agents/schedule` | 排班管理 | 班次 + 假期 |
| `/cs/quality/sla` | SLA监控 | 实时SLA达标情况 |
| `/cs/quality/inspection` | 质量抽检 | 抽检任务 + 评分 |
| `/cs/quality/satisfaction` | 满意度分析 | 评价数据 + 趋势 |
| `/cs/reports/overview` | 服务报表 | 综合数据看板 |
| `/cs/reports/tickets` | 工单报表 | 工单量 + 分类 + 趋势 |
| `/cs/reports/performance` | 绩效报表 | 客服个人绩效数据 |

#### 4.2.2 操作按钮

| 操作 | 权限 | 说明 |
| --- | --- | --- |
| 接单 | 客服专员+ | 将工单分配给自己 |
| 回复 | 当前处理人 | 向用户发送回复消息 |
| 转派 | 客服专员+ | 转给其他客服或客服组 |
| 修改分类 | 客服专员+ | 修改一级/二级分类 |
| 修改优先级 | 客服主管+ | 调整优先级 |
| 添加标签 | 客服专员+ | 添加/移除标签 |
| 关联工单 | 客服专员+ | 关联重复或相关工单 |
| 挂起 | 当前处理人 | 等待用户提供更多信息 |
| 解决 | 当前处理人 | 标记为已解决 |
| 关闭 | 客服主管+ | 关闭工单 |
| 重新打开 | 客服主管+ | 重新打开已关闭工单 |
| 标记重复 | 客服专员+ | 标记为重复工单 |
