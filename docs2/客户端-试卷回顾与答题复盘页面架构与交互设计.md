# 客户端 - 试卷回顾与答题复盘页面架构与交互设计

## 1. 模块概述

### 1.1 功能定位

试卷回顾与答题复盘是考试模拟和真题练习完成后的核心学习环节。学生在完成一套试卷后，通过该模块查看成绩概览、逐题回顾、错题归因、知识点薄弱分析，并将错题一键收录至错题本，实现"考试 → 复盘 → 补漏 → 提升"的完整学习闭环。

### 1.2 目标用户

| 学段 | 核心诉求 | 交互侧重 |
|------|----------|----------|
| 初中生 | 快速定位错题、看懂解析、收录错题 | 清晰的得分展示、分步解析、快捷操作 |
| 高中生 | 深度归因、知识点关联、同类题训练 | 多维度分析、专题关联、冲刺建议 |
| 小学生 | 简单直观的成绩展示、鼓励性反馈 | 大字号成绩、动画激励、简化归因 |

### 1.3 与相关模块的关系

```
考试模拟与真题练习系统（完成考试）
        │
        ▼
  ┌─────────────────────┐
  │  试卷回顾与答题复盘  │ ◄── 考试结果数据
  └──────┬──────────────┘
         │
    ┌────┼────────┬──────────┐
    ▼    ▼        ▼          ▼
  错题本  学情分析  知识图谱   学习规划
  (收录)  (更新画像) (薄弱点) (调整任务)
```

## 2. 页面结构与导航设计

### 2.1 页面层级

```
试卷回顾入口
 ├── 成绩总览页 (ExamResultSummaryPage)
 │    ├── 总分 / 正确率 / 用时
 │    ├── 各题型得分饼图
 │    ├── 知识点掌握雷达图
 │    └── 快捷操作栏（逐题回顾 / 收录全部错题 / 分享）
 │
 ├── 逐题回顾页 (QuestionReviewPage)
 │    ├── 题目展示区（题干 / 选项 / 图表）
 │    ├── 作答对比区（我的答案 ✓/✗ 标准答案）
 │    ├── 解析展示区（分步解析 / 知识点标签）
 │    └── 操作栏（收录错题 / 同类题练习 / AI追问）
 │
 ├── 错题归因分析页 (MistakeAnalysisPage)
 │    ├── 错因分类统计
 │    ├── 按知识点聚合的错误列表
 │    └── 薄弱知识点推荐复习路径
 │
 └── 历史成绩对比页 (HistoryComparisonPage)
      ├── 近 N 次同类型考试趋势
      ├── 进步/退步知识点对比
      └── 排名/百分位（如有）
```

### 2.2 导航交互

| 入口 | 触发条件 | 跳转目标 |
|------|----------|----------|
| 考试完成弹窗 | 交卷后自动弹出 | 成绩总览页 |
| 考试历史列表 | 从考试模块进入 | 成绩总览页 |
| 错题本"来源试卷" | 点击关联试卷 | 成绩总览页 → 逐题回顾页 |
| 学情报告"近期考试" | 点击具体考试 | 成绩总览页 |

## 3. 数据结构定义

### 3.1 核心数据模型

```dart
/// 试卷回顾结果
class ExamReviewResult {
  final String examId;              // 考试记录ID
  final String examType;            // EXAM_MOCK | EXAM_REAL | EXAM_PRACTICE
  final String subjectCode;         // MATH | PHYSICS | ...
  final String title;               // "2025年全国I卷数学"
  final int totalQuestions;         // 总题数
  final int correctCount;           // 正确数
  final int wrongCount;             // 错误数
  final int skippedCount;           // 跳过数
  final int totalScore;             // 总分
  final int earnedScore;            // 得分
  final int totalDurationSeconds;   // 总用时
  final DateTime completedAt;       // 完成时间
  final List<QuestionReviewItem> questions;   // 逐题数据
  final ScoreDistribution distribution;       // 得分分布
  final KnowledgePointAnalysis kpAnalysis;    // 知识点分析
  final MistakeSummary mistakeSummary;        // 错题摘要
  final ExamComparison? comparison;           // 历史对比
}

/// 单题回顾项
class QuestionReviewItem {
  final String questionId;          // 题目ID
  final int questionIndex;          // 题号（1-based）
  final String questionType;        // SINGLE_CHOICE | MULTI_CHOICE | FILL | SHORT_ANSWER | CALCULATE
  final int score;                  // 该题分值
  final int earnedScore;            // 实际得分
  final AnswerStatus status;        // CORRECT | WRONG | PARTIAL | SKIPPED
  final String? myAnswer;           // 我的答案
  final String? standardAnswer;     // 标准答案
  final String? analysis;           // 解析内容(富文本)
  final List<String> knowledgePointIds;  // 涉及知识点
  final int timeSpentSeconds;       // 该题用时
  final bool isInMistakeBook;       // 是否已加入错题本
  final String? mistakeReason;      // 错因标签
}

/// 答题状态枚举
enum AnswerStatus {
  correct,    // 完全正确
  wrong,      // 完全错误
  partial,    // 部分正确（填空/简答）
  skipped,    // 未作答
}

/// 得分分布
class ScoreDistribution {
  final List<TypeScore> byType;             // 按题型分布
  final List<DifficultyScore> byDifficulty;  // 按难度分布
}

class TypeScore {
  final String type;      // SINGLE_CHOICE | FILL | ...
  final String label;     // "选择题" | "填空题" | ...
  final int totalScore;
  final int earnedScore;
  final int count;
}

class DifficultyScore {
  final String difficulty; // EASY | MEDIUM | HARD
  final int totalScore;
  final int earnedScore;
  final int count;
}

/// 知识点分析
class KnowledgePointAnalysis {
  final List<KPScore> points;       // 各知识点得分
  final List<String> weakPoints;    // 薄弱知识点ID列表
  final List<String> strongPoints;  // 优势知识点ID列表
}

class KPScore {
  final String kpId;
  final String kpName;
  final String chapterName;
  final double mastery;    // 掌握度 0-100
  final int correct;
  final int total;
}

/// 错题摘要
class MistakeSummary {
  final Map<String, int> reasonDistribution;  // 错因分布 key=MistakeReason名
  final List<String> topWeakKPIds;            // 高频薄弱知识点
  final int totalMistakes;
  final bool allAddedToMistakeBook;           // 是否已全部加入错题本
}

/// 错因枚举
enum MistakeReason {
  conceptUnclear,    // 概念不清
  misreadQuestion,   // 审题错误
  calcError,         // 计算失误
  methodWrong,       // 方法错误
  careless,          // 粗心大意
  timePressure,      // 时间不够
  knowledgeGap,      // 知识盲区
  unknown,           // 未归类
}

/// 历史对比
class ExamComparison {
  final List<HistoryScore> recentScores;  // 近期同类型考试
  final double? percentile;               // 百分位（如有）
  final List<KPChange> kpChanges;         // 知识点变化
}

class HistoryScore {
  final String examId;
  final String title;
  final double scorePercentage;  // 得分率
  final DateTime completedAt;
}

class KPChange {
  final String kpName;
  final double previousMastery;
  final double currentMastery;
  final double change;  // 正为进步，负为退步
}
```

### 5.3 关键交互逻辑

```dart
class ExamResultSummaryController extends GetxController {
  final ExamReviewResult result;
  final int currentTabIndex = 0; // 0:题型 1:难度 2:知识点

  /// 收录全部错题到错题本
  Future<void> addAllToMistakeBook() async {
    final wrongQuestions = result.questions
        .where((q) =>
            (q.status == AnswerStatus.wrong ||
             q.status == AnswerStatus.partial) &&
            !q.isInMistakeBook)
        .toList();

    if (wrongQuestions.isEmpty) {
      showToast('没有需要收录的错题');
      return;
    }

    // 弹出错因批量标注弹窗
    final reasons = await showBatchMistakeReasonDialog(wrongQuestions);
    if (reasons == null) return; // 用户取消

    showLoading('正在收录错题...');
    try {
      final resp = await ExamApi.batchAddToMistakeBook(
        examResultId: result.examId,
        questionIds: wrongQuestions.map((q) => q.questionId).toList(),
        mistakeReasons: reasons,
      );

      if (resp.success) {
        for (var q in wrongQuestions) {
          q.isInMistakeBook = true;
        }
        showToast('已收录 ${resp.data['addedCount']} 道错题');
      }
    } catch (e) {
      showError('收录失败，请重试');
    } finally {
      hideLoading();
    }
  }

  /// 导航到逐题回顾（优先跳到第一道错题）
  void goToQuestionReview() {
    final firstWrongIndex = result.questions.indexWhere(
      (q) => q.status == AnswerStatus.wrong || q.status == AnswerStatus.partial
    );
    Navigator.pushNamed(
      context,
      '/exam/question-review',
      arguments: {
        'examResultId': result.examId,
        'startIndex': firstWrongIndex >= 0 ? firstWrongIndex : 0,
      },
    );
  }
}
```

### 6.2 解析渐进式展示策略

为避免学生直接看答案而不思考，解析区采用渐进式展示：

| 展示层级 | 内容 | 触发方式 |
|----------|------|----------|
| 第1层 | 思路提示（1-2句话） | 默认展示 |
| 第2层 | 关键步骤 | 用户点击"展开详细步骤" |
| 第3层 | 完整解析+公式推导 | 用户点击"展开全部" |
| 附加 | 易错点提醒 | 始终展示（如有） |
| 附加 | 知识点标签 | 始终展示 |

```dart
enum AnalysisExpandLevel { hint, steps, full }

class AnalysisSection extends StatefulWidget {
  final String analysis;       // 完整解析HTML
  final String hint;           // 思路提示
  final String keySteps;       // 关键步骤HTML
  final List<String> kpTags;   // 知识点标签
  final String? trapTip;       // 易错点
  final AnswerStatus status;

  @override
  _AnalysisSectionState createState() => _AnalysisSectionState();
}

class _AnalysisSectionState extends State<AnalysisExpandSection> {
  AnalysisExpandLevel _level = AnalysisExpandLevel.hint;

  @override
  Widget build(BuildContext context) {
    // 正确的题目默认全部展开
    if (widget.status == AnswerStatus.correct) {
      _level = AnalysisExpandLevel.full;
    }

    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        // 第1层：思路提示（始终展示）
        if (_level == AnalysisExpandLevel.hint)
          _buildHintCard(),

        // 第2层：关键步骤
        if (_level.index >= AnalysisExpandLevel.steps.index)
          _buildStepsCard(),

        // 第3层：完整解析
        if (_level == AnalysisExpandLevel.full)
          _buildFullAnalysisCard(),

        // 展开/收起按钮
        _buildExpandControl(),

        // 易错点
        if (widget.trapTip != null)
          _buildTrapTip(),

        // 知识点标签
        _buildKPTags(),
      ],
    );
  }
}
```

```java
@Service
public class MistakeReasonInferenceService {

    /**
     * 基于答题行为推断错因
     */
    public MistakeReason infer(ExamAnswerRecord record, Question question,
                               UserLearningProfile profile) {
        // 1. 答案格式接近正确答案 → 计算失误/粗心
        if (isCloseToCorrect(record.getMyAnswer(), record.getStandardAnswer())) {
            // 答题时间很短 → 粗心
            if (record.getTimeSpentSec() < estimateMinTime(question) * 0.5) {
                return MistakeReason.careless;
            }
            return MistakeReason.calcError;
        }

        // 2. 答案与正确答案无关 → 概念不清/知识盲区
        if (!hasPartialMatch(record.getMyAnswer(), record.getStandardAnswer())) {
            // 该知识点历史正确率低于40% → 知识盲区
            double historyRate = profile.getKPMastery(question.getPrimaryKPId());
            if (historyRate < 0.4) {
                return MistakeReason.knowledgeGap;
            }
            return MistakeReason.conceptUnclear;
        }

        // 3. 未作答/时间极短 → 时间压力
        if (record.getAnswerStatus().equals("SKIPPED") ||
            record.getTimeSpentSec() < 10) {
            return MistakeReason.timePressure;
        }

        // 4. 默认归类为方法错误
        return MistakeReason.methodWrong;
    }
```

## 9. 状态流转

### 9.1 试卷回顾页面状态

```
ExamReviewState:
  idle         → 初始状态，等待加载
  loading      → 正在获取考试结果
  loaded       → 数据加载完成，展示总览
  reviewing    → 正在逐题回顾
  error        → 加载失败

事件:
  LoadExamReview(examResultId)
  → loading → API调用
  → loaded(data) / error(message)

  NavigateToQuestion(index)
  → reviewing(currentIndex=index)

  AddToMistakeBook(questionId, reason)
  → loaded (更新 isInMistakeBook 标记)

  BatchAddToMistakeBook(questionIds, reasons)
  → loaded (批量更新标记)

  SubmitMistakeReason(questionId, reason)
  → loaded (更新错因标注)
```

### 9.2 逐题回顾导航状态

```
QuestionReviewState:
  currentIndex: int         → 当前题目索引
  totalQuestions: int       → 总题数
  analysisLevel: ExpandLevel → 解析展开层级
  filterMode: ReviewFilter  → ALL | WRONG_ONLY | SKIPPED_ONLY

导航逻辑:
  nextQuestion():
    if filterMode == WRONG_ONLY:
      找到下一个 status == WRONG || PARTIAL 的题目
    else:
      currentIndex++

  prevQuestion(): 同理反向查找

  jumpToQuestion(index):
    currentIndex = index
    analysisLevel = hint (重置解析展开)
```

## 10. 错误处理

### 10.1 网络异常处理

| 场景 | 处理策略 |
|------|----------|

### 10.2 数据异常处理

```dart
class ExamReviewErrorHandler {
  /// 处理API返回的数据异常
  static ExamReviewResult? safeParse(Map<String, dynamic> json) {
    try {
      // 核心字段校验
      if (json['examId'] == null || json['questions'] == null) {
        logError('ExamReview: missing core fields');
        return null;
      }

      final result = ExamReviewResult.fromJson(json);

      // 逻辑一致性校验
      final actualWrong = result.questions.where(
        (q) => q.status == AnswerStatus.wrong
      ).length;
      if (actualWrong != result.wrongCount) {
        logWarn('ExamReview: wrongCount mismatch, using actual count');
        // 以实际数据为准，不阻断流程
      }

      return result;
    } catch (e) {
      logError('ExamReview: parse error', e);
      return null;
    }
  }
}
```

## 11. 性能优化

### 11.1 数据加载策略

```
加载顺序（瀑布式）:
1. 核心数据（分数、题号列表）        → 首屏必须，<500ms
2. 题目内容（逐题按需加载）          → 滑到再加载

5. 历史对比（用户点击时才加载）      → 按需

预加载策略:
- 当前题的解析在用户停留>2秒后自动预加载
- 下一题的内容在当前题展示时后台预加载
- 错因分析页的数据在总览页加载完后后台预加载
```
