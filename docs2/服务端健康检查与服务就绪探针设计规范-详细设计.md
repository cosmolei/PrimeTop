# 服务端健康检查与服务就绪探针设计规范 - 详细设计

> **模块定位**：本模块定义 PrimeTop 服务端统一的健康检查端点规范、启动就绪检查机制、优雅停机流程和 Kubernetes 探针集成方案。为生产环境的服务生命周期管理（启动、运行、停止）提供标准化的可观测性和自动化控制能力。
>
> **与现有文档的边界**：
> - **服务端服务架构与部署设计**：涵盖总体架构和部署方案，本文档聚焦生命周期的健康与就绪细节
> - **服务端分布式链路追踪与全链路可观测体系**：侧重请求级追踪和指标采集，本文档侧重服务级健康状态暴露
> - **错误处理与服务降级策略**：侧重运行时故障处理，本文档侧重主动健康探测和预防性熔断
> - **CI-CD流水线与自动化构建发布系统**：侧重部署流程，本文档为部署流水线提供健康校验能力

## 1. 设计目标与原则

### 1.1 设计目标

| 目标 | 说明 |
|------|------|
| **快速故障检测** | 秒级发现服务异常，自动触发流量切换或重启 |
| **优雅启动** | 确保所有依赖就绪后才接收流量，避免启动期错误 |
| **优雅停机** | 停机时完成在途请求，不丢失用户数据 |
| **标准化接口** | 所有服务统一健康检查协议，便于基础设施层统一管理 |
| **K8s 原生集成** | 完整支持 readiness/liveness/startup 三种探针 |

### 1.2 设计原则

1. **轻量级**：健康检查接口响应时间 ≤ 50ms，不消耗显著资源
2. **幂等安全**：检查操作不修改任何状态，不产生副作用
3. **分层检测**：基础存活 / 依赖就绪 / 业务深度 三层检查分离
4. **可配置**：检查项、超时时间、阈值均可动态配置
5. **渐进式**：启动时检查从浅到深，避免阻塞启动

### 1.3 非目标

- 不做分布式健康共识（Raft 等），单节点级别的健康判定即可
- 不替代监控告警体系，仅作为探针数据源
- 不覆盖前端客户端的健康检查（由客户端网络请求治理模块负责）

## 2. 核心概念与状态模型

### 2.1 服务生命周期状态

```text
                    ┌─────────────────┐
                    │   STARTING      │  应用启动中
                    │   (初始化各组件)  │
                    └────────┬────────┘
                             │ 所有启动依赖满足
                             ▼
                    ┌─────────────────┐
                    │   READY         │  就绪，可接收流量
                    │   (正常服务)      │
                    └────────┬────────┘
                        ┌────┴────┐
                        │         │
                  依赖故障   收到 SIGTERM
                        │         │
                        ▼         ▼
                 ┌──────────┐  ┌──────────────┐
                 │ DEGRADED │  │  STOPPING    │  优雅停机中
                 │ (降级服务) │  │ (排空在途请求) │
                 └──────────┘  └──────┬───────┘
                        │             │ 在途请求完成或超时
                        │             ▼
                        │      ┌──────────────┐
                        │      │   STOPPED    │  已停止
                        └──────┴──────────────┘
```

### 2.2 健康状态枚举

```python
# primetop/core/health/models.py

from enum import Enum
from dataclasses import dataclass, field
from datetime import datetime
from typing import Optional

class HealthStatus(str, Enum):
    """健康状态"""
    UP = "UP"              # 健康
    DOWN = "DOWN"          # 不可用
    DEGRADED = "DEGRADED"  # 降级（部分依赖异常但核心功能可用）
    UNKNOWN = "UNKNOWN"    # 未知（检查未执行或超时）

class CheckSeverity(str, Enum):
    """检查项严重级别"""
    CRITICAL = "CRITICAL"  # 关键：影响核心功能，DOWN 时不应接收流量
    WARNING = "WARNING"    # 警告：影响部分功能，可以 DEGRADED 运行

@dataclass
class HealthCheckResult:
    """单个检查项结果"""
    name: str                          # 检查项名称，如 "database"、"redis"
    status: HealthStatus               # 检查状态
    severity: CheckSeverity            # 严重级别
    response_time_ms: float            # 检查耗时（毫秒）
    error_message: Optional[str] = None  # 错误信息（DOWN 时必填）
    details: dict = field(default_factory=dict)  # 扩展信息

    def to_dict(self) -> dict:
        return {
            "name": self.name,
            "status": self.status.value,
            "severity": self.severity.value,
            "responseTimeMs": round(self.response_time_ms, 2),
            **({"errorMessage": self.error_message} if self.error_message else {}),
            **({"details": self.details} if self.details else {}),
        }

@dataclass
class HealthReport:
    """服务整体健康报告"""
    service_name: str
    status: HealthStatus
    version: str
    uptime_seconds: float
    started_at: datetime
    checks: list[HealthCheckResult]
    checked_at: datetime = field(default_factory=datetime.utcnow)

    def to_dict(self) -> dict:
        return {
            "serviceName": self.service_name,
            "status": self.status.value,
            "version": self.version,
            "uptimeSeconds": round(self.uptime_seconds, 1),
            "startedAt": self.started_at.isoformat(),
            "checkedAt": self.checked_at.isoformat(),
            "checks": [c.to_dict() for c in self.checks],
        }
```

### 2.3 状态判定规则

```
整体状态判定逻辑：
  1. 任一 CRITICAL 检查项 DOWN  → 整体 DOWN
  2. 任一 WARNING 检查项 DOWN   → 整体 DEGRADED
  3. 所有检查项 UP              → 整体 UP
  4. 任一检查项 UNKNOWN + CRITICAL → 整体 DOWN
  5. 无 CRITICAL DOWN，但存在 UNKNOWN + WARNING → 整体 DEGRADED
```

## 3. API 接口设计

### 3.1 端点总览

| 端点 | 用途 | 响应时间要求 | 认证 |
|------|------|-------------|------|
| `GET /health` | 存活检查（Liveness） | ≤ 10ms | 无 |
| `GET /health/ready` | 就绪检查（Readiness） | ≤ 50ms | 无 |
| `GET /health/detail` | 深度检查（运维排障） | ≤ 200ms | 需要管理员 Token |
| `GET /health/startup` | 启动探针（Startup Probe） | ≤ 50ms | 无 |

### 3.2 存活检查 - GET /health

最轻量级检查，仅验证进程存活和事件循环可用。

**响应示例**：

```json
// HTTP 200
{
  "status": "UP",
  "timestamp": "2026-05-26T13:00:00Z"
}

// HTTP 503 Service Unavailable（进程僵死或严重故障）
{
  "status": "DOWN",
  "timestamp": "2026-05-26T13:00:00Z"
}
```

**实现**：

```python
# primetop/core/health/endpoints.py

from fastapi import APIRouter
from datetime import datetime

router = APIRouter(tags=["health"])

@router.get("/health", status_code=200)
async def liveness_check():
    """
    存活检查 - 仅验证进程存活。
    如果能返回 200，说明进程和事件循环正常。
    """
    return {
        "status": "UP",
        "timestamp": datetime.utcnow().isoformat(),
    }
```

检查服务是否准备好接收流量，包含所有关键依赖的连通性检查。

```python
@router.get("/health/ready", status_code=200)
async def readiness_check(response: Response):
    """
    就绪检查 - 验证所有关键依赖可用。
    用于 K8s readinessProbe，决定 Pod 是否接收流量。
    """
    report = await health_checker.check_readiness()

    if report.status == HealthStatus.DOWN:
        response.status_code = 503
    elif report.status == HealthStatus.DEGRADED:
        response.status_code = 200  # 降级但仍可接收流量

    return {
        "status": report.status.value,
        "service": report.service_name,
        "version": report.version,
        "timestamp": report.checked_at.isoformat(),
        **({"failedChecks": _failed_names(report, CheckSeverity.CRITICAL)}
           if report.status == HealthStatus.DOWN else {}),
        **({"degradedChecks": _failed_names(report, CheckSeverity.WARNING)}
           if report.status == HealthStatus.DEGRADED else {}),
    }
```

### 3.5 启动探针 - GET /health/startup

用于 K8s startupProbe，判断应用是否完成了初始化。启动完成前一直返回 503。

```python
@router.get("/health/startup", status_code=200)
async def startup_check(response: Response):
    """
    启动探针 - 检查应用是否完成初始化。
    K8s startupProbe 成功后才会开始 readiness/liveness 探测。
    """
    if not app_state.is_initialized():
        response.status_code = 503
        return {
            "status": "STARTING",
            "initializedSteps": app_state.completed_init_steps(),
            "totalSteps": app_state.total_init_steps(),
        }

    return {
        "status": "UP",
        "initializedAt": app_state.initialized_at().isoformat(),
    }
```

## 4. 检查项定义

### 4.1 检查项注册表

```python
# primetop/core/health/checks.py

from abc import ABC, abstractmethod
import time
import asyncio
from typing import Optional

class HealthCheck(ABC):
    """健康检查基类"""

    @property
    @abstractmethod
    def name(self) -> str:
        """检查项唯一名称"""
        ...

    @property
    @abstractmethod
    def severity(self) -> CheckSeverity:
        """严重级别"""
        ...

    @property
    def timeout_ms(self) -> int:
        """超时时间（毫秒），默认 2000ms"""
        return 2000

    @property
    def include_in_readiness(self) -> bool:
        """是否包含在就绪检查中，默认 True"""
        return True

    @abstractmethod
    async def check(self) -> HealthCheckResult:
        """执行检查，返回结果"""
        ...

    async def safe_check(self) -> HealthCheckResult:
        """带超时和异常捕获的安全检查"""
        start = time.monotonic()
        try:
            result = await asyncio.wait_for(
                self.check(),
                timeout=self.timeout_ms / 1000.0,
            )
            result.response_time_ms = (time.monotonic() - start) * 1000
            return result
        except asyncio.TimeoutError:
            return HealthCheckResult(
                name=self.name,
                status=HealthStatus.DOWN,
                severity=self.severity,
                response_time_ms=self.timeout_ms,
                error_message=f"Check timed out after {self.timeout_ms}ms",
            )
        except Exception as e:
            return HealthCheckResult(
                name=self.name,
                status=HealthStatus.DOWN,
                severity=self.severity,
                response_time_ms=(time.monotonic() - start) * 1000,
                error_message=str(e),
            )
```

#### 4.2.1 数据库检查

```python
class DatabaseHealthCheck(HealthCheck):
    """MySQL/PostgreSQL 数据库连接检查"""

    @property
    def name(self) -> str:
        return "database"

    @property
    def severity(self) -> CheckSeverity:
        return CheckSeverity.CRITICAL

    @property
    def timeout_ms(self) -> int:
        return 3000  # 数据库检查允许稍长超时

    async def check(self) -> HealthCheckResult:
        from primetop.core.database import get_engine

        engine = get_engine()
        start = time.monotonic()

        async with engine.connect() as conn:
            # 执行简单查询验证连接可用
            result = await conn.execute(text("SELECT 1"))
            result.fetchone()

            # 获取连接池状态
            pool = engine.pool
            details = {
                "poolSize": pool.size(),
                "poolActive": pool.checkedout(),
                "poolIdle": pool.size() - pool.checkedout(),
                "poolOverflow": pool.overflow(),
            }

        elapsed = (time.monotonic() - start) * 1000

        return HealthCheckResult(
            name=self.name,
            status=HealthStatus.UP,
            severity=self.severity,
            response_time_ms=elapsed,
            details=details,
        )
```

```python
class RedisHealthCheck(HealthCheck):
    """Redis 连接检查"""

    @property
    def name(self) -> str:
        return "redis"

    @property
    def severity(self) -> CheckSeverity:

    async def check(self) -> HealthCheckResult:
        from primetop.core.redis import get_redis

        redis = get_redis()
        start = time.monotonic()

        # PING 命令验证连接
        pong = await redis.ping()
        if pong:
            # 获取 Redis 信息

                "connectedClients": await redis.dbsize(),

            elapsed = (time.monotonic() - start) * 1000
            return HealthCheckResult(
                name=self.name,
                status=HealthStatus.UP,
                severity=self.severity,
                response_time_ms=elapsed,
                details=details,
            )
        else:
            return HealthCheckResult(
                name=self.name,
                status=HealthStatus.DOWN,
                severity=self.severity,
                response_time_ms=(time.monotonic() - start) * 1000,
                error_message="Redis PING returned False",
```

```python
class AIProviderHealthCheck(HealthCheck):
    """AI 大模型供应商连通性检查"""

    def __init__(self, provider_code: str, model: str):
        self._provider_code = provider_code
        self._model = model

    @property
    def name(self) -> str:
        return f"ai_provider:{self._provider_code}"

    @property
    def severity(self) -> CheckSeverity:
        return CheckSeverity.WARNING  # 单供应商不可用可降级到其他供应商

    @property
    def timeout_ms(self) -> int:
        return 5000  # AI 接口允许较长超时

    async def check(self) -> HealthCheckResult:
        from primetop.modules.ai.service import get_model_adapter
        from primetop.core.redis import get_redis

        adapter = get_model_adapter(self._provider_code)
        redis = get_redis()
        start = time.monotonic()

        # 方式1：检查最近的调用统计（轻量）
        error_key = f"health:ai:{self._provider_code}:errors"
        latency_key = f"health:ai:{self._provider_code}:latency"

        recent_errors = await redis.get(error_key) or 0
        recent_errors = int(recent_errors)

        # 方式2：发送极简 completion 验证连通性（仅主供应商）
        if self._provider_code in settings.HEALTH_CHECK_AI_FULL_CHECK_PROVIDERS:
            try:
                await adapter.chat_completion(
                    messages=[{"role": "user", "content": "hi"}],
                    model=self._model,
                    max_tokens=1,
                    timeout=5,
                )
                ai_status = HealthStatus.UP
            except Exception as e:
                ai_status = HealthStatus.DOWN
                elapsed = (time.monotonic() - start) * 1000
                return HealthCheckResult(
                    name=self.name,
                    status=ai_status,
                    severity=self.severity,
                    response_time_ms=elapsed,
                    error_message=str(e)[:200],
                    details={"model": self._model, "recentErrors": recent_errors},
                )

        elapsed = (time.monotonic() - start) * 1000

        return HealthCheckResult(
            name=self.name,
            status=HealthStatus.UP,
            severity=self.severity,
            response_time_ms=elapsed,
            details={"model": self._model, "recentErrors": recent_errors},
        )
```

```python
class DiskSpaceHealthCheck(HealthCheck):
    """磁盘空间检查"""

    @property
    def name(self) -> str:
        return "disk_space"

    @property
    def severity(self) -> CheckSeverity:
        return CheckSeverity.CRITICAL

    @property
    def timeout_ms(self) -> int:
        return 100  # 本地操作，极快

    @property
    def include_in_readiness(self) -> bool:
        return False  # 不阻塞启动，但影响存活判定

    async def check(self) -> HealthCheckResult:
        import shutil

        disk_usage = shutil.disk_usage(settings.DATA_DIR)
        usage_percent = (disk_usage.used / disk_usage.total) * 100

        # 使用率 > 95% 标记为 DOWN
        if usage_percent > 95:
            status = HealthStatus.DOWN
            error_message = f"Disk usage {usage_percent:.1f}% exceeds 95% threshold"
        # 使用率 > 85% 标记为 DEGRADED
        elif usage_percent > 85:
            status = HealthStatus.DEGRADED
            error_message = f"Disk usage {usage_percent:.1f}% exceeds 85% warning"
        else:
            status = HealthStatus.UP
            error_message = None

        return HealthCheckResult(
            name=self.name,
            status=status,
            severity=self.severity,
            response_time_ms=0.1,
            error_message=error_message,
            details={
                "totalGB": round(disk_usage.total / (1024**3), 1),
                "usedGB": round(disk_usage.used / (1024**3), 1),
                "availableGB": round(disk_usage.free / (1024**3), 1),
                "usagePercent": round(usage_percent, 1),
            },
        )
```

```python
        return CheckSeverity.WARNING  # 消息队列不可用可通过同步降级

    @property
    def timeout_ms(self) -> int:
        return 3000

    async def check(self) -> HealthCheckResult:
        from primetop.core.messaging import get_kafka_admin

        admin = get_kafka_admin()
        start = time.monotonic()

        # 列出主题验证连通性
        topics = await admin.list_topics()
        elapsed = (time.monotonic() - start) * 1000

        # 检查关键主题是否存在
        required_topics = [
            "learning-events",
            "ai-requests",
            "notification-events",
        ]
        missing = [t for t in required_topics if t not in topics]

        if missing:
            return HealthCheckResult(
                name=self.name,
                status=HealthStatus.DEGRADED,
                severity=self.severity,
                response_time_ms=elapsed,
                error_message=f"Missing topics: {missing}",
                details={
                    "topicCount": len(topics),
                    "missingTopics": missing,
                },
            )

        return HealthCheckResult(
            name=self.name,
            status=HealthStatus.UP,
            severity=self.severity,
            response_time_ms=elapsed,
            details={"topicCount": len(topics)},
        )
```

## 5. 健康检查编排器

### 5.1 核心编排器实现

```python
# primetop/core/health/checker.py

import asyncio
import time
import logging
from datetime import datetime
from typing import Optional

from primetop.core.health.models import (
    HealthCheck, HealthCheckResult, HealthReport, HealthStatus, CheckSeverity,
)
from primetop.core.health.checks import (
    DatabaseHealthCheck,
    RedisHealthCheck,
    ElasticsearchHealthCheck,
    DiskSpaceHealthCheck,
    MessageQueueHealthCheck,
)

logger = logging.getLogger(__name__)

class HealthChecker:
    """
    健康检查编排器。
    负责注册、执行和汇总所有健康检查项。
    """

    def __init__(self, service_name: str, version: str):
        self.service_name = service_name
        self.version = version
        self._checks: dict[str, HealthCheck] = {}
        self._started_at: Optional[datetime] = None
        self._last_readiness_result: Optional[HealthReport] = None

    def register(self, check: HealthCheck) -> None:
        """注册检查项"""
        self._checks[check.name] = check
        logger.info(f"Registered health check: {check.name} ({check.severity.value})")

    def unregister(self, name: str) -> None:
        """移除检查项"""
        self._checks.pop(name, None)

    def mark_started(self) -> None:
        """标记服务启动完成"""
        self._started_at = datetime.utcnow()

    @property
    def uptime_seconds(self) -> float:
        if self._started_at is None:
            return 0.0
        return (datetime.utcnow() - self._started_at).total_seconds()

    async def check_readiness(self) -> HealthReport:
        """
        执行就绪检查 - 只包含 include_in_readiness=True 的检查项。
        用于 K8s readinessProbe。
        """
        checks_to_run = [
            c for c in self._checks.values() if c.include_in_readiness
        ]
        results = await self._run_checks(checks_to_run)
        overall = self._compute_overall_status(results)

        report = HealthReport(
            service_name=self.service_name,
            status=overall,
            version=self.version,
            uptime_seconds=self.uptime_seconds,
            started_at=self._started_at or datetime.utcnow(),
            checks=results,
        )
        self._last_readiness_result = report
        return report

    async def check_full(self) -> HealthReport:
        """执行全部检查项"""
        results = await self._run_checks(list(self._checks.values()))
        overall = self._compute_overall_status(results)

        return HealthReport(
            service_name=self.service_name,
            status=overall,
            version=self.version,
            uptime_seconds=self.uptime_seconds,
            started_at=self._started_at or datetime.utcnow(),
            checks=results,
        )

    async def _run_checks(self, checks: list[HealthCheck]) -> list[HealthCheckResult]:
        """并发执行所有检查项"""
        tasks = [check.safe_check() for check in checks]
        results = await asyncio.gather(*tasks, return_exceptions=False)

        # 记录 DOWN 的检查项
        for r in results:
            if r.status == HealthStatus.DOWN:
                logger.warning(
                    f"Health check DOWN: {r.name} - {r.error_message}"
                )

        return list(results)

    def _compute_overall_status(self, results: list[HealthCheckResult]) -> HealthStatus:
        """根据各项结果计算整体状态"""
        has_critical_down = False
        has_warning_down = False
        has_unknown = False

        for r in results:
            if r.status == HealthStatus.DOWN:
                if r.severity == CheckSeverity.CRITICAL:
                    has_critical_down = True
                else:
                    has_warning_down = True
            elif r.status == HealthStatus.UNKNOWN:
                has_unknown = True
            elif r.status == HealthStatus.DEGRADED:
                if r.severity == CheckSeverity.WARNING:
                    has_warning_down = True

        if has_critical_down:
            return HealthStatus.DOWN
        if has_warning_down:
            return HealthStatus.DEGRADED
        if has_unknown:
            return HealthStatus.DEGRADED
        return HealthStatus.UP


# 全局单例
_health_checker: Optional[HealthChecker] = None

def get_health_checker() -> HealthChecker:
    global _health_checker
    if _health_checker is None:
        raise RuntimeError("HealthChecker not initialized")
    return _health_checker

def init_health_checker(service_name: str, version: str) -> HealthChecker:
    global _health_checker
    _health_checker = HealthChecker(service_name, version)
    return _health_checker
```

## 6. 缓存与性能优化

### 6.1 检查结果缓存

避免高频探针导致检查风暴（多个 K8s 节点同时探测）。

```python
# primetop/core/health/cache.py

import time
import asyncio
from typing import Optional

class CachedHealthResult:
    """带 TTL 的检查结果缓存"""

    def __init__(self, ttl_seconds: float = 5.0):
        self._ttl = ttl_seconds
        self._cached_report: Optional[HealthReport] = None
        self._cached_at: float = 0
        self._lock = asyncio.Lock()

    async def get_or_check(
        self,
        checker: 'HealthChecker',
        full: bool = False,
    ) -> HealthReport:
        """获取缓存的报告或执行新检查"""
        now = time.monotonic()

        # 缓存未过期，直接返回
        if (self._cached_report is not None
                and (now - self._cached_at) < self._ttl):
            # 更新 checkedAt 为实际返回时间
            return self._cached_report

        # 加锁避免并发重复检查
        async with self._lock:
            # Double-check
            if (self._cached_report is not None
                    and (time.monotonic() - self._cached_at) < self._ttl):
                return self._cached_report

            # 执行检查
            if full:
                report = await checker.check_full()
            else:
                report = await checker.check_readiness()

            self._cached_report = report
            self._cached_at = time.monotonic()
            return report


# 全局缓存实例
_readiness_cache = CachedHealthResult(ttl_seconds=5)
_detail_cache = CachedHealthResult(ttl_seconds=10)
```

## 7. 优雅停机

### 7.1 停机流程

```text
收到 SIGTERM/SIGINT
      │
      ▼
┌─────────────────────────────┐
│ 1. 标记服务为 STOPPING      │  新请求立即返回 503
│    (stop accepting traffic) │
└────────────┬────────────────┘
             │
             ▼
┌─────────────────────────────┐
│ 2. 从负载均衡器摘除         │  K8s 自动完成（readinessProbe 失败）
└────────────┬────────────────┘
             │
             ▼
┌─────────────────────────────┐
│ 3. 等待在途请求完成         │  等待所有活跃请求响应
│    (drain connections)       │  超时后强制关闭
└────────────┬────────────────┘
             │
             ▼
┌─────────────────────────────┐
│ 4. 完成在途异步任务         │  AI 请求、文件上传等
│    (cancel pending tasks)   │  不可取消的等待完成
└────────────┬────────────────┘
             │
             ▼
┌─────────────────────────────┐
│ 5. 释放资源                 │
│  - 关闭数据库连接池          │
│  - 关闭 Redis 连接          │
│  - 关闭 Kafka Producer      │
│  - 关闭 HTTP Server         │
└────────────┬────────────────┘
             │
             ▼
┌─────────────────────────────┐
│ 6. 进程退出 (exit code 0)   │
└─────────────────────────────┘
```

### 7.2 实现方案

```python
# primetop/core/health/shutdown.py

import asyncio
import signal
import logging
from typing import Callable, Awaitable, Optional

logger = logging.getLogger(__name__)

class GracefulShutdown:
    """优雅停机管理器"""

    def __init__(
        self,
        drain_timeout: float = 30.0,  # 排空超时（秒）
    ):
        self.drain_timeout = drain_timeout
        self._shutdown_event = asyncio.Event()
        self._active_requests = 0
        self._active_requests_zero = asyncio.Event()
        self._active_requests_zero.set()  # 初始状态：无活跃请求
        self._shutdown_hooks: list[Callable[[], Awaitable]] = []
        self._is_shutting_down = False

    @property
    def is_shutting_down(self) -> bool:
        return self._is_shutting_down

    def request_started(self) -> None:
        """请求开始处理时调用"""
        self._active_requests += 1
        self._active_requests_zero.clear()

    def request_finished(self) -> None:
        """请求处理完成时调用"""
        self._active_requests -= 1
        if self._active_requests <= 0:
            self._active_requests = 0
            self._active_requests_zero.set()

    def add_shutdown_hook(self, hook: Callable[[], Awaitable]) -> None:
        """注册停机钩子"""
        self._shutdown_hooks.append(hook)

    def install_signal_handlers(self, loop: asyncio.AbstractEventLoop) -> None:
        """安装信号处理"""
        for sig in (signal.SIGTERM, signal.SIGINT):
            loop.add_signal_handler(sig, lambda: asyncio.create_task(self._handle_signal()))

    async def _handle_signal(self) -> None:
        """处理终止信号"""
        if self._is_shutting_down:
            logger.warning("Already shutting down, ignoring signal")
            return

        self._is_shutting_down = True
        logger.info("Shutdown signal received, starting graceful shutdown...")
        self._shutdown_event.set()

    async def wait_for_shutdown(self) -> None:
        """等待停机信号"""
        await self._shutdown_event.wait()

    async def execute_shutdown(self) -> None:
        """执行优雅停机流程"""
        logger.info(f"Waiting for {self._active_requests} active requests to complete...")

        # 步骤3：等待在途请求完成（带超时）
        try:
            await asyncio.wait_for(
                self._active_requests_zero.wait(),
                timeout=self.drain_timeout,
            )
            logger.info("All active requests completed")
        except asyncio.TimeoutError:
            logger.warning(
                f"Drain timeout ({self.drain_timeout}s) exceeded, "
                f"forcing shutdown with {self._active_requests} active requests"
            )

        # 步骤4和5：执行停机钩子
        for i, hook in enumerate(self._shutdown_hooks):
            try:
                logger.info(f"Executing shutdown hook {i + 1}/{len(self._shutdown_hooks)}")
                await asyncio.wait_for(hook(), timeout=10.0)
            except Exception as e:
                logger.error(f"Shutdown hook failed: {e}")

        logger.info("Graceful shutdown complete")


# 全局单例
_shutdown_manager: Optional[GracefulShutdown] = None

def get_shutdown_manager() -> GracefulShutdown:
    global _shutdown_manager
    if _shutdown_manager is None:
        _shutdown_manager = GracefulShutdown()
    return _shutdown_manager
```

### 7.3 FastAPI 中间件集成

```python
# primetop/core/health/middleware.py

from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import JSONResponse

class ActiveRequestTracker(BaseHTTPMiddleware):
    """
    跟踪活跃请求数，支持优雅停机时的请求排空。
    停机期间拒绝新请求。
    """

    async def dispatch(self, request: Request, call_next):
        shutdown = get_shutdown_manager()

        # 健康检查端点始终放行
        if request.url.path.startswith("/health"):
            return await call_next(request)

        # 停机中拒绝新请求
        if shutdown.is_shutting_down:
            return JSONResponse(
                status_code=503,
                content={
                    "error": "SERVICE_SHUTTING_DOWN",
                    "message": "Server is shutting down, please retry later",
                },
                headers={"Retry-After": "5"},
            )

        # 跟踪活跃请求
        shutdown.request_started()
        try:
            response = await call_next(request)
            return response
        finally:
            shutdown.request_finished()
```

### 8.1 Deployment 探针配置

```yaml
# k8s/deployment.yaml

apiVersion: apps/v1
kind: Deployment
metadata:
  name: primetop-api
spec:
  replicas: 3
  selector:
    matchLabels:
      app: primetop-api
  template:

      containers:
        - name: api
          image: primetop/api:1.2.0
          ports:
            - containerPort: 8080

          # === 启动探针 ===
          # 应用初始化期间使用，避免慢启动被 liveness 杀死
          startupProbe:
            httpGet:
              path: /health/startup
              port: 8080
            failureThreshold: 30  # 允许最多30次失败
            periodSeconds: 2      # 每2秒检查一次
            # 总计等待时间：30 * 2 = 60秒
            # 超过后 K8s 杀死容器重启

          # === 存活探针 ===
          # startupProbe 成功后才开始
          livenessProbe:
            httpGet:
              path: /health
              port: 8080
            failureThreshold: 3   # 连续3次失败则重启
            periodSeconds: 10     # 每10秒检查一次
            successThreshold: 1
            timeoutSeconds: 3

          # === 就绪探针 ===
          # startupProbe 成功后才开始
          readinessProbe:
            httpGet:
              path: /health/ready
              port: 8080
            failureThreshold: 3   # 连续3次失败则摘除流量
            periodSeconds: 5      # 每5秒检查一次
            successThreshold: 1
            timeoutSeconds: 3

          # === 生命周期钩子 ===
          lifecycle:
            preStop:
              exec:
                # 等待 K8s iptables 规则更新完成后再开始停机
                # 避免仍有请求路由到正在停止的 Pod
                command: ["/bin/sh", "-c", "sleep 5"]

          resources:
            requests:
              cpu: "500m"
              memory: "512Mi"
            limits:
              cpu: "2000m"
              memory: "2Gi"
```

| **用途** | 应用初始化完成检测 | 进程存活检测 | 流量接收就绪检测 |
| **端点** | `/health/startup` | `/health` | `/health/ready` |
| **periodSeconds** | 2 | 10 | 5 |
| **timeoutSeconds** | 3 | 3 | 3 |
| **failureThreshold** | 30 | 3 | 3 |
| **successThreshold** | 1 | 1 | 1 |
| **最大等待时间** | 60s | - | - |
| **失败后果** | 重启容器 | 重启容器 | 摘除流量（不重启） |

```python
    ["service"],

        HealthStatus.DEGRADED: 1,
        HealthStatus.DOWN: 0,
        HealthStatus.UNKNOWN: 0,
    }[report.status]

    health_status_gauge.labels(service=report.service_name).set(status_value)

        health_check_status_gauge.labels(
            service=report.service_name,
            check_name=check.name,
            severity=check.severity.value,
        ).set(check_value)

            check_name=check.name,
```

## 15. FAQ

**Q: 健康检查会影响性能吗？**
A: 影响极小。就绪检查带 5 秒缓存，存活检查仅检查进程存活（无 IO），深度检查有独立缓存且需要管理员权限。单次检查耗时控制在 50ms 内。

**Q: 如果 AI 供应商检查耗时过长怎么办？**
A: AI 供应商检查设为 WARNING 级别且不包含在就绪检查中，不会阻塞启动和流量接收。超时设为 5 秒，超时后标记 DOWN 但不影响整体 UP 状态。

**Q: 优雅停机时在途的 AI 请求怎么处理？**
A: AI 请求通常耗时 5-30 秒。优雅停机超时设为 30 秒。对于 SSE 流式响应，停机时会立即停止接收新请求，在途流会在下一个 chunk 后正常结束或超时关闭。未被消费的 AI 响应会被丢弃（不影响数据一致性）。

**Q: 为什么需要 startupProbe 而不只靠 readinessProbe？**
A: 慢启动场景下（如大量数据预热、模型加载），readinessProbe 可能在启动早期连续失败达到 failureThreshold 被误判为不健康。startupProbe 提供独立的启动检测窗口，成功后才启用 liveness/readiness 探测，避免启动期被误杀。

**Q: 如何新增一个自定义检查项？**
A: 继承 `HealthCheck` 基类，实现 `name`、`severity`、`check()` 三个成员，然后在启动注册流程中调用 `checker.register(MyCustomCheck())`。
