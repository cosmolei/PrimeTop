# 服务端 - 学习时机感知与场景化内容推荐编排引擎 详细设计

> **文档版本**: v1.0  
> **创建日期**: 2026-06-20  
> **所属模块**: 数据分析服务 / 推荐系统  
> **依赖模块**: 用户学习画像、知识点体系、学习计划服务、消息推送服务、学习会话管理  
> **优先级**: P1（V1.5 阶段）

---

## 1. 概述

### 1.1 设计目标

构建一个**场景化、时机感知**的推荐编排引擎，区别于传统基于用户画像的静态推荐。本引擎聚焦于回答以下核心问题：

- **何时推荐**（When）：基于学习时段、间隔时间、考试倒计时等时间维度
- **何种场景**（What context）：基于学习状态、认知负荷、情绪信号等上下文维度
- **推荐什么**（What content）：基于场景动态选择推荐内容类型和难度
- **如何呈现**（How）：基于设备、网络、当前页面决定推荐展现形式

### 1.2 与现有推荐模块的边界

| 模块 | 关注点 | 本引擎关系 |
|------|--------|------------|
| 自适应学习与个性化推荐引擎 | 基于用户画像的长期推荐策略 | **本引擎是其在场景层的动态调度器** |
| 首页内容卡片推荐与聚合编排服务 | 首页卡片具体编排 | **本引擎为其提供场景信号输入** |
| 推荐内容多样性保障引擎 | 避免信息茧房 | **本引擎在选题时调用其多样性保障策略** |
| 个性化推荐解释生成引擎 | 为推荐生成可解释理由 | **本引擎输出推荐场景标签供解释引擎使用** |
| 学习场景意图识别与智能路由引擎 | 识别用户当前学习意图 | **本引擎消费其意图信号，叠加时机维度** |
| 统一学习干预编排与智能频控引擎 | 学习干预策略 | **本引擎为其提供时机决策依据** |

### 1.3 核心价值

```
传统推荐:  Student Profile  →  Content  →  Show
场景推荐:  Student Profile + Time Context + Learning State + Environment Signal
           → Scene Model
           → Content Strategy (type/difficulty/quantity)
           → Channel Strategy (push/in-app/banner/homepage)
           → Execution
```

**核心差异**：同一个学生在不同场景下应该收到完全不同的推荐内容。例如：
- 考前 7 天 → 高频考点 + 真题模拟 + 错题重练
- 考后 1 天 → 心态调整内容 + 薄弱点分析 + 鼓励性内容
- 工作日晚间 → 当日作业复习 + 明日预习
- 周末上午 → 深度专题 + 知识体系梳理
- 连续答错 3 题 → 降难度 + 基础知识回顾 + 休息提醒

## 3. 数据结构定义

### 3.1 场景信号上下文 (SceneContext)

```typescript
interface SceneContext {
  // ===== 时机维度 =====
  timing: {
    currentTime: string;            // ISO 8601 时间戳
    dayOfWeek: number;              // 1-7 (周一到周日)
    timeSlot: TimeSlot;             // 时段枚举
    daysToNextExam: number | null;  // 距下次考试天数 (null=无考试安排)
    daysToNextDeadline: number | null; // 距下次任务截止天数
    lastStudyInterval: number;      // 距上次学习的分钟数
    semesterPhase: SemesterPhase;   // 学期阶段
    isHoliday: boolean;             // 是否假期
    holidayType: string | null;     // 寒假/暑假/国庆等
  };

  // ===== 学习状态维度 =====
  learningState: {
    currentSessionId: string | null;  // 当前学习会话ID
    currentSubject: Subject | null;   // 当前正在学习的学科
    currentChapterId: string | null;  // 当前学习章节
    consecutiveCorrectCount: number;  // 连续正确次数
    consecutiveWrongCount: number;    // 连续错误次数
    sessionDuration: number;          // 当前会话已持续分钟数
    todayStudyMinutes: number;        // 今日已学习分钟数
    cognitiveLoadLevel: CognitiveLoad; // 认知负荷等级
    engagementScore: number;          // 投入度评分 0-100
  };

  // ===== 情绪信号维度 =====
  emotionSignals: {
    frustrationLevel: number;        // 挫败感 0-100
    confidenceLevel: number;         // 自信心 0-100
    boredomLevel: number;            // 无聊感 0-100
    signalSource: SignalSource[];    // 信号来源
    confidence: number;              // 情绪判断置信度 0-1
  };

  // ===== 环境上下文维度 =====
  environment: {
    deviceType: DeviceType;          // phone / tablet / web
    networkType: NetworkType;        // wifi / 4g / 5g / weak
    screenAvailable: number;         // 可用屏幕时间(分钟)
    currentPage: PageType;           // 当前所在页面
    isBackground: boolean;           // App 是否在后台
    batteryLevel: number | null;     // 电量百分比
  };

  // ===== 用户画像摘要 =====
  userSummary: {
    userId: string;
    gradeLevel: GradeLevel;
    textbookVersion: string;
    membershipTier: MembershipTier;
    learningStyleHint: LearningStyle | null;
    preferredDifficulty: Difficulty;
    weakSubjects: Subject[];
    strongSubjects: Subject[];
  };
}

enum TimeSlot {
  EARLY_MORNING = 'early_morning',     // 6:00-8:00
  MORNING = 'morning',                  // 8:00-12:00
  NOON = 'noon',                        // 12:00-14:00
  AFTERNOON = 'afternoon',              // 14:00-17:00
  EVENING = 'evening',                  // 17:00-19:00
  NIGHT = 'night',                      // 19:00-22:00
  LATE_NIGHT = 'late_night',            // 22:00-6:00 (限制推荐)
}

enum SemesterPhase {
  SEMESTER_START = 'semester_start',   // 开学期 (前2周)
  REGULAR = 'regular',                  // 常规教学期
  MIDTERM_PREP = 'midterm_prep',        // 期中备考期 (考前3周)
  MIDTERM_WEEK = 'midterm_week',        // 期中考试周
  FINAL_PREP = 'final_prep',            // 期末备考期 (考前4周)
  FINAL_WEEK = 'final_week',            // 期末考试周
  WINTER_BREAK = 'winter_break',        // 寒假
  SUMMER_BREAK = 'summer_break',        // 暑假
  ZHONGKAO_SPRINT = 'zhongkao_sprint', // 中考冲刺期 (最后8周)
  GAOKAO_SPRINT = 'gaokao_sprint',     // 高考冲刺期 (最后8周)
}

enum CognitiveLoad {
  LOW = 'low',           // 轻松，有余力
  MODERATE = 'moderate', // 适中
  HIGH = 'high',         // 较高，需要减负
  OVERLOAD = 'overload', // 过载，应立即降负
}

enum DeviceType {
  PHONE = 'phone',
  TABLET = 'tablet',
  WEB = 'web',
}

interface SignalSource {
  type: 'response_time' | 'answer_pattern' | 'session_behavior' | 'interaction_density';
  description: string;
}
```

```typescript
  // ===== 特殊场景 =====

  LOW_BATTERY_QUICK = 'low_battery_quick',               // 低电量快速学习
  WEAK_NETWORK_OFFLINE = 'weak_network_offline',         // 弱网友好推荐
  NEW_USER_ONBOARDING = 'new_user_onboarding',           // 新用户引导推荐
}

interface SceneDefinition {
  sceneType: SceneType;
  priority: number;              // 场景优先级 1-10 (10最高)
  matchConditions: SceneCondition[];
  contentStrategy: ContentStrategy;
  channelStrategy: ChannelStrategy;
  frequencyLimit: FrequencyLimit;
  cooldownMinutes: number;       // 同场景冷却时间(分钟)
  description: string;
}

interface SceneCondition {
  field: string;                 // SceneContext 中的字段路径
  operator: 'eq' | 'ne' | 'gt' | 'lt' | 'gte' | 'lte' | 'in' | 'between' | 'is_null' | 'not_null';
  value: any;
  logicOp?: 'AND' | 'OR';       // 与下一个条件的逻辑关系
}
```

### 3.3 内容推荐策略 (ContentStrategy)

```typescript
interface ContentStrategy {
  // 内容类型权重分配
  contentTypeWeights: {
    knowledge_review: number;       // 知识点复习
    exercise_practice: number;      // 练习题
    error_retry: number;            // 错题重做
    mock_exam: number;              // // 模拟测试
    reading_material: number;       // 阅读材料
    video_lesson: number;           // 视频课程
    essay_practice: number;         // 作文练习
    recitation_check: number;       // 背诵检测
    knowledge_map: number;          // 知识图谱浏览
    rest_suggestion: number;        // 休息建议
    motivational_content: number;   // 激励内容
  };

  // 难度策略
  difficultyStrategy: {
    targetDifficulty: Difficulty;
    adjustDirection: 'easier' | 'harder' | 'maintain';
    adjustRange: number;            // 调整幅度 ±n
  };

  // 数量策略
  quantityStrategy: {
    recommendedItemCount: number;   // 推荐条目数
    estimatedMinutes: number;       // 预计耗时(分钟)
    allowExtend: boolean;           // 是否允许"查看更多"
  };

  // 学科策略
  subjectStrategy: {
    mode: 'single_subject' | 'cross_subject' | 'weak_first' | 'balanced';
    targetSubject?: Subject;        // 指定学科 (single_subject模式)
    excludeSubjects?: Subject[];    // 排除学科
  };

  // 知识点策略
  knowledgeStrategy: {
    mode: 'weakness_targeted' | 'review_cycle' | 'new_learning' | 'exam_focused' | 'mixed';
    chapterScope?: string[];        // 限定章节范围
    knowledgePointIds?: string[];   // 限定知识点ID
  };

  // 排序策略
  rankingStrategy: {
    primaryFactor: 'urgency' | 'importance' | 'difficulty_asc' | 'difficulty_desc' | 'mastery_asc' | 'random';
    secondaryFactor: 'importance' | 'recency' | 'mastery';
  };
}

enum Difficulty {
  EASY = 'easy',
  MEDIUM_EASY = 'medium_easy',
  MEDIUM = 'medium',
  MEDIUM_HARD = 'medium_hard',
  HARD = 'hard',
}
```

### 3.4 渠道策略 (ChannelStrategy)

```typescript
interface ChannelStrategy {
  primaryChannel: RecommendationChannel;

enum RecommendationChannel {
  HOMEPAGE_BANNER = 'homepage_banner',     // 首页顶部横幅
  HOMEPAGE_CARD = 'homepage_card',         // 首页推荐卡片
  IN_PAGE_BANNER = 'in_page_banner',       // 页面内横幅
  BOTTOM_SHEET = 'bottom_sheet',           // 底部弹窗
  FULL_SCREEN_MODAL = 'full_screen_modal', // 全屏弹窗 (少用，强干预)
  NOTIFICATION_PUSH = 'notification_push', // 推送通知
  IN_APP_MESSAGE = 'in_app_message',       // 站内信
  STUDY_PLAN_INSERT = 'study_plan_insert', // 插入学习计划
  INTERSTITIAL = 'interstitial',           // 插页式 (页面切换间)
  TOAST_TIP = 'toast_tip',                 // 轻提示
}

enum PresentationHint {
  URGENT_ALERT = 'urgent_alert',           // 紧急提醒样式 (红色)
  FRIENDLY_SUGGESTION = 'friendly_suggestion', // 友好建议 (蓝色)
  CELEBRATION = 'celebration',             // 庆祝样式 (彩色动画)
  SUBTLE_HINT = 'subtle_hint',             // 轻量提示 (灰色小字)
  CARD_GRID = 'card_grid',                 // 卡片网格布局
  LIST_VIEW = 'list_view',                 // 列表布局
}

enum ChannelPriority {
  CRITICAL = 1,   // 必须展示 (如深夜保护)
  HIGH = 2,       // 强烈推荐展示

  LOW = 4,        // 软性推荐
}

interface FrequencyLimit {
  maxPerSession: number;          // 单次学习会话最多展示次数
  maxPerDay: number;              // 每日最多展示次数
  minIntervalMinutes: number;     // 最小间隔(分钟)
  perSceneTypeLimit: number;      // 同场景类型每日上限
  globalRecommendationCap: number; // 全局推荐每日上限
}
```

### 4.2 场景优先级仲裁规则

当多个场景同时匹配时，按以下规则仲裁：

1. **保护类场景优先**：`LATE_NIGHT_PROTECTION`、`COGNITIVE_OVERLOAD` 等涉及用户健康的场景无条件最高优先级
2. **干预类场景次之**：`WRONG_STREAK_FRUSTRATION`、`PLAN_DEVIATION_ALERT` 等即时干预
3. **计划类场景第三**：`EXAM_SPRINT`、`DAILY_WARMUP` 等基于计划的推荐
4. **增强类场景最后**：`CORRECT_STREAK_BOOST`、`PEER_COMPARISON` 等锦上添花

仲裁算法：

```java
public SceneDefinition arbitrate(List<SceneDefinition> matchedScenes, SceneContext context) {
    if (matchedScenes.isEmpty()) {
        return getDefaultScene(context);
    }
    
    // 1. 按场景类别优先级分层
    Map<SceneCategory, List<SceneDefinition>> grouped = matchedScenes.stream()
        .collect(Collectors.groupingBy(SceneDefinition::getCategory));
    
    // 2. 取最高优先级类别
    SceneCategory topCategory = SceneCategory.highestPriority(grouped.keySet());
    List<SceneDefinition> topGroup = grouped.get(topCategory);
    
    // 3. 同类别内按 priority 降序，取第一个
    return topGroup.stream()
        .sorted(Comparator.comparingInt(SceneDefinition::getPriority).reversed())
        .findFirst()
        .orElse(getDefaultScene(context));
}
```

```java
@Service
public class SceneContextCollector {

    @Autowired private UserLearningStateService userStateService;
    @Autowired private ExamCalendarService examCalendarService;
    @Autowired private DeviceContextService deviceContextService;
    @Autowired private EmotionSignalEstimator emotionEstimator;
    @Autowired private StudySessionService sessionService;

    /**
     * 采集完整的场景上下文
     */
    public SceneContext collect(String userId) {
        // 并行采集各类信号
        CompletableFuture<UserLearningState> stateFuture = 
            CompletableFuture.supplyAsync(() -> userStateService.getLatestState(userId));
        
        CompletableFuture<ExamInfo> examFuture = 
            CompletableFuture.supplyAsync(() -> examCalendarService.getNextExam(userId));
        
        CompletableFuture<DeviceContext> deviceFuture = 
            CompletableFuture.supplyAsync(() -> deviceContextService.getCurrentDeviceContext(userId));
        
        CompletableFuture<StudySession> sessionFuture = 
            CompletableFuture.supplyAsync(() -> sessionService.getActiveSession(userId));

        CompletableFuture.allOf(stateFuture, examFuture, deviceFuture, sessionFuture).join();

        UserLearningState state = stateFuture.join();
        ExamInfo exam = examFuture.join();
        DeviceContext device = deviceFuture.join();
        StudySession session = sessionFuture.join();

        // 构建时机维度
        TimingContext timing = buildTimingContext(exam, state);
        
        // 构建学习状态维度
        LearningStateContext learningState = buildLearningStateContext(session, state);
        
        // 估算情绪信号
        EmotionSignals emotion = emotionEstimator.estimate(userId, session, state);
        
        // 构建环境维度
        EnvironmentContext env = buildEnvironmentContext(device);
        
        // 构建用户摘要
        UserSummary summary = buildUserSummary(userId);

        return SceneContext.builder()
            .timing(timing)
            .learningState(learningState)
            .emotionSignals(emotion)
            .environment(env)
            .userSummary(summary)
            .build();
    }

    private TimingContext buildTimingContext(ExamInfo exam, UserLearningState state) {
        LocalDateTime now = LocalDateTime.now();
        int dayOfWeek = now.getDayOfWeek().getValue();
        TimeSlot timeSlot = TimeSlot.fromHour(now.getHour());
        
        Long daysToExam = exam != null 
            ? ChronoUnit.DAYS.between(now.toLocalDate(), exam.getExamDate()) 
            : null;
        
        long lastStudyInterval = state.getLastStudyTime() != null
            ? Duration.between(state.getLastStudyTime(), now).toMinutes()
            : Long.MAX_VALUE;

        SemesterPhase phase = SemesterPhaseResolver.resolve(now, state.getGradeLevel());

        return TimingContext.builder()
            .currentTime(now.toString())
            .dayOfWeek(dayOfWeek)
            .timeSlot(timeSlot)
            .daysToNextExam(daysToExam != null ? daysToExam.intValue() : null)
            .daysToNextDeadline(null) // 从计划服务获取
            .lastStudyInterval(lastStudyInterval)
            .semesterPhase(phase)
            .isHoliday(HolidayCalendar.isHoliday(now.toLocalDate()))
            .holidayType(HolidayCalendar.getHolidayType(now.toLocalDate()))
```

### 5.3 情绪信号估算器

情绪信号不依赖生物传感器，而是通过行为特征间接推断：

```java
@Service
public class EmotionSignalEstimator {

    /**
     * 基于行为特征估算学生情绪状态
     * 
     * 输入信号:
     * - response_time: 答题响应时间分布
     * - answer_pattern: 答题正确率变化趋势
     * - session_behavior: 会话行为模式 (快速跳过/反复修改等)
     * - interaction_density: 交互频率 (点击/滑动/停留)
     */
    public EmotionSignals estimate(String userId, StudySession session, UserLearningState state) {
        if (session == null || session.getRecentAnswers() == null) {
            return EmotionSignals.neutral();
        }

        List<AnswerRecord> recent = session.getRecentAnswers();
        
        // 挫败感 = f(连续错误数, 错误密度, 快速提交率)
        double frustration = calculateFrustration(recent);
        
        // 自信心 = f(连续正确数, 平均响应时间适中, 主动挑战难题)
        double confidence = calculateConfidence(recent);
        
        // 无聊感 = f(长时间停留无操作, 重复查看相同内容, 频繁切换)
        double boredom = calculateBoredom(session);
        
        // 置信度 = 样本量充足度
        double signalConfidence = Math.min(1.0, recent.size() / 10.0);

        return EmotionSignals.builder()
            .frustrationLevel(frustration)
            .confidenceLevel(confidence)
            .boredomLevel(boredom)
            .signalSource(buildSignalSources(recent, session))
            .confidence(signalConfidence)
            .build();
    }

    private double calculateFrustration(List<AnswerRecord> recent) {
        if (recent.size() < 3) return 0;
        
        // 最近5题的错误率
        int recentCount = Math.min(5, recent.size());
        long wrongCount = recent.stream()
            .skip(recent.size() - recentCount)
            .filter(a -> !a.isCorrect())
            .count();
        double wrongRate = (double) wrongCount / recentCount;

        // 快速提交率 (答题时间 < 5秒 可能是乱猜)
        double quickSubmitRate = recent.stream()
            .skip(recent.size() - recentCount)
            .filter(a -> a.getTimeSpentSeconds() < 5)
            .count() / (double) recentCount;

        // 综合挫败感评分
        double score = wrongRate * 60 + quickSubmitRate * 40;
        return Math.min(100, Math.max(0, score));
    }

    private double calculateConfidence(List<AnswerRecord> recent) {
        if (recent.size() < 3) return 50;
        
        // 最近5题正确率
        int recentCount = Math.min(5, recent.size());
        long correctCount = recent.stream()
            .skip(recent.size() - recentCount)
            .filter(AnswerRecord::isCorrect)
            .count();
        double correctRate = (double) correctCount / recentCount;

        // 响应时间适中度 (既不太快也不太慢)
        double avgTime = recent.stream()
            .skip(recent.size() - recentCount)
            .mapToInt(AnswerRecord::getTimeSpentSeconds)
            .average().orElse(30);
        double timeScore = 1.0 - Math.abs(avgTime - 30) / 60.0; // 30秒为最佳
        timeScore = Math.max(0, Math.min(1, timeScore));

        double score = correctRate * 70 + timeScore * 30;
        return Math.min(100, Math.max(0, score));
    }

    private double calculateBoredom(StudySession session) {
        // 空闲时间比例 (长时间无操作)
        double idleRatio = session.getIdleSeconds() / (double) session.getDurationSeconds();
        
        // 页面切换频率
        double pageSwitchRate = session.getPageSwitchCount() / 
            Math.max(1, session.getDurationSeconds() / 60.0);
        
        double score = idleRatio * 50 + Math.min(50, pageSwitchRate * 10);
        return Math.min(100, Math.max(0, score));
    }
}
```

```java
@Service
public class RecommendationRanker {

    /**
     * 多策略融合排序
     */
    public List<RecommendationItem> rank(
            List<RecommendationItem> candidates,
            ContentStrategy strategy,
            SceneContext context) {
        
        // 1. 按内容类型权重分配基础分
        for (RecommendationItem item : candidates) {
            double typeWeight = getTypeWeight(item.getItemType(), strategy);
            item.setPriority(item.getPriority() * (float) typeWeight);
        }

        // 2. 主排序因子打分
        applyPrimaryFactor(candidates, strategy.getRankingStrategy().getPrimaryFactor(), context);

        // 3. 次排序因子打分
        applySecondaryFactor(candidates, strategy.getRankingStrategy().getSecondaryFactor(), context);

        // 4. 情绪调节
        applyEmotionAdjustment(candidates, context.getEmotionSignals());

        // 5. 去重和多样性保障
        List<RecommendationItem> deduped = deduplicate(candidates);
        List<RecommendationItem> diversified = ensureDiversity(deduped);

        // 6. 截断到推荐数量
        int count = strategy.getQuantityStrategy().getRecommendedItemCount();
        return diversified.stream()
            .sorted(Comparator.comparingDouble(RecommendationItem::getPriority).reversed())
            .limit(count)
            .collect(Collectors.toList());
    }

    /**
     * 情绪调节：根据学生情绪状态微调推荐排序
     */
    private void applyEmotionAdjustment(
            List<RecommendationItem> items, 
            EmotionSignals emotion) {
        
        if (emotion.getConfidence() < 0.3) return; // 信号置信度太低，不调节

        for (RecommendationItem item : items) {
            // 挫败感高时，降低难题权重
            if (emotion.getFrustrationLevel() > 60) {
                if (item.getDifficulty() == Difficulty.HARD || 
                    item.getDifficulty() == Difficulty.MEDIUM_HARD) {
                    item.setPriority(item.getPriority() * 0.5f);
                }
            }
            
            // 自信心高时，提升挑战内容权重
            if (emotion.getConfidenceLevel() > 70) {
                if (item.getDifficulty() == Difficulty.HARD) {
                    item.setPriority(item.getPriority() * 1.3f);
                }
            }
            
            // 无聊感高时，提升多样化内容权重
            if (emotion.getBoredomLevel() > 60) {
                if (item.getItemType() == ContentType.VIDEO_LESSON ||
                    item.getItemType() == ContentType.KNOWLEDGE_MAP) {
                    item.setPriority(item.getPriority() * 1.2f);
                }
            }
        }
    }

    /**
     * 多样性保障：避免同一知识点/同一题型集中出现
     */
    private List<RecommendationItem> ensureDiversity(List<RecommendationItem> items) {
        List<RecommendationItem> result = new ArrayList<>();
        Set<String> usedKnowledgePoints = new HashSet<>();
        Map<ContentType, Integer> typeCount = new HashMap<>();
        int maxPerType = 3; // 同类型最多3个

        for (RecommendationItem item : items.stream()
                .sorted(Comparator.comparingDouble(RecommendationItem::getPriority).reversed())
                .collect(Collectors.toList())) {
            
            // 同类型限制
            int count = typeCount.getOrDefault(item.getItemType(), 0);
            if (count >= maxPerType) continue;

            // 知识点去重 (允许最多2个相同知识点)
            long overlap = item.getKnowledgePointIds().stream()
                .filter(usedKnowledgePoints::contains)
                .count();
            if (overlap > 1) continue;

            result.add(item);
            typeCount.merge(item.getItemType(), 1, Integer::sum);
            usedKnowledgePoints.addAll(item.getKnowledgePointIds());
        }

        return result;
    }
}
```

### 7.2 Redis 频控实现

```java
@Service
public class RecommendationFrequencyController {

    @Autowired private StringRedisTemplate redis;

    private static final String KEY_DAILY_GLOBAL = "rec:freq:%s:daily:%s";     // userId, date
    private static final String KEY_DAILY_SCENE  = "rec:freq:%s:scene:%s:%s";   // userId, sceneType, date
    private static final String KEY_SESSION      = "rec:freq:%s:session:%s";    // userId, sessionId
    private static final String KEY_COOLDOWN     = "rec:cooldown:%s:%s";        // userId, sceneType
    private static final String KEY_LAST_SHOW    = "rec:lastshow:%s:%s";        // userId, sceneType

    /**
     * 检查是否可以展示推荐
     */
    public FrequencyCheckResult check(
            String userId, 
            String sessionId,
            SceneDefinition scene) {
        
        String today = LocalDate.now().toString();
        
        // 1. 全局每日上限
        String globalKey = String.format(KEY_DAILY_GLOBAL, userId, today);
        Long globalCount = redis.opsForValue().increment(globalKey);
        if (globalCount == 1) redis.expire(globalKey, Duration.ofDays(1));
        if (globalCount > scene.getFrequencyLimit().getGlobalRecommendationCap()) {
            redis.opsForValue().decrement(globalKey); // 回滚
            return FrequencyCheckResult.reject("全局推荐已达每日上限");
        }

        // 2. 场景类型每日上限
        String sceneKey = String.format(KEY_DAILY_SCENE, userId, scene.getSceneType(), today);
        Long sceneCount = redis.opsForValue().increment(sceneKey);
        if (sceneCount == 1) redis.expire(sceneKey, Duration.ofDays(1));
        if (sceneCount > scene.getFrequencyLimit().getPerSceneTypeLimit()) {
            redis.opsForValue().decrement(sceneKey);
            redis.opsForValue().decrement(globalKey);
            return FrequencyCheckResult.reject("场景类型已达每日上限");
        }

        // 3. 会话内上限
        if (sessionId != null) {
            String sessionKey = String.format(KEY_SESSION, userId, sessionId);
            Long sessionCount = redis.opsForValue().increment(sessionKey);
            if (sessionCount == 1) redis.expire(sessionKey, Duration.ofHours(4));
            if (sessionCount > scene.getFrequencyLimit().getMaxPerSession()) {
                redis.opsForValue().decrement(sessionKey);
                redis.opsForValue().decrement(sceneKey);
                redis.opsForValue().decrement(globalKey);
                return FrequencyCheckResult.reject("会话内已达上限");
            }
        }

        // 4. 冷却期检查
        String cooldownKey = String.format(KEY_COOLDOWN, userId, scene.getSceneType());
        if (Boolean.TRUE.equals(redis.hasKey(cooldownKey))) {
            long ttl = redis.getExpire(cooldownKey);
            // 回滚计数
            redis.opsForValue().decrement(sceneKey);
            redis.opsForValue().decrement(globalKey);
            if (sessionId != null) {
                redis.opsForValue().decrement(String.format(KEY_SESSION, userId, sessionId));
            }
            return FrequencyCheckResult.reject("场景冷却中，剩余" + ttl + "秒");
        }

        // 5. 设置冷却
        redis.opsForValue().set(
            cooldownKey, 
            String.valueOf(System.currentTimeMillis()),
            Duration.ofMinutes(scene.getCooldownMinutes())
        );

        return FrequencyCheckResult.allow();
    }
}
```

```java
public void autoTuneStrategyWeights() {
    List<String> sceneTypes = sceneRuleRepository.getAllSceneTypes();
    
    for (String sceneType : sceneTypes) {
        // 获取过去4周数据
        SceneEffectStats stats = analyticsService.getSceneStats(sceneType, 28);
        
        if (stats.getSampleSize() < 100) continue; // 样本不足跳过
        
        // 基于效果指标调整策略
        StrategyAdjustment adj = StrategyAdjustmentBuilder.create()
            // 点击率低于均值 → 降低内容数量或调整难度
            .ifCtrBelow(stats.getCtr(), stats.getBaselineCtr(), 0.5,
                s -> s.adjustDifficultyDown().reduceItemCount())
            // 完成率低 → 内容太难或太多
            .ifCompletionRateBelow(stats.getCompletionRate(), 0.5,
                s -> s.adjustDifficultyDown().reduceItemCount())
            // 推荐疲劳度高 → 降低频率
            .ifFatigueHigh(stats.getFatigueRate(), 0.4,
                s -> s.increaseCooldown().decreaseDailyLimit())
            // 点击率和完成率都高 → 可适当增加频率
            .ifHighPerformance(stats.getCtr(), stats.getCompletionRate(),
                s -> s.slightlyIncreaseFrequency())
            .build();
        
        if (adj.hasChanges()) {
            sceneRuleService.applyAdjustment(sceneType, adj);
            log.info("自动调优: sceneType={}, changes={}", sceneType, adj.getChangesSummary());
        }
```

## 10. 缓存策略

### 10.1 多级缓存设计

```
L1 - 客户端缓存 (TTL: 5分钟)
  │ 缓存最近一次推荐结果，避免短时间内重复请求
  │
L2 - Redis 场景规则缓存 (TTL: 10分钟)
  │ 缓存所有启用的场景规则配置，后台修改后主动失效
  │
L3 - Redis 用户上下文缓存 (TTL: 2分钟)
  │ 缓存用户学习状态、情绪信号等，减少服务调用
  │
L4 - 本地 Caffeine 推荐候选缓存 (TTL: 5分钟)
    缓存推荐候选题目/内容列表，同一用户短时间内不重复查询
```

### 10.2 缓存更新策略

```java
// 场景规则修改后主动刷新缓存
@EventListener
public void onSceneRuleUpdated(SceneRuleUpdatedEvent event) {
    // 清除规则缓存
    String ruleKey = "scene:rules:active";
    redis.delete(ruleKey);
    
    // 清除所有用户的推荐结果缓存 (因为规则变了)
    Set<String> keys = redis.keys("scene:rec:result:*");
    if (keys != null && !keys.isEmpty()) {
        redis.delete(keys);
    }
    
    log.info("场景规则更新，已刷新缓存, ruleId={}, sceneType={}", 
        event.getRuleId(), event.getSceneType());
}
```

## 11. 异常处理与降级策略

### 11.1 异常分级与处理

| 异常场景 | 处理策略 | 降级方案 |
|---------|---------|---------|
| 用户学习状态服务不可用 | 等待 500ms 超时 | 使用缓存数据，标记为低置信度 |
| 情绪信号估算失败 | 跳过情绪维度 | 使用默认中性情绪值 |
| 考试日历服务不可用 | daysToNextExam = null | 不触发考试相关场景 |
| 候选集获取超时 | 使用已获取的部分结果 | 不足时用通用推荐补齐 |
| Redis 频控不可用 | 放行推荐 (fail-open) | 记录日志，标记需人工核查 |
| 规则引擎执行异常 | 捕获异常，返回默认推荐 | 默认推荐 = 基础每日推荐 |
| 全部依赖不可用 | 返回空推荐 | 客户端展示默认首页内容 |

### 12.3 客户端侧缓存策略

```dart
class RecommendationCache {
  static const Duration _cacheTtl = Duration(minutes: 5);
  RecommendationResult? _cached;
  DateTime? _cachedAt;

  RecommendationResult? get() {
    if (_cached == null || _cachedAt == null) return null;
    if (DateTime.now().difference(_cachedAt!) > _cacheTtl) {
      _cached = null;
      return null;
    }
    // 检查推荐是否过期
    if (DateTime.now().isAfter(_cached!.expireAt)) {
      _cached = null;
      return null;
    }
    return _cached;
  }

  void set(RecommendationResult result) {
    _cached = result;
    _cachedAt = DateTime.now();
  }

  void clear() {
    _cached = null;
    _cachedAt = null;
  }
}
```

## 14. 安全与合规

### 14.1 数据安全

- 场景上下文中不包含明文敏感信息（手机号、真实姓名等）
- 推荐日志中用户ID做脱敏处理
- 管理后台场景规则变更需双人审核

- 推荐内容必须经过适龄过滤
- 情绪信号数据不长期存储，24小时自动清除
- 家长模式可查看推荐历史
