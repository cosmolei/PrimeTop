# 客户端-学习专注模式与全局防打扰智能调度引擎-详细设计

## 1. 概述

### 1.1 功能定位

学习专注模式（Focus Mode）是 PrimeTop 客户端核心学习体验保障能力之一。当学生进入学习会话（AI 辅导、同步课堂、练习测评、错题复习等）时，系统自动或手动激活专注模式，屏蔽非必要的通知弹窗、运营消息、社交互动等干扰源，为学生创造沉浸式学习环境。

同时，专注模式提供家长可控的"白名单紧急联系人"机制，确保安全通道不被切断。

### 1.2 设计目标

| 目标 | 说明 |
|------|------|
| **沉浸保障** | 学习期间 0 非必要 UI 打断 |
| **灵活可控** | 用户/家长可自定义屏蔽策略 |
| **安全兜底** | 紧急联系人和系统级安全通道不被屏蔽 |
| **无缝衔接** | 专注模式与番茄钟、学习计时器深度联动 |
| **数据可溯** | 记录每次专注会话的打断事件和屏蔽日志 |
| **跨场景一致** | 在 AI 对话、阅读、练习、复习等场景行为一致 |

### 1.3 适用范围

- **平台**：Flutter 客户端（Android / iOS）
- **学段**：全学段（幼儿段由家长配置，小学以上可自主配置）
- **关联模块**：学习计时器与番茄钟、通知中心、运营弹窗系统、消息推送、防沉迷系统

### 1.4 术语定义

| 术语 | 定义 |
|------|------|
| FocusSession | 一次专注学习会话，从激活到结束的完整周期 |
| Interruption | 专注期间的打断事件（通知、弹窗、来电等） |
| ShieldRule | 屏蔽规则，定义哪些事件应被屏蔽 |
| BypassChannel | 白名单通道，定义哪些事件可穿透屏蔽 |
| FocusProfile | 专注配置档案，包含屏蔽规则和白名单 |

```dart
/// 专注配置档案
class FocusProfile {
  final String profileId;
  final String name;                    // 档案名称：如"标准模式"、"考试冲刺"
  final FocusLevel level;               // 屏蔽强度等级
  final Set<ShieldTarget> shieldTargets; // 屏蔽目标集合
  final Set<BypassRule> bypassRules;    // 白名单穿透规则

  final bool allowBreaks;               // 是否允许中途休息

  final bool parentLocked;              // 家长锁定（学生不可修改）

  final DateTime updatedAt;

enum FocusLevel {
  /// 轻度屏蔽：仅屏蔽运营弹窗和非学习推送

  deep,
  /// 极致屏蔽：全屏蔽模式，仅系统安全告警可穿透
  extreme,
}
```

### 3.3 FocusModeEngine 核心接口

```dart
/// 专注模式引擎 - 对外统一接口
abstract class FocusModeEngine {
  /// 获取当前活跃的专注会话（null 表示无活跃会话）
  FocusSession? get currentSession;

  /// 获取当前专注状态流
  Stream<FocusSession?> get sessionStream;

  /// 激活专注模式
  ///
  /// [scene] - 触发场景
  /// [profileId] - 使用的配置档案ID（null则使用场景默认档案）
  /// [duration] - 计划专注时长（null则使用档案默认值）
  /// [context] - 场景上下文信息
  Future<FocusSession> activate({
    required FocusScene scene,
    String? profileId,
    Duration? duration,
    String? context,
  });

  /// 暂停专注（开始休息或用户手动暂停）
  Future<void> pause({required bool isBreak});

  /// 恢复专注
  Future<void> resume();

  /// 结束专注
  ///
  /// [reason] - 结束原因
  /// [satisfactionScore] - 用户主观评分（可选）
  Future<FocusSession> end({
    required FocusEndReason reason,
    int? satisfactionScore,
  });

  /// 评估通知是否应被屏蔽
  ///
  /// 返回: ShieldAction.blocked / .bypassed / .delayed
  ShieldAction evaluate(NotificationEvent event);

  /// 获取专注配置档案列表
  List<FocusProfile> getProfiles();

  /// 创建/更新专注配置档案
  Future<FocusProfile> saveProfile(FocusProfile profile);

  /// 删除专注配置档案
  Future<void> deleteProfile(String profileId);

  /// 获取专注历史记录
  Future<List<FocusSession>> getHistory({
    DateTime? startDate,
    DateTime? endDate,
    int limit = 50,
  });

  /// 获取专注统计
  Future<FocusStats> getStats({DateTime? startDate, DateTime? endDate});

  /// 家长远程控制：激活/结束孩子的专注模式
  Future<void> remoteControl({
    required String childUserId,
    required RemoteAction action,
  });
}

enum RemoteAction { activate, end, pause }
```

**状态转换规则：**

```dart
/// 专注会话状态机实现
class FocusStateMachine {
  final FocusSessionState _state = FocusSessionState.ended;

  static const Map<FocusSessionState, Set<FocusSessionState>> _transitions = {
    FocusSessionState.active: {
      FocusSessionState.onBreak,
      FocusSessionState.paused,
      FocusSessionState.ending,
    },
    FocusSessionState.onBreak: {
      FocusSessionState.active,
      FocusSessionState.ending,
    },
    FocusSessionState.paused: {
      FocusSessionState.active,
      FocusSessionState.ending,
    },
    FocusSessionState.ending: {
      FocusSessionState.ended,
    },
    FocusSessionState.ended: {},
  };

  bool canTransition(FocusSessionState from, FocusSessionState to) {
    return _transitions[from]?.contains(to) ?? false;
  }

  void transition(FocusSession session, FocusSessionState newState) {
    if (!canTransition(session.state, newState)) {
      throw FocusModeException(
        '非法状态转换: ${session.state} -> $newState',
        code: 'INVALID_STATE_TRANSITION',
      );
    }
    session.state = newState;
    _logStateChange(session, newState);
  }
}
```

### 4.2 屏蔽决策引擎（ShieldDecision）

屏蔽决策引擎是核心组件，负责对每个进入的通知/弹窗/推送做出实时决策。

#### 4.2.1 决策流程

```
通知/弹窗/推送到达
        │
        ▼
┌───────────────────┐
│ 1. 提取事件特征     │
│ (来源、类型、优先级) │
└───────┬───────────┘
        │
        ▼

        │
   ┌────┴────┬─────────┐
```

#### 4.2.2 决策器实现

```dart
class ShieldDecisionEngine {
  final FocusProfile _profile;
  final BypassEvaluator _bypassEvaluator;

  ShieldDecision evaluate(IncomingEvent event) {
    // Step 1: 白名单优先评估
    final bypassResult = _bypassEvaluator.evaluate(event, _profile.bypassRules);
    if (bypassResult.shouldBypass) {
      return ShieldAction.bypassed;
    }

    // Step 2: 检查是否在屏蔽目标范围内
    final target = _mapEventToTarget(event);
    if (target == null || !_profile.shieldTargets.contains(target)) {
      return ShieldAction.notApplicable;
    }

    // Step 3: 根据专注等级决定处理方式
    switch (_profile.level) {
      case FocusLevel.light:
        // 轻度：仅屏蔽运营弹窗和营销推送
        if (target == ShieldTarget.operationPopup ||
            target == ShieldTarget.marketingPush) {
          return ShieldAction.blocked;
        }
        return ShieldAction.notApplicable;

      case FocusLevel.standard:
        // 标准：屏蔽所有目标，但延迟成就弹窗
        if (target == ShieldTarget.achievementPopup) {
          return ShieldAction.delayed;
        }
        return ShieldAction.blocked;

      case FocusLevel.deep:
        // 深度：屏蔽所有社交和推荐，延迟成就和报告
        if (target == ShieldTarget.achievementPopup ||
            target == ShieldTarget.weeklyReport) {
          return ShieldAction.delayed;
        }
        return ShieldAction.blocked;

      case FocusLevel.extreme:
        // 极致：全部屏蔽（白名单除外）
        return ShieldAction.blocked;
    }
  }

  /// 将事件映射到屏蔽目标枚举
  ShieldTarget? _mapEventToTarget(IncomingEvent event) {
    switch (event.source) {
      case EventSource.operationPopup:
        return ShieldTarget.operationPopup;
      case EventSource.marketingPush:
        return ShieldTarget.marketingPush;
      case EventSource.systemNotification:
        if (_isUrgentSystemNotification(event)) {
          return null; // 紧急系统通知不屏蔽
        }
        return ShieldTarget.systemNotification;
      case EventSource.socialMessage:
        return ShieldTarget.socialMessage;
      case EventSource.peerInteraction:
        return ShieldTarget.peerInteraction;
      case EventSource.achievementUnlock:
        return ShieldTarget.achievementPopup;
      case EventSource.recommendation:
        return ShieldTarget.recommendationCard;
      case EventSource.appUpdate:
        return ShieldTarget.updatePrompt;
      case EventSource.feedbackSurvey:
        return ShieldTarget.feedbackPrompt;
      case EventSource.learningUrgent:
        // 学习紧急事件（作业截止等）- 检查是否在白名单
        return null;
      default:
        return null;
    }
  }

  bool _isUrgentSystemNotification(IncomingEvent event) {
    // 心理危机预警、安全告警等
    return event.priority == EventPriority.critical ||
           event.tags?.contains('safety_alert') == true;
  }
}
```

### 4.3 白名单评估器（BypassEvaluator）

```dart
class BypassEvaluator {
  /// 评估事件是否应穿透屏蔽
  BypassResult evaluate(IncomingEvent event, Set<BypassRule> rules) {
    // 按优先级排序规则
    final sortedRules = rules.toList()
      ..sort((a, b) => b.priority.compareTo(a.priority));

    for (final rule in sortedRules) {
      if (_matchesRule(event, rule)) {
        return BypassResult(shouldBypass: true, matchedRule: rule);
      }
    }

    return BypassResult(shouldBypass: false);
  }

  bool _matchesRule(IncomingEvent event, BypassRule rule) {
    switch (rule.type) {
      case BypassType.emergencyContact:
        // 家长来电/消息穿透
        return _isFromEmergencyContact(event, rule.conditions);

      case BypassType.systemSafety:
        // 系统安全告警穿透
        return event.priority == EventPriority.critical &&
               event.tags?.contains('safety') == true;

      case BypassType.learningUrgent:
        // 学习紧急事件（作业即将截止等）
        return event.source == EventSource.learningUrgent &&
               _withinUrgencyWindow(event, rule.conditions);

      case BypassType.parentCommand:
        // 家长远程指令总是穿透
        return event.source == EventSource.parentControl;

      case BypassType.timerComplete:
        // 番茄钟/计时器完成
        return event.source == EventSource.timer &&
               event.type == EventType.timerComplete;
    }
  }

  bool _isFromEmergencyContact(IncomingEvent event, Map<String, dynamic> conditions) {
    final contactIds = conditions['contact_ids'] as List<dynamic>?;
    if (contactIds == null) return false;

    // 检查来电/消息是否来自紧急联系人
    final senderId = event.metadata?['sender_id'] as String?;
    return senderId != null && contactIds.contains(senderId);
  }

  bool _withinUrgencyWindow(IncomingEvent event, Map<String, dynamic> conditions) {
    final windowMinutes = conditions['urgency_window_minutes'] as int? ?? 60;
    final deadline = event.metadata?['deadline'] as DateTime?;
    if (deadline == null) return false;

    return deadline.difference(DateTime.now()).inMinutes < windowMinutes;
  }
}

class BypassResult {
  final bool shouldBypass;
  final BypassRule? matchedRule;
  BypassResult({required this.shouldBypass, this.matchedRule});
}
```

#### 4.4.1 应用内通知拦截

```dart
/// 应用内通知拦截器 - 挂载在通知中心分发管道上
class InAppNotificationInterceptor implements NotificationDispatcher {
  final FocusModeEngine _focusEngine;
  final NotificationDispatcher _downstreamDispatcher;
  final EventLogger _eventLogger;

  @override
  Future<void> dispatch(NotificationEvent event) async {
    final session = _focusEngine.currentSession;

    // 无活跃专注会话，直接分发
    if (session == null) {
      await _downstreamDispatcher.dispatch(event);
      return;
    }

    // 专注会话活跃，进行屏蔽决策
    final action = _focusEngine.evaluate(event);

    // 记录事件日志
    _eventLogger.log(FocusEvent(
      eventId: _generateId(),
      timestamp: DateTime.now(),
      type: _mapNotificationToEventType(event),
      source: event.source.value,
      description: event.title,
      action: action,
      metadata: event.toMap(),
    ));

    switch (action) {
      case ShieldAction.blocked:
        // 屏蔽：不展示，加入待显示队列
        _addToPendingQueue(event);
        break;

      case ShieldAction.delayed:
        // 延迟：专注结束后展示
        _addToDelayedQueue(event);
        break;

      case ShieldAction.bypassed:
        // 白名单放行：立即展示
        await _downstreamDispatcher.dispatch(event);
        break;

      case ShieldAction.userDecided:
        // 需要用户决定：展示静默横幅（非弹窗）
        _showSilentBanner(event);
        break;

      case ShieldAction.notApplicable:
        // 不适用：正常展示
        await _downstreamDispatcher.dispatch(event);
        break;
    }
  }

  /// 待显示队列（专注结束后批量展示）
  final List<NotificationEvent> _pendingQueue = [];

  void _addToPendingQueue(NotificationEvent event) {
    _pendingQueue.add(event);
    // 限制队列大小，避免积压过多
    if (_pendingQueue.length > 50) {
      _pendingQueue.removeRange(0, _pendingQueue.length - 50);
    }
  }

  final List<NotificationEvent> _delayedQueue = [];

  void _addToDelayedQueue(NotificationEvent event) {
    _delayedQueue.add(event);
  }

  /// 专注会话结束时，flush 所有待显示和延迟队列
  Future<void> flushPendingNotifications() async {
    if (_pendingQueue.isEmpty && _delayedQueue.isEmpty) return;

    // 合并并去重
    final allPending = [..._pendingQueue, ..._delayedQueue];
    _pendingQueue.clear();
    _delayedQueue.clear();

    // 智能合并：同一来源的多条通知合并为摘要
    final merged = _mergeNotifications(allPending);

    // 按优先级排序后展示
    merged.sort((a, b) => b.priority.index.compareTo(a.priority.index));

    for (final event in merged.take(10)) { // 最多展示10条
      await _downstreamDispatcher.dispatch(event);
    }

    if (merged.length > 10) {
      // 展示"还有N条通知"摘要
      _showSummaryNotification(merged.length - 10);
    }
  }

  /// 静默横幅展示（不打断当前学习，但告知用户有通知）
  void _showSilentBanner(NotificationEvent event) {
    // 在页面顶部展示非模态横幅，3秒后自动消失
    // 用户可下拉查看详情，但不会强制中断学习
    SilentBannerController.show(
      title: event.title,
      subtitle: '专注模式中 - 点击查看',
      duration: const Duration(seconds: 3),
      onTap: () => _downstreamDispatcher.dispatch(event),
    );
  }
}
```

### 4.5 休息调度器（BreakScheduler）

```dart
/// 专注期间的休息调度器
class BreakScheduler {
  final FocusModeEngine _engine;
  final FocusProfile _profile;
  Timer? _breakTimer;
  Timer? _workTimer;
  int _completedWorkBlocks = 0;

  /// 启动工作-休息循环
  void startWorkBreakCycle() {
    if (!_profile.allowBreaks) return;
    _startWorkBlock();
  }

  void _startWorkBlock() {
    _workTimer?.cancel();
    _workTimer = Timer(_profile.breakInterval, () {
      _completedWorkBlocks++;
      _startBreak();
    });
  }

  void _startBreak() {
    _engine.pause(isBreak: true);
    
    // 发送通知提醒休息开始
    _showBreakStartNotification();

    _breakTimer?.cancel();
    _breakTimer = Timer(_profile.breakDuration, () {
      _engine.resume();
      _showBreakEndNotification();
      _startWorkBlock(); // 开始下一个工作块
    });
  }

  /// 手动延长休息
  void extendBreak(Duration extra) {
    _breakTimer?.cancel();
    _breakTimer = Timer(_profile.breakDuration + extra, () {
      _engine.resume();
      _startWorkBlock();
    });
  }

  /// 跳过休息，继续专注
  void skipBreak() {
    _breakTimer?.cancel();
    _engine.resume();
    _startWorkBlock();
  }

  void dispose() {
    _workTimer?.cancel();
    _breakTimer?.cancel();
  }

  void _showBreakStartNotification() {
    // 使用静默横幅而非弹窗
    SilentBannerController.show(
      title: '休息时间到啦 ☕',
      subtitle: '放松 ${_profile.breakDuration.inMinutes} 分钟再继续吧',
      duration: const Duration(seconds: 5),
    );
  }

  void _showBreakEndNotification() {
    SilentBannerController.show(
      title: '休息结束，继续加油 💪',
      subtitle: '下一个专注周期开始',
      duration: const Duration(seconds: 3),
```

```dart
/// 专注模式自动激活管理器
class AutoFocusActivator {
  final FocusModeEngine _engine;
  final ProfileManager _profileManager;

  /// 场景到配置档案的映射
  final Map<FocusScene, String> _sceneProfileMap = {};

  /// 根据学习场景自动激活专注模式
  Future<void> onSceneEntered(FocusScene scene, {String? context}) async {
    // 1. 检查是否已有活跃会话
    if (_engine.currentSession != null) {
      // 已有活跃会话，不重复激活
      return;
    }

    // 2. 检查用户是否启用了自动激活
    final globalSetting = await _profileManager.getGlobalSetting(
      'auto_focus_enabled',
      defaultValue: true,
    );
    if (!globalSetting) return;

    // 3. 获取场景对应的默认配置档案
    final profileId = _sceneProfileMap[scene] ?? 'default_standard';
    final profile = await _profileManager.getProfile(profileId);
    if (profile == null || !profile.autoActivate) return;

    // 4. 检查时间段是否适合自动激活
    if (!_shouldAutoActivateNow(scene)) return;

    // 5. 激活专注模式
    await _engine.activate(
      scene: scene,
      profileId: profileId,
      context: context,
    );
  }

  bool _shouldAutoActivateNow(FocusScene scene) {
    final now = DateTime.now();

    // 深夜不自动激活（22:00 - 07:00）
    if (now.hour >= 22 || now.hour < 7) return false;

    // 周末白天降低自动激活概率（避免过度干扰）
    // 仅在用户有明确学习计划时激活
    if (now.weekday == DateTime.saturday || now.weekday == DateTime.sunday) {
      return scene == FocusScene.examSimulation ||
             scene == FocusScene.mistakeReview;
    }

    return true;
  }

  /// 学习场景结束时自动结束专注
  Future<void> onSceneExited(FocusScene scene) async {
    final session = _engine.currentSession;
    if (session == null) return;

    // 只自动结束由该场景自动激活的会话
    if (session.trigger == FocusTrigger.auto && session.scene == scene) {
      await _engine.end(reason: FocusEndReason.userManual);
    }
  }
}
```

## 7. 错误处理与异常恢复

### 7.1 异常场景与处理策略

| 异常场景 | 处理策略 | 错误码 |
|---------|---------|--------|
| 专注会话激活时系统DND权限缺失 | 降级为应用内屏蔽模式，提示用户授权 | `FOCUS_DND_NO_PERMISSION` |
| 专注会话进行中App被杀死 | 下次启动时检测未完成的会话，标记为`ended(endReason: appKilled)` | `FOCUS_SESSION_INTERRUPTED` |
| 专注会话进行中App进入后台超时 | 超过5分钟后台自动结束会话 | `FOCUS_BACKGROUND_TIMEOUT` |
| 专注会话进行中低电量（<15%） | 发出低电量提醒，30分钟后自动结束 | `FOCUS_LOW_BATTERY` |
| 服务端上报失败 | 本地保留未同步标记，下次启动时重试同步 | `FOCUS_SYNC_FAILED` |
| 用户频繁尝试退出（3次以上） | 强制展示"确定要结束专注吗？"确认对话框 | `FOCUS_EXIT_WARNING` |
| 家长远程激活但孩子离线 | 记录指令，孩子下次上线时执行 | `FOCUS_REMOTE_QUEUED` |
| Profile 配置冲突（家长锁定vs学生修改） | 家长锁定配置优先 | `FOCUS_PROFILE_LOCKED` |

### 7.2 异常恢复流程

```dart
class FocusRecoveryHandler {
  /// App启动时检查未完成的专注会话
  Future<void> checkAndRecoverInterruptedSessions() async {
    final db = FocusDatabase.instance;

    // 查找状态仍为 active/paused/onBreak 的会话
    final interrupted = await db.getSessionsByStates([
      FocusSessionState.active,
      FocusSessionState.paused,
      FocusSessionState.onBreak,
    ]);

    for (final session in interrupted) {
      // 计算中断时长
      final lastEvent = session.events.last;
      final interruptDuration = DateTime.now().difference(lastEvent.timestamp);

      if (interruptDuration > const Duration(minutes: 30)) {
        // 超过30分钟，自动标记为中断结束
        await _endInterruptedSession(session, FocusEndReason.appBackground);
      } else if (interruptDuration > const Duration(minutes: 5)) {
        // 5-30分钟，标记为系统中断
        await _endInterruptedSession(session, FocusEndReason.systemInterrupt);
      }
      // 5分钟内，不处理（可能是正常的短暂后台切换）
    }
  }

  Future<void> _endInterruptedSession(
    FocusSession session,
    FocusEndReason reason,
  ) async {
    final db = FocusDatabase.instance;

    session.endTime = DateTime.now();
    session.endReason = reason;
    session.state = FocusSessionState.ended;

    // 计算实际专注时长（排除中断后的时间）
    final lastEventTime = session.events.last.timestamp;
    session.actualFocusDuration = lastEventTime.difference(session.startTime);

    await db.updateSession(session);

    // 上报到服务端
    await AnalyticsReporter.reportSession(session);
  }
}
```

## 8. 性能优化

### 8.1 关键性能指标

| 指标 | 目标 |
|------|------|
| 屏蔽决策延迟 | < 5ms（同步调用，不能阻塞UI） |
| 会话状态切换延迟 | < 50ms |
| 事件日志写入延迟 | < 10ms（异步写入SQLite） |
| 会话数据上报 | 异步批量，不阻塞UI |
| 内存占用增量 | < 5MB（专注引擎常驻内存） |

### 8.2 优化策略

```dart
class FocusPerformanceOptimizer {
  // 1. 屏蔽规则预编译：Profile加载时编译为高效匹配函数
  ShieldMatcher _precompileMatcher(FocusProfile profile) {
    final targets = profile.shieldTargets;
    final bypassRules = profile.bypassRules.toList()
      ..sort((a, b) => b.priority.compareTo(a.priority));

    // 返回编译后的快速匹配器
    return ShieldMatcher(
      targetSet: targets,  // Set查找 O(1)
      bypassEvaluators: bypassRules.map((r) => _compileBypassRule(r)).toList(),
    );
  }

  // 2. 事件日志批量写入
  final List<FocusEvent> _pendingLogs = [];
  Timer? _flushTimer;

  void logEvent(FocusEvent event) {
    _pendingLogs.add(event);
    // 批量写入：每2秒或积累20条时flush
    _flushTimer ??= Timer.periodic(const Duration(seconds: 2), (_) {
      _flushLogs();
    });
    if (_pendingLogs.length >= 20) {
      _flushLogs();
    }
  }

  Future<void> _flushLogs() async {
    if (_pendingLogs.isEmpty) return;
    final batch = List<FocusEvent>.from(_pendingLogs);
    _pendingLogs.clear();
    _flushTimer?.cancel();
    _flushTimer = null;

    // 批量插入SQLite
    await FocusDatabase.instance.batchInsertEvents(batch);
  }

  // 3. 会话数据延迟同步：WiFi且空闲时上报
  void scheduleSessionSync() {
    // 使用 WorkManager 注册延迟任务
    WorkManager.instance.registerOneTimeTask(
      'focus_session_sync',
      constraints: WorkConstraints(
        networkType: NetworkType.unmetered,  // WiFi环境
        requiresDeviceIdle: true,            // 设备空闲时
      ),
    );
  }
}
```

### 9.2 隐私保护

```dart
class FocusPrivacyGuard {
  /// 上报前脱敏处理
  Map<String, dynamic> sanitizeForReport(FocusSession session) {
    return {
      'session_id': session.sessionId,
      'profile_level': session.profile.level.name,
      'scene': session.scene.name,
      // 不上报具体通知内容，只上报类型和动作
      'events': session.events.map((e) => {
        'type': e.type.name,
        'action': e.action.name,
        'timestamp': e.timestamp.toIso8601String(),
        // 移除 source 和 description（可能含敏感信息）
      }).toList(),
      // 专注时长和效率数据
      'focus_duration_sec': session.actualFocusDuration.inSeconds,
      'efficiency': _calculateEfficiency(session),
    };
  }

  /// 检查家长远程控制权限
  Future<bool> validateParentControl(
    String parentUserId,
    String childUserId,
    RemoteAction action,
  ) async {
    // 1. 验证绑定关系
    final binding = await ParentBindingService.getBinding(parentUserId, childUserId);
    if (binding == null) return false;

    // 2. 检查家长是否有管控权限
    if (!binding.hasPermission(ParentPermission.focusControl)) return false;

    // 3. 检查孩子是否在可控制时间段
    if (!_isWithinControlWindow(binding)) return false;

    return true;
  }
}
```

### 9.3 合规要点

1. **通知内容不上报**：屏蔽决策日志仅记录事件类型和处理动作，不记录通知内容
2. **紧急通道保障**：无论专注等级如何，家长来电和系统安全告警始终穿透
3. **家长可审计**：家长可查看孩子的专注模式使用报告，但不可查看被屏蔽的具体通知内容
4. **学生反骚扰**：学生可在设置中关闭自动激活，但家长锁定的配置不可被学生修改
5. **数据保留策略**：专注事件日志本地保留30天，服务端保留180天
