# 教育内容用户评价体系与口碑驱动的质量迭代引擎 — 详细设计

## 1. 概述

### 1.1 模块定位

本引擎负责 PrimeTop 平台中**用户对教育内容的评价反馈**全链路处理，包括结构化评分、文字评论、好评/差评信号采集、口碑聚合分析以及由口碑数据驱动的内容质量迭代闭环。

与现有模块的边界划分：

| 模块 | 关注点 | 与本引擎区别 |
| --- | --- | --- |
| 教育内容质量自动评估引擎 | 机器自动检测低质内容（文本质量、知识覆盖等） | 本引擎聚焦**用户主观评价**，是人工/UUE 驱动的质量信号 |
| 教学内容用户纠错反馈引擎 | 用户报告具体错误（知识点错误、解析有误等） | 纠错是**bug级反馈**；评价是**体验级反馈**（好不好懂、有没有帮助） |
| AI回答质量监控引擎 | 监控AI对话回答的质量 | 本引擎覆盖所有教育内容（课程、章节、练习、考点专题等），不限于AI输出 |
| 用户反馈与AI质量评估 | AI对话质量抽样审核与用户评价 | 本引擎面向**结构化教育内容**的评价，非AI对话 |

### 1.2 核心职责

1. **评价采集**：提供多维度评分、文字评论、快速标签评价等采集能力
2. **评价审核**：对文字评论进行内容安全过滤与质量审核
3. **口碑聚合**：按内容维度（课程/章节/知识点/学科）聚合评分与评论
4. **质量评分计算**：综合多维度信号计算内容的口碑质量分
5. **质量预警**：对口碑下降或持续低分内容触发预警
6. **迭代闭环**：将口碑数据反馈至内容生产/运营团队，驱动内容改进
7. **推荐联动**：为推荐系统提供内容质量信号

### 1.3 依赖关系

```

│                   本引擎 (Content Rating Engine)          │
├──────────────┬──────────────┬──────────────┬─────────────┤
│   评价采集    │   口碑聚合    │   质量预警    │   迭代闭环   │
└──────┬───────┴──────┬───────┴──────┬───────┴──────┬──────┘
       │              │              │              │

  内容服务(目标内容)  学习记录服务    消息/通知服务   运营管理后台

  安全审核服务        搜索服务        数据看板       配置中心
```

### 2.2 数据库表结构

#### 2.2.1 content_rating — 内容评分表

```sql
CREATE TABLE content_rating (
    id              BIGINT       NOT NULL AUTO_INCREMENT  COMMENT '主键ID',
    rating_id       VARCHAR(40)  NOT NULL                 COMMENT '评分唯一标识(UUID)',
    user_id         BIGINT       NOT NULL                 COMMENT '评价用户ID',
    user_grade      SMALLINT     NOT NULL                 COMMENT '评价时用户年级(1-12)',
    user_stage      TINYINT      NOT NULL                 COMMENT '学段: 1幼儿 2小学 3初中 4高中',
    is_vip          TINYINT      DEFAULT 0                COMMENT '是否会员用户',

    -- 评价目标
    target_type     TINYINT      NOT NULL                 COMMENT '目标类型: 1课程章节 2练习题集 3考点专题 4知识点讲解 5作文素材 6模拟试卷',
    target_id       VARCHAR(64)  NOT NULL                 COMMENT '目标内容ID',
    subject_code    VARCHAR(20)  DEFAULT NULL             COMMENT '学科编码',
    knowledge_point_ids JSON     DEFAULT NULL             COMMENT '关联知识点ID列表',

    -- 多维度评分 (每项1-5星)
    score_clarity   TINYINT      DEFAULT NULL             COMMENT '清晰度: 讲解是否清楚易懂',
    score_difficulty TINYINT     DEFAULT NULL             COMMENT '难度适宜度: 难度是否适合当前年级',
    score_engagement TINYINT     DEFAULT NULL             COMMENT '吸引力: 内容是否生动有趣',
    score_helpfulness TINYINT    DEFAULT NULL             COMMENT '帮助度: 对学习是否有实际帮助',
    score_overall   TINYINT      NOT NULL                 COMMENT '总体评价(必填): 1-5星',

    -- 快速标签 (多选)
    quick_tags      JSON         DEFAULT NULL             COMMENT '快速标签: ["讲解清晰","例题好","太长","太难","太简单",...]',

    -- 上下文
    study_duration_sec INT       DEFAULT NULL             COMMENT '本次学习该内容的时长(秒)',
    learning_context  VARCHAR(50) DEFAULT NULL            COMMENT '学习场景: sync_class/exam_prep/error_review/free_explore',
    device_platform   VARCHAR(20) DEFAULT NULL            COMMENT '设备平台: android/ios/web',

    -- 状态
    status          TINYINT      DEFAULT 1                COMMENT '状态: 0已删除 1有效 2已隐藏(违规) 3审核中',
    is_anonymous    TINYINT      DEFAULT 0                COMMENT '是否匿名评价',

    created_at      DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
    updated_at      DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),

    PRIMARY KEY (id),
    UNIQUE KEY uk_rating_id (rating_id),
    KEY idx_target (target_type, target_id, status),
    KEY idx_user (user_id, created_at),
    KEY idx_subject_score (subject_code, score_overall, status),
    KEY idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容评分表';
```

```sql
CREATE TABLE content_review (
```

#### 2.2.3 content_quality_score — 内容口碑质量分表

```sql
CREATE TABLE content_quality_score (
    id              BIGINT       NOT NULL AUTO_INCREMENT,
    target_type     TINYINT      NOT NULL                 COMMENT '目标类型',
    target_id       VARCHAR(64)  NOT NULL                 COMMENT '目标内容ID',
    subject_code    VARCHAR(20)  DEFAULT NULL,

    -- 聚合统计
    total_ratings   INT          NOT NULL DEFAULT 0       COMMENT '总评分人数',
    total_reviews   INT          NOT NULL DEFAULT 0       COMMENT '总评论数',

    -- 各维度均分(保留两位小数)
    avg_overall     DECIMAL(3,2) NOT NULL DEFAULT 0.00    COMMENT '总体均分',
    avg_clarity     DECIMAL(3,2) DEFAULT NULL             COMMENT '清晰度均分',
    avg_difficulty  DECIMAL(3,2) DEFAULT NULL             COMMENT '难度适宜度均分',
    avg_engagement  DECIMAL(3,2) DEFAULT NULL             COMMENT '吸引力均分',
    avg_helpfulness DECIMAL(3,2) DEFAULT NULL             COMMENT '帮助度均分',

    -- 分布
    star_distribution JSON       NOT NULL                 COMMENT '星级分布: {"1":2,"2":5,"3":20,"4":80,"5":150}',

    -- 综合质量分(加权计算)
    quality_score   DECIMAL(5,2) NOT NULL DEFAULT 0.00    COMMENT '综合质量分(0-100)',
    quality_tier    VARCHAR(10)  NOT NULL DEFAULT 'C'     COMMENT '质量等级: S/A/B/C/D',

    -- 趋势
    score_trend     VARCHAR(10)  DEFAULT 'stable'         COMMENT '趋势: rising/falling/stable/new',
    prev_quality_score DECIMAL(5,2) DEFAULT NULL          COMMENT '上一周期质量分',

    -- 标签聚合(Top N)
    top_positive_tags JSON       DEFAULT NULL             COMMENT 'Top正面标签: [{"tag":"讲解清晰","count":120},...]',
    top_negative_tags JSON       DEFAULT NULL             COMMENT 'Top负面标签: [{"tag":"太难了","count":45},...]',

    last_rating_at  DATETIME(3)  DEFAULT NULL             COMMENT '最新评分时间',
    calculated_at   DATETIME(3)  NOT NULL DEFAULT CURRENT_TIMESTAMP(3) COMMENT '最近计算时间',

    PRIMARY KEY (id),
    UNIQUE KEY uk_target (target_type, target_id),
    KEY idx_quality (quality_score),
    KEY idx_tier (quality_tier),
    KEY idx_subject (subject_code, quality_score)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='内容口碑质量分表';
```

```sql
CREATE TABLE quality_alert (

    KEY idx_status_severity (status, severity, created_at)
```

## 3. API 接口设计

### 3.1 接口总览

| # | 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 提交内容评价 | POST | `/api/v1/content-ratings` | 提交评分+评论 |
| 2 | 查询我的评价 | GET | `/api/v1/content-ratings/mine` | 查询用户已提交的评价 |
| 3 | 检查评价状态 | GET | `/api/v1/content-ratings/check` | 检查是否已评价某内容 |
| 4 | 获取内容口碑概览 | GET | `/api/v1/content-ratings/summary` | 获取质量分+分布 |
| 5 | 获取内容评论列表 | GET | `/api/v1/content-ratings/reviews` | 分页获取评论 |
| 6 | 评论有用度投票 | POST | `/api/v1/content-ratings/reviews/{reviewId}/vote` | 投票"有用/无用" |
| 7 | 删除我的评价 | DELETE | `/api/v1/content-ratings/{ratingId}` | 用户删除自己的评价 |
| 8 | 获取可用快速标签 | GET | `/api/v1/content-ratings/tags` | 按内容类型获取标签 |
| 9 | 获取低质内容预警列表 | GET | `/api/v1/content-ratings/alerts` | 运营后台-预警列表 |
| 10 | 处理质量预警 | PUT | `/api/v1/content-ratings/alerts/{alertId}` | 运营后台-处理预警 |
| 11 | 获取内容质量排行榜 | GET | `/api/v1/content-ratings/rankings` | 按学科/类型排序 |
| 12 | 批量查询质量分 | POST | `/api/v1/content-ratings/batch-scores` | 给推荐系统用 |

### 3.2 详细接口定义

#### 3.2.1 提交内容评价

```
POST /api/v1/content-ratings
Authorization: Bearer {token}
Content-Type: application/json
```

**请求体：**

```json
{
  "targetType": 1,
  "targetId": "course_chapter_10086",
  "scores": {
    "overall": 5,
    "clarity": 5,
    "difficulty": 4,
    "engagement": 4,
    "helpfulness": 5
  },
  "quickTags": ["clear_explanation", "good_examples", "worth_recommending"],
  "review": {
    "content": "老师讲解非常清楚，例题选得很好，跟着学了一遍就懂了！",
    "isAnonymous": false
  },
  "learningContext": "sync_class",
  "studyDurationSec": 1200
}
```

**响应（200）：**

```json
{
  "code": 0,
  "data": {
    "ratingId": "rt_20260628_a1b2c3d4",
    "reviewId": "rv_20260628_e5f6g7h8",
    "auditStatus": 1,
    "message": "评价成功，感谢您的反馈！"
  }
}
```

**校验规则：**

| 字段 | 规则 |
| --- | --- |
| targetType | 枚举 1-6 |
| targetId | 非空，长度 ≤ 64 |
| scores.overall | 必填，1-5 |
| scores.clarity 等 | 可选，1-5 |
| quickTags | 可选，最多 5 个标签 |
| review.content | 可选，最长 500 字；不填则不创建评论 |
| 同一用户同一内容 | 只能评价一次，修改需调用更新接口 |

**限频：** 每用户每分钟最多 5 次评价提交。

**审核策略：**

1. **先机审后人工**：提交后先经过敏感词过滤 + NLP分类，机器判定高置信通过则直接 `PASS`，高置信拒绝则 `REJECT`，中等置信则 `AUTO_PASS` 进入人工复核队列
2. **敏感词过滤**：政治敏感、色情暴力、广告引流、人身攻击
3. **内容相关性检测**：评论是否与教育内容相关（防止灌水）
4. **未成年人保护**：自动检测不当内容，保护未成年用户
5. **批量审核工作台**：运营人员在管理后台集中处理 `AUTO_PASS` 队列

### 4.3 综合质量分计算算法

质量分采用**贝叶斯平均** + **多维度加权**模型：

```python
def calculate_quality_score(target_type: int, target_id: str) -> QualityScore:
    """
    计算内容的综合质量分(0-100)。
    
    算法步骤:
    1. 收集该内容的全部评分
    2. 使用贝叶斯平均计算各维度得分（避免少量评价时的偏差）
    3. 加权综合得出百分制质量分
    4. 映射到质量等级
    5. 计算趋势变化
    """
    # 拉取评分聚合数据
    ratings = fetch_ratings(target_type, target_id)
    n = len(ratings)
    
    if n == 0:
        return QualityScore(score=0, tier='C', trend='new')
    
    # ---- 贝叶斯平均 ----
    # 先验参数: 假设全局平均分为3.5, 先验样本数为5
    PRIOR_MEAN = 3.5
    PRIOR_COUNT = 5
    
    def bayesian_avg(values: list[float], prior_mean=PRIOR_MEAN, prior_count=PRIOR_COUNT) -> float:
        n = len(values)
        if n == 0:
            return prior_mean
        actual_sum = sum(values)
        return (actual_sum + prior_mean * prior_count) / (n + prior_count)
    
    bayes_overall     = bayesian_avg([r.overall for r in ratings])
    bayes_clarity     = bayesian_avg([r.clarity for r in ratings if r.clarity])
    bayes_difficulty  = bayesian_avg([r.difficulty for r in ratings if r.difficulty])
    bayes_engagement  = bayesian_avg([r.engagement for r in ratings if r.engagement])
    bayes_helpfulness = bayesian_avg([r.helpfulness for r in ratings if r.helpfulness])
    
    # ---- 样本量调节因子 ----
    # 评价数量越多, 分数可信度越高
    confidence = min(1.0, n / 50)  # 50条评价达到满置信
    
    # ---- 加权综合分 ----
    # 各维度权重(可配置)
    W_OVERALL     = 0.40
    W_CLARITY     = 0.20
    W_HELPFULNESS = 0.20
    W_ENGAGEMENT  = 0.10
    W_DIFFICULTY  = 0.10
    
    weighted = (
        bayes_overall     * W_OVERALL     +
        bayes_clarity     * W_CLARITY     +
        bayes_helpfulness * W_HELPFULNESS +
        bayes_engagement  * W_ENGAGEMENT  +
        bayes_difficulty  * W_DIFFICULTY
    )
    
    # 映射到0-100分(1星=0分, 5星=100分)
    raw_score = (weighted - 1.0) / 4.0 * 100
    
    # 置信度调节: 低样本量时分数向50分(中性)收缩
    adjusted_score = raw_score * confidence + 50 * (1 - confidence)
    
    # ---- 趋势计算 ----
    prev_score = get_prev_quality_score(target_type, target_id)
    trend = 'stable'
    if prev_score is None:
        trend = 'new'
    elif adjusted_score - prev_score > 5:
        trend = 'rising'
    elif prev_score - adjusted_score > 5:
        trend = 'falling'
    
    # ---- 质量等级映射 ----
    tier = score_to_tier(adjusted_score)
    
    return QualityScore(
        score=round(adjusted_score, 2),
        tier=tier,
        trend=trend,
        avg_overall=round(bayes_overall, 2),
        avg_clarity=round(bayes_clarity, 2) if bayes_clarity else None,
        avg_difficulty=round(bayes_difficulty, 2) if bayes_difficulty else None,
        avg_engagement=round(bayes_engagement, 2) if bayes_engagement else None,
        avg_helpfulness=round(bayes_helpfulness, 2) if bayes_helpfulness else None,
    )

def score_to_tier(score: float) -> str:
    if score >= 85: return 'S'
    if score >= 70: return 'A'
    if score >= 55: return 'B'
    if score >= 40: return 'C'
    return 'D'
```

### 4.4 质量预警规则

```python
class QualityAlertRules:
    """质量预警规则定义"""
    
    @staticmethod
    def check_alerts(target: ContentTarget, current: QualityScore, prev: QualityScore | None):
        alerts = []
        
        # 规则1: 低分预警 - 质量分持续低于阈值
        if current.total_ratings >= 10 and current.quality_score < 40:
            alerts.append(QualityAlert(
                alert_type='low_score',
                severity=3 if current.quality_score < 25 else 2,
                data={
                    'quality_score': current.quality_score,
                    'avg_overall': current.avg_overall,
                    'total_ratings': current.total_ratings,
                    'threshold': 40
                }
            ))
        
        # 规则2: 分数暴跌 - 质量分环比下降超过15分
        if prev and prev.quality_score - current.quality_score > 15:
            alerts.append(QualityAlert(
                alert_type='score_drop',
                severity=3,
                data={
                    'current_score': current.quality_score,
                    'prev_score': prev.quality_score,
                    'drop': prev.quality_score - current.quality_score
                }
            ))
        
        # 规则3: 投诉集中 - 短时间内负面标签激增
        recent_negative_ratio = calculate_negative_tag_ratio(target, days=7)
        historical_negative_ratio = calculate_negative_tag_ratio(target, days=30)
        if (recent_negative_ratio > 0.3 and 
            recent_negative_ratio > historical_negative_ratio * 1.5):
            alerts.append(QualityAlert(
                alert_type='low_volume_complaint',
                severity=2,
                data={
                    'recent_negative_ratio': recent_negative_ratio,
                    'historical_negative_ratio': historical_negative_ratio,
                    'top_negative_tags': current.top_negative_tags[:3]
                }
            ))
        
        # 规则4: 趋势持续下降 - 连续3个计算周期下降
        if current.trend == 'falling' and check_consecutive_decline(target, periods=3):
            alerts.append(QualityAlert(
                alert_type='trend_decline',
                severity=2,
                data={
                    'current_score': current.quality_score,
                    'consecutive_decline_periods': 3
                }
            ))
        
        return alerts
```

```java
@Service
@Slf4j
public class ContentRatingServiceImpl implements ContentRatingService {

    @Autowired private ContentRatingMapper ratingMapper;
    @Autowired private ContentReviewMapper reviewMapper;
    @Autowired private QualityScoreMapper scoreMapper;
    @Autowired private ReviewHelpfulVoteMapper voteMapper;
    @Autowired private QuickTagDictionaryMapper tagDictMapper;
    @Autowired private ContentSecurityService securityService;
    @Autowired private ContentServiceClient contentServiceClient;
    @Autowired private EventBus eventBus;
    @Autowired private RedisTemplate<String, Object> redisTemplate;

    private static final int RATE_LIMIT_PER_MINUTE = 5;
    private static final int REVIEW_MAX_LENGTH = 500;

    @Override
    @Transactional
    public SubmitRatingResponse submitRating(Long userId, SubmitRatingRequest request) {
        // 1. 频率限制
        checkRateLimit(userId);

        // 2. 验证内容存在
        if (!contentServiceClient.checkContentExists(request.getTargetType(), request.getTargetId())) {
            throw new BizException("RATING_001", "目标内容不存在");
        }

        // 3. 检查重复评价
        if (ratingMapper.existsByUserAndTarget(userId, request.getTargetType(), request.getTargetId())) {
            throw new BizException("RATING_002", "您已评价过该内容，请使用修改功能");
        }

        // 4. 验证标签
        validateQuickTags(request.getQuickTags(), request.getTargetType());

        // 5. 获取用户上下文
        UserProfile profile = getUserProfile(userId);

        // 6. 保存评分
        ContentRating rating = buildRating(userId, profile, request);
        ratingMapper.insert(rating);

        // 7. 保存评论(如果有)
        String reviewId = null;
        int auditStatus = 1; // 默认通过(无评论时)
        if (StringUtils.hasText(request.getReviewContent())) {
            if (request.getReviewContent().length() > REVIEW_MAX_LENGTH) {
                throw new BizException("RATING_004", "评论内容不能超过" + REVIEW_MAX_LENGTH + "字");
            }
            
            ContentReview review = buildReview(rating, request);
            
            // 先机审
            ContentAuditResult auditResult = securityService.auditReview(
                request.getReviewContent(), 
                profile.getUserStage()
            );
            review.setAuditStatus(auditResult.getStatus());
            review.setAutoLabels(auditResult.getLabels());
            reviewMapper.insert(review);
            
            reviewId = review.getReviewId();
            auditStatus = auditResult.getStatus();
            
            // AUTO_PASS 状态需要异步推送人工审核
            if (auditResult.getStatus() == 3) {
                eventBus.publish(new ReviewPendingHumanAuditEvent(review.getReviewId()));
            }
        }

        // 8. 失效缓存
        invalidateCaches(request.getTargetType(), request.getTargetId(), userId);

        // 9. 发布事件
        eventBus.publish(ContentRatingSubmittedEvent.builder()
            .ratingId(rating.getRatingId())
            .reviewId(reviewId)
            .userId(userId)
            .targetType(request.getTargetType())
            .targetId(request.getTargetId())
            .scoreOverall(request.getScores().getOverall())
            .timestamp(LocalDateTime.now())
            .build());

        return new SubmitRatingResponse(rating.getRatingId(), reviewId, auditStatus, "评价成功，感谢您的反馈！");
    }

    private void checkRateLimit(Long userId) {
        String key = "rating:rate_limit:" + userId;
        Long count = redisTemplate.opsForValue().increment(key);
        if (count == 1) {
            redisTemplate.expire(key, Duration.ofMinutes(1));
        }
        if (count > RATE_LIMIT_PER_MINUTE) {
            throw new BizException("RATING_008", "评价提交频率过高，请稍后再试");
        }
    }

    private void invalidateCaches(Integer targetType, String targetId, Long userId) {
        redisTemplate.delete(String.format("quality:score:%d:%s", targetType, targetId));
        redisTemplate.delete(String.format("quality:reviews:%d:%s:*", targetType, targetId));
        redisTemplate.delete(String.format("quality:rating:check:%d:%d:%d", userId, targetType, targetId));
    }
}
```

```java
/**
 * 监听评分事件，异步触发质量分重算

@Component
@Slf4j
public class QualityScoreCalculationConsumer {

    @Autowired private QualityScoreMapper scoreMapper;
    @Autowired private ContentRatingMapper ratingMapper;
    @Autowired private QualityAlertService alertService;
    @Autowired private RedisTemplate<String, Object> redisTemplate;

    @EventListener
    @Async("qualityCalculationExecutor")
    @Transactional(propagation = Propagation.REQUIRES_NEW)
    public void onRatingSubmitted(ContentRatingSubmittedEvent event) {
        Integer targetType = event.getTargetType();
        String targetId = event.getTargetId();
        
        log.info("开始重算质量分: type={}, id={}", targetType, targetId);

        try {
            // 1. 拉取全部评分
            List<ContentRating> ratings = ratingMapper.findByTarget(targetType, targetId);
            
            // 2. 计算贝叶斯平均
            QualityScoreResult result = BayesianQualityCalculator.calculate(ratings);
            
            // 3. 获取上一周期分数(用于趋势和预警)
            ContentQualityScore prevScore = scoreMapper.findByTarget(targetType, targetId);
            
            // 4. 构建质量分记录
            ContentQualityScore scoreRecord = buildScoreRecord(targetType, targetId, result, prevScore);
            
            // 5. 保存(存在则更新)
            if (prevScore != null) {
                scoreRecord.setId(prevScore.getId());
                scoreMapper.updateById(scoreRecord);
            } else {
                scoreMapper.insert(scoreRecord);
            }
            
            // 6. 更新标签聚合
            updateTagAggregation(targetType, targetId, ratings);
            
            // 7. 检查预警
            if (ratings.size() >= 10) {
                List<QualityAlert> alerts = QualityAlertRules.checkAlerts(
                    new ContentTarget(targetType, targetId),
                    toQualityScore(scoreRecord),
                    prevScore != null ? toQualityScore(prevScore) : null
                );
                for (QualityAlert alert : alerts) {
                    alertService.createIfNotExists(alert);
                }
            }
            
            // 8. 更新缓存
            String cacheKey = String.format("quality:score:%d:%s", targetType, targetId);
            redisTemplate.opsForValue().set(cacheKey, scoreRecord, Duration.ofMinutes(30));
            
            log.info("质量分重算完成: type={}, id={}, score={}, tier={}", 
                targetType, targetId, scoreRecord.getQualityScore(), scoreRecord.getQualityTier());
                
        } catch (Exception e) {
            log.error("质量分重算失败: type={}, id={}", targetType, targetId, e);
            // 失败不阻断用户流程，记录错误日志即可
        }
    }
```

### 5.4 评论审核服务

```java
/**
 * 评论内容安全审核服务
 */
@Service
@Slf4j
public class ContentReviewAuditService {

    @Autowired private ContentReviewMapper reviewMapper;
    @Autowired private SensitiveWordFilter sensitiveWordFilter;
    @Autowired private NlpContentClassifier nlpClassifier;
    @Autowired private ReviewAuditQueue auditQueue;

    private static final double AUTO_PASS_THRESHOLD = 0.95;
    private static final double AUTO_REJECT_THRESHOLD = 0.85;

    /**
     * 自动审核评论
     * @return 审核结果: status(1=直接通过, 2=直接拒绝, 3=需人工复核)
     */
    public ContentAuditResult auditReview(String content, int userStage) {
        // 1. 敏感词过滤
        SensitiveWordResult sensitiveResult = sensitiveWordFilter.filter(content);
        if (sensitiveResult.hasHit()) {
            log.warn("评论命中敏感词, review_content={}, labels={}", 
                content.substring(0, Math.min(content.length(), 50)),
                sensitiveResult.getLabels());
            return ContentAuditResult.reject(
                "包含敏感内容: " + sensitiveResult.getCategory(),
                sensitiveResult.getLabels()
            );
        }

        // 2. NLP分类
        NlpClassifyResult nlpResult = nlpClassifier.classify(content);
        
        // 3. 广告/灌水检测
        if (nlpResult.getCategoryProbabilities().containsKey("ad_promotion") 
            && nlpResult.getCategoryProbabilities().get("ad_promotion") > AUTO_REJECT_THRESHOLD) {
            return ContentAuditResult.reject(
                "疑似广告推广内容",
                List.of("ad_promotion")
            );
        }

        if (nlpResult.getCategoryProbabilities().containsKey("spam") 
            && nlpResult.getCategoryProbabilities().get("spam") > AUTO_REJECT_THRESHOLD) {
            return ContentAuditResult.reject(
                "疑似无意义灌水内容",
                List.of("spam")
            );
        }

        // 4. 不当内容检测(未成年人保护加严)
        if (userStage <= 3) { // 初中及以下
            String[] enhancedCategories = {"violence", "adult_content", "inappropriate_language"};
            for (String cat : enhancedCategories) {
                if (nlpResult.getCategoryProbabilities().getOrDefault(cat, 0.0) > 0.5) {
                    return ContentAuditResult.reject(
                        "内容不适合未成年人",
                        List.of(cat)
                    );
                }
            }
        }

        // 5. 正常内容 - 判定是否需要人工复核
        double normalProb = nlpResult.getCategoryProbabilities().getOrDefault("normal", 0.0);
        if (normalProb > AUTO_PASS_THRESHOLD) {
            return ContentAuditResult.pass();
        } else {
            // 中等置信度，需人工复核
            return ContentAuditResult.autoPassPendingReview(
                nlpResult.getTopCategories(3)
            );
        }
    }
}
```

### 5.5 推荐系统联动接口

```java
/**
 * 供推荐系统调用的内容质量信号提供者
 */
@RestController
@RequestMapping("/api/internal/content-ratings")
public class RatingSignalProvider {

    @Autowired private QualityScoreMapper scoreMapper;

    /**
     * 批量获取质量信号(供推荐排序使用)
     */
    @PostMapping("/batch-signals")
    public Result<Map<String, RatingSignal>> batchGetSignals(
            @RequestBody BatchSignalRequest request) {
        
        Map<String, RatingSignal> result = new HashMap<>();
        
        for (ContentTarget target : request.getTargets()) {
            ContentQualityScore score = scoreMapper.findByTarget(
                target.getTargetType(), target.getTargetId());
            
            if (score != null && score.getTotalRatings() >= 5) {
                // 推荐加权系数: S=1.3, A=1.1, B=1.0, C=0.8, D=0.5
                double boostFactor = switch (score.getQualityTier()) {
                    case "S" -> 1.3;
                    case "A" -> 1.1;
                    case "B" -> 1.0;
                    case "C" -> 0.8;
                    case "D" -> 0.5;
                    default -> 1.0;
                };
                
                // 负面标签惩罚
                double penalty = 1.0;
                if (score.getTopNegativeTags() != null) {
                    boolean hasErrorsTag = score.getTopNegativeTags().stream()
                        .anyMatch(t -> "errors_found".equals(t.get("tag")));
                    if (hasErrorsTag) penalty -= 0.3;
                }
                
                result.put(target.getKey(), new RatingSignal(
                    score.getQualityScore(),
                    score.getQualityTier(),
                    score.getAvgOverall(),
                    boostFactor * penalty,
                    score.getTotalRatings()
                ));
            } else {
                // 新内容或评价不足: 给予探索性加权
                result.put(target.getKey(), RatingSignal.newContent());
            }
        }
        
        return Result.success(result);
    }
}
```

```java
/**
 * 增量重算近24小时有新评价的内容质量分

@Component
@Slf4j
public class QualityScoreIncrementalJob {

    @Autowired private ContentRatingMapper ratingMapper;
    @Autowired private QualityScoreCalculationService calculationService;

    @Scheduled(fixedDelay = 30 * 60 * 1000) // 30分钟
    public void execute() {
        // 找出最近24小时有新评价的(target_type, target_id)组合
        List<ContentTarget> activeTargets = ratingMapper.findActiveTargets(
            LocalDateTime.now().minusHours(24)
        );
        
        log.info("增量质量分重算, 待处理内容数: {}", activeTargets.size());
        
        for (ContentTarget target : activeTargets) {
            try {
                calculationService.recalculate(target.getTargetType(), target.getTargetId());
            } catch (Exception e) {
                log.error("重算失败: {}", target, e);
            }
        }
        
        log.info("增量质量分重算完成, 处理: {}", activeTargets.size());
    }
}
```

## 7. 错误处理与降级策略

### 7.1 异常场景与处理

| 场景 | 处理策略 |
| --- | --- |
| 评价提交DB写入失败 | 退回用户重试；记录异常日志 |
| 评论机审服务超时 | 降级为直接放入人工审核队列(PENDING)；不阻断评价提交 |
| 质量分计算异常 | 不影响用户评价提交；记录错误日志；下次定时任务重试 |
| 批量查询质量分超时 | 返回缓存数据（可能过期但可用）；不报错 |
| 缓存不可用 | 降级直接查DB；增加限流保护 |
| 推荐系统联动接口异常 | 推荐系统应自行容错，默认使用 boost=1.0 |

### 7.2 数据一致性

| 场景 | 策略 |
| --- | --- |
| 评价写入成功但事件发送失败 | 定时任务比对 rating 表与 quality_score 表差异，补偿计算 |
| 评论投票数与实际投票记录不一致 | 定时任务每日校准 vote count |
| 缓存与DB不一致 | 写操作主动失效缓存；读操作发现不一致时刷新 |
| 评价删除但质量分未更新 | 删除评价后同步发送事件触发重算 |
