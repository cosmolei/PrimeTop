# 服务端 - 学生用户学习断更回归预测与智能唤醒策略引擎 详细设计

## 1. 概述

### 1.1 模块定位

本引擎是 PrimeTop 平台**学习留存保障体系**的核心服务之一，专注于解决"学生用户学习行为中断后的预测、诊断与智能召回"问题。

与现有模块的职责区分：

| 模块 | 关注点 | 与本引擎区别 |
| --- | --- | --- |
| 用户流失预警与智能挽留策略引擎 | 产品层面的用户流失（卸载、长期不登录） | 关注产品留存，非学习连续性；唤醒手段偏向营销 |
| 学习动力量化与学习倦怠预警引擎 | 活跃学习期间的动力衰减与倦怠 | 前置预防，学生在使用中但动力下降 |
| 学生AI学习伙伴主动对话触发引擎 | AI伙伴在日常对话中的主动关怀 | 交互层面触发，非策略层面编排 |
| 用户生命周期营销自动化引擎 | 营销触达自动化（短信/Push/弹窗） | 通用营销编排，无教育场景深度定制 |
| **本引擎** | **学习行为中断后的回归预测、原因诊断、个性化唤醒路径编排** | **聚焦"学习习惯连续性"，唤醒策略以教育内容与学习路径为核心** |

### 1.2 核心职责

1. **断更检测**：实时检测学生用户学习行为的中断模式（日中断、周中断、阶段性中断）。
2. **回归概率预测**：基于历史行为序列与上下文特征，预测学生在未来 7/14/30 天内回归学习的概率。
3. **断更原因诊断**：分析中断的可能原因（内容太难、进度太快、外部冲突、兴趣转移、疲劳积累等）。
4. **唤醒策略编排**：根据学生画像、中断原因、学习历史，生成个性化多步唤醒计划。
5. **唤醒效果追踪**：追踪唤醒策略执行后的学生回归行为，形成闭环反馈。
6. **学习习惯韧性评分**：计算学生学习习惯的"韧性"指标，识别高风险用户。

```

├─────────────┬──────────────┬─────────────────────────┤

       │             │                   │

└──────────────┘ └──────────────┘ └──────────────────┘
       │             │                   │
       ▼             ▼                   ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────────┐

└──────────────┘ └──────────────┘ └──────────────────┘
```

**上游依赖：**
- 统一用户行为埋点平台 → 提供原始学习行为事件
- 学生画像特征工程平台 → 提供用户特征向量
- 学习记录与进度追踪服务 → 提供学习进度快照
- 学情分析服务 → 提供掌握度与薄弱点数据

**下游消费：**
- 消息与推送服务 → 执行唤醒通知投递
- 学生AI学习伙伴主动对话触发引擎 → 触发AI伙伴关怀对话
- 运营活动与成长激励体系 → 发放回归奖励
- 学习计划动态调整服务 → 重新规划断更后的学习路径

## 2. 数据模型

### 2.1 核心实体定义

#### 2.1.1 学习断更事件 (LearningGapEvent)

```java
/**
 * 学习断更事件 - 每次检测到学生断更时生成
 */
@Data
@TableName("t_learning_gap_event")
public class LearningGapEvent {
    @TableId(type = IdType.ASSIGN_ID)
    private Long id;
    
    /** 用户ID */
    private Long userId;
    
    /** 断更类型: DAILY(日断更), WEEKLY(周断更), STAGE(阶段性断更) */
    private String gapType;
    
    /** 最后学习时间 */
    private LocalDateTime lastStudyTime;
    
    /** 检测时间 */
    private LocalDateTime detectedAt;
    
    /** 已断更天数 */
    private Integer gapDays;
    
    /** 断更前7天日均学习时长（分钟） */
    private Integer avgDailyMinutesBeforeGap;
    
    /** 断更前最后一次学习场景 */
    private String lastScene; // AI_TUTOR, PRACTICE, SYNC_CLASS, MISTAKE_REVIEW, etc.
    
    /** 断更前最后一次学习的知识点ID */
    private Long lastKnowledgePointId;
    
    /** 断更前最后一次学习的章节ID */
    private Long lastChapterId;
    
    /** 断更前最后一次学习难度 */
    private String lastDifficultyLevel;
    
    /** 断更前最后一次答题正确率 */
    private BigDecimal lastAccuracy;
    
    /** 断更时学习计划完成进度 */
    private BigDecimal planCompletionRate;
    
    /** 断更原因诊断结果(JSON) */
    private String diagnosedCausesJson;
    
    /** 回归概率评分 0-100 */
    private BigDecimal returnProbabilityScore;
    
    /** 风险等级: LOW, MEDIUM, HIGH, CRITICAL */
    private String riskLevel;
    
    /** 状态: DETECTED, DIAGNOSED, STRATEGY_GENERATED, AWAKENING, RETURNED, EXPIRED */
    private String status;
    
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;
    
    @TableField(fill = FieldFill.INSERT)
    private Long tenantId;
}
```

### 2.2 数据库表结构

```sql
-- 学习断更事件表
CREATE TABLE t_learning_gap_event (
    id                  BIGINT PRIMARY KEY,
    user_id             BIGINT NOT NULL,
    gap_type            VARCHAR(20) NOT NULL COMMENT 'DAILY/WEEKLY/STAGE',
    last_study_time     DATETIME NOT NULL,
    detected_at         DATETIME NOT NULL,
    gap_days            INT NOT NULL,
    avg_daily_minutes_before_gap  INT,
    last_scene          VARCHAR(50),
    last_knowledge_point_id       BIGINT,
    last_chapter_id               BIGINT,
    last_difficulty_level         VARCHAR(20),
    last_accuracy                 DECIMAL(5,2),
    plan_completion_rate          DECIMAL(5,2),
    diagnosed_causes_json         TEXT,
    return_probability_score      DECIMAL(5,2),
    risk_level                    VARCHAR(20),
    status                        VARCHAR(30) NOT NULL DEFAULT 'DETECTED',
    tenant_id                     BIGINT,
    created_at                    DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at                    DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_status (user_id, status),
    INDEX idx_detected (detected_at),
    INDEX idx_risk (risk_level, detected_at),
    INDEX idx_tenant (tenant_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习断更事件';

-- 唤醒策略计划表
CREATE TABLE t_awakening_plan (
    id                  BIGINT PRIMARY KEY,
    gap_event_id        BIGINT NOT NULL,
    user_id             BIGINT NOT NULL,
    strategy_template_id VARCHAR(100) NOT NULL,
    steps_json          TEXT NOT NULL,
    current_step_index  INT DEFAULT 0,
    status              VARCHAR(30) NOT NULL DEFAULT 'PENDING',
    first_trigger_time  DATETIME,
    expire_time         DATETIME,
    context_json        TEXT,
    effect_tracking_id  VARCHAR(64),
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_gap (gap_event_id),
    INDEX idx_user_status (user_id, status),
    INDEX idx_trigger (first_trigger_time, status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='唤醒策略计划';

-- 唤醒步骤执行记录表
CREATE TABLE t_awakening_step_execution (
    id                  BIGINT PRIMARY KEY,
    plan_id             BIGINT NOT NULL,
    step_index          INT NOT NULL,
    channel_type        VARCHAR(30) NOT NULL,
    triggered_at        DATETIME,
    delivery_status     VARCHAR(30) DEFAULT 'PENDING',
    user_response       VARCHAR(30),
    responded_at        DATETIME,
    response_latency_minutes INT,
    message_template_id VARCHAR(100),
    provider_message_id VARCHAR(200),
    created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_plan (plan_id),
    INDEX idx_response (user_response, triggered_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='唤醒步骤执行记录';

-- 学习习惯韧性评分表
CREATE TABLE t_habit_resilience_score (
    id                  BIGINT PRIMARY KEY,
    user_id             BIGINT NOT NULL,
    score_date          DATE NOT NULL,
    total_score         DECIMAL(5,2),
    streak_score        DECIMAL(5,2),
    frequency_score     DECIMAL(5,2),
    duration_score      DECIMAL(5,2),
    return_rate_score   DECIMAL(5,2),
    timing_score        DECIMAL(5,2),
    gap_count_90d       INT,
    max_streak_days     INT,
    current_streak_days INT,
    trend               VARCHAR(20),
    risk_tags_json      TEXT,
    calculated_at       DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE INDEX uk_user_date (user_id, score_date),
    INDEX idx_score (total_score, score_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='学习习惯韧性评分';

-- 唤醒策略效果统计表
CREATE TABLE t_awakening_effect_stats (
    id                  BIGINT PRIMARY KEY,
    strategy_template_id VARCHAR(100) NOT NULL,
    period              VARCHAR(20) NOT NULL,
    total_executions    INT DEFAULT 0,
    successful_returns  INT DEFAULT 0,
    ignored_count       INT DEFAULT 0,
    unsubscribed_count  INT DEFAULT 0,
    avg_return_hours    DECIMAL(10,2),
    retention_7d_rate   DECIMAL(5,2),
    retention_30d_rate  DECIMAL(5,2),
    effectiveness_score DECIMAL(5,2),
    calculated_at       DATETIME DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE INDEX uk_template_period (strategy_template_id, period)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='唤醒策略效果统计';
```

### 2.3 缓存策略

| 缓存键 | 用途 | TTL | 存储类型 |
| --- | --- | --- | --- |
| `gap:user:{userId}:status` | 用户当前断更状态 | 24h | Redis Hash |
| `gap:user:{userId}:streak` | 当前连续学习天数 | 1h | Redis String |
| `resilience:user:{userId}:latest` | 最新韧性评分 | 6h | Redis Hash |
| `awakening:plan:{planId}:executing` | 正在执行的唤醒计划 | 计划过期时删除 | Redis Hash |
| `awakening:cooldown:user:{userId}` | 唤醒冷却期标记 | 7d | Redis String |
| `gap:stats:daily:{date}` | 每日断更统计 | 7d | Redis Hash |

**检测流程：**

```java
/**
 * 每日断更检测扫描 - 由定时任务触发
 * 执行时间：每天 02:00 AM
 */
@Slf4j
@Service
public class DailyGapScanService {

    @Autowired
    private UserActiveRecordMapper userActiveRecordMapper;
    @Autowired
    private LearningGapEventService gapEventService;
    @Autowired
    private HabitResilienceService resilienceService;
    @Autowired
    private GapDiagnosisService diagnosisService;
    @Autowired
    private AwakeningStrategyService strategyService;

    /**
     * 执行每日断更扫描
     */
    public ScanResult executeScan(ScanRequest request) {
        LocalDate scanDate = request.getScanDate();
        List<Long> candidateUserIds = userActiveRecordMapper
            .findActiveUsers(scanDate.minusDays(30), request.getTenantId());
        
        ScanResult result = new ScanResult();
        
        for (Long userId : batchIterate(candidateUserIds, request.getBatchSize())) {
            try {
                processUser(userId, scanDate, result);
            } catch (Exception e) {
                log.warn("断更扫描异常 userId={}", userId, e);
                result.incrementError();
            }
        }
        
        return result;
    }

    private void processUser(Long userId, LocalDate scanDate, ScanResult result) {
        // 1. 获取用户最后学习时间
        LocalDateTime lastStudyTime = userActiveRecordMapper
            .getLastStudyTime(userId);
        
        if (lastStudyTime == null) return;
        
        long gapDays = ChronoUnit.DAYS.between(lastStudyTime.toLocalDate(), scanDate);
        
        // 2. 判断是否触发断更
        GapType gapType = determineGapType(gapDays);
        if (gapType == null) return;
        
        // 3. 检查是否已有未过期的断更事件
        if (gapEventService.hasActiveEvent(userId)) return;
        
        // 4. 检查唤醒冷却期
        if (strategyService.isInCooldown(userId)) {
            result.incrementSkippedCooldown();
            return;
        }
        
        // 5. 创建断更事件
        LearningGapEvent event = buildGapEvent(userId, lastStudyTime, gapDays, gapType);
        
        // 6. 收集断更前上下文
        enrichPreGapContext(event, userId);
        
        // 7. 执行原因诊断
        List<DiagnosedCause> causes = diagnosisService.diagnose(event);
        event.setDiagnosedCausesJson(JsonUtils.toJson(causes));
        
        // 8. 预测回归概率
        BigDecimal returnProb = predictReturnProbability(event);
        event.setReturnProbabilityScore(returnProb);
        event.setRiskLevel(calculateRiskLevel(gapDays, returnProb));
        
        // 9. 保存事件
        gapEventService.save(event);
        
        // 10. 生成唤醒策略
        if (shouldGenerateStrategy(event)) {
            AwakeningPlan plan = strategyService.generatePlan(event);
            strategyService.scheduleExecution(plan);
        }
        
        // 11. 更新韧性评分
        resilienceService.recalculateAsync(userId);
        
        result.incrementDetected(gapType);
    }

    private GapType determineGapType(long gapDays) {
        if (gapDays >= GapType.STAGE.getThresholdDays()) return GapType.STAGE;
        if (gapDays >= GapType.WEEKLY.getThresholdDays()) return GapType.WEEKLY;
        if (gapDays >= GapType.DAILY.getThresholdDays()) return GapType.DAILY;
        return null;
    }
}
```

#### 4.2.1 诊断维度

```java
/**
 * 断更原因诊断服务

@Service
@Slf4j
public class GapDiagnosisService {

    @Autowired
    private StudyRecordQueryService studyRecordQueryService;
    @Autowired
    private AccuracyTrendService accuracyTrendService;
    @Autowired
    private CalendarContextService calendarContextService;
    @Autowired
    private PlanProgressQueryService planProgressQueryService;

    /**
     * 诊断断更原因
     * @param event 断更事件
     * @return 按置信度排序的原因列表
     */
    public List<DiagnosedCause> diagnose(LearningGapEvent event) {
        List<DiagnosedCause> causes = new ArrayList<>();
        Long userId = event.getUserId();
        
        // 1. 内容难度突升检测
        causes.addAll(checkDifficultySpike(userId, event));
        
        // 2. 正确率急剧下降检测
        causes.addAll(checkAccuracyDrop(userId, event));
        
        // 3. 学习计划执行受挫检测
        causes.addAll(checkPlanFrustration(userId, event));
        
        // 4. 考试/假期等外部因素检测
        causes.addAll(checkExternalFactors(userId, event));
        
        // 5. 学习疲劳积累检测
        causes.addAll(checkBurnoutAccumulation(userId, event));
        
        // 6. 学习兴趣转移检测
        causes.addAll(checkInterestShift(userId, event));
        
        // 7. 进度停滞检测
        causes.addAll(checkProgressStagnation(userId, event));
        
        // 按置信度排序
        causes.sort(Comparator.comparing(DiagnosedCause::getConfidence).reversed());
        
        return causes.size() > 5 ? causes.subList(0, 5) : causes;
    }

    /**
     * 内容难度突升检测
     */
    private List<DiagnosedCause> checkDifficultySpike(Long userId, LearningGapEvent event) {
        List<DiagnosedCause> results = new ArrayList<>();
        
        // 获取断更前7天的学习难度趋势
        List<DailyDifficultyStat> trends = studyRecordQueryService
            .getDailyDifficultyTrend(userId, 7);
        
        if (trends.size() >= 3) {
            double recentAvg = avg(trends.subList(0, 3).stream()
                .mapToDouble(DailyDifficultyStat::getAvgDifficulty));
            double beforeAvg = avg(trends.subList(3, trends.size()).stream()
                .mapToDouble(DailyDifficultyStat::getAvgDifficulty));
            
            double difficultyIncrease = recentAvg - beforeAvg;
            
            if (difficultyIncrease >= 2.0) { // 难度提升2级以上
                DiagnosedCause cause = new DiagnosedCause();
                cause.setCause("CONTENT_DIFFICULTY_SPIKE");
                cause.setConfidence(calculateConfidence(difficultyIncrease));
                cause.setEvidence(String.format(
                    "断更前学习难度从%.1f升至%.1f，提升%.1f级，对应知识点：%s",
                    beforeAvg, recentAvg, difficultyIncrease,
                    event.getLastKnowledgePointId()
                ));
                cause.setSuggestedStrategy("REVIEW_BRIDGE"); // 建议使用桥接复习策略
                results.add(cause);
            }
        }
        
        return results;
    }

    /**
     * 正确率急剧下降检测
     */
    private List<DiagnosedCause> checkAccuracyDrop(Long userId, LearningGapEvent event) {
        List<DiagnosedCause> results = new ArrayList<>();
        
        AccuracyTrend trend = accuracyTrendService.getAccuracyTrend(userId, 14);
        
        if (trend.getRecent7dAccuracy() != null && trend.getPrevious7dAccuracy() != null) {
            double drop = trend.getPrevious7dAccuracy()
                .subtract(trend.getRecent7dAccuracy()).doubleValue();
            
            if (drop >= 20.0) { // 正确率下降超过20%
                DiagnosedCause cause = new DiagnosedCause();
                cause.setCause("ACCURACY_DROP");
                cause.setConfidence(Math.min(drop / 50.0, 0.95));
                cause.setEvidence(String.format(
                    "断更前7天正确率%.1f%%，前7天为%.1f%%，下降%.1f个百分点",
                    trend.getRecent7dAccuracy(), trend.getPrevious7dAccuracy(), drop
                ));
                cause.setSuggestedStrategy("EASIER_CONTENT_FIRST");
                results.add(cause);
            }
        }
        
        return results;
    }

    /**
     * 外部因素检测（考试、假期、节假日）
     */
    private List<DiagnosedCause> checkExternalFactors(Long userId, LearningGapEvent event) {
        List<DiagnosedCause> results = new ArrayList<>();
        
        CalendarContext ctx = calendarContextService.getContext(
            event.getLastStudyTime().toLocalDate()
        );
        
        if (ctx.isExamPeriodRecentlyEnded()) {
            DiagnosedCause cause = new DiagnosedCause();
            cause.setCause("EXAM_PERIOD_END");
            cause.setConfidence(0.65);
            cause.setEvidence("期末/期中考试刚结束，历史数据显示此节点断更概率增加3.2倍");
            cause.setSuggestedStrategy("LIGHT_RESTART");
            results.add(cause);
        }
        
        if (ctx.isHolidayPeriod()) {
            DiagnosedCause cause = new DiagnosedCause();
            cause.setCause("HOLIDAY_PERIOD");
            cause.setConfidence(0.55);
            cause.setEvidence("当前处于假期时段，学生学习意愿普遍降低");
            cause.setSuggestedStrategy("HOLIDAY_CAMP");
            results.add(cause);
        }
        
        return results;
    }

    /**
     * 学习疲劳积累检测
     */
    private List<DiagnosedCause> checkBurnoutAccumulation(Long userId, LearningGapEvent event) {
        List<DiagnosedCause> results = new ArrayList<>();
        
        // 断更前7天日均学习时长 vs 前30天日均
        Integer avg7d = studyRecordQueryService.getAvgDailyMinutes(userId, 7);
        Integer avg30d = studyRecordQueryService.getAvgDailyMinutes(userId, 30);
        
        if (avg7d != null && avg30d != null && avg30d > 0) {
            double ratio = (double) avg7d / avg30d;
            
            if (ratio > 1.8 && avg7d > 120) {
                // 断更前突击学习（超过日常1.8倍且超过2小时），可能是疲劳积累
                DiagnosedCause cause = new DiagnosedCause();
                cause.setCause("BURNOUT_FROM_OVERSTUDY");
                cause.setConfidence(0.70);
                cause.setEvidence(String.format(
                    "断更前7天日均学习%d分钟，是日常水平的%.1f倍，疑似疲劳积累",
                    avg7d, ratio
                ));
                cause.setSuggestedStrategy("GENTLE_RESTART");
                results.add(cause);
            }
        }
        
        return results;
    }
    
    // ... 其他诊断方法类似
}
```

### 4.3 回归概率预测模型

采用**Logistic Regression + 特征工程**方案（可解释、快速迭代），后续可升级为GBDT。

```java
/**
 * 回归概率预测器
 */
@Service
public class ReturnProbabilityPredictor {

    @Autowired
    private FeatureStoreClient featureStoreClient;

    // 模型权重（通过离线训练获得，定期更新）
    private static final Map<String, Double> MODEL_WEIGHTS = Map.ofEntries(
        Map.entry("bias", -0.5),
        Map.entry("gap_days", -0.08),           // 断更天数越长，回归概率越低
        Map.entry("streak_before_gap", 0.03),    // 断更前连续学习天数越长，回归概率越高
        Map.entry("resilience_score", 0.015),    // 韧性评分越高越好
        Map.entry("membership_active", 0.6),     // 会员状态有效
        Map.entry("parent_bound", 0.3),          // 已绑定家长
        Map.entry("plan_completion_rate", 1.2),  // 学习计划完成率
        Map.entry("recent_accuracy", 0.008),     // 近期正确率
        Map.entry("has_social_connection", 0.4), // 有社交关系（同学/班级）
        Map.entry("total_study_days_90d", 0.01), // 近90天总学习天数
        Map.entry("gap_count_90d", -0.15),       // 近90天断更次数（越多越不回来）
        Map.entry("last_subject_math", 0.1),     // 最后学数学的略容易回来
        Map.entry("difficulty_spike", -0.8),     // 难度突升降低回归概率
        Map.entry("accuracy_drop", -0.6)         // 正确率突降降低回归概率
    );

    /**
     * 预测回归概率
     * @return 0-100 的概率分数
     */
    public BigDecimal predict(LearningGapEvent event) {
        Map<String, Double> features = extractFeatures(event);
        
        double logit = MODEL_WEIGHTS.get("bias");
        for (Map.Entry<String, Double> entry : MODEL_WEIGHTS.entrySet()) {
            if ("bias".equals(entry.getKey())) continue;
            Double featureValue = features.get(entry.getKey());
            if (featureValue != null) {
                logit += entry.getValue() * featureValue;
            }
        }
        
        double probability = 1.0 / (1.0 + Math.exp(-logit));
        return BigDecimal.valueOf(probability * 100)
            .setScale(2, RoundingMode.HALF_UP);
    }

    private Map<String, Double> extractFeatures(LearningGapEvent event) {
        Map<String, Double> features = new HashMap<>();
        
        // 归一化断更天数 (cap at 60)
        features.put("gap_days", Math.min(event.getGapDays(), 60.0));
        
        features.put("streak_before_gap", 
            Math.min(event.getAvgDailyMinutesBeforeGap() != null ? 
                event.getAvgDailyMinutesBeforeGap() / 10.0 : 0, 10.0));
        
        // 从Feature Store获取用户特征
        UserFeatureVector uv = featureStoreClient.getFeatures(event.getUserId());
        features.put("resilience_score", uv.getResilienceScore() / 100.0);
        features.put("membership_active", uv.isMembershipActive() ? 1.0 : 0.0);
        features.put("parent_bound", uv.isParentBound() ? 1.0 : 0.0);
        features.put("plan_completion_rate", 
            event.getPlanCompletionRate() != null ? 
            event.getPlanCompletionRate().doubleValue() / 100.0 : 0.5);
        features.put("recent_accuracy", 
            event.getLastAccuracy() != null ? 
            event.getLastAccuracy().doubleValue() : 50.0);
        features.put("has_social_connection", uv.hasClassConnection() ? 1.0 : 0.0);
        features.put("total_study_days_90d", Math.min(uv.getStudyDays90d(), 90.0));
        features.put("gap_count_90d", Math.min(uv.getGapCount90d(), 10.0));
        
        // 从诊断结果提取
        if (event.getDiagnosedCausesJson() != null) {
            List<DiagnosedCause> causes = JsonUtils.parseList(
                event.getDiagnosedCausesJson(), DiagnosedCause.class);
            features.put("difficulty_spike", 
                causes.stream().anyMatch(c -> "CONTENT_DIFFICULTY_SPIKE".equals(c.getCause())) ? 1.0 : 0.0);
            features.put("accuracy_drop", 
                causes.stream().anyMatch(c -> "ACCURACY_DROP".equals(c.getCause())) ? 1.0 : 0.0);
        }
        
        return features;
    }
}
```

```java
public class RiskLevelEvaluator {

    public static String evaluate(int gapDays, BigDecimal returnProbability) {
        double prob = returnProbability.doubleValue();
        
        // 矩阵：断更天数 × 回归概率
        if (gapDays >= 21 || prob < 15) {
            return "CRITICAL";  // 极高风险：几乎不会自然回归
        }
        if (gapDays >= 14 || prob < 30) {
            return "HIGH";      // 高风险：需要主动干预
        }
        if (gapDays >= 7 || prob < 50) {
            return "MEDIUM";    // 中风险：适度干预
        }
        return "LOW";           // 低风险：轻量提醒即可
    }
```

```java
        LocalDateTime firstTrigger = calculateFirstTriggerTime(event, config);

            AwakeningStep step = new AwakeningStep();
            step.setStepIndex(i);

            steps.add(step);
        }
        
        return steps;
```

```java
/**
 * 唤醒步骤执行调度器
 */
@Service
@Slf4j
public class AwakeningStepScheduler {

    @Autowired
    private MessageDispatchService messageDispatchService;
    @Autowired
    private AwakeningPlanMapper planMapper;
    @Autowired
    private AwakeningStepExecutionMapper stepExecutionMapper;

    /**
     * 定时扫描并执行到期的唤醒步骤
     * 每小时执行一次
     */
    @Scheduled(cron = "0 0 * * * *")
    public void executeDueSteps() {
        List<AwakeningPlan> activePlans = planMapper.findExecutingPlans(LocalDateTime.now());
        
        for (AwakeningPlan plan : activePlans) {
            try {
                executeNextStep(plan);
            } catch (Exception e) {
                log.error("唤醒步骤执行异常 planId={}", plan.getId(), e);
            }
        }
    }

    private void executeNextStep(AwakeningPlan plan) {
        List<AwakeningStep> steps = JsonUtils.parseList(
            plan.getStepsJson(), AwakeningStep.class);
        
        if (plan.getCurrentStepIndex() >= steps.size()) {
            // 所有步骤执行完毕
            plan.setStatus("COMPLETED");
            planMapper.updateById(plan);
            return;
        }
        
        AwakeningStep step = steps.get(plan.getCurrentStepIndex());
        
        // 检查是否到期
        if (step.getScheduledTime().isAfter(LocalDateTime.now())) {
            return;
        }
        
        // 执行投递
        AwakeningStepExecution execution = new AwakeningStepExecution();
        execution.setPlanId(plan.getId());
        execution.setStepIndex(plan.getCurrentStepIndex());
        execution.setChannelType(step.getChannelType());
        execution.setTriggeredAt(LocalDateTime.now());
        
        try {
            DispatchResult result = messageDispatchService.dispatch(
                DispatchRequest.builder()
                    .userId(plan.getUserId())
                    .channel(step.getChannelType())
                    .title(step.getContent().getTitle())
                    .body(step.getContent().getBody())
                    .deepLink(step.getContent().getDeepLink())
                    .build()
            );
            
            execution.setDeliveryStatus(result.getStatus());
            execution.setProviderMessageId(result.getMessageId());
            execution.setMessageTemplateId(step.getContent().getTemplateId());
            
            // 调度下一步
            plan.setCurrentStepIndex(plan.getCurrentStepIndex() + 1);
            
        } catch (Exception e) {
            execution.setDeliveryStatus("FAILED");
            log.error("唤醒消息投递失败 planId={} step={}", 
                plan.getId(), plan.getCurrentStepIndex(), e);
            
            // 失败重试逻辑：最多重试2次
            if (shouldRetry(plan, step)) {
                reschedule(step, LocalDateTime.now().plusHours(6));
                return;
            }
        }
        
        stepExecutionMapper.insert(execution);
        
        // 如果是最后一步，更新计划状态
        if (plan.getCurrentStepIndex() >= steps.size()) {
            plan.setStatus("COMPLETED");
        }
        
        planMapper.updateById(plan);
    }

    /**
     * 用户学习恢复回调处理
     */
    @EventListener
    @Async
    public void onStudyEvent(StudyBehaviorEvent event) {
        // 检查该用户是否有活跃的断更事件
        LearningGapEvent gapEvent = gapEventService
            .findActiveByUserId(event.getUserId());
        
        if (gapEvent == null) return;
        
        // 标记回归
        gapEvent.setStatus("RETURNED");
        gapEvent.setUpdatedAt(LocalDateTime.now());
        gapEventService.update(gapEvent);
        
        // 更新唤醒计划
        AwakeningPlan plan = planMapper.findByGapEventId(gapEvent.getId());
        if (plan != null && !"COMPLETED".equals(plan.getStatus())) {
            plan.setStatus("COMPLETED");
            planMapper.updateById(plan);
            
            // 记录回归步骤
            AwakeningStepExecution stepExec = stepExecutionMapper
                .findLatestByPlanId(plan.getId());
            if (stepExec != null) {
                stepExec.setUserResponse("STUDIED");
                stepExec.setRespondedAt(LocalDateTime.now());
                stepExec.setResponseLatencyMinutes(
                    (int) ChronoUnit.MINUTES.between(
                        stepExec.getTriggeredAt(), LocalDateTime.now())
                );
                stepExecutionMapper.updateById(stepExec);
            }
        }
        
        // 触发回归后体验：推送"欢迎回来"内容推荐
        publishReturnExperienceEvent(gapEvent, plan);
        
        // 更新效果统计
        effectStatsService.recordReturn(plan.getStrategyTemplateId(), 
            gapEvent.getGapDays());
        
        // 设置冷却期，7天内不再触发新的断更检测
        strategyService.setCooldown(event.getUserId(), 7);
    }
}
```

```java
/**
 * 学习习惯韧性评分服务
 * 定期计算（每天凌晨3点），基于近30天行为数据
 */
@Service
@Slf4j
public class HabitResilienceService {

    /**
     * 计算韧性评分
     * 评分维度权重：
     * - streak_score (25%): 连续学习天数
     * - frequency_score (25%): 学习频率稳定性
     * - duration_score (20%): 学习时长一致性
     * - return_rate_score (15%): 历史断更后回归率
     * - timing_score (15%): 学习时间段集中度
     */
    public HabitResilienceScore calculate(Long userId) {
        LocalDate today = LocalDate.now();
        
        // 获取近30天学习行为数据
        StudyBehaviorData data = studyBehaviorDataService.load(userId, today, 30);
        
        HabitResilienceScore score = new HabitResilienceScore();
        score.setUserId(userId);
        score.setScoreDate(today);
        
        // 1. 连续学习天数维度 (0-100)
        int currentStreak = data.getCurrentStreakDays();
        int maxStreak = data.getMaxStreakDays();
        double streakScore = Math.min(currentStreak * 3.0 + maxStreak * 0.5, 100.0);
        score.setStreakScore(BigDecimal.valueOf(streakScore));
        score.setCurrentStreakDays(currentStreak);
        score.setMaxStreakDays(maxStreak);
        
        // 2. 学习频率稳定性 (0-100)
        // 计算近30天有学习的天数比例，以及周分布的标准差
        int studyDays = data.getStudyDaysCount();
        double frequencyRatio = studyDays / 30.0;
        double weeklyStdDev = calculateWeeklyStdDev(data.getDailyStudyFlags());
        double frequencyScore = frequencyRatio * 80 + (1 - Math.min(weeklyStdDev, 1.0)) * 20;
        score.setFrequencyScore(BigDecimal.valueOf(frequencyScore));
        
        // 3. 学习时长一致性 (0-100)
        // 计算日均学习时长的变异系数(CV)，CV越低越稳定
        List<Integer> dailyMinutes = data.getDailyStudyMinutes();
        double meanMinutes = mean(dailyMinutes);
        double stdDevMinutes = stdDev(dailyMinutes, meanMinutes);
        double cv = meanMinutes > 0 ? stdDevMinutes / meanMinutes : 1.0;
        double durationScore = Math.max(0, (1 - Math.min(cv, 1.0)) * 100);
        score.setDurationScore(BigDecimal.valueOf(durationScore));
        
        // 4. 历史断更后回归率 (0-100)
        int totalGaps = data.getHistoricalGapCount();
        int returnedGaps = data.getHistoricalReturnedCount();
        double returnRate = totalGaps > 0 ? (double) returnedGaps / totalGaps : 0.8;
        double returnRateScore = returnRate * 100;
        score.setReturnRateScore(BigDecimal.valueOf(returnRateScore));
        score.setGapCount90d(data.getGapCount90d());
        
        // 5. 学习时间段集中度 (0-100)
        // 检测学生是否有固定的学习时间段
        double timingConcentration = calculateTimingConcentration(
            data.getStudyHourHistogram()
        );
        double timingScore = timingConcentration * 100;
        score.setTimingScore(BigDecimal.valueOf(timingScore));
        
        // 计算总评分
        double total = streakScore * 0.25 
            + frequencyScore * 0.25 
            + durationScore * 0.20 
            + returnRateScore * 0.15 
            + timingScore * 0.15;
        
        score.setTotalScore(BigDecimal.valueOf(total).setScale(2, RoundingMode.HALF_UP));
        
        // 计算趋势
        HabitResilienceScore previous = getScoreBefore(userId, today, 7);
        if (previous != null) {
            double diff = total - previous.getTotalScore().doubleValue();
            if (diff > 3) score.setTrend("IMPROVING");
            else if (diff < -3) score.setTrend("DECLINING");
            else score.setTrend("STABLE");
        } else {
            score.setTrend("STABLE");
        }
        
        // 生成风险标签
        score.setRiskTagsJson(generateRiskTags(score, data));
        
        return score;
    }

    /**
     * 生成风险标签
     */
    private String generateRiskTags(HabitResilienceScore score, StudyBehaviorData data) {
        List<String> tags = new ArrayList<>();
        
        if (score.getStreakScore().doubleValue() < 30) {
            tags.add("LOW_STREAK");
        }
        if (score.getFrequencyScore().doubleValue() < 40) {
            tags.add("IRREGULAR_FREQUENCY");
        }
        if (score.getDurationScore().doubleValue() < 40) {
            tags.add("INCONSISTENT_DURATION");
        }
        if (score.getReturnRateScore().doubleValue() < 50) {
            tags.add("LOW_RETURN_RATE");
        }
        if (score.getGapCount90d() >= 3) {
            tags.add("FREQUENT_GAPPER");
        }
        if (data.isAfterExamPeriod()) {
            tags.add("POST_EXAM");
        }
        if (data.isInHoliday()) {
            tags.add("HOLIDAY_RISK");
        }
        
        return JsonUtils.toJson(tags);
    }
}
```

## 5. 状态流转

### 5.1 断更事件状态机

```
                  ┌───────────┐
                  │  DETECTED  │ ← 扫描检测到断更
                  └──────┬─────┘
                         │ 诊断完成
                         ▼
                  ┌───────────┐
                  │ DIAGNOSED  │ ← 原因诊断、回归概率预测完成
                  └──────┬─────┘
                         │ 策略生成
                         ▼
              ┌──────────────────┐
              │ STRATEGY_GENERATED│ ← 唤醒计划已生成
              └────────┬─────────┘
                       │ 首步触发
                       ▼
                ┌────────────┐
       ┌───────│ AWAKENING   │───────┐
       │        └─────┬──────┘        │
       │ 用户回归      │ 所有步骤完成    │ 计划过期
       │              │ 且未回归        │
       ▼              ▼               ▼
  ┌─────────┐  ┌───────────┐  ┌─────────┐
  │ RETURNED │  │ COMPLETED │  │ EXPIRED  │
  └─────────┘  └───────────┘  └─────────┘
```

### 5.2 唤醒计划状态机

```
  ┌─────────┐     到期触发      ┌──────────┐
  │ PENDING  │ ──────────────→ │EXECUTING  │
  └────┬─────┘                  └────┬──────┘
       │                             │
       │ 首步前用户回归                 │ 用户回归/所有步骤完成
       ▼                             ▼
  ┌──────────┐               ┌───────────┐
  │CANCELLED  │               │ COMPLETED  │
  └──────────┘               └───────────┘
```

### 5.3 步骤投递状态

```
  PENDING → SENT → DELIVERED → (NONE | OPENED | CLICKED | STUDIED | DISMISSED)
                                                  │
                                            SKIPPED (用户关闭通知/冷却期内)
                                            FAILED (投递失败 → 重试或跳过)
```

## 7. 消息推送文案规范

### 7.1 文案原则

## 8. 效果评估与闭环

### 8.1 效果追踪指标

```java
/**
 * 唤醒效果追踪服务
 */
@Service
public class AwakeningEffectTrackingService {

    /**
     * 每周统计各策略模板效果
     */
    @Scheduled(cron = "0 0 4 * * MON")  // 每周一凌晨4点
    public void weeklyEffectCalculation() {
        LocalDate weekStart = LocalDate.now().minusWeeks(1);
        List<String> templateIds = strategyRegistry.getAllTemplateIds();
        
        for (String templateId : templateIds) {
            AwakeningEffectStats stats = calculateStats(templateId, weekStart);
            effectStatsMapper.insertOrUpdate(stats);
        }
        
        // 根据效果自动调整策略权重
        adjustStrategyWeights();
    }

    private AwakeningEffectStats calculateStats(String templateId, LocalDate weekStart) {
        List<AwakeningPlan> plans = planMapper.findByTemplateAndPeriod(
            templateId, weekStart, weekStart.plusDays(7)
        );
        
        int total = plans.size();
        int returned = 0;
        int ignored = 0;
        int unsubscribed = 0;
        List<Long> returnHours = new ArrayList<>();
        
        for (AwakeningPlan plan : plans) {
            LearningGapEvent gapEvent = gapEventService.getById(plan.getGapEventId());
            if ("RETURNED".equals(gapEvent.getStatus())) {
                returned++;
                long hours = ChronoUnit.HOURS.between(
                    plan.getCreatedAt(),
                    gapEvent.getUpdatedAt()
                );
                returnHours.add(hours);
            } else if (hasUserUnsubscribed(plan.getUserId())) {
                unsubscribed++;
            } else {
                ignored++;
            }
        }
        
        // 计算回归后留存
        BigDecimal retention7d = calculateRetention(
            plans, returned, 7
        );
        BigDecimal retention30d = calculateRetention(
            plans, returned, 30
        );
        
        AwakeningEffectStats stats = new AwakeningEffectStats();
        stats.setStrategyTemplateId(templateId);
        stats.setPeriod(formatWeek(weekStart));
        stats.setTotalExecutions(total);
        stats.setSuccessfulReturns(returned);
        stats.setIgnoredCount(ignored);
        stats.setUnsubscribedCount(unsubscribed);
        stats.setAvgReturnHours(returnHours.isEmpty() ? null : 
            BigDecimal.valueOf(mean(returnHours)));
        stats.setRetention7dRate(retention7d);
        stats.setRetention30dRate(retention30d);
        
        // 效果评分 = 回归率 * 0.4 + 7日留存 * 0.3 + 30日留存 * 0.2 - 退订率 * 0.1
        double returnRate = total > 0 ? (double) returned / total : 0;
        double unsubscribeRate = total > 0 ? (double) unsubscribed / total : 0;
        double effectiveness = returnRate * 40 
            + retention7d.doubleValue() * 0.3 
            + retention30d.doubleValue() * 0.2 
            - unsubscribeRate * 10;
        stats.setEffectivenessScore(
            BigDecimal.valueOf(Math.max(0, effectiveness)).setScale(2, RoundingMode.HALF_UP)
        );
        
        return stats;
    }

    /**
     * 根据效果数据自动调整策略权重
     * 效果好的策略优先级提升，效果差的降级或触发人工评审
     */
    private void adjustStrategyWeights() {
        List<AwakeningEffectStats> recentStats = effectStatsMapper.findRecentWeeks(4);
        
        for (AwakeningEffectStats stats : recentStats) {
            double score = stats.getEffectivenessScore().doubleValue();
            
            if (score < 15 && stats.getTotalExecutions() > 50) {
                // 效果持续很差，触发告警
                alertService.sendAlert(
                    "STRATEGY_UNDERPERFORMING",
                    String.format("策略 %s 近4周效果评分仅 %.1f，需人工评审",
                        stats.getStrategyTemplateId(), score)
                );
            }
            
            if (score > 60) {
                // 效果很好，可以作为推荐策略
                strategyRegistry.markAsRecommended(
                    stats.getStrategyTemplateId()
                );
            }
        }
    }
}
```

```java
/**
 * 断更扫描使用批量查询 + 分片处理
 * 避免逐用户查询导致的N+1问题
 */
@Service
public class OptimizedGapScanner {

    /**
     * 单次扫描5000用户，使用批量SQL获取最后学习时间
     */
    @Scheduled(cron = "0 0 2 * * *")
    public void optimizedDailyScan() {
        int shardCount = 10;
        int shardSize = 5000;
        
        // 分片并行处理
        CompletableFuture<?>[] futures = new CompletableFuture[shardCount];
        for (int i = 0; i < shardCount; i++) {
            final int shardIndex = i;
            futures[i] = CompletableFuture.runAsync(() -> {
                List<Long> userIds = userShardMapper.getShard(shardIndex, shardSize);
                
                // 批量获取最后学习时间
                Map<Long, LocalDateTime> lastStudyMap = 
                    userActiveRecordMapper.batchGetLastStudyTime(userIds);
                
                // 批量获取韧性评分
                Map<Long, HabitResilienceScore> resilienceMap = 
                    resilienceService.batchGetLatest(userIds);
                
                // 批量检查冷却期
                Set<Long> inCooldown = strategyService.batchCheckCooldown(userIds);
                
                // 处理每个用户
                for (Long userId : userIds) {
                    if (inCooldown.contains(userId)) continue;
                    LocalDateTime lastStudy = lastStudyMap.get(userId);
                    if (lastStudy == null) continue;
                    
                    processUserGap(userId, lastStudy, resilienceMap.get(userId));
                }
            }, gapScanExecutor);
        }
        
        CompletableFuture.allOf(futures).join();
    }
}
```

## 10. 安全考虑

### 10.1 隐私保护

- **家长通知隐私**：家长通知内容不暴露学生具体答题数据，仅提示学习中断状态
- **数据访问控制**：断更诊断数据仅限系统内部服务和有权限的管理员查看
- **数据脱敏**：管理后台展示时对低龄用户昵称进行脱敏处理
- **通知频次限制**：单用户7天内最多触发一次完整唤醒流程，避免骚扰

### 10.2 防滥用

```java
/**
 * 唤醒频次控制
 */
@Component
public class AwakeningFrequencyGuard {

    private static final int MAX_CONCURRENT_PLANS = 1;  // 单用户最多1个活跃计划
    private static final int COOLDOWN_DAYS = 7;         // 冷却期7天
    private static final int MAX_STEPS_PER_PLAN = 5;    // 单计划最多5步
    private static final int MAX_TOTAL_NOTIFICATIONS_30D = 8; // 30天内最多8次唤醒通知

    public void validate(Long userId) {
        // 检查并发计划数
        int activeCount = planMapper.countActiveByUser(userId);
        if (activeCount >= MAX_CONCURRENT_PLANS) {
            throw new BusinessException("GAP_PLAN_ALREADY_ACTIVE", 
                "用户已有活跃唤醒计划");
        }
        
        // 检查冷却期
        if (isInCooldown(userId)) {
            throw new BusinessException("GAP_PLAN_IN_COOLDOWN",
                "用户处于唤醒冷却期");
        }
        
        // 检查30天通知总数
        int recentCount = stepExecutionMapper.countByUserAndPeriod(
            userId, LocalDateTime.now().minusDays(30)
        );
        if (recentCount >= MAX_TOTAL_NOTIFICATIONS_30D) {
            log.warn("用户{}近30天唤醒通知已达上限{}", userId, recentCount);
            throw new BusinessException("GAP_FREQUENCY_EXCEEDED",
                "近30天唤醒通知次数已达上限");
        }
    }
}
```
