# 客户端-学习内容统一阅读器核心架构与沉浸式阅读体验管理引擎-详细设计

## 1. 概述

### 1.1 模块定位

学习内容统一阅读器（Unified Content Reader，简称 **UCR**）是 PrimeTop 客户端的核心基础组件，负责承载所有结构化教育内容的展示、交互与阅读体验管理。它是同步课堂、知识点讲解、考点梳理、文科背诵等多个业务模块的底层渲染容器。

UCR 不是某个特定功能的阅读器，而是一个**通用内容消费框架**——类似于浏览器引擎之于网页。各业务模块通过 UCR 提供的标准接口注册内容类型、挂载交互插件，由 UCR 统一管理渲染流程、阅读进度、显示设置、资源加载和性能调优。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 统一渲染 | 一套渲染管线支持图文、富文本、公式、音视频、交互组件等多种内容类型 |
| 插件化扩展 | 批注、高亮、查词、即时练习等作为插件动态挂载，互不耦合 |
| 沉浸体验 | 提供专注模式、护眼模式、朗读模式等沉浸式阅读体验 |
| 进度追踪 | 细粒度阅读进度追踪，支持跨设备同步与断点续读 |
| 个性化适配 | 字号、行距、配色、字体等用户可自定义，并按学段提供预设方案 |
| 性能保障 | 大文档虚拟滚动、按需渲染、内存复用，确保低端设备流畅 |
| 离线可用 | 内容预缓存支持离线阅读，网络恢复后自动同步进度 |

### 1.3 适用范围

- **同步课堂**：教材章节内容、课文正文、知识讲解
- **考点梳理**：考点清单、专题说明、知识总结
- **错题解析**：错题详细解析、解题步骤展示
- **AI 对话**：AI 回答的长文本渲染（卡片化展示）
- **文科背诵**：背诵材料分段展示、填空式记忆卡片
- **作文辅导**：范文展示、批改报告
- **所有需要结构化内容展示的场景**

### 1.4 与现有模块的关系

| 模块 | 关系 |
| --- | --- |
| `客户端-学习内容统一卡片系统与智能渲染引擎` | 卡片系统是 UCR 的内容承载单元，UCR 负责卡片的排列、滚动与生命周期管理 |

### 2.2 核心设计原则

1. **内容与渲染分离**：内容数据以结构化 JSON 描述，渲染器根据描述选择对应适配器渲染，不耦合具体业务逻辑。
2. **插件零侵入**：插件通过事件总线订阅阅读器事件（如文本选中、滚动、区块进入视口），不修改阅读器核心代码。
3. **渐进式增强**：基础阅读功能零依赖，高级功能（批注、查词、练习）按需加载。
4. **响应式适配**：阅读区域自动适配横竖屏、平板宽屏、折叠屏等不同屏幕形态。

### 3.1 阅读内容文档模型 (ReaderDocument)

### 4.2 块适配器注册体系

每种内容块类型对应一个 `BlockAdapter`，负责将结构化数据渲染为 Flutter Widget。第三方业务模块可注册自定义适配器。

```dart
/// 块适配器接口
abstract class BlockAdapter {
  /// 此适配器处理的内容块类型
  ContentBlockType get supportedType;

  /// 构建渲染 Widget
  Widget buildWidget(
    BuildContext context,
    ContentBlock block,
    BlockAdapterContext adapterContext,
  );

  /// 预估块的渲染高度（用于虚拟滚动布局计算）
  double estimateHeight(
    ContentBlock block,
    DisplaySettings settings,
    double viewportWidth,
  );

  /// 块进入视口时回调
  void onBlockEnterViewport(ContentBlock block, ReaderController controller) {}

  /// 块离开视口时回调
  void onBlockLeaveViewport(ContentBlock block, ReaderController controller) {}

  /// 是否支持选中文字
  bool get isTextSelectable => false;

  /// 是否可聚焦（朗读模式焦点）
  bool get isFocusable => true;
}

/// 适配器上下文（提供阅读器核心能力）
class BlockAdapterContext {
  final ReaderController controller;
  final DisplaySettings displaySettings;
  final ReaderThemePalette themePalette;
  final PluginManager pluginManager;
  final ResourceLoader resourceLoader;
}
```

### 4.3 适配器注册中心

```dart
/// 块适配器注册中心
class BlockAdapterRegistry {
  final Map<ContentBlockType, BlockAdapter> _adapters = {};
  final Map<String, BlockAdapter> _customAdapters = {};

  /// 注册标准块适配器
  void registerAdapter(BlockAdapter adapter) {
    _adapters[adapter.supportedType] = adapter;
  }

  /// 注册自定义块适配器（业务自定义类型）
  void registerCustomAdapter(String customType, BlockAdapter adapter) {
    _customAdapters[customType] = adapter;
  }

  /// 获取适配器
  BlockAdapter? resolveAdapter(ContentBlock block) {
    // 先查标准类型
    final adapter = _adapters[block.type];
    if (adapter != null) return adapter;

    // 再查自定义类型
    final customType = block.data['customType'] as String?;
    if (customType != null) {
      return _customAdapters[customType];
    }

    // 返回默认降级适配器
    return _adapters[ContentBlockType.paragraph];
  }
}
```

## 5. 虚拟滚动引擎

### 5.1 设计动机

教育内容文档可能包含数百个内容块（如整章教材），一次性渲染所有块会导致严重的性能问题。UCR 使用虚拟滚动（Virtual Scrolling）技术，仅渲染当前视口及其缓冲区内的块。

### 5.2 核心实现

```dart
/// 虚拟滚动控制器
class VirtualScrollController {
  /// 全部内容块列表
  final List<ContentBlock> _allBlocks;

  /// 块高度缓存（blockId → 高度）
  final Map<String, double> _heightCache = {};

  /// 累计高度前缀和（用于快速定位）
  final List<double> _prefixHeights = [];

  /// 当前可视区域块索引范围
  (int, int) _visibleRange = (0, 0);

  /// 视口上下缓冲块数量
  static const int _bufferCount = 5;

  /// 滚动位置 → 对应块索引（二分查找）
  int _findBlockIndexAtOffset(double offset) {
    int lo = 0, hi = _prefixHeights.length - 1;
    while (lo < hi) {
      final mid = (lo + hi + 1) >> 1;
      if (_prefixHeights[mid] <= offset) {
        lo = mid;
      } else {
        hi = mid - 1;
      }
    }
    return lo;
  }

  /// 计算当前可视范围
  (int, int) computeVisibleRange(
    double viewportTop,
    double viewportHeight,
  ) {
    final startIndex = max(0,
        _findBlockIndexAtOffset(viewportTop) - _bufferCount);
    final endIndex = min(
        _allBlocks.length - 1,
        _findBlockIndexAtOffset(viewportTop + viewportHeight) + _bufferCount,
    );
    return (startIndex, endIndex);
  }

  /// 更新块实际高度（渲染后回调）
  void updateBlockHeight(String blockId, double actualHeight) {
    final cached = _heightCache[blockId];
    if (cached != null && (cached - actualHeight).abs() < 1.0) return;

    _heightCache[blockId] = actualHeight;
    _rebuildPrefixHeights();
  }

  /// 重建高度前缀和
  void _rebuildPrefixHeights() {
    double cumulative = 0;
    for (int i = 0; i < _allBlocks.length; i++) {
      final height = _heightCache[_allBlocks[i].blockId] ??
          _allBlocks[i].estimatedHeight;
      cumulative += height;
      if (i < _prefixHeights.length) {
        _prefixHeights[i] = cumulative;
      } else {
        _prefixHeights.add(cumulative);
      }
    }
  }

  /// 获取块在文档中的偏移量（用于滚动跳转）
  double getBlockOffset(String blockId) {
    final index = _allBlocks.indexWhere((b) => b.blockId == blockId);
    if (index < 0) return 0;
    return index > 0 ? _prefixHeights[index - 1] : 0;
  }
}
```

### 5.4 高度估算策略

虚拟滚动依赖准确的高度估算来计算滚动条位置和总文档高度。

```dart
/// 块高度估算器
class BlockHeightEstimator {
  /// 基于内容特征的估算
  static double estimate(
    ContentBlock block,
    DisplaySettings settings,
    double viewportWidth,
  ) {
    final contentWidth = viewportWidth - settings.pagePadding.horizontal;

    switch (block.type) {
      case ContentBlockType.heading:
        final level = block.data['level'] as int? ?? 2;
        final baseHeight = [0, 32, 28, 24, 22, 20, 18][level.clamp(0, 6)];
        return (baseHeight * settings.fontScale * 1.8) + 16;

      case ContentBlockType.paragraph:
      case ContentBlockType.richText:
        final text = block.data['text'] as String? ?? '';
        final charsPerLine = (contentWidth / (16 * settings.fontScale)).floor();
        final lineCount = (text.length / charsPerLine).ceil().clamp(1, 999);
        return lineCount * 24 * settings.fontScale * settings.lineSpacing
            + 12 * settings.paragraphSpacing;

      case ContentBlockType.image:
        final aspectRatio = block.data['aspectRatio'] as double? ?? (16 / 9);
        final imgWidth = block.data['width'] as double? ?? contentWidth;
        final renderWidth = min(imgWidth, contentWidth);
        return renderWidth / aspectRatio + 40; // +caption

      case ContentBlockType.formula:
        return 60 * settings.fontScale + 12;

      case ContentBlockType.table:
        return 200; // 保守估算，渲染后修正

      case ContentBlockType.audio:
        return 56; // 固定高度播放器

      case ContentBlockType.video:
        final aspect = block.data['aspectRatio'] as double? ?? (16 / 9);
        return contentWidth / aspect + 8;

      case ContentBlockType.callout:
        final text = block.data['text'] as String? ?? '';
        final lineCount = (text.length / 30).ceil().clamp(1, 20);
        return lineCount * 24 * settings.fontScale + 48;

      case ContentBlockType.quiz:
        return 180; // 练习块默认高度，渲染后修正

      default:
        return 80;
    }
  }
}
```

```dart
/// 插件管理器
class PluginManager {
  final Map<String, UCRPlugin> _plugins = {};
  final EventBus _eventBus = EventBus();
  late UCRPluginContext _context;

  /// 注册插件
  void registerPlugin(UCRPlugin plugin) {
    if (_plugins.containsKey(plugin.pluginId)) {
      log.warning('Plugin ${plugin.pluginId} already registered, skipping.');
      return;
    }
    _plugins[plugin.pluginId] = plugin;
    plugin.onInit(_context);
    log.info('UCR Plugin registered: ${plugin.pluginId}');
  }

  /// 注销插件
  void unregisterPlugin(String pluginId) {
    final plugin = _plugins.remove(pluginId);
    plugin?.onDispose();
  }

  /// 分发事件到所有订阅的插件
  void dispatchEvent(UCREvent event) {
    for (final plugin in _plugins.values) {
      if (plugin.subscribedEvents.contains(event.type)) {
        try {
          plugin.onEvent(event);
        } catch (e, stack) {
          log.error('Plugin ${plugin.pluginId} event handler error', e, stack);
          // 单个插件异常不影响其他插件
        }
      }
    }
  }

  /// 获取所有插件的工具栏按钮
  List<Widget> buildToolbarButtons(BuildContext context) {
    return _plugins.values
        .map((p) => p.buildToolbarButton(context))
        .whereType<Widget>()
        .toList();
  }

  /// 获取所有插件的浮动层
  List<Widget> buildOverlays(BuildContext context) {
    return _plugins.values
        .map((p) => p.buildOverlay(context))
        .whereType<Widget>()
        .toList();
  }

  /// 序列化所有插件状态（用于会话快照）
  Map<String, dynamic> serializePluginStates() {
    return _plugins.map((id, plugin) => MapEntry(id, plugin.toJson()));
  }
```

## 7. 阅读进度管理

### 7.1 进度追踪策略

UCR 采用**块级粒度**的进度追踪，而非简单的页面百分比。这允许精确还原阅读位置并分析阅读行为。

```dart
/// 进度追踪器
class ProgressTracker {
  final String documentId;
  final String userId;
  final String deviceId;

  /// 已访问块集合
  final Set<String> _visitedBlocks = {};

  /// 阅读路径（块索引序列）
  final List<int> _readingPath = [];

  /// 当前位置
  int _currentIndex = 0;
  DateTime _sessionStart = DateTime.now();
  Timer? _heartbeatTimer;
  int _totalReadSeconds = 0;

  /// 块进入视口时调用
  void onBlockEntered(String blockId, int index) {
    _currentIndex = index;

    if (_visitedBlocks.add(blockId)) {
      // 首次到达此块
      _readingPath.add(index);
    }

    _heartbeatTimer?.cancel();
    _heartbeatTimer = Timer.periodic(
      const Duration(seconds: 15),
      (_) => _flushProgress(),
    );
  }

  /// 块离开视口时调用
  void onBlockLeft(String blockId, int index) {
    // 记录该块的停留时长
    final blockDuration = _getBlockDuration(blockId);
    _accumulateReadTime(blockDuration);
  }

  /// 阅读器暂停/进入后台时调用
  void onPause() {
    _heartbeatTimer?.cancel();
    _flushProgress();
  }

  /// 阅读器恢复时调用
  void onResume() {
    _sessionStart = DateTime.now();
    _heartbeatTimer = Timer.periodic(
      const Duration(seconds: 15),
      (_) => _flushProgress(),
    );
  }

  /// 刷新进度到本地缓存与服务端
  Future<void> _flushProgress() async {
    final progress = ReadingProgress(
      documentId: documentId,
      userId: userId,
      lastBlockIndex: _currentIndex,
      currentBlockId: _allBlocks[_currentIndex]?.blockId,
      percentage: _visitedBlocks.length / _totalBlocks,
      totalReadSeconds: _totalReadSeconds,
      sessionStart: _sessionStart,
      updatedAt: DateTime.now(),
      visitedBlockIds: Set.from(_visitedBlocks),
      readingPath: List.from(_readingPath),
      deviceId: deviceId,
    );

    // 1. 先写入本地（保证离线可用）
    await _localCache.saveProgress(progress);

    // 2. 异步同步到服务端
    if (_networkInfo.isConnected) {
      _apiClient.syncProgress(progress).catchError((e) {
        log.warning('Progress sync failed, will retry: $e');
      });
    }
  }
}
```

```dart
/// 断点续读恢复器
class ResumeManager {
  /// 获取用户在某文档的最后阅读位置
  Future<ReadingSessionSnapshot?> getLastSession(
    String userId,
    String documentId,
  ) async {
    // 1. 先查本地缓存
    final local = await _localCache.getLastSession(userId, documentId);
    if (local != null) {
      // 2. 尝试用服务端数据修正（可能有更新的进度）
      if (await _networkInfo.isConnected) {
        final remote = await _apiClient.getLastSession(userId, documentId);
        if (remote != null && remote.progress.updatedAt.isAfter(local.progress.updatedAt)) {
          return remote; // 服务端更新
        }
      }
      return local;
    }

    // 3. 本地没有，查服务端
    if (await _networkInfo.isConnected) {
      return _apiClient.getLastSession(userId, documentId);
    }

    return null;
  }

  /// 恢复阅读会话
  Future<void> restoreSession(
    ReaderController controller,
    ReadingSessionSnapshot snapshot,
  ) async {
    // 恢复显示设置
    controller.updateDisplaySettings(snapshot.displaySettings);

    // 恢复滚动位置
    controller.scrollToBlock(
      snapshot.progress.currentBlockId ??
          controller.blocks[snapshot.progress.lastBlockIndex].blockId,
      duration: Duration.zero,
    );

    // 恢复插件状态
    for (final entry in snapshot.pluginStates.entries) {
      controller.pluginManager.getPlugin(entry.key)?.fromJson(entry.value);
    }
  }
}
```

### 8.3 朗读模式

朗读模式将阅读器与 TTS 引擎结合，提供"听书"体验。

```dart
/// 朗读模式控制器
class ReadAloudController extends ChangeNotifier {
  final ReaderController _readerController;
  final TTSService _ttsService;

  bool _isReading = false;
  String? _currentReadingBlockId;
  ReadAloudSpeed _speed = ReadAloudSpeed.normal;

  /// 开始朗读（从当前可见块开始）
  Future<void> startReading() async {
    final currentBlock = _readerController.currentVisibleBlock;
    if (currentBlock == null) return;

    _isReading = true;
    await _readBlock(currentBlock);
    notifyListeners();
  }

  /// 朗读单个块
  Future<void> _readBlock(ContentBlock block) async {
    _currentReadingBlockId = block.blockId;

    // 提取块的可朗读文本
    final text = _extractReadableText(block);
    if (text.isEmpty) {
      // 无文本可读（如图片块），跳到下一块
      await _readNextBlock();
      return;
    }

    // 高亮当前朗读块
    _readerController.highlightBlock(block.blockId, HighlightStyle.reading);

    // 调用 TTS 服务
    await _ttsService.speak(
      text,
      speed: _speed.rate,
      onComplete: _readNextBlock,
      onError: (e) {
        log.error('TTS error for block ${block.blockId}', e);
        _readNextBlock();
      },
    );
  }

  /// 朗读下一块
  Future<void> _readNextBlock() async {
    final nextBlock = _readerController.nextBlock(_currentReadingBlockId);
    if (nextBlock == null) {
      _isReading = false;
      _currentReadingBlockId = null;
      notifyListeners();
      return;
    }

    // 自动滚动到下一块
    _readerController.scrollToBlock(
      nextBlock.blockId,
      duration: const Duration(milliseconds: 300),
    );

    // 等待滚动完成后开始朗读
    await Future.delayed(const Duration(milliseconds: 350));
    await _readBlock(nextBlock);
  }

  /// 提取块的可朗读文本
  String _extractReadableText(ContentBlock block) {
    switch (block.type) {
      case ContentBlockType.heading:
      case ContentBlockType.paragraph:
      case ContentBlockType.richText:
        return block.data['text'] as String? ?? '';

      case ContentBlockType.callout:
        final prefix = block.data['type'] == 'warning' ? '注意：'
            : block.data['type'] == 'tip' ? '提示：'
            : block.data['type'] == 'summary' ? '总结：'
            : '';
        return '$prefix${block.data['text'] ?? ''}';

      case ContentBlockType.quote:
        return block.data['text'] as String? ?? '';

      case ContentBlockType.formula:
        // 公式块朗读数学表达式
        return block.data['spokenText'] as String? ?? '公式';

      case ContentBlockType.image:
        return block.data['alt'] as String? ?? '图片';

      case ContentBlockType.table:
        // 表格转语音描述
        return _tableToSpeech(block.data);

      default:
        return '';
    }
  }

  /// 停止朗读
  Future<void> stopReading() async {
    _isReading = false;
    _currentReadingBlockId = null;
    await _ttsService.stop();

    // 移除朗读高亮
    _readerController.clearHighlight(HighlightStyle.reading);
    notifyListeners();
  }
}
```

```dart
/// 阅读器本地缓存数据访问层
class ReaderLocalCache {
  final Database _db;

  /// 保存阅读进度（本地优先写入）
  Future<void> saveProgress(ReadingProgress progress) async {
    await _db.into(_db.readingProgressTable).insertOnConflictUpdate(
      ReadingProgressTableCompanion(
        userId: Value(progress.userId),
        documentId: Value(progress.documentId),
        lastBlockIndex: Value(progress.lastBlockIndex),
        currentBlockId: Value(progress.currentBlockId),
        percentage: Value(progress.percentage),
        totalReadSeconds: Value(progress.totalReadSeconds),
        visitedBlockIds: Value(progress.visitedBlockIds.join(',')),
        readingPath: Value(jsonEncode(progress.readingPath)),
        deviceId: Value(progress.deviceId),
        updatedAt: Value(progress.updatedAt),
      ),
    );
  }

  /// 缓存文档内容（离线阅读）
  Future<void> cacheDocument(ReaderDocument document) async {
    await _db.into(_db.cachedDocumentTable).insertOnConflictUpdate(
      CachedDocumentTableCompanion(
        documentId: Value(document.documentId),
        title: Value(document.title),
        content: Value(jsonEncode(document.toJson())),
        version: Value(document.version),
        cachedAt: Value(DateTime.now()),
      ),
    );
  }

  /// 获取缓存的文档
  Future<ReaderDocument?> getCachedDocument(String documentId) async {
    final row = await (_db.select(_db.cachedDocumentTable)
          ..where((t) => t.documentId.equals(documentId)))
        .getSingleOrNull();

    if (row == null) return null;

    return ReaderDocument.fromJson(jsonDecode(row.content));
  }

  /// 离线进度同步队列
  Future<void> enqueueProgressSync(ReadingProgress progress) async {
    await _db.into(_db.progressSyncQueue).insert(
      ProgressSyncQueueCompanion(
        documentId: Value(progress.documentId),
        progress: Value(jsonEncode(progress.toJson())),
        createdAt: Value(DateTime.now()),
        retryCount: Value(0),
      ),
    );
  }

  /// 获取待同步的进度记录
  Future<List<ReadingProgress>> getPendingProgressSyncs({int limit = 50}) async {
    final rows = await (_db.select(_db.progressSyncQueue)
          ..orderBy([(t) => OrderingTerm.asc(t.createdAt)])
          ..limit(limit))
        .get();

    return rows.map((r) =>
      ReadingProgress.fromJson(jsonDecode(r.progress))
    ).toList();
  }
}
```

### 12.2 缓存淘汰策略

```dart
/// 阅读器缓存管理器
class ReaderCacheManager {
  static const int maxCachedDocuments = 20;
  static const Duration maxCacheAge = Duration(days: 7);

  /// 清理过期缓存
  Future<void> cleanupExpiredCache() async {
    // 1. 删除超过7天的缓存文档
    await _db.customStatement(
      'DELETE FROM cached_document_table WHERE cached_at < ?',
      [DateTime.now().subtract(maxCacheAge).millisecondsSinceEpoch],
    );

    // 2. 如果缓存数量超过上限，删除最旧的
    final count = await _db.cachedDocumentTable.count().getSingle();
    if (count > maxCachedDocuments) {
      final toDelete = count - maxCachedDocuments;
      await _db.customStatement(
        '''DELETE FROM cached_document_table
           WHERE document_id IN (
             SELECT document_id FROM cached_document_table
             ORDER BY cached_at ASC LIMIT ?
           )''',
        [toDelete],
      );
    }
  }

  /// 预缓存文档（智能预加载）
  Future<void> precacheDocuments(List<String> documentIds) async {
    for (final docId in documentIds) {
      // 检查是否已缓存且版本最新
      final cached = await _localCache.getCachedDocument(docId);
      final serverVersion = await _apiClient.getDocumentVersion(docId);

      if (cached == null || cached.version != serverVersion) {
        final document = await _apiClient.fetchDocument(docId);
        await _localCache.cacheDocument(document);
        // 同时预下载关联资源（图片等）
        await _precacheResources(document.resources ?? []);
      }
    }
  }
}
```

## 13. 错误处理

### 13.1 错误码定义

| 错误码 | 场景 | 处理策略 |
| --- | --- | --- |
| `READER_DOC_NOT_FOUND` | 文档不存在或已下线 | 展示"内容不可用"页面，提供返回入口 |
| `READER_DOC_PARSE_ERROR` | 文档 JSON 解析失败 | 展示"内容加载失败"，提供重试按钮 |
| `READER_BLOCK_RENDER_ERROR` | 单个块渲染异常 | 该块位置显示错误占位符，不影响其他块 |
| `READER_RESOURCE_LOAD_FAILED` | 图片/音频等资源加载失败 | 显示占位图 + 重试按钮 |
| `READER_PROGRESS_SYNC_FAILED` | 进度同步到服务端失败 | 静默失败，存入本地重试队列 |
| `READER_PLUGIN_INIT_FAILED` | 插件初始化失败 | 禁用该插件，阅读器核心功能不受影响 |
| `READER_OFFLINE_NO_CACHE` | 离线且无本地缓存 | 展示"需要网络连接"提示页 |
| `READER_VERSION_MISMATCH` | 文档版本与服务端不一致 | 提示内容已更新，提供重新加载 |

### 13.2 块级错误隔离

```dart
/// 安全块渲染包装器
class SafeBlockRenderer extends StatefulWidget {
  final ContentBlock block;
  final BlockAdapter adapter;
  final BlockAdapterContext context;

  @override
  State<SafeBlockRenderer> createState() => _SafeBlockRendererState();
}

class _SafeBlockRendererState extends State<SafeBlockRenderer> {
  Object? _error;
  StackTrace? _stackTrace;

  @override
  void initState() {
    super.initState();
    // 捕获同步渲染错误
    FlutterError.onError = (details) {
      setState(() {
        _error = details.exception;
        _stackTrace = details.stack;
      });
      _reportBlockError(details);
    };
  }

  @override
  Widget build(BuildContext context) {
    if (_error != null) {
      // 错误降级：显示错误占位符，不影响后续块渲染
      return _buildErrorPlaceholder();
    }

    try {
      return widget.adapter.buildWidget(
        context,
        widget.block,
        widget.context,
      );
    } catch (e, stack) {
      _reportBlockError(FlutterErrorDetails(
        exception: e,
        stack: stack,
        context: ErrorDescription('Rendering block ${widget.block.blockId}'),
      ));
      return _buildErrorPlaceholder();
    }
  }

  Widget _buildErrorPlaceholder() {
    return Container(
      padding: const EdgeInsets.all(16),
      decoration: BoxDecoration(
        color: Colors.orange.shade50,
        borderRadius: BorderRadius.circular(8),
        border: Border.all(color: Colors.orange.shade200),
      ),
      child: Row(
        children: [
          Icon(Icons.warning_amber, color: Colors.orange.shade700, size: 20),
          const SizedBox(width: 8),
          Expanded(
            child: Text(
              '此部分内容显示异常，可尝试重新加载',
              style: TextStyle(color: Colors.orange.shade900, fontSize: 13),
            ),
          ),
          TextButton(
            onPressed: () => setState(() => _error = null),
            child: const Text('重试'),
          ),
        ],
      ),
    );
  }

  void _reportBlockError(FlutterErrorDetails details) {
    CrashReporter.report(
      'reader_block_render_error',
      blockId: widget.block.blockId,
      blockType: widget.block.type.name,
      error: details.exception.toString(),
      stackTrace: details.stack.toString(),
    );
  }
}
```

## 14. 性能优化

### 14.1 性能目标

| 指标 | 目标值 | 说明 |
| --- | --- | --- |
| 首屏渲染时间 | < 500ms | 从拿到文档 JSON 到首屏渲染完成 |
| 滚动帧率 | ≥ 55fps | 标准设备上持续滚动不丢帧 |
| 内存占用 | < 150MB | 500 块文档的总内存占用 |
| 块切换延迟 | < 16ms | 单个块从进入缓冲区到渲染完成 |
| 文档解析耗时 | < 100ms | 200 块文档的 JSON 解析 + 验证 |
| 冷启动进度恢复 | < 300ms | 从本地缓存恢复到上次阅读位置 |

### 14.2 优化策略清单

| 策略 | 说明 |
| --- | --- |
| **虚拟滚动** | 仅渲染可视区域 ±5 块缓冲区，回收离屏块 |
| **异步解析** | 文档解析在 Isolate 中执行，不阻塞主线程 |
| **图片懒加载** | 图片块使用 `cached_network_image`，先占位后加载 |
| **高度缓存** | 块实际渲染高度缓存，避免重复计算 |
| **Widget 复用** | 同类型块的 Widget 使用 `key` 复用，减少重建 |
| **资源预下载** | 阅读当前块时预下载后 5 块的图片资源 |
| **公式预编译** | LaTeX 公式在解析阶段预编译为渲染树 |
| **分帧渲染** | 初始渲染分帧执行，避免首帧卡顿 |
| **内存预警** | 监听系统内存预警，主动清理缓冲区外资源 |

### 14.3 首屏分帧渲染

```dart
/// 分帧渲染调度器
class StagedRenderer {
  static const int _initialBatchSize = 8;  // 首屏渲染块数量
  static const Duration _frameInterval = Duration(milliseconds: 16);

  /// 分批渲染块列表
  static Future<void> renderInBatches(
    List<ContentBlock> blocks,
    void Function(int startIndex, int endIndex) onBatchReady,
  ) async {
    // 第一帧：渲染首屏可见块（约8个）
    onBatchReady(0, min(_initialBatchSize, blocks.length));

    // 后续帧：每帧追加 4 个块到缓冲区
    for (int i = _initialBatchSize; i < blocks.length; i += 4) {
      await Future.delayed(_frameInterval);
      onBatchReady(i, min(i + 4, blocks.length));
    }
  }
}
```

## 17. 安全与权限

### 17.1 内容访问控制

```dart
/// 阅读器内容访问鉴权拦截器
class ReaderAuthInterceptor {
  /// 加载文档前校验用户是否有权限访问
  Future<AccessResult> checkAccess(
    String userId,
    String documentId,
    ReaderSource source,
  ) async {
    // 1. 免费内容直接放行
    final meta = await _contentMetaCache.get(documentId);
    if (meta?.accessLevel == AccessLevel.free) {
      return AccessResult.allowed();
    }

    // 2. 会员内容校验
    if (meta?.accessLevel == AccessLevel.premium) {
      final membership = await _membershipService.check(userId);
      if (!membership.isActive) {
        return AccessResult.denied(
          reason: '需要开通会员才能查看完整内容',
          action: AccessAction.upgradeToMember,
        );
      }
    }

    // 3. 年级限制（低年级学生不应看到高年级内容）
    final userGrade = await _userService.getGradeLevel(userId);
    if (meta != null && !_isGradeAppropriate(userGrade, meta.gradeLevel)) {
      return AccessResult.denied(
        reason: '此内容不适合当前年级',
        action: AccessAction.contactParent,
      );
    }

    return AccessResult.allowed();
  }
}
```

### 17.2 敏感数据保护

- 阅读进度和行为数据中的 `userId` 在传输时使用临时令牌替代
- 本地 SQLite 中的用户数据使用 SQLCipher 加密
- 阅读行为上报数据不包含文档实际内容（仅块 ID 和行为类型）

```dart
// 示例：注册一个"实验步骤"自定义块类型

class ExperimentStepAdapter implements BlockAdapter {
  @override
  ContentBlockType get supportedType => ContentBlockType.interactive;

  @override
  Widget buildWidget(
    BuildContext context,
    ContentBlock block,
    BlockAdapterContext adapterContext,
  ) {
    final stepData = ExperimentStepData.fromJson(block.data);

    return ExperimentStepWidget(
      stepNumber: stepData.stepNumber,
      title: stepData.title,
      description: stepData.description,
      imageUrl: stepData.imageUrl,
      safetyNote: stepData.safetyNote,
      onTap: () => adapterContext.controller.scrollToBlock(stepData.nextBlockId),
    );
  }

  @override
  double estimateHeight(ContentBlock block, DisplaySettings settings, double viewportWidth) {
    final data = ExperimentStepData.fromJson(block.data);
    final descLines = (data.description.length / 25).ceil();
    return 120 + descLines * 24 * settings.fontScale;
  }
}

void initReaderAdapters() {
  UCRRegistry.registerCustomAdapter('experiment_step', ExperimentStepAdapter());
```
