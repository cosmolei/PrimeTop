# 客户端 - 意见反馈与帮助中心页面架构与交互设计

## 1. 模块概述

### 1.1 定位

意见反馈与帮助中心是 PrimeTop 客户端的用户服务入口，为学生、家长提供从自助解决问题到人工客服支持的完整服务链路。涵盖 AI 回答即时反馈、应用内意见反馈提交、帮助中心/FAQ 浏览与搜索、客服在线咨询、工单进度查看五大能力。

### 1.2 与现有系统的关系

| 关联系统 | 交互方式 | 说明 |
|----------|----------|------|
| 用户反馈与AI质量评估 | API 调用 | 点赞/点踩、纠错标注提交至反馈系统 |
| 客服与工单系统 | API 调用 | 工单创建、进度查询、FAQ 数据源 |
| 消息与推送服务 | 推送接收 | 工单状态变更通知 |
| 用户账号体系 | 身份信息 | 自动携带用户 ID、角色、年级等上下文 |
| 客户端全局搜索与智能发现引擎 | 搜索组件复用 | FAQ 搜索复用搜索组件 |

### 1.3 设计目标

1. **零门槛反馈**：AI 回答反馈一步触达，不超过 2 次操作
2. **自助优先**：FAQ + 智能推荐覆盖 70%+ 常见问题，减少人工工单量
3. **全角色适配**：学生端简洁友好，家长端信息完整，教师端专业高效
4. **闭环透明**：反馈和工单状态全程可查

## 3. AI 回答即时反馈组件

### 3.1 组件概述

每条 AI 回答消息底部附带的轻量反馈条，允许用户快速评价 AI 回答质量，或在发现错误时提交纠错标注。

### 3.2 状态流转

```
[初始态] ──👍──→ [已点赞] ──点击取消──→ [初始态]
   │                                   ↑
   ├──👎──→ [已点踩] ──点击取消──→ [初始态]
   │            │
   │            └──点击再次👎──→ [纠错标注弹窗]
   │
   └──长按/更多──→ [操作菜单]
                    ├── 纠错标注
                    ├── 重新生成
                    ├── 复制回答
                    └── 分享回答
```

```dart
class AIAnswerFeedbackBar extends ConsumerStatefulWidget {
  final String answerId;
  final String conversationId;
  final String scene;          // tutor | photo_question | essay | ...
  final String? subject;
  final int? gradeId;

  const AIAnswerFeedbackBar({
    super.key,
    required this.answerId,
    required this.conversationId,
    required this.scene,
    this.subject,
    this.gradeId,
  });

  @override
  ConsumerState<AIAnswerFeedbackBar> createState() =>
      _AIAnswerFeedbackBarState();
}

class _AIAnswerFeedbackBarState extends ConsumerState<AIAnswerFeedbackBar> {
  FeedbackType? _currentFeedback;    // like | dislike | null
  bool _isSubmitting = false;

  // 反馈提交
  Future<void> _submitFeedback(FeedbackType type, {String? reason}) async {
    if (_isSubmitting) return;
    setState(() => _isSubmitting = true);

    try {
      await ref.read(feedbackRepositoryProvider).submitQuickFeedback(
        answerId: widget.answerId,
        feedbackType: type,
        reason: reason,
        scene: widget.scene,
        subject: widget.subject,
      );

      setState(() => _currentFeedback = type);

      // 点踩后延迟弹出纠错引导
      if (type == FeedbackType.dislike) {
        Future.delayed(const Duration(milliseconds: 500), () {
          if (mounted) _showDislikeFollowUp();
        });
      }
    } catch (e) {
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(content: Text('反馈提交失败，请稍后重试')),
        );
      }
    } finally {
      if (mounted) setState(() => _isSubmitting = false);
    }
  }

  // 点踩后续引导
  void _showDislikeFollowUp() {
    showModalBottomSheet(
      context: context,
      builder: (_) => _DislikeFollowUpSheet(
        onReportError: () {
          Navigator.pop(context);
          _showErrorReportSheet();
        },
        onRegenerate: () {
          Navigator.pop(context);
          // 触发重新生成
          ref.read(aiConversationProvider(widget.conversationId).notifier)
              .regenerateAnswer(widget.answerId);
        },
        onDismiss: () => Navigator.pop(context),
      ),
    );
  }

  void _showErrorReportSheet() {
    showModalBottomSheet(
      context: context,
      isScrollControlled: true,
      builder: (_) => ErrorReportSheet(
        answerId: widget.answerId,
        scene: widget.scene,
        subject: widget.subject,
        gradeId: widget.gradeId,
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);

    return Padding(
      padding: const EdgeInsets.only(top: 4),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          // 点赞按钮
          _FeedbackButton(
            icon: Icons.thumb_up_outlined,
            activeIcon: Icons.thumb_up,
            isActive: _currentFeedback == FeedbackType.like,
            onTap: () => _submitFeedback(FeedbackType.like),
          ),
          const SizedBox(width: 4),
          // 点踩按钮
          _FeedbackButton(
            icon: Icons.thumb_down_outlined,
            activeIcon: Icons.thumb_down,
            isActive: _currentFeedback == FeedbackType.dislike,
            onTap: () => _submitFeedback(FeedbackType.dislike),
          ),
          const SizedBox(width: 4),
          // 更多操作
          PopupMenuButton<String>(
            icon: Icon(Icons.more_horiz, size: 18, color: theme.hintColor),
            itemBuilder: (_) => [
              const PopupMenuItem(value: 'report', child: Text('纠错标注')),
              const PopupMenuItem(value: 'regenerate', child: Text('重新生成')),
              const PopupMenuItem(value: 'copy', child: Text('复制回答')),
            ],
            onSelected: (value) {
              switch (value) {
                case 'report':
                  _showErrorReportSheet();
                  break;
                case 'regenerate':
                  ref.read(aiConversationProvider(widget.conversationId).notifier)
                      .regenerateAnswer(widget.answerId);
                  break;
                case 'copy':
                  _copyAnswer();
                  break;
              }
            },
          ),
        ],
      ),
    );
  }
}
```

```dart
class _ErrorReportSheetState extends ConsumerState<ErrorReportSheet> {
  final _descriptionController = TextEditingController();
  ErrorCategory? _selectedCategory;
  bool _isSubmitting = false;

  /// 纠错类型选项
  static const _errorCategories = [
    ErrorCategory(
      id: 'calculation',
      label: '计算错误',
      icon: Icons.calculate,
      description: '公式或数值计算有误',
    ),
    ErrorCategory(
      id: 'concept',
      label: '概念错误',
      icon: Icons.menu_book,
      description: '知识点或概念讲解有误',
    ),
    ErrorCategory(
      id: 'logic',
      label: '推理错误',
      icon: Icons.psychology,
      description: '解题步骤或逻辑有误',
    ),
    ErrorCategory(
      id: 'irrelevant',
      label: '答非所问',
      icon: Icons.help_outline,
      description: '回答没有针对我的问题',
    ),
    ErrorCategory(
      id: 'inappropriate',
      label: '内容不当',
      icon: Icons.warning_amber,
      description: '包含不适宜的内容',
    ),
    ErrorCategory(
      id: 'other',
      label: '其他问题',
      icon: Icons.more_horiz,
      description: '以上都不是',
    ),
  ];

  Future<void> _submit() async {
    if (_selectedCategory == null || _isSubmitting) return;

    setState(() => _isSubmitting = true);
    try {
      await ref.read(feedbackRepositoryProvider).submitErrorReport(
        answerId: widget.answerId,
        errorCategory: _selectedCategory!.id,
        description: _descriptionController.text.trim(),
        scene: widget.scene,
        subject: widget.subject,
      );

      if (mounted) {
        Navigator.pop(context);
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('感谢反馈，我们会尽快核实'),
            duration: Duration(seconds: 2),
          ),
        );
      }
    } catch (e) {
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(content: Text('提交失败，请稍后重试')),
        );
      }
    } finally {
      if (mounted) setState(() => _isSubmitting = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return SafeArea(
      child: Padding(
        padding: EdgeInsets.fromLTRB(
          16, 16, 16,
          MediaQuery.of(context).viewInsets.bottom + 16,
        ),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            // 标题
            Text('纠错标注', style: Theme.of(context).textTheme.titleMedium),
            const SizedBox(height: 16),
            // 错误类型选择
            Wrap(
              spacing: 8,
              runSpacing: 8,
              children: _errorCategories.map((cat) {
                final selected = _selectedCategory == cat;
                return ChoiceChip(
                  avatar: Icon(cat.icon, size: 16),
                  label: Text(cat.label),
                  selected: selected,
                  onSelected: (_) {
                    setState(() => _selectedCategory = cat);
                  },
                );
              }).toList(),
            ),
            // 选中类型的说明文字
            if (_selectedCategory != null) ...[
              const SizedBox(height: 8),
              Text(
                _selectedCategory!.description,
                style: Theme.of(context).textTheme.bodySmall?.copyWith(
                  color: Theme.of(context).hintColor,
                ),
              ),
            ],
            const SizedBox(height: 16),
            // 补充描述
            TextField(
              controller: _descriptionController,
              maxLines: 3,
              maxLength: 500,
              decoration: const InputDecoration(
                hintText: '请描述具体错误（选填）',
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 12),
            // 提交按钮
            SizedBox(
              width: double.infinity,
              child: FilledButton(
                onPressed: _selectedCategory != null ? _submit : null,
                child: _isSubmitting
                    ? const SizedBox(
                        width: 20, height: 20,
                        child: CircularProgressIndicator(strokeWidth: 2),
                      )
                    : const Text('提交纠错'),
              ),
            ),
          ],
        ),
      ),
    );
  }
}
```

```dart
class FAQSearchPage extends ConsumerStatefulWidget {
  const FAQSearchPage({super.key});

  @override
  ConsumerState<FAQSearchPage> createState() => _FAQSearchPageState();
}

class _FAQSearchPageState extends ConsumerState<FAQSearchPage> {
  final _searchController = TextEditingController();
  final _debouncer = Debouncer(milliseconds: 300);

  @override
  void dispose() {
    _searchController.dispose();
    _debouncer.dispose();
    super.dispose();
  }

  void _onSearchChanged(String query) {
    _debouncer.run(() {
      if (query.trim().isNotEmpty) {
        ref.read(faqSearchQueryProvider.notifier).state = query.trim();
      }
    });
  }

  @override
  Widget build(BuildContext context) {
    final resultsAsync = ref.watch(faqSearchResultsProvider);

    return Scaffold(
      appBar: AppBar(
        title: TextField(
          controller: _searchController,
          autofocus: true,
          decoration: const InputDecoration(
            hintText: '搜索常见问题...',
            border: InputBorder.none,
          ),
          onChanged: _onSearchChanged,
        ),
      ),
      body: resultsAsync.when(
        loading: () => const Center(child: CircularProgressIndicator()),
        error: (e, _) => _ErrorStateWidget(
          message: '搜索失败',
          onRetry: () => ref.invalidate(faqSearchResultsProvider),
        ),
        data: (results) {
          if (results.isEmpty) {
            return _EmptySearchResult(
              query: _searchController.text,
              onFeedback: () => context.push('/help/feedback'),
            );
          }
          return ListView.builder(
            itemCount: results.length,
            itemBuilder: (_, index) {
              final article = results[index];
              return ListTile(
                title: _highlightMatch(article.title, _searchController.text),
                subtitle: Text(
                  article.content.replaceAll(RegExp(r'[#*\[\]]'), ''),
                  maxLines: 2,
                  overflow: TextOverflow.ellipsis,
                ),
                onTap: () => context.push('/help/faq/${article.id}'),
              );
            },
          );
        },
      ),
    );
  }

  /// 高亮匹配文字
  Widget _highlightMatch(String text, String query) {
    if (query.isEmpty) return Text(text);
    final spans = <TextSpan>[];
    int start = 0;
    final lowerText = text.toLowerCase();
    final lowerQuery = query.toLowerCase();
    while (true) {
      final index = lowerText.indexOf(lowerQuery, start);
      if (index == -1) {
        spans.add(TextSpan(text: text.substring(start)));
        break;
      }
      if (index > start) {
        spans.add(TextSpan(text: text.substring(start, index)));
      }
      spans.add(TextSpan(
        text: text.substring(index, index + query.length),
        style: const TextStyle(
          fontWeight: FontWeight.bold,
          color: Colors.blue,
        ),
      ));
      start = index + query.length;
    }
    return RichText(text: TextSpan(children: spans));
  }
}
```

```dart
class FeedbackPage extends ConsumerStatefulWidget {
  const FeedbackPage({super.key});

  @override
  ConsumerState<FeedbackPage> createState() => _FeedbackPageState();
}

class _FeedbackPageState extends ConsumerState<FeedbackPage> {
  final _descriptionController = TextEditingController();
  final _contactController = TextEditingController();
  FeedbackCategory? _selectedCategory;
  final List<XFile> _selectedImages = [];
  bool _includeLogs = true;
  bool _isSubmitting = false;

  static const int _maxImages = 5;
  static const int _minDescLength = 10;
  static const int _maxDescLength = 1000;

  bool get _canSubmit =>
      _selectedCategory != null &&
      _descriptionController.text.trim().length >= _minDescLength &&
      !_isSubmitting;

  Future<void> _submit() async {
    if (!_canSubmit) return;
    setState(() => _isSubmitting = true);

    try {
      // 1. 上传图片 (如有)
      final imageUrls = <String>[];
      if (_selectedImages.isNotEmpty) {
        final uploadResults = await ref.read(uploadServiceProvider).batchUpload(
          files: _selectedImages,
          bucket: 'feedback',
        );
        imageUrls.addAll(uploadResults.map((r) => r.url));
      }

      // 2. 采集应用上下文
      final appCtx = await _collectAppContext();

      // 3. 提交反馈
      await ref.read(feedbackRepositoryProvider).submitFeedback(
        FeedbackSubmission(
          category: _selectedCategory!.id,
          description: _descriptionController.text.trim(),
          imageUrls: imageUrls,
          contactInfo: _contactController.text.trim().isEmpty
              ? null
              : _contactController.text.trim(),
          includeLogs: _includeLogs,
          appContext: appCtx.toJson(),
        ),
      );

      if (mounted) {
        // 成功提示
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('感谢您的反馈，我们会认真处理'),
            duration: Duration(seconds: 3),
          ),
        );
        // 重置表单
        _descriptionController.clear();
        _contactController.clear();
        setState(() {
          _selectedCategory = null;
          _selectedImages.clear();
          _includeLogs = true;
        });
      }
    } catch (e) {
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(
            content: Text('提交失败: ${e.toString()}'),
            action: SnackBarAction(label: '重试', onPressed: _submit),
          ),
        );
      }
    } finally {
      if (mounted) setState(() => _isSubmitting = false);
    }
  }

  Future<FeedbackAppContext> _collectAppContext() async {
    final packageInfo = await PackageInfo.fromPlatform();
    final deviceInfo = ref.read(deviceInfoProvider);
    final connectivity = ref.read(connectivityProvider);

    return FeedbackAppContext(
      appVersion: packageInfo.version,
      platform: defaultTargetPlatform.name,
      osVersion: deviceInfo.osVersion,
      deviceModel: deviceInfo.model,
      networkType: connectivity.type.name,
      userId: ref.read(currentUserIdProvider),
      userRole: ref.read(currentUserRoleProvider),
      gradeId: ref.read(currentGradeIdProvider),
      currentRoute: GoRouter.of(context).routerDelegate.currentConfiguration.uri.path,
    );
  }

  Future<void> _pickImages() async {
    final remaining = _maxImages - _selectedImages.length;
    if (remaining <= 0) return;

    final images = await ref.read(imagePickerProvider).pickMultiImage(
      imageQuality: 80,
      maxWidth: 1920,
    );
    if (images != null && images.isNotEmpty) {
      setState(() {
        _selectedImages.addAll(images.take(remaining));
      });
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('意见反馈')),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            // 反馈类型
            _CategorySelector(
              selected: _selectedCategory,
              onChanged: (cat) => setState(() => _selectedCategory = cat),
            ),
            const SizedBox(height: 20),
            // 问题描述
            TextField(
              controller: _descriptionController,
              maxLines: 6,
              maxLength: _maxDescLength,
              decoration: InputDecoration(
                labelText: '问题描述',
                hintText: '请详细描述您遇到的问题或建议（至少$_minDescLength个字）',
                border: const OutlineInputBorder(),
                counterText: '${_descriptionController.text.length}/$_maxDescLength',
              ),
              onChanged: (_) => setState(() {}),
            ),
            const SizedBox(height: 16),
            // 上传截图
            _ImagePickerSection(
              images: _selectedImages,
              maxImages: _maxImages,
              onAdd: _pickImages,
              onRemove: (index) => setState(() => _selectedImages.removeAt(index)),
            ),
            const SizedBox(height: 16),
            // 联系方式
            TextField(
              controller: _contactController,
              decoration: const InputDecoration(
                labelText: '联系方式 (选填)',
                hintText: '手机号或邮箱',
                border: OutlineInputBorder(),
              ),
              keyboardType: TextInputType.emailAddress,
            ),
            const SizedBox(height: 12),
            // 日志授权
            SwitchListTile(
              title: const Text('允许收集应用日志'),
              subtitle: const Text('帮助诊断问题，不包含个人信息'),
              value: _includeLogs,
              onChanged: (v) => setState(() => _includeLogs = v),
              contentPadding: EdgeInsets.zero,
            ),
            const SizedBox(height: 20),
            // 提交按钮
            SizedBox(
              width: double.infinity,
              height: 48,
              child: FilledButton(
                onPressed: _canSubmit ? _submit : null,
                child: _isSubmitting
                    ? const SizedBox(
                        width: 24, height: 24,
                        child: CircularProgressIndicator(
```

```dart
/// 离线反馈队列
class OfflineFeedbackQueue {
  final Box<Map> _box;

  OfflineFeedbackQueue(this._box);

  /// 入队
  Future<void> enqueue(FeedbackAction action) async {
    await _box.add({
      'type': action.type,        // quick_feedback | error_report | general_feedback
      'payload': action.toJson(),
      'created_at': DateTime.now().toIso8601String(),
      'retry_count': 0,
    });
  }

  /// 获取待发送队列
  List<StoredFeedbackAction> getPending() {
    return _box.values.map((e) => StoredFeedbackAction.fromJson(Map<String, dynamic>.from(e))).toList();
  }

  /// 移除已发送项
  Future<void> remove(int key) async {
    await _box.delete(key);
  }

  /// 更新重试计数
  Future<void> incrementRetry(int key) async {
    final item = _box.get(key);
    if (item != null) {
      item['retry_count'] = (item['retry_count'] as int) + 1;
      await _box.put(key, item);
    }
  }
}

/// 网络恢复后的自动上报
class FeedbackSyncWorker {
  final OfflineFeedbackQueue _queue;
  final FeedbackRepository _repository;
  final ConnectivityService _connectivity;

  static const _maxRetry = 3;

  FeedbackSyncWorker(this._queue, this._repository, this._connectivity);

  void start() {
    _connectivity.onOnline.listen((_) => _flush());
  }

  Future<void> _flush() async {
    final pending = _queue.getPending();
    for (final action in pending) {
      if (action.retryCount >= _maxRetry) {
        _queue.remove(action.boxKey);
        continue;
      }
      try {
        await _send(action);
        _queue.remove(action.boxKey);
      } catch (_) {
        _queue.incrementRetry(action.boxKey);
      }
    }
  }

  Future<void> _send(StoredFeedbackAction action) async {
    switch (action.type) {
      case 'quick_feedback':
        await _repository.submitQuickFeedback(/* ... */);
        break;
      case 'error_report':
        await _repository.submitErrorReport(/* ... */);
        break;
    }
  }
}
```

```dart
      'TICKET_004' => '附件大小不能超过10MB',
```

## 16. 安全与合规

### 16.1 注意事项

| 风险点 | 处理策略 |
|--------|----------|
| 反馈内容包含敏感信息 | 提交前进行内容安全检查，拦截违规内容 |
| 图片附件含隐私信息 | 提示用户避免上传含身份证、银行卡等信息的图片 |
| 工单系统被恶意利用 | 限制每用户每日工单创建数(≤5)，频率限制 |
| 反馈数据泄露 | 反馈数据仅用户本人和客服可见，API 层面鉴权 |
| 未成年人直接投诉 | 低龄用户反馈自动通知绑定家长 |
| 联系方式收集合规 | 联系方式为选填项，明确告知用途 |

### 16.2 内容安全检查

```dart
/// 反馈内容安全预检
class FeedbackContentChecker {
  final ContentModerationService _moderation;

  FeedbackContentChecker(this._moderation);

  /// 检查反馈文本内容安全性
  Future<ContentCheckResult> checkText(String text) async {
    return _moderation.checkText(
      text,
      scenes: ['feedback'],
      checkTypes: ['porn', 'politics', 'abuse', 'privacy'],
    );
  }

  /// 检查图片内容安全性
  Future<ContentCheckResult> checkImage(XFile image) async {
    return _moderation.checkImage(
      image,
      scenes: ['feedback'],
      checkTypes: ['porn', 'violence', 'qr_code'],
    );
  }
}
```
