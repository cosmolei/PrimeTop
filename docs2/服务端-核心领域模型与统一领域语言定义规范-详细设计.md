# 服务端-核心领域模型与统一领域语言定义规范-详细设计

## 1. 概述

### 1.1 文档目的

本文档定义 PrimeTop 教育平台的核心业务领域模型、限界上下文（Bounded Context）边界、统一领域语言（Ubiquitous Language）词汇表、聚合根（Aggregate Root）设计及跨上下文交互契约。

**为什么需要这份文档？**

当前平台已有数百个服务端引擎和功能模块的详细设计文档，但缺少一份统一的全局领域模型定义。这导致：

- 不同文档中同一概念使用不同术语（如"学生"在用户服务中叫 `User`，在学习服务中叫 `Student`，在内容服务中叫 `Learner`）。
- 各服务之间的实体边界不清晰，容易产生贫血模型或事务边界混乱。
- 新成员加入团队时，缺少全局视角的领域地图。
- 微服务拆分缺少明确的限界上下文依据，容易产生分布式大泥球。

本文档作为**平台级领域建模权威参考**，所有功能模块的详细设计文档应与本文档保持术语和模型的一致性。

### 1.2 适用范围

- 服务端架构设计与微服务拆分
- 各业务模块的详细设计与编码实现
- 数据库 Schema 设计与数据模型映射
- API 接口设计中的领域概念一致性
- 前后端协作中的统一业务术语

### 1.3 设计原则

| 原则 | 说明 |
| --- | --- |
| 统一语言 | 领域专家与开发团队使用同一套术语，代码中的类名、方法名、字段名与领域语言一一对应 |
| 限界上下文 | 每个业务领域有明确的边界，上下文内部模型自治，跨上下文通过契约交互 |
| 聚合一致性 | 聚合内保证强一致性，聚合间保证最终一致性 |
| 防腐层隔离 | 外部系统对接通过防腐层（ACL）隔离，不污染核心领域模型 |
| 演进式设计 | 领域模型随业务认知深化而演进，通过版本化和变更管理保持可控 |

## 3. 上下文映射（Context Map）

### 3.1 上下文关系矩阵

以下矩阵描述各限界上下文之间的协作关系。

**关系类型说明：**

| 符号 | 类型 | 含义 |
| --- | --- | --- |
| ↘ | 上游 → 下游（U→D） | 上游上下文被下游依赖，下游遵循上游模型 |
| ACL | 防腐层（Anti-Corruption Layer） | 下游通过翻译层隔离上游模型，防止概念污染 |
| OHS | 开放主机服务（Open Host Service） | 上游提供标准化的开放 API 供所有下游使用 |
| PL | 共享内核（Shared Kernel） | 两个上下文共享部分模型，需协调变更 |
| CF | 客户/供应商（Customer-Supplier） | 上游服务于下游需求，双方协商接口 |
| CL | 遵奉者（Conformist） | 下游无条件遵从上游模型 |

#### 3.3.2 Practice → Mistake（客户/供应商）

```java
// Practice 上下文发布答题结果事件
// Mistake 上下文订阅并决定是否收录错题
public class AnswerGradedEvent {
    private final String userId;
    private final String questionId;
    private final String exerciseSessionId;
    private final boolean correct;
    private final String studentAnswer;
    private final String correctAnswer;
    private final List<String> relatedKnowledgePoints;
    private final Instant gradedAt;
}

// Mistake 上下文的防腐层：将答题事件翻译为错题收录决策
@EventHandler
public class MistakeCollectionHandler {
    
    public void onAnswerGraded(AnswerGradedEvent event) {
        if (event.isCorrect()) {
            return; // 答对不收录
        }
        
        // 检查是否已存在相同错题
        if (mistakeRepository.exists(event.getUserId(), event.getQuestionId())) {
            mistakeRepository.updateLastAttempt(event.getUserId(), event.getQuestionId());
            return;
        }
        
        // 创建新的错题条目
        MistakeEntry entry = MistakeEntry.builder()
            .userId(event.getUserId())
            .questionId(event.getQuestionId())
            .studentAnswer(event.getStudentAnswer())
            .correctAnswer(event.getCorrectAnswer())
            .knowledgePoints(event.getRelatedKnowledgePoints())
            .source(OutcomeSource.PRACTICE)
            .status(MistakeStatus.PENDING_REVIEW)
            .addedAt(Instant.now())
            .build();
            
        mistakeRepository.save(entry);
        
        // 发布错题收录事件
        domainEventPublisher.publish(new MistakeAddedEvent(entry));
    }
}
```

## 5. 核心聚合根详细设计

### 5.1 Account（账号）

```java
/**
 * 账号聚合根
 * 
 * 不变式（Invariants）：
 * 1. 手机号全局唯一
 * 2. 账号状态为 FROZEN 或 DEACTIVATED 时不允许任何业务操作
 * 3. 密码修改后所有已签发的 Token 立即失效
 * 4. 第三方绑定不可重复（同一平台同一 OpenID 只能绑定一个账号）
 */
@Entity
@Table(name = "accounts")
public class Account {
    
    @Id
    private AccountId id;
    
    /** 手机号（加密存储） */
    @Column(name = "phone_number_encrypted")
    private String encryptedPhoneNumber;
    
    /** 手机号哈希（用于唯一性校验和查询） */
    @Column(name = "phone_number_hash", unique = true)
    private String phoneNumberHash;
    
    /** 密码哈希 */
    private String passwordHash;
    
    /** 账号状态 */
    @Enumerated(EnumType.STRING)
    private AccountStatus status;
    
    /** 实名认证信息 */
    @Embedded
    private RealNameVerification verification;
    
    /** 第三方绑定列表 */
    @ElementCollection
    private List<ThirdPartyBinding> thirdPartyBindings;
    
    /** 最后登录时间 */
    private Instant lastLoginAt;
    
    /** 创建时间 */
    private Instant createdAt;
    
    // ===== 领域方法 =====
    
    /**
     * 注册新账号
     */
    public static Account register(String phoneNumber, String password, 
                                    VerificationCode code) {
        // 前置条件校验
        Preconditions.checkArgument(code.isValid(), "验证码无效或已过期");
        
        Account account = new Account();
        account.id = AccountId.next();
        account.encryptedPhoneNumber = CryptoUtil.encrypt(phoneNumber);
        account.phoneNumberHash = HashUtil.sha256(phoneNumber);
        account.passwordHash = PasswordUtil.hash(password);
        account.status = AccountStatus.ACTIVE;
        account.thirdPartyBindings = new ArrayList<>();
        account.createdAt = Instant.now();
        
        // 发布领域事件
        DomainEvents.publish(new UserRegisteredEvent(account.id, phoneNumber));
        
        return account;
    }
    
    /**
     * 通过第三方登录注册
     */
    public static Account registerByThirdParty(ThirdPartyUserInfo userInfo) {
        Account account = new Account();
        account.id = AccountId.next();
        account.encryptedPhoneNumber = null; // 第三方注册可能无手机号
        account.passwordHash = null;
        account.status = AccountStatus.ACTIVE;
        account.thirdPartyBindings = new ArrayList<>();
        account.thirdPartyBindings.add(
            ThirdPartyBinding.of(userInfo.getPlatform(), userInfo.getOpenId())
        );
        account.createdAt = Instant.now();
        
        DomainEvents.publish(new UserRegisteredEvent(account.id, null));
        
        return account;
    }
    
    /**
     * 绑定第三方账号
     */
    public void bindThirdParty(ThirdPartyPlatform platform, String openId) {
        // 不变式校验：不可重复绑定
        boolean exists = thirdPartyBindings.stream()
            .anyMatch(b -> b.getPlatform() == platform && b.getOpenId().equals(openId));
        if (exists) {
            throw new DomainException("THIRD_PARTY_ALREADY_BOUND", "该第三方账号已绑定");
        }
        
        thirdPartyBindings.add(ThirdPartyBinding.of(platform, openId));
        
        DomainEvents.publish(new ThirdPartyBoundEvent(this.id, platform, openId));
    }
    
    /**
     * 修改密码
     */
    public void changePassword(String oldPassword, String newPassword) {
        if (!PasswordUtil.verify(oldPassword, this.passwordHash)) {
            throw new DomainException("PASSWORD_MISMATCH", "原密码不正确");
        }
        
        this.passwordHash = PasswordUtil.hash(newPassword);
        
        // 所有 Token 失效
        DomainEvents.publish(new PasswordChangedEvent(this.id));
    }
    
    /**
     * 冻结账号
     */
    public void freeze(String reason) {
        if (this.status == AccountStatus.DEACTIVATED) {
            throw new DomainException("ACCOUNT_DEACTIVATED", "账号已注销，无法操作");
        }
        this.status = AccountStatus.FROZEN;
        DomainEvents.publish(new AccountFrozenEvent(this.id, reason));
    }
    
    /**
     * 注销账号
     */
    public void deactivate() {
        this.status = AccountStatus.DEACTIVATED;
        DomainEvents.publish(new AccountDeactivatedEvent(this.id));
    }
}

/** 账号状态 */
public enum AccountStatus {
    ACTIVE,       // 正常
    FROZEN,       // 冻结（可恢复）
    DEACTIVATED   // 注销（不可恢复）
}
```

### 5.2 StudentProfile（学生档案）

```java
/**
 * 学生档案聚合根
 * 
 * 不变式：
 * 1. 学段与年级必须匹配（小学阶段对应1-6年级，初中对应7-9年级，高中对应10-12年级）
 * 2. 教材版本变更时，所有关联的学习进度需要触发迁移检查
 * 3. 年级升迁后，学段可能发生变化（如6年级→7年级时学段从小学变为初中）
 */
@Entity
@Table(name = "student_profiles")
public class StudentProfile {
    
    @Id
    private StudentProfileId id;
    
    /** 关联的账号 ID */
    private AccountId accountId;
    
    /** 昵称 */
    private String nickname;
    
    /** 头像 URL */
    private String avatarUrl;
    
    /** 学段 */
    @Enumerated(EnumType.STRING)
    private EducationStage educationStage;
    
    /** 年级（数字表示：1-12） */
    private Integer gradeLevel;
    
    /** 教材版本偏好（按学科） */
    @ElementCollection
    private Map<String, String> textbookPreferences; // subject -> textbookVersion
    
    /** 学习偏好 */
    @Embedded
    private LearningPreferences learningPreferences;
    
    /** 家长绑定关系 */
    private ParentBindingId parentBindingId;
    
    /** 班级关联 */
    private ClassId classId;
    
    /** 创建时间 */
    private Instant createdAt;
    
    /** 最后更新时间 */
    private Instant updatedAt;
    
    // ===== 领域方法 =====
    
    /**
     * 创建学生档案
     */
    public static StudentProfile create(AccountId accountId, EducationStage stage, 
                                         Integer gradeLevel, String nickname) {
        // 不变式校验：学段与年级匹配
        validateGradeStage(stage, gradeLevel);
        
        StudentProfile profile = new StudentProfile();
        profile.id = StudentProfileId.next();
        profile.accountId = accountId;
        profile.educationStage = stage;
        profile.gradeLevel = gradeLevel;
        profile.nickname = nickname;
        profile.textbookPreferences = new HashMap<>();
        profile.learningPreferences = LearningPreferences.defaultFor(stage);
        profile.createdAt = Instant.now();
        profile.updatedAt = Instant.now();
        
        DomainEvents.publish(new ProfileCreatedEvent(profile.id, accountId, stage, gradeLevel));
        
        return profile;
    }
    
    /**
     * 升级年级（新学年）
     */
    public void promoteGrade() {
        Integer oldGrade = this.gradeLevel;
        EducationStage oldStage = this.educationStage;
        
        this.gradeLevel++;
        
        // 检查学段是否需要切换
        this.educationStage = EducationStage.fromGrade(this.gradeLevel);
        
        // 学段切换时，教材版本偏好需要重新设置
        if (oldStage != this.educationStage) {
            this.textbookPreferences.clear();
        }
        
        this.updatedAt = Instant.now();
        
        DomainEvents.publish(new GradePromotedEvent(
            this.id, oldStage, oldGrade, this.educationStage, this.gradeLevel
        ));
    }
    
    /**
     * 设置教材版本
     */
    public void setTextbookVersion(String subject, String textbookVersion) {
        String oldVersion = this.textbookPreferences.get(subject);
        this.textbookPreferences.put(subject, textbookVersion);
        this.updatedAt = Instant.now();
        
        DomainEvents.publish(new TextbookVersionChangedEvent(
            this.id, subject, oldVersion, textbookVersion
        ));
    }
    
    /**
     * 绑定家长
     */
    public void bindParent(ParentBindingId bindingId, AccountId parentAccountId) {
        if (this.parentBindingId != null) {
            throw new DomainException("PARENT_ALREADY_BOUND", "该学生已绑定家长");
        }
        this.parentBindingId = bindingId;
        this.updatedAt = Instant.now();
        
        DomainEvents.publish(new ParentBoundEvent(this.id, bindingId, parentAccountId));
    }
    
    /**
     * 校验学段与年级匹配关系
     */
    private static void validateGradeStage(EducationStage stage, Integer grade) {
        boolean valid = switch (stage) {
            case PRESCHOOL -> grade >= 0 && grade <= 3;       // 幼儿：K1-K3
            case PRIMARY -> grade >= 1 && grade <= 6;          // 小学：1-6年级
            case JUNIOR_HIGH -> grade >= 7 && grade <= 9;      // 初中：7-9年级
            case SENIOR_HIGH -> grade >= 10 && grade <= 12;    // 高中：10-12年级
        };
        if (!valid) {
            throw new DomainException(
                "GRADE_STAGE_MISMATCH",
                String.format("学段 %s 与年级 %d 不匹配", stage, grade)
            );
        }
    }
}
```

### 5.3 LearningSession（学习会话）

```java
/**
 * 学习会话聚合根
 * 
 * 不变式：
 * 1. 会话状态只能按照 INITIALIZED → ACTIVE → PAUSED → ACTIVE → ENDED 流转
 * 2. 有效学习时长 = 总时长 - 暂停时长 - 空闲超时时长
 * 3. 一个用户同一时间只能有一个 ACTIVE 状态的学习会话
 * 4. 会话结束后不可再修改
 */
@Entity
@Table(name = "learning_sessions")
public class LearningSession {
    
    @Id
    private LearningSessionId id;
    
    /** 用户 ID */
    private UserId userId;
    
    /** 会话类型 */
    @Enumerated(EnumType.STRING)
    private SessionType sessionType;  // AI_TUTORING, EXERCISE, READING, MEMORIZATION, ...
    
    /** 会话状态 */
    @Enumerated(EnumType.STRING)
    private SessionStatus status;
    
    /** 关联的学科 */
    private String subject;
    
    /** 关联的章节 ID（可选） */
    private ChapterId chapterId;
    
    /** 开始时间 */
    private Instant startedAt;
    
    /** 结束时间 */
    private Instant endedAt;
    
    /** 最后活跃时间 */
    private Instant lastActiveAt;
    
    /** 暂停时间 */
    private Instant pausedAt;
    
    /** 累计暂停时长（秒） */
    private Long totalPausedDurationSeconds;
    
    /** 累计有效学习时长（秒） */
    private Long effectiveDurationSeconds;
    
    /** 学习行为记录数量 */
    private Integer behaviorCount;
    
    /** 设备标识 */
    private String deviceFingerprint;
    
    /** 会话快照（用于断点续学） */
    @Embedded
    private SessionSnapshot snapshot;
    
    // ===== 领域方法 =====
    
    /**
     * 开始新会话
     */
    public static LearningSession start(UserId userId, SessionType type, 
                                          String subject, String deviceFingerprint) {
        LearningSession session = new LearningSession();
        session.id = LearningSessionId.next();
        session.userId = userId;
        session.sessionType = type;
        session.subject = subject;
        session.status = SessionStatus.ACTIVE;
        session.startedAt = Instant.now();
        session.lastActiveAt = session.startedAt;
        session.totalPausedDurationSeconds = 0L;
        session.effectiveDurationSeconds = 0L;
        session.behaviorCount = 0;
        session.deviceFingerprint = deviceFingerprint;
        
        DomainEvents.publish(new SessionStartedEvent(session.id, userId, type, subject));
        
        return session;
    }
    
    /**
     * 暂停会话
     */
    public void pause() {
        assertStatus(SessionStatus.ACTIVE, "只有活跃状态的会话才能暂停");
        
        this.status = SessionStatus.PAUSED;
        this.pausedAt = Instant.now();
        
        DomainEvents.publish(new SessionPausedEvent(this.id, this.userId));
    }
    
    /**
     * 恢复会话
     */
    public void resume() {
        assertStatus(SessionStatus.PAUSED, "只有暂停状态的会话才能恢复");
        
        long pausedDuration = Duration.between(this.pausedAt, Instant.now()).getSeconds();
        this.totalPausedDurationSeconds += pausedDuration;
        
        this.status = SessionStatus.ACTIVE;
        this.lastActiveAt = Instant.now();
        this.pausedAt = null;
        
        DomainEvents.publish(new SessionResumedEvent(this.id, this.userId));
    }
    
    /**
     * 记录学习行为
     */
    public void recordBehavior() {
        assertStatus(SessionStatus.ACTIVE, "只有活跃状态的会话才能记录行为");
        
        this.behaviorCount++;
        this.lastActiveAt = Instant.now();
        
        // 更新有效时长
        this.effectiveDurationSeconds = Duration.between(
            this.startedAt, this.lastActiveAt
        ).getSeconds() - this.totalPausedDurationSeconds;
    }
    
    /**
     * 保存会话快照（用于断点续学）
     */
    public void saveSnapshot(String contentType, String contentId, 
                              Integer progressPercent, Map<String, Object> contextData) {
        this.snapshot = new SessionSnapshot(contentType, contentId, progressPercent, contextData);
        this.lastActiveAt = Instant.now();
    }
    
    /**
     * 结束会话
     */
    public SessionSummary end() {
        if (this.status == SessionStatus.PAUSED) {
            // 自动恢复后结束
            resume();
        }
        
        assertStatus(SessionStatus.ACTIVE, "只能结束活跃状态的会话");
        
        this.endedAt = Instant.now();
        this.status = SessionStatus.ENDED;
        
        // 计算最终有效时长
        this.effectiveDurationSeconds = Duration.between(
            this.startedAt, this.endedAt
        ).getSeconds() - this.totalPausedDurationSeconds;
        
        SessionSummary summary = new SessionSummary(
            this.id, this.userId, this.sessionType, this.subject,
            this.startedAt, this.endedAt, this.effectiveDurationSeconds,
            this.behaviorCount, this.snapshot
        );
        
        DomainEvents.publish(new SessionEndedEvent(summary));
        
        return summary;
    }
    
    private void assertStatus(SessionStatus expected, String message) {
        if (this.status != expected) {
            throw new DomainException("INVALID_SESSION_STATE", 
                String.format("%s 当前状态: %s", message, this.status));
        }
    }
}

/** 会话状态机 */
public enum SessionStatus {
    INITIALIZED,  // 初始化（预留，一般不使用）
    ACTIVE,       // 活跃中
    PAUSED,       // 暂停
    ENDED         // 已结束
}

/** 会话类型 */
public enum SessionType {
    AI_TUTORING,      // AI 辅导对话
    EXERCISE,         // 练习答题
    CONTENT_READING,  // 内容阅读
    MEMORIZATION,     // 背诵练习
    EXAM_SIMULATION,  // 考试模拟
    MISTAKE_REVIEW,   // 错题复习
    PLAN_EXECUTION    // 计划执行
}
```

### 5.4 MistakeEntry（错题条目）

```java
/**
 * 错题条目聚合根
 * 
 * 不变式：
 * 1. 同一学生 + 同一题目的错题只能有一条（合并模式）
 * 2. 错题状态只能按 PENDING → REVIEWING → MASTERED 流转

@Entity
@Table(name = "mistake_entries", 
       uniqueConstraints = @UniqueConstraint(columnNames = {"user_id", "question_id"}))
public class MistakeEntry {
    
    @Id
    private MistakeEntryId id;
    
    /** 学生 ID */
    private UserId userId;
    
    /** 题目 ID */
    private QuestionId questionId;
    
    /** 学生答案（首次错误答案） */
    private String firstWrongAnswer;
    
    /** 最近一次答案 */
    private String lastAnswer;
    
    /** 错因标签列表 */
    @ElementCollection
    private Set<MistakeTag> mistakeTags;
    
    /** 知识点列表 */
    @ElementCollection
    private Set<String> knowledgePointIds;
    
    /** 来源 */
    @Enumerated(EnumType.STRING)
    private OutcomeSource source;  // PRACTICE, EXAM, PHOTO_SEARCH, MANUAL
    
    /** 错题状态 */
    @Enumerated(EnumType.STRING)
    private MistakeStatus status;
    
    /** 连续正确次数 */
    private Integer consecutiveCorrectCount;
    
    /** 总复习次数 */
    private Integer totalReviewCount;
    
    /** 总答错次数 */
    private Integer totalWrongCount;
    
    /** 掌握度（0.0-1.0） */
    private Double masteryLevel;
    
    /** 下次复习时间 */
    private Instant nextReviewAt;
    
    /** 最后复习时间 */
    private Instant lastReviewedAt;
    
    /** 添加时间 */
    private Instant addedAt;
    
    /** SRS 参数（间隔重复算法参数） */
    @Embedded
    private SRSParameters srsParameters;
    
    // ===== 领域方法 =====
    
    /**
     * 添加错题
     */
    public static MistakeEntry add(UserId userId, QuestionId questionId, 
                                     String wrongAnswer, List<String> knowledgePoints,
                                     OutcomeSource source) {
        MistakeEntry entry = new MistakeEntry();
        entry.id = MistakeEntryId.next();
        entry.userId = userId;
        entry.questionId = questionId;
        entry.firstWrongAnswer = wrongAnswer;
        entry.lastAnswer = wrongAnswer;
        entry.mistakeTags = new HashSet<>();
        entry.knowledgePointIds = new HashSet<>(knowledgePoints);
        entry.source = source;
        entry.status = MistakeStatus.PENDING;
        entry.consecutiveCorrectCount = 0;
        entry.totalReviewCount = 0;
        entry.totalWrongCount = 1;
        entry.masteryLevel = 0.0;
        entry.addedAt = Instant.now();
        entry.srsParameters = SRSParameters.initial();
        entry.nextReviewAt = entry.addedAt.plus(Duration.ofHours(12)); // 首次复习在12小时后
        
        DomainEvents.publish(new MistakeAddedEvent(entry.id, userId, questionId));
        
        return entry;
    }
    
    /**
     * 记录复习结果
     */
    public void recordReview(String answer, boolean correct) {
        assertNotMastered();
        
        this.lastAnswer = answer;
        this.lastReviewedAt = Instant.now();
        this.totalReviewCount++;
        
        if (correct) {
            handleCorrectAnswer();
        } else {
            handleWrongAnswer();
        }
        
        // 更新下次复习时间（基于 SRS 算法）
        this.nextReviewAt = SRSScheduler.calculateNextReview(
            this.srsParameters, 
            this.consecutiveCorrectCount,
            this.lastReviewedAt
        );
        
        DomainEvents.publish(new MistakeReviewedEvent(
            this.id, this.userId, this.questionId, correct, this.masteryLevel
        ));
    }
    
    /**
     * 添加错因标签
     */
    public void addTag(MistakeTag tag) {
        this.mistakeTags.add(tag);
    }
    
    private void handleCorrectAnswer() {
        this.consecutiveCorrectCount++;
        
        // 根据连续正确次数更新掌握度
        this.masteryLevel = Math.min(1.0, 
            this.masteryLevel + MasteryCalculator.increment(this.consecutiveCorrectCount));
        
        // SRS 参数调整：增加间隔
        this.srsParameters = this.srsParameters.onCorrect(this.consecutiveCorrectCount);
        
        // 掌握度达到阈值，标记为已掌握
        if (this.masteryLevel >= MasteryCalculator.MASTERY_THRESHOLD) {
            this.status = MistakeStatus.MASTERED;
            DomainEvents.publish(new MistakeMasteredEvent(this.id, this.userId, this.questionId));
        }
    }
    
    private void handleWrongAnswer() {
        this.totalWrongCount++;
        this.consecutiveCorrectCount = 0; // 重置连续正确
        this.masteryLevel = Math.max(0.0, this.masteryLevel - 0.15);
        
        // SRS 参数调整：缩短间隔
        this.srsParameters = this.srsParameters.onWrong();
        
        // 如果之前已标记为复习中，保持状态不变
        if (this.status == MistakeStatus.PENDING) {
            this.status = MistakeStatus.REVIEWING;
        }
    }
    
    private void assertNotMastered() {
        if (this.status == MistakeStatus.MASTERED) {
            throw new DomainException("MISTAKE_ALREADY_MASTERED", "该错题已掌握，无需再复习");
        }
    }
}

/** 错题状态机 */
public enum MistakeStatus {
    PENDING,      // 待复习（刚加入）
    REVIEWING,    // 复习中（已开始复习）
    MASTERED      // 已掌握
}
```

```java
/**
 * Token 预算（值对象）
 */
@Embeddable
public class TokenBudget {
    private int totalBudget;
    private int consumed;
    private int reservedForResponse;
    
    public int getRemaining() {
        return totalBudget - consumed - reservedForResponse;
    }
    
    public void consume(int tokens) {
        if (consumed + tokens > totalBudget) {
            throw new DomainException("TOKEN_BUDGET_EXCEEDED", 
                String.format("Token 预算超限: 已用 %d + 本次 %d > 总量 %d", 
                    consumed, tokens, totalBudget));
        }
        this.consumed += tokens;
    }
    
    public boolean hasBudgetFor(int tokens) {
        return getRemaining() >= tokens;
    }
}

/**
 * SRS 参数（值对象）
 * 间隔重复算法参数
 */
@Embeddable
public class SRSParameters {
    private double easeFactor;      // 难易因子（默认 2.5）
    private int intervalDays;       // 当前间隔天数
    private int repetitions;        // 已完成重复次数
    
    public static SRSParameters initial() {
        return new SRSParameters(2.5, 0, 0);
    }
    
    public SRSParameters onCorrect(int consecutiveCorrect) {
        double newEase = Math.max(1.3, easeFactor + 0.1);
        int newInterval = switch (consecutiveCorrect) {
            case 1 -> 1;       // 第一次正确：1天后
            case 2 -> 3;       // 第二次正确：3天后
            case 3 -> 7;       // 第三次正确：7天后
            case 4 -> 15;      // 第四次正确：15天后
            default -> (int) (newInterval * newEase);  // 后续按因子增长
        };
        return new SRSParameters(newEase, newInterval, repetitions + 1);
    }
    
    public SRSParameters onWrong() {
        // 答错：重置间隔，降低因子
        return new SRSParameters(Math.max(1.3, easeFactor - 0.2), 0, 0);
    }
}
```

## 10. 应用服务规范

### 10.1 应用服务职责

应用服务是领域层的外壳，负责：
1. 接收外部请求（API/RPC/MQ）
2. 权限校验
3. 事务管理
4. 调用领域服务/聚合根方法
5. 发布领域事件
6. 返回 DTO

**应用服务不应包含业务逻辑。**

### 10.2 应用服务示例

```java
/**
 * 错题应用服务
 */
@Service
@Transactional
public class MistakeApplicationService {
    
    private final MistakeEntryRepository mistakeRepo;
    private final QuestionRepository questionRepo;
    private final UserRepository userRepo;
    private final DomainEventPublisher eventPublisher;
    
    /**
     * 手动添加错题
     */
    public MistakeEntryDTO addMistake(AddMistakeCommand cmd) {
        // 1. 权限校验
        User user = userRepo.findById(cmd.userId())
            .orElseThrow(() -> new NotFoundException("用户不存在"));
        if (!user.canAddMistake()) {
            throw new ForbiddenException("无权添加错题");
        }
        
        // 2. 获取相关聚合
        Question question = questionRepo.findById(cmd.questionId())
            .orElseThrow(() -> new NotFoundException("题目不存在"));
        
        // 3. 检查是否已存在
        Optional<MistakeEntry> existing = mistakeRepo
            .findByUserAndQuestion(cmd.userId(), cmd.questionId());
        
        MistakeEntry entry;
        if (existing.isPresent()) {
            // 已存在，更新复习记录
            entry = existing.get();
            entry.recordReview(cmd.answer(), false);
        } else {
            // 新增错题
            entry = MistakeEntry.add(
                cmd.userId(),
                cmd.questionId(),
                cmd.wrongAnswer(),
                question.getKnowledgePointIds(),
                OutcomeSource.MANUAL
            );
        }
        
        // 4. 持久化
        mistakeRepo.save(entry);
        
        // 5. 返回 DTO
        return MistakeEntryDTO.from(entry);
    }
    
    /**
     * 获取待复习错题列表
     */
    @Transactional(readOnly = true)
    public List<MistakeEntryDTO> getPendingReviews(UserId userId, int limit) {
        List<MistakeEntry> entries = mistakeRepo.findPendingReviews(
            userId, Instant.now()
        );
        return entries.stream()
            .sorted(Comparator.comparing(MistakeEntry::getNextReviewAt))
            .limit(limit)
            .map(MistakeEntryDTO::from)
            .collect(Collectors.toList());
    }
}

/**
 * 命令对象（Command）
 */
public record AddMistakeCommand(
    UserId userId,
    QuestionId questionId,
    String wrongAnswer,
    String answer
) {}

/**
 * DTO（数据传输对象）
 */
public record MistakeEntryDTO(
    String id,
    String questionId,
    String status,
    double masteryLevel,
    int totalReviewCount,
    int consecutiveCorrectCount,
    Instant nextReviewAt,
    List<String> knowledgePoints
) {
    public static MistakeEntryDTO from(MistakeEntry entry) {
        return new MistakeEntryDTO(
            entry.getId().toString(),
            entry.getQuestionId().toString(),
            entry.getStatus().name(),
            entry.getMasteryLevel(),
            entry.getTotalReviewCount(),
            entry.getConsecutiveCorrectCount(),
            entry.getNextReviewAt(),
            List.copyOf(entry.getKnowledgePointIds())
        );
    }
}
```

## 11. 跨上下文数据一致性策略

### 11.1 一致性模型

| 场景 | 一致性要求 | 策略 |
| --- | --- | --- |
| 聚合根内部 | 强一致性 | 单数据库事务 |
| 同一限界上下文内 | 强一致性 | 本地事务 |
| 跨限界上下文 | 最终一致性 | 领域事件 + Saga |
| 跨服务查询 | 最终一致性 | CQRS 读模型 + 缓存 |

### 11.2 Saga 模式示例

以「学生购买会员」为例，涉及 Payment、Membership、Gamification 三个上下文：

```java
/**
 * 订阅购买 Saga 协调器
 */
@Service
public class SubscriptionPurchaseSaga {
    
    /**
     * Saga 执行步骤：
     * 1. [Payment] 创建订单 → OrderCreatedEvent
     * 2. [Payment] 支付处理 → PaymentSucceededEvent
     * 3. [Membership] 激活会员 → SubscribedEvent
     * 4. [Gamification] 发放积分 → PointsEarnedEvent
     * 5. [Notification] 发送通知
     * 
     * 补偿步骤（逆序）：
     * 5. 撤销通知（无需补偿）
     * 4. [Gamification] 扣除积分
     * 3. [Membership] 取消会员
     * 2. [Payment] 发起退款
     * 1. [Payment] 关闭订单
     */
    
    @SagaStep(compensation = "cancelOrder")
    public void createOrder(CreateOrderCommand cmd) {
        // 创建支付订单
        Order order = Order.create(cmd.userId(), cmd.planId(), cmd.amount());
        orderRepo.save(order);
        eventPublisher.publish(new OrderCreatedEvent(order.getId()));
    }
    
    @SagaStep(compensation = "refundPayment")
    public void processPayment(OrderCreatedEvent event) {
        // 处理支付
        Order order = orderRepo.findById(event.orderId());
        Payment payment = paymentService.process(order);
        if (payment.isSuccess()) {
            eventPublisher.publish(new PaymentSucceededEvent(
                order.getId(), payment.getId(), order.getUserId()
            ));
        }
    }
    
    @SagaStep(compensation = "deactivateMembership")
    public void activateMembership(PaymentSucceededEvent event) {
        // 激活会员
        Membership membership = membershipService.activate(
            event.userId(), event.orderId()
        );
        eventPublisher.publish(new SubscribedEvent(membership));
    }
    
    @SagaStep(compensation = "deductPoints")
    public void awardPoints(SubscribedEvent event) {
        // 发放购买奖励积分
        gamificationService.awardPoints(
            event.membership().getUserId(), 
            PointSource.PURCHASE_REWARD,
            event.membership().getPlan().getRewardPoints()
        );
    }
}
```

## 12. 与现有详细设计文档的关系

### 12.1 本文档的定位

```
本文档（核心领域模型）
    │
    ├── 定义了所有限界上下文的边界
    ├── 定义了统一领域语言
    ├── 定义了核心聚合根和值对象
    ├── 定义了领域事件目录
    ├── 定义了跨上下文交互契约
    │
    ↓ 指导 ↓
    
各模块详细设计文档（docs2/ 目录下的数百个文档）
    │
    ├── 应使用本文档定义的术语
    ├── 聚合根设计应与本文档一致
    ├── 领域事件命名应遵循本文档规范
    └── 跨模块交互应遵循本文档的上下文映射
```

### 12.2 约束规则

1. **术语一致性**：各详细设计文档中使用的领域概念名称必须与本文档第 4 节统一领域语言词汇表一致。
2. **聚合边界一致性**：各文档中涉及的聚合根边界必须与本文档第 5 节定义一致，不得随意扩大或缩小。
3. **事件命名一致性**：领域事件命名遵循本文档第 6.1 节的命名规范。
4. **新增上下文**：如果需要新增限界上下文，应更新本文档的第 2 节和第 3 节。
5. **模型变更**：核心领域模型的变更需要经过架构评审。

## 14. 性能与扩展考虑

### 14.1 聚合设计优化

| 策略 | 说明 |
| --- | --- |
| 小聚合 | 聚合内只包含强一致性必须的字段，关联数据通过 ID 引用 |

### 15.2 时区与时间处理规范

```java
/**
 * 全局时间规范：
 * - 数据库存储：UTC 时间（TIMESTAMP WITH TIME ZONE）
 * - API 传输：ISO 8601 带时区（如 2026-08-11T10:30:00+08:00）
 * - 业务计算：统一使用 Asia/Shanghai 时区
 * - 领域模型内部：使用 Instant（UTC）
 */
public final class TimeUtils {
    
    private static final ZoneId BUSINESS_ZONE = ZoneId.of("Asia/Shanghai");
    
    /** 获取当前业务时间 */
    public static LocalDateTime nowBusinessTime() {
        return LocalDateTime.now(BUSINESS_ZONE);
    }
    
    /** 获取当前 UTC 时间 */
    public static Instant now() {
        return Instant.now();
    }
    
    /** 将业务日期转换为 UTC Instant（当天开始） */
    public static Instant businessDayToUtcStart(LocalDate businessDate) {
        return businessDate.atStartOfDay(BUSINESS_ZONE).toInstant();
    }
    
    /** 将业务日期转换为 UTC Instant（当天结束） */
    public static Instant businessDayToUtcEnd(LocalDate businessDate) {
        return businessDate.atTime(23, 59, 59).atZone(BUSINESS_ZONE).toInstant();
    }
    
    /** 判断两个 Instant 是否在同一业务日 */
    public static boolean isSameBusinessDay(Instant a, Instant b) {
        LocalDate dateA = a.atZone(BUSINESS_ZONE).toLocalDate();
        LocalDate dateB = b.atZone(BUSINESS_ZONE).toLocalDate();
        return dateA.equals(dateB);
    }
}
```
