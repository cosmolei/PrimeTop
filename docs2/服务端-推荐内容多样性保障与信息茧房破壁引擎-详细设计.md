# 推荐内容多样性保障与信息茧房破壁引擎 — 详细设计

> **文档版本**：v1.0
> **创建日期**：2026-06-16
> **所属模块**：推荐系统 / 内容分发
> **依赖模块**：题目智能推荐服务、首页内容卡片推荐服务、自适应学习推荐引擎、用户学习画像服务、知识点体系服务

---

## 1. 背景与目标

### 1.1 问题背景

PrimeTop 的推荐系统已具备较强的个性化推荐能力（题目推荐、首页卡片推荐、学习路径推荐等），但纯准确性导向的推荐存在以下风险：

| 风险 | 表现 | 影响 |
|------|------|------|
| 学科信息茧房 | 学生只看到擅长或偏好的学科内容 | 偏科加剧，弱势学科得不到练习 |
| 知识点窄化 | 推荐集中在少数高频知识点 | 知识盲区扩大，综合能力下降 |
| 题型单一化 | 反复推送同类题型 | 缺乏题型迁移能力，考试适应性差 |
| 难度固化 | 长期推荐舒适区难度内容 | 学习瓶颈无法突破 |
| 探索缺失 | 新内容/新话题难以获得曝光 | 用户兴趣无法拓展，长期倦怠 |

### 1.2 设计目标

1. **多样性保障**：在推荐结果中注入多样性约束，确保推荐内容在学科、知识点、题型、难度等维度保持合理分布。
2. **信息茧房检测**：持续监测用户的推荐消费分布，当检测到信息茧房趋势时主动触发破壁策略。
3. **探索-利用平衡**：在保证推荐质量的前提下，为用户引入适度的探索性内容，拓展学习边界。
4. **可配置干预**：提供运营可配置的多样性规则与干预策略，支持按学段、学科、场景灵活调整。
5. **效果可度量**：建立多样性指标体系，持续评估多样性策略的效果与影响。

### 1.3 设计原则

- **不伤害原则**：多样性策略不应显著降低推荐准确率和用户满意度（准确率下降 < 5%）。
- **分龄差异化**：低年级学生更需要引导式探索，高年级学生更注重考试导向，多样性策略需差异化。
- **渐进式引入**：多样性权重随用户数据积累动态调整，冷启动期低权重，数据充分后逐步提高。
- **可解释性**：多样性调整原因可追溯，支持向用户/家长/运营解释为何推荐某内容。

## 4. 核心算法设计

### 4.1 信息茧房检测算法

#### 4.1.1 多维度茧房评分

对用户最近 N 天（默认 7 天）的推荐消费分布进行多维度评分，每个维度独立计算后加权汇总。

```java
/**
 * 茧房评分算法
 * 输入: 用户最近N天的推荐消费分布
 * 输出: 0-100的茧房评分，越高越严重
 */
public class FilterBubbleDetector {
    
    private static final int ANALYSIS_WINDOW_DAYS = 7;
    private static final int MIN_SAMPLE_SIZE = 20;
    
    // 各维度权重
    private static final Map<String, Double> DIMENSION_WEIGHTS = Map.of(
        "subject",        0.30,  // 学科分布最重要
        "knowledge_point", 0.25, // 知识点集中度
        "question_type",   0.15, // 题型多样性
        "difficulty",      0.15, // 难度分布
        "ability",         0.15  // 能力维度
    );
    
    public FilterBubbleReport detect(Long userId) {
        // 1. 获取最近N天的消费分布
        List<DistributionSnapshot> snapshots = 
            distributionRepository.getRecentSnapshots(userId, ANALYSIS_WINDOW_DAYS);
        
        if (totalSamples(snapshots) < MIN_SAMPLE_SIZE) {
            return FilterBubbleReport.insufficientData(userId);
        }
        
        // 2. 聚合N天分布
        DistributionSnapshot aggregated = aggregate(snapshots);
        
        // 3. 各维度独立评分
        Map<String, Double> dimensionScores = new HashMap<>();
        dimensionScores.put("subject",        scoreSubjectDistribution(aggregated));
        dimensionScores.put("knowledge_point", scoreKnowledgeConcentration(aggregated));
        dimensionScores.put("question_type",   scoreQuestionTypeDiversity(aggregated));
        dimensionScores.put("difficulty",      scoreDifficultySpread(aggregated));
        dimensionScores.put("ability",         scoreAbilityDistribution(aggregated));
        
        // 4. 加权汇总
        double overallScore = dimensionScores.entrySet().stream()
            .mapToDouble(e -> e.getValue() * DIMENSION_WEIGHTS.get(e.getKey()))
            .sum();
        
        // 5. 生成告警
        List<BubbleAlert> alerts = generateAlerts(dimensionScores, aggregated);
        
        // 6. 生成探索建议
        List<ExplorationSuggestion> suggestions = generateSuggestions(aggregated, dimensionScores);
        
        return FilterBubbleReport.builder()
            .userId(userId)
            .overallScore(overallScore)
            .dimensionScores(dimensionScores)
            .alerts(alerts)
            .suggestions(suggestions)
            .interventionNeeded(overallScore > 65)
            .build();
    }
    
    /**
     * 学科分布评分 — 基于香农熵
     * 熵越高越多样，评分越低(越好)
     * 评分 = (1 - normalizedEntropy) * 100
     */
    private double scoreSubjectDistribution(DistributionSnapshot dist) {
        Map<String, Double> subjectDist = dist.getSubjectDist();
        int numSubjects = subjectDist.size();
        if (numSubjects <= 1) return 100; // 只有一个学科 = 满分茧房
        
        // 计算香农熵
        double entropy = subjectDist.values().stream()
            .filter(p -> p > 0)
            .mapToDouble(p -> -p * Math.log(p))
            .sum();
        
        // 归一化: max entropy = ln(numSubjects)
        double maxEntropy = Math.log(Math.max(numSubjects, 2));
        double normalizedEntropy = entropy / maxEntropy;
        
        return (1 - normalizedEntropy) * 100;
    }
    
    /**
     * 知识点集中度评分 — 基于基尼系数
     * 基尼系数越高，分布越不均匀，茧房越严重
     */
    private double scoreKnowledgeConcentration(DistributionSnapshot dist) {
        Map<String, Double> kpDist = dist.getKnowledgeDist();
        if (kpDist.size() < 3) return 80; // 知识点太少
        
        List<Double> values = kpDist.values().stream()
            .sorted().collect(Collectors.toList());
        
        // 计算基尼系数
        double sum = 0;
        int n = values.size();
        for (int i = 0; i < n; i++) {
            sum += (2 * (i + 1) - n - 1) * values.get(i);
        }
        double gini = sum / (n * values.stream().mapToDouble(d -> d).sum());
        
        return gini * 100;
    }
    
    /**
     * 难度分布评分 — 基于难度跨度的标准差
     * 难度集中在单一区间 = 高茧房分
     */
    private double scoreDifficultySpread(DistributionSnapshot dist) {
        Map<String, Double> diffDist = dist.getDifficultyDist();
        
        // 映射为数值
        double easy = diffDist.getOrDefault("EASY", 0.0);
        double medium = diffDist.getOrDefault("MEDIUM", 0.0);
        double hard = diffDist.getOrDefault("HARD", 0.0);
        
        // 加权平均难度
        double avgDifficulty = easy * 1 + medium * 2 + hard * 3;
        
        // 标准差
        double variance = easy * Math.pow(1 - avgDifficulty, 2) 
                        + medium * Math.pow(2 - avgDifficulty, 2) 
                        + hard * Math.pow(3 - avgDifficulty, 2);
        double stdDev = Math.sqrt(variance);
        
        // stdDev 范围 0~0.8167(均匀分布), 归一化
        double normalizedSpread = Math.min(stdDev / 0.8167, 1.0);
        
        return (1 - normalizedSpread) * 100;
    }
}
```

### 4.2 多样性重排算法

#### 4.2.1 MMR (Maximal Marginal Relevance) 重排

MMR 是经典的多样性重排算法，在相关性和多样性之间寻找帕累托最优。

```java
/**
 * MMR 多样性重排
 * 
 * MMR = argmax [ λ * Sim(d, q) - (1-λ) * max(Sim(d, d_selected)) ]
 * 
 * λ: 相关性-多样性平衡因子, 0~1
 *   λ=1 纯相关性排序 (无多样性保障)
 *   λ=0 纯多样性排序 (可能推荐无关内容)
 *   推荐默认: λ=0.7 (偏相关性，适度多样性)
 */
public class MMRReranker implements DiversityReranker {
    
    @Override
    public DiversityRerankResult rerank(
            List<DiversityCandidate> candidates,
            DiversityConfig config,
            FilterBubbleReport bubbleReport) {
        
        // 根据茧房评分动态调整 λ
        double lambda = adjustLambda(config.getLambda(), bubbleReport);
        
        // 预计算候选对之间的相似度矩阵
        double[][] simMatrix = computeSimilarityMatrix(candidates);
        
        // 用户兴趣向量 (从用户画像获取)
        double[] userProfile = getUserInterestVector(candidates.get(0).getUserId());
        
        // 候选与用户兴趣的相似度
        double[] relevanceScores = candidates.stream()
            .mapToDouble(c -> computeRelevance(c, userProfile))
            .toArray();
        
        // MMR 贪心选择
        List<Integer> selected = new ArrayList<>();
        Set<Integer> remaining = IntStream.range(0, candidates.size())
            .boxed().collect(Collectors.toSet());
        
        int targetSize = Math.min(config.getWindowSize(), candidates.size());
        
        while (selected.size() < targetSize && !remaining.isEmpty()) {
            int bestIdx = -1;
            double bestScore = Double.NEGATIVE_INFINITY;
            
            for (int i : remaining) {
                // 相关性项
                double relevance = lambda * relevanceScores[i];
                
                // 多样性惩罚项
                double maxSim = selected.isEmpty() ? 0 :
                    selected.stream().mapToDouble(j -> simMatrix[i][j]).max().orElse(0);
                double diversityPenalty = (1 - lambda) * maxSim;
                
                double mmrScore = relevance - diversityPenalty;
                
                // 叠加探索加分
                mmrScore += candidates.get(i).getExplorationBonus();
                
                if (mmrScore > bestScore) {
                    bestScore = mmrScore;
                    bestIdx = i;
                }
            }
            
            selected.add(bestIdx);
            remaining.remove(bestIdx);
        }
        
        // 构建结果
        List<DiversityCandidate> reranked = selected.stream()
            .map(candidates::get)
            .peek(c -> c.setFinalScore(/* 重新计算 */))
            .collect(Collectors.toList());
        
        return DiversityRerankResult.builder()
            .rerankedList(reranked)
            .beforeMetrics(computeMetrics(candidates))
            .afterMetrics(computeMetrics(reranked))
            .algorithm("MMR")
            .build();
    }
    
    /**
     * 根据茧房评分动态调整 λ
     * 茧房越严重，λ 越小（多样性权重越大）
     */
    private double adjustLambda(double baseLambda, FilterBubbleReport report) {
        if (report == null || !report.isInterventionNeeded()) {
            return baseLambda;
        }
        
        double score = report.getOverallScore();
        if (score > 80) return Math.max(baseLambda - 0.3, 0.3);  // 极端: λ=0.3~0.4
        if (score > 65) return Math.max(baseLambda - 0.2, 0.4);  // 重度: λ=0.4~0.5
        if (score > 50) return Math.max(baseLambda - 0.1, 0.5);  // 中度: λ=0.5~0.6
        return baseLambda;
    }
    
    /**
     * 计算候选项之间的相似度
     * 基于多维特征的Jaccard/余弦混合相似度
     */
    private double[][] computeSimilarityMatrix(List<DiversityCandidate> candidates) {
        int n = candidates.size();
        double[][] matrix = new double[n][n];
        
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                double sim = computePairSimilarity(candidates.get(i), candidates.get(j));
                matrix[i][j] = sim;
                matrix[j][i] = sim;
            }
        }
        return matrix;
    }
    
    /**
     * 两个候选项之间的相似度
     * 综合学科、知识点、题型、难度等维度
     */
    private double computePairSimilarity(DiversityCandidate a, DiversityCandidate b) {
        // 学科相似度 (权重 0.3)
        double subjectSim = a.getSubject().equals(b.getSubject()) ? 1.0 : 0.0;
        
        // 知识点重叠度 (权重 0.3) - Jaccard
        Set<Long> kpUnion = new HashSet<>(a.getKnowledgePoints());
        kpUnion.addAll(b.getKnowledgePoints());
        Set<Long> kpInter = new HashSet<>(a.getKnowledgePoints());
        kpInter.retainAll(b.getKnowledgePoints());
        double kpSim = kpUnion.isEmpty() ? 0 : 
            (double) kpInter.size() / kpUnion.size();
        
        // 题型相似度 (权重 0.15)
        double qtSim = Objects.equals(a.getQuestionType(), b.getQuestionType()) ? 1.0 : 0.0;
        
        // 难度相似度 (权重 0.15)
        double diffSim = Objects.equals(a.getDifficultyLevel(), b.getDifficultyLevel()) ? 1.0 : 0.0;
        
        // 能力维度重叠 (权重 0.1)
        Set<String> abUnion = new HashSet<>(a.getAbilityDims());
        abUnion.addAll(b.getAbilityDims());
        Set<String> abInter = new HashSet<>(a.getAbilityDims());
        abInter.retainAll(b.getAbilityDims());
        double abilitySim = abUnion.isEmpty() ? 0 :
            (double) abInter.size() / abUnion.size();
        
        return 0.30 * subjectSim + 0.30 * kpSim + 0.15 * qtSim 
             + 0.15 * diffSim + 0.10 * abilitySim;
    }
}
```

#### 4.2.2 约束满足重排 (Constraint-Based Reranking)

当茧房评分较高时，切换为约束满足模式，硬性保证各维度配比。

```java
/**
 * 约束满足重排器
 * 在满足多样性约束的前提下，最大化相关性分数
 */
public class ConstraintBasedReranker implements DiversityReranker {
    
    @Override
    public DiversityRerankResult rerank(
            List<DiversityCandidate> candidates,
            DiversityConfig config,
            FilterBubbleReport bubbleReport) {
        
        // 提取适用的约束规则
        List<DiversityRule> rules = ruleService.getActiveRules(
            config.getScene(), config.getStage());
        
        // 按相关性降序排列候选
        candidates.sort(Comparator.comparing(DiversityCandidate::getOriginalScore).reversed());
        
        List<DiversityCandidate> result = new ArrayList<>();
        Map<String, Deque<Integer>> dimensionCounts = new HashMap<>();
        
        int windowSize = config.getWindowSize();
        
        for (DiversityCandidate candidate : candidates) {
            if (result.size() >= windowSize) break;
            
            // 检查是否违反任何约束
            if (!violatesConstraints(candidate, result, rules, dimensionCounts)) {
                result.add(candidate);
                updateDimensionCounts(dimensionCounts, candidate);
            }
        }
        
        // 如果约束太严格导致结果不足，放松约束补充
        if (result.size() < windowSize) {
            relaxAndFill(candidates, result, rules, windowSize);
        }
        
        return DiversityRerankResult.builder()
            .rerankedList(result)
            .algorithm("CONSTRAINT")
            .build();
    }
    
    private boolean violatesConstraints(
            DiversityCandidate candidate,
            List<DiversityCandidate> selected,
            List<DiversityRule> rules,
            Map<String, Deque<Integer>> counts) {
        
        for (DiversityRule rule : rules) {
            String dimKey = getDimensionKey(candidate, rule.getDimension());
            int currentCount = counts.getOrDefault(rule.getDimension(), new ArrayDeque<>()).size();
            
            switch (rule.getRuleType()) {
                case "ABSOLUTE":
                    int maxPer = rule.getParams().getInt("max_per_dimension");
                    String val = getDimensionValue(candidate, rule.getDimension());
                    long existing = selected.stream()
                        .map(s -> getDimensionValue(s, rule.getDimension()))
                        .filter(val::equals)
                        .count();
                    if (existing >= maxPer) return true;
                    break;
                    
                case "MIN_MAX":
                    int minTypes = rule.getParams().getInt("min_types");
                    int window = rule.getParams().getInt("window");
                    if (selected.size() >= window - 1) {
                        // 检查加入后是否满足最小类型数
                        Set<String> types = selected.stream()
                            .map(s -> getDimensionValue(s, rule.getDimension()))
                            .collect(Collectors.toSet());
                        types.add(getDimensionValue(candidate, rule.getDimension()));
                        if (types.size() < minTypes) return true;
                    }
                    break;
            }
        }
        return false;
    }
}
```

### 4.3 探索-利用平衡 (Exploration-Exploitation)

#### 4.3.1 ε-Greedy 策略

```java
/**
 * ε-Greedy 探索策略
 * 
 * 以 ε 概率从探索池中选取内容，以 1-ε 概率使用推荐系统结果。
 * ε 值根据用户探索接受度动态调整。
 */
public class EpsilonGreedyExplorer {
    
    public List<DiversityCandidate> injectExploration(
            List<DiversityCandidate> rankedCandidates,
            UserExplorationProfile profile,
            FilterBubbleReport bubbleReport,
            int targetSize) {
        
        // 动态计算 ε
        double epsilon = computeDynamicEpsilon(profile, bubbleReport);
        
        // 计算探索内容数量 (至少1个，最多占30%)
        int exploreCount = Math.max(1, (int) Math.round(targetSize * epsilon));
        exploreCount = Math.min(exploreCount, (int) (targetSize * 0.3));
        
        // 获取探索内容
        List<DiversityCandidate> explorationItems = explorationPoolService
            .getExplorationCandidates(
                profile.getUserId(),
                bubbleReport.getSuggestions(),
                exploreCount * 3  // 多取一些用于筛选
            );
        
        // 计算探索加分 (UCB风格)
        for (DiversityCandidate item : explorationItems) {
            double bonus = computeExplorationBonus(item, profile);
            item.setExplorationBonus(bonus);
        }
        
        // 合并: 替换推荐列表中相关性最低的 N 个位置
        List<DiversityCandidate> result = new ArrayList<>(rankedCandidates);
        explorationItems.sort(Comparator.comparing(DiversityCandidate::getExplorationBonus).reversed());
        
        int injectCount = Math.min(exploreCount, explorationItems.size());
        for (int i = 0; i < injectCount; i++) {
            int replaceIdx = result.size() - 1 - i; // 替换末尾(低分)位置
            if (replaceIdx >= 0) {
                result.set(replaceIdx, explorationItems.get(i));
            }
        }
        
        return result;
    }
    
    /**
     * 动态 ε 计算
     * 基础ε + 茧房加成 + 新用户加成 - 探索失败惩罚
     */
    private double computeDynamicEpsilon(
            UserExplorationProfile profile, 
            FilterBubbleReport bubbleReport) {
        
        double epsilon = profile.getEpsilon(); // 基础值 0.1
        
        // 茧房越严重，探索越多
        if (bubbleReport != null) {
            double bubbleBoost = Math.max(0, (bubbleReport.getOverallScore() - 50) / 100.0 * 0.15);
            epsilon += bubbleBoost;
        }
        
        // 新用户探索期 (前14天)
        if (profile.getLastExploredAt() == null) {
            epsilon += 0.1; // 新用户额外探索
        }
        
        // 探索成功率低则减少探索
        if (profile.getExplorationSuccessRate() < 0.3) {
            epsilon *= 0.7;
        }
        
        // 钳制
        return Math.max(0.05, Math.min(epsilon, 0.3));
    }
    
    /**
     * UCB风格探索加分
     * bonus = c * sqrt(ln(N_total) / N_content)
     * 内容曝光越少，加分越高
     */
    private double computeExplorationBonus(
            DiversityCandidate item,
            UserExplorationProfile profile) {
        
        // 从探索池获取该内容的曝光数据
        ExplorationPoolEntry entry = explorationPoolService.getEntry(item.getContentId());
        
        double c = profile.getUcbC(); // 默认 2.0
        int totalExposure = entry.getTotalExposureForUser(profile.getUserId());
        int userTotalExposure = profile.getTotalExplorationExposure();
        
        if (totalExposure == 0) {
            // 从未曝光给该用户，给予最大探索分
            return c * 0.5;
        }
        
        double bonus = c * Math.sqrt(Math.log(Math.max(userTotalExposure, 1)) / (double) totalExposure);
        
        // 叠加新颖度分
        bonus += item.getNoveltyScore() * 0.3;
        
        return bonus;
    }
}
```

### 7.1 完整重排流程编排

```java
/**
 * 多样性引擎核心编排服务
 */
@Service
public class DiversityEngineService {
    
    @Autowired private FilterBubbleDetector bubbleDetector;
    @Autowired private MMRReranker mmrReranker;
    @Autowired private ConstraintBasedReranker constraintReranker;
    @Autowired private EpsilonGreedyExplorer explorer;
    @Autowired private DiversityRuleService ruleService;
    @Autowired private UserExplorationProfileService profileService;
    @Autowired private DiversityMetricsService metricsService;
    @Autowired private DistributionSnapshotRepository snapshotRepo;
    
    /**
     * 核心入口: 对推荐候选执行多样性重排
     */
    public DiversityRerankResponse rerank(DiversityRerankRequest request) {
        long startTime = System.currentTimeMillis();
        Long userId = request.getUserId();
        
        // 1. 加载配置
        DiversityConfig config = loadConfig(request);
        
        // 2. 茧房检测 (可跳过)
        FilterBubbleReport bubbleReport = null;
        if (!request.getOptions().isSkipBubbleDetection()) {
            bubbleReport = bubbleDetector.detect(userId);
        }
        
        // 3. 算法选择
        DiversityReranker reranker = selectAlgorithm(config, bubbleReport);
        
        // 4. 执行重排
        List<DiversityCandidate> reranked = reranker.rerank(
            request.getCandidates(), config, bubbleReport).getRerankedList();
        
        // 5. 探索内容注入
        if (request.getOptions().isEnableExploration()) {
            UserExplorationProfile profile = profileService.getOrCreate(userId);
            reranked = explorer.injectExploration(
                reranked, profile, bubbleReport, config.getWindowSize());
        }
        
        // 6. 约束合规校验 (后置检查)
        reranked = postConstraintCheck(reranked, config);
        
        // 7. 计算指标
        DiversityMetrics beforeMetrics = metricsService.compute(request.getCandidates());
        DiversityMetrics afterMetrics = metricsService.compute(reranked);
        
        // 8. 异步更新分布快照
        CompletableFuture.runAsync(() -> 
            updateDistributionSnapshot(userId, reranked, request.getScene()));
        
        // 9. 构建响应
        return DiversityRerankResponse.builder()
            .rerankedList(reranked)
            .beforeMetrics(beforeMetrics)
            .afterMetrics(afterMetrics)
            .algorithm(reranker.getName())
            .bubbleReport(bubbleReport)
            .processingTimeMs(System.currentTimeMillis() - startTime)
            .build();
    }
    
    /**
     * 算法选择策略
     */
    private DiversityReranker selectAlgorithm(
            DiversityConfig config, 
            FilterBubbleReport bubbleReport) {
        
        String algorithm = config.getAlgorithm();
        
        if ("AUTO".equals(algorithm)) {
            // 自动选择: 茧房严重时使用约束模式，否则用MMR
            if (bubbleReport != null && bubbleReport.getOverallScore() > 65) {
                return constraintReranker;
            }
            return mmrReranker;
        }
        
        return switch (algorithm) {
            case "MMR" -> mmrReranker;
            case "CONSTRAINT" -> constraintReranker;
            default -> mmrReranker;
        };
    }
    
    /**
     * 后置约束检查: 确保硬性约束被满足
     * 如果MMR结果违反硬性约束，在相应位置插入合规内容
     */
    private List<DiversityCandidate> postConstraintCheck(
            List<DiversityCandidate> list, DiversityConfig config) {
        
        List<DiversityRule> hardRules = ruleService.getHardConstraints(
            config.getScene(), config.getStage());
        
        for (DiversityRule rule : hardRules) {
            if (!checkConstraintSatisfied(list, rule)) {
                list = repairConstraintViolation(list, rule);
            }
        }
        return list;
    }
    
    /**
     * 异步更新用户推荐分布快照
     */
    private void updateDistributionSnapshot(
            Long userId, List<DiversityCandidate> items, String scene) {
        try {
            LocalDate today = LocalDate.now();
            
            UserRecommendationDistribution snapshot = 
                snapshotRepo.findByUserDateScene(userId, today, scene)
                    .orElse(new UserRecommendationDistribution(userId, today, scene));
            
            // 累加今天的推荐分布
            for (DiversityCandidate item : items) {
                snapshot.addSubject(item.getSubject());
                snapshot.addKnowledgePoints(item.getKnowledgePoints());
                snapshot.addQuestionType(item.getQuestionType());
                snapshot.addDifficulty(item.getDifficultyLevel());
                snapshot.incrementTotal();
            }
            
            // 重新计算茧房评分
            double newScore = bubbleDetector.computeQuickScore(snapshot);
            snapshot.setBubbleScore(BigDecimal.valueOf(newScore));
            
            snapshotRepo.save(snapshot);
        } catch (Exception e) {
            log.warn("更新分布快照失败 userId={}", userId, e);
        }
    }
}
```

```java
@Service
public class ExplorationFeedbackHandler {
    
    /**
     * 处理用户对探索内容的反馈
     */
    public void handleFeedback(ExplorationFeedbackEvent event) {
        Long userId = event.getUserId();
        Long contentId = event.getContentId();
        
        // 判断是否为探索内容
        ExplorationPoolEntry entry = explorationPoolService.getEntry(contentId);
        if (entry == null || !entry.isExplorationTag()) return;
        
        // 更新探索池统计
        explorationPoolService.incrementExposure(contentId);
        
        switch (event.getAction()) {
            case VIEWED, STARTED -> {
                explorationPoolService.incrementEngagement(contentId);
            }
            case COMPLETED, RATED_POSITIVE -> {
                explorationPoolService.incrementPositive(contentId);
                updateUserExplorationSuccess(userId, true);
            }
            case SKIPPED, RATED_NEGATIVE -> {
                explorationPoolService.incrementSkip(contentId);
                updateUserExplorationSuccess(userId, false);
            }
        }
        
        // 更新用户探索画像
        UserExplorationProfile profile = profileService.getOrCreate(userId);
        profile.recordExploration(entry.getExplorationTag(), event.getAction());
        
        // 如果连续5次探索内容被跳过，降低探索频率
        if (profile.getConsecutiveSkips() >= 5) {
            profileService.adjustEpsilon(userId, profile.getEpsilon() * 0.8);
            log.info("用户{}连续跳过探索内容，降低ε至{}", userId, profile.getEpsilon() * 0.8);
        }
        
        // 如果探索内容获得正面反馈，扩大相关探索方向
        if (event.getAction() == Action.COMPLETED) {
            profileService.expandCuriosityDimension(userId, entry.getExplorationTag());
        }
        
        profileService.save(profile);
    }
    
    private void updateUserExplorationSuccess(Long userId, boolean success) {
        profileService.updateSuccessRate(userId, success);
    }
```

## 8. 多样性指标体系

### 8.1 核心指标定义

| 指标 | 计算方式 | 含义 | 目标方向 |
|------|----------|------|----------|
| **ILS (Intra-List Similarity)** | 列表内所有候选项对相似度的平均值 | 推荐列表内部相似度，越低越多样 | ↓ 越低越好 |
| **Shannon Entropy** | -Σ p(i) * ln(p(i)) | 分布的不确定性，越高越均匀 | ↑ 越高越好 |
| **Coverage** | 推荐涉及的唯一维度值 / 全量维度值 | 推荐内容覆盖了多少比例的可推荐空间 | ↑ 越高越好 |
| **Subject Spread** | 推荐中不同学科数量 | 最直接的学科多样性度量 | ≥ 3 (10条中) |
| **Difficulty Spread** | 推荐难度的标准差 | 难度的跨度，避免全在舒适区 | 0.5~0.7 |
| **Exploration Ratio** | 探索内容占推荐总量的比例 | 探索-利用平衡的直观体现 | 8%~15% |
| **Bubble Score** | 多维度加权茧房评分 | 用户整体茧房风险 | < 50 |
| **Novelty** | 推荐内容平均新颖度 | 用户接触到新内容的程度 | > 0.4 |

### 8.2 指标聚合计算

```java
/**
 * 多样性指标计算器
 */
@Component
public class DiversityMetricsCalculator {
    
    public DiversityMetrics compute(List<DiversityCandidate> list) {
        if (list.isEmpty()) return DiversityMetrics.empty();
        
        return DiversityMetrics.builder()
            .ilsScore(computeILS(list))
            .entropy(computeEntropy(list))
            .coverage(computeCoverage(list))
            .uniqueSubjects(countUnique(list, DiversityCandidate::getSubject))
            .uniqueKnowledgePoints(countUniqueKPs(list))
            .uniqueQuestionTypes(countUnique(list, DiversityCandidate::getQuestionType))
            .difficultySpread(computeDifficultySpread(list))
            .novelty(computeAvgNovelty(list))
            .build();
    }
    
    /**
     * ILS: 列表内平均相似度
     */
    private double computeILS(List<DiversityCandidate> list) {
        int n = list.size();
        if (n < 2) return 0;
        
        double totalSim = 0;
        int pairs = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                totalSim += pairSimilarity(list.get(i), list.get(j));
                pairs++;
            }
        }
        return pairs > 0 ? totalSim / pairs : 0;
    }
    
    /**
     * Shannon 熵 (基于学科分布)
     */
    private double computeEntropy(List<DiversityCandidate> list) {
        Map<String, Long> subjectCounts = list.stream()
            .collect(Collectors.groupingBy(
                DiversityCandidate::getSubject, Collectors.counting()));
        
        int total = list.size();
        return subjectCounts.values().stream()
            .mapToLong(c -> c)
            .mapToDouble(c -> {
                double p = c / (double) total;
                return -p * Math.log(p);
            })
            .sum();
    }
    
    /**
     * 覆盖率: 推荐涉及的知识点数 / 用户未掌握知识点总数
     */
    private double computeCoverage(List<DiversityCandidate> list) {
        Set<Long> recommendedKPs = list.stream()
            .flatMap(c -> c.getKnowledgePoints().stream())
            .collect(Collectors.toSet());
        
        int totalUnmasteredKPs = knowledgeService.countUnmasteredKPs(
            list.get(0).getUserId());
        
        return totalUnmasteredKPs > 0 ? 
            (double) recommendedKPs.size() / totalUnmasteredKPs : 0;
    }
}
```

### 9.1 异常场景与处理

| 异常场景 | 影响 | 处理策略 | 降级方案 |

| 分布快照写入失败 | 茧房数据不更新 | 记录日志，不阻塞推荐 | 下次补偿更新 |
| 配置中心不可达 | 无法加载规则 | 使用本地缓存的最近配置 | 默认基础规则 |

```java
/**
 * 性能优化: 相似度矩阵缓存
 */
@Component
public class SimilarityMatrixCache {
    
    @Autowired private RedisTemplate<String, Object> redis;
    
    private static final String CACHE_KEY = "diversity:sim_matrix:";
    private static final Duration TTL = Duration.ofMinutes(30);
    
    /**
     * 批量获取候选项的相似度向量
     * 利用内容ID的哈希做缓存键
     */
    public double[][] getOrCompute(List<DiversityCandidate> candidates) {
        String cacheKey = buildCacheKey(candidates);
        
        // 尝试命中缓存
        double[][] cached = (double[][]) redis.opsForValue().get(cacheKey);
        if (cached != null) return cached;
        
        // 计算
        double[][] matrix = computeMatrix(candidates);
        
        // 仅缓存中小规模矩阵
        if (candidates.size() <= 200) {
            redis.opsForValue().set(cacheKey, matrix, TTL);
        }
        return matrix;
    }
    
    private String buildCacheKey(List<DiversityCandidate> candidates) {
        // 用候选集合的指纹做key
        String fingerprint = candidates.stream()
            .map(c -> c.getContentId().toString())
            .sorted()
            .collect(Collectors.joining(","));
        return CACHE_KEY + DigestUtils.md5Hex(fingerprint);
    }
}
```

### 12.2 接入示例（调用方改动）

```java
// 改造前: 首页推荐直接返回
public List<RecommendationItem> recommendHomepage(Long userId) {
    List<Candidate> candidates = multiChannelRecall(userId);
    List<Candidate> ranked = rankByRelevance(candidates, userId);
    return ranked.stream().limit(20).map(this::toItem).collect(toList());
}

// 改造后: 接入多样性引擎
public List<RecommendationItem> recommendHomepage(Long userId) {
    List<Candidate> candidates = multiChannelRecall(userId);
    List<Candidate> ranked = rankByRelevance(candidates, userId);
    
    // 调用多样性重排
    DiversityRerankRequest request = DiversityRerankRequest.builder()
        .userId(userId)
        .scene("HOMEPAGE")
        .candidates(toDiversityCandidates(ranked))
        .context(getUserContext(userId))
        .options(DiversityRerankOptions.auto())
        .build();
    
    DiversityRerankResponse response = diversityEngineClient.rerank(request);
    
    // 降级处理
    if (response.isDegraded()) {
        log.info("多样性引擎降级，使用原始排序 userId={}", userId);
        return ranked.stream().limit(20).map(this::toItem).collect(toList());
    }
    
    return response.getRerankedList().stream()
        .limit(20)
        .map(this::toItem)
        .collect(toList());
}
```

## 15. 安全与合规

### 15.1 数据安全

- 用户推荐分布数据属于用户行为数据，遵循与学习记录同级别的隐私保护策略。
- 分布快照中不存储具体内容，仅存储聚合统计分布，无可逆风险。
- 探索画像中的偏好数据加密存储，不向第三方暴露。

### 15.2 未成年人保护

- 多样性策略的**首要目标是教育公平性**，确保学生不会因为算法偏见而得不到全学科覆盖。
- 茧房告警在家长端可见（脱敏后），帮助家长了解孩子学习广度。
- 探索内容必须经过与正常推荐相同的内容安全审核和适龄性过滤。

### 16.3 FAQ

**Q1: 多样性重排会不会降低推荐准确性？**

A: 短期来看，ILS降低通常伴随CTR微降（<5%）。但长期来看，多样性推荐能提升用户留存和学习效果，因为学生接触到更全面的知识。建议通过A/B实验验证后全量发布。

**Q2: 茧房检测需要多少数据才准确？**

A: 最少需要20条推荐消费记录（约2-3天正常使用）。数据不足时使用默认配置，不触发干预。

**Q3: 探索内容会不会让用户觉得推荐不相关？**

A: 探索比例控制在5%~15%之间，且探索内容仍需通过基础质量过滤。通过ε-greedy动态调整，对探索接受度低的用户会自动降低探索频率。

**Q4: 如何平衡"分步提示"策略与多样性？**

A: 多样性引擎作用于内容选择层，答案管控与渐进式提示属于展示层，两者正交。同一条推荐内容在展示时仍遵循渐进式提示逻辑。

**Q5: 是否考虑过 DPP 算法？**

A: DPP (Determinantal Point Process) 在理论上有更优的多样性保障，但计算复杂度 O(N³) 远高于 MMR 的 O(N²)。对于实时推荐场景，MMR 的性价比更高。DPP 可作为离线批量推荐的选项，留作后续迭代。
