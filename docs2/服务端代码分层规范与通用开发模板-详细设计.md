# 服务端代码分层规范与通用开发模板 - 详细设计

> 版本: v1.0 | 更新日期: 2026-05-24 | 状态: 初稿
> 原始需求来源：`docs/design/启硕-PrimeTop-全学段AI辅助学习软件项目设计文档.md` §8.4

## 1. 模块概述

### 1.1 定位

本文档定义 PrimeTop 服务端（FastAPI + Python）的统一代码分层规范、目录结构、命名约定、基类模板和通用开发模式。目标是让所有后端开发者遵循一致的代码组织方式，降低协作摩擦，确保新模块可以快速搭建、易于维护。

**本文档解决的核心问题：**
- 新模块应该怎么建目录、怎么分层？
- Router / Service / Repository / Schema / Model 之间的职责边界是什么？
- 通用能力（分页、排序、过滤、异常、日志、事务）怎么复用？
- 一个标准的 CRUD API 从编码到测试的完整模板是什么？

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 统一分层 | 所有模块遵循 Router → Service → Repository → Model 四层架构 |
| 接口先行 | 先定义 Schema（请求/响应模型），再实现逻辑 |
| 约定大于配置 | 目录名、文件名、类名遵循统一命名规则，减少决策成本 |
| 基类复用 | 通用能力封装为基类 / 工具函数，避免每处重复实现 |
| 可测试性 | 业务逻辑与外部依赖解耦，便于 Mock 和单元测试 |

### 1.3 适用范围

- 技术栈：Python 3.11+ / FastAPI 0.100+ / SQLAlchemy 2.0+ / Pydantic V2
- 架构模式：模块化单体（Modular Monolith），各模块按相同规范组织
- 数据库：MySQL 8.0+（主库）、Redis 7.x（缓存）

## 3. 各层职责与交互规范

### 3.1 分层架构图

```
┌─────────────────────────────────────────────┐
│              Router (路由层)                   │
│  - HTTP 方法 & URL 映射                       │
│  - 请求参数解析 (Path/Query/Body)             │
│  - Pydantic 校验 & 序列化                     │
│  - 调用 Service，返回统一响应                  │
├─────────────────────────────────────────────┤
│              Service (业务逻辑层)              │
│  - 业务规则校验 & 编排                         │
│  - 事务管理 (@transactional)                  │
│  - 跨模块调用（通过 Service 接口）              │
│  - 事件发布（event_bus.publish）              │
│  - 缓存策略（读缓/写穿）                       │
├─────────────────────────────────────────────┤
│              Repository (数据访问层)           │
│  - SQLAlchemy 查询构建                        │
│  - CRUD 操作封装                              │
│  - 过滤/排序/分页查询                          │
│  - 不包含业务逻辑                              │
├─────────────────────────────────────────────┤
│              Model (数据模型层)                │
│  - SQLAlchemy ORM 映射                        │
│  - 表结构、索引、约束定义                       │
│  - 不包含业务方法                              │
└─────────────────────────────────────────────┘
```

### 3.2 层间交互规则

| 规则 | 说明 |
|------|------|
| Router 不直接操作数据库 | Router 只调用 Service，不注入 Session |
| Service 不感知 HTTP | Service 方法接收/返回纯 Python 对象（Schema 或 dict），不依赖 Request/Response |
| Repository 只做查询 | 不包含业务判断（如"如果已存在则抛异常"），由 Service 决定 |
| Model 只做映射 | 不包含业务方法，只定义字段和表结构 |
| 禁止跨层调用 | Router 不可跳过 Service 直接调用 Repository |
| Service 间可调用 | 通过依赖注入获取其他模块 Service，不直接导入 Repository |

## 4. 基类定义

### 4.1 SQLAlchemy 基类 (`app/common/base_model.py`)

```python
"""
所有 ORM 模型的基类，提供公共字段和通用方法。
"""
from datetime import datetime
from typing import Any

from sqlalchemy import BigInteger, DateTime, SmallInteger, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, as_declarative


class Base(DeclarativeBase):
    """SQLAlchemy 声明式基类"""
    pass


class TimestampMixin:
    """时间戳混入：所有表必须包含 created_at 和 updated_at"""
    created_at: Mapped[datetime] = mapped_column(
        DateTime,
        nullable=False,
        server_default=func.now(),
        comment="创建时间",
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime,
        nullable=False,
        server_default=func.now(),
        onupdate=func.now(),
        comment="更新时间",
    )


class SoftDeleteMixin:
    """软删除混入：通过 status 字段标记删除"""
    status: Mapped[int] = mapped_column(
        SmallInteger,
        nullable=False,
        default=1,
        comment="状态: 0=禁用/删除, 1=正常",
    )


class BaseModel(Base, TimestampMixin, SoftDeleteMixin):
    """
    通用模型基类。
    所有业务表继承此类，自动获得 id、created_at、updated_at、status 字段。
    """
    __abstract__ = True

    id: Mapped[int] = mapped_column(
        BigInteger,
        primary_key=True,
        autoincrement=True,
        comment="主键ID",
    )

    def to_dict(self) -> dict[str, Any]:
        """转换为字典（用于简单的序列化场景）"""
        return {
            c.name: getattr(self, c.name)
            for c in self.__table__.columns
        }
```

### 4.2 Pydantic 基类 (`app/common/base_schema.py`)

```python
"""
Pydantic Schema 基类，提供通用字段和配置。
"""
from datetime import datetime
from typing import Optional, Generic, TypeVar, Any

from pydantic import BaseModel, ConfigDict, Field


T = TypeVar("T")


class OrmBaseSchema(BaseModel):
    """ORM 模式基类：所有从 ORM 对象转换的 Schema 继承此类"""
    model_config = ConfigDict(from_attributes=True)


class IdSchema(OrmBaseSchema):
    """带 ID 的基础响应"""
    id: int = Field(..., description="主键ID")


class TimestampSchema(OrmBaseSchema):
    """带时间戳的响应"""
    created_at: datetime = Field(..., description="创建时间")
    updated_at: datetime = Field(..., description="更新时间")


class PageRequest(BaseModel):
    """分页请求基类"""
    page: int = Field(1, ge=1, description="页码，从 1 开始")
    page_size: int = Field(20, ge=1, le=100, description="每页条数，最大 100")


class PageResponse(BaseModel, Generic[T]):
    """分页响应泛型模型"""
    items: list[T] = Field(..., description="数据列表")
    total: int = Field(..., description="总记录数")
    page: int = Field(..., description="当前页码")
    page_size: int = Field(..., description="每页条数")
    total_pages: int = Field(..., description="总页数")

    @classmethod
    def create(
        cls, items: list[Any], total: int, page: int, page_size: int
    ) -> "PageResponse":
        total_pages = (total + page_size - 1) // page_size
        return cls(
            items=items,
            total=total,
            page=page,
            page_size=page_size,
            total_pages=total_pages,
        )
```

### 4.3 泛型 Repository 基类 (`app/common/base_repository.py`)

```python
"""
泛型 Repository 基类，提供标准 CRUD 操作模板。
子类可通过继承获得通用能力，也可覆写特定方法。
"""
from typing import TypeVar, Generic, Type, Optional, Sequence

from sqlalchemy import Select, func, select
from sqlalchemy.orm import Session

from app.common.base_model import BaseModel
from app.common.base_schema import PageRequest, PageResponse

ModelType = TypeVar("ModelType", bound=BaseModel)


class BaseRepository(Generic[ModelType]):
    """
    泛型 Repository 基类。

    用法:
        class UserRepository(BaseRepository[User]):
            pass

        repo = UserRepository(db_session)
        user = repo.get_by_id(1)
        users = repo.list_page(PageRequest(page=1, page_size=10))
    """

    def __init__(self, model: Type[ModelType], db: Session):
        self.model = model
        self.db = db

    def get_by_id(self, id: int) -> Optional[ModelType]:
        """根据 ID 查询单条记录（仅 status=1）"""
        return self.db.execute(
            select(self.model).where(
                self.model.id == id,
                self.model.status == 1,
            )
        ).scalar_one_or_none()

    def get_by_id_strict(self, id: int) -> ModelType:
        """根据 ID 查询，不存在则抛 404"""
        obj = self.get_by_id(id)
        if obj is None:
            from app.core.exceptions import NotFoundException
            raise NotFoundException(f"{self.model.__name__}(id={id}) 不存在")
        return obj

    def list_all(self) -> Sequence[ModelType]:
        """查询所有有效记录"""
        result = self.db.execute(
            select(self.model).where(self.model.status == 1)
        )
        return result.scalars().all()

    def list_page(
        self,
        page_req: PageRequest,
        filters: Optional[list] = None,
        order_by: Optional[list] = None,
    ) -> PageResponse:
        """
        分页查询。

        Args:
            page_req: 分页参数
            filters: SQLAlchemy where 条件列表
            order_by: 排序条件列表

        Returns:
            PageResponse 包含分页信息和数据
        """
        # 构建基础查询
        stmt = select(self.model).where(self.model.status == 1)

        # 应用过滤条件
        if filters:
            for condition in filters:
                stmt = stmt.where(condition)

        # 计算总数
        count_stmt = select(func.count()).select_from(stmt.subquery())
        total = self.db.execute(count_stmt).scalar_one()

        # 应用排序
        if order_by:
            for col in order_by:
                stmt = stmt.order_by(col)
        else:
            stmt = stmt.order_by(self.model.id.desc())

        # 应用分页
        offset = (page_req.page - 1) * page_req.page_size
        stmt = stmt.offset(offset).limit(page_req.page_size)

        result = self.db.execute(stmt)
        items = result.scalars().all()

        return PageResponse.create(
            items=items,
            total=total,
            page=page_req.page,
            page_size=page_req.page_size,
        )

    def create(self, obj: ModelType) -> ModelType:
        """创建记录"""
        self.db.add(obj)
        self.db.flush()
        return obj

    def update(self, obj: ModelType, **kwargs) -> ModelType:
        """更新指定字段"""
        for key, value in kwargs.items():
            if hasattr(obj, key):
                setattr(obj, key, value)
        self.db.flush()
        return obj

    def soft_delete(self, id: int) -> bool:
        """软删除（status → 0）"""
        obj = self.get_by_id(id)
        if obj is None:
            return False
        obj.status = 0
        self.db.flush()
        return True
```

## 5. 统一响应格式

### 5.1 响应构建器 (`app/common/response.py`)

```python
"""
统一 API 响应构建器。
所有 Router 必须通过此构建器返回响应，确保前端收到的格式一致。
"""
from typing import Any, Optional, Generic, TypeVar

from pydantic import BaseModel, Field


T = TypeVar("T")


class ApiResponse(BaseModel, Generic[T]):
    """统一响应模型"""
    code: int = Field(0, description="业务码，0=成功")
    message: str = Field("success", description="提示信息")
    data: Optional[T] = Field(None, description="业务数据")


def ok(data: Any = None, message: str = "success") -> dict:
    """成功响应"""
    return {"code": 0, "message": message, "data": data}


def created(data: Any = None, message: str = "创建成功") -> dict:
    """资源创建成功"""
    return {"code": 0, "message": message, "data": data}


def paginated(page_resp: Any) -> dict:
    """分页响应"""
    return {"code": 0, "message": "success", "data": page_resp}
```

## 6. 异常处理规范

### 6.1 自定义异常类 (`app/core/exceptions.py`)

```python
"""
统一异常体系。
所有业务异常必须使用以下异常类，由全局异常处理器统一转换为 API 响应。
"""
from typing import Any, Optional


class BaseAppException(Exception):
    """应用异常基类"""
    def __init__(
        self,
        message: str = "服务内部错误",
        code: int = 500,
        http_status: int = 500,
        data: Any = None,
    ):
        self.message = message
        self.code = code
        self.http_status = http_status
        self.data = data
        super().__init__(message)


class NotFoundException(BaseAppException):
    """资源不存在 (404)"""
    def __init__(self, message: str = "资源不存在"):
        super().__init__(message=message, code=40400, http_status=404)


class BadRequestException(BaseAppException):
    """请求参数错误 (400)"""
    def __init__(self, message: str = "请求参数错误"):
        super().__init__(message=message, code=40000, http_status=400)


class UnauthorizedException(BaseAppException):
    """未认证 (401)"""
    def __init__(self, message: str = "请先登录"):
        super().__init__(message=message, code=40100, http_status=401)


class ForbiddenException(BaseAppException):
    """无权限 (403)"""
    def __init__(self, message: str = "无访问权限"):
        super().__init__(message=message, code=40300, http_status=403)


class BusinessRuleException(BaseAppException):
    """业务规则冲突 (409)"""
    def __init__(self, message: str = "操作冲突"):
        super().__init__(message=message, code=40900, http_status=409)


class RateLimitException(BaseAppException):
    """频率限制 (429)"""
    def __init__(self, message: str = "操作过于频繁，请稍后重试"):
        super().__init__(message=message, code=42900, http_status=429)
```

```python
            status_code=422,
            content={
                "code": 42200,
                "message": "请求参数校验失败",
                "data": {"errors": errors},
            },
        )

        logger.exception(f"未处理异常: {exc}")
```

### 7.1 排序参数解析 (`app/common/sorting.py`)

```python
"""
统一排序参数解析器。
前端传入 sort_by=created_at&sort_order=desc 格式的排序参数，
后端解析为 SQLAlchemy order_by 表达式。
"""
from enum import Enum
from typing import Optional, Type

from fastapi import Query
from pydantic import BaseModel
from sqlalchemy import Column, asc, desc

from app.common.base_model import BaseModel as AppBaseModel


class SortOrder(str, Enum):
    asc = "asc"
    desc = "desc"


class SortParams(BaseModel):
    """排序参数"""
    sort_by: str = "id"
    sort_order: SortOrder = SortOrder.desc

    def to_order_by(self, model: Type[AppBaseModel]):
        """将排序参数转换为 SQLAlchemy 排序表达式"""
        if not hasattr(model, self.sort_by):
            raise ValueError(f"不支持排序字段: {self.sort_by}")
        col: Column = getattr(model, self.sort_by)
        return desc(col) if self.sort_order == SortOrder.desc else asc(col)


def SortQuery(
    sort_by: str = Query("id", description="排序字段"),
    sort_order: SortOrder = Query(SortOrder.desc, description="排序方向: asc/desc"),
) -> SortParams:
    """FastAPI 依赖注入：排序参数"""
    return SortParams(sort_by=sort_by, sort_order=sort_order)
```

### 7.2 过滤条件构建 (`app/common/filtering.py`)

```python
"""
通用过滤条件构建器。
支持精确匹配、范围查询、IN 查询等常见过滤模式。
"""
from typing import Optional, Any

from sqlalchemy import Column, and_, in_


class FilterBuilder:
    """
    过滤条件构建器，链式调用构建复杂 WHERE 条件。

    用法:
        filters = (
            FilterBuilder(MistakeRecord)
            .eq("subject", "数学")
            .gte("created_at", start_date)
            .in_("error_type", ["计算失误", "概念不清"])
            .build()
        )
    """

    def __init__(self, model):
        self.model = model
        self._conditions = []

    def eq(self, field: str, value: Any) -> "FilterBuilder":
        """精确匹配"""
        if value is not None:
            self._conditions.append(getattr(self.model, field) == value)
        return self

    def ne(self, field: str, value: Any) -> "FilterBuilder":
        """不等于"""
        if value is not None:
            self._conditions.append(getattr(self.model, field) != value)
        return self

    def like(self, field: str, value: Optional[str]) -> "FilterBuilder":
        """模糊匹配（包含）"""
        if value:
            self._conditions.append(getattr(self.model, field).f"%{value}%"))
        return self

    def startswith(self, field: str, value: Optional[str]) -> "FilterBuilder":
        """前缀匹配"""
        if value:
            self._conditions.append(getattr(self.model, field).startswith(value))
        return self

    def gte(self, field: str, value: Any) -> "FilterBuilder":
        """大于等于"""
        if value is not None:
            self._conditions.append(getattr(self.model, field) >= value)
        return self

    def lte(self, field: str, value: Any) -> "FilterBuilder":
        """小于等于"""
        if value is not None:
            self._conditions.append(getattr(self.model, field) <= value)
        return self

    def in_(self, field: str, values: Optional[list]) -> "FilterBuilder":
        """IN 查询"""
        if values:
            self._conditions.append(getattr(self.model, field).in_(values))
        return self

    def build(self) -> list:
        """返回条件列表（传给 BaseRepository.list_page 的 filters 参数）"""
        return self._conditions
```

### 8.4 Service (`service.py`)

```python
"""收藏模块 Service"""
from sqlalchemy.orm import Session

from app.common.base_service import BaseService
from app.common.base_schema import PageRequest, PageResponse
from app.core.exceptions import (
    BusinessRuleException,
    NotFoundException,
    QuotaExceededException,
)
from app.event_bus.bus import event_bus
from .repository import FavoriteRepository
from .models import Favorite
from .schemas import CreateFavoriteRequest, UpdateFavoriteRequest, FavoritePageRequest


# 收藏数量上限
MAX_FAVORITES_PER_USER = 5000


class FavoriteService(BaseService[FavoriteRepository]):
    """收藏业务逻辑层"""

    def __init__(self, db: Session):
        super().__init__(FavoriteRepository(db), db)

    def add_favorite(self, user_id: int, req: CreateFavoriteRequest) -> Favorite:
        """添加收藏"""
        # 1. 检查是否已收藏
        existing = self.repo.find_by_user_and_target(
            user_id, req.target_type, req.target_id
        )
        if existing:
            raise BusinessRuleException("已收藏该内容")

        # 2. 检查收藏数量上限
        count_result = self.repo.list_page(
            PageRequest(page=1, page_size=1),
            filters=[Favorite.user_id == user_id],
        )
        if count_result.total >= MAX_FAVORITES_PER_USER:
            raise QuotaExceededException("收藏数量已达上限")

        # 3. 创建收藏记录
        fav = Favorite(
            user_id=user_id,
            target_type=req.target_type,
            target_id=req.target_id,
            folder_id=req.folder_id,
            note=req.note,
        )
        self.repo.create(fav)
        self.db.commit()

        # 4. 发布事件
        event_bus.publish("favorite.created", {
            "user_id": user_id,
            "target_type": req.target_type,
            "target_id": req.target_id,
        })

        self.logger.info(f"用户{user_id}收藏了{req.target_type}:{req.target_id}")
        return fav

    def remove_favorite(self, user_id: int, favorite_id: int) -> bool:
        """取消收藏"""
        fav = self.repo.get_by_id_strict(favorite_id)
        if fav.user_id != user_id:
            raise ForbiddenException("无权操作他人收藏")
        self.repo.soft_delete(favorite_id)
        self.db.commit()

        event_bus.publish("favorite.removed", {
            "user_id": user_id,
            "target_type": fav.target_type,
            "target_id": fav.target_id,
        })
        return True

    def list_my_favorites(
        self, user_id: int, page_req: FavoritePageRequest
    ) -> PageResponse:
        """查询我的收藏列表"""
        return self.repo.list_user_favorites(
            user_id=user_id,
            page_req=page_req,
            target_type=page_req.target_type,
            folder_id=page_req.folder_id,
        )
```

## 13. 新模块开发检查清单

创建新业务模块时，按以下步骤执行：

```
□ 1. 在 app/modules/ 下创建模块目录
□ 2. 定义 ORM 模型 (models.py)
□ 3. 创建 Alembic 迁移脚本 (alembic revision --autogenerate -m "add xxx tables")
```

## 14. 常见错误与纠正

| 错误做法 | 正确做法 | 原因 |
|---------|---------|------|
| Router 里写业务逻辑 | Router 只做参数解析和调用 Service | 保持职责单一，便于测试 |
| Service 里写 SQL 查询 | 查询逻辑放 Repository | 分离关注点，Repository 可独立测试 |
| Service 方法返回 HTTP Response | Service 返回纯数据对象 | Service 不应感知 HTTP 层 |
| 每个方法单独 try/except | 抛出 BaseAppException 子类，由全局处理器兜底 | 减少重复代码，格式统一 |
| 在 Repository 里 commit | Repository 只 flush，由 Service commit | Service 管理事务边界 |
| 用 print 调试 | 使用 structlog 记录 | 生产环境可控制、可检索 |
| 硬编码配置值 | 从 config.py 读取环境变量 | 便于环境切换和运维 |
