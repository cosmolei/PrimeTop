# 教育内容知识切片与微课智能分段生成引擎 - 详细设计

## 1. 模块概述

### 1.1 功能定位

将长篇教育内容（教材章节、讲义全文、录播课字幕、教辅文档）自动拆分为 **3-5 分钟的微课知识切片**，并为每个切片生成：

- 知识点标签与难度标注
- 前置依赖声明
- 知识检查题（checkpoint quiz）
- 切片间过渡摘要

同时支持运营教研人员对切片结果进行人工审核、调整与发布。

### 1.2 核心价值

| 痛点 | 解决方案 |
|------|----------|
| 长视频/长文档学习完成率低 | 拆分为短时微课，降低认知负荷 |
| 学生找不到"刚才看到哪" | 切片级别的断点续学，精确定位到知识点 |
| 推荐系统粒度太粗 | 以切片为最小推荐单元，实现精准内容推荐 |
| 教研生产效率低 | 自动分段 + 人工审核，大幅降低内容生产成本 |

### 1.3 在系统中的位置

```
┌─────────────────────────────────────────────────────┐
│                 内容运营后台 (Admin)                   │
│  教研人员上传原始内容 → 触发切片任务 → 审核切片 → 发布   │
└──────────────────────┬──────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────┐
│           知识切片与微课分段生成引擎 (本模块)            │
│                                                     │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐          │
│  │ 内容预处理 │→│ 智能分段  │→│ 切片标注  │          │
│  └──────────┘  └──────────┘  └──────────┘          │
│       │              │              │                │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐          │
│  │ 检查题生成 │→│ 过渡摘生成 │→│ 质量校验  │          │
│  └──────────┘  └──────────┘  └──────────┘          │
└──────────────────────┬──────────────────────────────┘
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
   ┌──────────┐ ┌──────────┐ ┌──────────┐
   │ 同步课堂   │ │ 推荐引擎   │ │ 学习路径   │
   │ (内容消费) │ │ (精准推荐) │ │ (编排素材) │
   └──────────┘ └──────────┘ └──────────┘
```

### 1.4 关键术语

| 术语 | 说明 |
|------|------|
| 原始内容 (RawContent) | 教研上传的未处理文档/视频/字幕 |
| 知识切片 (KnowledgeSlice) | 分段后的最小学习单元 |
| 切片组 (SliceGroup) | 同一原始内容下所有切片的有序集合 |
| 检查题 (CheckpointQuiz) | 切片末尾的 1-3 道快速检测题 |
| 过渡摘要 (TransitionSummary) | 连接前后切片的简短过渡语 |
| 分段策略 (SegmentationStrategy) | 根据内容类型选择的不同分段算法 |

## 2. 数据结构设计

### 2.1 PostgreSQL 表结构

#### 2.1.1 `content_slice_tasks` — 切片任务表

```sql
CREATE TABLE content_slice_tasks (
    id              BIGSERIAL PRIMARY KEY,
    task_no         VARCHAR(64) NOT NULL UNIQUE,      -- 业务任务编号 SLICE-20260616001
    raw_content_id  BIGINT NOT NULL,                   -- 原始内容ID (关联 contents 表)
    raw_content_type VARCHAR(32) NOT NULL,             -- TEXT / VIDEO / AUDIO / PDF
    strategy        VARCHAR(32) NOT NULL,              -- AUTO_SEMANTIC / MANUAL / HYBRID
    status          VARCHAR(32) NOT NULL DEFAULT 'PENDING',
    -- PENDING → PROCESSING → SLICED → REVIEWING → PUBLISHED / REJECTED
    
    -- 处理参数
    target_duration_sec  INT,                          -- 目标切片时长(秒)，视频/音频类
    target_word_count    INT,                          -- 目标切片字数，文本类
    language             VARCHAR(16) DEFAULT 'zh-CN',
    
    -- 处理结果
    total_slices    INT,                                -- 生成的切片总数
    total_duration_sec INT,                             -- 切片总时长
    quality_score   DECIMAL(3,2),                      -- 整体质量分 0.00-1.00
    
    -- 审核信息
    reviewer_id     BIGINT,
    reviewed_at     TIMESTAMPTZ,
    review_comment  TEXT,
    
    -- 元数据
    created_by      BIGINT NOT NULL,
    updated_by      BIGINT,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ
);

CREATE INDEX idx_slice_tasks_status ON content_slice_tasks(status) WHERE deleted_at IS NULL;
CREATE INDEX idx_slice_tasks_raw_content ON content_slice_tasks(raw_content_id) WHERE deleted_at IS NULL;
CREATE INDEX idx_slice_tasks_created ON content_slice_tasks(created_at DESC) WHERE deleted_at IS NULL;
```

#### 2.1.2 `content_slices` — 知识切片表

```sql
CREATE TABLE content_slices (
    id              BIGSERIAL PRIMARY KEY,
    slice_uuid      UUID NOT NULL DEFAULT gen_random_uuid(),
    task_id         BIGINT NOT NULL REFERENCES content_slice_tasks(id),
    raw_content_id  BIGINT NOT NULL,
    
    -- 顺序与层级
    sequence_no     INT NOT NULL,                      -- 切片序号 (从1开始)
    parent_slice_id BIGINT,                             -- 父切片(支持二级切分)
    
    -- 内容
    title           VARCHAR(256) NOT NULL,              -- 切片标题
    summary         VARCHAR(512),                       -- 切片摘要(一句话)
    
    -- 文本类内容
    content_text    TEXT,                               -- 切片正文(富文本/Markdown)
    word_count      INT,
    
    -- 视频/音频类内容
    media_url       VARCHAR(1024),                      -- 切片媒体文件地址
    start_time_sec  DECIMAL(10,2),                     -- 起始时间(秒) - 相对原始媒体
    end_time_sec    DECIMAL(10,2),                     -- 结束时间(秒)
    duration_sec    DECIMAL(10,2),
    transcript_text TEXT,                               -- 字幕文本
    
    -- 知识点关联
    knowledge_point_ids BIGINT[],                       -- 关联知识点ID列表
    
    -- 难度与认知层级
    difficulty_level    VARCHAR(16) DEFAULT 'MEDIUM',   -- EASY / MEDIUM / HARD
    cognitive_level     VARCHAR(32),                    -- 记忆/理解/应用/分析/评价/创造 (Bloom分类)
    grade appropriateness VARCHAR(32),                  -- 适龄学段标签
    
    -- 切片属性
    slice_type      VARCHAR(32) NOT NULL DEFAULT 'KNOWLEDGE',
    -- KNOWLEDGE(知识讲解) / EXAMPLE(例题演示) / PRACTICE(练习) / SUMMARY(总结) / INTRO(引入)
    
    is_free_preview BOOLEAN DEFAULT FALSE,              -- 是否免费试看
    requires_parent_unlock BOOLEAN DEFAULT FALSE,       -- 是否需要家长解锁
    
    -- 质量分
    quality_score   DECIMAL(3,2),
    
    -- 状态
    status          VARCHAR(32) NOT NULL DEFAULT 'DRAFT',
    -- DRAFT → PENDING_REVIEW → PUBLISHED / ARCHIVED
    
    -- 时间戳
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    published_at    TIMESTAMPTZ,
    deleted_at      TIMESTAMPTZ,
    
    UNIQUE(task_id, sequence_no)
);

-- 查询某内容的全部已发布切片(按序)
CREATE INDEX idx_slices_content_seq ON content_slices(raw_content_id, sequence_no)
    WHERE deleted_at IS NULL AND status = 'PUBLISHED';
CREATE INDEX idx_slices_kp ON content_slices USING GIN(knowledge_point_ids)
    WHERE deleted_at IS NULL;
CREATE INDEX idx_slices_task ON content_slices(task_id, sequence_no) WHERE deleted_at IS NULL;
```

#### 2.1.3 `content_slice_quizzes` — 切片检查题表

```sql
CREATE TABLE content_slice_quizzes (
    id              BIGSERIAL PRIMARY KEY,
    slice_id        BIGINT NOT NULL REFERENCES content_slices(id),
    quiz_sequence   INT NOT NULL DEFAULT 1,            -- 同一切片内的题目序号
    quiz_type       VARCHAR(32) NOT NULL,              -- SINGLE_CHOICE / MULTI_CHOICE / TRUE_FALSE / FILL_BLANK / SHORT_ANSWER
    question_text   TEXT NOT NULL,
    options         JSONB,                              -- 选项 [{key:'A', text:'...'}, ...]
    correct_answer  JSONB NOT NULL,                    -- 正确答案
    explanation     TEXT,                               -- 答案解析
    knowledge_point_id BIGINT,                          -- 关联知识点
    
    -- 难度
    difficulty_level VARCHAR(16) DEFAULT 'MEDIUM',
    
    -- 质量与使用统计
    pass_rate       DECIMAL(3,2),                      -- 通过率(异步更新)
    attempt_count   INT DEFAULT 0,
    
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ,
    
    UNIQUE(slice_id, quiz_sequence)
);

CREATE INDEX idx_quizzes_slice ON content_slice_quizzes(slice_id) WHERE deleted_at IS NULL;
```

#### 2.1.4 `content_slice_transitions` — 切片过渡摘要表

```sql
CREATE TABLE content_slice_transitions (
    id                  BIGSERIAL PRIMARY KEY,
    from_slice_id       BIGINT NOT NULL REFERENCES content_slices(id),
    to_slice_id         BIGINT NOT NULL REFERENCES content_slices(id),
    transition_text     VARCHAR(512) NOT NULL,         -- 过渡语
    transition_type     VARCHAR(32) NOT NULL DEFAULT 'BRIDGE',
    -- BRIDGE(桥接) / RECAP(回顾) / PREVIEW(预告) / MOTIVATION(激励)
    
    created_at          TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    UNIQUE(from_slice_id, to_slice_id)
);
```

#### 2.1.5 `content_slice_learning_records` — 切片学习记录表

```sql
CREATE TABLE content_slice_learning_records (
    id              BIGSERIAL PRIMARY KEY,
    user_id         BIGINT NOT NULL,
    slice_id        BIGINT NOT NULL REFERENCES content_slices(id),
    raw_content_id  BIGINT NOT NULL,
    
    -- 学习状态
    status          VARCHAR(32) NOT NULL DEFAULT 'STARTED',
    -- STARTED → IN_PROGRESS → COMPLETED → SKIPPED → REPLAYED
    
    -- 进度数据
    progress_pct    DECIMAL(5,2) DEFAULT 0,            -- 完成百分比 0-100
    last_position_sec DECIMAL(10,2),                   -- 视频/音频最后播放位置
    time_spent_sec  INT DEFAULT 0,                     -- 累计学习时长(秒)
    replay_count    INT DEFAULT 0,
    
    -- 检查题结果
    quiz_passed     BOOLEAN,
    quiz_score      DECIMAL(3,2),                      -- 0.00-1.00
    quiz_attempts   INT DEFAULT 0,
    
    -- 评价
    user_rating     SMALLINT,                          -- 1-5 星
    feedback_tag    VARCHAR(32),                       -- TOO_FAST / TOO_SLOW / UNCLEAR / GREAT / HELPFUL
    
    -- 时间戳
    started_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    completed_at    TIMESTAMPTZ,
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    
    UNIQUE(user_id, slice_id)
);

-- 查询用户在某内容下的切片进度
CREATE INDEX idx_learning_user_content ON content_slice_learning_records(user_id, raw_content_id);
-- 查询用户最近学习的切片
CREATE INDEX idx_learning_user_recent ON content_slice_learning_records(user_id, started_at DESC);
```

### 2.2 Redis 缓存结构

```
# 切片任务处理状态
slice:task:status:{taskId}  → Hash { phase, progress, currentStep, totalSteps, errorMsg }
TTL: 24h

# 已发布切片列表缓存(按原始内容)
slice:list:{rawContentId}  → String (JSON array of slice summaries)
TTL: 1h (content change时主动失效)

# 切片详情缓存
slice:detail:{sliceUuid}  → String (JSON slice detail)
TTL: 30min

# 用户切片学习进度缓存
slice:progress:{userId}:{rawContentId}  → Hash { currentSliceSeq, completedCount, totalCount, lastSliceUuid }
TTL: 7d

# 热门切片(用于推荐)
slice:hot:{subject}:{grade}  → ZSET sliceUuid → score
TTL: 6h, updated by scheduled job

# 切片质量分排队(待审核)
slice:review:queue  → LIST taskId (FIFO)
```

```
Authorization: Bearer {admin_token}

Request:

  "rawContentId": 10086,
  "rawContentType": "VIDEO",          // TEXT / VIDEO / AUDIO / PDF
  "strategy": "AUTO_SEMANTIC",        // AUTO_SEMANTIC / MANUAL / HYBRID
  "config": {
    "targetDurationSec": 240,         // 目标切片时长(视频/音频)，null=自动
    "targetWordCount": null,          // 目标切片字数(文本)，null=自动
```

## 4. 核心处理流程

### 4.1 切片任务处理全流程（状态机）

```
┌─────────┐     ┌────────────┐     ┌──────────┐     ┌───────────┐
│ PENDING │────▶│ PROCESSING │────▶│ SLICED   │────▶│ REVIEWING │
└─────────┘     └─────┬──────┘     └──────────┘     └─────┬─────┘
                      │                                   │
                      │ 失败/超时                         │
                      ▼                                   ├──────────┐
                ┌──────────┐                              ▼          ▼
                │  FAILED  │                     ┌───────────┐ ┌──────────┐
                └──────────┘                     │ PUBLISHED │ │ REJECTED │
                                                 └───────────┘ └──────────┘
```

### 4.2 PROCESSING 阶段内部流程

```
PROCESSING 内部阶段:

Step 1: PREPROCESS     — 内容预处理 (提取文本/字幕/结构)
Step 2: ANALYZE        — AI 内容分析 (识别主题/知识点/难度)
Step 3: SEGMENT        — 智能分段 (核心切分逻辑)
Step 4: ENRICH         — 切片标注 (知识点/难度/认知层级)
Step 5: QUIZ_GENERATE  — 检查题生成
Step 6: TRANSITION     — 过渡摘要生成
Step 7: QUALITY_CHECK  — 质量校验与评分
```

### 4.3 智能分段算法详解 (Step 3: SEGMENT)

#### 4.3.1 文本内容分段

```python
# pseudo code

def segment_text_content(raw_text: str, knowledge_points: list, config: dict) -> list[Slice]:
    """
    文本内容语义分段算法
    基于: 段落边界检测 + 主题切换检测 + 知识点边界 + 长度约束
    """
    # Step A: 预处理 — 清洗、段落识别
    paragraphs = split_into_paragraphs(raw_text)
    
    # Step B: 为每段生成语义向量
    embeddings = [embedding_model.encode(p.text) for p in paragraphs]
    
    # Step C: 计算相邻段落语义相似度
    similarities = [cosine_similarity(embeddings[i], embeddings[i+1]) 
                    for i in range(len(embeddings)-1)]
    
    # Step D: 检测语义断点 (相似度低于阈值的位置)
    threshold = config.get('semantic_threshold', 0.65)
    breakpoints = [i+1 for i, sim in enumerate(similarities) if sim < threshold]
    
    # Step E: 结合标题/小标题结构修正断点
    heading_positions = find_heading_positions(paragraphs)
    breakpoints = merge_close_breakpoints(breakpoints, heading_positions, min_gap=3)
    
    # Step F: 应用长度约束 (太短合并，太长再拆)
    target_words = config.get('target_word_count', 800)  # 默认目标字数
    min_words = target_words * 0.5
    max_words = target_words * 1.5
    
    segments = group_paragraphs(paragraphs, breakpoints, min_words, max_words)
    
    # Step G: AI 辅助 — 对每个segment生成标题和摘要
    for segment in segments:
        segment.title = ai_generate_title(segment.text)
        segment.summary = ai_generate_summary(segment.text, max_chars=80)
    
    # Step H: 知识点匹配
    for segment in segments:
        segment.knowledge_point_ids = match_knowledge_points(
            segment.text, knowledge_points
        )
    
    return segments
```

#### 4.3.2 视频/音频内容分段

```python
def segment_media_content(
    media_url: str, 
    transcript: str, 
    config: dict
) -> list[MediaSlice]:
    """
    媒体内容分段算法
    基于: 字幕语义分段 + 场景切换检测 + 语音停顿检测 + 时长约束
    """
    target_duration = config.get('target_duration_sec', 240)  # 默认4分钟
    min_duration = target_duration * 0.5  # 最短2分钟
    max_duration = target_duration * 1.5  # 最长6分钟
    
    # Step A: 获取字幕(如有), 按句切分带时间戳
    if transcript:
        sentences = parse_subtitle_with_timestamps(transcript)
    else:
        # 无字幕 → ASR 转写
        sentences = asr_transcribe_with_timestamps(media_url)
    
    # Step B: 语义分段(同文本算法)
    text_segments = segment_text_by_semantic(
        [s.text for s in sentences],
        threshold=0.65
    )
    
    # Step C: 将文本段映射回时间区间
    time_segments = []
    for seg in text_segments:
        start_sentence = sentences[seg.start_idx]
        end_sentence = sentences[seg.end_idx]
        time_segments.append(TimeSegment(
            start_sec=start_sentence.start_sec,
            end_sec=end_sentence.end_sec,
            text=seg.text
        ))
    
    # Step D: 检测场景切换点 (视频类额外处理)
    if is_video(media_url):
        scene_changes = detect_scene_changes(media_url)  # 使用OpenCV等
        time_segments = align_with_scene_changes(
            time_segments, scene_changes, tolerance_sec=5.0
        )
    
    # Step E: 应用时长约束
    final_segments = adjust_by_duration(
        time_segments, min_duration, max_duration, target_duration
    )
    
    # Step F: 检测语音停顿，在自然停顿处微调切分点
    pause_points = detect_speech_pauses(media_url, min_pause_sec=0.8)
    final_segments = snap_to_pauses(final_segments, pause_points, tolerance_sec=3.0)
    
    # Step G: 物理切割媒体文件
    for seg in final_segments:
        seg.media_clip_url = ffmpeg_cut_media(
            media_url, seg.start_sec, seg.end_sec,
            output_format='mp4'
        )
    
    return final_segments
```

### 4.5 质量校验 (Step 7: QUALITY_CHECK)

```python
def quality_check_slice(slice_obj: Slice) -> SliceQualityReport:
    """
    对每个切片进行质量检查
    返回评分和问题列表
    """
    issues = []
    score = 1.0
    
    # 1. 时长/字数检查
    if slice_obj.duration_sec:
        if slice_obj.duration_sec < 60:
            issues.append({'type': 'TOO_SHORT', 'detail': '切片不足1分钟'})
            score -= 0.2
        elif slice_obj.duration_sec > 600:
            issues.append({'type': 'TOO_LONG', 'detail': '切片超过10分钟'})
            score -= 0.1
    
    # 2. 知识点覆盖检查
    if not slice_obj.knowledge_point_ids:
        issues.append({'type': 'NO_KP_LINKED', 'detail': '未关联任何知识点'})
        score -= 0.15
    
    # 3. 标题与内容一致性
    title_content_sim = compute_similarity(
        slice_obj.title, slice_obj.content_text[:200]
    )
    if title_content_sim < 0.3:
        issues.append({'type': 'TITLE_MISMATCH', 'detail': '标题与内容关联度低'})
        score -= 0.1
    
    # 4. 检查题质量
    if slice_obj.quizzes:
        for quiz in slice_obj.quizzes:
            # 验证答案唯一性
            if not has_unique_correct_answer(quiz):
                issues.append({'type': 'QUIZ_AMBIGUOUS', 'detail': f'题目答案不明确: {quiz.question_text[:30]}'})
                score -= 0.1
            # 验证干扰项质量
            if not has_reasonable_distractors(quiz):
                issues.append({'type': 'WEAK_DISTRACTORS', 'detail': f'干扰项区分度不足'})
                score -= 0.05
    
    # 5. 内容完整性 (前后是否有明显截断)
    if has_truncated_sentences(slice_obj.content_text):
        issues.append({'type': 'TRUNCATED', 'detail': '内容存在句子截断'})
        score -= 0.1
    
    # 6. 重复检测
    if is_near_duplicate_with_neighbors(slice_obj):
        issues.append({'type': 'DUPLICATE', 'detail': '与相邻切片内容高度重复'})
        score -= 0.15
    
    return SliceQualityReport(
        score=max(score, 0.0),
        issues=issues,
        passed=score >= 0.7
    )
```

### 5.2 关键代码: 智能分段服务

```java
@Service
@Slf4j
public class SliceSegmentService {

    @Autowired private TextSegmentEngine textEngine;
    @Autowired private MediaSegmentEngine mediaEngine;
    @Autowired private SliceEnrichService enrichService;
    @Autowired private SliceQuizService quizService;
    @Autowired private SliceTransitionService transitionService;
    @Autowired private SliceQualityService qualityService;
    @Autowired private ContentSliceRepository sliceRepo;
    @Autowired private ApplicationEventPublisher eventPublisher;

    /**
     * 执行完整的切片任务
     */
    @Transactional
    public SegmentResult executeSegmentation(ContentSliceTask task, RawContent rawContent) {
        
        // 1. 根据内容类型选择分段引擎
        List<SliceDraft> drafts = switch (task.getRawContentType()) {
            case TEXT, PDF -> textEngine.segment(rawContent, task);
            case VIDEO, AUDIO -> mediaEngine.segment(rawContent, task);
        };
        
        log.info("Task {}: segmented into {} drafts", task.getTaskNo(), drafts.size());
        
        // 2. 标注每个切片
        for (SliceDraft draft : drafts) {
            enrichService.enrich(draft, rawContent);
        }
        
        // 3. 生成检查题
        if (task.getConfig().isGenerateQuiz()) {
            for (SliceDraft draft : drafts) {
                List<ContentSliceQuiz> quizzes = quizService.generateFor(
                    draft, task.getConfig().getQuizCountPerSlice()
                );
                draft.setQuizzes(quizzes);
            }
        }
        
        // 4. 生成过渡摘要
        if (task.getConfig().isGenerateTransition()) {
            transitionService.generateTransitions(drafts);
        }
        
        // 5. 质量校验
        BigDecimal totalScore = BigDecimal.ZERO;
        int passCount = 0;
        for (SliceDraft draft : drafts) {
            SliceQualityReport report = qualityService.check(draft);
            draft.setQualityScore(report.getScore());
            if (report.isPassed()) passCount++;
            
            if (!report.getIssues().isEmpty()) {
                log.warn("Task {} slice {} quality issues: {}", 
                    task.getTaskNo(), draft.getSequenceNo(), report.getIssues());
            }
        }
        
        // 6. 持久化
        List<ContentSlice> slices = sliceRepo.saveAll(
            drafts.stream().map(this::toEntity).toList()
        );
        
        BigDecimal avgScore = totalScore.divide(
            BigDecimal.valueOf(drafts.size()), 2, RoundingMode.HALF_UP
        );
        
        // 7. 发布事件
        eventPublisher.publishEvent(new SliceTaskCompletedEvent(
            task.getTaskNo(), slices.size(), avgScore, passCount
        ));
        
        return new SegmentResult(slices.size(), avgScore, passCount);
    }
}
```

### 5.3 关键代码: 异步任务消费者

```java
@Component
@Slf4j
public class SliceTaskProcessorJob {

    @Autowired private SliceTaskService taskService;
    @Autowired private SliceSegmentService segmentService;
    @Autowired private ContentRawService rawContentService;
    @Autowired private RedisTemplate<String, Object> redis;

    private static final String TASK_QUEUE = "slice:task:queue";
    private static final int MAX_RETRY = 2;
    private static final Duration PROCESSING_TIMEOUT = Duration.ofMinutes(30);

    /**
     * 消费切片任务队列
     */
    public void consumeTaskQueue() {
        while (true) {
            String taskNo = redis.opsForList().rightPop(TASK_QUEUE);
            if (taskNo == null) break;
            
            processTask(taskNo);
        }
    }

    @Async("sliceTaskExecutor")
    public void processTask(String taskNo) {
        ContentSliceTask task = taskService.findByTaskNo(taskNo);
        String statusKey = "slice:task:status:" + task.getId();
        
        try {
            // 更新状态
            task.setStatus(SliceTaskStatus.PROCESSING);
            taskService.save(task);
            
            updateProgress(statusKey, "PREPROCESS", 1, 7);
            
            // 获取原始内容
            RawContent rawContent = rawContentService.getById(task.getRawContentId());
            
            updateProgress(statusKey, "ANALYZE", 2, 7);
            
            // 执行切片
            SegmentResult result = segmentService.executeSegmentation(task, rawContent);
            
            updateProgress(statusKey, "DONE", 7, 7);
            
            // 更新任务状态
            task.setStatus(SliceTaskStatus.SLICED);
            task.setTotalSlices(result.getTotalSlices());
            task.setQualityScore(result.getAvgScore());
            taskService.save(task);
            
            // 推入审核队列
            redis.opsForList().leftPush("slice:review:queue", taskNo);
            
        } catch (Exception e) {
            log.error("Slice task {} failed", taskNo, e);
            handleFailure(task, statusKey, e);
        }
    }

    private void handleFailure(ContentSliceTask task, String statusKey, Exception e) {
        int retryCount = task.getRetryCount() == null ? 0 : task.getRetryCount();
        
        if (retryCount < MAX_RETRY) {
            task.setRetryCount(retryCount + 1);
            task.setStatus(SliceTaskStatus.PENDING);
            taskService.save(task);
            
            // 延迟重试 (指数退避)
            redis.opsForList().leftPush(TASK_QUEUE, task.getTaskNo());
            log.info("Task {} scheduled for retry (attempt {})", 
                task.getTaskNo(), retryCount + 1);
        } else {
            task.setStatus(SliceTaskStatus.FAILED);
            task.setErrorMessage(e.getMessage());
            taskService.save(task);
            
            redis.opsForHash().put(statusKey, "errorMsg", e.getMessage());
        }
    }
    
    private void updateProgress(String key, String phase, int step, int total) {
        redis.opsForHash().putAll(key, Map.of(
            "phase", phase,
            "currentStep", step,
            "totalSteps", total,
            "percent", step * 100 / total
        ));
        redis.expire(key, Duration.ofHours(24));
    }
}
```

## 6. 错误处理与边界条件

### 6.1 异步任务错误处理

| 场景 | 处理策略 |
|------|----------|
| AI 模型调用超时 | 重试2次(间隔30s/60s)，仍失败→标记FAILED并通知教研 |
| OCR/ASR 转写失败 | 降级为纯文本处理或标记FAILED |
| FFmpeg 媒体切割失败 | 重试1次，仍失败→保留文本切片，标记媒体缺失 |
| 检查题生成返回格式错误 | JSON解析失败→使用正则兜底提取，再失败→跳过该题 |
| 质量分低于0.5 | 自动标记为需人工审核，不自动发布 |
| 任务处理超过30分钟 | 超时中断，标记TIMEOUT，进入重试队列 |

### 6.2 数据一致性处理

| 场景 | 处理策略 |
|------|----------|
| 原始内容被删除/下架 | 切片级联标记ARCHIVED，已发布的学习记录保留 |
| 切片合并后检查题重复 | 合并时自动去重，保留质量分较高的检查题 |
| 切片拆分后过渡摘要失效 | 拆分时标记过渡摘要需重新生成 |
| 发布后紧急下架 | status→ARCHIVED，Redis缓存即时失效，推送通知关联用户 |
| 并发编辑同一切片组 | 乐观锁(version字段)，冲突时提示最新版本 |

### 6.3 边界条件
