# 客户端-文科背诵页面架构与交互设计

> 本文档细化 PrimeTop 文科背诵模块的客户端页面架构、交互流程、组件设计与数据流，
> 使开发人员可直接参照实现 Flutter 页面与 Widget。
>
> 服务端设计详见：[文科背诵-详细设计.md](./文科背诵-详细设计.md)

---

## 1. 概述

### 1.1 功能定位

文科背诵模块面向小学至高中学生，覆盖语文（古诗文、文言文、课文段落）、英语（单词、短语、范文）、历史/政治/地理（概念、事件、框架）等文科学科，提供**记忆辅助 → 背诵练习 → 检测评分 → 复习调度**的完整背诵学习闭环。

客户端负责：

1. 背诵材料的浏览、搜索与筛选
2. 四种背诵模式的交互实现（初学/复习/检测/速览）
3. 文本输入与语音背诵的采集与提交
4. AI 背诵结果的对比、评分与错误标注展示
5. 复习日历与遗忘曲线进度的可视化
6. 背诵统计与成就反馈

### 1.2 覆盖学段与分龄策略

| 学段 | 典型背诵内容 | 交互侧重 | 页面复杂度 |
|------|------------|---------|-----------|
| 幼儿 | 儿歌、简单古诗 | 大卡片、语音引导、趣味动画 | 低 |
| 小学低年级(1-3) | 古诗词、生字词、英语单词 | 图文结合、语音背诵为主、奖励明显 | 中低 |
| 小学高年级(4-6) | 古诗文、课文段落、英语短语 | 文本+语音混合、分段背诵 | 中 |
| 初中 | 文言文全文、英语范文、历史事件 | 完整背诵检测、关键词提示 | 中高 |
| 高中 | 长篇文言文、高考词汇、政治框架 | 高效速览、专题检测、精确评分 | 高 |

  /// 今日待复习材料

  /// 学科快捷入口
  List<SubjectTab> subjects;

  List<ReciteRecentItem> recentItems;

  /// 总背诵统计摘要

class ReciteTaskItem {
  final int materialId;
  final String title;
  final String subject;
  final String reason;      // "今日复习", "已过期", "新学"

### 3.5 ReciteLearnPage — 初学模式

初学模式适合首次学习某篇材料，流程：**通读原文 → 逐段跟读 → 关键词提示 → 完整背诵**。

#### 3.5.1 交互流程

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ Step 1  │────►│ Step 2  │────►│ Step 3  │────►│ Step 4  │
│ 通读原文 │     │ 逐段学习 │     │ 关键词  │     │ 完整背诵│
│         │     │ (逐段)   │     │ 提示回忆 │     │         │
└─────────┘     └─────────┘     └─────────┘     └─────────┘
    │               │               │               │
    │ 展示全文      │ 逐段高亮       │ 隐藏关键词     │ 全部隐藏
    │ 朗读播放      │ 跟读练习       │ 填空回忆       │ 文本/语音输入
    │ 了解大意      │ 初步记忆       │ 检验记忆       │ 完整检测
```

```
