# 客户端-文科背诵页面架构与交互设计

> 本文档细化 PrimeTop 文科背诵模块的客户端页面架构、交互流程、组件设计与数据流，
> 使开发人员可直接参照实现 Flutter 页面与 Widget。
>
> 服务端设计详见：[文科背诵-详细设计.md](./文科背诵-详细设计.md)

---

## 1. 概述

### 1.1 功能定位

文科背诵模块面向小学至高中学生，覆盖语文（古诗文、文言文、课文段落）、英语（单词、短语、范文）、历史/政治/地理（概念、事件、框架）等文科学科，提供**记忆辅助 → 背诵练习 → 检测评分 → 复习调度**的完整背诵学习闭环。

客户端负责：

1. 背诵材料的浏览、搜索与筛选
2. 四种背诵模式的交互实现（初学/复习/检测/速览）
3. 文本输入与语音背诵的采集与提交
4. AI 背诵结果的对比、评分与错误标注展示
5. 复习日历与遗忘曲线进度的可视化
6. 背诵统计与成就反馈

### 1.2 覆盖学段与分龄策略

| 学段 | 典型背诵内容 | 交互侧重 | 页面复杂度 |
|------|------------|---------|-----------|
| 幼儿 | 儿歌、简单古诗 | 大卡片、语音引导、趣味动画 | 低 |
| 小学低年级(1-3) | 古诗词、生字词、英语单词 | 图文结合、语音背诵为主、奖励明显 | 中低 |
| 小学高年级(4-6) | 古诗文、课文段落、英语短语 | 文本+语音混合、分段背诵 | 中 |
| 初中 | 文言文全文、英语范文、历史事件 | 完整背诵检测、关键词提示 | 中高 |
| 高中 | 长篇文言文、高考词汇、政治框架 | 高效速览、专题检测、精确评分 | 高 |

```dart
class ReciteHomeState {
  /// 今日待复习材料
  List<ReciteTaskItem> todayTasks;

  /// 今日已完成数
  int todayCompleted;

  /// 学科快捷入口
  List<SubjectTab> subjects;

  /// 推荐背诵列表（根据学习进度 + 教材章节 + 考点热度排序）
  List<ReciteRecommendItem> recommendations;

  /// 最近背诵记录
  List<ReciteRecentItem> recentItems;

  /// 总背诵统计摘要
  ReciteSummary summary;
}

class ReciteTaskItem {
  final String materialId;  // v1.1 修正:String 型 RM 前缀编号(E2E 权威),v1.0 误写 int
  final String title;
  final String subject;

class ReciteRecommendItem {

  final String author;
```

### 3.5 ReciteLearnPage — 初学模式

初学模式适合首次学习某篇材料，流程：**通读原文 → 逐段跟读 → 关键词提示 → 完整背诵**。

#### 3.5.1 交互流程

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ Step 1  │────►│ Step 2  │────►│ Step 3  │────►│ Step 4  │
│ 通读原文 │     │ 逐段学习 │     │ 关键词  │     │ 完整背诵│
│         │     │ (逐段)   │     │ 提示回忆 │     │         │
└─────────┘     └─────────┘     └─────────┘     └─────────┘
    │               │               │               │
```

- 未成年人自定义内容默认仅本人可见，家长端可见（家长绑定链路，对齐家长中心可见性分级）

## 5. 关键代码示例

### 5.1 背诵会话编排器（模式分发）

```dart
class ReciteSessionController extends StateNotifier<ReciteSessionState> {
  final ReciteApi _api;
  final String materialId;
  final ReciteMode mode;

  Future<void> start() async {
    state = state.copyWith(phase: RecitePhase.creating);
    // 幂等:G2 同材料同模式重复进入时服务端返回未完结会话(session_id 复用)
    final resp = await _api.createSession(CreateSessionRequest(
      materialId: materialId,
      reciteMode: mode == ReciteMode.test ? 'full' : 'segment',
      inputType: 'voice',
      targetSegment: null,
    ));
    state = state.copyWith(
      phase: RecitePhase.ready,
      sessionId: resp.sessionId,
      timeLimitSeconds: resp.timeLimitSeconds,
      expectedSegments: resp.expectedSegments,
    );
  }

  Future<void> submitText(String text, {int? segmentIndex}) async {
    if (state.phase == RecitePhase.submitting) return; // 防重复点击 G2
    state = state.copyWith(phase: RecitePhase.submitting);
    try {
      await _api.submit(state.sessionId!, SubmitRequest(
        inputType: 'text',
        inputText: text,
        segmentIndex: segmentIndex,
      ));
      state = state.copyWith(phase: RecitePhase.scoring);
    } on ApiException catch (e) {
      // 401040 会话过期 → 重新开始(D4);其余 → 草稿保留可重试
      state = state.copyWith(
        phase: e.code == 401040 ? RecitePhase.expired : RecitePhase.ready,
      );
      rethrow;
    }
  }
}
```

### 5.2 语音采集与双通道提交

```dart
class VoiceSubmitController {
  /// 录音完成 → 上传文件服务 → 携带 audio_file_id + 本地ASR兜底文本提交
  Future<void> submitVoice(String sessionId, String audioPath) async {
    final upload = await fileService.upload(audioPath,
        scene: 'recite', retention: 'transient'); // 音频即传即焚,G4
    final fallbackText = await localAsr.transcribe(audioPath)
        .catchError((_) => ''); // 本地ASR失败不阻塞,服务端兜底
    await reciteApi.submit(sessionId, SubmitRequest(
      inputType: 'voice',
      audioFileId: upload.fileId,
      durationSeconds: upload.durationSeconds,
      fallbackText: fallbackText,
    ));
    await safeDelete(audioPath); // 临时录音文件立即清理
  }
}
```

## 6. 状态机与守卫

### 6.1 背诵会话状态机（客户端展示态）

```
creating → ready → recording → submitting → scoring → done
              │          │            │
              │          │            └─(失败,可重试)→ ready(草稿保留)
              │          └─(取消)→ ready
              └─(401040 会话过期)→ expired → (用户确认) creating

scoring ─(轮询超时)→ pending_lookup (本地待查任务,结果页可稍后拉取)
```

### 6.2 守卫总表

| 守卫 | 规则 | 违反后果 |
|------|------|---------|
| G1 答案防泄露 | 检测模式(test)全程不渲染原文与提示 | 守卫失败禁止进入检测页 |
| G2 提交幂等 | submitting 态重复提交直接吞没；同 session_id 重复 submit 以服务端幂等键为准 | 本地防重 + 服务端幂等双保险 |
| G3 录音权限 | 麦克风未授权时语音入口置灰并引导设置，不得静默失败 | 401050 映射权限引导页 |
| G4 音频最小化 | 录音临时文件即录即传即删；本地不留存完整录音 | 退出页面强制清理临时目录 |
| G5 防沉迷联动 | 连续背诵达到学段上限时触发休息提示（时长口径归防沉迷引擎） | 仅提示不强制中断 |
| G6 离线边界 | 离线可浏览与自测（本地对比），结果标记 offline，恢复网络后补传 | 离线结果不计掌握度 |
| G7 学段适配 | 目录默认过滤当前学段已学年级材料 | 深链携带越学段 materialId 时 403 拦截 |
| G8 检测严肃性 | 检测模式禁用提示/回改/续答 | 退出即按已提交计分 |
| G9 会话唯一 | 同材料同时只允许一个活跃会话（跨端由服务端裁决，本地配合） | 重复进入提示已有进行中的会话 |
| G10 SSE 讲解 | explain SSE 断线自动重连（Last-Event-ID），最多 3 次 | 超限降级 D8 静态注释 |

## 7. 幂等与并发

| 场景 | 幂等键 | 未知态裁决 |
|------|--------|-----------|
| 创建背诵会话 | （材料+模式）服务端去重，返回未完结原 session | 重复点击合并为同一请求 |
| 提交背诵（文本） | `session_id + client_submit_id`(UUID) | 3 次指数退避重试后落本地待查 |
| 提交背诵（语音） | `audio_file_id` 唯一 + `client_submit_id` | 上传成功提交未知 → 凭 fileId 查询补判 |
| 离线补交 | `client_request_id` | 网络恢复后自动补传，重复提交服务端幂等 |
| 结果轮询 | `session_id` | 轮询上限 30s 转 pending_lookup |
| 自定义材料创建 | `client_request_id`(标题+正文 hash) | 重复提交返回原材料，不重复建库 |

**多端并发**：多端同时进入同材料背诵时，服务端会话唯一（G9）裁决先到者胜；客户端收到 401040/冲突响应时引导「继续在原设备背诵或重新开始」。

## 8. 错误码与降级

### 8.1 错误码映射（权威归 E2E §10.1）

| 业务码 | 客户端表现 | 降级策略 |
|--------|-----------|---------|
| 401001 材料不存在 | toast + 返回列表 | - |
| 401002 材料已下架 | 提示并推荐同类材料 | 缓存材料标记已下线灰显 |
| 401003 无背诵权限 | 会员引导（频率受限） | 展示免费可背材料 |
| 401010/401011 ASR失败/超时 | 提示切换文本输入 | D1 |
| 401020 对比服务异常 | 精确匹配降级评分 | D2 |
| 401030 复习调度失败 | 默认 1 天后复习 | D3 |
| 401040 会话过期 | 提示重新开始 | D4 |
| 401050 录音权限未授予 | 引导系统设置 | 文本输入兜底 |
| 网络错误 | 重试横幅 | 离线草稿暂存 |

客户端本地诊断码 `RECITE_xxx` 仅用于埋点与日志（对齐日志采集系统注册），不对用户透出。

### 8.2 降级矩阵 D1-D10

| 编号 | 故障 | 降级行为 | 恢复 |
|------|------|---------|------|
| D1 | ASR 服务不可用 | 语音入口降级为文本输入 | 服务恢复自动回弹 |
| D2 | 对比服务异常 | 精确匹配粗评 + 标注「评分可能有偏差」 | 服务端恢复后重评 |
| D3 | 复习调度失败 | 默认 1 天间隔 + 重试任务 | 后台补偿 |
| D4 | 会话过期 | 保留草稿，一键重建会话 | - |
| D5 | 网络断开 | 文本草稿本地暂存，恢复补交 | 自动 |
| D6 | TTS 不可用 | 静音自学不阻塞流程 | 自动 |
| D7 | 首页聚合失败 | 缓存快照 + 手动刷新 | 自动 |
| D8 | explain SSE 失败 | 静态注释模板兜底 | 自动 |
| D9 | 统计接口失败 | 上次缓存 + 「更新于 x 小时前」标注 | 自动 |
| D10 | 语音上传失败 | fallback_text 文本比对兜底 | 自动 |

## 13. 验收场景

1. 首页今日待复习卡片展示 due_now 数据，完成一次复习后卡片数即时 -1（乐观更新）并 30s 内与服务端校准
2. 初学模式四步流程完整走完：通读→逐段→关键词→完整背诵，每步可上一步回退
3. 关键词提示三级展开（首字→关键词→结构）逐次埋点
4. 挖空布局与下发 blank_positions 完全一致，断网重进不漂移
5. 检测模式全程不出现原文与提示按钮（G1 自动化断言：页面树无原文文本节点）
6. 检测中途退出弹确认，退出后按已提交计分且不可续答
7. 语音提交失败（401010）自动提示并切换文本输入，草稿不丢失
8. 会话过期（401040）提示重新开始，文本草稿保留可一键重提
9. 重复点击提交仅产生一次 submit 请求（G2 网络层断言）
10. 离线文本背诵暂存，恢复网络自动补交且结果正确归因
11. 结果页错误对比四色标注与 diff_display 一一对应
12. 评分超时转 pending_lookup，稍后进入结果页可拉取到结果
13. 日历月视图切换流畅，复习完成后当日红标消除
14. 统计页接口失败展示缓存并标注更新时间（D9）
15. 自定义材料创建→分段预览→调整边界→入库→详情可见全流程通过
16. 录音临时文件在提交/退出页面后本地不存在（G4 文件系统断言）
17. 深链携带越学段 materialId 被拦截并提示（G7）
18. 切换账号后背诵缓存与草稿完全隔离
