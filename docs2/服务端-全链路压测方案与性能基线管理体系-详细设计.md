# 服务端-全链路压测方案与性能基线管理体系-详细设计

## 1. 文档概述

### 1.1 目的

为 PrimeTop 全学段 AI 辅助学习平台建立系统化的全链路压测方案与性能基线管理体系，确保各类核心业务场景在生产负载下的稳定性、可扩展性和响应效率。本文档提供可直接落地的压测策略、工具选型、场景设计、数据准备、结果分析和性能回归保障机制。

### 1.2 适用范围

- 所有 P0/P1 级别业务接口的全链路性能验证
- AI 大模型调用链路的延迟与吞吐验证
- OCR、ASR/TTS 等多模态处理管线的压力测试
- SSE 流式响应与 WebSocket 长连接的并发验证
- 数据库、缓存、消息队列等中间件的性能基线
- CI/CD 流水线中的性能回归门禁
- 大促/开学季等峰值场景的容量预估验证

### 1.3 设计原则

| 原则 | 说明 |
| --- | --- |
| **仿真优先** | 压测流量模型尽量贴近真实用户行为序列，而非孤立接口轰炸 |
| **分层定位** | 从接入层→业务层→AI层→数据层逐层定位瓶颈 |
| **基线驱动** | 所有性能评估以历史基线数据为参照，量化回归幅度 |
| **安全隔离** | 压测环境与生产环境严格隔离，压测数据打标且不可污染生产 |
| **持续演进** | 性能基线随业务迭代动态更新，形成闭环反馈 |

## 2. 核心概念定义

### 2.1 SLA / SLO / SLI

```yaml
SLI (Service Level Indicator):
  "可直接度量的服务质量指标"
  例: AI问答首token响应时间、OCR识别成功率

SLO (Service Level Objective):
  "对SLI设定的目标值或范围"
  例: AI问答首token响应 P95 < 3s

SLA (Service Level Agreement):
  "与用户约定的服务可用性承诺"
  例: 核心学习功能月可用性 ≥ 99.5%
```

### 2.2 负载模型术语

| 术语 | 定义 | 示例 |
| --- | --- | --- |
| 基线负载 (Baseline Load) | 日常峰值 QPS | AI问答 500 QPS |
| 目标负载 (Target Load) | 预期可承载的峰值 | 开学季 1500 QPS |
| 极限负载 (Stress Load) | 逐步加压至系统崩溃 | 持续加压至响应超时 |
| 浸泡负载 (Soak Load) | 长时间中等负载运行 | 80% 基线负载持续 12h |
| 突发负载 (Spike Load) | 瞬时流量尖峰 | 10秒内 QPS 从 100→3000 |

#### 4.3.1 AI 模型 Mock

```python
"""
AI 模型 Mock 服务
模拟大模型 API 的延迟特征和响应模式，用于压测中被测系统的 AI 调用链路
"""

import asyncio
import random
import time
from typing import AsyncGenerator
from fastapi import FastAPI, Request
from fastapi.responses import StreamingResponse
import json

app = FastAPI(title="AI Model Mock")

# 延迟分布配置
LATENCY_PROFILES = {
    "default": {
        "first_token_delay_mean": 1500,   # ms
        "first_token_delay_std": 400,
        "token_interval_mean": 50,         # ms
        "token_interval_std": 15,
        "total_tokens_mean": 400,
        "total_tokens_std": 120,
        "error_rate": 0.005,               # 0.5% 错误率
    },
    "reasoning": {  # 推理模型更慢
        "first_token_delay_mean": 2500,
        "first_token_delay_std": 600,
        "token_interval_mean": 60,
        "token_interval_std": 20,
        "total_tokens_mean": 600,
        "total_tokens_std": 200,
        "error_rate": 0.008,
    },
    "embedding": {  # 嵌入模型快速返回
        "delay_mean": 200,
        "delay_std": 50,
        "error_rate": 0.002,
    }
}


def gaussian_clipped(mean: float, std: float, min_val: float = 0) -> float:
    """生成截断高斯分布随机数"""
    val = random.gauss(mean, std)
    return max(min_val, val)


def should_inject_error(error_rate: float) -> bool:
    """按概率注入错误"""
    return random.random() < error_rate


@app.post("/v1/chat/completions")
async def chat_completions(request: Request):
    """模拟 chat completions 接口（SSE 流式）"""
    body = await request.json()
    profile = LATENCY_PROFILES.get(
        body.get("model", "default"),
        LATENCY_PROFILES["default"]
    )

    if should_inject_error(profile["error_rate"]):
        return {"error": {"message": "Mock: simulated error", "code": 500}}

    total_tokens = int(gaussian_clipped(
        profile["total_tokens_mean"],
        profile["total_tokens_std"],
        min_val=50
    ))

    first_delay = gaussian_clipped(
        profile["first_token_delay_mean"],
        profile["first_token_delay_std"],
        min_val=100
    ) / 1000  # 转秒

    interval = profile["token_interval_mean"] / 1000

    async def stream_response() -> AsyncGenerator[bytes, None]:
        # 模拟首token延迟
        await asyncio.sleep(first_delay)

        for i in range(total_tokens):
            chunk = {
                "choices": [{
                    "delta": {"content": f"tok{i} "},
                    "index": 0,
                    "finish_reason": None if i < total_tokens - 1 else "stop"
                }]
            }
            yield f"data: {json.dumps(chunk)}\n\n".encode()

            # 模拟token间隔抖动
            jitter = gaussian_clipped(0, profile["token_interval_std"]) / 1000
            await asyncio.sleep(interval + jitter)

        yield b"data: [DONE]\n\n"

    return StreamingResponse(
        stream_response(),
        media_type="text/event-stream"
    )


@app.post("/v1/embeddings")
async def embeddings(request: Request):
    """模拟 embeddings 接口"""
    profile = LATENCY_PROFILES["embedding"]
    
    if should_inject_error(profile["error_rate"]):
        return {"error": {"message": "Mock: simulated error", "code": 500}}

    delay = gaussian_clipped(
        profile["delay_mean"], profile["delay_std"], min_val=50
    ) / 1000
    await asyncio.sleep(delay)

    return {
        "data": [{
            "embedding": [random.gauss(0, 1) for _ in range(1536)],
            "index": 0
        }],
        "usage": {"prompt_tokens": 100, "total_tokens": 100}
    }


@app.get("/health")
async def health():
    return {"status": "ok", "service": "ai-model-mock"}


if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8100)
```

```javascript
function randomLogNormal(mean, std) {
  // 生成对数正态分布的思考时间
  const u1 = Math.random();
  const u2 = Math.random();
  const z = Math.sqrt(-2 * Math.ln(u1)) * Math.cos(2 * Math.PI * u2);
  return Math.exp(z * Math.log(1 + std / mean)) * mean / (1 + std / mean);
```

## 6. 压测数据管理

### 6.1 测试数据准备策略

```python
"""
压测数据准备脚本
生成符合业务特征的用户、题目、学习记录等测试数据
"""

import json
import random
import uuid
from datetime import datetime, timedelta


class PerfDataGenerator:
    """压测数据生成器"""
    
    def __init__(self, target_users: int = 100_000):
        self.target_users = target_users
        self.grades = list(range(1, 13))  # 1年级到高三
        self.subjects = ["chinese", "math", "english", "physics", "chemistry",
                         "biology", "history", "geography", "politics"]
        self.textbook_versions = ["renjiao", "sujiap", "beishida", "waiyan"]
    
    def generate_users(self) -> list[dict]:
        """生成测试用户数据"""
        users = []
        grade_distribution = [
            (range(1, 3), 0.08),   # 小学低年级 8%
            (range(3, 5), 0.12),   # 小学中年级 12%
            (range(5, 7), 0.15),   # 小学高年级 15%
            (range(7, 10), 0.35),  # 初中 35%
            (range(10, 13), 0.30), # 高中 30%
        ]
        
        for i in range(self.target_users):
            grade = self._weighted_choice(grade_distribution)
            user = {
                "user_id": f"perf_user_{i:06d}",
                "phone": f"1{random.choice(['3','5','8','9'])}{random.randint(100000000, 999999999)}",
                "grade": grade,
                "subject_target": random.choice(self.subjects),
                "textbook_version": random.choice(self.textbook_versions),
                "membership_level": random.choices(
                    ["free", "monthly", "annual"],
                    weights=[70, 15, 15]
                )[0],
                "register_date": (
                    datetime.now() - timedelta(days=random.randint(1, 365))
                ).isoformat(),
                "last_active": (
                    datetime.now() - timedelta(hours=random.randint(0, 168))
                ).isoformat(),
            }
            users.append(user)
        
        return users
    
    def generate_learning_records(self, users: list[dict]) -> list[dict]:
        """为用户生成历史学习记录"""
        records = []
        for user in users:
            # 每个用户 10-200 条学习记录
            num_records = random.randint(10, 200)
            for _ in range(num_records):
                records.append({
                    "record_id": str(uuid.uuid4()),
                    "user_id": user["user_id"],
                    "subject": random.choice(self.subjects),
                    "grade": user["grade"],
                    "session_type": random.choices(
                        ["ai_chat", "practice", "sync_class", "photo_search"],
                        weights=[40, 30, 20, 10]
                    )[0],
                    "duration_sec": random.randint(60, 3600),
                    "created_at": (
                        datetime.now() - timedelta(days=random.randint(0, 90))
                    ).isoformat(),
                    "knowledge_points": [
                        f"kp_{random.randint(1, 5000)}" for _ in range(random.randint(1, 5))
                    ],
                })
        return records
    
    def generate_mistakes(self, users: list[dict]) -> list[dict]:
        """生成错题记录"""
        mistakes = []
        for user in users:
            num_mistakes = random.randint(5, 100)
            for _ in range(num_mistakes):
                mistakes.append({
                    "mistake_id": str(uuid.uuid4()),
                    "user_id": user["user_id"],
                    "question_id": f"q_{random.randint(1, 50000)}",
                    "subject": random.choice(self.subjects),
                    "error_type": random.choice([
                        "concept_unclear", "careless", "method_wrong",
                        "calculation_error", "misread"
                    ]),
                    "review_count": random.randint(0, 5),
                    "next_review_date": (
                        datetime.now() + timedelta(days=random.randint(-7, 30))
                    ).isoformat(),
                    "status": random.choices(
                        ["pending", "reviewed", "mastered"],
                        weights=[30, 50, 20]
                    )[0],
                })
        return mistakes
    
    def _weighted_choice(self, weighted_options):
        """加权随机选择"""
        total = sum(w for _, w in weighted_options)
        r = random.random() * total
        upto = 0
        for options, weight in weighted_options:
            upto += weight
            if r <= upto:
                return random.choice(list(options))
        return random.choice(list(weighted_options[-1][0]))
    
    def export_all(self, output_dir: str = "./perf-data"):
        """导出所有测试数据"""
        import os
        os.makedirs(output_dir, exist_ok=True)
        
        users = self.generate_users()
        records = self.generate_learning_records(users)
        mistakes = self.generate_mistakes(users)
        
        for name, data in [("users", users), ("records", records), ("mistakes", mistakes)]:
            path = f"{output_dir}/{name}.jsonl"
            with open(path, "w", encoding="utf-8") as f:
                for item in data:
                    f.write(json.dumps(item, ensure_ascii=False) + "\n")
            print(f"Generated {len(data)} {name} → {path}")


# 运行数据生成
if __name__ == "__main__":
    generator = PerfDataGenerator(target_users=100_000)
    generator.export_all()
```

### 8.3 性能回归检测规则

```python
"""
性能回归检测引擎
对比当前压测结果与历史基线，判定是否触发回归
"""

from dataclasses import dataclass
from typing import Optional
import json


@dataclass
class RegressionResult:
    scenario_id: str
    metric_name: str
    baseline_value: float
    current_value: float
    change_percent: float
    severity: str  # "pass", "warning", "critical"
    message: str


class PerformanceRegressionDetector:
    """性能回归检测器"""
    
    # 回归阈值配置
    THRESHOLDS = {
        "latency": {
            "warning_pct": 15,     # 延迟增加15%告警
            "critical_pct": 30,    # 延迟增加30%严重
        },
        "error_rate": {
            "warning_multiplier": 1.5,
            "critical_multiplier": 2.0,
        },
        "throughput": {
            "warning_drop_pct": 10,
            "critical_drop_pct": 20,
        },
        "resource": {
            "warning_increase_pct": 20,
            "critical_increase_pct": 40,
        }
    }
    
    # 需要检测的延迟指标关键字
    LATENCY_KEYWORDS = ["p50", "p95", "p99", "response_time", "latency"]
    
    def __init__(self, baseline_path: str):
        with open(baseline_path, 'r', encoding='utf-8') as f:
            self.baseline = json.load(f)
    
    def compare(
        self,
        current_results: dict,
        scenario_id: Optional[str] = None
    ) -> list[RegressionResult]:
        """对比当前结果与基线"""
        results = []
        
        for baseline_scenario in self.baseline["scenarios"]:
            sid = baseline_scenario["scenario_id"]
            
            if scenario_id and sid != scenario_id:
                continue
            
            current_scenario = self._find_scenario(current_results, sid)
            if not current_scenario:
                continue
            
            # 对比每个指标
            for metric_name, baseline_value in baseline_scenario.get("metrics", {}).items():
                current_value = current_scenario.get("metrics", {}).get(metric_name)
                if current_value is None:
                    continue
                
                result = self._compare_metric(sid, metric_name, baseline_value, current_value)
                results.append(result)
        
        return results
    
    def _compare_metric(
        self,
        scenario_id: str,
        metric_name: str,
        baseline: float,
        current: float
    ) -> RegressionResult:
        """对比单个指标"""
        
        # 判断指标类型
        if any(kw in metric_name.lower() for kw in self.LATENCY_KEYWORDS):
            return self._compare_latency(scenario_id, metric_name, baseline, current)
        elif "error" in metric_name.lower():
            return self._compare_error_rate(scenario_id, metric_name, baseline, current)
        else:
            return self._compare_generic(scenario_id, metric_name, baseline, current)
    
    def _compare_latency(
        self, scenario_id: str, metric: str, baseline: float, current: float
    ) -> RegressionResult:
        change_pct = ((current - baseline) / baseline) * 100
        
        if change_pct >= self.THRESHOLDS["latency"]["critical_pct"]:
            severity = "critical"
            msg = f"严重回归: {metric} 增加了{change_pct:.1f}%（基线{baseline:.0f}→当前{current:.0f}）"
        elif change_pct >= self.THRESHOLDS["latency"]["warning_pct"]:
            severity = "warning"
            msg = f"性能退化: {metric} 增加了{change_pct:.1f}%（基线{baseline:.0f}→当前{current:.0f}）"
        else:
            severity = "pass"
            msg = f"正常: {metric} 变化{change_pct:+.1f}%（基线{baseline:.0f}→当前{current:.0f}）"
        
        return RegressionResult(
            scenario_id=scenario_id, metric_name=metric,
            baseline_value=baseline, current_value=current,
            change_percent=change_pct, severity=severity, message=msg
        )
    
    def _compare_error_rate(
        self, scenario_id: str, metric: str, baseline: float, current: float
    ) -> RegressionResult:
        multiplier = current / max(baseline, 0.001)
        
        if multiplier >= self.THRESHOLDS["error_rate"]["critical_multiplier"]:
            severity = "critical"
        elif multiplier >= self.THRESHOLDS["error_rate"]["warning_multiplier"]:
            severity = "warning"
        else:
            severity = "pass"
        
        return RegressionResult(
            scenario_id=scenario_id, metric_name=metric,
            baseline_value=baseline, current_value=current,
            change_percent=(multiplier - 1) * 100,
            severity=severity,
            message=f"错误率{'严重回归' if severity == 'critical' else '退化' if severity == 'warning' else '正常'}: {baseline:.2f}% → {current:.2f}%（{multiplier:.1f}x）"
        )
    
    def _compare_generic(
        self, scenario_id: str, metric: str, baseline: float, current: float
    ) -> RegressionResult:
        change_pct = abs((current - baseline) / max(baseline, 0.001)) * 100
        severity = "pass" if change_pct < 20 else "warning"
        
        return RegressionResult(
            scenario_id=scenario_id, metric_name=metric,
            baseline_value=baseline, current_value=current,
            change_percent=change_pct, severity=severity,
            message=f"{metric}: {baseline:.2f} → {current:.2f}（{change_pct:+.1f}%）"
        )
    
    def _find_scenario(self, results: dict, scenario_id: str) -> Optional[dict]:
        for s in results.get("scenarios", []):
            if s.get("scenario_id") == scenario_id:
                return s
        return None
    
    def generate_report(self, results: list[RegressionResult]) -> str:
        """生成回归报告"""
        critical = [r for r in results if r.severity == "critical"]
        warnings = [r for r in results if r.severity == "warning"]
        
        lines = [
            "# 性能回归检测报告",
            f"\n**严重回归**: {len(critical)} 项",
            f"**警告退化**: {len(warnings)} 项",
            f"**总体判定**: {'❌ 阻断发布' if critical else '⚠️ 需评审' if warnings else '✅ 通过'}",
            "\n---\n",
        ]
        
        for r in results:
            icon = {"critical": "❌", "warning": "⚠️", "pass": "✅"}[r.severity]
            lines.append(f"{icon} [{r.scenario_id}] {r.message}")
        
        return "\n".join(lines)
```

### 9.2 性能门禁判定逻辑

```python
"""
性能门禁判定引擎
根据回归检测结果决定是否阻断CI流水线
"""

import sys
import json
from dataclasses import dataclass


@dataclass
class GateResult:
    passed: bool
    summary: str
    blocks: list[str]
    warnings: list[str]


def evaluate_perf_gate(report_path: str, config: dict) -> GateResult:
    """
    性能门禁判定
    
    config:
      max_critical: 允许的最大严重回归数（通常为0）
      max_warning: 允许的最大警告数
      exempted_metrics: 豁免的指标列表（已知原因）
    """
    with open(report_path, 'r', encoding='utf-8') as f:
        results = json.load(f)
    
    max_critical = config.get("max_critical", 0)
    max_warning = config.get("max_warning", 5)
    exempted = config.get("exempted_metrics", [])
    
    critical_items = []
    warning_items = []
    
    for item in results:
        metric = item["metric_name"]
        severity = item["severity"]
        
        # 跳过豁免指标
        if any(ex in metric for ex in exempted):
            continue
        
        if severity == "critical":
            critical_items.append(f"[{item['scenario_id']}] {item['message']}")
        elif severity == "warning":
            warning_items.append(f"[{item['scenario_id']}] {item['message']}")
    
    passed = len(critical_items) <= max_critical and len(warning_items) <= max_warning
    
    summary = (
        f"性能门禁{'✅ 通过' if passed else '❌ 未通过'}: "
        f"严重回归 {len(critical_items)}/{max_critical}, "
        f"警告 {len(warning_items)}/{max_warning}"
    )
    
    return GateResult(
        passed=passed,
        summary=summary,
        blocks=critical_items,
        warnings=warning_items
    )


if __name__ == "__main__":
    config = {
        "max_critical": 0,
        "max_warning": 3,
        "exempted_metrics": [
            # "upload_p95_ms",  # 已知对象存储升级中
        ]
    }
    
    result = evaluate_perf_gate("regression-report.json", config)
    
    print(result.summary)
    if result.blocks:
        print("\n❌ 严重回归项:")
        for b in result.blocks:
            print(f"  {b}")
    if result.warnings:
        print("\n⚠️ 警告项:")
        for w in result.warnings:
            print(f"  {w}")
    
    sys.exit(0 if result.passed else 1)
```

## 10. AI 专项压测策略

### 10.1 AI 链路特殊性分析

AI 大模型调用链路与传统 API 有本质差异，需要专门的压测策略：

| 特性 | 传统 API | AI 大模型调用 | 压测影响 |
| --- | --- | --- | --- |
| 响应模式 | 一次性 JSON 返回 | SSE 流式逐 token 返回 | 连接占用时间长 |
| 响应时间 | 50-500ms | 3-30s | 单连接占用资源更久 |
| 并发模型 | 请求-响应短连接 | 长连接 + 流式写入 | WebSocket/SSE连接数瓶颈 |
| 外部依赖 | DB/Cache 可控 | 大模型供应商不可控 | 需 Mock 但也要测真实 |
| 成本 | 每次调用成本低 | 按 token 计费昂贵 | 压测需控制真实调用次数 |
| 变异性 | 响应大小稳定 | 输出长度差异大（200-2000 token） | 吞吐量不稳定 |

### 10.2 AI 链路分层压测策略

```text
┌─────────────────────────────────────────────────┐
```

### 11.2 常见瓶颈与排查清单

| 症状 | 可能根因 | 排查方法 | 优化方向 |
| --- | --- | --- | --- |
| P95延迟突增 | 慢SQL、GC停顿、连接池等待 | SkyWalking span分析 + DB慢查询日志 | 加索引、连接池调优、GC参数调优 |
| 错误率升高 | 限流触发、下游超时、OOM | 检查限流日志、堆dump分析 | 扩容、超时参数调整、内存优化 |
| 吞吐量上不去 | 线程池满、连接数限制、锁竞争 | 线程dump分析、连接数监控 | 线程池扩容、非阻塞改造 |
| AI首token慢 | 模型排队、网络抖动 | 检查模型API延迟分布 | 预热连接、调整并发池 |
| SSE频繁断开 | 网关超时、代理buffer问题 | 检查Nginx/网关超时配置 | 调整proxy_read_timeout |
| Redis命中率下降 | 缓存过期、key膨胀 | 分析key分布和TTL | 调整过期策略、预加载 |
| MySQL慢查询增加 | 数据量增长、索引缺失 | slow_query_log + EXPLAIN | 加索引、分库分表、读写分离 |
| Kafka消费延迟 | 消费者处理慢、分区不均 | 检查consumer lag分布 | 增加消费者、调整分区策略 |

### 11.3 性能优化优先级矩阵

```text
         高影响
            │
     ┌──────┼──────┐
     │  P0  │  P1  │
     │ 立即  │ 短期  │
 低  │ 修复  │ 优化  │ 高
成本├──────┼──────┤ 成本
     │  P2  │  P3  │
     │ 排期  │ 评估  │
     │ 优化  │ 取舍  │
     └──────┼──────┘
            │
         低影响

示例:
P0: 添加缺失索引（成本极低，影响极大）
P1: 缓存策略优化（需要开发，影响中等）
P2: 服务异步化改造（成本高，影响中等）
P3: 分库分表迁移（成本极高，需要架构评估）
```

### 14.3 Makefile 快捷命令

```makefile
# Performance Testing Makefile

.PHONY: perf-env-up perf-env-down perf-data perf-test perf-regression perf-report

PERF_ENV ?= perf-test
TARGET ?= https://perf-test.primetop.com
SCENARIO ?= pt-001

# 启动压测环境
perf-env-up:
	docker compose -f docker-compose.perf.yml up -d
	@echo "Waiting for services to be ready..."
	@./scripts/wait-for-services.sh

# 关闭压测环境
perf-env-down:
	docker compose -f docker-compose.perf.yml down -v

# 生成测试数据
perf-data:
	python scripts/perf-data.py --users $(USERS)

# 执行指定场景
perf-test:
	k6 run --env TARGET=$(TARGET) scenarios/$(SCENARIO).js

# 执行冒烟测试
perf-smoke:
	k6 run --env TARGET=$(TARGET) --env VUS=50 --env DURATION=2m scenarios/$(SCENARIO)-smoke.js

# 执行全量P0场景
perf-all-p0:
	@for scenario in pt-001 pt-002 pt-003 pt-004 pt-005 pt-006 pt-007; do \
		echo "=== Running $$scenario ===" && \
		k6 run --env TARGET=$(TARGET) scenarios/$$scenario.js && \
		echo "=== $$scenario done ===" || exit 1 ; \
	done

# 回归检测
perf-regression:
	python scripts/perf-regression.py --baseline latest --report

# 性能门禁
perf-gate:
	python scripts/perf-gate.py --report regression-report.md

# 生成完整报告
perf-report:
	python scripts/perf-report-generator.py --date $(DATE)
```
