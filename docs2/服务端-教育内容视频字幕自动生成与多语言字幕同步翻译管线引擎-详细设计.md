# 服务端-教育内容视频字幕自动生成与多语言字幕同步翻译管线引擎-详细设计

## 1. 概述

### 1.1 模块定位

教育内容视频字幕自动生成与多语言字幕同步翻译管线引擎，是 PrimeTop 教育平台多媒体内容生产体系的核心子模块之一。该引擎负责将平台内的教育视频内容（知识点讲解、课程微课、实验演示等）自动转化为高精度的时间轴对齐字幕，并支持多语言字幕的同步翻译与分发。

### 1.2 业务目标

| 目标 | 描述 |
| --- | --- |
| 自动化字幕生成 | 对平台所有教育视频自动生成中文字幕，准确率 ≥ 95% |
| 多语言翻译 | 支持英、日、韩等主流语言的字幕自动翻译，可人工校对 |
| 教育术语精准识别 | 针对数学公式、化学方程式、物理定理等学科术语优化识别精度 |
| 字幕交付低延迟 | 字幕生成任务在视频上传后 30 分钟内完成 |
| 多端同步渲染 | 字幕文件支持 App、Web、小程序多端渲染，时间轴精确到 ±200ms |

### 1.3 适用范围

- 教育视频内容生产团队：批量字幕生成与校对
- 多语言内容运营：自动翻译字幕的审核与发布
- 客户端播放器：字幕数据消费与渲染
- 内容管理系统：字幕资产的版本管理

### 1.4 上下文关系

```
教育内容多媒体转码处理服务 ──┐
                              ├──▶ 字幕自动生成管线 ──▶ 字幕存储 ──▶ 客户端播放器
语音服务(ASR-TTS) ────────────┘            │
                                          ├──▶ 多语言翻译引擎 ──▶ 多语言字幕存储
教育学科术语词典 ──────────────────────────┘            │
                                                       └──▶ 字幕审核工作台
```

## 2. 数据结构定义

### 2.1 字幕轨道表 `subtitle_track`

一个视频可拥有多条字幕轨道（不同语言）。

```sql
CREATE TABLE subtitle_track (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    track_uuid      VARCHAR(36) NOT NULL UNIQUE COMMENT '字幕轨道唯一标识(UUID)',
    video_id        BIGINT NOT NULL COMMENT '关联视频内容ID',
    language_code   VARCHAR(10) NOT NULL COMMENT '语言代码: zh-CN, en-US, ja-JP, ko-KR',
    track_type      VARCHAR(20) NOT NULL COMMENT '轨道类型: full(完整字幕)/partial(仅关键词)',
    generation_type VARCHAR(20) NOT NULL COMMENT '生成方式: auto(自动)/manual(手动)/hybrid(混合)',
    status          VARCHAR(20) NOT NULL DEFAULT 'pending' COMMENT '状态: pending/processing/ready/review/published/failed',
    asr_model_version  VARCHAR(50) NULL COMMENT 'ASR模型版本号',
    translation_model_version VARCHAR(50) NULL COMMENT '翻译模型版本号',
    confidence_score   DECIMAL(5,4) NULL COMMENT '整体置信度评分(0-1)',
    word_count       INT NULL COMMENT '字幕总词数',
    duration_seconds INT NULL COMMENT '视频时长(秒)',
    created_by       BIGINT NULL COMMENT '创建者用户ID(自动生成则为系统)',
    reviewed_by      BIGINT NULL COMMENT '审核人员ID',
    created_at       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at       DATETIME NULL,
    INDEX idx_video_lang (video_id, language_code),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='字幕轨道表';
```

### 2.2 字幕条目表 `subtitle_cue`

每条字幕对应视频中的一个时间段落。

```sql
CREATE TABLE subtitle_cue (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT,
    cue_uuid        VARCHAR(36) NOT NULL UNIQUE COMMENT '字幕条目唯一标识',
    track_id        BIGINT NOT NULL COMMENT '关联字幕轨道ID',
    sequence_index  INT NOT NULL COMMENT '字幕序号(从1开始)',
    start_time_ms   INT NOT NULL COMMENT '开始时间(毫秒)',
    end_time_ms     INT NOT NULL COMMENT '结束时间(毫秒)',
    text            TEXT NOT NULL COMMENT '字幕文本内容(含标记)',
    text_plain      TEXT NULL COMMENT '纯文本版本(用于搜索)',
    speaker_label   VARCHAR(50) NULL COMMENT '说话人标签: teacher/student/narrator',
    is_key_term     BOOLEAN NOT NULL DEFAULT FALSE COMMENT '是否包含学科关键术语',
    key_terms       JSON NULL COMMENT '关键术语列表: [{"term":"勾股定理","start":0,"end":4}]',
    confidence      DECIMAL(5,4) NULL COMMENT '该条字幕的识别置信度',
    edit_status     VARCHAR(20) NOT NULL DEFAULT 'auto' COMMENT '编辑状态: auto/user_edited/verified',
    created_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX idx_track_seq (track_id, sequence_index),
    INDEX idx_time_range (track_id, start_time_ms, end_time_ms),
    CONSTRAINT fk_track FOREIGN KEY (track_id) REFERENCES subtitle_track(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='字幕条目表';
```

## 4. 核心处理流程

### 4.1 字幕生成全链路

```
视频上传完成
    │
    ▼
┌──────────────────────┐
│ 1. 音频提取与预处理    │  从视频中分离音频轨道
│    (FFmpeg)           │  降噪、音量归一化、重采样至16kHz
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 2. 语音活动检测(VAD)   │  检测语音段与非语音段
│    (Silero VAD)       │  生成语音片段列表
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 3. ASR 识别           │  调用语音识别引擎
│    (Paraformer/Whisper)│  输出: 文本 + 时间戳 + 置信度
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 4. 学科术语后处理      │  加载学科术语词典
│    (术语纠正与标注)     │  纠正ASR误识别的术语
│                       │  标注关键术语位置
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 5. 字幕分段与时间对齐  │  按语义和时长切分字幕条目
│    (智能分段)          │  每条 1-7 秒，最长 42 字符
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 6. 标点恢复与文本规范  │  补充标点、数字格式化
│                       │  数学公式 LaTeX 标记
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 7. 说话人分离(可选)    │  区分教师讲解/学生提问
│    (Speaker Diarization)│
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 8. 质量评估            │  计算整体置信度
│    (Confidence Scoring)│  标记低置信度条目
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 9. 入库 & 通知        │  字幕数据写入数据库
│                       │  通知内容审核团队
└──────────┬───────────┘
           │
           ▼ (若需多语言)
┌──────────────────────┐
│ 10. 多语言翻译        │  按字幕条目逐条翻译
│     (NMT Engine)      │  保持时间轴对齐
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 11. 翻译后处理        │  术语一致性校验
│     (Post-Editing)    │  时长适配(目标语言可能更长)
```


### 4.3 ASR 识别核心流程

```python
import asyncio
import logging
from dataclasses import dataclass
from typing import List, Optional

logger = logging.getLogger(__name__)


@dataclass
class AudioSegment:
    """音频片段"""
    start_ms: int
    end_ms: int
    audio_data: bytes
    sample_rate: int = 16000


@dataclass
class ASRResult:
    """单段ASR识别结果"""
    text: str
    start_ms: int
    end_ms: int
    confidence: float
    words: List[dict]  # 词级时间戳: [{"word": "勾股", "start": 100, "end": 300, "confidence": 0.98}]


class SubtitleASRPipeline:
    """字幕ASR识别管线"""

    def __init__(
        self,
        asr_provider: str = "paraformer",
        vad_model: str = "silero",
        term_dict_loader=None,
        max_segment_duration_ms: int = 7000,
        max_text_length: int = 42,
    ):
        self.asr_provider = asr_provider
        self.vad_model = vad_model
        self.term_dict_loader = term_dict_loader
        self.max_segment_duration_ms = max_segment_duration_ms
        self.max_text_length = max_text_length

    async def process_video_audio(
        self,
        audio_stream: bytes,
        video_id: int,
        language: str = "zh-CN",
        on_progress: Optional[callable] = None,
    ) -> List[ASRResult]:
        """
        完整的音频到字幕识别流程
        """
        # Step 1: 音频预处理
        logger.info(f"[video={video_id}] Starting audio preprocessing")
        processed_audio = await self._preprocess_audio(audio_stream)
        if on_progress:
            on_progress(10)

        # Step 2: 语音活动检测 (VAD)
        logger.info(f"[video={video_id}] Running VAD segmentation")
        segments = await self._detect_speech_segments(processed_audio)
        logger.info(f"[video={video_id}] VAD detected {len(segments)} speech segments")
        if on_progress:
            on_progress(25)

        # Step 3: ASR 识别
        logger.info(f"[video={video_id}] Running ASR recognition on {len(segments)} segments")
        raw_results = await self._run_asr_batch(segments, language)
        if on_progress:
            on_progress(60)

        # Step 4: 学科术语纠正
        logger.info(f"[video={video_id}] Applying term correction")
        corrected = await self._apply_term_correction(raw_results, video_id)
        if on_progress:
            on_progress(75)

        # Step 5: 智能分段与时间对齐
        logger.info(f"[video={video_id}] Segmenting and aligning")
        final_cues = self._segment_and_align(corrected)
        if on_progress:
            on_progress(90)

        # Step 6: 质量评估
        logger.info(f"[video={video_id}] Computing confidence scores")
        self._compute_confidence(final_cues)
        if on_progress:
            on_progress(100)

        return final_cues

    async def _preprocess_audio(self, raw_audio: bytes) -> bytes:
        """
        音频预处理: 转码至16kHz单声道WAV, 降噪, 音量归一化
        """
        # 使用FFmpeg进行音频预处理
        cmd = (
            f"ffmpeg -i pipe:0 -ar 16000 -ac 1 -af "
            f"loudnorm=I=-16:TP=-1.5:LRA=11,"
            f"highpass=f=80,lowpass=f=8000 "
            f"-f wav pipe:1"
        )
        proc = await asyncio.create_subprocess_shell(
            cmd,
            stdin=asyncio.subprocess.PIPE,
            stdout=asyncio.subprocess.PIPE,
            stderr=asyncio.subprocess.PIPE,
        )
        stdout, _ = await proc.communicate(raw_audio)
        return stdout

    async def _detect_speech_segments(self, audio: bytes) -> List[AudioSegment]:
        """
        使用 VAD 模型检测语音段，合并过短间隙( < 300ms)
        """
        # 调用 Silero VAD 或等效服务
        # 返回检测到的语音片段列表
        vad_service_url = self._get_vad_endpoint()
        # ... 调用 VAD 服务 ...
        # 合并间隙 < 300ms 的相邻段
        # 过滤时长 < 500ms 的极短段（噪声）
        segments = []  # 实际从VAD服务返回
        return self._merge_short_gaps(segments, max_gap_ms=300)

    async def _run_asr_batch(
        self,
        segments: List[AudioSegment],
        language: str,
    ) -> List[ASRResult]:
        """
        批量ASR识别, 支持并发调用
        """
        semaphore = asyncio.Semaphore(5)  # 限制并发数为5

        async def recognize_one(segment: AudioSegment) -> ASRResult:
            async with semaphore:
                return await self._call_asr_api(segment, language)

        tasks = [recognize_one(seg) for seg in segments]
        results = await asyncio.gather(*tasks, return_exceptions=True)

        # 过滤失败的识别
        valid_results = []
        for i, result in enumerate(results):
            if isinstance(result, Exception):
                logger.warning(f"ASR failed for segment {i}: {result}")
                # 用空文本占位，保留时间轴
                valid_results.append(ASRResult(
                    text="",
                    start_ms=segments[i].start_ms,
                    end_ms=segments[i].end_ms,
                    confidence=0.0,
                    words=[],
                ))
            else:
                valid_results.append(result)

        return valid_results

    async def _call_asr_api(self, segment: AudioSegment, language: str) -> ASRResult:
        """
        调用ASR服务API (Paraformer / Whisper / 自建模型)
        """
        if self.asr_provider == "paraformer":
            return await self._call_paraformer(segment, language)
        elif self.asr_provider == "whisper":
            return await self._call_whisper(segment, language)
        else:
            raise ValueError(f"Unknown ASR provider: {self.asr_provider}")

    async def _apply_term_correction(
        self,
        results: List[ASRResult],
        video_id: int,
    ) -> List[ASRResult]:
        """
        学科术语后处理纠正
        """
        if not self.term_dict_loader:
            return results

        # 加载该视频相关学科的术语词典
        term_dict = await self.term_dict_loader.get_terms_for_video(video_id)

        for result in results:
            original = result.text
            corrected, corrections = self._correct_terms(original, term_dict)
            if corrections:
                logger.info(
                    f"Term correction applied: {original} -> {corrected}, "
                    f"changes: {corrections}"
                )
                result.text = corrected
                # 术语纠正后提升置信度
                result.confidence = min(1.0, result.confidence + 0.05 * len(corrections))

        return results

    def _correct_terms(self, text: str, term_dict: dict) -> tuple:
        """
        基于术语词典的文本纠正
        返回: (纠正后文本, 纠正列表)
        """
        corrections = []
        corrected = text

        for wrong, right in term_dict.items():
            if wrong in corrected:
                corrected = corrected.replace(wrong, right)
                corrections.append({"from": wrong, "to": right})

        return corrected, corrections

    def _segment_and_align(self, results: List[ASRResult]) -> List[ASRResult]:
        """
        智能分段: 将ASR输出切分为适合字幕显示的段落
        规则:
        - 每条字幕 1-7 秒
        - 每条字幕不超过 max_text_length 个字符
        - 在标点符号或语义停顿处切分
        - 相邻字幕时间不重叠
        """
        cues = []

        for result in results:
            if not result.text.strip():
                # 空识别段直接作为间隙
                continue

            text = result.text
            duration = result.end_ms - result.start_ms

            # 如果文本短且时长合理，直接作为一条字幕
            if len(text) <= self.max_text_length and duration <= self.max_segment_duration_ms:
                cues.append(result)
                continue

            # 按标点和长度切分
            sub_segments = self._split_text(text, result.words)

            # 按词级时间戳重新分配时间
            for sub_text, sub_start, sub_end in sub_segments:
                cues.append(ASRResult(
                    text=sub_text.strip(),
                    start_ms=result.start_ms + sub_start,
                    end_ms=result.start_ms + sub_end if sub_end else duration,
                    confidence=result.confidence,
                    words=[],
                ))

        # 确保时间轴连续性
        return self._ensure_timeline_continuity(cues)

    def _split_text(self, text: str, words: List[dict]) -> List[tuple]:
        """
        按标点和长度切分文本
        返回: [(子文本, 相对开始ms, 相对结束ms), ...]
        """
        import re

        # 按中文标点切分: 。！？，；、
        sentences = re.split(r'([。！？，；、])', text)

        segments = []
        current = ""
        current_start = 0

        for i in range(0, len(sentences) - 1, 2):
            piece = sentences[i] + (sentences[i + 1] if i + 1 < len(sentences) else "")

            if len(current) + len(piece) <= self.max_text_length:
                current += piece
            else:
                if current:
                    segments.append((current, current_start, 0))
                current = piece
                current_start = 0  # 简化处理，实际应从words时间戳获取

        if current:
            segments.append((current, current_start, 0))

        return segments

    def _ensure_timeline_continuity(self, cues: List[ASRResult]) -> List[ASRResult]:
        """
        确保字幕时间轴连续, 消除间隙和重叠
        """
        if not cues:
            return cues

        aligned = []
        for i, cue in enumerate(cues):
            if i > 0:
                prev_end = aligned[-1].end_ms
                if cue.start_ms < prev_end:
                    # 重叠: 调整当前字幕开始时间
                    cue.start_ms = prev_end
                elif cue.start_ms - prev_end > 2000:
                    # 过大间隙: 可接受(表示无声区域)
                    pass

            aligned.append(cue)

        return aligned

    def _compute_confidence(self, cues: List[ASRResult]):
        """
        计算整体和单条字幕的置信度
        """
        for cue in cues:
            if cue.words:
                avg_word_conf = sum(w.get("confidence", 0.9) for w in cue.words) / len(cue.words)
                cue.confidence = round(avg_word_conf, 4)

    def _merge_short_gaps(
        self,
        segments: List[AudioSegment],
        max_gap_ms: int = 300,
    ) -> List[AudioSegment]:
        """合并间距小于 max_gap_ms 的相邻语音段"""
        if len(segments) <= 1:
            return segments

        merged = [segments[0]]
        for seg in segments[1:]:
            prev = merged[-1]
            gap = seg.start_ms - prev.end_ms
            if gap <= max_gap_ms:
                # 合并
                prev.end_ms = seg.end_ms
                prev.audio_data = prev.audio_data + seg.audio_data
            else:
                merged.append(seg)

        return merged

    def _get_vad_endpoint(self) -> str:
        return "http://vad-service.internal:8501/v1/detect"
```

### 4.4 多语言字幕翻译流程

```python
class SubtitleTranslationPipeline:
    """字幕多语言翻译管线"""

    def __init__(
        self,
        nmt_provider: str = "internal",
        max_chars_per_line: int = 35,
        terminology_glossary: dict = None,
    ):
        self.nmt_provider = nmt_provider
        self.max_chars_per_line = max_chars_per_line
        self.terminology_glossary = terminology_glossary or {}

    async def translate_track(
        self,
        source_cues: List[dict],
        source_lang: str,
        target_lang: str,
        subject: str = None,
    ) -> List[dict]:
        """
        翻译整条字幕轨道
        保持时间轴不变，仅翻译文本
        """
        # Step 1: 提取所有文本，构建翻译批次
        texts = [cue["text"] for cue in source_cues]

        # Step 2: 加载学科术语词汇表（双向）
        glossary = self._load_glossary(source_lang, target_lang, subject)

        # Step 3: 批量翻译 (保持上下文连贯)
        translated_texts = await self._batch_translate_with_context(
            texts,
            source_lang,
            target_lang,
            glossary,
        )

        # Step 4: 翻译后处理
        result_cues = []
        for orig, translated in zip(source_cues, translated_texts):
            # 时长适配: 目标语言文本长度可能超过源语言
            duration_ms = orig["end_time_ms"] - orig["start_time_ms"]
            adapted_text = self._adapt_text_length(translated, duration_ms)

            result_cues.append({
                **orig,
                "text": adapted_text,
                "source_text": orig["text"],
                "translation_confidence": translated.get("confidence", 0.85),
            })

        return result_cues

    async def _batch_translate_with_context(
        self,
        texts: List[str],
        source_lang: str,
        target_lang: str,
        glossary: dict,
    ) -> List[dict]:
        """
        带上下文的批量翻译
        将相邻字幕合并为段落翻译，保持语义连贯
        """
        BATCH_SIZE = 10  # 每批翻译10条字幕
        results = [None] * len(texts)

        for i in range(0, len(texts), BATCH_SIZE):
            batch = texts[i:i + BATCH_SIZE]

            # 构建带上下文的翻译prompt
            prompt = self._build_translation_prompt(
                batch, source_lang, target_lang, glossary
            )

            # 调用翻译引擎
            translated = await self._call_nmt(prompt)

            # 对齐翻译结果到原批次
            for j, trans in enumerate(translated):
                results[i + j] = {
                    "text": trans,
                    "confidence": 0.85,  # 翻译引擎置信度
                }

        return results

    def _build_translation_prompt(
        self,
        sentences: List[str],
        source_lang: str,
        target_lang: str,
        glossary: dict,
    ) -> str:
        """
        构建翻译Prompt，包含学科术语约束
        """
        lang_map = {
            "en-US": "English",
            "ja-JP": "Japanese",
            "ko-KR": "Korean",
            "zh-CN": "Simplified Chinese",
        }

        source_name = lang_map.get(source_lang, source_lang)
        target_name = lang_map.get(target_lang, target_lang)

        prompt = (
            f"Translate the following {source_name} educational subtitle sentences "
            f"into {target_name}. Maintain educational accuracy.\n\n"
        )

        if glossary:
            prompt += "Use these terminology translations:\n"
            for src_term, tgt_term in glossary.items():
                prompt += f"  {src_term} → {tgt_term}\n"
            prompt += "\n"

        prompt += "Sentences to translate (one per line):\n"
        for i, s in enumerate(sentences):
            prompt += f"{i + 1}. {s}\n"

        prompt += (
            f"\nOutput ONLY the translated sentences, one per line, "
            f"numbered identically. Keep each line under {self.max_chars_per_line} characters."
        )

        return prompt

    def _adapt_text_length(self, text: str, duration_ms: int) -> str:
        """
        根据字幕显示时长适配文本长度
        规则: 中文 5字/秒, 英文 3词/秒
        """
        if duration_ms <= 0:
            return text

        max_chars = max(7, int(duration_ms / 1000 * 8))  # 宽松限制

        if len(text) <= max_chars:
            return text

        # 截断并添加省略号
        return text[:max_chars - 1] + "…"

    def _load_glossary(self, source_lang: str, target_lang: str, subject: str) -> dict:
        """加载学科术语双语对照表"""
        if not subject:
            return {}

        # 从术语词典加载
        # 示例: 数学 zh→en
        glossaries = {
            "math:zh-CN:en-US": {
                "勾股定理": "Pythagorean theorem",
                "三角形": "triangle",
                "函数": "function",
                "导数": "derivative",
                "积分": "integral",
            },
            "physics:zh-CN:en-US": {
                "牛顿运动定律": "Newton's laws of motion",
                "电磁感应": "electromagnetic induction",
                "能量守恒": "conservation of energy",
            },
        }

        key = f"{subject}:{source_lang}:{target_lang}"
        return glossaries.get(key, {})
```

```python
class SubtitleQualityEvaluator:
    """字幕质量评估器"""

    def evaluate(self, cues: List[dict], video_metadata: dict) -> dict:
        """
        多维度质量评估
        """
        return {
            "cer_score": self._compute_cer(cues),           # 字错率
            "coverage_ratio": self._compute_coverage(cues, video_metadata),  # 语音覆盖率
            "avg_confidence": self._avg_confidence(cues),    # 平均置信度
            "low_confidence_ratio": self._low_conf_ratio(cues),  # 低置信度比例
            "term_accuracy": self._term_accuracy(cues),      # 术语准确率
            "timing_quality": self._timing_quality(cues),    # 时间轴质量
            "overall_score": 0,                              # 综合评分
            "recommendation": "",                            # 处理建议
        }

    def _compute_cer(self, cues: List[dict]) -> float:
        """计算字错率（需要人工标注的参考文本对比）"""
        # CER = (S + D + I) / N
        # S=替换, D=删除, I=插入, N=参考文本总字数
        # 如无参考文本，则使用置信度估算
        avg_conf = self._avg_confidence(cues)
        estimated_cer = 1.0 - avg_conf
        return round(estimated_cer, 4)

    def _compute_coverage(self, cues: List[dict], meta: dict) -> float:
        """语音覆盖率: 字幕覆盖时长 / 视频总时长"""
        video_duration = meta.get("duration_seconds", 0) * 1000
        if video_duration <= 0:
            return 0.0

        subtitle_duration = sum(
            c["end_time_ms"] - c["start_time_ms"] for c in cues
        )
        return round(min(1.0, subtitle_duration / video_duration), 4)

    def _timing_quality(self, cues: List[dict]) -> dict:
        """时间轴质量检测"""
        issues = []

        for i, cue in enumerate(cues):
            duration = cue["end_time_ms"] - cue["start_time_ms"]

            # 检查: 单条字幕过短
            if duration < 500:
                issues.append({"cue_index": i, "type": "too_short", "duration_ms": duration})

            # 检查: 单条字幕过长
            if duration > 10000:
                issues.append({"cue_index": i, "type": "too_long", "duration_ms": duration})

            # 检查: 时间重叠
            if i > 0 and cue["start_time_ms"] < cues[i - 1]["end_time_ms"]:
                issues.append({
                    "cue_index": i,
                    "type": "overlap",
                    "overlap_ms": cues[i - 1]["end_time_ms"] - cue["start_time_ms"]
                })

            # 检查: 字幕文本过长
            if len(cue["text"]) > 42:
                issues.append({"cue_index": i, "type": "text_too_long", "length": len(cue["text"])})

        return {
            "total_issues": len(issues),
            "issues": issues[:20],  # 返回前20个问题
            "quality_score": max(0, 1.0 - len(issues) / max(len(cues), 1)),
        }
```

## 9. 安全与合规

### 9.1 内容安全

- ASR 识别出的文本需经过敏感词过滤中间件处理
- 翻译结果需经过目标语言的内容安全校验
- 字幕内容遵循与教育内容一致的安全标准

### 9.2 版权保护

- 自动生成的字幕版权归平台所有
- 字幕文件添加不可见水印（零宽字符标记）
- API 接口进行鉴权和防爬虫处理

### 9.3 数据隐私

- 视频中如包含学生声音（如互动课程），需脱敏处理
- 说话人识别仅区分角色（教师/学生），不关联具体用户身份
- 字幕审核日志保留 6 个月

### 10.1 任务队列与调度

字幕生成任务使用 Redis 有序集合实现优先级队列：

```python
class SubtitleTaskQueue:
    """字幕生成任务优先级队列"""

    QUEUE_KEY = "subtitle:task_queue"
    PROCESSING_KEY = "subtitle:processing"

    async def enqueue(self, task: dict, priority: int = 5):
        """入队"""
        score = self._compute_score(priority, task["created_at"])
        await redis.zadd(self.QUEUE_KEY, {task["task_uuid"]: score})

    async def dequeue(self, worker_id: str) -> Optional[dict]:
        """出队（原子操作）"""
        # 使用 Lua 脚本保证原子性
        lua_script = """
        local task = redis.call('ZRANGE', KEYS[1], 0, 0)
        if #task > 0 then
            redis.call('ZREM', KEYS[1], task[1])
            redis.call('HSET', KEYS[2], task[1], ARGV[1])
            return task[1]
        end
        return nil
        """
        task_uuid = await redis.eval(lua_script, 2, self.QUEUE_KEY, self.PROCESSING_KEY, worker_id)
        if task_uuid:
            return await self.db.get_task(task_uuid)
        return None

    def _compute_score(self, priority: int, created_at: float) -> float:
        """
        计算优先级分数: priority * 1e10 + timestamp
        确保高优先级任务先出队，同优先级按时间先后
        """
        return priority * 1e10 + created_at
```

```protobuf
package primetop.subtitle.v1;

service SubtitleService {
  // 生成字幕
```
