# 服务端-知识追踪模型引擎与学生能力动态评估服务-详细设计

## 1. 模块概述

### 1.1 功能定位

知识追踪模型引擎（Knowledge Tracing Engine, 简称 KTE）是 PrimeTop 学习数据体系的核心算法基座。它基于学生历史答题行为、学习时长、交互频次等多源信号，**实时计算每个学生在每个知识点上的掌握概率（mastery probability）**，为下游服务（个性化推荐、薄弱点诊断、学习路径规划、学情报告等）提供统一、权威、可解释的能力评估数据。

### 1.2 核心职责

| 职责 | 说明 |
|------|------|
| 掌握度计算 | 基于知识追踪算法计算学生-知识点对的掌握概率 |
| 能力值估计 | 基于 IRT 模型估计学生综合学科能力值（θ） |
| 实时增量更新 | 每次答题/学习行为后即时更新相关知识点掌握度 |
| 批量重算 | 定期全量重算，修正累积误差 |
| 冷启动评估 | 新用户通过入学测试或冷启动策略快速建立初始画像 |
| 置信度输出 | 提供掌握度估计的置信区间，辅助下游决策 |
| 模型参数管理 | 知识点级别的 slip/guess/转移概率参数的自动拟合 |

### 1.4 设计原则

1. **算法可解释**：掌握度变化必须可追溯至具体行为事件，避免黑盒
2. **实时优先**：单次答题后掌握度更新延迟 ≤ 500ms
3. **最终一致**：增量更新与批量重算结合，容忍短暂时延
4. **降级可用**：模型不可用时退化为基础正确率统计
5. **参数自进化**：slip/guess 等参数随数据积累自动拟合校准

## 3. 核心算法设计

### 3.1 贝叶斯知识追踪（BKT）— 基础模型

#### 3.1.1 算法原理

BKT 将知识点掌握建模为隐马尔可夫模型（HMM）的二值隐状态：

```
状态空间: {未掌握 (0), 已掌握 (1)}
观察空间: {答对 (1), 答错 (0)}

参数:
    P(L0)  = 初始已掌握概率    p_known_init
    P(T)   = 学习转移概率      p_transit（未掌握→已掌握）
    P(S)   = 失误概率          p_slip（已掌握→答错）
    P(G)   = 猜对概率          p_guess（未掌握→答对）
```

#### 3.1.2 更新公式

**每次答题后的贝叶斯更新：**

```
Step 1 — 观察（答对时）:
    P(L_t | correct) = P(L_t) × (1 - P(S)) / [P(L_t) × (1 - P(S)) + (1 - P(L_t)) × P(G)]

Step 2 — 观察（答错时）:
    P(L_t | wrong) = P(L_t) × P(S) / [P(L_t) × P(S) + (1 - P(L_t)) × (1 - P(G))]

Step 3 — 转移（学习发生）:
    P(L_{t+1}) = P(L_t | obs) + (1 - P(L_t | obs)) × P(T)

结果 P(L_{t+1}) 即为更新后的掌握概率
```

#### 3.1.3 Java 实现

```java
/**
 * BKT 单步更新
 * 
 * @param currentMastery 当前掌握概率 P(L_t)
 * @param isCorrect      本次答题是否正确
 * @param params         知识点 BKT 参数
 * @return 更新后的掌握概率 P(L_{t+1})
 */
public BigDecimal bktUpdate(BigDecimal currentMastery, boolean isCorrect, BktParams params) {
    BigDecimal one = BigDecimal.ONE;
    BigDecimal pL = currentMastery;
    BigDecimal pNotL = one.subtract(pL);
    
    BigDecimal pObsGivenL, pObsGivenNotL;
    
    if (isCorrect) {
        // P(correct | L) = 1 - P(S)
        pObsGivenL = one.subtract(params.getPSlip());
        // P(correct | not L) = P(G)
        pObsGivenNotL = params.getPGuess();
    } else {
        // P(wrong | L) = P(S)
        pObsGivenL = params.getPSlip();
        // P(wrong | not L) = 1 - P(G)
        pObsGivenNotL = one.subtract(params.getPGuess());
    }
    
    // Step 1-2: 观察更新
    BigDecimal numerator = pL.multiply(pObsGivenL);
    BigDecimal denominator = numerator.add(pNotL.multiply(pObsGivenNotL));
    BigDecimal pLObs = numerator.divide(denominator, 5, RoundingMode.HALF_UP);
    
    // Step 3: 转移更新
    BigDecimal pLNext = pLObs.add(one.subtract(pLObs).multiply(params.getPTransit()));
    
    // Clamp to [0.001, 0.999] 避免饱和
    pLNext = pLNext.max(new BigDecimal("0.001")).min(new BigDecimal("0.999"));
    
    return pLNext;
}
```

#### 3.1.4 扩展：带提示和多次尝试的 BKT

当学生在答题过程中使用了提示（hint），或同一题尝试了多次，需要对标准 BKT 进行调整：

```java
/**
 * 带元数据的 BKT 更新
 * 
 * @param meta 包含 hint_used, attempt_count, response_time_ms
 */
public BigDecimal bktUpdateWithMeta(BigDecimal currentMastery, boolean isCorrect, 
                                     BktParams params, AttemptMeta meta) {
    // 调整猜对概率：使用提示降低"真实答对"的信息量
    BigDecimal adjustedGuess = params.getPGuess();
    BigDecimal adjustedSlip = params.getPSlip();
    
    if (meta.isHintUsed()) {
        // 使用提示时，答对的猜对概率提高（可能是靠提示答对的）
        adjustedGuess = adjustedGuess.add(new BigDecimal("0.10")).min(new BigDecimal("0.45"));
    }
    
    if (meta.getAttemptCount() > 1) {
        // 多次尝试后答对，学习信号减弱
        BigDecimal decay = BigDecimal.ONE.divide(
            new BigDecimal(meta.getAttemptCount()), 5, RoundingMode.HALF_UP);
        adjustedGuess = adjustedGuess.add(new BigDecimal("0.05").multiply(decay));
    }
    
    // 响应时间异常长（可能是猜的或搜索了答案）
    if (meta.getResponseTimeMs() != null && meta.getResponseTimeMs() > 120_000) {
        adjustedGuess = adjustedGuess.add(new BigDecimal("0.05"));
    }
    
    BktParams adjusted = BktParams.builder()
        .pKnownInit(params.getPKnownInit())
        .pTransit(params.getPTransit())
        .pSlip(adjustedSlip)
        .pGuess(adjustedGuess.min(new BigDecimal("0.49")))  // 不超过 0.49
        .build();
    
    return bktUpdate(currentMastery, isCorrect, adjusted);
}
```

### 3.2 深度知识追踪（DKT）— 进阶模型

#### 3.2.1 适用场景

当单个知识点累积答题数据超过 **200 条**时，可切换至 DKT 模型进行更精细的预测。DKT 使用 LSTM/GRU 序列模型，能捕获更丰富的时序模式。

#### 3.2.2 架构设计

```
输入序列: [(kp_id, is_correct, timestamp), ...]  最近 N=100 次
    │
    ▼
Embedding Layer: kp_id → 128维, (is_correct, time_delta) → 32维
    │
    ▼
Concat → 160维
    │
    ▼
LSTM Layer 1 (hidden=128, dropout=0.3)
    │
    ▼
LSTM Layer 2 (hidden=64, dropout=0.3)
    │
    ▼
Dense + Sigmoid → 输出每个知识点的掌握概率 [0,1]
```

#### 3.2.3 训练数据生成

```python
# 训练数据从 kte_attempt_event 表构建
def build_dkt_dataset(user_id, subject_code, window_size=100):
    """构建 DKT 训练样本"""
    events = load_events(user_id, subject_code, limit=5000)
    # 按 knowledge_point 分组
    kp_set = set(e.kp_id for e in events)
    
    samples = []
    for i in range(window_size, len(events)):
        # 输入: 前 window_size 次答题序列
        input_seq = events[i-window_size:i]
        # 标签: 第 i 次答题是否正确
        label = (events[i].kp_id, events[i].is_correct)
        samples.append((encode_sequence(input_seq, kp_set), label))
    
    return samples

def encode_sequence(events, kp_set):
    """将事件序列编码为模型输入"""
    encoded = []
    for e in events:
        kp_embed = one_hot(e.kp_id, kp_set)  # 知识点 one-hot
        interaction = [1, 0] if e.is_correct else [0, 1]  # (correct, wrong)
        time_delta = normalize_time(e.time_since_last)  # 归一化时间间隔
        encoded.append(kp_embed + interaction + [time_delta])
    return np.array(encoded)
```

#### 3.2.4 在线推理与 BKT 的融合

```java
/**
 * 模型融合：BKT 与 DKT 的加权组合
 * 数据量少时以 BKT 为主，数据量大时增加 DKT 权重
 */
public BigDecimal fusedMastery(Long userId, Long kpId) {
    BigDecimal bktResult = bktService.computeMastery(userId, kpId);
    
    int attemptCount = attemptService.countAttempts(userId, kpId);
    
    if (attemptCount < DKT_THRESHOLD) {  // 阈值: 200
        return bktResult;
    }
    
    BigDecimal dktResult = dktService.predict(userId, kpId);
    
    // 动态权重：数据量越大，DKT 权重越高
    double dktWeight = Math.min(0.7, (attemptCount - 200.0) / 1000.0 * 0.7);
    double bktWeight = 1.0 - dktWeight;
    
    return bktResult.multiply(BigDecimal.valueOf(bktWeight))
           .add(dktResult.multiply(BigDecimal.valueOf(dktWeight)));
}
```

### 3.3 项目反应理论（IRT）— 能力估计

#### 3.3.1 2PL 模型（二参数逻辑斯蒂克模型）

用于估计学生在特定学科上的综合能力值 θ：

```
P(answer_correct | θ) = 1 / (1 + exp(-a × (θ - b)))

a = 题目区分度 (discrimination)
b = 题目难度   (difficulty)
θ = 学生能力值 (latent ability, 通常范围 [-3, +3])
```

#### 3.3.2 θ 值估计：贝叶斯后验估计

```java
/**
 * 基于学生最近 N 次答题记录，使用 MLE + 先验估计 θ 值
 * 
 * @param responses List<(a, b, isCorrect)> 最近答题记录
 * @return 能力值 θ 及标准误 SE
 */
public AbilityEstimate estimateTheta(List<ItemResponse> responses) {
    // 使用 Newton-Raphson 迭代求解 MLE
    double theta = 0.0;  // 初始值
    double learningRate = 0.01;
    int maxIter = 100;
    double tolerance = 1e-6;
    
    // 加入正态先验 N(0, 1) 防止极端值
    double priorMean = 0.0;
    double priorSd = 1.0;
    
    for (int iter = 0; iter < maxIter; iter++) {
        double gradient = 0.0;
        double hessian = 0.0;
        
        for (ItemResponse r : responses) {
            double a = r.getDiscrimination();
            double b = r.getDifficulty();
            double p = 1.0 / (1.0 + Math.exp(-a * (theta - b)));
            
            // 对数似然的梯度（一阶导）
            gradient += a * ( (r.isCorrect() ? 1 : 0) - p );
            
            // 对数似然的 Hessian（二阶导）
            hessian -= a * a * p * (1 - p);
        }
        
        // 加入先验项的梯度
        gradient -= (theta - priorMean) / (priorSd * priorSd);
        hessian  -= 1.0 / (priorSd * priorSd);
        
        // Newton-Raphson 更新
        if (Math.abs(hessian) < 1e-10) break;
        double delta = gradient / Math.abs(hessian);
        theta += learningRate * delta;
        
        // Clamp θ 范围
        theta = Math.max(-3.0, Math.min(3.0, theta));
        
        if (Math.abs(delta) < tolerance) break;
    }
    
    // 计算标准误
    double se = computeStandardError(theta, responses);
    
    return new AbilityEstimate(theta, se);
}

private double computeStandardError(double theta, List<ItemResponse> responses) {
    double info = 0.0;
    for (ItemResponse r : responses) {
        double a = r.getDiscrimination();
        double b = r.getDifficulty();
        double p = 1.0 / (1.0 + Math.exp(-a * (theta - b)));
        double q = 1.0 - p;
        // Fisher 信息量
        info += a * a * p * q;
    }
    // 信息量的倒数 = 估计方差的近似
    return info > 0 ? 1.0 / Math.sqrt(info) : 1.0;
}
```

#### 3.3.3 θ 值与掌握度的映射

```java
/**
 * 将 IRT θ 值映射为指定知识点的掌握概率
 * 结合知识点难度 b 和学生能力 θ
 */
public BigDecimal thetaToMastery(double theta, double kpDifficulty) {
    // 使用 2PL 模型：在难度等于知识点难度的题目上答对的概率
    double p = 1.0 / (1.0 + Math.exp(-(theta - kpDifficulty)));
    return BigDecimal.valueOf(p).setScale(5, RoundingMode.HALF_UP);
}
```

### 3.4 置信度模型

掌握度估计的置信度取决于数据量和数据质量：

```java
/**
 * 计算掌握度置信度 [0, 1]
 */
public BigDecimal computeConfidence(int totalAttempts, int daysSinceFirst, 
                                      double avgResponseTimeMs, double consistencyScore) {
    // 因子1: 数据量（对数增长，50次后基本饱和）
    double volumeScore = 1.0 - Math.exp(-totalAttempts / 20.0);
    
    // 因子2: 时间跨度（跨度越长，评估越稳定）
    double spanScore = Math.min(1.0, daysSinceFirst / 30.0);
    
    // 因子3: 一致性（答题表现是否波动大）
    // consistencyScore 由近期答题的正确率方差计算得出
    double consistScore = Math.max(0, Math.min(1.0, consistencyScore));
    
    // 加权组合
    double confidence = 0.5 * volumeScore + 0.2 * spanScore + 0.3 * consistScore;
    
    return BigDecimal.valueOf(confidence).setScale(3, RoundingMode.HALF_UP);
}
```

```java
/**
 * 实时掌握度更新 — 核心服务方法
 */
@Service
public class MasteryUpdateService {
    
    @Autowired private MasteryCacheService cacheService;
    @Autowired private KpParamService paramService;
    @Autowired private AttemptEventRepository eventRepo;
    @Autowired private KafkaTemplate<String, Object> kafka;
    
    private static final int CACHE_TTL_SECONDS = 7 * 24 * 3600;
    
    /**
     * 处理单次答题事件，更新掌握度
     * 目标延迟: P99 < 500ms
     */
    @Timed(value = "kte.mastery.update", percentiles = {0.5, 0.95, 0.99})
    public MasteryUpdateResult updateMastery(AttemptEventDTO dto) {
        long start = System.nanoTime();
        
        // 1. 获取当前掌握度（先查缓存，再查DB）
        BigDecimal currentMastery = cacheService.getMastery(dto.getUserId(), dto.getKpId());
        if (currentMastery == null) {
            currentMastery = loadFromDb(dto.getUserId(), dto.getKpId());
        }
        
        // 2. 获取知识点 BKT 参数
        BktParams params = paramService.getParams(dto.getKpId());
        
        // 3. 执行 BKT 更新
        AttemptMeta meta = new AttemptMeta(
            dto.isHintUsed(), dto.getAttemptCount(), dto.getResponseTimeMs()
        );
        BigDecimal newMastery = bktEngine.bktUpdateWithMeta(
            currentMastery, dto.isCorrect(), params, meta
        );
        
        // 4. 更新能力维度 θ 值（增量）
        AbilityUpdateResult abilityResult = abilityService.updateTheta(
            dto.getUserId(), dto.getSubjectCode(), dto
        );
        
        // 5. 计算置信度
        int totalAttempts = incrementAttemptCount(dto.getUserId(), dto.getKpId());
        BigDecimal confidence = confidenceCalculator.compute(totalAttempts, ...);
        
        // 6. 判定掌握状态
        int masteryStatus = MasteryStatus.fromProbability(newMastery);
        
        // 7. 写缓存
        cacheService.setMastery(dto.getUserId(), dto.getKpId(), 
            newMastery, masteryStatus, confidence, CACHE_TTL_SECONDS);
        
        // 8. 异步写DB（事件 + 掌握度）
        eventRepo.saveAsync(buildEventRecord(dto, currentMastery, newMastery));
        masteryRepo.updateAsync(dto.getUserId(), dto.getKpId(), 
            newMastery, masteryStatus, confidence);
        
        // 9. 发送 Kafka 事件（异步消费）
        kafka.send("kte-mastery-updated", MasteryUpdatedEvent.builder()
            .userId(dto.getUserId())
            .kpId(dto.getKpId())
            .subjectCode(dto.getSubjectCode())
            .masteryBefore(currentMastery)
            .masteryAfter(newMastery)
            .abilityAfter(abilityResult.getTheta())
            .build());
        
        long elapsed = (System.nanoTime() - start) / 1_000_000;
        log.debug("Mastery updated for user={} kp={} in {}ms", 
            dto.getUserId(), dto.getKpId(), elapsed);
        
        return MasteryUpdateResult.builder()
            .masteryBefore(currentMastery)
            .masteryAfter(newMastery)
            .masteryChange(newMastery.subtract(currentMastery))
            .masteryStatus(masteryStatus)
            .abilityTheta(abilityResult.getTheta())
            .confidence(confidence)
            .build();
    }
}
```

### 5.4 BKT 参数 EM 拟合

```java
/**
 * Expectation-Maximization 算法拟合 BKT 四参数
 * 基于大量学生的答题序列数据
 */
public BktParams fitParams(Long kpId, List<LearnerSequence> sequences) {
    // 初始化参数
    double pInit = 0.1, pTransit = 0.15, pSlip = 0.1, pGuess = 0.25;
    double prevLogLikelihood = Double.NEGATIVE_INFINITY;
    
    for (int iter = 0; iter < MAX_EM_ITERATIONS; iter++) {  // 通常 50-100 次
        // E-Step: 给定当前参数，计算每个序列每个时刻的后验概率
        double totalLogLik = 0;
        double[][] expectedStats = new double[4][2]; 
        // [0]=P(L0)期望, [1]=P(T)期望, [2]=P(S)期望, [3]=P(G)期望
        
        for (LearnerSequence seq : sequences) {
            ForwardBackwardResult fb = forwardBackward(seq, pInit, pTransit, pSlip, pGuess);
            totalLogLik += fb.getLogLikelihood();
            accumulateExpectedStats(expectedStats, fb, seq);
        }
        
        // M-Step: 更新参数
        pInit    = expectedStats[0][0] / sequences.size();
        pTransit = expectedStats[1][0] / (expectedStats[1][0] + expectedStats[1][1]);
        pSlip    = expectedStats[2][0] / (expectedStats[2][0] + expectedStats[2][1]);
        pGuess   = expectedStats[3][0] / (expectedStats[3][0] + expectedStats[3][1]);
        
        // 约束: 防止参数退化
        pInit    = clamp(pInit, 0.01, 0.5);
        pTransit = clamp(pTransit, 0.01, 0.5);
        pSlip    = clamp(pSlip, 0.01, 0.35);
        pGuess   = clamp(pGuess, 0.01, 0.45);
        
        // 收敛判断
        if (totalLogLik - prevLogLikelihood < CONVERGENCE_THRESHOLD) break;
        prevLogLikelihood = totalLogLik;
    }
    
    return BktParams.builder()
        .pKnownInit(BigDecimal.valueOf(pInit))
        .pTransit(BigDecimal.valueOf(pTransit))
        .pSlip(BigDecimal.valueOf(pSlip))
        .pGuess(BigDecimal.valueOf(pGuess))
        .paramSource(2)  // 数据拟合
        .sampleSize(sequences.size())
        .paramConfidence(computeParamConfidence(sequences.size(), prevLogLikelihood))
        .modelVersion("v1.0")
        .lastFittedAt(LocalDateTime.now())
        .build();
}
```

### 6.2 维度分数计算

```java
/**
 * 计算学生某学科各维度能力分数
 * 
 * 维度分数 = 该维度下所有已接触知识点的加权平均掌握度
 */
public List<DimensionScore> computeDimensionScores(Long userId, String subjectCode) {
    List<AbilityDimension> dimensions = dimensionConfig.get(subjectCode);
    
    List<DimensionScore> result = new ArrayList<>();
    for (AbilityDimension dim : dimensions) {
        // 获取该维度下所有知识点
        List<Long> kpIds = knowledgePointService.getKpIdsByDimension(subjectCode, dim.getCode());
        
        // 获取掌握度
        List<KnowledgeMastery> masteries = masteryRepo.findByUserAndKps(userId, kpIds);
        
        // 过滤掉未接触的
        List<KnowledgeMastery> attempted = masteries.stream()
            .filter(m -> m.getTotalAttempts() > 0)
            .collect(Collectors.toList());
        
        if (attempted.isEmpty()) {
            result.add(new DimensionScore(dim.getCode(), dim.getName(), 0.0, dim.getWeight(), 0));
            continue;
        }
        
        // 加权平均（知识点难度作为权重，高难度知识点权重略高）
        double weightedSum = 0;
        double totalWeight = 0;
        for (KnowledgeMastery m : attempted) {
            double w = 1.0; // 基础权重
            weightedSum += m.getMasteryProb().doubleValue() * w;
            totalWeight += w;
        }
        
        double score = weightedSum / totalWeight;
        result.add(new DimensionScore(dim.getCode(), dim.getName(), score, dim.getWeight(), attempted.size()));
    }
    
    return result;
}
```

### 7.2 CAT 自适应测试逻辑

```java
/**
 * Computerized Adaptive Testing - 基于 IRT 的自适应出题
 * 
 * 核心思想: 每次选择最能降低当前能力估计不确定性的题目
 */
@Service
public class CatTestEngine {
    
    private static final int MAX_QUESTIONS = 20;
    private static final int MIN_QUESTIONS = 8;
    private static final double STOP_THRESHOLD_SE = 0.25;  // SE 低于此值停止
    private static final int COLD_START_QUESTION_POOL = 500;
    
    /**
     * 选择下一道题（最大信息量原则）
     */
    public Long selectNextQuestion(CatTestState state) {
        double currentTheta = state.getCurrentTheta();
        Set<Long> usedQuestions = state.getUsedQuestionIds();
        
        // Fisher 信息量在 θ = b 处最大，选择难度最接近当前 θ 的题目
        List<QuestionItem> candidates = questionPool.getQuestionsForKps(
            state.getTargetKpIds(), COLD_START_QUESTION_POOL
        );
        
        QuestionItem best = null;
        double maxInfo = Double.NEGATIVE_INFINITY;
        
        for (QuestionItem q : candidates) {
            if (usedQuestions.contains(q.getId())) continue;
            
            // Fisher 信息量: I(θ) = a² × P(θ) × (1 - P(θ))
            double p = irtProbability(currentTheta, q.getDifficulty(), q.getDiscrimination());
            double info = q.getDiscrimination() * q.getDiscrimination() * p * (1 - p);
            
            // 多样性惩罚：避免同知识点连续出题
            if (q.getKpId().equals(state.getLastKpId())) {
                info *= 0.5;
            }
            
            if (info > maxInfo) {
                maxInfo = info;
                best = q;
            }
        }
        
        return best != null ? best.getId() : null;
    }
    
    /**
     * 判断是否应停止测试
     */
    public boolean shouldStop(CatTestState state) {
        if (state.getAnsweredCount() >= MAX_QUESTIONS) return true;
        if (state.getAnsweredCount() >= MIN_QUESTIONS 
            && state.getCurrentSE() < STOP_THRESHOLD_SE) return true;
        return false;
    }
    
    /**
     * 测试完成后初始化各知识点掌握度
     */
    public Map<Long, BigDecimal> initializeMasteryFromTheta(double theta, List<Long> kpIds) {
        Map<Long, BigDecimal> result = new HashMap<>();
        
        for (Long kpId : kpIds) {
            // 获取知识点难度
            KpParams params = paramService.getParams(kpId);
            double kpDifficulty = params.getIrtDifficulty();
            
            // 使用 2PL 模型映射
            double mastery = irtProbability(theta, kpDifficulty, 1.0);
            
            // 加入先验平滑
            mastery = 0.7 * mastery + 0.3 * params.getPKnownInit().doubleValue();
            
            result.put(kpId, BigDecimal.valueOf(mastery).setScale(5, RoundingMode.HALF_UP));
        }
        
        return result;
    }
}
```

### 8.2 遗忘衰减机制

```java
/**
 * 遗忘衰减定时任务（每日凌晨）
 * 对于长时间未复习的知识点，按遗忘曲线降低掌握度
 */
@Scheduled(cron = "0 30 2 * * ?")
public void forgettingDecay() {
    // 查找超过 14 天未接触的"基本掌握"和"熟练掌握"知识点
    List<KnowledgeMastery> stale = masteryRepo.findStaleMasteries(
        LocalDate.now().minusDays(14),
        Arrays.asList((short) 3, (short) 4)  // 基本掌握、熟练掌握
    );
    
    for (KnowledgeMastery m : stale) {
        long daysSinceLast = ChronoUnit.DAYS.between(
            m.getLastAttemptAt().toLocalDate(), LocalDate.now()
        );
        
        // 基于 Ebbinghaus 遗忘曲线的衰减
        // R = exp(-t / S)，S 为记忆稳定性（与掌握度正相关）
        double stability = 15.0 + m.getMasteryProb().doubleValue() * 30.0;
        double retentionRate = Math.exp(-(daysSinceLast - 14) / stability);
        
        BigDecimal decayedMastery = m.getMasteryProb()
            .multiply(BigDecimal.valueOf(retentionRate))
            .setScale(5, RoundingMode.HALF_UP);
        
        // 只在衰减幅度 > 0.05 时更新
        if (m.getMasteryProb().subtract(decayedMastery).compareTo(new BigDecimal("0.05")) > 0) {
            int newStatus = MasteryStatus.fromProbability(decayedMastery);
            masteryRepo.updateMasteryAndStatus(
                m.getUserId(), m.getKnowledgePointId(), 
                decayedMastery, newStatus
            );
            
            // 发送遗忘提醒事件
            eventPublisher.publishEvent(new MasteryDecayEvent(
                m.getUserId(), m.getKnowledgePointId(),
                m.getMasteryProb(), decayedMastery, daysSinceLast
            ));
        }
    }
}
```

```java
@Component
public class MasteryRateLimiter {
    
    // 每用户每分钟最多 60 次掌握度更新
    private static final int MAX_PER_MINUTE = 60;
    // 每用户每天最多 2000 次
    private static final int MAX_PER_DAY = 2000;

        String dayKey = "kte:rate:" + userId + ":day:" + LocalDate.now();
        
        Long minuteCount = redis.opsForValue().increment(minuteKey);
        if (minuteCount == 1) redis.expire(minuteKey, 60, TimeUnit.SECONDS);
        
        Long dayCount = redis.opsForValue().increment(dayKey);
        if (dayCount == 1) redis.expire(dayKey, 1, TimeUnit.DAYS);
        
        if (minuteCount > MAX_PER_MINUTE || dayCount > MAX_PER_DAY) {
            throw new BusinessException(30010, "答题事件频率异常，请稍后再试");
        }
    }
}
```

## 15. 边界条件与注意事项

### 15.1 数值边界

| 场景 | 处理方式 |
|------|---------|
| 掌握度 = 0 或 = 1（饱和） | Clamp 到 [0.001, 0.999]，保留更新空间 |
| P(guess) + P(slip) ≥ 1 | 参数非法，拒绝并告警 |
| 事件数据量 < 3 条 | 掌握度置信度极低（< 0.2），不参与排名/推荐 |
| θ 值超出 [-3, 3] | Clamp 到 [-3, 3] |
| 答题间隔 < 2 秒 | 判定为异常答题，降权处理（weight *= 0.3） |

### 15.2 多设备并发

```java
/**
 * 多设备同时提交答题事件时的并发控制
 * 使用 Redis 分布式锁保证用户-知识点级别的顺序一致性
 */
public MasteryUpdateResult updateMasterySafe(AttemptEventDTO dto) {
    String lockKey = "kte:lock:" + dto.getUserId() + ":" + dto.getKpId();
    
    try {
        // 获取锁（等待 500ms，持有 5s）
        boolean locked = redisLock.tryLock(lockKey, 500, 5000, TimeUnit.MILLISECONDS);
        if (!locked) {
            // 获取锁失败，放入异步队列延迟处理
            asyncQueue.offer(dto);
            return MasteryUpdateResult.deferred();
        }
        
        return updateMastery(dto);
        
    } finally {
        redisLock.unlock(lockKey);
    }
}
```

### 15.3 数据一致性保障

- **增量 vs 全量**：每日全量重算修正增量累积误差
- **缓存 vs DB**：写入时先写缓存再异步写DB，定期校验一致性
- **跨服务事件**：Kafka 消费幂等（基于 event_id 去重）

```java
/**
 * 幂等消费：基于 event_id 去重
 */
@KafkaListener(topics = "kte-mastery-updated")
public void onMasteryUpdated(MasteryUpdatedEvent event) {
    // 检查是否已处理过
    if (processedEventCache.exists(event.getEventId())) {
        log.debug("Duplicate event {} skipped", event.getEventId());
        return;
    }
    
    // 处理事件...
    processEvent(event);
    
    // 标记已处理（TTL 24h）
    processedEventCache.mark(event.getEventId(), 86400);
}
```
