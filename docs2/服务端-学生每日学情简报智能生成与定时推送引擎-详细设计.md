# 服务端 - 学生每日学情简报智能生成与定时推送引擎 详细设计

## 1. 概述

### 1.1 模块定位

每日学情简报是面向学生和家长推出的轻量级、高频次学情反馈产品形态。区别于周报、月报等深度学情分析报告，每日简报聚焦"当天学习行为的快速回顾与明日行动引导"，以卡片化、结构化、可分享的形式呈现，帮助学生建立学习仪式感、帮助家长快速了解孩子当天学习状况。

### 1.2 核心职责

| 职责 | 说明 |
| --- | --- |
| 学习数据当日聚合 | 从多模块（AI对话、练习、错题、同步课堂等）收集当日学习行为数据 |
| 简报内容智能生成 | 基于模板引擎 + AI 自然语言生成，输出个性化简报文案 |
| 多角色视图适配 | 学生版、家长版、教师版三种视图，内容和措辞各有侧重 |
| 定时推送投递 | 按用户配置的推送时段，通过多渠道（APP Push、微信、站内消息）推送 |
| 历史简报归档查询 | 按日/周/月归档，支持回溯查看与趋势对比 |
| 学习激励融入 | 在简报中自然嵌入成就解锁、连续打卡、进步鼓励等激励元素 |

### 2.2 数据库表结构

#### 2.2.1 `daily_brief_config` — 简报配置表

```sql
CREATE TABLE daily_brief_config (
    id              BIGINT       PRIMARY KEY AUTO_INCREMENT,
    user_id         BIGINT       NOT NULL COMMENT '用户ID',
    role_type       TINYINT      NOT NULL DEFAULT 1 COMMENT '角色: 1=学生 2=家长 4=教师',
    push_enabled    TINYINT      NOT NULL DEFAULT 1 COMMENT '是否开启推送',
    push_time       TIME         NOT NULL DEFAULT '20:30:00' COMMENT '推送时间(HH:mm:ss)',
    timezone        VARCHAR(32)  NOT NULL DEFAULT 'Asia/Shanghai' COMMENT '时区',
    channels        JSON         NOT NULL COMMENT '推送渠道 ["app_push","wechat","in_app"]',
    min_learning_minutes INT     NOT NULL DEFAULT 5 COMMENT '最小学习时长(分钟)，低于此不生成简报',
    template_version VARCHAR(16) NOT NULL DEFAULT 'v2' COMMENT '模板版本',
    language        VARCHAR(8)   NOT NULL DEFAULT 'zh-CN',
    enabled_modules JSON         NULL     COMMENT '启用的模块 ["ai_dialogue","practice","mistake","sync_class"]',
    parent_student_id BIGINT     NULL     COMMENT '家长角色的关联学生ID',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_role (user_id, role_type, parent_student_id),
    INDEX idx_push_time (push_time, push_enabled)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='每日学情简报配置';
```

#### 2.2.2 `daily_brief` — 简报主表

```sql
CREATE TABLE daily_brief (
    id                  BIGINT       PRIMARY KEY AUTO_INCREMENT,
    user_id             BIGINT       NOT NULL COMMENT '接收者用户ID',
    brief_date          DATE         NOT NULL COMMENT '简报日期',
    role_type           TINYINT      NOT NULL DEFAULT 1 COMMENT '接收者角色',
    config_id           BIGINT       NULL     COMMENT '关联配置ID',
    status              VARCHAR(16)  NOT NULL DEFAULT 'PENDING' COMMENT 'PENDING/GENERATING/READY/PUSHED/SKIPPED/FAILED',
    learning_duration_sec INT        NOT NULL DEFAULT 0 COMMENT '当日学习总时长(秒)',
    modules_involved    JSON         NOT NULL COMMENT '参与模块列表 ["ai_dialogue","practice",...]',
    brief_content       JSON         NOT NULL COMMENT '结构化简报内容(模板渲染数据)',
    nl_summary          TEXT         NULL     COMMENT 'AI生成的自然语言摘要',
    ai_generated_text   TEXT         NULL     COMMENT 'AI生成的完整文案(鼓励/建议)',
    achievement_ids     JSON         NULL     COMMENT '当日解锁成就ID列表',
    tomorrow_suggestion TEXT         NULL     COMMENT '明日学习建议',
    cover_image_url     VARCHAR(512) NULL     COMMENT '简报封面图URL',
    share_card_url      VARCHAR(512) NULL     COMMENT '分享卡片图URL',
    read_status         TINYINT      NOT NULL DEFAULT 0 COMMENT '0=未读 1=已读',
    read_at             DATETIME     NULL,
    generated_at        DATETIME     NULL     COMMENT '内容生成完成时间',
    pushed_at           DATETIME     NULL     COMMENT '推送完成时间',
    created_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_user_date_role (user_id, brief_date, role_type),
    INDEX idx_date_status (brief_date, status),
    INDEX idx_push_time (brief_date, status, pushed_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='每日学情简报';
```

#### 2.2.3 `daily_brief_module_data` — 简报模块明细表

```sql
CREATE TABLE daily_brief_module_data (
    id              BIGINT       PRIMARY KEY AUTO_INCREMENT,
    brief_id        BIGINT       NOT NULL COMMENT '关联简报ID',
    module_code     VARCHAR(32)  NOT NULL COMMENT '模块编码: ai_dialogue/practice/mistake/sync_class/essay/reading',
    module_name     VARCHAR(64)  NOT NULL COMMENT '模块显示名称',
    metrics         JSON         NOT NULL COMMENT '模块指标数据 {questions_count, correct_rate, duration_sec, ...}',
    highlights      JSON         NULL     COMMENT '亮点数据 {new_mistakes, mastered_points, streak_days, ...}',
    sort_order      INT          NOT NULL DEFAULT 0 COMMENT '排序顺序',
    created_at      DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_brief (brief_id),
    INDEX idx_module (brief_id, module_code)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='简报模块明细';
```

### 2.3 Redis 缓存设计

```
# 简报当日数据临时聚合缓存（按天滚动）
brief:daily_aggregate:{user_id}:{date} → Hash {
    "ai_dialogue_count": "12",
    "practice_count": "30",
    "correct_rate": "0.73",
    "mistake_new": "5",
    "sync_chapter": "第三章 第二节",
    "learning_duration_sec": "3600",
    "last_active_ts": "1721179200",
    ...
}
TTL: 48h

# 简报推送去重（防止重复推送）
brief:push_dedup:{user_id}:{date} → "1"
TTL: 25h

# 连续学习天数（streak）
brief:streak:{user_id} → "17"
TTL: 72h（无活动后自动过期）

# 简报内容缓存（已生成的简报）
brief:content:{user_id}:{date}:{role} → JSON string
TTL: 7d

# 推送时间轮询索引
brief:push_schedule:{HHmm} → SET of user_ids
TTL: 25h
```

## 3. API 接口设计

### 3.1 接口总览

| # | 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- | --- |
| 1 | 获取今日简报 | GET | `/api/v1/daily-brief/today` | 获取当前用户今日简报 |
| 2 | 获取历史简报 | GET | `/api/v1/daily-brief/list` | 分页查询历史简报列表 |

## 4. 简报生成流水线

### 4.1 整体流程

```
 ┌──────────────────────────────────────────────────────────────────────┐
 │                        定时调度触发 (每日各时段)                       │
 └──────────────────────────────┬───────────────────────────────────────┘
                                │
                                ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ Step 1: 扫描简报配置表，找出当前时段需推送的用户列表                    │
 │         SELECT user_id FROM daily_brief_config                         │
 │         WHERE push_enabled=1 AND push_time={当前时段}                   │
 └──────────────────────────────┬───────────────────────────────────────┘
                                │
                                ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ Step 2: 并行获取各模块当日学习数据（扇出）                              │
 │  ├── AI对话数据    ← ai_conversation_service / event_store             │
 │  ├── 练习答题数据  ← answer_record_service / practice_service           │
 │  ├── 错题数据      ← mistake_service                                    │
 │  ├── 同步课堂数据  ← sync_class_service / learning_progress_service     │
 │  ├── 作文辅导数据  ← essay_service (可选)                                │
 │  ├── 学习时长数据  ← learning_session_service                           │
 │  └── 成就/打卡数据 ← achievement_service / streak_service               │
 └──────────────────────────────┬───────────────────────────────────────┘
                                │
                                ▼
 ┌──────────────────────────────────────────────────────────────────────┐
 │ Step 3: 数据聚合与指标计算                                             │
```

### 4.2 数据聚合策略

#### 4.2.1 各模块数据源映射

#### 4.2.2 聚合方式

采用 **双轨聚合** 策略：

1. **实时增量聚合**（推荐主路径）：各业务模块在学习行为发生时，通过事件总线推送 `LearningActivityEvent`，简报引擎消费事件并增量更新 Redis Hash。生成时直接读取 Redis，无需查库。

2. **定时全量补全**（兜底路径）：对于事件丢失或延迟的场景，在生成简报前从各业务表执行一次补偿查询。

```java
// 实时事件消费示例
@KafkaListener(topics = "learning-activity-events")
public void onLearningActivity(LearningActivityEvent event) {
    String dateKey = LocalDate.now().format(YYYYMMDD);
    String redisKey = String.format("brief:daily_aggregate:%d:%s", event.getUserId(), dateKey);
    
    redisTemplate.opsForHash().increment(redisKey, "learning_duration_sec", event.getDurationSec());
    redisTemplate.opsForHash().increment(redisKey, event.getModuleCode() + "_count", 1);
    redisTemplate.opsForHash().put(redisKey, "last_active_ts", String.valueOf(Instant.now().getEpochSecond()));
    
    // 根据事件类型更新特定指标
    switch (event.getEventType()) {
        case "ANSWER_SUBMITTED":
            redisTemplate.opsForHash().increment(redisKey, "total_answers", 1);
            if (event.isCorrect()) {
                redisTemplate.opsForHash().increment(redisKey, "correct_answers", 1);
            }
            break;
        case "MISTAKE_ADDED":
            redisTemplate.opsForHash().increment(redisKey, "mistake_new", 1);
            break;
        case "MISTAKE_MASTERED":
            redisTemplate.opsForHash().increment(redisKey, "mistake_mastered", 1);
            break;
        // ... 其他事件类型
    }
    
    redisTemplate.expire(redisKey, Duration.ofHours(48));
}
```

```java
/**
 * 每日学情简报推送调度器
 * 每分钟执行一次，检查当前时间桶中的待推送用户
 */
@Component
@Slf4j
public class BriefPushScheduler {
    
    @Scheduled(cron = "0 * * * * ?") // 每分钟执行
    public void dispatchScheduledPush() {
        String timeBucket = LocalTime.now().format(DateTimeFormatter.ofPattern("HHmm"));
        String scheduleKey = "brief:push_schedule:" + timeBucket;
        
        // 获取当前时段需推送的用户列表
        Set<Object> userIds = redisTemplate.opsForSet().members(scheduleKey);
        if (CollectionUtils.isEmpty(userIds)) {
            return;
        }
        
        log.info("Brief push bucket {}: {} users", timeBucket, userIds.size());
        
        // 分批并行处理
        List<List<Object>> batches = partition(userIds, 50);
        for (List<Object> batch : batches) {
            briefPushExecutor.submit(() -> processBatch(batch));
        }
    }
    
    private void processBatch(List<Object> userIds) {
        for (Object uid : userIds) {
            long userId = Long.parseLong(uid.toString());
            try {
                processUserPush(userId);
            } catch (Exception e) {
                log.error("Brief push failed for user {}", userId, e);
                metricsCounter.increment("brief.push.error");
            }
        }
    }
    
    private void processUserPush(long userId) {
        String today = LocalDate.now().format(YYYYMMDD);
        String dedupKey = "brief:push_dedup:" + userId + ":" + today;
        
        // 防重检查
        if (!redisTemplate.opsForValue().setIfAbsent(dedupKey, "1", Duration.ofHours(25))) {
            log.debug("Brief already pushed for user {} on {}", userId, today);
            return;
        }
        
        // 查询今日简报状态
        DailyBrief brief = briefService.getOrCreateTodayBrief(userId);
        
        if ("SKIPPED".equals(brief.getStatus())) {
            // 学习时长不足，发送轻量提醒
            sendLowActivityReminder(userId);
            return;
        }
        
        if (!"READY".equals(brief.getStatus())) {
            // 简报尚未就绪，延迟推送
            redisTemplate.opsForValue().setIfAbsent(dedupKey, "0", Duration.ofMinutes(10));
            scheduleRetryPush(userId, 10);
            return;
        }
        
        // 执行推送
        BriefPushConfig config = briefConfigService.getConfig(userId);
        for (String channel : config.getChannels()) {
            pushChannelStrategyMap.get(channel).push(userId, brief);
        }
        
        // 更新状态
        briefService.markPushed(brief.getId());
        metricsCounter.increment("brief.push.success");
    }
    
    /**
     * 推送调度索引构建（每天凌晨执行）
     * 将所有启用推送的用户按push_time分组写入Redis SET
     */
    @Scheduled(cron = "0 0 0 * * ?") // 每天0点
    public void rebuildPushScheduleIndex() {
        LocalDate today = LocalDate.now();
        
        // 清理昨天的索引
        // 构建今天的索引
        List<BriefPushConfig> configs = briefConfigService.findAllEnabled();
        
        Map<String, List<Long>> timeBuckets = configs.stream()
            .collect(Collectors.groupingBy(
                c -> c.getPushTime().format(DateTimeFormatter.ofPattern("HHmm")),
                Collectors.mapping(BriefPushConfig::getUserId, Collectors.toList())
            ));
        
        timeBuckets.forEach((timeBucket, users) -> {
            String key = "brief:push_schedule:" + timeBucket;
            redisTemplate.opsForSet().add(key, users.stream().map(String::valueOf).toArray(String[]::new));
            redisTemplate.expire(key, Duration.ofHours(25));
        });
        
        log.info("Push schedule index rebuilt: {} buckets, {} total users", 
                 timeBuckets.size(), configs.size());
    }
}
```

### 8.1 简报生命周期状态机

### 8.2 状态流转规则

```java
public enum BriefStatus {
    PENDING,     // 待生成
    GENERATING,  // 生成中
    READY,       // 已就绪，待推送
    PUSHED,      // 已推送
    SKIPPED,     // 跳过（学习时长不足）
    FAILED,      // 生成失败
    READ         // 已读
}

public class BriefStateMachine {
    
    private static final Map<BriefStatus, Set<BriefStatus>> TRANSITIONS = Map.of(
        BriefStatus.PENDING,    EnumSet.of(BriefStatus.GENERATING),
        BriefStatus.GENERATING, EnumSet.of(BriefStatus.READY, BriefStatus.SKIPPED, BriefStatus.FAILED),
        BriefStatus.FAILED,     EnumSet.of(BriefStatus.GENERATING),   // 允许重试
        BriefStatus.READY,      EnumSet.of(BriefStatus.PUSHED),
        BriefStatus.PUSHED,     EnumSet.of(BriefStatus.READ),
        BriefStatus.SKIPPED,    EnumSet.of(),  // 终态
        BriefStatus.READ,       EnumSet.of()   // 终态
    );
    
    private static final int MAX_RETRY = 3;
    
    public void transition(DailyBrief brief, BriefStatus target) {
        BriefStatus current = BriefStatus.valueOf(brief.getStatus());
        
        if (!TRANSITIONS.get(current).contains(target)) {
            throw new IllegalStateTransitionException(
                String.format("Cannot transition from %s to %s", current, target)
            );
        }
        
        // FAILED → GENERATING 重试次数检查
        if (current == BriefStatus.FAILED && target == BriefStatus.GENERATING) {
            int retryCount = brief.getRetryCount();
            if (retryCount >= MAX_RETRY) {
                log.warn("Brief {} reached max retry count {}", brief.getId(), MAX_RETRY);
                // 升级为人工处理或使用降级文案
                briefService.useFallbackContent(brief);
                brief.setStatus(BriefStatus.READY.name());
                return;
            }
            brief.setRetryCount(retryCount + 1);
        }
        
        brief.setStatus(target.name());
        
        // 记录时间戳
        switch (target) {
            case READY:      brief.setGeneratedAt(LocalDateTime.now()); break;
            case PUSHED:     brief.setPushedAt(LocalDateTime.now());    break;
            case READ:       brief.setReadAt(LocalDateTime.now());      break;
            default: break;
        }
    }
}
```

## 9. 错误处理与容灾

### 9.1 异常分类与处理

| 异常类型 | 场景 | 处理策略 | 用户影响 |
| --- | --- | --- | --- |
| 数据源不可用 | 某模块服务宕机 | 使用缓存数据 + 跳过该模块 | 简报缺少该模块数据 |
| AI生成超时 | 大模型调用超时(>5s) | 降级到模板文案引擎 | 简报文案不如AI生成丰富 |
| AI生成异常 | 大模型返回错误内容 | 降级到模板文案 + 记录告警 | 同上 |
| 推送失败 | Push服务不可用 | 重试3次 → 记录失败日志 → 站内消息兜底 | 用户可能延迟收到推送 |
| 微信模板消息失败 | 公众号接口异常 | 降级到站内消息 | 家长可能不及时看到 |
| 数据库写入失败 | DB异常 | 写入失败队列 + 告警 + 后补 | 简报可能延迟 |
| 分享卡片渲染失败 | 无头浏览器异常 | 返回默认封面图 | 分享卡片不美观 |
| Redis不可用 | 缓存宕机 | 全量走DB查询 + 告警 | 性能下降但功能正常 |

```java
@Slf4j
@Service
public class BriefGenerationService {
    
    /**
     * 生成简报（包含完整容灾逻辑）
     */
    public DailyBrief generateBrief(long userId, LocalDate date, BriefRoleType roleType) {
        String traceId = MDC.get("traceId");
        
        try {
            // Step 1: 数据聚合（带容灾）
            BriefAggregateData aggregate = aggregateDataWithFallback(userId, date);
            
            // Step 2: 最小学习时长检查
            BriefPushConfig config = configService.getConfig(userId, roleType);
            if (aggregate.getLearningDurationSec() < config.getMinLearningMinutes() * 60) {
                return createSkippedBrief(userId, date, roleType, aggregate);
            }
            
            // Step 3: 结构化内容组装
            BriefContent content = contentAssembler.assemble(aggregate, config, roleType);
            
            // Step 4: AI自然语言生成（带降级）
            BriefNLResult nlResult = generateNLWithFallback(aggregate, roleType);
            
            // Step 5: 封面图选择
            String coverUrl = coverSelector.selectAndResolveUrl(aggregate);
            
            // Step 6: 持久化
            DailyBrief brief = persistBrief(userId, date, roleType, config, 
                                            aggregate, content, nlResult, coverUrl);
            
            // Step 7: 异步生成分享卡片
            shareCardGenerator.generateShareCard(brief);
            
            return brief;
            
        } catch (Exception e) {
            log.error("Brief generation failed for user {} date {}", userId, date, e);
            
            // 最后兜底：创建FAILED状态的简报记录
            return createFailedBrief(userId, date, roleType, e);
        }
    }
    
    /**
     * 数据聚合 - 带模块级容灾
     */
    private BriefAggregateData aggregateDataWithFallback(long userId, LocalDate date) {
        BriefAggregateData data = new BriefAggregateData();
        
        // 并行获取各模块数据，单个模块失败不影响整体
        Map<String, CompletableFuture<ModuleData>> futures = new HashMap<>();
        
        for (String moduleCode : BRIEF_MODULES) {
            futures.put(moduleCode, CompletableFuture.supplyAsync(() -> {
                try {
                    return moduleDataFetcherMap.get(moduleCode).fetch(userId, date);
                } catch (Exception e) {
                    log.warn("Module {} data fetch failed for user {}, using cache", 
                             moduleCode, userId, e);
                    return moduleDataFetcherMap.get(moduleCode).fetchFromCache(userId, date);
                }
            }, briefAggregatorExecutor));
        }
        
        // 等待所有模块完成（最多等待5秒）
        CompletableFuture.allOf(futures.values().toArray(new CompletableFuture[0]))
            .get(5, TimeUnit.SECONDS);
        
        for (Map.Entry<String, CompletableFuture<ModuleData>> entry : futures.entrySet()) {
            try {
                ModuleData md = entry.getValue().getNow(null);
                if (md != null) {
                    data.putModuleData(entry.getKey(), md);
                }
            } catch (Exception e) {
                log.warn("Module {} data unavailable, skipping", entry.getKey());
            }
        }
        
        // 学习时长是核心指标，必须有值
        if (data.getLearningDurationSec() == 0) {
            log.warn("Learning duration is 0 for user {}, attempting direct DB query", userId);
            data.setLearningDurationSec(
                learningSessionService.getDurationFromDB(userId, date)
            );
        }
        
        return data;
    }
    
    /**
     * AI自然语言生成 - 三级降级
     */
    private BriefNLResult generateNLWithFallback(BriefAggregateData data, BriefRoleType role) {
        try {
            // Level 0: 调用大模型
            return aiBriefGenerator.generate(data, role)
                .get(5, TimeUnit.SECONDS);  // 5秒超时
        } catch (TimeoutException e) {
            log.warn("AI brief generation timeout, falling back to template");
        } catch (Exception e) {
            log.warn("AI brief generation failed, falling back to template", e);
        }
        
        // Level 1: 模板引擎降级
        try {
            return templateEngine.generate(data, role);
        } catch (Exception e) {
            log.error("Template engine also failed", e);
        }
        
        // Level 2: 静态默认文案
        return BriefNLResult.builder()
            .nlSummary("今天学习了" + data.getDurationText() + "，完成了" + 
                       data.getTotalAnswers() + "道题目。继续加油！")
            .tomorrowSuggestion("明天继续坚持学习吧！")
            .fallback(true)
            .build();
    }
}
```

## 10. 性能优化

### 10.1 批量生成优化

高峰时段（如21:00-22:00）大量用户同时推送，需要批量处理：

```java
@Component
@Slf4j
public class BriefBatchGenerator {
    
    private static final int BATCH_SIZE = 100;
    private static final int PARALLELISM = 8;
    
    /**
     * 批量预生成简报
     * 在推送时间前15分钟开始预生成
     */
    @Scheduled(cron = "0 */15 * * * ?")
    public void preGenerateBriefs() {
        LocalTime now = LocalTime.now();
        LocalTime nextSlot = now.plusMinutes(15)
            .truncatedTo(ChronoUnit.HOURS)
            .withMinute((now.getMinute() / 15 + 1) * 15 % 60);
        
        String bucket = nextSlot.format(DateTimeFormatter.ofPattern("HHmm"));
        String scheduleKey = "brief:push_schedule:" + bucket;
        
        Set<Object> userIds = redisTemplate.opsForSet().members(scheduleKey);
        if (CollectionUtils.isEmpty(userIds)) return;
        
        // 过滤出尚未生成的用户
        List<Long> needGenerate = userIds.stream()
            .map(Long::parseLong)
            .filter(uid -> !briefService.existsReady(uid, LocalDate.now()))
            .collect(Collectors.toList());
        
        if (needGenerate.isEmpty()) return;
        
        // 分批并行生成
        Lists.partition(needGenerate, BATCH_SIZE).forEach(batch -> {
            CompletableFuture.runAsync(() -> {
                CountDownLatch latch = new CountDownLatch(batch.size());
                Semaphore semaphore = new Semaphore(PARALLELISM);
                
                for (Long userId : batch) {
                    semaphore.acquire();
                    CompletableFuture.runAsync(() -> {
                        try {
                            briefGenerationService.generateBrief(
                                userId, LocalDate.now(), BriefRoleType.STUDENT
                            );
                        } finally {
                            semaphore.release();
                            latch.countDown();
                        }
                    }, briefGenExecutor);
                }
                
                latch.await(5, TimeUnit.MINUTES);
            }, briefGenExecutor);
        });
        
        log.info("Pre-generated briefs for {} users in bucket {}", needGenerate.size(), bucket);
    }
}
```

| 查看自己简报 | 用户本人 | JWT token 校验 |
| 家长查看孩子简报 | 有效家长绑定关系 | 校验 ParentBinding 表 |
| 教师查看学生简报 | 有效师生关系 | 校验 TeacherStudent 表 |
| 简报配置修改 | 用户本人 | 不允许代修改 |
| 分享卡片生成 | 用户本人 | 分享即授权公开 |

### 13.2 隐私保护措施

1. **简报内容不含敏感信息**：不展示手机号、具体位置、IP地址等
2. **家长版简报数据脱敏**：不展示具体题目内容、AI对话原文（仅展示聚合指标）
3. **分享卡片不含个人识别信息**：仅展示昵称、学习数据、激励信息
4. **数据最小化原则**：简报仅保存必要的聚合指标，不保存原始学习行为数据
5. **用户数据删除**：支持用户删除全部历史简报（隐私合规要求）
6. **Redis缓存自动过期**：48小时后自动清理，不长期保存
