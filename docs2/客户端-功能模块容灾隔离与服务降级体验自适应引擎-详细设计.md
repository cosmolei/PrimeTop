# 客户端-功能模块容灾隔离与服务降级体验自适应引擎-详细设计

## 1. 概述

### 1.1 功能定位

PrimeTop 客户端包含 AI 辅导、拍照搜题、同步课堂、错题本、学情分析、学习规划、家长中心等众多功能模块，每个模块依赖不同的后端微服务。当某个后端服务出现故障、超时或降级时，客户端需要保证**其他功能模块不受影响**，且故障模块能提供**优雅的降级体验**而非崩溃或白屏。

本引擎作为客户端基础设施层组件，负责：

1. **模块隔离**：各功能模块独立运行，一个模块的异常不影响其他模块。
2. **服务健康感知**：实时监测各后端服务的健康状态。
3. **降级策略编排**：根据服务健康状态自动切换降级策略。
4. **故障恢复感知**：服务恢复后自动切回正常模式。
5. **统一降级体验**：为所有模块提供一致的降级 UI 和交互模式。

### 1.2 与现有文档的边界

| 现有文档 | 关注点 | 本文档区别 |
|---------|--------|-----------|
| 客户端全局异常处理与安全恢复机制 | 代码级异常捕获、Crash 恢复 | 本文关注**服务级**不可用的预防性降级 |
| 客户端-系统资源压力感知与智能降级调度引擎 | 设备资源（内存/CPU/电池）限制下的降级 | 本文关注**后端服务**不可用时的功能降级 |
| 错误处理与服务降级策略 | 服务端降级策略设计 | 本文关注**客户端体验侧**的降级编排 |
| 服务端-AI模型调用多供应商容灾切换与自动降级引擎 | AI 模型层面的容灾 | 本文关注**全功能模块**层面的容灾 |

### 1.3 设计目标

| 目标 | 指标 |
|------|------|
| 模块隔离率 | 100% — 任意单模块后端故障不影响其他模块 |
| 降级切换延迟 | ≤ 500ms（从检测到不可用到降级生效） |
| 恢复切换延迟 | ≤ 2s（从服务恢复到正常模式） |
| 降级体验评分 | 用户无感知或仅感知到轻微提示 |
| 内存开销 | ≤ 5MB（健康监测+降级缓存） |

### 1.4 适用学段

全学段通用，但降级 UI 根据学段自适应调整：
- 幼儿/小学低年级：使用图形化提示和语音引导
- 小学高年级/初中/高中：使用文字提示和功能引导

## 3. 数据结构定义

### 3.1 服务健康状态模型

```dart
/// 后端服务健康状态
enum ServiceHealthStatus {
  healthy,      // 健康：正常响应
  degraded,     // 降级：响应慢或有间歇性错误
  unhealthy,    // 不健康：连续失败
  unknown,      // 未知：尚未检测或信号过期
}

/// 单个后端服务的健康快照
class ServiceHealthSnapshot {
  final String serviceId;           // 服务标识，如 "ai-tutoring", "photo-ocr"
  final ServiceHealthStatus status;  // 当前健康状态
  final double healthScore;          // 健康分 0.0~1.0
  final DateTime lastCheckTime;      // 最后检测时间
  final DateTime lastSuccessTime;    // 最后成功时间
  final int consecutiveFailures;     // 连续失败次数
  final int? estimatedRecoveryMs;    // 预估恢复时间（毫秒）
  final String? message;             // 状态描述信息
  final Map<String, dynamic> metrics; // 扩展指标

  /// 是否需要降级
  bool get shouldDegrade =>
    status == ServiceHealthStatus.unhealthy ||
    (status == ServiceHealthStatus.degraded && healthScore < 0.5);

  /// 数据是否过期（超过30秒未更新）
  bool get isStale =>
    DateTime.now().difference(lastCheckTime).inSeconds > 30;
}
```

### 3.2 降级等级定义

```dart
/// 降级等级（从轻到重）
enum DegradationLevel {
  /// L0: 正常 — 全功能可用
  normal,

  /// L1: 轻度降级 — 核心功能可用，非核心功能关闭
  /// 示例：AI辅导关闭"生成同类题"但保留基础问答
  minor,

  /// L2: 中度降级 — 使用缓存或简化数据，实时功能不可用
  /// 示例：学情分析展示上次缓存数据，AI辅导使用预设模板回复
  moderate,

  /// L3: 重度降级 — 功能完全不可用，展示占位 UI
  /// 示例：拍照搜题完全不可用，引导用户手动输入
  severe,

  /// L4: 模块隐藏 — 从导航中隐藏该模块入口
  /// 示例：在线自习室因实时服务不可用而暂时隐藏
  hidden,
}
```

### 4.2 主动探针 (Active Probe)

客户端定期向后端发送轻量级健康检查请求：

```dart
/// 主动健康探针
class ActiveHealthProbe {
  final String serviceId;
  final String healthEndpoint;    // 健康检查端点
  final Duration interval;        // 探测间隔
  final Duration timeout;         // 超时时间
  final int warmupRetries;        // 预热重试次数

  /// 执行一次健康检查
  Future<ProbeResult> probe() async {
    try {
      final response = await _httpClient.get(
        healthEndpoint,
      ).timeout(timeout);

      final latency = response.timestamp.difference(DateTime.now());
      final isHealthy = response.statusCode == 200 &&
        response.data?['status'] == 'ok';

      return ProbeResult(
        success: isHealthy,
        latencyMs: latency.inMilliseconds,
        timestamp: DateTime.now(),
        serverMessage: response.data?['message'],
      );
    } catch (e) {
      return ProbeResult(
        success: false,
        latencyMs: timeout.inMilliseconds,
        timestamp: DateTime.now(),
        error: e.toString(),
      );
    }
  }
}
```

**各服务探测配置：**

| 服务 ID | 健康端点 | 探测间隔 | 超时 | 说明 |
|---------|---------|---------|------|------|
| `ai-tutoring` | `/api/v1/health/ai` | 30s | 5s | AI 辅导服务 |
| `photo-ocr` | `/api/v1/health/ocr` | 30s | 3s | OCR 识别服务 |
| `content-sync` | `/api/v1/health/content` | 60s | 3s | 同步课堂内容 |
| `mistake-book` | `/api/v1/health/mistake` | 60s | 3s | 错题本服务 |
| `analytics` | `/api/v1/health/analytics` | 120s | 5s | 学情分析服务 |
| `study-plan` | `/api/v1/health/plan` | 120s | 3s | 学习规划服务 |
| `payment` | `/api/v1/health/payment` | 120s | 3s | 支付服务 |
| `push-msg` | `/api/v1/health/push` | 120s | 3s | 消息推送服务 |
| `parent-center` | `/api/v1/health/parent` | 120s | 3s | 家长中心服务 |

**探测调度策略：**
- 仅探测**当前前台活跃模块**依赖的服务（节省电量和流量）
- 后台时探测频率降低为正常值的 1/3
- 从后台恢复到前台时立即触发一次全量探测
- 离线模式下跳过探测，标记为 `unknown`

### 4.3 被动信号收集 (Passive Signal)

被动收集业务请求的结果作为健康信号，无需额外网络开销：

```dart
/// 被动信号收集器
class PassiveSignalCollector {
  final Map<String, RollingWindow> _signalWindows = {};

  /// 记录一次请求结果
  void recordRequest({
    required String serviceId,
    required bool success,
    required int latencyMs,
    int? statusCode,
    String? errorType,
  }) {
    final window = _signalWindows.putIfAbsent(
      serviceId,
      () => RollingWindow(size: 20), // 滑动窗口：最近20次请求
    );

    window.add(SignalSample(
      success: success,
      latencyMs: latencyMs,
      statusCode: statusCode,
      errorType: errorType,
      timestamp: DateTime.now(),
    ));
  }

  /// 计算被动健康分
  PassiveHealthScore calculateScore(String serviceId) {
    final window = _signalWindows[serviceId];
    if (window == null || window.isEmpty) {
      return PassiveHealthScore(score: 0.5, confidence: 0.0);
    }

    final samples = window.samples;
    final successRate = samples.where((s) => s.success).length / samples.length;

    // 延迟评分：正常<500ms=1.0，500ms-2s=0.7，2s-5s=0.4，>5s=0.1
    final avgLatency = samples
      .map((s) => s.latencyMs)
      .reduce((a, b) => a + b) / samples.length;
    final latencyScore = _latencyToScore(avgLatency);

    // 综合分 = 成功率 * 0.7 + 延迟分 * 0.3
    final score = successRate * 0.7 + latencyScore * 0.3;

    // 置信度：基于样本数量
    final confidence = (samples.length / 20).clamp(0.0, 1.0);

    return PassiveHealthScore(
      score: score,
      confidence: confidence,
      successRate: successRate,
      avgLatencyMs: avgLatency,
    );
  }

  double _latencyToScore(double latencyMs) {
    if (latencyMs < 500) return 1.0;
    if (latencyMs < 2000) return 0.7;
    if (latencyMs < 5000) return 0.4;
    return 0.1;
  }
}
```

### 4.4 服务端推送信号 (Push Signal)

服务端通过 WebSocket 或 SSE 主动推送服务状态变更：

```dart
/// 服务端推送的健康状态消息
class ServerHealthPush {
  final String serviceId;
  final ServiceHealthStatus status;
  final double healthScore;
  final DateTime timestamp;
  final String? estimatedRecoveryTime;
  final String? message;
  final List<String>? affectedFeatures; // 受影响的功能列表

  /// WebSocket 消息处理
  void handleHealthPush(Map<String, dynamic> data) {
    final push = ServerHealthPush.fromJson(data);
    _healthMonitor.applyPushSignal(push);

    // 如果服务端明确标注受影响的功能，
    // 直接设置对应的降级等级
    if (push.affectedFeatures != null) {
      for (final featureId in push.affectedFeatures!) {
        _degradationManager.applyExternalDegradation(
          featureId,
          _mapStatusToLevel(push.status),
          push.estimatedRecoveryTime,
        );
      }
    }
  }

  DegradationLevel _mapStatusToLevel(ServiceHealthStatus status) {
    switch (status) {
      case ServiceHealthStatus.healthy:
        return DegradationLevel.normal;
      case ServiceHealthStatus.degraded:
        return DegradationLevel.minor;
      case ServiceHealthStatus.unhealthy:
        return DegradationLevel.severe;
      default:
        return DegradationLevel.normal;
    }
  }
}
```

### 4.5 健康分计算引擎

```dart
/// 综合健康分计算器
class HealthScoreCalculator {
  /// 计算最终健康快照
  ServiceHealthSnapshot calculate({
    required String serviceId,
    required ProbeResult? activeProbe,
    required PassiveHealthScore passiveScore,
    required ServerHealthPush? pushSignal,
    required ServiceHealthSnapshot? previous,
  }) {
    final now = DateTime.now();

    // 各信号权重
    const activeWeight = 0.3;
    const passiveWeight = 0.5;
    const pushWeight = 0.2;

    // 计算各信号得分
    double activeScore = activeProbe != null
      ? (activeProbe.success ? 1.0 : 0.0)
      : (previous?.healthScore ?? 0.5);
    double passive = passiveScore.score;
    double push = pushSignal?.healthScore ?? previous?.healthScore ?? 0.5;

    // 时间衰减：旧信号权重降低
    if (activeProbe != null) {
      final ageSec = now.difference(activeProbe.timestamp).inSeconds;
      activeScore *= math.exp(-ageSec / 60); // 60秒半衰期
    }

    // 加权平均
    double finalScore = activeScore * activeWeight +
      passive * passiveWeight +
      push * pushWeight;

    // 异常过滤：如果被动信号置信度低，更多依赖主动探测
    if (passiveScore.confidence < 0.3 && activeProbe != null) {
      finalScore = activeScore * 0.6 + push * 0.4;
    }

    // 计算连续失败次数
    int consecutiveFailures = previous?.consecutiveFailures ?? 0;
    if (activeProbe?.success == false) {
      consecutiveFailures++;
    } else if (activeProbe?.success == true) {
      consecutiveFailures = 0;
    }

    // 确定状态
    final status = _determineStatus(finalScore, consecutiveFailures);

    return ServiceHealthSnapshot(
      serviceId: serviceId,
      status: status,
      healthScore: finalScore,
      lastCheckTime: now,
      lastSuccessTime: activeProbe?.success == true
        ? now
        : previous?.lastSuccessTime,
      consecutiveFailures: consecutiveFailures,
      message: pushSignal?.message ?? activeProbe?.serverMessage,
    );
  }

  ServiceHealthStatus _determineStatus(
    double score, int consecutiveFailures,
  ) {
    if (consecutiveFailures >= 5 || score < 0.2) {
      return ServiceHealthStatus.unhealthy;
    }
    if (consecutiveFailures >= 2 || score < 0.6) {
      return ServiceHealthStatus.degraded;
    }
    if (score >= 0.6) {
      return ServiceHealthStatus.healthy;
    }
    return ServiceHealthStatus.unknown;
  }
}
```

## 5. 模块容灾隔离框架

### 5.1 错误边界 (Error Boundary)

每个功能模块被错误边界包裹，防止异常向上传播：

```dart
/// 模块错误边界 Widget
class ModuleErrorBoundary extends StatefulWidget {
  final String moduleId;
  final Widget child;
  final Widget Function(String moduleId, Object error)? onError;

  const ModuleErrorBoundary({
    super.key,
    required this.moduleId,
    required this.child,
    this.onError,
  });

  @override
  State<ModuleErrorBoundary> createState() => _ModuleErrorBoundaryState();
}

class _ModuleErrorBoundaryState extends State<ModuleErrorBoundary>
    with SingleTickerProviderStateMixin {
  bool _hasError = false;
  Object? _error;
  int _retryCount = 0;

  @override
  void didChangeDependencies() {
    super.didChangeDependencies();
    // 注册 FlutterError 回调
    FlutterError.onError = _handleFlutterError;
  }

  void _handleFlutterError(FlutterErrorDetails details) {
    if (_isModuleError(details.exception)) {
      setState(() {
        _hasError = true;
        _error = details.exception;
      });

      // 上报到全局异常处理
      GlobalErrorHandler.report(
        module: widget.moduleId,
        error: details.exception,
        stack: details.stack,
      );

      // 通知降级管理器
      DegradationManager.instance.recordModuleCrash(

      );
    }
  }

  void _retry() {

      _hasError = false;

      _retryCount++;
    });
  }
```

```dart
/// 服务调用门控器
class ServiceGate {
  final ServiceHealthMonitor _healthMonitor;
  final DegradationManager _degradationManager;

  /// 执行带门控的服务调用
  Future<T?> callWithGate<T>({
    required String serviceId,
    required Future<T> Function() apiCall,
    required String moduleId,
    T? Function()? fallback,
    Duration? timeout,
    bool enableRetry = true,
  }) async {
    // 1. 检查服务健康状态
    final health = _healthMonitor.getHealth(serviceId);

    if (health.status == ServiceHealthStatus.unhealthy) {
      // 服务不健康 — 直接返回降级数据
      _degradationManager.activateDegradation(
        moduleId: moduleId,
        serviceId: serviceId,
        level: DegradationLevel.moderate,
      );

      if (fallback != null) {
        return fallback();
      }
      throw ServiceUnavailableException(
        serviceId: serviceId,
        message: '服务暂时不可用，请稍后再试',
      );
    }

    // 2. 执行实际调用
    try {
      final result = await apiCall().timeout(
        timeout ?? const Duration(seconds: 10),
      );

      // 记录成功信号
      _healthMonitor.recordSuccess(serviceId);

      // 如果之前处于降级状态，触发恢复
      _degradationManager.maybeRecover(moduleId: moduleId);

      return result;
    } catch (e) {
      // 记录失败信号
      _healthMonitor.recordFailure(
        serviceId,
        error: e.toString(),
      );

      // 判断是否需要熔断
      if (enableRetry && _shouldCircuitBreak(serviceId)) {
        _degradationManager.activateDegradation(
          moduleId: moduleId,
          serviceId: serviceId,
          level: DegradationLevel.moderate,
        );
      }

      if (fallback != null) {
        return fallback();
      }
      rethrow;
    }
  }

  bool _shouldCircuitBreak(String serviceId) {
    final health = _healthMonitor.getHealth(serviceId);
    return health.consecutiveFailures >= 3 ||
      health.status == ServiceHealthStatus.unhealthy;
  }
}
```

```dart
/// 模块隔离容器 — 在独立 Zone 中运行模块逻辑
class ModuleIsolationContainer {

  late final Zone _isolatedZone;
  bool _isInitialized = false;

        },
        // 拦截 print 输出（模块级日志隔离）

          ModuleLogger.instance.log(moduleId, line);
        },
      ),
      // 模块级错误统计对象
      values: {
        'moduleId': moduleId,
        'errorCount': 0,
        'lastErrorTime': null,
      },
    );

    _isInitialized = true;
  }

  /// 在隔离 Zone 中运行模块代码
  T run<T>(T Function() body) {
    if (!_isInitialized) initialize();
    return _isolatedZone.run(body);
  }

  /// 在隔离 Zone 中运行异步模块代码
  Future<T> runAsync<T>(Future<T> Function() body) async {
    if (!_isInitialized) initialize();
    return _isolatedZone.run(body);
  }

  void _handleIsolatedError(Object error, StackTrace stack) {
    final errorCount = (_isolatedZone['errorCount'] as int) + 1;
    _isolatedZone.updateValue('errorCount', errorCount);

    // 错误风暴检测：短时间内大量错误
    final lastError = _isolatedZone['lastErrorTime'] as DateTime?;
    final now = DateTime.now();
    if (lastError != null &&
        now.difference(lastError).inSeconds < 10 &&
        errorCount > 5) {
      // 触发模块级熔断
      DegradationManager.instance.emergencyDegrade(
        moduleId: moduleId,
        reason: 'Error storm detected: $errorCount errors in 10s',
        level: DegradationLevel.severe,
      );
    }

    _isolatedZone.updateValue('lastErrorTime', now);

    GlobalErrorHandler.report(
      module: moduleId,
      error: error,
      stack: stack,
      severity: ErrorSeverity.warning,
    );
  }
}
```

```
        ▼

        ▼

└───────┬───────────────────────┘
        │
        ▼
┌───────────────────────────────┐
│ 调用自定义评估器（如果存在）   │
│ 做最终调整                     │
└───────┬───────────────────────┘
        │
        ▼
┌───────────────────┐
│ 如果等级发生变化： │
│ 触发降级/恢复切换 │
└───────────────────┘
```

### 6.2 降级管理器实现

```dart
/// 降级管理器 — 单例
class DegradationManager {
  static final DegradationManager instance = DegradationManager._();
  DegradationManager._();

  final Map<String, ModuleRegistration> _registrations = {};
  final Map<String, DegradationLevel> _currentLevels = {};
  final Map<String, List<DegradationChangeListener>> _listeners = {};
  final StreamController<DegradationEvent> _eventController =
    StreamController.broadcast();

  /// 注册功能模块
  void registerModule(ModuleRegistration registration) {
    _registrations[registration.moduleId] = registration;
    _currentLevels[registration.moduleId] = DegradationLevel.normal;
  }

  /// 根据服务健康更新触发降级评估
  void onServiceHealthChanged(
    String serviceId,
    ServiceHealthSnapshot snapshot,
  ) {
    // 找到所有依赖该服务的模块
    final affectedModules = _registrations.values
      .where((reg) => reg.dependencies.contains(serviceId))
      .toList();

    for (final module in affectedModules) {
      _evaluateAndApply(module.moduleId);
    }
  }

  /// 评估并应用降级等级
  void _evaluateAndApply(String moduleId) {
    final registration = _registrations[moduleId]!;
    final context = _buildContext(moduleId);

    DegradationLevel newLevel = DegradationLevel.normal;

    // 应用依赖传播规则
    for (final rule in registration.propagationRules) {
      final health = ServiceHealthMonitor.instance.getHealth(rule.serviceId);
      final mappedLevel = rule.statusToLevel[health.status];
      if (mappedLevel != null && mappedLevel.index > newLevel.index) {
        newLevel = mappedLevel;
      }
    }

    // 应用自定义评估器
    if (registration.strategy.customEvaluator != null) {
      for (final dep in registration.dependencies) {
        final health = ServiceHealthMonitor.instance.getHealth(dep);
        final customLevel = registration.strategy.customEvaluator!(
          health, context,
        );
        if (customLevel.index > newLevel.index) {
          newLevel = customLevel;
        }
      }
    }

    // 限制：不超过模块声明的最大可接受降级等级
    if (newLevel.index > registration.maxDegradation.index) {
      newLevel = registration.maxDegradation;
    }

    // 如果等级变化，执行切换
    final currentLevel = _currentLevels[moduleId]!;
    if (newLevel != currentLevel) {
      _applyDegradationChange(moduleId, currentLevel, newLevel);
    }
  }

  /// 执行降级/恢复切换
  void _applyDegradationChange(
    String moduleId,
    DegradationLevel oldLevel,
    DegradationLevel newLevel,
  ) {
    _currentLevels[moduleId] = newLevel;

    final isDegrading = newLevel.index > oldLevel.index;

    // 记录事件
    _eventController.add(DegradationEvent(
      moduleId: moduleId,
      oldLevel: oldLevel,
      newLevel: newLevel,
      timestamp: DateTime.now(),
      isDegrading: isDegrading,
    ));

    // 通知监听器
    _listeners[moduleId]?.forEach((listener) {
      listener(moduleId, oldLevel, newLevel);
    });

    // 埋点上报
    AnalyticsTracker.instance.track('degradation_change', {
      'module': moduleId,
      'old_level': oldLevel.name,
      'new_level': newLevel.name,
      'is_degrading': isDegrading,
    });

    // 触发恢复探测（如果是从降级恢复）
    if (!isDegrading && newLevel == DegradationLevel.normal) {
      _onModuleRecovered(moduleId);
    }
  }

  /// 激活降级（由 ServiceGate 调用）
  void activateDegradation({
    required String moduleId,
    required String serviceId,
    required DegradationLevel level,
  }) {
    final current = _currentLevels[moduleId] ?? DegradationLevel.normal;
    if (level.index > current.index) {
      _applyDegradationChange(moduleId, current, level);
    }
  }

  /// 紧急降级（由 Error Boundary 调用）
  void emergencyDegrade({
    required String moduleId,
    required String reason,
    DegradationLevel level = DegradationLevel.severe,
  }) {
    final current = _currentLevels[moduleId] ?? DegradationLevel.normal;
    if (level.index > current.index) {
      _applyDegradationChange(moduleId, current, level);
    }

    ModuleLogger.instance.error(moduleId, 'Emergency degrade: $reason');
  }

  /// 记录模块崩溃
  void recordModuleCrash(String moduleId, String error) {
    final current = _currentLevels[moduleId] ?? DegradationLevel.normal;
    if (current == DegradationLevel.normal) {
      _applyDegradationChange(
        moduleId, current, DegradationLevel.severe,
      );
    }
  }

  /// 尝试恢复
  void maybeRecover({required String moduleId}) {
    _evaluateAndApply(moduleId);
  }

  /// 当前降级等级
  DegradationLevel? getCurrentLevel(String moduleId) =>
    _currentLevels[moduleId];

  /// 降级事件流
  Stream<DegradationEvent> get events => _eventController.stream;

  void _onModuleRecovered(String moduleId) {
    ModuleLogger.instance.info(moduleId, 'Module recovered to normal');
    // 可以在这里执行数据刷新等恢复操作
  }

  DegradationContext _buildContext(String moduleId) {
    return DegradationContext(
      userId: UserManager.instance.currentUserId ?? '',
      gradeLevel: UserManager.instance.currentGradeLevel ?? '',
      isOffline: !NetworkManager.instance.isOnline,
      isBackground: LifecycleManager.instance.isBackground,
      networkType: NetworkManager.instance.networkType,
      currentTime: DateTime.now(),
      moduleState: {},
    );
  }
}
```

## 7. 恢复检测引擎

### 7.1 恢复检测策略

当模块处于降级状态时，系统需要持续检测服务是否恢复：

```dart
/// 恢复检测器
class RecoveryDetector {
  final ServiceHealthMonitor _healthMonitor;
  final DegradationManager _degradationManager;
  final Map<String, Timer> _recoveryTimers = {};

  /// 当模块进入降级状态时启动恢复检测
  void startRecoveryWatch(String moduleId, String serviceId) {
    _recoveryTimers[moduleId]?.cancel();

    // 根据降级等级确定检测频率
    final level = _degradationManager.getCurrentLevel(moduleId);
    final interval = _getRecoveryCheckInterval(level);

    _recoveryTimers[moduleId] = Timer.periodic(interval, (_) async {
      await _performRecoveryCheck(moduleId, serviceId);
    });
  }

  /// 执行恢复检测
  Future<void> _performRecoveryCheck(
    String moduleId, String serviceId,
  ) async {
    try {
      // 发送轻量级探测请求
      final probe = ActiveHealthProbe(
        serviceId: serviceId,
        healthEndpoint: '/api/v1/health/$serviceId',
        interval: const Duration(seconds: 0),
        timeout: const Duration(seconds: 3),
        warmupRetries: 0,
      );

      final result = await probe.probe();

      if (result.success) {
        // 连续成功 N 次才确认恢复
        _recoverySuccessCount[moduleId] =
          (_recoverySuccessCount[moduleId] ?? 0) + 1;

        if (_recoverySuccessCount[moduleId]! >= 2) {
          _confirmRecovery(moduleId, serviceId);
        }
      } else {
        _recoverySuccessCount[moduleId] = 0;
      }
    } catch (_) {
      _recoverySuccessCount[moduleId] = 0;
    }
  }

  /// 确认恢复
  void _confirmRecovery(String moduleId, String serviceId) {
    _recoveryTimers[moduleId]?.cancel();
    _recoveryTimers.remove(moduleId);
    _recoverySuccessCount.remove(moduleId);

    // 重新评估降级状态（如果服务确实恢复，会自动切回 normal）
    _degradationManager.maybeRecover(moduleId: moduleId);

    // 显示恢复提示
    ToastManager.instance.show(
      message: '${_getModuleName(moduleId)}已恢复正常',
      type: ToastType.success,
      duration: const Duration(seconds: 2),
    );
  }

  Duration _getRecoveryCheckInterval(DegradationLevel? level) {
    switch (level) {
      case DegradationLevel.minor:
        return const Duration(seconds: 30);
      case DegradationLevel.moderate:
        return const Duration(seconds: 60);
      case DegradationLevel.severe:
      case DegradationLevel.hidden:
        return const Duration(seconds: 120);
      default:
        return const Duration(seconds: 30);
    }
  }

  final Map<String, int> _recoverySuccessCount = {};
}
```

### 7.2 用户手动重试

除了自动恢复检测外，用户也可以手动触发重试：

```dart
/// 手动重试控制器
class ManualRetryController {
  final Map<String, int> _retryAttempts = {};

  /// 执行手动重试
  Future<bool> retry(String moduleId) async {
    final attempts = (_retryAttempts[moduleId] ?? 0) + 1;
    _retryAttempts[moduleId] = attempts;

    final registration = DegradationManager.instance
      ._registrations[moduleId];
    if (registration == null) return false;

    // 对所有依赖服务执行健康检查
    bool allHealthy = true;
    for (final serviceId in registration.dependencies) {
      final probe = ActiveHealthProbe(
        serviceId: serviceId,
        healthEndpoint: '/api/v1/health/$serviceId',
        interval: Duration.zero,
        timeout: const Duration(seconds: 5),
        warmupRetries: 0,
      );
      final result = await probe.probe();
      if (!result.success) {
        allHealthy = false;
      }
    }

    if (allHealthy) {
      _retryAttempts.remove(moduleId);
      DegradationManager.instance.maybeRecover(moduleId: moduleId);
      return true;
    }

    // 频率限制：最多每30秒重试一次
    return false;
  }
}
```

```dart
/// 降级内容缓存管理器
class FallbackContentCache {
  static const _storage = FlutterSecureStorage();

  /// 缓存各模块的关键数据快照
  Future<void> cacheModuleSnapshot<T>({
    required String moduleId,
    required String cacheKey,
    required T data,
    Duration ttl = const Duration(hours: 24),
  }) async {
    final entry = CacheEntry<T>(
      data: data,
      timestamp: DateTime.now(),
      ttl: ttl,
    );

    final box = await _getCacheBox(moduleId);
    await box.put(cacheKey, entry.toJson());
  }

  /// 读取缓存数据
  Future<T?> getCachedData<T>({
    required String moduleId,
    required String cacheKey,
  }) async {
    final box = await _getCacheBox(moduleId);
    final json = box.get(cacheKey);
    if (json == null) return null;

    final entry = CacheEntry<T>.fromJson(json);
    if (entry.isExpired) {
      await box.delete(cacheKey);
      return null;
    }

    return entry.data;
  }

  /// 预缓存策略 — 在正常模式下预先缓存降级时需要的数据
  Future<void> precacheCriticalData(String userId) async {
    // 1. 缓存首页工作台数据

      moduleId: 'home',
      cacheKey: 'workbench_$userId',
      data: await HomeApi.getWorkbenchData(userId),

      moduleId: 'analytics',
      cacheKey: 'summary_$userId',

class CacheEntry<T> {

  final DateTime timestamp;
  final Duration ttl;
```

**状态转换条件：**

| 从 | 到 | 条件 |
|----|-----|------|
| Normal | Minor | 服务连续失败 2 次或被动健康分 < 0.6 |
| Normal | Moderate | 服务直接返回 unhealthy 或连续失败 5 次 |
| Normal | Severe | 服务触发未捕获异常或 Crash |
| Minor | Moderate | 在 Minor 状态持续 2 分钟且未恢复 |
| Moderate | Severe | 在 Moderate 状态持续 5 分钟且未恢复 |
| Severe | Hidden | 在 Severe 状态持续 10 分钟且未恢复 |
| Any | Normal | 连续 2 次成功探测（间隔 30s）|
| Hidden→Normal | 需连续 3 次成功探测 |

### 10.2 状态转换实现

```dart
class DegradationStateMachine {
  final Map<String, DegradationLevel> _states = {};
  final Map<String, DateTime> _stateEntryTime = {};
  final Map<String, int> _probeSuccessStreak = {};

  /// 处理健康探测结果
  DegradationLevel? processProbeResult({
    required String moduleId,
    required bool success,
  }) {
    final current = _states[moduleId] ?? DegradationLevel.normal;
    final entryTime = _stateEntryTime[moduleId] ?? DateTime.now();
    final duration = DateTime.now().difference(entryTime);

    if (success) {
      _probeSuccessStreak[moduleId] =
        (_probeSuccessStreak[moduleId] ?? 0) + 1;

      final required = current == DegradationLevel.hidden ? 3 : 2;
      if ((_probeSuccessStreak[moduleId] ?? 0) >= required) {
        return _transitionTo(moduleId, DegradationLevel.normal);
      }
    } else {
      _probeSuccessStreak[moduleId] = 0;

      // 自动升级降级等级
      if (current == DegradationLevel.minor &&
          duration.inMinutes >= 2) {
        return _transitionTo(moduleId, DegradationLevel.moderate);
      }
      if (current == DegradationLevel.moderate &&
          duration.inMinutes >= 5) {
        return _transitionTo(moduleId, DegradationLevel.severe);
      }
      if (current == DegradationLevel.severe &&
          duration.inMinutes >= 10) {
        return _transitionTo(moduleId, DegradationLevel.hidden);
      }
    }

    return null; // 状态未变化
  }

  DegradationLevel _transitionTo(String moduleId, DegradationLevel newLevel) {
    _states[moduleId] = newLevel;
    _stateEntryTime[moduleId] = DateTime.now();
    _probeSuccessStreak[moduleId] = 0;
    return newLevel;
  }
}
```

```dart
/// 降级体验质量评分模型
class DegradationQualityScorer {
  /// 计算单次降级事件的体验质量分（0-100）
  double calculateScore(DegradationEventLog log) {
    double score = 100;

    // 1. 降级持续时间扣分（每分钟扣1分，最多扣30分）
    final durationMin = log.duration.inMinutes.clamp(0, 30);
    score -= durationMin;

    // 2. 降级等级扣分
    switch (log.maxLevel) {
      case DegradationLevel.minor:
        score -= 5;
      case DegradationLevel.moderate:
        score -= 15;
      case DegradationLevel.severe:
        score -= 30;
      case DegradationLevel.hidden:
        score -= 40;
      default:
        break;
    }

    // 3. 用户是否有替代操作加分
    if (log.hasAlternativeAction) score += 10;

    // 4. 用户主动重试并成功加分
    if (log.userRetrySuccess) score += 5;

    return score.clamp(0, 100);
  }
}
```

```dart
/// App 启动时的降级引擎初始化
class DegradationEngineInitializer {
  static Future<void> initialize() async {
    // 1. 初始化健康监测器
    await ServiceHealthMonitor.instance.initialize();

    // 2. 注册所有功能模块
    _registerAllModules();

    // 3. 加载降级配置
    await DegradationManager.instance.loadRemoteConfig();

    // 4. 执行首次全量健康探测
    await ServiceHealthMonitor.instance.probeAll();

    // 5. 预缓存关键数据
    if (UserManager.instance.isLoggedIn) {
      await FallbackContentCache.instance
        .precacheCriticalData(UserManager.instance.userId!);
    }

    // 6. 启动 WebSocket 监听
    WebSocketManager.instance.subscribe(
      'service_health_update',
      ServerHealthPush.handleHealthPush,
    );
  }

  static void _registerAllModules() {
    final modules = [
      ModuleRegistration(
        moduleId: 'ai-tutoring',
        displayName: 'AI辅导',
        dependencies: ['ai-tutoring', 'rag-knowledge'],
        maxDegradation: DegradationLevel.severe,
        strategy: DegradationStrategy(
          moduleId: 'ai-tutoring',
          behaviors: _aiTutoringBehaviors(),
          propagationRules: [
            DependencyPropagationRule(
              serviceId: 'ai-tutoring',
              statusToLevel: {
                ServiceHealthStatus.degraded: DegradationLevel.minor,
                ServiceHealthStatus.unhealthy: DegradationLevel.severe,
              },
            ),
          ],
        ),
        fallbackBuilder: () => ModuleDegradedView(
          moduleId: 'ai-tutoring',
          level: DegradationManager.instance
            .getCurrentLevel('ai-tutoring') ?? DegradationLevel.normal,
        ),
      ),
      // ... 其他模块注册
    ];

    for (final module in modules) {
      DegradationManager.instance.registerModule(module);
    }
  }
}
```

## 17. 总结

本文档定义了 PrimeTop 客户端的功能模块容灾隔离与服务降级体验自适应引擎的完整设计方案。核心价值在于：

1. **隔离性**：任何单个功能模块的后端服务故障不会影响其他模块的正常运行。
2. **优雅性**：降级体验通过缓存数据、替代功能引导、友好的提示文案等方式，最大程度减少用户感知到的服务中断。
3. **自愈性**：自动检测服务恢复并切回正常模式，无需用户手动干预或重启 App。
4. **可配置性**：降级策略、阈值、UI 样式均可通过服务端配置动态调整。
5. **可观测性**：完整的埋点体系让运营和开发团队能监控降级频率、持续时间和用户影响。

该引擎是保障 PrimeTop 作为多模块大型教育 App 在复杂网络环境和后端服务架构下提供稳定用户体验的关键基础设施。
