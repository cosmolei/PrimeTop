# 服务端-教育内容推荐冷启动与新用户内容引导策略引擎-详细设计

## 1. 概述

### 1.1 模块定位

教育内容推荐冷启动引擎是 PrimeTop 个性化推荐体系的前置模块，解决三类冷启动问题：

1. **用户冷启动**：新注册用户无学习历史、无答题记录、无偏好数据时，如何给出合理的初始推荐
2. **内容冷启动**：新入库的教育内容（新题目、新课程、新知识点讲解）缺乏交互数据时，如何获得合理曝光
3. **场景冷启动**：用户首次进入新场景（如首次打开作文辅导、首次使用拍照搜题）时，如何编排初始内容流

本引擎与已有模块的边界划分：
| 已有模块 | 边界 |
| --- | --- |
| 用户学习画像冷启动与初始能力评估引擎 | 负责用户画像建模与能力评估，输出用户特征向量 |
| 内容推荐与个性化推荐引擎 | 负责有充足数据后的常规推荐策略 |
| 推荐内容多样性保障与信息茧房破壁引擎 | 负责推荐结果的多样性后处理 |
| 学习时机感知与场景化内容推荐编排引擎 | 负责基于时间/场景的推荐编排 |
| 学生学习兴趣探索与学科偏好动态建模引擎 | 负责长期兴趣建模 |

**本模块聚焦**：从用户注册到积累足够数据进入常规推荐引擎之前的过渡期（通常为前 7~14 天或前 20~50 次交互），如何编排推荐内容、采集偏好信号、逐步移交给常规推荐引擎。

### 1.2 核心职责

1. 新用户注册后的初始内容流编排与分发
2. 冷启动期的多策略探索推荐（Exploration）
3. 用户隐式反馈信号的实时采集与偏好快速建模
4. 新内容冷启动曝光策略与探索-利用平衡
5. 冷启动到常规推荐的热切换过渡机制
6. 冷启动效果评估与策略自动调优

### 1.3 依赖关系

```
┌─────────────────────────────────────────────────────────────┐
│                  冷启动推荐引擎                               │
├─────────┬──────────┬───────────┬───────────┬───────────────┤
│  依赖   │ 用户画像  │ 内容画像   │ 学习行为   │  常规推荐引擎  │
│  上游   │ 冷启动    │ 标签体系   │ 事件流     │  (热切换目标)  │
└─────────┴──────────┴───────────┴───────────┴───────────────┘
         │
         ▼
┌─────────────────────┐
│  下游消费者           │
│  首页编排 / 同步课堂  │
│  错题复习 / 考点梳理  │
└─────────────────────┘
```

上游依赖：
- **用户服务**：提供用户注册信息（学段、年级、教材版本、学科、目标）
- **用户学习画像冷启动引擎**：提供初始能力评估结果与冷启动画像
- **内容服务**：提供内容元数据、标签、难度、知识图谱关联
- **学习行为事件流**：提供实时交互反馈信号

下游输出：
- **首页编排服务**：首页内容卡片推荐
- **同步课堂服务**：章节学习内容推荐
- **练习测评服务**：题目推荐
- **错题复习服务**：复习内容推荐

| id | BIGINT, PK | 自增主键 |

| exploration_budget | INT | 剩余探索推荐配额 |

| secondary_strategy | VARCHAR(64) | 辅助策略 |
| gradated_to | VARCHAR(64) | 毕业后移交的常规推荐策略 |
| graduated_at | DATETIME | 毕业时间 |
| metadata | JSON | 扩展字段 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

```sql

    id              BIGINT AUTO_INCREMENT PRIMARY KEY,
    user_id         BIGINT NOT NULL UNIQUE,
    stage           VARCHAR(32) NOT NULL DEFAULT 'INIT',
    entered_at      DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    interaction_count   INT NOT NULL DEFAULT 0,
    feedback_count      INT NOT NULL DEFAULT 0,

) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 4. 业务逻辑

### 4.1 冷启动阶段状态机

```
                    ┌──────┐
     用户注册 ──────▶│ INIT │
                    └──┬───┘
                       │ 首次推荐请求 + 初始画像就绪
                       ▼
               ┌───────────────┐
               │ EXPLORATION   │◀── 探索推荐 + 反馈采集
               │ (多策略探索)   │
               └──────┬────────┘
                      │ confidence_score ≥ 0.65 且 interaction_count ≥ 30
                      ▼
               ┌───────────────┐
               │ WARMING       │◀── 混合推荐（冷启动策略 + 常规策略加权）
               │ (预热过渡)     │
               └──────┬────────┘
                      │ confidence_score ≥ 0.75 且 interaction_count ≥ 50
                      │ 持续 3 天稳定
                      ▼
               ┌───────────────┐
               │ GRADUATED     │───▶ 移交常规推荐引擎
               │ (已毕业)       │
               └───────────────┘
```

**阶段详解：**

| 阶段 | 持续时间 | 策略 | 探索比例 | 目标 |
| --- | --- | --- | --- | --- |
| INIT | 0~1次请求 | 规则驱动（基于注册信息） | 30% | 首次推荐、触发初始画像评估 |
| EXPLORATION | 1~30次交互 | 多策略探索 | 40% | 快速采集偏好信号、构建偏好画像 |
| WARMING | 30~50次交互 | 混合推荐 | 20%→5% | 逐步增加常规推荐权重、验证画像稳定性 |
| GRADUATED | - | 常规推荐引擎 | 按常规策略 | 移交常规推荐 |

### 4.2 推荐策略详解

#### 4.2.1 策略一：规则驱动推荐（RULE_BASED）

**适用阶段**：INIT
**适用条件**：用户刚注册，仅有基础信息（学段、年级、教材版本、学科、目标）

```python
class RuleBasedStrategy:
    """基于规则的初始推荐策略"""
    
    def recommend(self, user_context: UserContext, scene: str, count: int) -> list[RecommendItem]:
        rules = self._get_rules(user_context.segment, user_context.grade, scene)
        items = []
        
        for rule in rules:
            # 规则1: 当前教材版本第一章基础内容
            if rule.type == "TEXTBOOK_FIRST_CHAPTER":
                chapter = self.chapter_service.get_first_chapter(
                    user_context.textbook_version,
                    user_context.grade,
                    rule.subject
                )
                content = self.content_service.get_chapter_intro(chapter.id)
                items.append(self._to_recommend_item(content, strategy="RULE_BASED",
                    reason="教材首章引导"))
            
            # 规则2: 学段入口知识检测
            elif rule.type == "GRADE_ENTRY_DIAGNOSTIC":
                diagnostic = self.diagnostic_service.get_grade_entry_test(
                    user_context.segment, user_context.grade
                )
                items.append(self._to_recommend_item(diagnostic, strategy="RULE_BASED",

            # 规则4: 目标驱动推荐
            elif rule.type == "GOAL_DRIVEN":
```

```python
            segment=user_context.segment,

            strategy="POPULARITY_EXPLORATION"

            noise = random.uniform(-0.1, 0.1)
            item.rank_score = item.popularity_score * 0.8 + noise + item.recency_score * 0.2
        return sorted(items, key=lambda x: x.rank_score, reverse=True)
```

```python
class CollaborativeColdStartStrategy:
    """基于群体相似性的冷启动协同过滤"""
    
    def recommend(self, user_context: UserContext, scene: str, count: int) -> list[RecommendItem]:
        # 获取用户当前冷启动偏好画像
        profile = self.cold_start_profile.get(user_context.user_id)
        
        if not profile or profile.interaction_count < 5:
            return []  # 交互不足，回退到其他策略
        
        # 构建用户特征向量
        user_vector = self._build_feature_vector(user_context, profile)
        
        # 在同年级群体中寻找最近邻
        neighbors = self.similarity_index.search(
            vector=user_vector,
            segment=user_context.segment,
            grade=user_context.grade,
            k=50,
            min_interactions=30  # 邻居必须有足够交互
        )
        
        # 聚合邻居的高满意度内容
        candidate_scores = defaultdict(float)
        for neighbor_id, similarity in neighbors:
            liked_items = self.feedback_service.get_positive_items(
                neighbor_id, limit=20
            )
            for item in liked_items:
                # 过滤用户已看过的
                if not self.interaction_service.has_interacted(user_context.user_id, item.content_id):
                    candidate_scores[item.content_id] += similarity * item.satisfaction_score
        
        # 取Top-N
        top_items = sorted(candidate_scores.items(), key=lambda x: x[1], reverse=True)[:count]
        
        items = []
        for content_id, score in top_items:
            content = self.content_service.get_by_id(content_id)
            if content:
                items.append(self._to_recommend_item(
                    content, strategy="COLLABORATIVE",
                    reason=f"同年级同学也在学",
                    rank_score=score
                ))
        
        return items
```

```python
class HybridColdStartStrategy:
    """冷启动混合推荐策略"""
    
    STRATEGY_WEIGHTS = {
        "WARMING": {
            "KNOWLEDGE_GRAPH": 0.35,
            "COLLABORATIVE": 0.30,
            "POPULARITY": 0.20,
            "RULE_BASED": 0.15
        },
        "EXPLORATION": {
            "KNOWLEDGE_GRAPH": 0.30,
            "POPULARITY": 0.40,
            "COLLABORATIVE": 0.10,
            "RULE_BASED": 0.20
        }
    }
    
    def recommend(self, user_context: UserContext, scene: str, count: int) -> list[RecommendItem]:
        stage = self.cold_start_state.get_stage(user_context.user_id)
        weights = self.STRATEGY_WEIGHTS.get(stage, self.STRATEGY_WEIGHTS["EXPLORATION"])
        
        # 并行执行各策略
        strategy_results = {}
        with ThreadPoolExecutor(max_workers=4) as executor:
            futures = {}
            for strategy_name, weight in weights.items():
                if weight > 0:
                    strategy = self.strategy_factory.get(strategy_name)
                    futures[strategy_name] = executor.submit(
                        strategy.recommend, user_context, scene, count
                    )
            for name, future in futures.items():
                try:
                    strategy_results[name] = future.result(timeout=2.0)
                except Exception as e:
                    logger.warning(f"Strategy {name} failed: {e}")
                    strategy_results[name] = []
        
        # 加权融合
        merged = self._merge_and_score(strategy_results, weights, count)
        
        # 多样性后处理
        diversified = self._diversity_filter(merged, count)
        
        return diversified
```

#### 4.3.2 快速画像更新算法

```python
class PreferenceProfileUpdater:
    """冷启动偏好画像增量更新"""
    
    SIGNAL_WEIGHTS = {
        "CLICK": 0.1, "DWELL_SHORT": -0.2, "DWELL_MEDIUM": 0.3,
        "DWELL_LONG": 0.5, "COMPLETE": 0.6, "CORRECT": 0.8,
        "WRONG": 0.4, "HINT_USED": 0.3, "LIKE": 0.7,
        "COLLECT": 0.8, "SKIP": -0.1, "ABANDON": -0.2, "SHARE": 0.9
    }
    
    def update(self, user_id: int, feedback: FeedbackSignal) -> UpdateResult:
        profile = self.profile_store.get_or_create(user_id)
        signal_weight = self.SIGNAL_WEIGHTS.get(feedback.feedback_type, 0)
        
        # 1. 更新学科偏好
        subject = feedback.content.subject
        current_weight = profile.preferred_subjects.get(subject, 0.0)
        # 指数移动平均
        alpha = 0.3  # 冷启动期较快更新
        new_weight = alpha * signal_weight + (1 - alpha) * current_weight
        profile.preferred_subjects[subject] = new_weight
        
        # 2. 更新难度偏好
        if feedback.feedback_type in ["CORRECT", "COMPLETE"]:
            # 正向反馈 → 当前难度合适或偏低
            self._adjust_difficulty(profile, feedback.content.difficulty, direction="up")
        elif feedback.feedback_type in ["WRONG", "HINT_USED", "ABANDON"]:
            # 负向反馈（但仍有兴趣）→ 当前难度偏高
            self._adjust_difficulty(profile, feedback.content.difficulty, direction="down")
        
        # 3. 更新内容类型偏好
        content_type = feedback.content.content_type
        ct_weight = profile.preferred_content_types.get(content_type, 0.0)
        profile.preferred_content_types[content_type] = alpha * max(signal_weight, 0) + (1 - alpha) * ct_weight
        
        # 4. 更新兴趣标签
        for kp_tag in feedback.content.knowledge_point_tags:
            tag_weight = profile.interest_tags.get(kp_tag, 0.0)
            profile.interest_tags[kp_tag] = alpha * signal_weight + (1 - alpha) * tag_weight
        
        # 5. 更新活跃时间段
        current_hour = datetime.now().hour
        self._update_active_time(profile, current_hour)
        
        # 6. 更新学习风格提示
        self._infer_learning_style(profile, feedback)
        
        # 7. 重新计算置信度
        old_confidence = profile.confidence_score
        profile.confidence_score = self._calculate_confidence(profile)
        confidence_delta = profile.confidence_score - old_confidence
        
        # 8. 持久化
        self.profile_store.save(profile)
        
        return UpdateResult(
            confidence_delta=confidence_delta,
            current_confidence=profile.confidence_score,
            graduated=profile.confidence_score >= 0.65
        )
    
    def _calculate_confidence(self, profile: ColdStartProfile) -> float:
        """基于信号丰富度和一致性的置信度计算"""
        # 信号丰富度：有多少不同维度的数据
        subject_count = len([v for v in profile.preferred_subjects.values() if abs(v) > 0.1])
        tag_count = len([v for v in profile.interest_tags.values() if abs(v) > 0.1])
        ct_count = len([v for v in profile.preferred_content_types.values() if v > 0.1])
        
        richness = min(1.0, (subject_count * 0.2 + tag_count * 0.05 + ct_count * 0.15))
        
        # 信号一致性：偏好分布的确定性（熵越低，确定性越高）
        subject_entropy = self._entropy(list(profile.preferred_subjects.values()))
        consistency = max(0, 1.0 - subject_entropy)
        
        # 交互量因子
        volume_factor = min(1.0, profile.interaction_count / 50.0)
        
        # 综合
        confidence = richness * 0.4 + consistency * 0.3 + volume_factor * 0.3
        return round(confidence, 4)
    
    def _entropy(self, values: list[float]) -> float:
        """计算归一化熵"""
        if not values:
            return 1.0
        total = sum(abs(v) for v in values)
        if total == 0:
            return 1.0
        probs = [abs(v) / total for v in values]
        entropy = -sum(p * math.log(p + 1e-10) for p in probs if p > 0)
        max_entropy = math.log(len(probs)) if len(probs) > 1 else 1.0
        return entropy / max_entropy if max_entropy > 0 else 0
```

### 4.4 探索-利用平衡（Epsilon-Greedy + UCB）

```python
class ExplorationExploitationBalancer:
    """冷启动期的探索-利用平衡控制器"""
    
    def decide(self, user_id: int, candidates: list[CandidateItem], 
               budget: int, stage: str) -> list[RecommendItem]:
        # 根据阶段确定探索比例
        epsilon = self._get_epsilon(stage, budget)
        
        exploit_count = int(len(candidates) * (1 - epsilon))
        explore_count = len(candidates) - exploit_count
        
        # 利用：选择已知最匹配的内容
        exploit_items = sorted(
            candidates, 
            key=lambda c: c.match_score, 
            reverse=True
        )[:exploit_count]
        
        # 探索：使用UCB策略选择内容
        explore_pool = [c for c in candidates if c not in exploit_items]
        explore_items = self._ucb_select(explore_pool, explore_count)
        
        # 交替排列（避免探索内容全部在末尾）
        result = self._interleave(exploit_items, explore_items)
        
        return result
    
    def _get_epsilon(self, stage: str, budget: int) -> float:
        """动态探索率"""
        if stage == "INIT":
            return 0.4
        elif stage == "EXPLORATION":
            # 随预算消耗递减
            return max(0.1, 0.4 * (budget / 50))
        elif stage == "WARMING":
            return 0.1
        return 0.05
    
    def _ucb_select(self, pool: list[CandidateItem], count: int) -> list[CandidateItem]:
        """UCB（Upper Confidence Bound）选择策略"""
        scored = []
        for item in pool:
            # UCB公式: 平均收益 + 置信区间宽度
            if item.exposure_count == 0:
                # 未曝光内容给予最高探索优先级
                ucb_score = float('inf')
            else:
                avg_reward = item.total_reward / item.exposure_count
                confidence = math.sqrt(2 * math.log(item.total_pool_exposure) / item.exposure_count)
                ucb_score = avg_reward + confidence
            scored.append((item, ucb_score))
        
        scored.sort(key=lambda x: x[1], reverse=True)
        return [item for item, _ in scored[:count]]
```

### 4.5 新内容冷启动曝光策略

```python
class ContentColdStartManager:
    """新内容冷启动曝光管理"""
    
    def register_new_content(self, content_id: int, content_type: str, 
                             metadata: ContentMetadata) -> None:
        """新内容入库时注册到冷启动池"""
        ttl_days = self._determine_ttl(content_type, metadata)
        self.pool_dao.insert(
            content_id=content_id,
            content_type=content_type,
            status="NEW",
            ttl_at=datetime.now() + timedelta(days=ttl_days)
        )
    
    def sample_for_exposure(self, segment: str, grade: str, 
                            count: int, exclude_ids: set[int]) -> list[int]:
        """为推荐采样新内容"""
        # 获取冷启动池中活跃的新内容
        candidates = self.pool_dao.get_active_by_segment(
            segment=segment, grade=grade, 
            statuses=["NEW", "WARMING"],
            exclude_ids=exclude_ids
        )
        
        if not candidates:
            return []
        
        scored = []
        for c in candidates:
            # 优先曝光 NEW 状态的内容
            recency_bonus = 1.0 if c.status == "NEW" else 0.5
            # 曝光不足的内容优先
            exposure_factor = 1.0 / (1 + c.exposure_count * 0.1)
            # 满意率（有反馈后）
            if c.interaction_count > 0:
                satisfaction = c.positive_feedback_count / c.interaction_count
            else:
                satisfaction = 0.5  # 中性先验
            
            score = recency_bonus * 0.3 + exposure_factor * 0.4 + satisfaction * 0.3
            scored.append((c.content_id, score))
        
        scored.sort(key=lambda x: x[1], reverse=True)
        return [cid for cid, _ in scored[:count]]
    
    def update_content_feedback(self, content_id: int, feedback: FeedbackSignal) -> None:
        """更新新内容的反馈数据"""
        pool_item = self.pool_dao.get_by_content_id(content_id)
        if not pool_item:
            return
        
        pool_item.exposure_count += 1
        if feedback.feedback_type in ["CLICK", "DWELL_MEDIUM", "DWELL_LONG", 
                                       "COMPLETE", "CORRECT", "LIKE", "COLLECT"]:
            pool_item.positive_feedback_count += 1
        elif feedback.feedback_type in ["SKIP", "ABANDON", "DWELL_SHORT"]:
            pool_item.negative_feedback_count += 1
        
        pool_item.interaction_count += 1
        pool_item.ctr = pool_item.positive_feedback_count / pool_item.exposure_count
        pool_item.satisfaction_rate = (
            pool_item.positive_feedback_count / pool_item.interaction_count
            if pool_item.interaction_count > 0 else 0
        )
        
        # 状态流转
        if pool_item.status == "NEW" and pool_item.exposure_count >= 10:
            pool_item.status = "WARMING"
        elif pool_item.status == "WARMING":
            if pool_item.satisfaction_rate >= 0.6 and pool_item.interaction_count >= 20:
                pool_item.status = "GRADUATED"
                pool_item.graduated_at = datetime.now()
            elif pool_item.satisfaction_rate < 0.3 and pool_item.interaction_count >= 10:
                pool_item.status = "DEPRIORITIZED"
        
        self.pool_dao.save(pool_item)
```

### 4.6 冷启动到常规推荐的热切换

```python
class ColdStartGraduator:
    """冷启动毕业与热切换管理"""
    
    GRADUATION_CRITERIA = {
        "min_interactions": 30,
        "min_confidence": 0.65,
        "min_feedback_count": 15,
        "min_subjects_explored": 2,
        "stable_days": 3  # 近3天置信度波动 < 0.1
    }
    
    def check_graduation(self, user_id: int) -> GraduationResult:
        """检查是否满足毕业条件"""
        state = self.state_dao.get(user_id)
        profile = self.profile_store.get(user_id)
        
        if state.stage == "GRADUATED":
            return GraduationResult(already_graduated=True)
        
        checks = {
            "interactions": state.interaction_count >= self.GRADUATION_CRITERIA["min_interactions"],
            "confidence": state.confidence_score >= self.GRADUATION_CRITERIA["min_confidence"],
            "feedback": state.feedback_count >= self.GRADUATION_CRITERIA["min_feedback_count"],
            "subjects": len([v for v in profile.preferred_subjects.values() if abs(v) > 0.1]) >= 2,
            "stability": self._check_stability(user_id)
        }
        
        all_passed = all(checks.values())
        
        if all_passed:
            return self._graduate(user_id, state, profile)
        else:
            return GraduationResult(
                graduated=False,
                failed_checks=[k for k, v in checks.items() if not v],
                progress=self._calculate_progress(state, profile, checks)
            )
    
    def _graduate(self, user_id: int, state: ColdStartState, 
                  profile: ColdStartProfile) -> GraduationResult:
        """执行毕业迁移"""
        # 1. 将冷启动画像转换为常规推荐引擎的输入格式
        transfer_payload = self._build_transfer_payload(profile)
        
        # 2. 调用常规推荐引擎的画像导入接口
        self.regular_recommendation_engine.import_profile(
            user_id=user_id,
            profile=transfer_payload
        )
        
        # 3. 更新冷启动状态
        state.stage = "GRADUATED"
        state.graduated_at = datetime.now()
        state.gradated_to = "PERSONALIZED_RECOMMENDATION_ENGINE"
        self.state_dao.save(state)
        
        # 4. 发送毕业事件
        self.event_bus.publish(ColdStartGraduatedEvent(
            user_id=user_id,
            profile_snapshot=profile.to_dict(),
            graduation_stats={
                "total_interactions": state.interaction_count,
                "total_feedback": state.feedback_count,
                "days_in_cold_start": (datetime.now() - state.entered_at).days,
                "final_confidence": state.confidence_score
            }
        ))
        
        # 5. WARMING阶段的渐进式切换（双写期）
        # 在正式毕业前，WARMING阶段已经进行双写：
        # - 冷启动引擎和常规引擎同时打分
        # - 冷启动权重从1.0线性递减到0.0
        # - 常规引擎权重从0.0线性递增到1.0
        # 毕业后冷启动引擎完全退出
        
        return GraduationResult(
            graduated=True,
            transferred_to="PERSONALIZED_RECOMMENDATION_ENGINE",
            graduation_stats={
                "total_interactions": state.interaction_count,
                "days_in_cold_start": (datetime.now() - state.entered_at).days,
                "final_confidence": state.confidence_score
            }
        )
```

### 4.7 WARMING 阶段双写融合

```python
class WarmingPhaseBlender:
    """WARMING阶段的冷启动与常规推荐融合"""
    
    def blend(self, user_id: int, cold_start_items: list[RecommendItem],
              regular_items: list[RecommendItem]) -> list[RecommendItem]:
        state = self.state_dao.get(user_id)
        
        # 计算融合权重（基于WARMING阶段的进度）
        warming_progress = self._calculate_warming_progress(state)
        # warming_progress: 0.0 (刚进入WARMING) -> 1.0 (即将毕业)
        
        cold_weight = max(0.0, 1.0 - warming_progress * 2)  # 从1.0降到0.0
        regular_weight = min(1.0, warming_progress * 2)      # 从0.0升到1.0
        
        # 合并候选并加权
        for item in cold_start_items:
            item.blended_score = item.rank_score * cold_weight
        for item in regular_items:
            item.blended_score = item.rank_score * regular_weight
        
        merged = cold_start_items + regular_items
        merged.sort(key=lambda x: x.blended_score, reverse=True)
        
        return merged[:len(cold_start_items)]  # 保持输出数量一致
```

```python
class ColdStartRecommendationOrchestrator:
    """冷启动推荐请求编排器"""
    
    def __init__(self, strategy_factory, profile_store, state_dao, 
                 feedback_processor, content_pool, event_bus):
        self.strategy_factory = strategy_factory
        self.profile_store = profile_store
        self.state_dao = state_dao
        self.feedback_processor = feedback_processor
        self.content_pool = content_pool
        self.event_bus = event_bus
    
    def recommend(self, request: ColdStartRecommendRequest) -> ColdStartRecommendResponse:
        user_id = request.user_id
        
        # 1. 获取/初始化冷启动状态
        state = self.state_dao.get_or_init(user_id, request.context)
        
        if state.stage == "GRADUATED":
            raise ColdStartAlreadyGraduatedError(
                "User has already graduated from cold start"
            )
        
        # 2. 阶段流转检查
        self._try_advance_stage(user_id, state)
        
        # 3. 选择策略
        strategy = self._select_strategy(state, request.context)
        
        # 4. 执行推荐
        try:
            items = strategy.recommend(
                user_context=request.context,
                scene=request.scene,
                count=request.page_size
            )
        except StrategyExecutionError as e:
            logger.error(f"Strategy {strategy.name} failed: {e}")
            # 降级到规则策略
            items = self.strategy_factory.get("RULE_BASED").recommend(
                user_context=request.context,
                scene=request.scene,
                count=request.page_size
            )
        
        # 5. 注入新内容探索
        if state.exploration_budget > 0:
            exploration_slots = max(1, int(len(items) * 0.3))
            new_content_items = self._inject_new_content(
                items, request.context, exploration_slots
            )
            items = new_content_items
        
        # 6. 记录探索日志
        session_id = self._generate_session_id(user_id)
        self._log_exploration(user_id, session_id, items, strategy.name)
        
        # 7. 构建响应
        return ColdStartRecommendResponse(
            items=items,
            cold_start_info=ColdStartInfo(
                stage=state.stage,
                interaction_count=state.interaction_count,
                confidence_score=state.confidence_score,
                remaining_exploration_budget=state.exploration_budget,
                estimated_graduation_interactions=max(0, 50 - state.interaction_count)
            ),
            session_id=session_id
        )
    
    def _select_strategy(self, state: ColdStartState, 
                         context: UserContext) -> RecommendationStrategy:
        if state.stage == "INIT":
            return self.strategy_factory.get("RULE_BASED")
        elif state.stage == "EXPLORATION":
            if state.interaction_count >= 5:
                return self.strategy_factory.get("HYBRID")
            else:
                return self.strategy_factory.get("POPULARITY")
        elif state.stage == "WARMING":
            return self.strategy_factory.get("HYBRID")
        else:
            return self.strategy_factory.get("RULE_BASED")
    
    def _try_advance_stage(self, user_id: int, state: ColdStartState) -> None:
        if state.stage == "INIT" and state.interaction_count >= 1:
            state.stage = "EXPLORATION"
            state.entered_at = datetime.now()
            self.state_dao.save(state)
            self.event_bus.publish(StageTransitionEvent(
                user_id=user_id, from_stage="INIT", to_stage="EXPLORATION"
            ))
        elif state.stage == "EXPLORATION":
            result = self.graduator.check_graduation(user_id)
            if result.graduated:
                state.stage = "GRADUATED"
                self.state_dao.save(state)
            elif result.can_enter_warming:
                state.stage = "WARMING"
                state.entered_at = datetime.now()
                self.state_dao.save(state)
                self.event_bus.publish(StageTransitionEvent(
                    user_id=user_id, from_stage="EXPLORATION", to_stage="WARMING"
                ))
```

```python
class ColdStartFeedbackConsumer:
    """消费用户反馈信号，更新冷启动状态和偏好画像"""
    
    def __init__(self, profile_updater, state_dao, exploration_log_dao,
                 content_pool_manager, event_bus):
        self.profile_updater = profile_updater
        self.state_dao = state_dao
        self.exploration_log_dao = exploration_log_dao
        self.content_pool_manager = content_pool_manager
        self.event_bus = event_bus
    
    async def on_feedback(self, event: FeedbackEvent) -> None:
        """处理反馈事件（通过消息队列异步消费）"""
        user_id = event.user_id
        
        # 1. 更新探索日志
        self.exploration_log_dao.update_feedback(
            user_id=user_id,
            session_id=event.session_id,
            content_id=event.content_id,
            feedback_type=event.feedback_type,
            feedback_value=event.feedback_value,
            dwell_duration_ms=event.dwell_duration_ms
        )
        
        # 2. 更新冷启动偏好画像
        update_result = self.profile_updater.update(user_id, event)
        
        # 3. 更新冷启动状态
        state = self.state_dao.get(user_id)
        if state and state.stage != "GRADUATED":
            state.interaction_count += 1
            if event.feedback_type != "NONE":
                state.feedback_count += 1
            state.confidence_score = update_result.current_confidence
            
            # 扣减探索预算
            if event.feedback_type in ["CLICK", "COMPLETE", "CORRECT", 
                                        "LIKE", "COLLECT"]:
                state.exploration_budget = max(0, state.exploration_budget - 1)
            
            self.state_dao.save(state)
        
        # 4. 更新内容冷启动池
        self.content_pool_manager.update_content_feedback(
            event.content_id, event
        )
        
        # 5. 检查是否触发毕业
        if update_result.graduated:
            self.event_bus.publish_async(
                GraduationCheckTriggered(user_id=user_id)
            )
```

```python
class ColdStartErrorHandler:
    """冷启动推荐错误处理"""
    
    STRATEGY_FALLBACK_CHAIN = {
        "HYBRID": ["KNOWLEDGE_GRAPH", "POPULARITY", "RULE_BASED"],
        "COLLABORATIVE": ["POPULARITY", "RULE_BASED"],
        "KNOWLEDGE_GRAPH": ["POPULARITY", "RULE_BASED"],
        "POPULARITY": ["RULE_BASED"],
        "RULE_BASED": []  # 终极兜底
    }
    
    def handle_strategy_failure(self, strategy_name: str, error: Exception,
                                request: ColdStartRecommendRequest) -> list[RecommendItem]:
        logger.error(
            f"Cold start strategy {strategy_name} failed for "
            f"user {request.user_id}: {error}",
            exc_info=True
        )
        
        # 尝试降级链中的下一个策略
        fallback_chain = self.STRATEGY_FALLBACK_CHAIN.get(strategy_name, ["RULE_BASED"])
        
        for fallback_name in fallback_chain:
            try:
                strategy = self.strategy_factory.get(fallback_name)
                items = strategy.recommend(
                    user_context=request.context,
                    scene=request.scene,
                    count=request.page_size
                )
                logger.info(f"Fallback to {fallback_name} succeeded")
                return items
            except Exception as e:
                logger.warning(f"Fallback {fallback_name} also failed: {e}")
                continue
        
        # 终极兜底：返回静态推荐
        return self._get_static_recommendations(request.context, request.page_size)
    
    def _get_static_recommendations(self, context: UserContext, 
                                     count: int) -> list[RecommendItem]:
        """静态兜底推荐（基于学段年级的预设内容）"""
        static = self.static_cache.get(
            segment=context.segment,
            grade=context.grade,
            scene="HOME_FEED"
        )
        return static[:count] if static else []
```

```python
class ColdStartConsistencyGuard:
    """冷启动数据一致性保障"""
    
    def reconcile_state(self, user_id: int) -> None:
        """定期对账：确保状态计数与实际日志一致"""
        state = self.state_dao.get(user_id)
        if not state:
            return
        
        # 从探索日志重新计算计数
        actual_interactions = self.exploration_log_dao.count_interactions(user_id)
        actual_feedbacks = self.exploration_log_dao.count_feedbacks(user_id)
        
        if (abs(state.interaction_count - actual_interactions) > 5 or
            abs(state.feedback_count - actual_feedbacks) > 3):
            logger.warning(
                f"State drift detected for user {user_id}: "
                f"state={state.interaction_count}/{state.feedback_count}, "
                f"actual={actual_interactions}/{actual_feedbacks}"
            )
            state.interaction_count = actual_interactions
            state.feedback_count = actual_feedbacks
            self.state_dao.save(state)
```

```python
class ColdStartConcurrencyController:
    """并发推荐请求控制"""
    
    # 同一用户同时只允许一个推荐请求在处理
    USER_LOCK_TIMEOUT = 5  # seconds
    
    async def acquire_user_lock(self, user_id: int) -> bool:
        """获取用户级推荐锁"""
        lock_key = f"cs:recommend:lock:{user_id}"
        return await self.redis.set(
            lock_key, "1", 
            nx=True,  # 只在不存在时设置
            ex=self.USER_LOCK_TIMEOUT
        )
    
    async def release_user_lock(self, user_id: int) -> None:
        lock_key = f"cs:recommend:lock:{user_id}"
        await self.redis.delete(lock_key)
```

```python
class ColdStartValidator:
    """输入数据校验"""
    
    VALID_SCENES = {"HOME_FEED", "SYNC_CLASSROOM", "EXERCISE", 
                    "ERROR_REVIEW", "EXAM_PREP", "AI_TUTOR"}
    VALID_STAGES = {"INIT", "EXPLORATION", "WARMING", "GRADUATED"}
    VALID_FEEDBACK_TYPES = {"CLICK", "DWELL_SHORT", "DWELL_MEDIUM", "DWELL_LONG",
                            "COMPLETE", "CORRECT", "WRONG", "HINT_USED",
                            "LIKE", "COLLECT", "SKIP", "ABANDON", "SHARE", "NONE"}
    
    def validate_recommend_request(self, request: dict) -> None:
        if not request.get("user_id"):
            raise ValidationError("user_id is required")
        if request.get("scene") not in self.VALID_SCENES:
            raise ValidationError(f"Invalid scene: {request.get('scene')}")
        context = request.get("context", {})
        if not context.get("segment") or not context.get("grade"):
            raise ValidationError("segment and grade are required")
        page_size = request.get("page_size", 10)
        if page_size < 1 or page_size > 50:
            raise ValidationError("page_size must be between 1 and 50")
    
    def validate_feedback(self, feedback: dict) -> None:
        if feedback.get("feedback_type") not in self.VALID_FEEDBACK_TYPES:
            raise ValidationError(
                f"Invalid feedback_type: {feedback.get('feedback_type')}"
            )
        if not feedback.get("content_id"):
            raise ValidationError("content_id is required")
        if not feedback.get("session_id"):
            raise ValidationError("session_id is required")
```

```python
                "page_size": 5
            })
            for item in resp.json()["data"]["items"]:
                self.client.post("/api/v1/recommend/cold-start/feedback", json={
                    "user_id": user_id,
                    "session_id": resp.json()["data"]["session_id"],
                    "content_id": item["content_id"],
                    "feedback_type": "COMPLETE",
                    "feedback_value": 0.7
                })
        
        # 5. 检查毕业状态
        status = self.client.get(f"/api/v1/recommend/cold-start/status?user_id={user_id}")
        assert status.json()["data"]["stage"] in ["WARMING", "GRADUATED"]
```

## 12. 与已有模块协作关系

```
┌──────────────────────────┐         ┌──────────────────────────────┐
│  用户学习画像冷启动引擎    │─────────▶│  本模块（冷启动推荐引擎）      │
│  输出: 初始能力评估、      │  画像     │  输入: 用户画像、内容画像      │
│  冷启动用户画像           │  数据     │  输出: 冷启动推荐列表          │
└──────────────────────────┘         └──────────┬───────────────────┘
                                                │
┌──────────────────────────┐         ┌──────────▼───────────────────┐
│  内容推荐与个性化推荐引擎  │◀────────│  WARMING阶段双写融合           │
│  输入: 常规用户画像        │  热切换   │  冷启动权重递减→常规权重递增   │
│  输出: 个性化推荐          │  迁移     │  毕业后完全移交                │
└──────────────────────────┘         └──────────┬───────────────────┘
                                                │
┌──────────────────────────┐         ┌──────────▼───────────────────┐
│  推荐内容多样性保障引擎    │─────────▶│  冷启动推荐结果多样性后处理    │
│  输入: 候选列表            │  多样性   │  确保学科、难度、类型分布      │
│  输出: 去重后的多样性列表  │  过滤     │                              │
└──────────────────────────┘         └──────────────────────────────┘
```

**数据流：**

1. **用户注册** → 用户服务发送 `UserRegisteredEvent` → 本模块初始化冷启动状态（INIT阶段）
2. **首次推荐请求** → 本模块调用规则策略 → 返回初始推荐 → 同时触发用户画像冷启动引擎进行能力评估
3. **用户交互** → 行为事件流 → 本模块消费反馈信号 → 更新偏好画像与置信度
4. **达到WARMING条件** → 本模块启动双写 → 冷启动策略 + 常规推荐策略并行打分 → 加权融合
5. **达到毕业条件** → 本模块将偏好画像迁移到常规推荐引擎 → 状态置为GRADUATED → 后续请求路由到常规引擎
6. **新内容入库** → 内容服务发送 `ContentCreatedEvent` → 本模块注册到冷启动池 → 在探索推荐中分配曝光

### 13.2 冷启动效果评估指标

| 指标 | 计算方式 | 目标值 |
| --- | --- | --- |
| 冷启动期用户活跃率 | 冷启动期DAU / 冷启动期注册用户数 | ≥ 60% |
| 冷启动期次留 | 次日回访率 | ≥ 50% |
| 冷启动期7留 | 7日回访率 | ≥ 30% |
| 平均冷启动天数 | 从注册到毕业的平均天数 | ≤ 7天 |
| 冷启动期推荐点击率 | 点击数 / 推荐数 | ≥ 40% |
| 冷启动期推荐完成率 | 完成数 / 推荐数 | ≥ 25% |
| 毕业后推荐效果提升 | 毕业后CTR - 冷启动期CTR | ≥ 10% |
| 新内容冷启动毕业率 | 14天内达到GRADUATED的内容比例 | ≥ 60% |

### 13.3 术语表

| 术语 | 说明 |
| --- | --- |
| 冷启动 | 新用户/新内容缺乏历史数据时的推荐阶段 |
| 探索（Exploration） | 推荐用户未接触过的内容以采集偏好信号 |
| 利用（Exploitation） | 推荐已知匹配用户偏好的内容 |
| 热切换 | 从冷启动引擎无缝切换到常规推荐引擎 |
| 双写 | WARMING阶段冷启动引擎和常规引擎同时计算并加权融合 |
| 探索预算 | 冷启动期允许的探索性推荐次数上限 |
| 置信度 | 偏好画像的可靠程度，用于判断是否可以毕业 |
| UCB | Upper Confidence Bound，一种探索-利用平衡算法 |
| EMA | Exponential Moving Average，指数移动平均 |
